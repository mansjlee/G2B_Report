Red Hat 제안
불가능 요소
  • [경쟁 DBMS 확정] 현행 DBMS로 Tibero가 명시되어 있어 Red Hat Data Grid, AMQ 등 데이터 레이어 제품 신규 제안 어려움
  • [클라우드 플랫폼 제약] 민간 클라우드로 가비아(IaaS)를 사용 중이며, OpenShift 기반 PaaS 전환 요구사항이 없어 OpenShift 신규 제안 난이도 높음
  • [MPR-004 상용SW 목록 내 Red Hat 제품 미명시] 통합발주 상용SW 13종 목록에 Red Hat 제품이 직접 명시되지 않음 (단, 세부 내용은 비공개로 JBoss EAP 포함 가능성 존재)
  • [20억 미만 중소기업 제한] 대기업·중견기업 입찰 참여 제한 사업으로 Red Hat 직접 참여 불가, SI 파트너를 통한 간접 공급 필요
  • [순수 운영·유지관리 사업] 신규 S/W 도입보다는 기존 시스템 유지관리 위주이므로 신규 라이선스 영업 기회는 제한적
Red Hat 제안
가능 요소
  • [JBoss EAP 7.4 현행 WAS 명시 — 핵심 기회] 시스템 구성현황에 WAS로 JBoss EAP 7.4(Red Hat 상용 제품)가 명시되어 있음. 운영·유지관리 사업 특성상 기존 JBoss EAP 구독 갱신(Annual Subscription Renewal)이 사업 범위에 포함될 가능성이 높으며, 비공개 상용SW 세부 목록에 포함 여부 확인 필요
  • [RHEL 제안 가능성] 현행 OS가 "Linux"로 명시되어 있어 특정 배포판 미확정 시 RHEL 제안 가능. 운영 안정성 및 보안 지원(CVE 패치, Extended Support) 강점 활용
  • [Ansible 자동화 제안 여지] 24시간 365일 무중단 운영, 정기 보안취약점 점검, 패치 관리 등 반복 운영 업무 자동화를 위한 Ansible Automation Platform 제안 가능
  • [Java 기반 시스템 — JBoss EAP 적합성] 개발 언어 Java/JSP, 프레임워크 기반 시스템으로 JBoss EAP의 기술 적합성 높음. EAP 버전 업그레이드(7.4 → 8.x) 제안 기회 존재
  • [보안 강화 요구] RFP 내 강도 높은 보안 요구사항(취약점 점검, 접근통제, 개인정보보호 등)에 대해 Red Hat의 보안 중심 솔루션(ACS, Satellite 패치 관리 등) 연계 제안 검토 가능
  • [RFP 내 명시된 Red Hat 제품명]
    • JBoss EAP 7.4 (WAS, 시스템 구성현황에 현행 명시) — 수량 미기재(비공개 세부 목록 확인 필요)
