대한사격연맹_총기·실탄 통합관리시스템 구축 사업 - 분석 리포트

레드햇 제안 가능성 중간
서버 OS 미지정, Linux·클라우드 제안여지
사업 개요 및 목적
  • 전국 14개 사격장 무기고의 총기·실탄 관리를 디지털 전환하여 수기 장부 방식의 구조적 취약점을 해소하고 실탄 불법 유출을 원천 차단하는 통합관리시스템 구축
  • RFID/NFC 기반 비접촉식 자동인식 기술을 적용하여 총기·실탄의 실시간 입고·출고·이동·반납 현황 파악 및 추적 관리 체계 구현
  • 경찰청·관세청·대한체육회 등 유관기관 시스템 연계를 통해 총기 관외 이동 승인, 외국인 선수 무기 반출입 관리 등 행정 프로세스 전자화
  • AI 기반 데이터 분석을 통한 이상 징후 사전 예측 및 감사 증적(Audit Trail) 자동화로 투명한 관리 체계 확립 (2차·3차 사업 포함 단계별 고도화 예정)
  • 전자정부 표준프레임워크 기반 반응형 웹·모바일 시스템으로 구축하여 향후 전국 확대 및 IoT·AI 카메라 연계 확장성 확보

Red Hat 제안
불가능 요소
  • Red Hat 상용 제품 미명시: RFP 전문 및 과업지시서 어디에도 RHEL, OpenShift, Ansible, JBoss EAP 등 Red Hat 상용 제품명이 구매·납품 품목으로 명시되어 있지 않음
  • 경쟁 제품 미명시 (일부 긍정 요소): Ubuntu, Rocky Linux, Oracle Linux, VMware 등 특정 경쟁 제품도 명시되지 않아 Red Hat 완전 배제 상황은 아니나, 특정 OS 선호 방향이 불분명함
  • 소규모 SI 사업 특성: 총 사업비 약 6.15억원의 중소기업 대상 SI 사업으로, Red Hat이 직접 입찰하기 어려운 구조이며 파트너사 통한 간접 제안 필요
  • 핵심 기술이 RFID/NFC 도메인: 사업의 핵심은 총기·실탄 물리적 자산 관리를 위한 RFID/NFC 하드웨어 연계 및 JAVA/JSP 기반 업무 시스템 개발로, Red Hat 솔루션 강점 영역(컨테이너·자동화·미들웨어)과 직접 연관성이 낮음
  • 전자정부 표준프레임워크 의존성: WildFly 기반 전자정부 표준프레임워크 사용이 일반적이며, JBoss EAP 상용 버전으로의 전환 필요성을 설득하기 어려운 환경
  • 클라우드 벤더 미지정: CSP 선택이 제안사 자유이나, 국내 공공 클라우드(NHN Cloud, KT Cloud, NCP 등)가 주로 사용되는 환경으로 Red Hat 기반 인프라 채택 가능성 제한적
Red Hat 제안
가능 요소
  • 서버 OS 미지정으로 RHEL 제안 가능: RFP 본문에 서버 운영체제가 명시되지 않았으며, 붙임 3 기술적용계획표에서 Linux(○ 적용)로 표기되어 있어 RHEL 제안의 여지가 존재함. 특정 경쟁 OS가 확정되지 않은 상태
  • 클라우드 인프라 구성 시 RHEL 기반 제안 가능: ECR-001~005에서 클라우드 자원 구성, 아키텍처 설계, 운영 인프라 구성을 제안사가 자유롭게 설계 가능하며, RHEL 기반 클라우드 인스턴스 또는 RHEL 지원 클라우드 서비스 제안 가능
  • Java 기반 WAS 환경에 JBoss EAP 제안 가능: JAVA/JSP 기반 개발 환경(SFR-001)에서 WAS로 JBoss EAP 상용 제품을 제안할 여지가 있음. 전자정부 표준프레임워크와의 호환성 검토 필요
  • CI/CD 자동화 환경에 Ansible 활용 가능: ECR-008에서 자동화된 CI/CD 빌드·배포 환경 구축을 요구하고 있어, Ansible Automation Platform(AAP)을 활용한 개발·운영 자동화 파이프라인 구성 제안 가능
  • 상용SW 도입 조항(ECR-006) 활용 가능: "통합관리시스템 플랫폼 운영에 필요한 상용SW 식별 및 도입 지원"을 명시하고 있어, Red Hat 제품을 필요 상용SW로 포지셔닝하여 제안 가능
  • RFP 내 Red Hat(또는 동의어) 제품명 명시: 없음 (해당 없음)
