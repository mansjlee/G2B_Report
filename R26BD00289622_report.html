Red Hat 제안
불가능 요소
  • 순수 유지보수 용역으로 S/W 납품·구독 항목 없음: 본 사업은 기존 CCTV 통합관제시스템에 대한 유지보수 서비스 용역으로, 신규 S/W 도입·납품·구독 계획이 전혀 없어 Red Hat 상용 제품 공급 기회 자체가 없음
  • 기존 인프라가 Microsoft 기반으로 확정: 가상화 서버가 Hyper-V(UniRC2212 Hyper-V 타입 2식)로 구성되어 있으며, 통신서버 S/W가 'MS 데이터센터(VURIX v1.0, 영상관리)' 4식으로 Windows Server 기반 환경이 이미 고정되어 있음. RHEV/OpenShift 등 Red Hat 가상화·컨테이너 플랫폼 제안 여지 없음
  • Red Hat 상용 제품명 전혀 없음: RFP 전체에 걸쳐 RHEL, OpenShift, Ansible, JBoss EAP, Satellite, Quay 등 Red Hat 상용 제품명이 단 한 건도 명시되지 않음
  • 대기업 참여 불가 사업: 소프트웨어진흥법에 의거 대기업 소프트웨어사업자 참여 제한, 하도급 전면 금지로 Red Hat 파트너 채널을 통한 접근도 제한적
  • 사업 기술 요구가 Red Hat 스택과 무관: CCTV 유지보수 특화 사업으로 Linux·컨테이너·자동화·PaaS 등 Red Hat 강점 기술 영역과 연관성 없음
Red Hat 제안
가능 요소
  • RFP에 명시된 Red Hat 제품명·수량: 없음 — RFP 전체를 검토한 결과, Red Hat(레드햇) 또는 동의어(RHEL, OpenShift, OCP, Ansible, JBoss, EAP, Satellite, Quay, AAP 등)에 해당하는 상용 제품명이 단 한 건도 명시되지 않았음
  • RHEL 적용 가능성: 가상화 서버의 OS가 명시적으로 Windows Server(MS 데이터센터)로 확인되어 있어 RHEL 제안 여지 없음. 일부 서버 OS가 불명확하나, 유지보수 용역 특성상 기존 OS 교체 제안은 사실상 불가
  • OpenShift/컨테이너 적용 가능성: 컨테이너·Kubernetes·PaaS 관련 요구사항이 전혀 없으며, 기존 CCTV 관제 솔루션 유지보수에 초점이 맞춰져 있어 OpenShift 제안 여지 없음
  • Ansible 적용 가능성: 네트워크 장비 및 서버 자동화 관련 요구사항이 일부 있으나(정기 패치, 펌웨어 업그레이드 지원 등), 이는 유지보수 서비스 항목이며 Ansible 별도 구독 제안 근거 없음
  • 종합: Red Hat 상용 제품 제안 가능 요소가 없는 순수 CCTV 유지보수 용역으로, 현재 단계에서는 영업 기회 없음
