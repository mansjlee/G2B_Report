사업 개요 및 목적
  • 행정안전부 수탁사업으로 한국지역정보개발원이 발주하는 재난 예·경보 통합관리 및 데이터 품질관리체계 구축 사업
  • 전국 지방정부 재난 예·경보 발령·단말기 현황을 NDMS와 연계하여 실시간 통합 모니터링하고, 행안부 재해문자전광판시스템 개편 및 지방정부 표준 플랫폼(9개 시·군)과 연계
  • 재난안전데이터 공유플랫폼의 간접연계(약 600개 데이터, 63개 시스템)를 직접연계로 전환하고, 데이터 품질 모니터링·분류체계 정비·비식별화 체계를 구축하여 AI 학습에 적합한 고품질 데이터 확보

불가능 요소
  • 직접구매 분리발주: 개인정보비식별화 처리모듈(3식), 작업관리모듈(3식)은 발주기관 직접구매 대상으로 용역 수행사의 S/W 공급 범위에서 제외
  • API관리 플랫폼: GPL v3 준수·오픈소스 라이선스 보유·자유로운 기능 수정 요건으로 Red Hat 상용 API관리(3scale 등) 단독 제안은 제약 존재
  • DBMS: “GIS 가능한 오픈소스 기반 DBMS”로 명시되어 PostgreSQL/PostGIS 등 OSS DB가 유력하며 RHEL 전용 DB 제품(RHOV 등) 직접 지정 없음
  • H/W·기반SW: 서버·스토리지·네트워크·기존 상용SW는 국가정보자원관리원 별도 관리·할당으로 용역 범위 외
  • 경쟁·대체 기술: VMware, Contrabass, Ubuntu, Oracle/Rocky Linux 등 특정 경쟁제품은 RFP에 명시되지 않으나, Linux·JBoss·오픈소스 DB·GPL v3 API 플랫폼 등 OSS 스택 중심으로 설계되어 상용 구독 S/W 단독 납품 기회는 제한적
  • 개발 중심 사업: 본 사업은 SI/개발 용역(기능 100건+)이 주류이며 Red Hat 제품 대량 라이선스 조달 구조가 아님
