S/W 미포함 응용개발 용역
사업 개요 및 목적
  • 초중등 교원의 자기주도적 성장 및 맞춤형 역량 개발 지원을 위한 교원역량개발지원제도 도입 기반 조성이 핵심 목표
  • 학생인식조사(학생이 교원을 평가), 자기역량진단, 다면평가(정성영역) 3개 항목을 통해 초중등 교원 역량을 진단하는 시스템을 나이스(NEIS)에 구축
  • 진단 결과를 국가교원역량개발지원포털과 연계하여 교원 개인별 맞춤형 역량 계발 계획 수립 지원
  • 기존 4세대 나이스(NEIS) 기반 위에 응용 S/W 기능 개발·개선 형태로 수행되는 사업
주요 정보
  • 사업 예산: 730백만원 (부가가치세 포함)
  • 사업 기간: 2026년 계약체결일 ~ 2027년 12월 10일
  • 사업 범위:
    • 다면평가(정성영역) 데이터 연계 기능 개발
    • 학생인식도 조사도구 적용을 위한 학생인식조사 고도화
    • 자기역량진단도구 적용을 위한 자기역량진단 기능 개발
    • 국가교원역량개발지원포털 연계
  • 주요 일정:
    • 다면평가 결과 입력: 2027년 1월 서비스 개시(예정), 2026년 내 기능 개발 완료 후 2027년 12월 파일럿 테스트
    • 학생인식조사: 2027년 6월 서비스 개시(예정), 2027년 3월까지 기능 개발 완료 → 3~4월 사전운영

    • 사업자 선정 방식: 제한공개경쟁입찰 (협상에 의한 계약), 중소 SW사업자만 입찰 참가 가능(20억 미만)

Red Hat 제안
불가능 요소
  • S/W 공급 미포함 사업: RFP 시스템 장비구성 요구사항에 "H/W, S/W 등 장비 도입 없음"을 명시하고 있으며, SW 분리발주 대상 사업이 아님. 상용 SW 구매·납품·구독 항목이 전혀 없는 순수 응용 SW 개발 용역
  • Red Hat 상용 제품 전혀 미언급: RFP 전체 문서에서 RHEL, OpenShift, Ansible, JBoss EAP 등 Red Hat 상용 제품명이 단 한 건도 등장하지 않음
  • 경쟁·대체 제품 고착화: 기존 4세대 나이스 인프라(기 구축된 DBMS, WAS, OS 포함)를 그대로 활용하는 기능개선 사업으로, 신규 인프라 도입 가능성 없음
  • 중소기업 전용 사업: 사업 규모 20억 미만으로 중소 SW사업자만 입찰 참가 가능 — Red Hat이 직접 수주 불가 구조
  • 에듀로 UI 솔루션으로 넥사크로(Nexacro) 지정: 특정 UI 솔루션이 기 지정된 사업
Red Hat 제안
가능 요소
  • RFP 내 Red Hat 상용 제품명·수량: 없음 — RFP 및 과업지시서 내 Red Hat(레드햇), RHEL, OpenShift, Ansible, JBoss EAP 등 상용 제품명이 전혀 명시되지 않음
  • 기술 스택 제안 여지 (제한적): 기술적용계획표에 Linux 서버 운영체제(POSIX, UNIX, Linux) 및 Java 프로그래밍 언어, RDBMS가 적용 기술로 기재되어 있으나, 이는 기존 4세대 나이스 인프라에 이미 구축된 환경을 지칭하는 것이며 본 사업에서 신규 도입·구매하는 것이 아님
  • 결론: 순수 응용 SW 개발 용역 사업으로 Red Hat 제품 제안 및 납품 가능 요소가 실질적으로 없음. 향후 나이스 인프라 유지관리·클라우드센터 위탁운영 사업(별도 사업)에 대한 간접 영향력 확보 차원에서만 관계 구축 가치 존재
