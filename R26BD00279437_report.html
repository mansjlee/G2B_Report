사업 개요 및 목적
  • 국립현대미술관이 발주한 미술품표준관리시스템 재구축 사업으로, 미술품의 수집·등록·보존·전시/대여·수장고관리·정보공유·웹서비스에 이르는 전 생애주기 통합관리 체계 구축이 핵심 목표
  • 클라우드 네이티브 기반으로 운영환경을 전환하고, MSA(마이크로서비스 아키텍처) 지향 구조로 재설계
  • 국제표준(CDWA, VRA Core, LIDO, CIDOC-CRM) 기반 소장품 데이터 표준화 및 AI 기반 지능형 검색 환경 구현
  • 수장고 전용 모바일 네이티브 앱 개발로 현장 중심 소장품 관리 업무 디지털 전환
  • 전국 58개 국·공립 미술관 배포형 공동활용 시스템 개발 및 정보 공유 체계 구축

핵심 요구사항
  • [기술·아키텍처] IaaS 민간 클라우드 기반 클라우드 네이티브 환경 구성 (ECR-001), MSA(마이크로서비스 아키텍처) 지향 모듈형 구조 설계, 컨테이너(도커) 및 쿠버네티스 보안 설정(RBAC, mTLS, CI/CD 보안스캐너) 요구
  • [기능] 소장품 수집·등록·보존·전시/대여·수장고 통합관리 기능 개발 (SFR-001~015), AI 기반 이미지 유사도 검색·자연어 검색·시맨틱 검색 고도화, 수장고 전용 오프라인 동작 네이티브 모바일 앱 개발, 국제표준 메타데이터 관리(CDWA·VRA Core·LIDO·CIDOC-CRM)
  • [연계] ESB 연계 서버·Open API 기반 표준 인터페이스 설계, 통합홈페이지·미술아카이브표준관리시스템·미술품보존DB 실시간 API 연계, 공공데이터포털·문화 공공데이터 통합활용시스템 연계
  • [보안] 민간 클라우드 서비스 이용 보안(CSAP 인증 서비스), 컨테이너 간 접근통제·통신 암호화(mTLS), 디바이스 인증 기반 모바일 보안, 시큐어코딩·웹 취약점 제거
  • [구매 S/W 목록] RFP 내 통합발주 대상 상용 S/W 품목이 별도 명시되지 않음. 현행 시스템 S/W 현황은 "방문 보안 서약 후 열람 가능"으로 비공개 처리됨. 제안사가 사업 수행에 필요한 상용 S/W를 포함하여 제안하는 구조이며, 오픈소스 활용 시 법적 하자 없을 것을 조건으로 허용
Red Hat 제안
불가능 요소
  • [S/W 납품 항목 미확정] RFP 내 통합발주 상용 S/W 목록이 구체적으로 명시되어 있지 않아 Red Hat 상용 제품의 품목 확정 납품 기회를 직접 확인하기 어려움
  • [경쟁 제품 비명시] VMware, Ubuntu, Rocky Linux, Oracle Linux 등 특정 경쟁 OS/플랫폼은 문서에 명시되어 있지 않아 경쟁 제품으로 인한 배제 위험은 낮음
  • [오픈소스 우선 선호 가능성] SFR-001에서 오픈소스 활용을 허용하고 있어, 사업자가 CentOS Stream, Rocky Linux 등 무료 대체 OS를 선택할 가능성 존재
  • [중소기업 제한 사업] 예산 20억 미만으로 중소기업만 입찰 가능하며, 사업자가 Red Hat 라이선스 비용 절감을 위해 커뮤니티 제품을 선호할 유인이 있음
  • [현행 SW 현황 비공개] 기존 시스템의 OS/미들웨어 등 SW 현황이 비공개이므로 기존 Red Hat 스택 사용 여부 및 증설 가능성 사전 확인 불가
Red Hat 제안
가능 요소
  • [RHEL 제안 가능] 기술적용계획표에 Linux 서버용 운영체제 기반환경 적용이 명시(○)되어 있어 RHEL 제안 가능. 특정 OS 미지정 상태로 상용 엔터프라이즈 Linux 제안 여지 있음
  • [OpenShift 제안 가능] MSA 지향 컨테이너 아키텍처, 쿠버네티스 RBAC·보안정책 요구(SER-006), CI/CD 자동화 보안스캐너 요구 등이 OpenShift Container Platform 및 OpenShift 보안 기능(ACS)의 강점과 직결됨
  • [OpenShift AI / RHEL AI 제안 가능] SFR-015에서 AI 기반 이미지 특징 벡터(Embedding) 추출, 유사도 매칭, 시맨틱 검색 모델 적용, 온톨로지 서비스 구조 설계 등 AI 인프라 요구사항이 명시되어 있어 OpenShift AI 플랫폼 제안 가능
  • [Ansible 제안 가능] 클라우드 네이티브 환경의 인프라 자동화, 컨테이너 배포·운영 자동화 수요에 Ansible Automation Platform 제안 가능
  • [Quay / 컨테이너 레지스트리 제안 가능] CI/CD 과정 보안스캐너, 컨테이너 이미지 서명·무결성 검증 요구(SER-006)에 Red Hat Quay 또는 ACS 제안 가능
  • [RFP 내 Red Hat 제품 명시] RFP 문서 내 Red Hat 상용 제품명(RHEL, OpenShift, Ansible 등) 및 수량이 직접 명시된 품목은 없음
