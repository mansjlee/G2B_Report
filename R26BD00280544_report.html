S/W 미포함 유지보수 용역, VMware·Citrix 명시
사업 개요 및 목적
  • 한국전력공사 본사의 ICT 개인정보화기기(데스크탑, 노트북, 프린터, 클라우드 PC, VDI 서버 등) 전반에 대한 정기적 유지보수 및 안정적 운영을 목적으로 함
  • 한전KDN이 원발주사(한국전력공사)로부터 위탁받아 재발주하는 구조의 ICT 운영업무 위탁용역 사업임
  • 장애 최소화, 빠른 장애 복구, 24시간 유지보수 운영체제 제공을 핵심 목표로 하며, 신규 S/W 도입이 아닌 기존 설비·라이선스 유지관리가 본질임

  • 순수 유지보수 용역 사업: 본 사업은 기존 설비 및 라이선스에 대한 유지보수·운영 용역으로, 신규 S/W 도입·납품·구독 항목이 없음. 세부품명도 '소프트웨어유지 및 지원서비스(8111229901)'로 분류됨
  • VMware 명시: 업무망 VDI 가상화 PC(VMware: 419User / Citrix 311User, 1식), 업무망 VDI 가상화 PC(VMware, 20식), Vsan User License(80User) 등 VMware 제품이 유지보수 대상으로 명시되어 있어 Red Hat Virtualization/OpenShift 대체 여지 없음
  • Citrix 명시: Citrix 311User가 기존 VDI 인프라로 명시되어 Red Hat 제안 여지 없음
  • Windows Server 2019 명시: 클라우드 운영서버 OS로 Windows Server 2019(124식)가 유지보수 대상으로 명시
  • 틸론(Tilon) VDI 플랫폼: 틸론 VDI 라이선스 및 관리포털이 기존 인프라의 핵심으로 운영 중이며, 대체 불가
  • Red Hat 상용 제품 전혀 미언급: RFP 전체에 RHEL, OpenShift, Ansible, JBoss 등 Red Hat 상용 제품명이 단 한 건도 명시되지 않음
  • 대기업·중견기업 입찰 제한: 20억원 미만 중소기업 간 경쟁 사업으로 Red Hat Korea 직접 입찰 불가 구조

가능 요소
  • 해당 사항 없음: 본 사업은 기존 설비(VMware, Citrix, 틸론 VDI, Windows Server 기반) 유지보수 용역으로, Red Hat 상용 제품(RHEL, OpenShift, Ansible 등)이 도입·납품·증설되는 항목이 전혀 없음

  • VDI 및 가상화 환경이 있으나 틸론/VMware/Citrix로 확정된 기존 환경 유지관리가 목적이므로 신규 플랫폼 제안 기회 없음
