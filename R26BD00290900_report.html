Red Hat 제안
불가능 요소
  • 순수 유지보수 용역 중심: 본 사업은 기존 시스템에 대한 통합유지보수 용역으로, 신규 S/W 납품·구독 계약이 주목적이 아님. Red Hat 상용 제품의 신규 도입·납품 확정 항목 없음
  • Red Hat 상용 제품명 전혀 없음: RHEL, OpenShift, Ansible, JBoss EAP, Satellite, Quay 등 Red Hat 상용 제품이 RFP 내 어디에도 품목으로 명시되지 않음
  • 기존 S/W 스택이 경쟁사 중심: 명시된 S/W(포와인드시스템, 영림원소프트랩, 웨어벨리, 시큐아이·안랩, 코닉글로리, 지니언스, 펜타시큐리티, 효성인포메이션시스템 등)는 모두 국내 타사 제품으로, Red Hat 제품 대체 여지 낮음
  • 기술지원확약서 의무화: 기존 도입 제품의 원 제조사로부터 기술지원확약서를 제출해야 하므로, Red Hat이 기존 납품사가 아닌 경우 참여 구조 없음
  • 지역 제한 입찰: 울산광역시 소재 업체만 참여 가능(Red Hat 직접 참여 불가, SI/파트너사 통한 간접 참여만 가능)
Red Hat 제안
가능 요소
  • RHCSA 자격 요구 → Red Hat 기술 환경 기반 확인: 정량 평가 항목(기술인력 보유상태)에 "서버·리눅스 기술자 (리눅스마스터 2급, LPIC-2, RHCSA 이상)"이 명시되어 있어, 현재 운영 인프라에 Red Hat Enterprise Linux(RHEL) 계열 서버가 실제 운용 중일 가능성이 높음
  • Linux 운영체제 기반 명시: 기술적용계획표(붙임4) 플랫폼 및 기반구조 분야에 서버용 운영체제로 "Linux ☑" 적용이 명시되어 있어, Linux 환경에서의 RHEL 구독 유지보수 또는 전환 제안 가능
  • 운영체제 패치·업그레이드 지원 요구 (MAR-009): "운영체제 및 패치 업그레이드 적용", "S/W 상위버전 구매 등 유상 업그레이드 필요 시 공단과 협의하여 실비 정산 가능" 조항이 있어, 기존 RHEL 운영 시 구독 갱신·업그레이드 기회 존재
  • DBMS·서버 운영 보안패치 포함 (SER-006): 서버, DBMS 등 취약점 점검 및 보안패치 의무화로 RHEL 구독 서비스(Security Patch, Extended Update Support 등) 연계 가능
  • 파트너/SI 통한 간접 영업 기회: Red Hat이 직접 입찰할 수 없으나, 낙찰 SI 파트너사를 통해 기존 RHEL 라이선스 갱신·확장 제안 가능. RHCSA 보유 인력이 투입되는 환경에서의 Red Hat 교육·인증 사업 연계도 검토 가능
  • RFP 내 Red Hat(또는 동의어) 제품명·수량 명시 없음: 현재 RFP 문서에는 Red Hat 상용 제품이 품목으로 직접 명시되지 않았으나, RHCSA 자격 요건으로 미루어 기존 RHEL 환경이 존재할 가능성이 있으므로 낙찰사 접촉을 통한 정보 확인 필요
