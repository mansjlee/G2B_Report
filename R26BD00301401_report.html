Red Hat 제안
불가능 요소
  • 상용 SW 직접구매 대상 아님: RFP 명시 — "본 사업은 응용 프로그램 개발사업으로 상용 SW 직접구매 대상 사업이 아님" → Red Hat 상용 제품(RHEL, OpenShift, Ansible 등) 납품·구독 품목이 전혀 없음
  • 경쟁 OS 확정 운영: 현행 클라우드 서버 OS가 Rocky Linux로 명시되어 있으며, 동일 환경 유지를 요구 → RHEL 상용 품목 아님, Rocky Linux(CentOS 계열 커뮤니티 배포판)가 운영 플랫폼으로 확정
  • DBMS 확정: MySQL 사용 확정 → Red Hat 관련 DB 제품 제안 여지 없음
  • 순수 SI·유지용역 사업: 사업 전체가 응용 프로그램 고도화 개발 및 웹사이트 유지보수 용역으로, SW 라이선스 납품 항목 자체가 없음
  • JBoss/WildFly 미언급: WAS 관련 미들웨어 제품명 명시 없음(WEB: Apache, 개발 언어: PHP 환경)
  • Red Hat 상용 제품명 전무: RFP 전문에 RHEL, OpenShift, Ansible, JBoss EAP, Satellite 등 Red Hat 상용 제품명이 단 한 건도 등장하지 않음
  • 20억 미만 중소기업 제한: Red Hat 코리아 직접 입찰 불가 구조
Red Hat 제안
가능 요소
  • 현행 OS Rocky Linux 운영: Rocky Linux는 RHEL 호환 커뮤니티 배포판으로, 향후 상용 지원·보안 패치가 필요할 경우 RHEL 전환 제안 가능성이 존재하나, 본 사업 범위 내에서는 "현 환경 동일 유지" 요구로 직접 전환 제안 불가
  • 클라우드 환경 운영: 충남교육정보 프라이빗 클라우드 기반 운영으로, 향후 컨테이너화·자동화 수요 발생 시 OpenShift/Ansible 간접 제안 가능성이 있으나, 현 사업에서는 명시적 요구 없음
  • RFP 내 Red Hat 상용 제품 명시 품목·수량: 없음 (0건)
  • 종합 평가: 본 사업은 Rocky Linux(커뮤니티 배포판) 기반 현행 환경 유지 조건의 순수 개발·유지용역으로, Red Hat 상용 제품 제안 기회가 사실상 없음. 향후 고객 관계 구축 차원에서 담당자 접점 확보 정도의 의미만 있음
