Red Hat 제안
불가능 요소
  • Red Hat 상용 제품명 미명시: RFP 내 RHEL, OpenShift, Ansible, JBoss EAP 등 Red Hat 상용 제품이 구매 품목으로 전혀 명시되지 않음
  • WEB/WAS/DBMS 이미 특정됨: WEB(WebtoB), WAS(JEUS), DBMS(Tibero) 등 핵심 미들웨어·DB가 티맥스소프트 제품으로 이미 확정되어 JBoss EAP, AMQ 등 Red Hat 미들웨어 진입 불가
  • 상용 SW 전량 직접구매(조달쇼핑몰): 6종 SW 모두 조달청 쇼핑몰 직접구매 예정으로 통합발주 SW 납품 기회 없음
  • 소규모 사업 및 중소기업 한정 입찰: 사업비 5억 900만원 규모, 대기업·중견기업 참여 제한으로 Red Hat 파트너사도 입찰 자격 요건 충족 필요
  • 컨테이너/클라우드 인프라 수요 없음: 온프레미스 물리 서버 구성으로 OpenShift, Ansible Automation Platform 등 클라우드 네이티브 솔루션 제안 여지 없음
Red Hat 제안
가능 요소
  • 서버 OS가 "Linux"로만 명시 → RHEL 제안 가능: WEB/WAS 서버 및 DB 서버 모두 OS를 "Linux"로만 기재하여 특정 배포판이 지정되지 않음. RHEL을 포함한 다양한 Linux 배포판 제안 가능 (통합발주 HW 항목)
  • 백신이 Linux Server용으로 명시: AhnLab V3 Net for Linux Server 도입으로 Linux 기반 운영 환경이 확정되어 있어 RHEL 도입의 기술적 적합성 논거로 활용 가능
  • 보안 및 안정성 강조 요구사항: RFP 전반에 걸쳐 보안패치, 취약점 조치, 정품 SW 사용을 강조하고 있어 상용 Linux인 RHEL의 보안 지원 및 라이프사이클 관리 강점을 어필 가능
  • RFP 내 Red Hat(또는 동의어) 제품명·수량: 해당 없음 (명시된 Red Hat 상용 제품 없음)
  • 영업 접근 전략: 통합발주 서버 OS 항목에서 RHEL을 제안하는 파트너사(시스템 구축 사업자)를 통한 간접 영업 추진 권장. 사업 규모 및 구조상 RHEL 소규모(서버 2대) 제안 가능
