Red Hat 제안
불가능 요소
  • 순수 운영·유지관리 용역 사업: 신규 S/W 구매·납품·구독 항목이 RFP 본문에 명시되어 있지 않음. 사업의 본질이 기존 구축 시스템 유지관리·관제 서비스임
  • Red Hat 상용 제품 전혀 미명시: RHEL, OpenShift, Ansible, JBoss EAP, Satellite, AAP 등 어떠한 Red Hat 상용 제품명도 RFP 내 언급 없음
  • 기존 시스템 유지 성격: 현행 664개 장비를 현 상태로 유지·관리하는 사업으로, 신규 플랫폼·OS 전환 요구가 없음
  • 경쟁·대체 제품 명시 없음: Ubuntu, VMware, Oracle Linux 등도 명시되지 않았으나, 동시에 Red Hat 도입 근거도 없음
  • 장비 목록 비공개: 유지관리 대상 장비 세부 목록이 현장 방문 열람 대상(보안확약서 필수)으로, 현재 운영 중인 OS·플랫폼 정보 확인 불가
Red Hat 제안
가능 요소
  • Linux·가상화 환경 추정 가능: 기술적용계획표에 POSIX·Linux 계열 개방형 운영체제 언급, 하이퍼바이저 보안취약점 조치 요구 → 기존 환경에 RHEL이 운영 중일 가능성 존재
  • 클라우드컴퓨팅·서버가상화 운영 과업: "서버시스템 및 클라우드컴퓨팅 시스템 운영" 인력이 별도 명시되어 있어, OpenShift 또는 RHEL 기반 가상화 환경 운영 가능성
  • OS·SW 라이선스 갱신 업무 포함: "유지보수 대상 서버 라이선스 기한 만료 전 갱신" 및 "상용 소프트웨어 라이선스 갱신 기술지원" 과업이 포함되어 있어, 현장 확인 시 RHEL 갱신 기회가 있을 수 있음
  • RFP 내 Red Hat(또는 동의어) 제품명·수량 명시 없음: 현 RFP 문서상에서는 Red Hat 상용 제품이 품목으로 확인되지 않아 사업 착수 전 사전 영업(현장 환경 파악)이 필요한 상황
