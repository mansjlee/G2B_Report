불가능 요소
  • [신규 S/W 납품·구독 항목 없음]: 본 사업은 기존 정보시스템 통합 유지관리 용역으로, 신규 S/W 도입·납품·구독 과업이 없음. Red Hat 상용 제품(RHEL, OpenShift, Ansible, JBoss EAP 등)을 신규 납품할 기회 없음
  • [Oracle DBMS 기존 확정]: 주요 DBMS로 Oracle이 총 7식 이상 운영 중이며, MAR-003에서 "DBMS(Oracle)는 3자 유지관리 서비스 가능"으로 명시되어 기존 Oracle 생태계 유지가 확정됨
  • [TmaxSoft 미들웨어 기존 확정]: 미들웨어로 Jeus·WebToB(TmaxSoft)가 전 시스템에 걸쳐 다수 식 운영 중. Red Hat JBoss EAP 제안 불가
  • [Windows Server 운영 중]: 망분리 환경에 Windows Server 2012가 사용 중으로 명시됨
  • [IBM AIX 계열 서버 환경]: ERP 서버·통합업무 AP서버 등 핵심 서버가 IBM p770·p740·p720·S924·S1024 등 IBM Power 계열로 구성되어 있어 AIX 또는 IBM 전용 OS 환경으로 추정됨. RHEL for Power 제안도 기존 환경 교체 없이 불가
  • [RFP 전체에 Red Hat 상용 제품명 전혀 미등장]: RHEL, OpenShift, Ansible, JBoss EAP, Satellite 등 어떤 Red Hat 상용 제품도 기존 SW 목록(134식)에 포함되지 않음
  • [134식 기존 상용SW 전체가 비-Red Hat 스택]: SAP, Oracle, TmaxSoft, HandySoft 등 기존 벤더 생태계로 고착되어 있어 유지관리 범위 내 Red Hat 도입 여지 없음
Red Hat 제안
가능 요소
  • [배포자동화 시스템의 Linux 환경]: MAR-020에서 "Docker 기반 Linux 운영환경 및 컨테이너"를 명시적으로 언급. 현재 운영 중인 Linux 배포판이 특정되지 않아 향후 RHEL 또는 RHEL 기반 컨테이너 환경으로의 전환 제안 가능성 존재 (단, 기존 인프라 유지관리 범위이므로 즉각적 교체 기회는 낮음)
  • [CI/CD DevOps 도구 환경]: Jenkins, Nexus, Git, Wiki.js 등 오픈소스 DevOps 도구 스택이 운영 중. Red Hat의 OpenShift DevSpaces, Quay, Ansible Automation Platform 등의 중장기 전환 제안을 위한 사전 관계 구축 가능
  • [서버 OS 업그레이드 지원 과업]: MAR-002에서 "DB, OS 업그레이드 및 패치, 운영 및 유지관리" 요구. HP DL 계열 서버(DL360 GEN10 등)에서의 Linux 운영환경에 대해 기술지원 인력 파견 시 RHEL 전문성을 어필할 수 있는 간접적 기회
  • [RFP 내 Red Hat(또는 동의어) 제품명 명시 현황]: 해당 없음 — RFP 및 붙임14 SW 목록 전체에 걸쳐 RHEL, Red Hat, OpenShift, Ansible, JBoss EAP 등 Red Hat 상용 제품명이 단 한 건도 명시되지 않음
  • [종합 평가]: 본 사업은 기존 비-Red Hat 스택(Oracle·TmaxSoft·SAP·IBM) 중심의 통합유지관리 용역으로, 신규 SW 구매·납품 항목이 없고 Red Hat 상용 제품이 기존 환경에 전혀 포함되어 있지 않아 실질적인 영업 기회는 매우 낮음. 다만 배포자동화 시스템의 Linux 환경을 접점으로 중장기 관계 구축 차원의 간접 접근은 고려 가능
