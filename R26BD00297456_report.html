Red Hat 제안
불가능 요소
  • Red Hat 상용 제품명 미명시: RFP 전체에서 RHEL, OpenShift, Ansible, JBoss EAP 등 Red Hat 상용 제품명이 도입·납품·유지보수 대상으로 명시적으로 기재되지 않음
  • 경쟁 OS 직접 명시 없음(단, OS 미지정): Ubuntu, Rocky Linux, Oracle Linux 등 특정 경쟁 OS가 확정 도입 품목으로 명시된 사항은 없으나, Red Hat OS도 명시되지 않아 제안 여지는 존재하나 현황 파악 불가
  • 순수 유지관리·운영 용역 중심 사업: 신규 S/W 도입·납품보다는 기존 시스템의 운영·유지보수·개발변경이 주요 과업으로, Red Hat 제품 신규 구독·납품 기회가 명확하지 않음
  • 시스템 현황 비공개: 행정안전부 고시에 따라 현행 시스템 구성도, H/W·S/W 세부 목록이 보안사항으로 비공개 처리되어 있어 현재 Red Hat 제품 운영 여부를 확인하기 어려움 (사업설명회 현장 배포 예정)
  • WAS 서버 제품명 미지정: 시스템관리자 요건에 "WAS 및 웹서버 관리"만 명시되어 있고, JBoss EAP, JEUS 등 특정 WAS 제품명은 명시되지 않음. 우대사항에 "JEUS / FrameWork 기반 Java 개발 환경 경험"이 언급되어 JEUS 운영 가능성도 존재
  • SW 분리발주 없음: SW분리발주 여부 '아니오'로 표시되어 있어, 개별 S/W 별도 발주 구조가 아님
  • 대기업 참여 제한: 40억~80억 미만 사업으로 매출액 8천억 원 이상 대기업 참여 불가 (Red Hat 직접 참여 불가, 파트너사를 통해서만 접근 가능)
Red Hat 제안
가능 요소
  • RFP 내 Red Hat 명시 제품 없음: 현재 RFP 본문에서 Red Hat 상용 제품명은 확인되지 않음. 단, 시스템 세부 현황이 비공개이므로 사업설명회 자료 확인 후 판단 필요
  • UNIX/Linux 서버 운영환경: 시스템관리자 요건에 "UNIX 서버 관리 경력 3년 이상" 명시 → 현재 운영 중인 서버 OS가 Linux/UNIX 계열일 가능성 높으며, RHEL 운영 여부 사업설명회에서 확인 필요
  • 기술적용계획표 내 Linux 명시: 플랫폼 및 기반구조 분야에서 서버용 운영체제로 "UNIX", "Windows Server", "Linux" 모두 적용 계획으로 체크되어 있어 Linux 계열 OS 운영 가능성 존재 (RHEL 제안 여지 있음)
  • WAS·컨테이너 운영 환경: "WAS 및 웹서버 관리" 요건, Java 기반 Tomcat·Apache 운영, Spring 프레임워크 개발 환경 → JBoss EAP 또는 OpenShift 기반 컨테이너 플랫폼 제안 여지 있음
  • 자동화·운영 최적화 수요: 24시간 무중단 운영, 보안패치 자동화, 백업 자동화 등 운영 자동화 니즈 존재 → Ansible Automation Platform 제안 가능성
  • 보안 강화 요구사항: SIEM, SOAR, WAF, IPS, DDoS 등 보안장비 운영 및 취약점 개선 요구 → Red Hat ACS(Advanced Cluster Security) 또는 Satellite 보안 패치 관리 기능 제안 가능
  • AI/MLOps 운영 환경: AI 모델(MLOps) 운영, AI 챗봇·콜봇 유지관리 → OpenShift AI 또는 RHEL AI 플랫폼 제안 여지 있음
  • 클라우드·컨테이너 기술 적용 계획: 기술적용계획표에 IaaS, PaaS, SaaS 클라우드 컴퓨팅 항목이 적용 계획으로 체크되어 있어 OpenShift/컨테이너 플랫폼 도입 논의 가능
  • 영업 접근 전략: 사업설명회에서 현행 인프라 현황 파악 후 RHEL·JBoss EAP·Ansible 운영 여부 확인 필수. 수행사(SI) 파트너를 통해 Red Hat 구독 갱신·신규 도입 기회 탐색 권장
