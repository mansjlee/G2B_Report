Red Hat 제안
불가능 요소
  • HW(서버)는 국가정보자원관리원(G클라우드)에서 운영 중이며, HW 유지보수는 국가정보자원관리원 담당 — HW 직접 공급 불가
  • 업무포털의 JBossEAP 7.4 및 JBossEWS는 현 사업에서 국가정보자원관리원 유지보수 대상으로 명시되어 있어, 본 용역사업자의 직접 납품 범위가 아님
  • 대표 홈페이지의 RHEL 6.5(7식) 역시 국가정보자원관리원 유지보수 대상으로 별도 관리 — 본 사업에서 Red Hat 구독 신규 구매 명시 없음
  • 20억원 미만 사업으로 중소 SW사업자만 입찰 가능 (대기업·중견기업 참여 불가) — Red Hat이 직접 입찰 불가, 파트너사 협력 필요
  • 순수 운영·유지관리 용역 사업으로 신규 상용 SW 도입 예산이 별도로 명시되지 않음
  • 경쟁 제품(Ubuntu, VMware, Oracle Linux 등)은 명시되어 있지 않음
Red Hat 제안
가능 요소
  • [RFP 명시 Red Hat 제품]
    • RHEL 6.5 — 7식 (대표 홈페이지 OS, 국가정보자원관리원 유지보수 대상으로 명시)
    • JBossEAP 7.4 — 2식 (업무포털 WAS, 국가정보자원관리원 유지보수 대상)
    • JBossEWS(Apache) 2.4.51 — 2식 (업무포털 WEB, 국가정보자원관리원 유지보수 대상)
    • JBossEAP 6.2.3 — 2식 (대표 홈페이지 WAS, 국가정보자원관리원 유지보수 대상)
    • JBossEWS(Apache) 2.0.1 — 2식 (대표 홈페이지 WEB, 국가정보자원관리원 유지보수 대상)
  • [제안 가능 포인트]
    • 기 도입된 JBossEAP(6.2.3 / 7.4) 및 JBossEWS가 현재 구버전으로, 향후 업그레이드·증설 시 JBoss EAP 최신 버전 또는 Red Hat OpenShift 전환 제안 기회 존재
    • RHEL 6.5는 이미 EOL(지원 종료) 버전으로, RHEL 8/9 또는 최신 버전으로의 버전업 제안 가능 — 국가정보자원관리원과 인사혁신처 협의 과정에서 Red Hat 파트너사와 연계 가능성
    • PSR-01(기술지원 체계 유지) 요구사항에 "유지보수 대상 SW의 재설치 및 패치 등 업그레이드"가 명시되어 있어, JBoss EAP 패치·업그레이드 관련 기술지원 참여 가능
    • Java 기반 전자정부 표준프레임워크 환경에서 JBoss EAP는 Red Hat 공식 지원 WAS로 지속 활용 가능
    • G클라우드(IaaS) 환경에서 컨테이너·PaaS 전환 요구 시 OpenShift 제안 여지 존재 (기술적용계획표 IaaS/PaaS 항목 적용 검토로 명시)
    • Ansible Automation Platform을 통한 운영 자동화(시스템 모니터링, 패치 관리, 배포 자동화) 제안 가능
