사업 개요 및 목적
  • 대구광역시 교통정보운영과가 운영하는 버스운행관리시스템(BMS)을 안정적·효율적으로 운영하기 위해 전문 유지관리 업체와 용역 계약을 체결하는 사업
  • 센터 서버·네트워크·상용 S/W(DB, 미들웨어 등), 응용 S/W, 홈페이지, 현장장비(버스정보안내기, 승객용·행선지안내기)에 대한 정기·수시·상시 예방점검 및 장애 발생 시 신속 복구 수행
  • 버스 대·폐차에 따른 차내장비(승객용안내기, 행선지안내기) 이설 업무 포함
  • 버스정보시스템(홈페이지, 모바일, 초정밀 버스정보 웹서비스) 운영 및 대시민 교통정보 서비스 품질 유지

Red Hat 제안
불가능 요소
  • 신규 S/W 납품 규모 미미: 이 사업은 신규 S/W 도입이 아닌 기존 시스템 유지관리 중심이며, 통합발주 S/W는 백신류 및 웹로그 분석 소프트웨어에 한정됨 → Red Hat 상용 제품 납품 기회 거의 없음
  • 기존 미들웨어 TmaxSoft 제품 고착: 현재 JEUS Ent 2식, WebtoB Std 2식 등 TmaxSoft 제품이 WAS/WEB으로 운영 중 → JBoss EAP 또는 OpenShift 기반 미들웨어 교체 여지 없음
  • DB는 Oracle 고착: Oracle 10g, Oracle 19c, Ark for Oracle 등 Oracle DB 스택 전면 적용 중 → Red Hat 기반 DB 솔루션 제안 불가
  • Red Hat 상용 제품명 미명시: RFP 전체에 걸쳐 RHEL, OpenShift, Ansible, JBoss EAP, Satellite 등 Red Hat 상용 제품명이 품목으로 전혀 명시되지 않음
  • 대기업 참여 제한: 소프트웨어 진흥법에 따라 대기업 참여 불가 → Red Hat Korea가 직접 입찰 참여 불가, 파트너 채널을 통한 간접 납품 구조 필요
Red Hat 제안
가능 요소
  • Linux 서버 다수 운영, 배포판 미지정: 백신 서버(Linux) 8개 라이선스 통합발주 명시 등, 총 43대 센터 서버 중 Linux 운영 서버가 다수 존재하나 특정 배포판(RHEL, CentOS, Ubuntu 등)이 RFP 본문 어디에도 명시되지 않음 → RHEL 제안·전환 제안 여지 있음
  • 기술적용계획표상 Linux 운영체제 적용 확인: 기술적용계획표 플랫폼 기반구조 분야에서 "Linux" 운영체제 항목이 "적용"으로 체크되어 있어, Linux 계열 OS가 실제 운영 중임을 공식 확인 → RHEL 제안 근거 존재
  • Ansible 기반 자동화 운영 제안 가능: RFP에서 OS 패치, 보안취약점 조치, 월 1회 정기점검 자동화 등을 요구하고 있어 Ansible Automation Platform(AAP) 기반 자동화 운영 방안 제안이 가능함
  • 보안·컴플라이언스 강화 요구: 국가정보보안기본지침 준수, 보안취약점 점검 월 1회 이상, OS/SW 패치 관리 등 강도 높은 보안 요구사항 존재 → RHEL의 SELinux, Insights, Satellite 기반 패치·컴플라이언스 관리 솔루션 제안 가능
  • RFP에 명시된 Red Hat(또는 동의어) 제품명·수량: 없음 (해당 없음)
