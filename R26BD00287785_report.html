불가능 요소
  • [SW 구매 없음 — 핵심 불가 요인] RFP 제안요청 사업범위에 "HW 및 SW 구매 범위 - 없음"으로 명시, 직접구매 사항도 "해당없음"으로 확정되어 있어 RHEL, OpenShift, Ansible 등 Red Hat 상용 제품의 신규 납품·구독 계약 기회가 전혀 없음
  • [순수 유지관리 용역] 사업 전체가 기존 시스템의 운영 및 유지관리에 한정되며, 신규 인프라나 플랫폼 도입이 포함되지 않음
  • [Red Hat 상용 제품명 미명시] RFP 전문에 RHEL, OpenShift, Ansible, JBoss EAP 등 Red Hat 상용 제품명이 품목으로 전혀 명시되지 않음
  • [기존 시스템 환경 비공개] "정보시스템 구성도 및 제품버전 등 공개될 경우 보안침해 사고 우려"를 이유로 OS, 미들웨어, DBMS 등 현행 제품 정보가 RFP에서 삭제 처리됨. 기술적용계획표에 Linux, RDBMS, Oracle(ORDBMS) 등이 언급되나 구체적 제품명 및 버전 미확인
  • [중소기업 전용 사업] 대기업·중견기업 입찰 참여 불가, Red Hat이 직접 입찰 불가 구조이며 파트너(SI)도 중소기업만 참여 가능
Red Hat 제안
가능 요소
  • [간접적 Linux 환경 존재] 기술적용계획표에 서버 OS로 Linux가 적용 검토 대상에 포함되어 있으며, 정보소통광장(Web Server 5식, 검색엔진서버 3식, DB Server 2식) 및 문서공개시스템(WAS 서버, AP서버, 변환서버, 통합DB서버 등) 운영에 Linux 계열 OS가 사용될 가능성 있음
  • [유지관리 중 OS 라이선스 갱신 가능성 탐색] 기존 운영 시스템의 상용 SW 유지관리 항목에 OS 라이선스 갱신이 포함될 수 있으므로, 사업 수주 후 현황 파악 단계에서 RHEL 전환 또는 갱신 기회를 확인할 수 있음 (단, 현재 RFP 상에는 근거 없음)
  • [전자정부 표준프레임워크 적용] Java 기반 전자정부 표준프레임워크 운영 환경에 JBoss EAP 미들웨어 제안 여지가 이론적으로 존재하나, SW 구매 범위가 없어 현 사업에서는 실질적 제안 불가
  • [RFP 내 Red Hat 제품명 명시 없음] RFP 전문에 Red Hat 또는 동의어(RHEL, OpenShift, Ansible, JBoss EAP 등) 제품명이 품목으로 명시된 사례 없음. Red Hat 영업 기회로 직결되는 근거 없음
  • [결론] 현 입찰 건은 SW 구매가 완전히 배제된 순수 유지관리 용역이므로 Red Hat 상용 제품 제안 기회 없음. 다만, 사업 수행사(SI)와의 관계 형성을 통해 차기 시스템 구축·전환 사업 시 RHEL/OpenShift 제안 파이프라인 구축 관점에서 관심 유지 권장
