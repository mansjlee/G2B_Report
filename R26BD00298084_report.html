Red Hat 제안
불가능 요소
  • S/W 신규 구매·납품 없음: 본 사업은 순수 운영·유지관리 용역으로, RFP 기술적용계획표에 "도입SW 없음"이 명시되어 있어 Red Hat 상용 제품의 신규 납품·구독 판매 기회 없음
  • Red Hat 제품명 전혀 미명시: RFP 전체에 걸쳐 RHEL, OpenShift, JBoss, Ansible 등 Red Hat 상용 제품명이 단 한 차례도 등장하지 않음
  • 일반 문구만 존재: 운영체제 관련으로 "Linux", "UNIX", "Windows Server" 등 일반적인 플랫폼 목록만 기술되어 있으며, 특정 Red Hat 제품명 없음
  • 경쟁 OS 미지정이나 Red Hat 도입 근거 부재: OS 플랫폼이 특정되지 않았으나, 사업 성격상 기존 환경 유지관리가 목적이므로 신규 OS 제안 여지 없음
  • 중소기업 제한 입찰: 소프트웨어 진흥법 제48조에 따라 중소 소프트웨어사업자만 입찰 참여 가능하여 Red Hat 직접 참여 불가 구조
  • 현행 시스템 구성 비공개: 행정기관 정보시스템 구축·운영 지침 제17조에 따라 시스템 구성 현황이 비공개이며, 현행 운영 대상에 Red Hat 제품 포함 여부 확인 불가
Red Hat 제안
가능 요소
  • RFP 내 Red Hat 상용 제품명 없음: RHEL, OpenShift, JBoss, Ansible Automation Platform 등 Red Hat 제품이 명시적으로 도입·유지 대상으로 기재되어 있지 않아 직접적인 제안 근거 없음
  • 간접적 제안 여지 (매우 제한적):
    • 기술적용계획표에 "Linux" 서버용 운영체제가 적용 항목으로 포함되어 있어, 현행 서버 환경에 Linux 계열 OS가 운영 중일 가능성 있음 → 사전 방문 시 현황 확인 필요
    • WEB/WAS/DB 서버 운영 환경이 존재하므로, 향후 갱신 시 RHEL 도입 가능성을 간접적으로 탐색할 수 있음
  • 현황 파악 기회: RFP상 "제안서 작성 또는 입찰 전 발주기관 방문 필수"로 명시되어 있어, 현황 파악 시 Red Hat 제품 운영 여부 확인 가능. 만약 현행 시스템에 RHEL, JBoss 등이 포함되어 있다면 추후 구독 갱신·확장 기회 발굴 가능
  • 결론: 현재 RFP 텍스트만으로는 Red Hat 제품 제안 근거가 없으며, 실질적인 기회는 현장 방문을 통한 현행 시스템 확인 이후 판단 필요
