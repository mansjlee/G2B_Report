Red Hat 제안
불가능 요소
  • S/W 신규 도입·납품 항목 없음: 본 사업은 기존 운영 시스템 유지관리 용역이며, 신규 상용 S/W 구매 발주(통합발주) 항목이 없음
  • WAS 서버 명시 제품: JBoss 7.4 (커뮤니티 버전): RFP 운영현황에 "JBoss 7.4"가 공개SW로 명시되어 있으며, 이는 Red Hat 상용 제품인 JBoss EAP가 아닌 커뮤니티 업스트림 제품(WildFly 기반)으로 간주. 상용 JBoss EAP 도입이 명시되지 않아 높음 판정 불가
  • Red Hat 상용 제품명 전혀 미명시: RFP 전체에 RHEL, OpenShift, Ansible, JBoss EAP, Satellite 등 Red Hat 상용 제품명이 구매 품목으로 명시되지 않음
  • OS 플랫폼 미지정: 운영 OS에 대한 별도 명시가 없으며, 경쟁 OS(Ubuntu, Rocky 등)도 명시되지 않음 — 단, 기존 운영 환경 유지가 전제이므로 신규 OS 제안 여지 제한적
  • 대기업·중견기업 입찰 제한: 총 예산 768백만원으로 중소기업 제한 사업이며, Red Hat Korea 직접 입찰 참여 불가
  • 순수 유지관리 용역 중심: 사업의 본질이 소프트웨어 납품이 아닌 운영·유지관리 서비스이므로 라이선스 직접 매출 발생 구조가 아님
Red Hat 제안
가능 요소
  • JBoss 7.4 → JBoss EAP 전환 제안 여지: 현재 운영 중인 WAS 서버가 "JBoss 7.4"(공개SW 커뮤니티 버전)로 명시되어 있어, 유지관리 사업자를 통해 Red Hat JBoss EAP(상용) 전환·업그레이드 제안 가능. 유지관리 사업자(파트너)를 통한 간접 세일즈 어프로치 기회 존재
  • OS 환경 미지정으로 RHEL 제안 여지: 운영 OS가 RFP에 명확히 명시되지 않아 유지관리 수행 시 OS 교체 또는 신규 서버 도입 시 RHEL 제안 가능성 존재. MAR-001에 "클라우드 이전 및 OS 변경 등의 기반환경 변화 시 소스 이관 등의 기술 지원"이 명시되어 환경 변화 시 Red Hat 스택 제안 기회 발생 가능
  • 클라우드 이전 관련 언급: 요구사항(MAR-001)에 "클라우드 이전" 관련 기술지원이 명시되어 있어, 향후 OpenShift 기반 컨테이너 플랫폼 전환 시 사전 영업 기회 마련 가능
  • Ansible 자동화 제안 여지: 다수 시스템(e-푸른바다, 홈페이지, 오믹스데이터 등) 운영·예방점검·배포 자동화 관점에서 Ansible Automation Platform 제안 가능성 존재 (유지관리 효율화 어필)
  • 파트너 경유 간접 영업 전략 필요: 본 사업에 참여할 중소 IT서비스 업체(유지관리 전문사)를 대상으로 JBoss EAP, RHEL 등 상용 제품 전환 제안을 지원하는 파트너 세일즈 전략 권장
  • RFP 내 Red Hat(또는 동의어) 상용 제품 명시 현황: 없음 (JBoss 7.4는 공개SW로 분류되어 상용 RH 제품 미해당)
