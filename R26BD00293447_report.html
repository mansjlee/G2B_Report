Red Hat 제안
불가능 요소
  • S/W 신규 납품 없음: 본 사업은 순수 유지관리·운영 용역으로 신규 S/W 구매·납품·구독 갱신 품목이 별도로 명시되어 있지 않음. 신규 Red Hat 상용 제품 도입 확정 기회는 없음
  • JBoss 7.4는 커뮤니티 제품(WildFly 계열): 운영 현황에 명시된 "JBOSS JBOSS 7.4"는 Red Hat의 상용 제품인 JBoss EAP가 아닌 오픈소스/커뮤니티 버전으로 추정됨. 상용 JBoss EAP·RHEL 구독 품목으로 명시되지 않아 "높음" 판정 근거로 사용 불가
  • 예산 규모 제한: 총 사업비 768백만원, 총 예산 20억원 미만으로 대기업·중견기업 입찰 참여 제한 사업. Red Hat이 직접 입찰 참여 불가하며 SI 파트너 통해서만 접근 가능
  • OS 미명시(경쟁 제품 없음): RFP에 Ubuntu, Rocky Linux, Oracle Linux 등 경쟁 제품이 명시되어 있지는 않으나, RHEL 등 Red Hat 상용 OS도 명시되지 않음
  • 개발도구/런타임이 JSP·JAVA 중심: 시스템 개발도구는 JSP, JAVA, ActiveSquare 등 범용 기술 스택 위주로 Red Hat 특정 제품 필요성이 낮음
Red Hat 제안
가능 요소
  • JBoss 7.4 WAS서버 기 운영 중: 공개SW 현황에 "JBOSS JBOSS 7.4"가 WAS서버로 명시되어 현재 운영 중. JBoss(커뮤니티)를 Red Hat JBoss EAP(상용) 구독으로 전환 제안 여지가 있음. 구독 전환 시 기술지원·보안패치·라이선스 정합성 확보 가능
  • APACHE 2.4 WEB서버 운영: Apache HTTP Server 운영 환경에서 Red Hat Enterprise Linux(RHEL) 기반 플랫폼으로의 전환 또는 운영체제 업그레이드 제안 가능성 존재
  • OS·인프라 플랫폼 미지정: RFP에 서버 OS가 명시되지 않아, 유지관리 수행 중 OS 변경·클라우드 이전 등 기반환경 변화 시 RHEL 제안 가능 (MAR-001: "클라우드 이전 및 OS 변경 등의 기반환경 변화 시 소스 이관 등의 기술 지원" 명시)
  • Ansible 자동화 제안 가능: 상시 모니터링, 예방점검(월 1회), 반복적 장애 대응 자동화 요구사항 다수 존재. Ansible Automation Platform을 통한 운영 자동화 솔루션 제안 여지 있음
  • RFP에 명시된 Red Hat(또는 동의어) 제품명·수량:
    • JBOSS 7.4 (WAS서버, 공개SW) - 수량 미상 (공개SW 4식 중 1식)
    • ※ 상용 Red Hat 제품(RHEL, JBoss EAP, OpenShift, Ansible 등)은 구매/납품 품목으로 명시되지 않음
  • 파트너사 통한 영업 접근: 본 사업의 SI 수행업체(낙찰사)를 통해 JBoss EAP 구독 전환, RHEL 도입 등을 제안하는 간접 영업 전략 수립 필요
