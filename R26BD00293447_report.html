Red Hat 제안
불가능 요소
  • S/W 신규 납품·구독 항목 없음: 본 사업은 순수 유지관리 용역으로, 신규 S/W 도입·납품·구독 갱신 품목이 RFP에 명시되지 않음. 상용SW 9식은 모두 타 국내 벤더 제품으로 구성
  • Red Hat 상용 제품명 미명시: RHEL, OpenShift, Ansible, JBoss EAP 등 Red Hat 상용 제품명이 운영 환경 및 유지보수 대상 목록에 전혀 기재되지 않음
  • WAS서버가 JBoss 7.4(커뮤니티 업스트림)로 명시: 현행 WAS 환경이 JBoss EAP(상용)가 아닌 JBoss 7.4(커뮤니티 버전, WildFly 계열)로 운영 중. 상용 RH 제품 도입 확정 근거 불가
  • 소규모 중소기업 전용 사업: 예산 20억원 미만으로 대기업·중견기업 입찰 참여 제한. Red Hat이 직접 입찰에 참여하기 어려운 구조이며, SI 파트너를 통한 간접 제안도 쉽지 않은 환경
  • 경쟁·대체 OS 미명시, 단 RH도 미명시: Ubuntu, Rocky Linux, Oracle Linux 등 명시적 경쟁 제품은 없으나, Red Hat 상용 제품도 없음
Red Hat 제안
가능 요소
  • JBoss 7.4 → JBoss EAP 전환 제안 여지: 현행 WAS 환경이 JBoss 7.4(커뮤니티 업스트림, WildFly 계열)로 운영 중. 차기 사업 수행 시 또는 중장기적으로 상용 지원이 필요한 시점에 JBoss EAP(Red Hat 상용 WAS) 전환을 제안할 수 있는 영업 접점 존재
  • APACHE 2.4 WEB서버 운영 환경: APACHE + JBoss 조합으로 운영 중인 환경은 Red Hat 솔루션 스택(RHEL + JBoss EAP)과 기술적으로 친화적. 향후 OS 및 미들웨어 상용화 전환 논의 가능
  • 클라우드 이전 및 OS 변경 기술지원 요구(MAR-001): RFP에 "클라우드 이전 및 OS 변경 등의 기반환경 변화 시 소스 이관 등의 기술 지원을 수행해야 함"이 명시되어 있어, 향후 RHEL 또는 OpenShift 기반 전환 시나리오 논의 가능성 존재
  • 보안·운영 요구사항 강도 높음: DB 접근통제, 소프트웨어 개발보안, 네트워크 보안 등 강화된 보안 요구사항은 RHEL의 SELinux, 보안 강화 기능 및 Ansible Automation Platform을 활용한 자동화 보안 패치 관리 등을 제안할 수 있는 기반
  • RFP에 명시된 Red Hat(또는 동의어) 상용 제품명·수량: 없음 (JBoss 7.4는 커뮤니티 업스트림 버전으로 상용 JBoss EAP와 동일시 불가)
