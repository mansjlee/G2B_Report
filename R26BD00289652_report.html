Red Hat 제안
불가능 요소
  • 순수 유지관리 용역 사업: 본 사업은 기존에 구축된 면세운영시스템(ERP) 및 POS결제시스템의 운영·유지관리 용역으로, 신규 S/W 납품·구독 항목이 전혀 없음. 상용 SW 목록은 기존 운영 중인 제품의 유지관리 대상임.
  • 기존 기술 스택이 Red Hat과 무관:
    • POS 시스템: Windows 10 OS + .NET Framework 4.0 + C# + SQLite 기반
    • 면세운영 Application: Xplatform 9.2 기반
    • DBMS: Oracle Database Standard Edition (Red Hat 스택 아님)
    • 클라우드 인프라: 네이버 공공클라우드 (Red Hat OpenShift 환경 아님)
  • Red Hat 상용 제품명 전혀 미명시: RHEL, OpenShift, Ansible, JBoss EAP, Satellite 등 Red Hat 상용 제품이 RFP 전체에 걸쳐 단 한 건도 언급되지 않음.
  • 인프라 교체 여지 없음: 기존 네이버 공공클라우드 환경 유지가 전제이며, 수행사는 클라우드 서비스 제공사와 협업하는 역할에 한정. OS·플랫폼 변경 재량 없음.
  • Linux·컨테이너·자동화 관련 요구사항 없음: RFP 전반에 걸쳐 Linux, Kubernetes, 컨테이너, PaaS, 자동화 플랫폼 관련 기술 요구사항이 전혀 없음.
  • 소프트웨어 분리발주 없음: 본 사업 총액 20억 미만의 단일 유지관리 용역으로, Red Hat 제품을 별도 품목으로 제안할 구조적 여지 없음.
Red Hat 제안
가능 요소
  • 제안 가능 포인트: 사실상 없음
    • RFP 및 과업지시서 전체에 Red Hat 상용 제품명(RHEL, OpenShift, Ansible, JBoss 등) 또는 그 동의어가 전혀 명시되어 있지 않음.
    • 기존 구축 환경(Windows/Oracle/Naver Cloud/Xplatform)이 이미 확정되어 있으며, 수행사는 현행 유지관리만 수행하므로 플랫폼 교체 제안이 현실적으로 불가능.
    • DB 관련으로도 Oracle DBMS가 명시 지정되어 있어 Red Hat Data Grid 등 대체 제안 여지 없음.
  • 제안 불가능 포인트 요약:
    • 신규 S/W 도입·납품 항목 없는 순수 유지관리 용역 → SW 구독 제안 불가
    • OS: Windows 10 확정(POS), 서버 OS는 Naver Cloud 관리 영역 → RHEL 제안 불가
    • DBMS: Oracle Database Standard Edition 확정 → Red Hat 대체 불가
    • 클라우드: 네이버 공공클라우드 확정 운영 중 → OpenShift 전환 제안 불가
    • 자동화·컨테이너·PaaS 요구사항 없음 → Ansible/OpenShift 제안 근거 없음
  • RFP 내 Red Hat 제품명·수량: 없음 (0건)
