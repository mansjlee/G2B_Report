Red Hat 제안
불가능 요소
  • [S/W 납품 없음]: RFP 제6조 가항에 "SW 분리발주 하지 않음 (상용 소프트웨어 도입이 없는 사업)"으로 명시. 상용 SW 구독·납품 항목이 구조적으로 존재하지 않는 순수 유지관리 용역 사업
  • [Red Hat 상용 제품 미언급]: RFP 전문 및 별표·별지 포함 어디에도 RHEL, OpenShift, Ansible, JBoss EAP, Satellite 등 Red Hat 상용 제품명이 전혀 명시되어 있지 않음
  • [경쟁 제품 미언급]: VMware, Ubuntu, Rocky Linux, Oracle Linux 등 경쟁 제품도 명시되지 않으나, SW 납품 자체가 없으므로 경쟁 구도 성립 불가
  • [기타 제약]: 기술적용계획표에 Linux(서버용 운영체제)가 기존 적용 항목으로 표시되어 있으나, 이는 기존 시스템 운영환경 확인용이며 신규 OS 도입이 아님. 20억 미만 사업으로 중소기업만 참여 가능하여 Red Hat 직접 참여도 불가
Red Hat 제안
가능 요소
  • [RFP 내 Red Hat 제품명 명시]: 없음 — RHEL, OpenShift, Ansible, JBoss EAP 등 Red Hat 상용 제품 일체 미언급
  • [기술 스택 관련]: 기술적용계획표상 서버용 운영체제로 UNIX, Linux, Windows Server 모두 기재되어 있으나, 기존 환경 표시일 뿐 신규 도입 계획이 아님. 전자정부 표준프레임워크(Java 기반), RDBMS 운영이 핵심으로 Red Hat 스택 신규 도입 여지 없음
