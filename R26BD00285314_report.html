Red Hat 제안
불가능 요소
  • 경쟁 OS 확정 명시: 구독료 목록에 Oracle Enterprise Linux OS 9개가 OS 구독 품목으로 명시 → RHEL 도입 여지 없음 (판정규칙상 낮음 사유)
  • 경쟁 미들웨어 확정: WAS로 JEUS(TmaxSoft), Web서버로 WEBTOB(TmaxSoft)가 유지관리 대상으로 확정 → JBoss EAP·WildFly 제안 불가
  • 경쟁 DBMS 확정: Oracle 19c/Oracle Standard, Tibero 6/7 Enterprise가 1등급 DBMS로 운영 중 → Red Hat 관련 없음
  • Red Hat 상용 제품 전무: RFP 전체(유지관리 대상 목록 204종 SW, 33종 HW, 구독료 12종)를 통틀어 RHEL·OpenShift·Ansible·JBoss EAP 등 Red Hat 상용 제품명이 단 한 건도 언급되지 않음
  • 순수 유지관리 사업 성격: 신규 SW 도입이 아닌 기존 스택 유지·관리 중심 사업으로, 기존 확정된 Oracle EL/JEUS/Tibero/Oracle DB 스택 교체 가능성 없음
  • 하드웨어 현황: IBM E980(Unix), Lenovo ThinkAgile HX, HPE DL360/DL380 등 x86·Unix 서버 기반으로 Red Hat 가상화(RHEV) 제안 여지 없음

    • 클라우드 전환 계획 시 OpenShift/RHEL 제안 여지 (현재는 온프레미스 환경 유지관리)
