불가능 요소
  • 입찰공고서 원문이 OCR 손상으로 판독 불가능한 수준이며, S/W 구매·납품 항목이 전혀 확인되지 않음

  • 경쟁 제품(VMware, Ubuntu, Oracle Linux 등)도 언급되지 않으나, 전반적으로 S/W 도입 항목 자체가 불명확함
  • 금융권 내부 시스템 개발 특성상 특정 상용 OS/미들웨어가 별도 공고 없이 기존 인프라를 활용할 가능성이 높음
Red Hat 제안
가능 요소
  • 금융권(은행) BIS 리스크 산출 시스템은 일반적으로 Linux 기반 서버 환경에서 운영되므로, RHEL 제안 여지가 간접적으로 존재할 수 있음
  • 신규 시스템 개발 시 컨테이너 기반(OpenShift) 또는 자동화(Ansible) 아키텍처 도입을 제안할 여지가 있으나, 현재 RFP에서 명시적 요구 확인 불가
  • JBoss EAP(엔터프라이즈 Java 미들웨어) 기반의 금융 애플리케이션 제안 가능성 있으나, 근거 텍스트 없음
  • RFP 내 Red Hat 제품명·수량 명시: 없음 (원문 손상으로 추가 확인 필요)
