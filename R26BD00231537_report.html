  • 목표 아키텍처 수립: 타깃 클라우드 환경으로의 성공적인 이전을 위한 목표 시스템 개념도 도출 및 단계별 세부 전환 방안 수립 필요.

4. Red Hat 주요 제품 제안 가능 포인트

국가화재정보시스템의 성공적인 클라우드 네이티브 전환을 위해 다음과 같은 Red Hat 솔루션 스택 제안이 유효합니다.

  • Red Hat OpenShift (EAP / Container Platform): 클라우드 네이티브 전환의 핵심 플랫폼으로서, 소방청 애플리키션의 컨테이너화(Containerization)와 쿠버네티스(Kubernetes) 기반 오케스트레이션을 제공하여 중단 없는 자동 스케일링 환경 구축 가능.
  • Red Hat Enterprise Linux (RHEL): 하이브리드 클라우드 인프라의 표준 운영체제(OS)로서, 공공기관이 요구하는 강력한 보안성과 고성능의 안정적인 엔터프라이즈 인프라 기반 제공.
  • OpenShift Virtualization Engine: 클라우드 네이티브 환경으로 즉시 전환이 어려운 일부 legacy 가상머신(VM) 가동 시스템들을 컨테이너 환경 내에서 단일 플랫폼으로 통합 관리할 수 있도록 지원.
  • Red Hat JBoss (EAP): 기존 전자정부 표준 프레임워크 기반의 Java 웹 애플리케이션을 가볍고 기민한 컨테이너 기반 런타임 환경으로 마이그레이션하는 최적의 솔루션 제공.
  • Red Hat Ansible Automation Platform: 인프라 구성 관리 및 애플리케이션 배포 자동화(CI/CD 연계)를 통해 재난 상황 시 신속한 복구 및 인적 오류 최소화를 위한 IT 프로세스 자동화 실현.
