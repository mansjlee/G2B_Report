사업 개요 및 목적

  • 신규 개방과제 3종(지방정부 공공문서 통합정보, 온라인 쇼핑몰 통합정보, 시니어 생활 밀착형 통합정보)과 기개방과제 4종 확대를 통해 인공지능 친화적 통합데이터를 제공하고, 국가공유데이터플랫폼·공공데이터포털과의 범정부 데이터 파이프라인 전환을 추진한다.
  • 데이터 품질진단·표준화, 오픈API 개발·운영, 차년도 개방과제 발굴 및 중장기 개방전략 수립 등 데이터 개방 전주기 운영·고도화가 핵심 목표이다.

Red Hat 제안
가능 요소
  • RHEL: 기술적용계획표 플랫폼 분야에서 Linux가 서버용 운영체제 적용 대상으로 제시되어, 제안서 기술아키텍처·운영환경 최적화 방안으로 RHEL 기반 안정적 Linux 운영·보안·커널 지원을 부가 제안 가능(단, 필수 조달 항목 아님).
  • OpenShift: '26.4월 클라우드 환경 이관, 오픈소스 기반 이중화·서비스 환경 구성, 실시간 대용량 API 처리 요구와 연계하여 컨테이너·PaaS 기반 확장·운영 자동화를 제안서 차별화 요소로 제시 가능.
  • Ansible: 17개 광역시도·다수 지방정부 오픈API 배포모듈 설치·기술지원, 모니터링·장애관리, 환경변경 대응(OSR·OSR-05) 등 반복 운영·구성관리에 Ansible Automation Platform 활용 방안 제시 가능.
  • 기술 요구 정합성: 24×365 무중단 운영, 이중화·장애복구, 성능·부하테스트, DevSecOps·자동화, 클라우드 전환, MCP·AI Agent 연계 등 Red Hat 오픈 하이브리드 클라우드·자동화 스택과 부합하는 기술 요구 다수 존재.
  • 파트너·하도급 경로: Red Hat이 직접 수주하기 어려울 경우, 중소·중견 SI 수행사의 기술 파트너·하도급 형태로 RHEL/OpenShift/Ansible 아키텍처 자문·PoC 지원은 가능(하도급 50% 이내, 사전승인 필요).
