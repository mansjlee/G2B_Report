가능 요소
  • [OS 미지정 Linux 전환 기회 - 핵심] SAS 서버 OS 변경(Unix → Linux) 시 특정 Linux 배포판이 RFP에 명시되지 않음 → G-Cloud 신규 서버 Linux OS로 RHEL(Red Hat Enterprise Linux) 제안 가능

  • [SAS 재설치 환경 구성 지원] SAS 재설치를 위한 OS 환경설정·필수 패키지·라이브러리 설치 지원(MPR-007) 과정에서 RHEL 기반 환경 제안 및 기술 지원 여지 존재
  • [Ansible 자동화 제안 여지] 다수의 상용 SW(5,005개) 모니터링·패치·백업 자동화 업무에 Ansible Automation Platform(AAP) 제안 검토 가능
  • [RFP 내 Red Hat 제품명 직접 명시] RFP 내 Red Hat(레드햇) 상용 제품명·수량이 직접 명시된 항목은 없음
