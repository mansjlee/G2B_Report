  • [구형 버전 운영] RHEL 6~9 혼재 운영 중으로, RHEL 6·7은 이미 EOS(기술지원 종료) 상태, 유지관리 방안 별도 협의 필요 (MAR-002 기술지원 종료 S/W 방안 명시)

    • OS:Red Hat Enterprise Linux Server 탑재 서버: 대상 B 6식
