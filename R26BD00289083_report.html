불가능 요소
  • [S/W 유지관리 목록 미포함]: 붙임3 S/W 유지관리 대상 목록에 RHEL, JBoss EAP, Ansible 등 Red Hat 상용 제품이 명시적으로 포함되지 않음 → 라이선스 갱신 품목으로 확정 불가
  • [경쟁 OS 명시]: 시스템 현황 개발환경 표에 OracleLinux 8.8이 일부 서버(영상, 공공거점) OS로 명시되어 있음
  • [커뮤니티 제품 혼용]: WAS로 HF-Wildfly 26.x가 사용 중 (WildFly 기반 커뮤니티 계열, Red Hat 상용 JBoss EAP와 상이)
  • [유지관리 전문 SI 사업]: 사업 특성상 Red Hat이 직접 참여하기 어려운 구조이며, SI 사업자가 S/W를 간접 구매하는 방식
  • [기술 범위 제한]: OpenShift(컨테이너), Ansible(자동화), RHEL AI 등 신규 Red Hat 플랫폼 도입 요구사항이 전혀 없음
  • [20억 미만 중소기업 제한]: 대기업·중견기업 입찰 참가 제한으로 Red Hat 직접 참여 불가
Red Hat 제안
가능 요소
  • [RHEL 기존 운영 확인]: 시스템 현황 개발환경 표에 OS로 Redhat(RHEL) 6.9 명시(영상, 공공거점 서버) → 현재 RHEL 상용 라이선스 사용 중인 환경
  • [JBoss 운영 확인]: 전산자원 현황 WAS 목록에 JBoss 명시 → Red Hat 상용 제품(JBoss EAP)으로 해석 가능한 환경 존재
  • [RHEL 업그레이드 기회]: RHEL 6.9는 EOL(End of Life) 상태로, 보안 취약점 지원 종료 → ISMS-P 인증 및 공공시스템 보안 강화 요구사항과 연계하여 RHEL 최신 버전(8.x/9.x) 업그레이드 제안 가능
  • [상용 S/W 라이선스 갱신 범위 포함]: MPR-002 "유지관리 대상 상용 S/W 유지관리 및 라이선스 갱신" 명시, 사업 내용 중 "SW라이선스 등의 정기적인 파악 및 구매/교체/적용 처리 지원" 포함 → RHEL/JBoss 라이선스 갱신 지원 업무 포함 가능성
  • [Linux 기반 인프라 환경]: G-Cloud(국가정보자원관리원) 기반 Linux 서버 운영 환경으로 RHEL 확산 또는 전환 제안 여지 존재
  • [RFP 명시 Red Hat 제품·수량]: 시스템 현황 개발환경 표에 OS로 Redhat 6.9(수량 미명시, 영상·공공거점 서버), WAS/웹서비스로 JBoss(수량 미명시) 명시
  • [전략 제안]: 유지관리 사업자를 통해 RHEL EOL 이슈를 발주기관에 공유하고, 차기 인프라 교체·구축 사업 시 RHEL/OpenShift 도입 연계 영업 기회로 활용 가능
