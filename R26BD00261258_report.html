사업 개요 및 목적
  • 「돌봄통합지원법」 시행에 따른 돌봄 통합지원정보시스템 구축(2단계) 사업의 PMO(사업관리 위탁) 용역으로, 진행 중인 2단계 구축 사업의 집행·사후관리를 지원하고 2027년 차기 구축 사업 기획을 병행 지원함
  • 구축 사업 전반에 대한 통합관리, 위험·품질·일정·범위 관리, 기술 검토·자문, 감리·개인정보영향평가 대응, 안정화 및 기술이전 지원 등을 통해 성공적인 시스템 구축을 목표로 함
  • PMO 대상 사업(구축)은 의료·요양·돌봄 통합지원 기능 고도화, 외부·내부 시스템 연계(24개 서비스), API 표준 개발, 서비스 제공기관 업무처리 지원, 데이터 기반 통계·DW 등을 범위로 함

불가능 요소
  • S/W 공급 미포함: 본 사업은 PMO(사업관리·컨설팅) 용역이며, Red Hat 제품(RHEL, OpenShift, Ansible 등)의 조달·공급·라이선스 구매 요건이 RFP에 전혀 명시되지 않음
  • 경쟁/타사 제품 명시 없음: VMware, Contrabass, Ubuntu, Oracle/Rocky Linux 등 특정 상용 S/W 지정은 없으나, Linux·Windows Server 등 범용 OS가 기술적용계획표에 병렬 기재되어 있어 Red Hat 단독 지정도 없음
  • 입찰 자격·사업 성격: 전자정부사업관리(PMO) 수탁 자격(공공기관·감리법인·SW사업자) 대상, 중소 SW사업자만 참가 가능, 하도급 불허 → Red Hat은 PMO 용역 수행 주체가 아님
  • 이해충돌 제약: PMO 사업자는 PMO 대상 구축사업 수행자·감리업체로 참여 불가(PMR-006) → Red Hat이 구축사로서 제품을 공급하는 경로와 PMO 입찰 경로가 상호 배타적
  • 직접 매출 기회 부재: PMO 계약 범위는 관리·검토·자문이며, S/W 조달관리(CSR-010)는 구축사업자의 조달계획 점검 수준이므로 Red Hat 제품 판매 계약 구조에 해당하지 않음
Red Hat 제안
가능 요소
  • 2027년 구축사업 기획 간접 영향(CSR-001): PMO가 2027년 RFP·기술요건 상세화·FP 산출을 지원하므로, PMO 수행사 또는 발주기관 자문 과정에서 컨테이너·API·클라우드 아키텍처 관련 Red Hat 기술을 참고안으로 제시할 여지는 있으나, PMO RFP 자체의 조달 항목은 아님
  • 기술검토·자문 영역(CSR-013, PSR-002): PMO 대상 구축사업의 시스템 아키텍처·연계·보안·성능 검토 시 Linux 기반 인프라, RESTful API, 클라우드(IaaS/PaaS) 등 Red Hat 강점 영역과 부합하는 기술 검토가 가능하나, 이는 PMO 용역 내 기술자문이지 Red Hat 제품 공급이 아님
  • 차기 구축사업 직접 입찰 기회: PMO 대상 사업(5,144백만원)은 별도 구축 입찰로, Linux·API·클라우드·DevOps 요구가 포함될 경우 RHEL/OpenShift/Ansible 제안 가능성 존재 — 단 본 PMO 공고(R26BD00261258)와는 별개 사업
  • 파트너 연계: PMO 입찰 참여 SW사업자(중소기업)와 협력하여 2027년 기획 단계 또는 구축사업 입찰 시 Red Hat 솔루션을 서브컨트랙터·기술파트너로 제안하는 간접 영업 경로는 검토 가능
