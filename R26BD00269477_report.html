사업 개요 및 목적
  • 한국농어촌공사가 운영 중인 농촌용수종합정보시스템(RAWRIS) 및 KRC재난안전종합상황실시스템(DIMAS)의 안정적 운영·유지관리와 기능 고도화를 위한 용역 사업
  • RAWRIS의 노후화된 대국민 포털·모바일 UI/UX를 전면 개편하여 정보 접근성과 이용 편의성 향상
  • DIMAS에 위젯 기반 맞춤형 대시보드를 구축하여 재난 상황 의사결정 지원 강화
  • 저수지 수문(水文) 공인신청 및 농업용수 공급량 산출체계 자동화로 데이터 신뢰성과 업무 효율 향상
  • AI 기반 저수지 수위 예측모델 지속 관리·개선 및 기상청·NDMS 등 대외 시스템 연계 현행화
주요 정보

  • 계약 방법: 협상에 의한 계약 / 제한경쟁입찰 (중소기업자만 입찰 참가 가능, 대기업·중견기업 참여 제한)

  • 주요 일정: 2026년 7~12월 사업준비·발주·계약·착수 → 2027년 RAWRIS UI/UX 개편·DIMAS 대시보드 1차 구축·수문공인 산정체계 구축·유지관리 → 2028년 DIMAS 위젯 5종 추가 개발·수문공인 보고서 자동생성·완료보고회

핵심 요구사항
  • [기능 요구사항]
    • RAWRIS 대국민 웹·모바일 UI/UX 개선, 메인화면·서브화면 전면 개편 (반응형 설계, 웹 접근성 준수)
    • DIMAS 위젯 프레임워크 구축 및 정보 위젯 15종 개발 (저수지 위기단계, 기상특보, AI 홍수예측 등)
    • REDIS CCTV 채널·영상정보 DIMAS 추가 연계 및 통합조회 기능 구현
    • 저수지 수문 공인신청 자료 관리 및 농업용수 공급량 산정·관리 기능 개발 (이상치 자동검출·보정, 보고서 자동생성)
  • [기술 스택 현황 (기존 시스템)]
    • WAS: Oracle Weblogic / OS: Windows Server (WAS서버), Linux (DB서버·AI모듈서버)
    • DBMS: Oracle / WEB: Apache / 연계 WAS: Apache Tomcat
    • 개발언어: JAVA(1.7/1.8), JSP, J-query, HTML, Python 등
    • GIS: GeoServer
  • [구매가 명시된 S/W]: 본 사업은 순수 기능개선·유지관리 용역 사업으로, RFP 내 통합발주 또는 조달쇼핑몰 직접구매 대상 상용 S/W 품목이 별도 명시되어 있지 않음. H/W·S/W EOS로 인한 교체 시 서비스 이관 과업이 포함되어 있으나 구체적 납품 제품명 및 수량은 미기재.
  • [비기능 요구사항]: 동시 사용자 200명 이상, 응답시간 3초 이내(3MB 이하 페이지), 장애 복구 3시간 이내, 데이터 복구 6시간 이내, 웹 접근성 준수율 95% 이상, 전자정부 표준프레임워크 최신 버전 적용 의무화
  • [보안·제약]: 국가정보보안기본지침, 개인정보보호법, 시큐어코딩 가이드 준수, SSL 구간 암호화, SSO 인증체계 연계(업무포털 KORUS), 보안약점 진단도구 사용 의무
Red Hat 제안
불가능 요소
  • 순수 용역 사업 구조: 본 사업은 소프트웨어 개발·유지관리 용역으로, RFP 내 상용 S/W(라이선스·구독) 납품·구매 항목이 명시되어 있지 않아 Red Hat 상용 제품을 직접 납품·도입하는 구조가 아님
  • 기존 WAS 스택 고착화: 현재 WAS 서버에 Oracle Weblogic이 사용 중이며, 사업 범위가 기존 시스템의 유지관리 및 기능개선이므로 JBoss EAP로의 대체 제안이 현실적으로 어려운 구조
  • 기존 DBMS 고착화: DB 서버에 Oracle DBMS가 사용 중이며 교체 범위에 포함되지 않음
  • 대기업 입찰 참여 제한: 20억 미만 사업으로 중소기업자만 입찰 참가 가능 → Red Hat Korea가 직접 입찰 불가, SI 파트너 협력 필요
  • Red Hat 상용 제품명 전혀 없음: RFP, 과업지시서, 기술적용계획표 어디에도 RHEL, OpenShift, Ansible, JBoss EAP 등 Red Hat 상용 제품이 품목으로 명시되지 않음
Red Hat 제안
가능 요소
  • Linux OS 미지정 (RHEL 전환 제안 여지): DB 서버 및 AI 모듈 서버의 OS가 "Linux"로만 명시되어 특정 배포판이 지정되지 않음. 현재 CentOS/Oracle Linux 등을 사용 중일 가능성이 있으며, EOS 이관 과업 수행 시 RHEL로의 전환을 제안할 수 있는 여지 존재
  • EOS 기반 OS 이관 과업 명시: MPR-003 요구사항에 "LINUX 체계에서 변경되는 운영체계에 대해 고려해야 할 제반사항을 분석 후 발주사와 협의 후 이관 업무 수행" 명시 → OS 마이그레이션 시 RHEL 채택 제안 기회
  • Python·AI 모듈 서버 환경: AI 기반 저수지 수위 예측 모델을 Python으로 운영하는 Linux 서버가 존재하며, RHEL AI 또는 RHEL 기반 AI 워크로드 환경 제안 가능
  • 형상관리·빌드·배포 자동화 요구: PMR-007에서 "형상관리, 빌드, 배포관리 등 자동화 관리 도구 활용 의무화" 및 "오픈소스 이용 권장" 명시 → Ansible Automation Platform, OpenShift(CI/CD 파이프라인) 제안 여지
  • 컨테이너·클라우드 보안 기준 명시: 기술적용계획표 보안 분야에 "민간 클라우드 활용 시 CSAP 인증 서비스" 언급, 가상화 제품 CC인증 언급 → 향후 컨테이너 플랫폼(OpenShift) 또는 RHEV 제안 접점 탐색 가능
  • RFP에 명시된 Red Hat(또는 동의어) 제품명·수량: 없음 (Red Hat 상용 제품이 RFP 어디에도 명시되지 않음)
