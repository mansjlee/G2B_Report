사업 개요 및 목적
  • 국립수산물품질관리원이 운영하는 수산물안전관리시스템 및 정보화시설 전반에 대한 2년간 통합 유지관리 사업
  • 수산물의 품질관리·안전성 확보·상품성 향상을 통한 농어업인 소득 증대 및 소비자 보호를 지원하는 정보시스템의 안정적 운영 보장
  • 체계적 예방점검·운영관리를 통해 장애요인을 사전 제거하고, 긴급 상황 시 신속 복구·지원체계 마련
  • 전문 유지관리 업체를 통한 위탁운영으로 효율적·안정적인 정보시스템 운영·관리 품질 제고

Red Hat 제안
불가능 요소
  • 신규 SW 통합발주 없음: 본 사업은 기존 시스템의 유지관리·운영 용역 사업으로, 신규 상용 SW 납품·구독 품목이 RFP에 명시되지 않음. 상용 SW 242식은 기존 도입 제품 유지관리 대상임
  • Red Hat 상용 제품명 미명시: RHEL, OpenShift, Ansible, JBoss EAP 등 Red Hat 상용 제품명이 RFP 본문 어디에도 품목으로 명시되지 않음
  • 기존 SW 구성 비공개: 유지관리 대상 SW 세부 목록이 비공개(현장 방문 열람)이므로, 현재 RHEL 도입 여부 및 경쟁 OS 사용 여부를 RFP만으로 확인 불가
  • 순수 유지관리 용역 성격: 사업 대부분이 인력 상주 운영·점검·장애대응 용역으로, SW 신규 납품 기회가 제한적
  • 중소기업 전용 입찰: 20억 미만 사업으로 대기업·중견기업 참여 제한, Red Hat 및 대형 총판의 직접 입찰 참여 불가 — SI 파트너를 통한 간접 제안 필요
Red Hat 제안
가능 요소
  • Linux OS 유지관리 명시 (OS 23식): 유지관리 대상 SW에 OS 23식이 포함되어 있으며, 기술지원확약서 제출 요건에 "운영체제(Linux)"가 명시됨. 기존 서버 OS 중 RHEL이 포함될 가능성이 있으며, RHEL 구독 갱신·기술지원 제안 기회 존재
  • 미들웨어 4식 유지관리 포함: 미들웨어 4식 유지관리 대상에 JBoss EAP 등 Red Hat 미들웨어가 포함될 가능성 있음 (세부 목록 현장 확인 필요)
  • WEB/WAS 8식 유지관리 포함: WEB/WAS 영역에서 JBoss EAP 또는 Red Hat 기반 WAS 운영 가능성 존재
  • 기술지원확약서 제출 요건 활용: MPR-001 요구사항에서 "운영체제(Linux) 제조사 기술지원확약서 제출" 명시 → 기존 RHEL 운영 환경이라면 Red Hat의 기술지원확약서 제출로 직접 참여 가능
  • Linux 서버 운영환경 기반 제안: 기술적용계획표에 "Linux" 서버 운영체제가 적용 항목으로 기재되어 있어, RHEL 기반 서버 OS 유지관리·구독 갱신 제안 가능
  • RFP에 명시된 Red Hat 제품명·수량: 없음 (상용 Red Hat 제품명 직접 명시 없음)
  • 영업 전략 제안: 현장 방문 열람을 통해 기존 SW 목록 확인 후, RHEL/JBoss EAP 구독 갱신 또는 CentOS→RHEL 전환 제안을 파트너(중소 SI 업체)와 협력하여 추진하는 방안 검토 권장
