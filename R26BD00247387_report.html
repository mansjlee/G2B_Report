  • 기술·기능 요구사항: MLOps 기반 통합 학습 시스템 구축 — 데이터셋 생성·편집·정제·레이블링·시각화·버전관리(SFR-001), 코드 기반 AI 모델 개발환경·분산학습·하이퍼파라미터 최적화·프로젝트 관리(SFR-002), 모델 서빙·변환·컴파일·패키징·배포·성능 모니터링(SFR-003), 통합 운영 UI/UX·사용자 인증·실시간 모니터링(SFR-004)
  • HW 구성: 학습용 전산처리기 2식(CPU 56Core+, RAM 512GB+, GPU 2×A100급+, SSD 2TB+, HDD 8TB+), 운용통제장치 3식(CPU 12Core+, RAM 32GB+), 캐비닛 1식(10G 스위칭허브 12포트+)
  • 운영·지원 요구: 상용·사용제한 SW 라이선스 제공, 계약기간 중 기술·운용 지원, 해상·육상 시험 데이터 전처리, 추론모델 컨테이너 형태 무인수상정 운용 지원, 오프라인 가상환경 지속 운용 및 패키지 업데이트, 현장 지원 및 운용자 교육

Red Hat 제안
불가능 요소
  • 직접 입찰 불가: Red Hat은 소프트웨어사업자가 아니며, 본 사업은 중소소프트웨어사업자만 참가 가능한 20억원 미만 용역 — Red Hat 단독 수주 불가, SI 파트너를 통한 간접 제안만 가능
  • 특정 S/W 지정 없음: RHEL, OpenShift 등 Red Hat 제품이 RFP에 명시되지 않았으며, 경쟁사 제품(VMware, Ubuntu, Oracle Linux 등)도 지정되지 않음 — 선정 우위 확보 근거 부재
  • 통합 SI·용역 중심: HW 납품, 데이터 전처리, 해상시험 현장 지원, 레이블링, 교육 등 Red Hat 제품 공급 범위를 넘어서는 용역 비중이 큼
  • 지식재산권 귀속: 용역 결과물의 지식재산권이 국방과학연구소에 귀속 — 커스텀 개발·통합 위주 사업 특성
  • 보안·방위산업 제약: 방위산업기술보호법, 국방과학연구소 보안예규 준수 필요 — 폐쇄·오프라인 환경 운용 요건
Red Hat 제안
가능 요소
  • OpenShift: MLOps 통합 운용, 모델 학습·배포·서빙 파이프라인, 컨테이너 기반 추론모델 무인수상정 배포, 모델 레지스트리·계층형 데이터체계 관리, GPU 워크로드 스케줄링·분산학습 환경에 적합
  • RHEL: 학습용 전산처리기(2식)·운용통제장치(3식) OS 기반, 고성능 GPU 서버(A100급) Linux 운영환경, 오프라인 패키지·모듈 업데이트 지원 요건 충족 가능
  • Ansible: 학습시스템 HW/SW 운용환경 자동 구축·구성관리, 다수 노드(5대+) 통합 배포 및 운영 자동화
  • OpenShift AI / MLOps 스택: 데이터셋 관리, 실험·프로젝트 관리, 하이퍼파라미터 튜닝, 모델 패키징·배포·성능 메트릭 수집 등 SFR-001~004 기능 요구와 기술적 정합성 높음
  • 파트너 협력 기회: MLOps 공급 실적 요건을 충족하는 중소 SW SI 업체와 Red Hat 구독·기술지원 패키지로 공동 제안 가능 — 제안서 제2장(소요기술), 제3장(추진방안)에서 인프라·플랫폼 레이어로 포지셔닝
