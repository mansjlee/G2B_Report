사업 개요 및 목적
  • 「교육환경 보호에 관한 법률」 제12조에 따라 구축·운영 중인 한국교육환경보호원의 4개 정보시스템(스마트 교육환경정보시스템, 교육환경플랫폼, 기관 대표홈페이지, 내부 심의관리시스템)에 대한 2개년(2027~2028년) 유지관리 및 운영지원 사업
  • 2024~2026년 3개년에 걸쳐 구축한 (스마트) 교육환경정보시스템의 전환 오픈 이후 장애·오류 대응 및 기존 기능 안정화
  • 대국민·시도교육청·업무담당자 문의 대응 및 자료입력 지원 등 온라인 업무지원 체계 운영을 통한 정보시스템 사용자 만족도 제고
  • 정보시스템의 효율적·체계적 관리 및 안정적 운영 확보

  • 프로젝트 지원(PSR): 업무 인수인계 및 기술이전, (스마트) 교육환경정보시스템 3차년도 구축사업 협업 및 운영 인수인계 등 2개 요구사항
  • 전자정부 표준프레임워크 적용, 웹 접근성·호환성 준수, RESTful API 기반 연계, GIS 기반 공간정보 서비스 운영
[구매 명시 S/W]
  • RFP 내 통합발주·조달구매 대상으로 명시된 개별 S/W 품목 및 수량은 존재하지 않음
  • 다만, MPR-013(상용SW 유지관리 및 무상지원 종료 전환) 조항에 "파일전송, 애플리케이션 모니터링, 현장점검 서식 등 운영 중인 상용SW"를 유지관리 대상으로 관리한다고 명시되어 있으나, 구체적인 제품명·수량은 미공개(실제 납품·검수 내역 기준으로 확정 예정)
  • 3차년도 구축사업에서 도입 또는 연계하는 모니터링 시스템(MPR-010)도 실제 구축범위·라이선스를 착수 시 확인 예정으로 명시적 제품명 없음
Red Hat 제안
불가능 요소
  • S/W 신규 구매·납품 항목 없음: 본 사업은 순수 유지관리·운영지원 용역 사업으로, 별도 S/W 구독·라이선스 구매·납품 품목이 RFP에 명시되어 있지 않음
  • Red Hat 상용 제품명 미명시: RFP 전체에 걸쳐 RHEL, OpenShift, Ansible, JBoss EAP 등 Red Hat 상용 제품명이 유지관리 대상·도입 품목으로 전혀 기재되어 있지 않음
  • 경쟁 제품 명시 없음(단, RH도 없음): Ubuntu, VMware, Oracle Linux, Rocky Linux 등 경쟁 제품도 명시되어 있지 않으나, Red Hat 상용 제품도 명시 없는 상태
  • 중소기업 전용 사업: 20억 미만 사업으로 대기업·중견기업 참여 제한 → Red Hat Korea 직접 입찰 불가, SI 파트너를 통한 간접 기회만 존재
  • 현행 시스템 구성 비공개: 네트워크 및 인프라 구성 현황은 보안상 공개하지 않고 제안사 요청 시 별도 제공 → 현행 RH 제품 사용 여부 사전 확인 불가
  • JBoss/WildFly 미명시: WAS 서버로 WEB/WAS가 언급되나 JBoss, WildFly 등 구체적 제품명은 기재되어 있지 않음
Red Hat 제안
가능 요소
  • Linux 기반 서버 운영환경 가능성: 기술적용 계획표 플랫폼 분야에 "Linux"가 서버용 개방형 운영체제 항목에 적용 대상으로 표시되어 있어 현행 또는 향후 Linux 계열 OS 사용 가능성 존재 → RHEL 제안 여지
  • 전자정부 표준프레임워크(Java 기반) 적용: Java 기반 WEB/WAS 환경이 전제되며, JBoss EAP 등 Red Hat 애플리케이션 서버 플랫폼 제안 여지 존재
  • 상용SW 유지관리 전환 기회: MPR-013에서 무상지원 종료 이후 상용SW의 유지관리 전환을 명시 → 현행 운영 중인 SW 중 Red Hat 제품이 포함되어 있을 경우, 구독 갱신·전환 기회 가능
  • EOS(기술지원 종료) 대응 요구: MPR-012에서 주요 구성요소의 버전 및 EOS 현황 목록화, 버전업 필요 시 호환성·보안·라이선스 검토를 요구 → CentOS 등에서 RHEL 전환 제안 가능성
  • 컨테이너·클라우드 기술 적용 여지: 기술적용 계획표에 IaaS·PaaS·SaaS 항목이 포함되어 있어 향후 컨테이너 기반 운영 전환 시 OpenShift 제안 가능성
  • RFP 내 명시된 Red Hat 제품명·수량: 없음 (RFP 어디에도 Red Hat 상용 제품명이 명시적으로 기재되어 있지 않음)
  • 영업 접근 전략: 현재 운영 중인 시스템의 실제 SW 구성(현행화 착수 시 확인 예정)에 Red Hat 제품 포함 여부를 SI 파트너(수주 사업자)를 통해 사전 파악하고, 구독 갱신 또는 RHEL/JBoss EAP 전환 기회를 모색하는 간접 영업 전략이 유효함
