불가능 요소
  • S/W 납품·구독 항목 없음: 본 사업은 기존 PORT-MIS 시스템에 대한 위탁운영 용역으로, 신규 상용S/W 구매·납품·구독 항목이 없음. 붙임6의 상용S/W는 기존 설치 제품의 유지관리 대상에 불과
  • Red Hat 제품 미명시: RFP 전문 및 붙임6 유지관리 목록 어디에도 RHEL, OpenShift, Ansible, JBoss EAP 등 Red Hat 상용 제품이 품목으로 명시되지 않음
  • 기존 SW Stack 고착: 이미 국정자원(대전) 환경에서 운영 중인 기존 SW 스택(BizFrame, Elevisor, WebSquare, Crownix 등)을 그대로 유지관리하는 구조로, 신규 플랫폼·OS 도입 여지가 사실상 없음
  • 경쟁 제품 특정 없으나 교체 불가: Ubuntu, Rocky Linux, Oracle Linux 등 경쟁 OS가 명시되지는 않았으나, 기존 운영 환경이 이미 고정되어 있어 OS 교체 가능성 극히 낮음
  • 사업 성격상 제약: 협상에 의한 계약으로 낙찰자가 SI 사업자이며, Red Hat이 직접 참여하는 구조가 아닌 운영 아웃소싱 형태
Red Hat 제안
가능 요소
  • Linux 서버 OS 적용 가능 명시: 기술적용계획표(붙임7)의 플랫폼 및 기반구조 분야에서 "Linux O(적용)" 으로 명시되어 있어, 현 운영 서버 인프라에 Linux 계열 OS가 사용 중임을 확인할 수 있음 → 향후 인프라 갱신 시 RHEL 전환 제안의 근거가 될 수 있음
  • DB 및 WAS 모니터링 환경: Elevisor 등 모니터링 도구 19식 운영 중으로, Red Hat Ansible 기반 자동화 및 OpenShift 기반 컨테이너 전환 중장기 제안 가능성 존재 (단, 현 RFP 범위 외)
  • 보안 요구사항 강화: 월 1회 이상 보안 취약점 점검, 소스코드 보안약점 진단 등 강화된 보안 요구 → Red Hat의 Advanced Cluster Security(ACS) 등 솔루션을 관계사 제안으로 연계할 여지가 있으나 현 사업 범위에는 해당 없음
  • RFP 내 Red Hat(또는 동의어) 제품 명시 없음: 현재 RFP 및 붙임 전체에 걸쳐 Red Hat 상용 제품명은 전혀 언급되지 않음 → 직접적인 영업 기회 없음
