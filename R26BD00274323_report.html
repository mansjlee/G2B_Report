  • NTIS 등 타 시스템과의 연계·연동 및 데이터 구축(ETL) 지원 포함

불가능 요소
  • S/W 신규 납품·구독 항목 부재: 본 사업은 기존 운영 중인 자료관리시스템의 유지관리 용역으로, 신규 S/W 구매·도입 항목이 포함되지 않음
  • 시스템 구성 비공개: 현 운영 시스템의 H/W·S/W 구성 상세 내역이 보안사항으로 공개되지 않아 기존 스택 확인 불가
  • Red Hat 상용 제품명 미기재: RFP 전문에 RHEL, OpenShift, Ansible, JBoss EAP 등 Red Hat 상용 제품명이 단 한 건도 명시되지 않음
  • ETL 도구 고정: Informatica PowerCenter가 기존 운영 도구로 명시되어 있어 Red Hat 연계 솔루션 제안 여지 없음
  • 중소기업 제한 입찰: 20억 미만 사업으로 중소기업자만 입찰 참가 가능 (Red Hat 직접 참여 구조적 제한)
Red Hat 제안
가능 요소
  • Linux 서버 운영 환경: 기술 적용 계획표(붙임 10)에서 서버용 개방형 운영체제로 Linux가 명시되어 있으나, 특정 배포판(RHEL 등)은 미지정. 기존 시스템 유지관리이므로 신규 제안 가능성 낮음
  • Unix Shell Script 사용 환경: Unix/Linux 기반 환경에서의 스크립트 운영이 확인되나, 이는 기존 운영 환경의 유지 수준에 해당
  • JAVA 기반 웹 애플리케이션: JAVA, JSP 기반 개발 환경으로 이론적으로 JBoss EAP 제안 여지가 있으나, 기존 WAS 교체가 포함된 사업이 아니므로 실질적 기회 없음
  • RFP 내 Red Hat 제품명 명시 없음: RHEL, OCP, Ansible, JBoss EAP 등 Red Hat 상용 제품·동의어가 RFP 전문에 전혀 기재되지 않음
  • 종합 의견: 기존 운영 중인 시스템의 순수 유지관리 용역으로, 신규 S/W 도입 기회가 없으며 Red Hat 제품 제안 가능성이 매우 낮음
