Red Hat 제안
불가능 요소
  • 신규 S/W 납품 없음: 본 사업은 기존 시스템에 대한 유지관리·운영 용역 사업으로, 신규 Red Hat 제품 도입·납품이 확정된 품목은 별도로 명시되어 있지 않음
  • 중소기업 참여 제한 사업: 20억원 미만 사업으로 대기업·중견기업 입찰 참여 제한 → Red Hat이 직접 입찰 불가, SI/통합사업자를 통한 간접 영업 필요
  • 경쟁 제품 공존: DBMS로 TIBERO Enterprise(바다넷), CUBRID(홈페이지) 등 경쟁 DB 사용 중이며, WAS로 Tomcat 8.5도 일부 사용 (홈페이지)
  • RHEL 버전 노후화: 현재 운영 중인 RHEL 7.8은 2024년 6월 EOM(End of Maintenance) 도달 → 신규 제안보다 버전 업그레이드·구독 갱신 관점의 접근 필요
  • 상용SW 유지관리 품목 고정: 유지관리 대상 SW 목록(별표7)이 이미 고정되어 있어 신규 Red Hat 상용 제품 추가 제안이 어려운 구조
Red Hat 제안
가능 요소
  • [RFP 명시 Red Hat 상용 제품 - 높음 판정 근거]
    • Redhat Enterprise Linux(RHEL) 7.8: 업무포털(바다넷) 시스템 OS로 명시 (별표7 바다넷 S/W 현황)
    • Redhat Enterprise Linux(RHEL) 7.8: 홈페이지 시스템 OS로 명시 (별표7 홈페이지 S/W 현황)
    • JBoss EAP Server 7.3: 업무포털(바다넷) WAS로 명시 (별표7 바다넷 S/W 현황)
    • JBoss EAP 7.3: 홈페이지 WAS로 명시 (별표7 홈페이지 S/W 현황)
  • [구독 갱신·업그레이드 기회]
    • RHEL 7.8은 EOM 도달로 Extended Life Cycle Support(ELS) 또는 RHEL 8/9 업그레이드 구독 갱신 제안 가능
    • JBoss EAP 7.3 → 최신 버전(JBoss EAP 8.x) 업그레이드 제안 가능
    • RFP 내 "상용SW 패치, 버전 업그레이드 등이 필요한 경우 상용SW 제조사 및 발주기관과 협의 후 계약 범위 내에서 실시" 조항 → 구독 갱신·확장 기회 존재
  • [추가 제안 가능 영역]
    • 국가정보자원관리원 B-S존 → S2존 이관 예정('27~'28년) 시 인프라 환경 변화에 따른 RHEL/JBoss EAP 재설치·재구성 지원 기회
    • 현행 RHEL 7.8 운영 환경에서 성능관리 도구(Elevisor) 및 응용프로그램 연동 지원 과정에서 Red Hat 기술지원 참여 가능
    • MAR-001 요구사항 中 "운영 환경관리를 위하여 상용 S/W에 대한 모니터링 등 응용프로그램과 관계되는 S/W에 대한 유기적인 연계처리" → Red Hat SW 유지관리 전문업체로 A/S 확약서 제출 참여 가능
