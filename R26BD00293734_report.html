Red Hat 제안
불가능 요소
  • S/W 신규 납품 없음: 본 사업은 순수 유지관리·운영 용역 사업으로, Red Hat 상용 제품(RHEL, OpenShift, Ansible 등)의 신규 도입·납품·증설·구독 갱신이 품목으로 명시되어 있지 않음
  • 경쟁 DBMS 사용 중: 업무포털(바다넷)은 TIBERO Enterprise 5.0 TSC, 홈페이지는 CUBRID 10.2를 DBMS로 운영 중 (Oracle/Red Hat 무관)
  • WAS 환경 혼용: 홈페이지 WAS로 JBoss EAP 7.3과 함께 Tomcat 8.5가 혼용되어 있어 JBoss EAP 단독 도입 확장 여지 제한적
  • 중소기업 전용 사업: 20억 미만 사업으로 대기업·중견기업 입찰참여 제한, Red Hat이 직접 참여 불가 (파트너사를 통한 간접 영향에 그침)
  • 라이선스 추가 발주 없음: RFP 내 RHEL, JBoss EAP 등 기존 운영 중인 Red Hat 상용 제품이 현행 시스템 SW로 기재되어 있으나, 구독 갱신·증설 품목으로는 명시되어 있지 않음
Red Hat 제안
가능 요소
  • [기존 Red Hat 상용 제품 운영 환경 확인 - 중간 판정 근거]
    • RHEL(Red Hat Enterprise Linux) 7.8: 업무포털(바다넷) 및 홈페이지 시스템 모두 OS로 Redhat Enterprise Linux 7.8을 현재 운영 중 (별표7 시스템 현황에 명시)
    • JBoss EAP(JBoss EAP Server) 7.3: 업무포털(바다넷) WAS로 Jboss EAP Server 7.3 운영 중 / 홈페이지 WAS로 JBoss EAP 7.3 운영 중 (별표7 시스템 현황에 명시)
  • [업셀·갱신 기회]
    • RHEL 7.8은 2023년 6월 ELS(Extended Life Cycle Support) 단계 진입 예정이며, 현재 유지보수 위험 상태 → RHEL 8 또는 RHEL 9로의 업그레이드 필요성 어필 가능
    • JBoss EAP 7.3도 구버전으로 EAP 7.4 또는 EAP 8로의 업그레이드 제안 가능
    • 국가정보자원관리원 B-S존 → S2존 이관 예정 사업에서 OS 재설치 및 구독 갱신 기회 발생 가능
  • [Red Hat 스택 제안 여지]
    • 성능관리 솔루션(Elevisor for J2EE Enterprise) 다수 운영 중 → Red Hat Insights, Satellite 등 대체·보완 제안 여지
    • 국가정보자원관리원 클라우드 자원 사용 환경에서 컨테이너·자동화(Ansible, OpenShift) 제안 여지 존재
    • 보안취약점 관리, 패치 관리 요구사항 → Red Hat Satellite 또는 Ansible Automation Platform(AAP) 활용 제안 가능
  • [RFP 내 Red Hat 제품명 명시 현황]
    • 업무포털(바다넷) OS: Redhat Enterprise Linux 7.8 (별표7)
    • 업무포털(바다넷) WAS: Jboss EAP Server 7.3 (별표7)
    • 홈페이지 OS: Redhat Enterprise Linux 7.8 (별표7)
    • 홈페이지 WAS: JBoss EAP 7.3 / Tomcat 8.5 (별표7)
