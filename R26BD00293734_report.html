Red Hat 제안
불가능 요소
  • 본 사업은 시스템 유지관리·운영 용역이 주목적으로, 신규 S/W 구독 라이선스 직접 구매·납품 항목은 별도 명시되지 않음
  • 기존 도입된 RHEL 7.8, JBoss EAP 7.3은 유지관리 대상으로, Red Hat 입장에서는 신규 구독 판매보다는 기존 구독의 갱신·유지 형태로 접근해야 함
  • RHEL 7.8은 EOS(Extended Life Cycle 단계) 버전으로 버전 업그레이드 필요성이 있으나, RFP에 버전 업그레이드 항목이 명시되어 있지 않음
  • 경쟁 제품(Ubuntu, Rocky Linux, Oracle Linux, VMware 등)은 RFP에 명시되지 않음
  • 본 사업은 20억원 미만 중소SW사업자 참여 사업으로 대기업·중견기업 입찰 참여가 제한되며, Red Hat이 직접 입찰하기 어려운 구조임 (SI·통합사업자를 통한 납품 형태)
  • WAS로 Tomcat 8.5도 일부 사용 중으로 JBoss EAP 단독 환경이 아님
Red Hat 제안
가능 요소
  • [RFP 명시 Red Hat 상용 제품]
  • RHEL(Redhat Enterprise Linux) 7.8: 업무포털 바다넷 시스템 OS 및 홈페이지 시스템 OS로 명시 도입 운영 중 (별표7 시스템 현황)
  • JBoss EAP Server 7.3: 업무포털 바다넷 WAS로 명시 / JBoss EAP 7.3: 홈페이지 WAS로 명시 (별표7 시스템 현황)
  • [제안 가능 포인트]
  • RHEL 버전 업그레이드 제안: 현재 RHEL 7.8은 ELS(Extended Life Cycle Support) 구간으로, 2027~2028년 사업 기간 중 RHEL 8 또는 RHEL 9로 업그레이드 필요성 존재. 인프라 환경 변화 시 패치·버전 업그레이드를 요구사항(MAR-001)에 명시하고 있어 구독 갱신·업그레이드 제안 가능
  • JBoss EAP 구독 갱신 및 버전 업그레이드 제안: JBoss EAP 7.3도 지원 종료 주기에 따른 EAP 7.4 또는 EAP 8.x 업그레이드 제안 기회 존재
  • 국가정보자원관리원 B-S존→S2존 이관 대응: AP 이관 시 OS·WAS 환경 재구성 필요로 RHEL, JBoss EAP 신규 구독 편입 가능성 있음 (MAR-003 명시)
  • SI 파트너 영업 접근: 본 사업의 낙찰 사업자(중소 SW사업자)가 기존 RHEL·JBoss EAP 구독을 유지하거나 갱신하도록 Red Hat 파트너 채널을 통한 간접 영업 활동 가능
  • Ansible Automation Platform 제안 여지: 다수 서버(WEB/WAS/DB) 운영관리, 패치, 모니터링 자동화 수요가 있어 Ansible 자동화 플랫폼 제안 가능 (현재 명시는 없으나 제안 여지 있음)
  • Red Hat Satellite 제안 여지: RHEL 패치 관리 및 버전 현행화 수요에 대응하여 Satellite를 통한 시스템 관리 자동화 제안 검토 가능
