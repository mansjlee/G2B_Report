Red Hat 제안
불가능 요소
  • 신규 S/W 납품 품목 거의 없음: 본 사업은 운영·유지관리 용역 중심으로, 별도 S/W 패키지 구매·납품 항목이 사실상 없음. Wowza Streaming Engine 1EA 추가 도입이 유일한 신규 도입 품목으로, Red Hat 제품 신규 납품 기회는 없음.
  • 경쟁·대체 OS 다수 명시: 현행 시스템 운영환경에 CentOS 7, CentOS 7.9, CentOS 6, Ubuntu 22.04 LTS, Rocky Linux, Windows Server 2019, Solaris 11 등이 명시되어 있음. 모바일의정지원서비스 서버군(API Gateway, WAS, DB, 블록체인 노드, DID 서버, 관리자 서버 등 총 11대)은 전부 Ubuntu 22.04 LTS로 운영 중.
  • GVPN 서버는 Rocky Linux 명시: 클라우드 기반 GVPN 서버 2대가 Rocky Linux로 운영 중이며, RHEL 전환 여지가 불분명함.
  • RFP 내 Red Hat 상용 제품명(RHEL, JBoss EAP, OpenShift 등) 미명시: 상용 S/W 목록 및 운영환경 표 어디에도 RHEL, JBoss EAP, OpenShift, Ansible 등 Red Hat 상용 제품명이 품목으로 기재되지 않음.
  • JBoss 미명시: WAS 환경은 JEUS 6, JEUS 8 Enterprise, Tomcat 7, Apache Tomcat 9, Nginx 등이 사용되며, JBoss/JBoss EAP/WildFly는 전혀 언급되지 않음.
  • 중소기업 제한 입찰: 대기업·중견기업 참여가 제한된 사업으로 Red Hat 코리아가 직접 입찰 불가. SI 파트너를 통한 간접 채널만 가능.
Red Hat 제안
가능 요소
  • 현행 운영환경에 "RedHat" 회사명 기재: 홈페이지 WEB서버 OS 항목에 "RedHat"이, 상용 S/W 목록 홈페이지 OS 항목에 "Linux Redhat OS"가 기재되어 있음. 단, 정확한 제품명(RHEL 버전 등)이 명시되지 않아 판정 규칙상 "중간"에 해당. 해당 서버의 OS가 현재 Red Hat Enterprise Linux일 가능성이 높으며, 구독 갱신·현행화 기회 존재 가능.
  • CentOS → RHEL 전환 기회: 현행 시스템의 대다수 서버(홈페이지 WAS/백업, 회의록 WEB/WAS, 의정포털·의정자료 WEB/WAS/DB/검색/DRM/내부메일/간편인증 서버 등)가 CentOS 7.x로 운영 중. CentOS의 EOL(End-of-Life) 대응 필요성을 근거로 RHEL 전환 제안 가능.
  • Rocky Linux → RHEL 전환 제안 여지: GVPN 서버 2대가 Rocky Linux로 운영 중이며, RHEL로의 전환 또는 RHEL 기반 표준화 제안 가능.
  • Linux 계열 서버 다수 운영: 사업 범위 내 Linux 기반 서버가 20대 이상으로, 중장기적으로 RHEL 표준화, Ansible 기반 자동화 운영, Satellite를 통한 패치·라이선스 관리 등 Red Hat 솔루션 제안 여지 존재.
  • 모바일·클라우드 운영 고도화 기회: Ubuntu 기반 클라우드 서버 11대(모바일의정지원서비스)에 대한 컨테이너(Docker) 기반 운영 중으로, 향후 OpenShift 또는 RHEL 기반 전환 제안 가능성 있음(단, 현재는 확정된 품목 없음).
  • RFP에 명시된 Red Hat(동의어 포함) 제품명·수량:
    • "RedHat" (회사명) - 홈페이지 WEB서버 OS 항목: 1식 (정확한 제품명·버전 불명)
    • "Linux Redhat OS" - 상용 S/W 목록 홈페이지 OS 항목: 1식 (정확한 제품명·버전 불명)
    • ※ 상기 2건 모두 회사명/일반 문구 수준으로 기재되어 있으며, 정확한 Red Hat 상용 제품명(RHEL 등)은 미명시
  • 파트너 영업 접근 전략: 본 사업의 수행사(SI 파트너)를 통해 CentOS 서버의 RHEL 마이그레이션 필요성을 사전 제안하거나, 차기 인프라 교체·재구축 사업 연계 기회를 모색하는 것이 현실적인 접근 방법.
