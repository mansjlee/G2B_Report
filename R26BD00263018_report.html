불가능 요소
  • Red Hat 상용 제품 전무: RFP 전체에 RHEL, OpenShift, Ansible, JBoss/EAP, Satellite 등 Red Hat 상용 제품명이 단 한 건도 명시되지 않음
  • 주요 구매 S/W가 Red Hat과 무관: 핵심 구매품목이 SOLIDWORKS(Dassault Systèmes)와 NVIDIA GPU 서버(HW)로 Red Hat 솔루션과 직접 연관 없음
  • 오픈소스 LLM 방향 고정: AI 인프라 구축을 Gemma, Meta Llama, Qwen 등 오픈소스 모델 + vLLM 서빙으로 명시하여 Red Hat AI/RHEL AI Accelerator 등 상용 제품 진입 여지가 제한적
  • 소프트웨어 개발 용역 중심: 사업의 핵심은 플랫폼 고도화 개발 용역이며, Red Hat이 직접 납품하는 구독형 상용 SW 품목이 명시되어 있지 않음
  • 중소기업 대상 제한: 사업금액 9억원으로 대기업 및 중견기업 SW 사업자 참여 제한 — Red Hat이 SI 사업자로 직접 입찰 불가 (파트너 경유 필요)
  • 오픈소스 라이선스 관리 기준 명시: GPL, AGPL 등 강한 카피레프트 오픈소스 사용 시 발주자 사전 동의 필요 — 오픈소스 활용 방향은 명확하나 Red Hat 상용 제품 전환 유도는 어려운 구조
Red Hat 제안
가능 요소
  • GPU 서버 OS 미지정 → RHEL 제안 가능: GPU 서버(1대) 및 질병 솔버 플랫폼 서버의 운영체제(OS)가 RFP에 명시되어 있지 않아, RHEL을 온프레미스 AI 서버 OS로 제안할 수 있는 여지가 존재
  • vLLM 온프레미스 서빙 환경 → RHEL/OpenShift AI 제안여지: vLLM 기반 모델 서빙, OpenAI 호환 API 구성은 RHEL 기반 컨테이너 환경 또는 OpenShift AI(RHOAI) 플랫폼과 기술적으로 연계 가능한 아키텍처이며, 안정성·보안 측면에서 RHEL 강점 제안 가능
  • 폐쇄망 온프레미스 보안 요구 → RHEL 보안 강점 부각 가능: 임상 데이터 보안(SER-002)을 위해 외부망 차단 폐쇄망 운영이 필수로, RHEL의 SELinux·보안인증(CC EAL4+) 및 Red Hat Insights 등 엔터프라이즈 보안 기능을 차별화 포인트로 제안 가능
  • RFP에 명시된 Red Hat(또는 동의어) 제품명·수량: 없음 (RHEL, OpenShift, Ansible, JBoss 등 어떠한 Red Hat 상용 제품도 RFP에 명시되어 있지 않음)
