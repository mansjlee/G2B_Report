Red Hat 제안
불가능 요소
  • Red Hat 상용 제품 미명시: RFP 및 과업지시서 전체에 걸쳐 RHEL, OpenShift, Ansible, JBoss EAP 등 Red Hat 상용 제품명이 단 한 건도 명시되지 않음
  • S/W 구매는 AhnLab 백신 위주: 통합발주 S/W는 AhnLab V3 계열 백신 라이선스 갱신(총 149개)과 Lustre/스토리지 관련 소프트웨어로 한정되어 있어 Red Hat SW 납품 기회 없음
  • 유지보수 용역 중심 사업: 기존 장비의 유지관리·운영이 주목적이며 신규 OS·플랫폼 도입 항목이 없어 RHEL 신규 구독 제안 공간이 사실상 없음
  • HPE 중심 HW 환경: HPE 공인파트너 인증서 제출이 필수 요건으로, 특정 제조사 중심의 기존 환경을 유지하는 방향으로 구성되어 있음
  • 소규모 입찰 제한: 20억 원 미만 사업으로 중소기업 전용 입찰이며, 대기업·중견기업 SW사업자는 입찰 참여 자체가 제한됨
Red Hat 제안
가능 요소
  • Linux 서버 환경 운영 중: AhnLab V3 Net for Linux Server 라이선스 갱신(54개)이 명시되어 있어 상당수 서버가 Linux 기반으로 운영 중임을 간접 확인 가능 → 해당 서버 OS가 RHEL인 경우 갱신 기회 존재하나 RFP에 명시 없음
  • Pacemaker 클러스터 구성 기술 요구: MAR-007에서 pacemaker 클러스터 구성 및 기술 제공을 요구하고 있으며, Pacemaker는 RHEL High Availability Add-On의 핵심 구성요소로 Red Hat 기술 스택 친화적 환경임
  • OS 명시 없음: Linux 서버 운영이 확인되나 특정 OS(RHEL, CentOS, Ubuntu 등)가 명시되지 않아 기술 제안 시 RHEL 언급 여지는 이론적으로 존재
  • 단, 판단: 위 요소들은 제안 가능성을 뒷받침하기에 미약함. 이 사업은 기존 운영환경의 유지보수가 목적이며 신규 SW 도입 항목이 없으므로 실질적인 Red Hat 영업 기회로 보기 어려움
