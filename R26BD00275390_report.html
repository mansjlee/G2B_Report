사업 개요 및 목적
  • 한국의약품안전관리원이 운영하는 의약품통합정보시스템(의약품안전나라, 정보공동활용포털, 행정서비스포털, 협업시스템 등), 위기대응의료제품정보시스템, 장기추적조사시스템, e-IRB시스템 등 정보시스템의 안정적 운영·유지관리를 위한 전문 용역 사업
  • 응용시스템(개발 SW) 및 상용 소프트웨어 유지관리, 장애 예방·복구, 기능 개선, 보안 관리, 사용자 지원 등을 포괄하는 종합 IT 유지보수 사업
  • 다량의 민감 의약품 정보를 취급하는 국가 공공 정보시스템의 서비스 안전성·신뢰성 확보 목적

Red Hat 제안
불가능 요소
  • Red Hat 상용 제품 전무: RFP 전체 문서에 RHEL, OpenShift, Ansible, JBoss EAP, Satellite 등 Red Hat 상용 제품명이 단 한 건도 명시되어 있지 않음
  • 기존 시스템 유지보수 중심: 신규 인프라 구축·OS 도입 항목이 없는 순수 유지보수 용역으로, OS 교체 또는 신규 플랫폼 도입 기회 없음
  • SW 구매 항목 모두 비-RH 제품: 라이선스 갱신 대상 상용 SW(ECM, DB암호화, 검색엔진, PDF변환, UI Tool, 통계SW 등) 전체가 Red Hat과 무관한 제품으로 고정되어 있음
  • DBMS Oracle 고정: 전체 시스템의 DBMS가 Oracle로 명시되어 있어 Red Hat 기반 데이터 플랫폼 제안 여지 없음
  • 미들웨어 요구 없음: JBoss EAP 등 WAS/미들웨어 교체·도입 관련 요구사항이 전혀 없으며, 개발 언어는 Java이나 WAS 제품 지정 없이 기존 환경 유지
  • 중소기업 참여 제한 사업: 소프트웨어진흥법에 따라 대기업 참여 불가 사업으로, Red Hat 코리아 직접 입찰 불가 (SI/유지보수 전문 중소기업이 대상)
Red Hat 제안
가능 요소
  • Linux OS 기반 운영 환경 (배포판 미명시): 유지보수 대상 전 시스템(의약품안전나라, 행정서비스포털, 정보공동활용포털, 협업시스템, 위기대응의료제품정보시스템, 장기추적조사시스템, 규제과학행정포털, eIRB 등)의 OS가 모두 "Linux"로 기재되어 있으며 특정 배포판이 명시되지 않음. 다만 이는 기존 운영 환경 설명으로 신규 OS 도입 기회는 아님
  • Java 개발 환경: 전 시스템이 Java 기반으로 개발되어 있어 이론적으로 JBoss EAP 제안 여지가 있으나, RFP에 WAS 교체·도입 항목이 명시되어 있지 않음
  • RFP에 명시된 Red Hat 제품명·수량: 없음 (Red Hat 관련 제품이 단 한 건도 언급되지 않음)
  • 종합 평가: Linux 환경이 기반이나, 이 사업은 신규 도입이 아닌 기존 시스템 유지보수 성격이 강하며 SW 구매 목록도 모두 비-RH 제품으로 고정되어 있어 실질적인 Red Hat 제안 기회는 극히 제한적임. 향후 차기 인프라 고도화·전환 사업 시 관계 구축 목적의 파트너사 영업 지원 관점으로 접근 권장
