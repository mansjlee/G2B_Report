Red Hat 제안
불가능 요소
  • 신규 Red Hat 상용 제품 구매 품목 없음: 통합발주 구매 품목은 CCTV 비식별화 시스템 1식뿐이며, 직접구매 해당없음으로 Red Hat 상용 SW 납품 품목이 RFP에 명시되지 않음
  • 경쟁 OS 혼용: 현행 운영 서버의 OS가 "Ubuntu, Red Hat" 혼용으로 명시되어 있어 Ubuntu가 기존 운영 환경의 절반을 차지하는 경쟁 OS임
  • 순수 운영·유지관리 중심 사업: 사업 성격상 신규 SW 도입보다는 기존 시스템 운영·유지관리 및 데이터 수급이 주 과업으로, SW 구독 신규 계약 발생 가능성이 낮음
  • 사업비 규모 제한: 총 사업비 6.52억원으로 소규모이며 대부분이 데이터 수급 비용(통신사·카드사), 인건비(10.68 M/M), 클라우드 운영비 등으로 구성되어 SW 구매 예산이 제한적
Red Hat 제안
가능 요소
  • 현행 시스템에 Red Hat OS 사용 중: RFP 시스템 현황에 "OS (Ubuntu, Red Hat)"이 명시되어 있어 현재 운영 서버(6식) 중 일부에 Red Hat Enterprise Linux가 사용 중임. 운영·유지관리 과업 수행자로서 RHEL 구독 갱신 또는 유지 제안 가능
  • AI·LLM·MCP 서버 운영 환경: 신규 도입되는 LLM 운영서버 1식 및 MCP 운영서버 1식(외부 클라우드)에 RHEL 기반 OS 또는 OpenShift AI 플랫폼 제안 여지 있음
  • Linux 계열 서버 운영 지속: 미들웨어(Tomcat), Java(JDK11), DB(PostgreSQL) 스택이 Linux 환경에서 운영 중이므로 RHEL 기반 안정적 운영환경 제안 가능
  • Ansible 자동화 제안 여지: 다수의 운영 서버(6식+클라우드 서버) 관리, 데이터 수집 자동화, CCTV 연계 작업 등에 Ansible Automation Platform 도입 제안 가능
  • RFP 명시 Red Hat 제품명·수량: 시스템 현황에 "Red Hat" (OS, 수량 미명시) — 구매 품목으로 확정 명시는 없으나 현행 인프라 구성요소로 언급됨
