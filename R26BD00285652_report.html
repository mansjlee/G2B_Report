관세청_모리셔스 전자통관시스템(RM, DW) 구축 사업 - 분석 리포트

레드햇 제안 가능성 중간
오픈소스 우선·Linux OS 미지정
사업 개요 및 목적
  • 한국 관세청이 발주하는 ODA(공적개발원조) 해외원조사업으로, 모리셔스(Mauritius) 관세청의 전자통관시스템 중 위험관리시스템(RM: Risk Management) 및 데이터웨어하우스(DW: Data Warehouse) 구축을 지원하는 사업
  • BPR/ISP 수립, 원산지관리시스템(OOMS) 및 FTA 포털(FTA-PASS, FTA심사) 개발, ICT 기자재 공급, 역량강화(초청연수·현지교육)를 포함하는 통합형 정보화 사업
  • 모리셔스의 무역환경 개선, 통관 소요시간 및 비용 절감, 관세 세수 달성률 향상을 통해 국가 경쟁력 강화 및 경제성장에 기여하는 것이 목표
  • 한국 관세청의 기존 시스템인 'FTA Pass', 전자통관시스템 'UNIPASS'의 FTA 모듈을 기반으로 수원국 맞춤형 시스템을 구축하고 기술이전 수행
  • 감리용역은 별도 선정하여 추진하며, AI 기반 Auto MLOps 체계 및 자연어 질의 기반 통계 조회 기능도 요구

Red Hat 제안
불가능 요소
  • Red Hat 상용 제품명 미명시: RFP 전문 및 S/W 구매 목록에 RHEL, OpenShift, Ansible, JBoss EAP 등 Red Hat 상용 제품이 전혀 명시되지 않아 '높음' 판정 근거 없음
  • S/W 목록 미확정: 통합발주 S/W 목록이 공란으로, 현 단계에서 Red Hat 제품 포함 여부 확인 불가
  • ODA 해외 구축 사업 특성: 수원국(모리셔스) 현지 환경 기준 우선 적용 (기술적용계획표에 IaaS·SaaS 항목에 "대상국 인프라 사용" 명시), Red Hat 제품 도입이 현지 조달 및 예산 조건에 따라 제한될 수 있음
  • 경쟁·대체 제품 확정 사례 없음: Ubuntu, Rocky Linux, VMware 등 경쟁 제품도 명시되지 않아 대체 불가 상황은 아니나, 명확한 Red Hat 도입 근거도 부재
  • SI 통합사업자 납품 구조: PMC 선정 통합사업자가 S/W 선택권을 갖는 구조이며, Red Hat이 직접 입찰 참여가 어려운 간접 납품 형태
Red Hat 제안
가능 요소
  • 오픈소스 SW 우선 검토 원칙 (COR-005): "공개 SW 사용이 적절한 분야는 공개 SW 사용을 권장"하여 RHEL(구독형 엔터프라이즈 리눅스), OpenShift 등을 적극 제안 가능
  • Linux OS 미지정 및 지원 명시: 기술적용계획표에 운영체제로 UNIX, Windows Server, Linux 모두 지원으로 기재되어 있어 RHEL 제안 여지 명확; 특정 OS로 확정되지 않음
  • HCI 서버·가상화 인프라: HCI 솔루션(Gold/EPYC CPU) 기반 가상화 환경 구축 요구 → RHEL 기반 운영체제 및 가상화 플랫폼 제안 가능 (RHEV/RHV 또는 OpenShift Virtualization)
  • Java WAS 환경: Java 기반 전자정부 프레임워크 및 Web/WAS 계층(Active-Active 고가용성) 구성 요구 → JBoss EAP(Enterprise Application Platform) 제안 가능
  • AI/MLOps 자동화 체계: Auto MLOps(데이터 준비→학습→평가→배포→재학습 자동화) 구축 요구 → OpenShift AI 및 OpenShift Container Platform 제안 여지
  • 컨테이너·마이크로서비스 아키텍처: 대용량 데이터 실시간 처리, 시스템 확장성 요구, 컴포넌트 기반 개발 원칙 → OpenShift(OCP) 제안 가능
  • 자동화 및 형상관리: 소스코드 변경 영향 범위 자동 분석, CI/CD 파이프라인, 인프라 자동화 요구 → Ansible Automation Platform(AAP) 제안 여지
  • RFP에 나온 Red Hat(또는 동의어) 제품명·수량: 없음 (문서 전체에 Red Hat 상용 제품명 미등장)
