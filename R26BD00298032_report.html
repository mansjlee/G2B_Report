Red Hat 제안
불가능 요소
  • Red Hat 상용 제품명 미명시: 별첨2 상용SW 목록 및 라이선스 갱신 목록 어디에도 RHEL, OpenShift, JBoss EAP, Ansible 등 Red Hat 상용 제품명이 직접 기재되어 있지 않음
  • 경쟁 제품 명시: VMware vSphere (가상화 도구, '15년 도입)가 상용SW 유지관리 대상으로 명시되어 있음. 가상화 인프라는 VMware 기반으로 운영 중
  • Microsoft OS 명시: Windows Server 2016 (2개), Windows Server 2022 (14개)가 서버용 OS로 명시되어 있음
  • 순수 유지관리 용역 성격: 본 사업은 신규 S/W 도입·납품·구독 발주가 아닌 기존 도입 장비 및 소프트웨어에 대한 운영·유지관리 용역임. 별도의 Red Hat 상용 S/W 신규 구매 품목은 보이지 않음
  • 서버 OS 현황 불명확: 서버 108대 중 운영 OS가 별도 명시되지 않아 Linux 서버의 배포판(RHEL, CentOS, Rocky 등) 확인 불가. 단, 라이선스 갱신 목록에 "V3 for Linux SVR (리눅스 서버용 백신)"이 포함되어 있어 Linux 서버가 운영 중임은 확인되나 배포판 종류는 미확인
  • 대기업 참여 제한: 사업금액 40억원 미만으로 대기업 참여 불가 (중소·중견기업만 가능). Red Hat Korea가 직접 입찰 불가능하며, 파트너사를 통한 간접 참여만 가능
  • JBoss/WildFly 미명시: WAS 관련 소프트웨어(JBoss, WildFly 등) 도입·운영 항목이 전혀 없음
Red Hat 제안
가능 요소
  • Linux 서버 운영 중: 라이선스 갱신 목록에 "V3 for Linux SVR(리눅스) 서버용 백신(인터넷망) 10개"가 포함되어 있어 Linux 서버가 운영 중임을 확인 가능. 해당 Linux 서버의 OS가 RHEL일 가능성 존재 (배포판 불명확하므로 최대 중간 판정)
  • 대규모 서버 인프라: 서버 108대, VDI 서버(유니와이드 RD228-P3 20대 등) 운영 중. VDI 환경 및 서버 인프라에 RHEL 적용 여지가 있으며, 향후 OS 전환·증설 시 제안 가능
  • 상용SW 유지관리 담당자 접근 기회: 본 사업의 수주 업체가 상용SW 운영·유지관리를 담당하므로, 현행 OS·미들웨어 환경 파악 및 향후 RHEL/Ansible 제안을 위한 고객 접점 확보 가능
  • 자동화·운영 효율화 필요성: 서버 108대, 네트워크 686대, 보안장비 52대, OA기기 12,822대 등 대규모 인프라 운영. 이 규모의 인프라 관리에 Ansible Automation Platform을 활용한 자동화 제안 가능성 존재
  • RFP 내 Red Hat 관련 직접 명시 제품 없음: 본 RFP 및 별첨 목록 전체에서 RHEL, OpenShift, JBoss EAP, Ansible, Satellite 등 Red Hat 상용 제품명은 발견되지 않음
  • 파트너사 연계 간접 참여: 직접 입찰은 불가하나, 본 사업 수주 SI 업체에 대한 RHEL 구독 갱신, OS 현황 파악 후 차기 사업에서의 전환 제안 등을 위한 파트너사와의 협력 기회로 활용 가능
