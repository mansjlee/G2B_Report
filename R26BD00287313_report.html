사업 개요 및 목적

  • 모델의 기능 오류 수정, 성능 개선, 모의 논리 수정 등을 통해 합동작전 모의분석의 효과성 및 효율성을 증대하고, 사용자 만족도를 향상시키는 것이 핵심 목표
  • 작전계획 수립, 방책 분석, 소요 분석, 연합/합동 연습 지원 등 실전적 모의분석 능력 유지 및 발전

Red Hat 제안
불가능 요소
  • 순수 용역 사업으로 신규 S/W 납품·구독 항목 없음: 본 사업은 기존 모의분석모델(JOAM-K II, K-COSAGE)에 대한 유지관리·기능개선 용역으로, 신규 상용 SW 도입·납품·구독이 포함되지 않음
  • 기존 운용 환경이 Windows/Oracle 기반: JOAM-K II 및 K-COSAGE 모두 Windows OS(Windows 11, Windows Server Standard), Oracle Database를 기반으로 운영되고 있어 Red Hat 제품 개입 여지가 없음
  • Red Hat 상용 제품명 전혀 미언급: RFP 전체에 걸쳐 RHEL, OpenShift, Ansible, JBoss 등 Red Hat 상용 제품명이 단 한 건도 명시되지 않음
  • Linux/컨테이너/쿠버네티스 관련 기술 요구사항 없음: 모든 기술 요구사항이 Windows 기반 응용SW 유지관리, C++ 계열 시뮬레이션 로직 개선에 집중되어 있음
  • 국방 특수 환경: 합참 폐쇄망 환경 운용, 보안 제약으로 인해 외부 플랫폼 전환 가능성 매우 낮음
Red Hat 제안
가능 요소
  • RFP 내 Red Hat 상용 제품 명시 없음: RHEL, OpenShift, Ansible, JBoss EAP 등 Red Hat 상용 제품이 구매 품목으로 명시된 사항 없음
  • 신기술 적용 가능성 검토 언급: RFP에 "모델 진부화 방지를 위한 신기술 적용 가능성 검토"가 추진목표로 언급되어 있으나, 구체적인 기술 방향이 명시되지 않아 Red Hat 솔루션과의 연계 가능성은 극히 낮음
  • 실질적 제안 가능 요소 없음: 기존 Windows/Oracle 기반 폐쇄망 환경 유지관리 사업으로 RHEL, OpenShift, Ansible 등 Red Hat 스택을 제안할 수 있는 기술적·사업적 접점이 없음
