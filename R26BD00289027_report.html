Red Hat 제안
불가능 요소
  • S/W 납품·구독 항목 없음: RFP 및 자가점검표에 "본 사업은 별도의 상용 SW 구매를 포함하지 않음(SW 직접구매 해당없음)", "상용SW도입 없음"으로 명시됨. Red Hat 상용 제품(RHEL, OCP, JBoss EAP 등) 구독 갱신·납품 기회 없음.
  • WAS(JBoss/JBCS) 유지관리 범위 제외: 국가정보자원관리원 입주 시스템의 OS, WEB, WAS, DBMS는 "유상 유지관리 대상 제외"로 명시되어, JBCS·JBoss가 사용된 시스템(대표홈페이지, 업무포털 등)의 WAS 유지관리는 본 사업 범위 밖임.
  • 순수 유지관리·위탁운영 용역 사업: 기존 구축된 시스템의 운영·유지관리 서비스 용역으로, 소프트웨어 라이선스 납품·구독 항목이 전혀 없는 서비스 사업임.
  • 기존 상용S/W 목록에 Red Hat 제품 미포함: 유지관리 대상 상용S/W 목록(DB보안, DB암호화, PKI, 검색엔진, 문서뷰어 등)에 Red Hat 상용 제품명이 전혀 명시되어 있지 않음.
  • 경쟁 제품 사용 중: 제도개선관리시스템에 JEUS(WAS), Oracle DB(통합DB), IIS(WEB), MS-SQL 등 타 벤더 제품이 명시적으로 사용 중이며, Cubrid(국산 DB)도 사용.
Red Hat 제안
가능 요소
  • 기존 환경에 JBCS·JBoss 사용 중: 대표홈페이지(국문·영문·어린이) 및 내부 업무포털의 WEB 서버로 JBCS(JBoss Core Services), WAS로 JBoss가 현재 운영 중임. 이는 Red Hat 제품군이 해당 기관에 도입되어 있음을 나타내며, 향후 구독 갱신·증설 관련 별도 영업 기회로 연결될 수 있음. (단, 본 사업 범위 외)
  • Linux 서버 환경: 기술적용계획표에 서버용 개방형 운영체제로 Linux 적용이 명시되어 있어, RHEL 제안 가능성이 있는 인프라 환경임. (단, 본 사업에서 OS 구매 없음)
  • 가상화·컨테이너 인프라 SLA 지표 존재: SLA 선택지표에 "VM 가동률", "하이퍼바이저 가동률" 항목이 포함되어 있어 가상화 인프라가 존재함을 시사. OpenShift/RHEV 제안의 배경 환경으로 볼 수 있음. (단, 본 사업에서 구매 없음)
  • 향후 별도 라이선스 갱신 사업 연계 가능: 본 유지관리 사업 수행 중 JBCS·JBoss EAP 구독 만료 시, 별도 구독 갱신 사업 발주 가능성이 있어 관계 관리 차원의 영업 접점으로 활용 가능.
  • RFP 내 Red Hat 제품명 직접 명시 현황: 상용 제품명(RHEL, OCP, JBoss EAP, Ansible 등)은 RFP 본문에 직접 명시되지 않음. "Jboss"(WAS 현황), "JBCS"(WEB 현황)만 현행 시스템 구성표에 기재되어 있으며, 이는 통합발주 품목이 아닌 현행 운영 현황 기재임.
