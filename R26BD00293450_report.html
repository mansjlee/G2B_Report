Red Hat 제안
불가능 요소
  • S/W 신규 납품·구독 항목 없음: 본 사업은 「소프트웨어 진흥법 시행령」 제35조 제2항에 근거한 단순 유지관리·운영 용역으로, 상용 S/W 직접구매(조달쇼핑몰) 또는 통합발주 S/W 납품 항목이 존재하지 않음
  • Red Hat 상용 제품명 미명시: RFP 전문에 RHEL, OpenShift, Ansible, JBoss EAP, Satellite 등 Red Hat 상용 제품명이 단 한 건도 명시되지 않음. 유지관리 대상 상용 S/W 26종의 구체적인 제품명은 비공개(현장 방문 열람)로 처리되어 확인 불가
  • 경쟁 제품 명시 없으나 확인 불가: 특정 경쟁 OS(Ubuntu, Rocky Linux 등)나 VMware 등이 명시되지는 않았으나, 유지관리 대상 상용 S/W 26종 목록이 비공개로 Red Hat 경쟁 제품 포함 여부 불확실
  • 중소기업 제한 입찰: 연간 평균금액 20억 미만 사업으로 대기업·중견기업 참여 불가. Red Hat Korea가 직접 입찰 참여 불가하며 중소 파트너사를 통한 간접 영업 필요
Red Hat 제안
가능 요소
  • 공개 S/W 유지관리 대상 포함: MPR-007에서 공개SW(PostgreSQL DBMS) 4식의 고급 서비스 수준 유지관리가 명시되어 있으며, 전체 공개 S/W 4종이 유지관리 대상에 포함됨. PostgreSQL 외 나머지 공개 S/W의 종류는 비공개이나 Linux/오픈소스 계열 포함 가능성 있음
  • 서버 OS 및 시스템 S/W 유지관리 포함: MPR-002에서 OS 패치, 업그레이드, 최신 버전 관리가 명시되어 있으며, 서버 53대·클러스터 2식 등 대규모 서버 인프라의 OS 운영 환경이 포함됨. 비공개 상용 S/W 26종 중 Linux 계열 OS(RHEL 포함 가능) 운영 여지 있음
  • 가상화 S/W 유지관리 대상 포함: 상용 S/W 26종 중 가상화 3종이 유지관리 대상으로 명시됨. 가상화 솔루션 종류는 비공개이나 RHEV/Red Hat Virtualization 또는 경쟁 제품 가능성 모두 존재
  • WEB/WAS 10종 유지관리 포함: 상용 S/W 26종 중 WEB/WAS 분야 10종이 포함되어 있어 JBoss EAP 등 Red Hat 미들웨어 스택 운영 가능성 있음(비공개로 확인 불가)
  • 현장 방문 열람을 통한 추가 확인 필요: 유지관리 대상 상용 S/W 26종의 세부 목록이 비공개(현장 방문 열람)로 처리되어 있어, 직접 방문 열람 시 Red Hat 상용 제품 포함 여부 확인 가능. 포함 확인 시 판정 높음으로 상향 가능
  • RFP에 명시된 Red Hat 제품명·수량: 없음 (비공개 목록 열람 전 확인 불가)
  • 파트너 영업 기회: 낙찰 예정 중소 IT서비스 업체 대상으로 Red Hat 제품 운영 지원·기술교육·구독 갱신 기회 모색 가능. 사업 수행업체가 기술지원확약서 제출 시 Red Hat 공인 파트너로서 협력 구도 활용 가능
