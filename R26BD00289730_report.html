Red Hat 제안
불가능 요소
  • S/W 납품 범위 제한: 본 사업은 운영·유지관리 위탁용역이 주목적이며, 신규 상용SW 도입은 예산·일정에 소규모로 편성되어 있고 구체적 품목은 RFP에 명시되지 않음
  • Red Hat 상용 제품명 전무: RFP 전체에 걸쳐 RHEL, OpenShift, Ansible, JBoss, AAP 등 Red Hat 상용 제품명이 단 한 건도 언급되지 않음
  • 홈페이지 서버 스택 고정: 홈페이지 서버는 Apache(오픈소스), Tomcat(오픈소스), MariaDB(오픈소스)로 명시되어 있으며, 이는 Red Hat 상용 제품이 아닌 커뮤니티/업스트림 SW임
  • 구매 SW가 보안·네트워크 관리 제품 위주: 명시된 SW(NMS, 망연계솔루션, 유해사이트차단)는 Red Hat 포트폴리오와 무관한 제품군임
  • 서버 OS 미지정이나 제안 여지 낮음: 시스템 상세 현황은 보안상 비공개(방문 열람만 가능)이며, 기존 운영 중인 시스템의 OS 교체·전환은 유지관리 사업의 범위를 벗어남
  • 중소기업 제한 입찰: 20억 미만 사업으로 대기업·중견기업 참여 제한, Red Hat이 직접 입찰 불가 구조
Red Hat 제안
가능 요소
  • 상용SW 신규 구입 일정 존재: 추진일정상 매년 "상용SW·노후 전산장비 구입" 항목이 포함되어 있어, 방문 열람 후 구체적인 SW 품목 확인 시 Red Hat 제품 제안 기회가 존재할 수 있음
  • 서버 OS 미지정 구간: 행정정보시스템 서버(HW 400식 규모)의 운영체제가 RFP에 명시되지 않았으며, 시스템 열람 후 RHEL 제안 가능성 탐색 여지 있음
  • 정보보안 강조 환경: 보안취약점 점검, 정보보호시스템 운영(방화벽·IPS·WAF·NAC 등) 등 보안 요구사항이 강하여 Ansible Automation Platform(자동화 패치·컴플라이언스 관리) 및 Red Hat Satellite(OS 패치 자동화) 제안 여지가 이론적으로 존재
  • RFP 내 Red Hat(또는 동의어) 제품 명시: 없음 (0건) — 제안 가능 요소로 작용하는 명시적 RH 품목 없음
  • 종합 판단: 현재 RFP만으로는 Red Hat 상용 제품의 제안 근거가 전무하므로, 사업 수주 업체 또는 담당자 접촉을 통해 차년도 상용SW 구입 계획 내역 확인이 선행되어야 실질적 영업 기회 여부를 판단할 수 있음
