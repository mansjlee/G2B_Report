불가능 요소
  • 신규 S/W 도입·납품·구독 항목 없음: 본 사업은 기존 장비·소프트웨어 유지보수 용역이며, 신규 Red Hat 제품 구매·납품·구독 갱신 품목이 전혀 명시되어 있지 않음
  • Red Hat 상용 제품명 미기재: RFP 전체(유지보수 대상 S/W 목록 포함)에서 RHEL, OpenShift, Ansible, JBoss EAP 등 Red Hat 상용 제품명이 단 한 건도 명시되지 않음
  • 경쟁·대체 제품 명시: 서버 운영체제로 Windows Server 2019/2022, 서버가상화로 VMware vSphere 6.x/7/8, vCenter가 기존 운영 중 S/W로 명시. 가상화 플랫폼으로 ABLESTACK v4.0(에이블클라우드) 도입 확정. Linux 계열 OS 적용 여지 없음
  • 참여인력 자격증 목록에 경쟁 자격증 명시: 인정 자격증으로 VMware VCP, Linux RHCSA·RHCE 등이 병기되어 있으나, 이는 인력 평가 기준일 뿐 Red Hat 제품 도입 근거 아님
  • 순수 유지보수 용역 사업: 기술적용계획표에 "정보시스템 구축사업이 아님"으로 명시. 플랫폼·인프라 신규 구축 없음
  • 중소기업 전용 입찰: 20억원 미만, 대기업·중견기업 참여 제한으로 Red Hat 직접 입찰 불가
Red Hat 제안
가능 요소
  • RFP 내 Red Hat 상용 제품 명시 없음: 유지보수 대상 S/W 목록 전체에서 RHEL, JBoss EAP, OpenShift, Ansible 등 Red Hat 상용 제품명이 확인되지 않음. 판정 규칙상 "높음" 근거 없음
  • 인력 자격증 목록에 RHCSA·RHCE 언급: 참여인력 인정 자격증 목록에 "Linux RHCSA, RHCE"가 포함되어 있으나, 이는 Red Hat 제품 도입·운영 환경을 의미하지 않으며 단순 자격증 인정 목록임
  • 간접적 Linux 운영 환경 가능성: 서버 운영체제로 Windows Server가 명시되어 있으나, 일부 관제 서버·AI 플랫폼 서버 등에서 Linux 계열 운영 환경이 존재할 가능성은 있음. 단, RFP 내 구체적인 Linux 배포판·제품명 미기재로 제안 근거 불충분
  • 차기 사업 기회: 현재는 유지보수 용역이나, 2027년 이후 노후 시스템 교체·AI CCTV 시스템 확장 등 신규 구축 사업 발생 시 RHEL, Ansible, OpenShift 등 제안 여지 존재. 현재 사업을 통한 고객 관계 형성이 중장기적 기회로 연결 가능
  • 결론: 현재 RFP 기준으로 Red Hat 상용 제품 명시가 전혀 없고 신규 S/W 도입 항목도 없어 즉각적인 제안 기회는 없음. 레드햇 제안 가능성 낮음으로 판정
