Red Hat 제안
불가능 요소
  • Rocky Linux OS 명시 확정: 통합발주 HW 서버 6종(GEO AI 메시지버스·배치·Serving·시각화 서버, 의심축 판독 AI·통합 서버) 전체에 OS를 "Rocky Linux 9.7 이상"으로 명시 → RHEL 대체 가능성 극히 낮음
  • Red Hat 상용 제품명 전무: RFP 전체에 RHEL, OpenShift, Ansible, JBoss EAP 등 Red Hat 상용 제품명이 단 한 곳도 언급되지 않음
  • 오픈소스 SW 스택 명시: GEO AI 솔루션 구성에 nginx, tomcat, PostgreSQL 등 오픈소스 SW가 명시되어 Red Hat 상용 미들웨어(JBoss EAP 등) 제안 여지 없음
  • S/W 납품 규모 미미: 사업 구조가 HW 도입 및 AI 개발용역 중심이며, 별도 상용 SW 통합발주 품목이 사실상 없음
  • 경쟁 OS 확정: Rocky Linux는 CentOS 계열의 무료 커뮤니티 OS로, RHEL 도입 없이 해당 OS로 사업이 확정될 경우 Red Hat 라이선스 수익 기회 없음

가능 요소
  • 인공지능 판독 GPU 서버 1식 OS 미지정: "표준 OS 제공"으로만 명시되어 있어 이론적으로 RHEL 제안이 가능하나, 나머지 서버가 모두 Rocky Linux로 지정된 점을 고려하면 실질적 가능성은 매우 낮음
  • 컨테이너·MSA 아키텍처 구조: GEO AI 솔루션이 MSA 기반 컨테이너 가상화 구조를 채택하고 있어, 향후 확장·유지관리 시 OpenShift 또는 Ansible 제안 여지가 이론적으로 존재하나 현재 RFP 상 Red Hat 상용 제품명 없음
  • RFP 내 Red Hat(또는 동의어) 제품명·수량: 해당 없음 (전무)
  • 종합 판단: Rocky Linux OS가 서버 전반에 명시 확정된 상황으로, 판정 규칙상 낮음에 해당. 윈백(CentOS→RHEL 전환) 관점의 어프로치도 Rocky Linux가 이미 차기 OS로 지정된 만큼 설득력 확보 어려움
