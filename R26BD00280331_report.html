사업 개요 및 목적
  • 연세대학교 구성원(학생·교수·직원)의 학습·연구·행정 목적을 위한 멀티LLM 기반 생성형 AI 플랫폼 구축 및 운영
  • 다양한 상용 LLM 모델(ChatGPT, Gemini 등 유사 UX)을 단일 플랫폼에서 통합 제공하여 사용자가 용도에 따라 선택·활용할 수 있는 환경 조성
  • 크레딧 기반 사용 관리, 멀티LLM 응답 비교, RAG 문서검색, 챗봇 스토어, Deep Research, AI 프레젠테이션·회의록 자동 생성 등 종합 AI 서비스 제공
  • 본교 SSO 환경 연동 및 개인정보 보호(차단·마스킹)를 통한 안전한 AI 활용 환경 구현
  • KISA(한국인터넷진흥원) 인증 및 CSAP(클라우드 보안 인증) 획득 클라우드 기반으로 구축
주요 정보
  • 사업 예산: RFP 내 예산 총액 미명시. 사업비 산출내역서(플랫폼 사용료·SSO 연동 구축비·크레딧 비용 등 항목 포함) 별도 제출 방식. 입찰공고문 참조 필요
  • 사업 기간: 계약일 ~ 2028년 2월 29일 / ① 구축 및 시범 서비스: 계약일로부터 1개월 이내 완료 / ② 서비스 운영 및 무상 유지보수: 구축 시범 서비스 종료일 ~ 2028년 2월 29일
  • 사업 범위: CSAP 인증 클라우드 기반 멀티LLM 플랫폼 구축·운영 (생성형 AI 플랫폼, 멀티LLM 채팅·챗봇, 이미지/영상 생성, RAG 문서검색, Deep Research, AI 프레젠테이션·회의록 생성, SSO 연동, 관리자 페이지, 보안·유지보수 포함). 하도급 및 공동수급 불허, 자사 인력 단독 구성
  • 주요 일정: 입찰공고 → 입찰서·제안서 접수 → 제안서류 심사(기술평가 90% + 가격평가 10%) → 협상 및 계약체결 → 착수보고. 기술평가 85% 이상(76.5점) 획득자를 협상적격자로 선정. 발표 20분, Q&A 10분

Red Hat 제안
불가능 요소
  • S/W 직접 납품·구독 구매 항목 없음: 발주처(연세대학교)가 특정 S/W를 직접 구매하는 조달 방식이 아니라, 제안사가 모든 인프라·SW·라이선스를 포함한 완성형 클라우드 서비스를 제공하는 방식. Red Hat 제품을 별도 품목으로 제안할 기회 없음
  • Red Hat 제품 및 동의어 전혀 미명시: RHEL, OpenShift, OCP, Ansible, JBoss, EAP, AAP, Quay, AMQ, ACM, ACS, Satellite 등 Red Hat 상용 제품명이 RFP 어디에도 언급되지 않음
  • 경쟁·대체 제품도 미명시: VMware, Ubuntu, Rocky Linux, Oracle Linux 등 경쟁 제품 역시 미명시. 기술 스택 선택 자유도는 있으나 발주처의 RH 제품 도입 의지 확인 불가
  • 인프라 선택 주체가 제안사: 클라우드 환경 및 서버·OS는 제안사가 자율 선택하므로, 발주처와 Red Hat 간 직접적인 영업 접점 형성이 어려움
  • 기존 Red Hat 스택 존재 여부 불명: 연세대학교의 기존 Red Hat 도입 이력이나 증설 필요성에 대한 언급 없음
Red Hat 제안
가능 요소
  • RFP 내 Red Hat(동의어 포함) 제품명·수량 명시: 없음
  • 클라우드 플랫폼 인프라 구성 요건: ECR-001에서 CSAP 인증 클라우드 기반, 물리적으로 분리된 서버·네트워크, 백업·복구 서비스 요구 → 제안사 인프라 구성 시 RHEL 또는 OpenShift 컨테이너 플랫폼 활용 가능성 존재 (간접 기회)
  • 모듈화·분산 아키텍처 요구: SFR-001, PER-001·002에서 로드밸런서 기반 부하 분산, 모듈화 설계, 고가용성 요구 → OpenShift 기반 컨테이너 오케스트레이션 적용 여지 (단, 제안사 자율 선택 사항)
  • API Gateway 및 멀티LLM 통합: SFR-002, SFR-005에서 API Gateway 기반 멀티LLM 라우팅, 분산 처리 구조 요구 → Red Hat OpenShift API Management(3scale) 활용 제안 가능성 (간접 기회)
  • 파트너/SI 영업 접근: 이 사업을 수주하는 SI 업체에 대해 Red Hat이 파트너 채널을 통해 RHEL·OpenShift 인프라를 제안하는 간접 영업 전략 검토 가능. 그러나 발주처 RFP에 품목으로 명시되지 않아 직접 영업 기회로는 분류 어려움
