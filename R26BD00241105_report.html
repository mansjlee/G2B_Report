Red Hat 제안
불가능 요소
  • 본 사업은 인프라·OS·미들웨어 구매가 아닌 민간 에듀테크 콘텐츠 구독권 및 SSO·xAPI 연계 용역으로, Red Hat 제품 직접 조달·납품 요건이 없음
  • SSO는 기 구현된 KsignAccess V4.1 기반으로 명시되어 Red Hat SSO/JBoss 대체 제안 여지가 제한적
  • 콘텐츠는 CP사 클라우드 서버에서 스트리밍 제공하므로 발주기관·수행사의 RHEL/OpenShift 등 인프라 S/W 공급 범위에 포함되지 않음
  • VMware, Contrabass, Ubuntu, Oracle/Rocky Linux 등 특정 경쟁 OS·가상화 제품은 명시되지 않았으나, 기술적용계획표에 Linux·Windows Server 등 범용 OS만 선택지로 기재되어 Red Hat 전용 지정 없음
  • 하도급 불허, 이러닝사업자 자격 필수로 Red Hat 단독 또는 Red Hat 중심 공동수급 직접 참여가 사업 성격상 부적합
  • 평가 배점이 콘텐츠 구성(20점), 학습지원(10점), SSO 연계(10점) 등 에듀테크 서비스 역량 중심(정성 70점)으로 Red Hat 기술 스택 평가 항목 없음
Red Hat 제안
가능 요소
  • 간접 기회: 제안 CP사·이러닝 플랫폼 운영사의 백엔드가 RHEL/OpenShift 기반인 경우 Red Hat 구독·기술지원을 CP사에 제안 가능(본 RFP 직접 납품 항목 아님)
  • 기술적용계획표에 Linux, 클라우드(IaaS/PaaS/SaaS), RESTful API, OAuth 등 범용 기술이 기재되어 있으나 특정 Red Hat 제품 매핑 요구는 없음
  • SSO·xAPI 연동, 학습데이터 분석, 클라우드 기반 서비스 운영 등은 Red Hat OpenShift·Ansible Automation Platform 역량과 부합하나, RFP상 수행사가 자체 개발·연동하는 인프라 구축 사업이 아니므로 직접 제안 근거가 약함
  • Red Hat이 국내 에듀테크 CP·SI 파트너와 협력하여 CP사 인프라 표준화(RHEL/OpenShift)를 선제 제안하는 간접 영업 채널 전략은 가능하나 본 입찰 Red Hat 직접 수주 가능성은 낮음
