레드햇 제안 가능성 중간
기존 RHEL 운영 환경, 구독 갱신 제안 여지
사업 개요 및 목적
  • 전남개발공사에서 운영 중인 H/W 및 S/W의 장애 발생을 사전에 예방하여 무중단 서비스 제공
  • 장애 발생 시 신속한 대처·복구를 통한 정보화 서비스의 안정적 운영
  • SLA(Service Level Agreement) 기반 유지관리로 서비스 수준 관리의 효율성·생산성 향상
  • 전문기술 인력을 투입하여 운영 관리의 전문성을 높이고, 계량화된 KPI를 통해 유지관리 운영 품질 지속 개선
  • 과업 수행 중 전남개발공사와 광주광역시도시공사 통합에 따른 유지관리 대상 및 업무 범위 변경 가능성 명시

Red Hat 제안
불가능 요소
  • 순수 유지관리 용역 사업: 신규 S/W 납품·구매·도입 항목이 별도로 명시되지 않은 운영 인력 상주 용역으로, Red Hat 상용 제품의 신규 납품·증설 항목 없음
  • VMware vSphere 사용 확정: 서버 가상화 솔루션으로 VMware vSphere 8.0(AIS PR750 2대, DELL R740 1대)이 이미 도입·운영 중이며 상용 SW 유지관리 목록에도 포함됨 (경쟁 제품)
  • CentOS 6.9 운영 중: 백업 마스터 서버(DELL R740)의 OS로 CentOS 6.9(x64)가 사용 중 (커뮤니티 제품, RHEL 전환 여지 있으나 확정 아님)
  • 대기업 입찰 참가 제한: 소프트웨어 진흥법 제48조에 따라 대기업 및 상호출자제한기업집단 소속 회사 입찰 불가 — Red Hat Korea 또는 파트너 대기업 직접 입찰 불가
  • 하도급·공동수급 불가: 본 용역은 단독 수행 필수로, Red Hat이 컨소시엄 구성 또는 하도급 참여 불가
  • 티맥스 미들웨어 확정 사용: WebtoB/JEUS 등 티맥스소프트 미들웨어가 이미 도입·운영 중으로 JBoss EAP 신규 제안 어려움
Red Hat 제안
가능 요소
  • RHEL 기존 운영 확인 (MPR-02): DELL R740 서버에 Red Hat Enterprise Linux 8.3(x64)이 전자결재 서버 OS로 운영 중 — RHEL 구독 갱신 및 유지보수 제안 기회 존재
  • RHEL 기반 보안 솔루션 유지관리 포함 (MPR-03): 하우리 REDOWL SecuOS V5.6 (RHEL) 서버보안 솔루션 6대가 유지관리 대상에 포함 — RHEL 기반 운영 환경 유지 필요
  • RFP 내 Red Hat 제품 명시 현황:
    • DELL R740 — Red Hat 8.3(x64) (전자결재 서버, 1대) [MPR-02]
    • 하우리 REDOWL SecuOS V5.6 (RHEL) (서버보안, 6대) [MPR-03]
  • Linux 기반 서버 다수 운영: ATL Linux(방화벽 로그 서버), CentOS 6.9(백업), Red Hat 8.3(전자결재) 등 Linux OS 서버 다수 운영 중 — 추후 RHEL 전환·확장 제안 여지
  • RHEL 구독 갱신 영업 접점: 기존 RHEL 8.3 운영 환경의 구독 만료 도래 시 갱신 협상 가능, EOL(End-of-Life) 이슈를 활용한 RHEL 9 업그레이드 제안 기회
  • CentOS → RHEL 전환 제안: CentOS 6.9는 이미 EOL 상태로 보안 취약점 위험 존재 — RHEL 마이그레이션 제안으로 보안 강화 명분 활용 가능
  • Ansible 자동화 제안 여지: 160개 유지관리 대상에 대한 패치 관리, 구성 관리, 보안 패치 자동화 요구사항(MPR-13, MPR-14) 존재 — Ansible Automation Platform 제안 접점
