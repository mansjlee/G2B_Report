가능 요소
  • 상용SW 유지관리 범위 포함: 사업 범위에 "국방행정관리체계의 상용SW 장애처리, 패치적용, 설치, 삭제, 변경, 업그레이드 및 기술지원"이 명시되어 있어, 현행 운영 중인 상용SW 목록에 Red Hat 제품이 포함될 가능성 존재
  • Linux 서버 운영환경 가능성: 기술적용계획표에 운영체제로 "Linux" 항목이 명시되어 있으며(적용 체크), 43개 정보체계의 서버 OS로 RHEL 계열이 운영 중일 가능성 있음
  • 오픈소스/공개SW 관리 범위: RFP에서 공개SW 라이센스 준수 의무, 오픈소스 적용 기능 리스트 제공 요건 등이 언급되어 있어, Red Hat 기반 공개SW 환경일 가능성 존재
  • DevOps/DevSecOps 제안 여지: MPR-004에서 "DevOps, DevSecOps 등 사례 참조"하여 발전적 유지보수 방안 제시 요구 → Ansible Automation Platform, OpenShift 기반 자동화·컨테이너 플랫폼 제안 기회
  • 방문 열람을 통한 실제 제품 확인 필요: 상용SW 유지보수 대상 세부 목록은 공고 기간 중 방문 열람으로만 확인 가능 → 현장 확인 시 RHEL, JBoss EAP 등 Red Hat 상용 제품 포함 여부 파악 가능
  • RFP에 명시된 Red Hat(동의어 포함) 제품명·수량: 없음 (RFP 본문 내 RHEL, OpenShift, JBoss, Ansible, Red Hat 등 어떠한 Red Hat 상용 제품명도 명시되지 않음)
