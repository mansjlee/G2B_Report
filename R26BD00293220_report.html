Red Hat 제안
불가능 요소
  • S/W 납품·구매 항목 없음: 본 사업은 순수 유지보수 용역 사업으로, 신규 S/W 도입·납품·구독 구매 항목이 RFP에 명시되어 있지 않음
  • 상용SW 목록 비공개: 기존 운영 중인 상용SW 현황은 방문 열람으로만 확인 가능하여 Red Hat 제품 포함 여부 불명확
  • Red Hat 상용 제품명 미명시: RFP 전체 문서에 RHEL, OpenShift, Ansible, JBoss/EAP 등 Red Hat 상용 제품명이 구매·납품 품목으로 전혀 명시되지 않음
  • 경쟁 제품 명시 없음(대신 기존 체계 유지가 목적): 특정 OS·플랫폼 교체 없이 기존 정보체계 현상 유지 및 운영 연속성 확보가 핵심 목적
  • 국방 보안 제약: 국방 보안업무훈령·사이버안보훈령 등 엄격한 보안 규정 적용으로 신규 제품 도입 여지 낮음
  • 판정 규칙 적용: 상용 RH 제품명이 신규 도입·납품 품목으로 명시되지 않고, 기존 유지보수 대상 목록도 비공개 → 낮음 조건에 해당 (순수 용역·유지보수 사업, S/W 납품·구독 항목 없음)
Red Hat 제안
가능 요소
  • 기존 운영 중인 상용SW 유지관리 포함: 43개 정보체계에 대한 상용SW 유지관리가 사업 범위에 포함되어 있어, 기존에 RHEL·JBoss EAP 등이 운영 중일 가능성 존재 (단, 비공개로 확인 불가)
  • Linux 서버 환경 추정: 서식8 기술적용계획표에 Linux 서버 운영체제 적용 항목이 존재하며, 일부 체계에서 Linux 기반 서버 운영 가능성 있음
  • DevOps/DevSecOps 언급: MPR-004에서 DevOps, DevSecOps, SRE 등 사례 참조 요구 → Ansible Automation Platform, OpenShift 등 제안 논리로 활용 가능
  • RFP에 명시된 Red Hat(또는 동의어) 제품명·수량: 없음 (RFP 내 Red Hat 상용 제품명 전혀 미명시)
  • 종합 의견: 상용SW 목록이 방문 열람으로만 공개되므로, 영업 담당자가 직접 방문 열람을 통해 기존 운영 Red Hat 제품 포함 여부를 확인하는 것이 필요. 현재 RFP 텍스트만으로는 Red Hat 제안 근거가 불충분하여 낮음으로 판정
