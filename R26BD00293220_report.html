불가능 요소
  • S/W 납품·구독 항목 미포함: 본 사업은 기존 운영 중인 43개 정보체계를 유지보수하는 서비스 용역 계약으로, RFP상 신규 S/W 납품·구독 구매 항목이 명시되어 있지 않음
  • Red Hat 상용 제품명 전혀 미기재: RHEL, OpenShift, Ansible, JBoss EAP, AAP 등 Red Hat 상용 제품이 RFP 내 어디에도 품목으로 명시되지 않음
  • 상용SW 목록 비공개: 구체적인 상용SW 목록은 방문 열람을 통해서만 확인 가능하여, 현시점에서 Red Hat 제품 포함 여부 확인 불가 → 높음 판정 근거 없음
  • 기존 운영환경 유지 중심: 사업 특성상 기존 정보체계 및 상용SW를 현행 상태로 유지·관리하는 것이 주 목적이며, 신규 기술 스택 도입보다 기존 환경 운영 지속이 우선
  • 군 보안 제약: 국방보안업무훈령 등 엄격한 군 보안 요건이 적용되어 외부 클라우드 플랫폼 및 신규 상용SW 도입이 구조적으로 제한적

가능 요소
  • 상용SW 목록 방문 열람 기회: 공고 기간 중 방문 열람을 통해 기존 운영 상용SW 목록 확인 시, RHEL·JBoss EAP·Ansible 등 Red Hat 제품이 기존 운영 스택에 포함되어 있을 가능성 존재 (현재 단계에서 미확인, 확인 필요)
  • 미들웨어 관리 요건: PSR-002(교육 지원 및 기술이전)에서 "미들웨어 관리" 교육을 명시하고 있어, 현재 운영 중인 미들웨어가 JBoss/EAP 계열일 가능성을 배제할 수 없음
  • DevOps/DevSecOps 사례 참조: MPR-004에서 DevOps·DevSecOps를 개발·운영 연계 방안의 사례로 명시 → Ansible Automation Platform 등 Red Hat 자동화 솔루션의 부가 제안 참고 자료로 활용 가능 (구매 전환 가능성은 낮음)
  • Linux 서버 운영환경 가능성: 기술적용계획표(서식 8)에서 Linux가 서버용 개방형 운영체제 중 하나로 포함되어 있어, 기존 RHEL 기반 운영 환경일 가능성 있음 (방문 열람 통한 확인 필요)
  • RFP에 명시된 Red Hat 제품명·수량: 없음 (방문 열람을 통한 상용SW 목록 확인 필수)
