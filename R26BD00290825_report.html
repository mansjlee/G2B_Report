Red Hat 제안
불가능 요소
  • S/W 납품·구독 항목 없음: 본 사업은 순수 운영·유지보수·콘텐츠 제작 용역 사업으로, Red Hat 포함 신규 상용 S/W 구매·납품 항목이 제안요청서 내 전혀 존재하지 않음
  • 경쟁 OS 사용 환경: SLA 협약서 표준안(붙임4 월간 운영보고서) SW 구성 현황 예시에 Rocky Linux가 기재되어 있어 현재 시스템이 RHEL의 경쟁·대체 Linux 배포판을 사용 중임을 시사
  • 기존 미들웨어 스택이 비 Red Hat 기반: TmaxSoft의 Webtob(웹서버)·JEUS(WAS) 및 Oracle/Tibero(DBMS) 스택으로 구성되어 있어 Red Hat 미들웨어(JBoss EAP 등) 제안 여지 없음
  • 워드프레스 기반 운영: 콘텐츠 플랫폼이 WordPress로 확정되어 있어 Red Hat PaaS(OpenShift) 또는 컨테이너 플랫폼 제안 여지 없음
  • 중소SW사업자 전용 사업: 대기업·중견기업 입찰 참여 불가 조건으로, Red Hat 파트너를 통한 간접 참여도 사실상 어려운 구조
Red Hat 제안
가능 요소
  • RFP 내 Red Hat(동의어 포함) 제품 명시 없음: RHEL, OpenShift, Ansible, JBoss EAP 등 Red Hat 상용 제품명이 요구사항, 구매 목록, 기술스택 어디에도 명시되지 않음
  • Apache 웹서버 운영·업그레이드 포함: MAR-002에서 '아파치 서버(SW) 업그레이드, 환경설정, 장애관리 등 유지관리'가 명시되어 있어 이론적으로는 RHEL 기반 Apache 환경 운영이 가능하나, OS 전환 제안 요구사항은 없음
  • Linux 계열 OS 기술 표준 포함: 기술적용계획표(붙임12)에 '서버용(개방형) 운영체제 - Linux' 항목이 포함되어 있어 개방형 Linux OS로서 RHEL 제안 가능성이 원천 배제되지는 않으나, 기존 Rocky Linux 스택 교체에 대한 고객 동기 부재
  • 종합 평가: 신규 S/W 구매가 없는 순수 운영 용역이며, 기존 시스템이 비 Red Hat 스택(Rocky Linux + TmaxSoft + Oracle)으로 구성되어 있어 실질적인 Red Hat 제품 제안 기회는 없음
