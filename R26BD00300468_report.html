사업 개요 및 목적
  • 영유아 교육·보육 부처 통합(유보통합)에 따라 분절된 정보시스템(유아교육정보시스템·보육통합정보시스템)의 데이터를 통합·연계하기 위한 마스터데이터(MDM) 체계 구축 및 시범서비스 개발 사업
  • 영유아, 보호자, 교직원, 기관(어린이집·유치원) 정보를 대상으로 마스터데이터 모델 설계, 데이터 품질관리 체계 마련, 데이터 시범 이관·검증 수행
  • 클라우드 네이티브 기반 공통 인프라 구축, 교직원 디지털 커리어패스 서비스 시범 구축, 데이터 시각화(AI/자연어 질의 기반 리포트) 시범 구현 포함
  • 「유보통합정보시스템 마스터플랜(ISMP)」 주요 과제 이행을 위한 선결 단계로, 향후 전체 통합 시스템 구축의 기반 마련이 목적

Red Hat 제안
불가능 요소
  • 상용SW 직접구매 품목에 Red Hat 제품 미포함: 직접구매 대상 3개 품목(MDM, API Gateway, 데이터시각화)은 모두 제안요청설명회 참석업체에만 공개하는 특정 솔루션으로, Red Hat 제품이 명시되어 있지 않음
  • RFP 전체에 Red Hat 상용 제품명(RHEL, OpenShift, Ansible, JBoss EAP 등) 미명시: 현행 시스템 구성, 유지보수 대상, 도입 품목 목록 어디에도 Red Hat 상용 제품이 기재되어 있지 않음
  • OS 미지정(단, Linux 언급 존재): 인프라 요구사항에 "Linux(64bit)"가 명시되어 있으나, 이는 Docker 운영환경에 대한 일반 요구이며 특정 배포판(RHEL 등)이 지정되지 않음
  • 순수 SI 개발 용역 중심: 클라우드는 CSP 임차 방식(IaaS)으로 도입하며, Red Hat 플랫폼 제품의 직접 도입 기회가 구조적으로 제한됨
  • 경쟁 솔루션 대체 가능성: MDM(마스터데이터관리), API Gateway, 데이터시각화 솔루션 모두 발주기관이 사전 지정한 S/W를 그대로 사용하도록 요구(SFR-005, SFR-011, SFR-012)하고 있어 Red Hat 제품 대체 여지 없음
  • JBoss/WAS 미언급: WAS 관련 요구사항에 JBoss, WildFly 등 어떠한 WAS 제품도 명시되어 있지 않으며, 전자정부 표준프레임워크 기반 개발만 요구함
Red Hat 제안
가능 요소
  • RFP 내 Red Hat 상용 제품 명시 없음: RHEL, OpenShift, Ansible, JBoss EAP, Satellite 등 Red Hat 상용 제품이 도입·유지보수 품목으로 단 한 건도 명시되어 있지 않음
  • 제한적 간접 제안 가능성 (낮음):
    • 클라우드 네이티브 환경(컨테이너, 쿠버네티스, CI/CD, 서비스메시) 구성 시 사업수행사가 자체 판단으로 OpenShift 또는 RHEL을 기반 인프라로 선택할 가능성이 이론적으로 존재하나, 발주기관이 CSP 임차 방식을 명시하여 실현 가능성은 낮음
    • 인프라 OS로 "Linux(64bit)"가 요구되어 RHEL 제안이 기술적으로는 가능하나, 발주기관이 사전 지정한 CSP 서비스 내에서 결정될 사항으로 Red Hat의 직접 영업 접점은 미약함
  • 향후 사업 연계 모니터링 권고: 본 사업은 「영유아 통합·연계시스템 1단계」 사업으로, 2단계 이후 전체 통합 시스템 구축 사업에서 OpenShift, RHEL, Ansible 등의 도입 기회가 발생할 수 있으므로 발주기관(교육부) 관계 유지 필요
  • 이번 RFP에서 Red Hat 직접 제안 기회 없음: 현 단계에서는 Red Hat 솔루션의 직접적인 영업 대응보다는 시장 모니터링 수준의 관리가 적합함
