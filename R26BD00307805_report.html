Red Hat 제안
불가능 요소
  • 순수 유지보수 용역 중심: 본 사업은 신규 S/W 도입·납품보다는 기존 시스템 유지보수·라이선스 갱신 위주의 용역 사업으로, Red Hat 상용 제품명(RHEL, OpenShift, Ansible 등)이 과업이행요청서 어디에도 명시되지 않음
  • VMware 명시: 가상화 S/W로 "VMware vCenter Server v6 (1식)" 라이선스 갱신이 과업에 명시되어 있어 Red Hat Virtualization(RHEV) 또는 OpenShift Virtualization 대체 제안이 현실적으로 어려운 상황
  • Oracle RDBMS 명시: ITS 시스템 및 신호 시스템 DBMS로 Oracle RDBMS Standard 8 core가 각각 명시되어 있어 Red Hat 계열 DBMS 제안 여지 없음
  • Microsoft 제품 확정: 스마트정류장 운영서버에 Windows 2016 Standard 및 MS-SQL 2016 Standard가 명시되어 있어 해당 영역 Red Hat 제안 불가
  • 현장 장비 중심 사업: 버스 OBE, 전광판, BIT 등 임베디드·현장 장비 유지관리가 주요 과업으로, Red Hat 솔루션 적용 대상이 아님
  • 기존 협력사 기술지원협약 의존: 제조사(기술지원사)와 춘천시 간 기술지원협약이 체결된 사업으로 기존 솔루션 교체 가능성이 매우 낮음
Red Hat 제안
가능 요소
  • OS 미지정 Linux 계열 서버 운영 환경: BIS 서버시스템에 Unix 가상화 서버(rx2800 i4), X86 가상화 서버(DL380Gen9) 등 다수의 서버가 존재하며, 마을버스 OBE 운영 OS로 "Linux"가 명시(Cortex A9 1.4Ghz, Linux)되어 있어 센터 서버 OS 환경이 Linux 계열임을 시사함 — 향후 OS 교체·증설 시 RHEL 제안 가능성 있음
  • VMware 라이선스 갱신 이슈: VMware vCenter Server v6 라이선스 갱신이 명시되어 있으나, Broadcom 인수 이후 VMware 라이선스 정책 변화로 인해 고객사에서 대안을 검토할 가능성이 있음 — OpenShift Virtualization 또는 RHEL 기반 가상화 대안 제안 접점으로 활용 가능
  • ITS 서버 인프라 규모: ITS 센터 H/W에 스마트교차로 영상분석서버(3대), ITS 서버(4대), 신호 서버(3대), 통합영상서버(1대) 등 다수의 x86 서버 인프라가 운영 중으로, 차기 도입 시 RHEL 구독 제안 여지 존재
  • RFP 내 Red Hat 상용 제품명 명시 없음: 현재 과업이행요청서 및 별첨 목록에 RHEL, OpenShift, Ansible, JBoss EAP 등 Red Hat 상용 제품명은 전혀 나타나지 않음
  • 종합 판단: 본 사업에서 Red Hat 제품의 직접적인 납품·갱신 기회는 없으나, VMware 대체 검토 시기를 활용한 선제적 고객 접촉 및 다음 사업 연계 영업 기회로 활용하는 것이 적절함
