Red Hat 제안
불가능 요소
  • 순수 기능 유지관리 용역: 본 사업은 애플리케이션 기능 유지관리 용역으로, S/W 납품·구독·라이선스 구매 항목이 전혀 없음. Red Hat 상용 제품의 도입·납품·증설 기회 없음
  • Red Hat 제품명 미명시: RFP 전체에 걸쳐 RHEL, OpenShift, Ansible, JBoss EAP 등 Red Hat 상용 제품명이 단 한 차례도 언급되지 않음
  • 인프라(클라우드) 분리발주: 서버·OS·미들웨어 등 인프라 영역은 별도 사업자(클라우드 MSP)가 담당하며, 본 용역 범위에서 완전히 제외됨. 따라서 OS·컨테이너 플랫폼 제안 불가
  • 경쟁 제품 명시 없음(단, RH 제품도 없음): Ubuntu, VMware 등 경쟁 제품도 명시되지 않았으나, Red Hat 제품 역시 명시되지 않아 제안 근거 부재
  • 현행 운영 S/W 목록에 Red Hat 제품 미확인: 현행 시스템 구성표(DBMS, DB이중화, BI, CRM, 보안솔루션 등)에 제품명이 비공개 처리되어 있으며, Linux·리눅스·공개SW·오픈소스 등 일반 문구조차 명시되지 않음. JBoss, WildFly 등 WAS 관련 제품도 별도 목록에 나타나지 않음
  • 대기업 참여 제한: 중소 소프트웨어사업자만 입찰 가능하여 Red Hat이 직접 입찰하기 어렵고, 채널을 통한 납품 대상 품목 자체가 없음
Red Hat 제안
가능 요소
  • RFP 내 Red Hat 상용 제품 명시 없음: RHEL, OpenShift, Ansible, JBoss EAP 등 Red Hat 상용 제품이 RFP 어디에도 명시되지 않아 직접적인 제안 근거 없음
  • 간접적 기술 연관성(제한적):
    • 현행 시스템이 클라우드(IaaS/PaaS/SaaS) 기반으로 운영되고 있어, 인프라 운영 사업자 측에서 RHEL 또는 OpenShift 계열 플랫폼을 사용할 가능성을 완전히 배제할 수는 없으나, 본 용역 범위 밖의 사안임
    • Java 기반 개발 환경(JSP, Java 프로그래밍 명시)과 WAS(운영자 매뉴얼에 WAS 언급) 운영 환경이 존재하므로, 인프라 담당 사업자를 통해 JBoss EAP 활용 가능성을 간접 탐색할 수 있으나 본 RFP에서는 확인 불가
    • 전자정부 표준프레임워크 기반 개발 환경 명시 → Java/WAS 스택 존재 가능성
  • 향후 인프라 분리발주 사업 모니터링 필요: 본 사업과 별도로 발주되는 "온라인도매시장 통합플랫폼 유지관리·운영" 사업에서 RHEL, OpenShift 등 Red Hat 제품이 활용될 가능성이 있으므로, 해당 분리발주 RFP를 별도 모니터링할 것을 권장
  • 결론: 본 사업(R26BD00298426)에 대한 Red Hat 직접 제안 기회는 없음. 인프라 분리발주 사업 발굴을 통한 간접 접근 전략 필요
