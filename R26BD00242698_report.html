레드햇 제안 가능성 중간
K8s·DevSecOps 간접제안
사업 개요 및 목적
  • 한국연구재단 온라인 논문투고 심사시스템(JAMS)을 재단 내부 클라우드 환경으로 전환·고도화하여 보안성을 강화하고 안정적·효율적 서비스 운영 기반을 마련하는 SW 개발 용역 사업
  • 학회·재단 관리자 권한 분리, 망분리 기반 접근통제, UI/UX 개선, Oracle→Tibero DBMS 전환 및 데이터 이관, DevSecOps·CI/CD 기반 Kubernetes 클라우드 운영환경 구축, 보안 취약점 점검·강화를 핵심 목표로 함
  • 기 보급 학회 1,647개 및 신규 70개 학회 대상 논문 투고·심사·게재·관리 서비스 연속성 확보
주요 정보
  • 사업 예산: 997,900,000원(부가세 포함) ※ 추가 HW·SW 구매 비용은 본 사업 예산에서 제외
  • 사업 기간: 계약체결일로부터 270일(약 9개월)
  • 사업 범위: 설계·보안 컨설팅, JAMS 기능 고도화(44개 기능요구사항), 재단 내부 클라우드 전환, DBMS 전환(Oracle 11g→Tibero) 및 iBatis 쿼리 변환, 정형·비정형 데이터 이관, 학회·재단 관리자 포털 물리 분리, KCI·KRI 연계, 시스템 안정화 및 운영 매뉴얼 제공
  • 기능점수: 226.2FP
  • 주요 일정: M(계약·사업준비·컨설팅) → M+1~M+2(분석·설계) → M+3~M+5(DB변환·구현) → M+6~M+7(실데이터 이관·테스트) → M+8(시스템 안정화·최종완료보고)
  • 입찰방식: 협상에 의한 계약, 기술평가 90% + 가격평가 10%, 중소 SW사업자 대상(20억 미만)

Red Hat 제안
불가능 요소
  • S/W 공급 미포함: 본 사업 예산(약 9.98억)은 SW 개발 용역 중심이며, 추가 HW·SW 구매 비용은 사업 예산에서 제외됨. Red Hat 제품 직접 조달·납품 기회 없음
  • 경쟁·대체 제품 명시: DBMS는 Tibero로 전환 지정(Oracle→Tibero), 검색엔진은 ElasticSearch 명시, H/W는 IBM Power System·DELL·HP 등 이기종 서버 현행 유지, 보안·운영 S/W는 국산 상용제품(Zenius-EMS, Secuguard, NGS, RedCastle 등) 고정
  • DB·미들웨어 직접 제안 제한: Tibero DBMS 및 iBatis 쿼리 변환이 핵심 과업으로 지정되어 RHEL DB·JBoss 등 Red Hat 미들웨어 직접 대체 제안 어려움
  • 재단 인프라 종속: NRF 내부 클라우드·기존 보안·네트워크·형상관리(데브아이) 등 재단 기반 인프라 최대 활용 원칙, 기술적용계획표에 특정 벤더·제품 선정 항목 존재
  • DB암호화 별도 발주: DB 암호화 솔루션은 한국연구재단 별도 발주 계획으로 본 사업 범위 외
Red Hat 제안
가능 요소
  • OpenShift: SFR-001·SFR-003에서 Kubernetes 기반 클라우드 환경 구축 및 DevSecOps·CI/CD 자동화 운영체계가 명시되어 OpenShift Container Platform을 컨테이너 오케스트레이션·DevSecOps 플랫폼으로 간접 제안 가능(낙찰 SI 파트너 경유)
  • Ansible Automation Platform: CI/CD 파이프라인, 배포·운영 자동화, 보안 패치·설정 관리, Kubernetes 환경 운영 자동화 요구와 부합하여 제안 가능
  • RHEL: 기술적용계획표 플랫폼 분야에서 Linux 서버 OS가 개방형 기술로 인정, NRF 내부 클라우드 IaaS/PaaS 환경의 컨테이너 호스트·WAS OS로 RHEL 제안 가능(단, IBM Power AIX 환경과의 호환성 검토 필요)
  • Red Hat Advanced Cluster Security(ACS): SER-001 Kubernetes 컨테이너 이미지·운영환경 보안 방안 요구, 시큐어 DevSecOps 파이프라인 보안 강화 제안 포인트
  • 제안 전략: 본 입찰은 직접 Red Hat 납품 사업이 아닌 SI/개발사업자와의 파트너십·기술 제휴를 통한 OpenShift·Ansible·RHEL 간접 제안이 현실적. 클라우드 전환·DevSecOps 평가항목(정성 10점) 및 보안 적용(10점) 대응 솔루션으로 차별화 가능
