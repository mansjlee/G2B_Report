Red Hat 제안
불가능 요소
  • Red Hat 상용 제품명 완전 부재: 79종 상용SW 기술지원확약 목록 어디에도 RHEL, OpenShift, Ansible, JBoss EAP, Satellite 등 Red Hat 상용 제품이 전혀 포함되어 있지 않음
  • 기존 환경 유지관리 위주 사업: 신규 SW 도입·납품이 아닌 기 구축된 시스템의 운영·유지관리가 핵심으로, 플랫폼·OS 변경 여지 없음
  • 비 Red Hat DB·미들웨어 확정: 시스템 개발환경이 Oracle, Cubrid, Tibero(DB), Java+정부표준프레임워크(AP)로 고정되어 있으며, JBoss 계열 명시 없음
  • 인프라 관리 주체 별도: 서버·스토리지·네트워크 등 인프라는 국가정보자원관리원(광주)이 관리하므로, OS 변경·RHEL 제안이 사실상 불가
  • 소규모 중소기업 경쟁 사업: 1차년도 20억원 미만으로 대기업·중견기업 참여 제한, Red Hat이 직접 입찰하기 어려운 구조
  • 경쟁·대체 제품 간접 확정: SSO/IAM은 Bandi 제품, DB암호화는 Magic DB Plus·D'Amo, DRM은 파수닷컴으로 이미 운영 중이며 Red Hat RH-SSO/Keycloak 제안 여지 없음
Red Hat 제안
가능 요소
  • OS 비명시 구간 미미: RFP 어디에도 특정 Linux OS(RHEL, CentOS, Rocky 등)가 명시되지 않았으나, 국가정보자원관리원 소관 인프라라 실질 제안 권한 없음
  • Java 기반 애플리케이션 환경: 사건처리시스템, ThinkFair 등 Java/JSP 기반 시스템에 이론상 JBoss EAP 제안 가능하나, 기존 운영환경 유지 원칙으로 실현 가능성 극히 낮음
  • Red Hat 제품명·수량 명시 없음: RFP 전문 어디에도 Red Hat(레드햇), RHEL, OpenShift, Ansible, JBoss, EAP 등 Red Hat 상용 제품명이 단 한 건도 언급되지 않음
  • 종합 판단: 실질적인 Red Hat 제품 제안 포인트가 없는 순수 운영·유지관리 위탁 사업으로, 영업 우선순위 낮음
