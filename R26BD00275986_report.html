WEB/WAS 신규도입, OS 미지정 인프라
사업 개요 및 목적
  • 기존 트러스트폼(TrustForm)/ActiveX 기반의 노후 정보시스템(MIS, PMS, 그룹웨어, e-감사)을 HTML5 웹 표준 환경으로 전면 전환
  • HCI(Hyper-Converged Infrastructure) 기반 고가용성 서버 인프라 신규 구축 및 노후 서버 P2V 마이그레이션
  • 한국연구재단 연구비 통합연계 모듈(Ezbaro, RCMS) 표준 API 고도화 및 양방향 데이터 정합성 확보
  • 상용 S/W(미들웨어, UI/UX 플랫폼, DB암호화, 레포팅 등 7종) 업그레이드 및 신규 도입
  • AI Agent 연계를 위한 표준 MIS API(OpenAPI) 설계·구현 및 향후 sLLM 기반 지능형 서비스 확장 토대 마련

핵심 요구사항
  • [기술·비즈니스 요구사항]
    • 기존 TrustForm 기반 비표준 화면(MIS 전 모듈: 인사·총무·급여·예산·회계·구매·자산관리 / PMS 전 모듈: 과제신청·연구과제·연구성과·통계 등) HTML5 웹 표준 전환 (SFR-001~018)
    • HCI 가상화 인프라(2EA 이상) 및 전용 DBMS 서버(1EA) 신규 구축, 스토리지(1EA) 및 SAN 스위치(2EA) 도입 (ECR-001~004)
    • 한국연구재단 통합연계(Ezbaro, RCMS) 최신 표준 API 연계 모듈 재개발 및 양방향 데이터 동기화 (SFR-022~025, SIR-001~002)
    • AI Agent 연계를 위한 RESTful 표준 MIS API(OpenAPI) 설계·구현 (SFR-026)
    • 향후 sLLM 기반 지능형 서비스 연계를 위한 Loosely Coupled 확장형 아키텍처 설계 (SFR-027)
    • J2EE 기반 개발환경 적용, 전자정부 표준프레임워크 또는 Spring Boot 기반 프레임워크 사용 (COR-001)
    • 국가정보원 검증필(KCMVP) 암호모듈 적용 의무, 시큐어코딩 69개 항목 준수 (SER-001~008)
    • Oracle DB 라이선스 포함 DBMS 서버 도입 명시 (ECR-002)
  • [통합발주 상용 S/W 구매 목록 — 7종]
    • 레포팅 솔루션 업그레이드: 1식 (HTML5 기반 웹 전용, 기존 버전에서 업그레이드) (ECR-005)
    • UI/UX 플랫폼 신규 도입: 1식 (HTML5 웹 표준 기반 상용 UI/UX 프레임워크) (ECR-006)
    • 미들웨어(WEB) 솔루션 신규 도입: 1식 (Standard Edition 이상, Java EE 표준 지원) (ECR-007)
    • 미들웨어(WAS) 솔루션 신규 도입: 1식 (Standard Edition 이상, Java EE 표준 지원) (ECR-007)
    • PDF 변환 솔루션 업그레이드: 1식 (서버 기반 자동 변환, 기존 버전에서 업그레이드) (ECR-008)
    • PDF 뷰어 업그레이드: 1식 (HTML5 기반 Non-ActiveX 뷰어, 기존 버전에서 업그레이드) (ECR-009)
    • 전자문서 시점확인 솔루션(타임스탬프) 신규 도입: 1식 (TSA 연동, 국가 공인인증기관 연계) (ECR-010)
    • DB 암호화 솔루션 신규 도입: 1Core 기준 (KCMVP 인증 필수, 칼럼 단위 암호화) (ECR-011)

Red Hat 제안
불가능 요소
  • Red Hat 상용 제품 미명시: 통합발주 7종 S/W 목록(ECR-005~011)에 Red Hat 제품명(RHEL, JBoss EAP, OpenShift, Ansible 등)이 단 한 건도 명시되지 않음
  • 현행 경쟁 제품 존재: 현행 WAS로 Jeus(TmaxSoft), WEB으로 WebtoB(TmaxSoft)가 운영 중이며 교체 대상이나 후계 제품 미지정 — TmaxSoft 재도입 가능성 존재
  • VMware 기반 현행 운영: 현행 가상화 인프라에 vCenter 1식, vSphere Client 1식이 운영 중 (신규 HCI 도입 시 하이퍼바이저 미지정이나 VMware 재도입 가능성 있음)
  • Oracle DB 확정: DBMS 서버(ECR-002) 사양에 "오라클 라이선스 포함" 명시 — Red Hat 연계 DB 전환 여지 없음
  • SSO 기존 연동: SSO(ECR-012)는 기 구축된 솔루션과의 연동으로 RH-SSO 신규 납품 기회 없음
  • 순수 웹 전환 SI 중심 사업: 전체 사업 비중의 대부분이 기존 시스템의 HTML5 전환 개발 용역으로, S/W 납품은 7종으로 한정되어 있음
Red Hat 제안
가능 요소
  • [JBoss EAP / JBoss Web Server — WEB/WAS 신규 도입 기회]
    • ECR-007에서 WEB 서버 및 WAS 소프트웨어를 각 1식 신규 납품 조건 명시 (특정 제품 미지정)
    • 요구사항: "최신 Java EE 표준 규격 완벽 지원", "부하 분산(Load Balancing) 및 세션 클러스터링", "다수의 공공기관 구축 실적으로 검증된 안정성" → JBoss EAP(WAS), JBoss Web Server(WEB)가 모든 조건 충족
    • 현행 WebtoB(WEB)/Jeus(WAS)를 대체하는 신규 도입으로 실질적인 영업 기회
  • [RHEL — HCI 서버 OS 제안 기회]
    • ECR-001(HCI 가상화 서버 2EA), ECR-002(DBMS 서버 1EA)의 서버 OS가 명시되지 않음 ("서버 사양에 맞는 OS 설치 지원" 수준)
    • COR-003에서 "범용 Linux/Windows 기반 운영" 명시 → RHEL을 게스트 OS 또는 하이퍼바이저 Host OS로 제안 가능
  • [Ansible Automation Platform — 인프라 자동화 제안 여지]
    • HCI 가상화 인프라 구축, P2V 마이그레이션, 배포 자동화(형상관리 환경 구축) 등 인프라 자동화 수요 존재 (PMR-006)
    • 다만 자동화 S/W가 구매 품목으로 명시되지 않아 제안 가능성은 낮음
  • [RFP에 명시된 Red Hat(또는 동의어) 제품명·수량]: 없음 — Red Hat 상용 제품명이 본 RFP 어디에도 명시되어 있지 않음
  • [영업 전략 포인트]: WEB/WAS 품목(ECR-007)이 핵심 제안 기회이며, SI 수행사(낙찰업체)를 통한 JBoss EAP 공급 경로 확보가 중요. 제안사가 직접 구매하여 납품하는 통합발주 구조이므로 SI 파트너 영업 필수
