Red Hat 제안
불가능 요소
  • S/W 공급 범위 제한: 본 사업은 네트워크·보안·스토리지·DB 인프라 구축 용역으로, Red Hat 제품(RHEL, OpenShift, Ansible 등) 구매·공급 요구사항이 RFP에 명시되지 않음
  • Oracle DBMS 명시: DBMS 및 복제솔루션이 Oracle Enterprise Edition, Oracle Partitioning, Oracle Active Data Guard로 통합발주 대상으로 명시되어 있으며, 주센터 기존 Oracle 환경과의 호환성이 필수 조건
  • IBM Power 서버 지정: 통합DB서버는 IBM Power E1050 계열(32코어 이상, AIX/Unix 계열) 규격이며, HMC관리콘솔 도입 요건으로 IBM 생태계에 종속
  • 기존 장비 호환성: 주센터 사용 중 IBM FS7300·FS5045 스토리지, Lenovo DM3010H, WINs DDoS/IPS, FutureSystem VPN 등 기존 제품과의 호환·연동이 필수
  • 경쟁 제품·기술 명시: VMware, Citrix, Hyper-V, OPEN Xen 등 가상화 하이퍼바이저 지원 요건은 스토리지 측면에서만 언급되며 Red Hat 관련 제품은 미명시
  • 직접구매 제외 S/W: 붙임15에 Oracle DBMS·Oracle Active Data Guard가 직접구매 제외(통합발주) 품목으로 등재되어 Red Hat 대체 제안 여지 없음
  • 입찰 참가 자격: 정보통신공사업(0036) 등록, 해당 제품 제조업체와 기술지원협약서(Certification) 체결 가능 업체 등 네트워크·인프라 SI 업체 중심 자격 요건
Red Hat 제안
가능 요소
  • 인력 자격(RHCE): PSR-001에 정보시스템 구축 전문인력 투입 시 RHCE 자격 보유자 투입 가능하며, Red Hat은 SI/네트워크 통합업체를 통한 기술자격·교육 지원 형태로 간접 참여 가능
  • Linux OS 호환성: ECR-002·ECR-018·ECR-019에 운영체제 상호운용성 및 Linux OS 지원 요건이 있으나, 제조사 자체 OS 또는 스토리지 관리용 Linux 수준이며 RHEL 지정은 없음
  • 자동화·프로비저닝(간접): 네트워크 장비 ZTP(Zero Touch Provisioning), Telemetry 모니터링 요건이 있어 Ansible Automation Platform 기반 네트워크 자동화를 추가제안(별지서식14) 형태로 제시할 여지는 있으나 필수 요구사항 아님
  • DR·고가용성 아키텍처 컨설팅: DR센터 구축·데이터 복제·전환 훈련 등 Red Hat OpenShift/컨테이너 기반 DR 아키텍처는 현재 Oracle·IBM 기반 요구와 불일치하나, 향후 애플리케이션 현대화 연계 시 Red Hat 솔루션 제안 가능성 존재
  • 파트너 협력 모델: Red Hat은 직접 입찰 참가보다 네트워크·인프라 SI 파트너(공동수급·하도급)와의 기술지원협약, RHCE 인력 파견, Linux 기반 관리서버 OS 제안 등 제한적 협력 경로 검토 가능
