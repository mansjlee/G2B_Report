한국지능정보사회진흥원_2027년 범정부 데이터 공유시스템 운영 및 기능 개선 사업 - 분석 리포트

레드햇 제안 가능성 중간
RHEL·JBoss 운영중, 구매품목 아님
사업 개요 및 목적
  • 대상시스템: 기관공유데이터 관리시스템과 국가공유데이터 플랫폼입니다. 범정부 데이터 허브 역할을 합니다.
  • 목적 ①: 24시간 365일 무중단으로 운영합니다.
  • 목적 ②: 데이터관리시스템 공통기능을 전담 운영합니다. 대상은 통합 로그인, 사용자·조직 통합관리, LDAP 연계입니다.
  • 수집·제공 표준화: 자동 수집 연계를 확대합니다. URI·고유식별자 체계와 MCP 기반 제공체계(AI 에이전트·온AI 연계)를 적용합니다.
  • 공유·개방 일원화: 공유·개방데이터 등록·관리 체계를 통합하고 중복 등록 데이터를 정비합니다.
  • 기관 활용 확대: 기관 내·외부 데이터 공유체계를 제공합니다. 권한체계는 N2SF C·S·O 등급을 기반으로 합니다.
  • 사업 분리: 2027년부터 「범정부 메타 및 품질·표준관리 통합시스템 운영·유지관리 사업」과 분리 발주됩니다.

Red Hat 제안
불가능 요소
  • 신규 S/W 공급 없음:
    • 사업비 대부분은 운영·개발 인건비입니다.
    • 상용SW는 기 도입 제품의 유지관리만 대상입니다. 직접구매·분리발주 계획도 없습니다.
    • 상용SW 유지관리 목록에 Red Hat 제품이 없습니다.
  • 시스템SW 관리 주체가 별도:
    • OS 등 시스템SW는 국가정보자원관리원 유지관리 사업에서 제공·관리합니다.
    • 통합자원(WEB·WAS·DB)은 메타·품질표준 사업이 전담합니다.
    • 따라서 본 사업자가 RHEL/JBoss 구독을 직접 갱신하거나 증설할 권한이 제한적입니다.
  • "오픈소스 설치·운영" 표기:
    • RHEL·JBoss가 상용 구독이 아닌 오픈소스로 인식되고 있습니다.
    • 구독 비용이 예산에 반영되지 않았을 가능성이 높습니다.
  • 대체 경쟁 요소:
    • WAS/WEB 대체가능 SW로 Apache·Tomcat 영향도 테스트를 요구합니다.
    • Node.js, Python 런타임과 PostgreSQL·Tibero DBMS를 사용합니다.
    • VMware·Ubuntu·Rocky 등 경쟁 OS/가상화 명시는 없습니다.
  • 입찰 구조:
    • 20억 미만 사업으로 중소 SW사업자만 참여할 수 있습니다.
    • 개방형 기술 적용, 특정규격 명시 금지 원칙이 있어 특정 벤더 지정이 어렵습니다.
Red Hat 제안
가능 요소
  • RFP 내 Red Hat(동의어) 제품명·수량:
    • OS: RHEL 7.4 / 8.8, 수량 미명시. 국가공유·기관공유 전 서버에 적용되며 Ⅰ.3 장비현황, MPR-009, ECR-003에 명시되어 있습니다.
    • WEB: JBOSS-Apache 2.4, 수량 미명시
    • WAS: JBOSS-Was 7.8, 수량 미명시. JBoss EAP 7.x 계열로 추정됩니다.
    • 참고 규모: WEB·WAS·DB·연계서버 등 다수 노드가 운영 중입니다. 예를 들어 국가공유 전용자원은 내·외부망 각각 WAS 18식, DB 2식, LLM 서버 1식입니다.
  • RHEL 7.4 EOS 대응:
    • RHEL 7은 표준 지원이 종료되었습니다.
    • SER-007(지원 종료 OS 사용중지·업그레이드)과 연계해 RHEL 9 전환을 제안할 수 있습니다. 대안은 RHEL 7 ELS 구독입니다.
    • 국가정보자원관리원 유지관리 사업 및 통합자원 사업과 연계한 영업이 필요합니다.
  • JBoss EAP 정식 구독화:
    • 현재 JBoss를 "오픈소스"로 운영 중입니다.
    • 전자정부 표준프레임워크와 호환되는 EAP 구독으로 보안패치·기술지원 체계를 확보하도록 제안할 수 있습니다.
    • 무중단 운영과 log4j 등 취약점 대응 요구에 부합합니다.
  • Ansible Automation Platform:
    • 약 600개 기관 에이전트의 중앙 원격관리와 설정·버전 일괄 배포 요구에 적합합니다.
    • 시스템 유형별(공동활용형·단독형·지자체형) 패치 배포와 보안점검 자동화에도 활용할 수 있습니다.
  • Red Hat Satellite: 다수 RHEL 서버의 패치·구성관리와 보안 취약점 관리에 활용할 수 있습니다.
  • Red Hat build of Keycloak(RH-SSO): 통합 로그인 개선, 2차 인증, 등급 기반 권한체계(SFR-003·004), MCP 게이트웨이 인증·인가에 적용할 수 있습니다.
  • OpenShift / OpenShift AI / RHEL AI:
    • 대상 요구: MCP 서버·게이트웨이, RAG DB, LLM 모델 평가·교체·형상관리
    • 컨테이너 기반 AI 운영 플랫폼으로 중장기·차년도 고도화 과제를 제안할 수 있습니다.
  • 영업 전략:
    • 수행사(중소 SI)에 RHEL·EAP 기술지원 파트너십을 제안합니다.
    • NIA·국가정보자원관리원에는 차년도 구독 예산 반영을 제안합니다.
