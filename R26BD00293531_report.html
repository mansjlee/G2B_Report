  • 범정부 메타·품질표준 사업과 분리 발주되며, 양 사업 간 통합자원(WEB·WAS·DB) 공유 및 협조 의무 부담

불가능 요소
  • 신규 S/W 직접구매 없음: RFP 명시("본 사업은 직접구매 대상 상용SW가 없음. 신규 도입 계획 없어 직접구매 대상 구매계획 첨부 안 함") → 신규 RHEL 구독 라이선스 납품 기회 없음
  • 인프라(HW·시스템SW)는 국가정보자원관리원 담당: OS 포함 시스템SW 유지관리는 국정자원 사업에서 수행. 본 사업은 응용계층(AP) 담당이므로 OS 계층 변경 권한 없음
  • 통합자원(WEB·WAS·DB) 운영은 메타·품질표준 사업 전담: JBoss-Apache, JBoss-WAS 등 통합자원 상용SW 운영·유지관리 비용 부담은 본 사업이나, 실제 운영권한은 타 사업자
  • JBoss·RHEL이 "오픈소스 설치·운영"으로 분류됨: RFP에서 RHEL, JBoss-Apache, JBoss-WAS를 "시스템SW는 오픈소스 설치·운영"으로 명시하여 상용 구독 제품으로 취급하지 않고 있음 (커뮤니티/무상 버전 운영 가능성)
  • 20억 미만 중소기업 제한 사업: Red Hat Korea 직접 입찰 불가 (파트너사 통해 간접 기회만 존재)
  • 상용SW 유지관리 대상 목록에 Red Hat 구독 제품 없음: 유지관리 대상 상용SW 9개 품목에 RHEL, OpenShift, Ansible 등 Red Hat 상용 제품 미포함

가능 요소
  • RHEL 7.4 / RHEL 8.8 품목 명시 — 판정 근거 (높음): RFP 본문 및 ECR-003(상용SW 구성 요구사항), MPR-009(운영 요구사항) 등 다수 위치에서 "OS: RHEL 7.4/8.8"이 시스템 SW로 명시되어 현재 운영 중. RHEL 기반 인프라가 확정 도입·운영되고 있으므로 Red Hat 상용 제안 기회 존재
  • JBoss-Apache 2.4 / JBoss-WAS 7.8 운영 환경: WEB/WAS 레이어에 JBoss 기반 스택이 명시되어 있어 JBoss EAP 상용 전환 또는 유지관리 제안 여지 있음. 단, 현재 오픈소스로 분류·운영 중
  • MCP 기반 AI 플랫폼 구축 (SFR-005): MCP 서버·게이트웨이 구축, AI 에이전트 환경 보안통제 요구 → OpenShift AI, RHEL AI 등 Red Hat AI 플랫폼 제안 가능성 검토 필요
  • 컨테이너·쿠버네티스 미지정 영역: 생성형 AI 서비스(LLM 서버 1식 운영 중), RAG DB 관리, MCP 게이트웨이 등 신규 구축 요소에 대해 OpenShift Container Platform 또는 Ansible Automation Platform 제안 여지
  • 자동 수집 연계 고도화 (MPR-008): 600여 개 기관 동시 연계, 에이전트 중앙 원격관리(상태 모니터링, 설정·버전 일괄 배포, 장애 알림) 요구 → Ansible Automation Platform 제안 가능 포인트
  • RHEL 7.4 EOS 대응 기회: RHEL 7.4는 이미 EOS(Extended Life Cycle Support) 단계 진입. 보안 패치, 유지관리 연장 지원(ELS) 또는 RHEL 8/9 업그레이드 제안 가능. SER-007에서 "보안지원 종료 운영체제 업그레이드 실시" 명시
  • RFP 명시 Red Hat 관련 제품 수량 정리:
    • RHEL 7.4: 국가공유데이터 플랫폼 및 기관공유데이터 관리시스템 전체 서버 OS (수량 미명시, 대전·광주·대구센터 수십 식 규모)
    • RHEL 8.8: 동일 시스템 OS (수량 미명시)
    • JBoss-Apache 2.4: WEB 서버 레이어 (수량 미명시)
    • JBoss-WAS 7.8: WAS 서버 레이어 (수량 미명시)
  • 파트너 영업 전략: 20억 미만 중소기업 제한 사업이므로, Red Hat 공인 파트너사(중소 SW사업자)를 통한 간접 영업 및 솔루션 제안 전략 수립 필요. RHEL ELS/업그레이드, Ansible 자동화, OpenShift AI 포함 제안서 작성 지원 검토
