사업 개요 및 목적
  • 인천광역시 버스정보시스템(BIS)의 센터장비(H/W 서버, 네트워크, 보안 장비 등), 상용/개발 S/W, 버스정보안내기(BIT) 등에 대한 전문 유지관리 용역 사업
  • 체계적이고 안정적인 버스정보시스템 운영을 도모하고, 시민들에게 신속·정확한 대중교통(버스) 정보를 제공하는 것이 핵심 목표
  • 센터시스템 운영·유지보수, 현장 BIT 유지관리, 기반정보(노선·정류소 DB) 관리, 수도권 광역버스 연계시스템 유지관리 등을 포함하는 종합 유지관리 용역

Red Hat 제안
불가능 요소
  • 순수 운영·유지관리 용역으로 S/W 신규 납품·구독 항목 없음: 본 사업은 기존 버스정보시스템에 대한 유지관리 용역이며, Red Hat 상용 제품의 신규 도입·납품·구독 갱신 항목이 명시되지 않음
  • RFP 내 Red Hat 제품명 전혀 없음: RHEL, OpenShift, Ansible, JBoss EAP 등 Red Hat 상용 제품명이 RFP 어디에도 기재되지 않음. 현행 유지보수 대상 S/W 목록에도 Red Hat 제품 미포함
  • 현행 OS가 Windows Server로 확정: 버스정보시스템(BIS) 전체 운영환경이 Windows Server 기반으로 명시되어 있어 RHEL 제안 여지 없음
  • 미들웨어가 경쟁 제품(WebtoB/JEUS)으로 명시: 웹 미들웨어로 티맥스소프트의 WebtoB Std 및 JEUS-Ent가 현행 운영 중이며, JBoss EAP 등 Red Hat WAS 제품 도입 여지 없음
  • 대기업 입찰 참여 제한: 중소기업에 한해 입찰 참여 가능하며, Red Hat Korea가 직접 사업자로 참여 불가
  • 컨테이너·클라우드·자동화 기술 요구사항 없음: OpenShift, Ansible 등 Red Hat 솔루션의 주요 적용 분야인 컨테이너, Kubernetes, 자동화 관련 기술 요구사항이 전혀 없음
Red Hat 제안
가능 요소
  • RFP 내 Red Hat 상용 제품명 명시 없음: RHEL, OpenShift, Ansible Automation Platform, JBoss EAP, Satellite 등 어떠한 Red Hat 상용 제품도 RFP에 기재되지 않아 직접적인 제안 근거 없음
  • 간접적 접근 가능성 (매우 낮음): 유지보수 사업자가 향후 시스템 개선 제안 시 Red Hat 기술 스택을 권고할 수 있으나, 본 용역의 계약 범위 내에서는 사실상 불가능
  • 향후 차기 사업 연계 가능성: 버스정보시스템 차세대 구축 또는 고도화 사업이 발주될 경우 RHEL 기반 서버 OS 전환, OpenShift 기반 컨테이너 플랫폼 도입 등을 제안할 수 있는 간접적 기회로 활용 가능
  • 결론: 본 사업은 Windows Server 기반 현행 시스템의 순수 유지관리 용역으로, Red Hat 상용 제품 도입 가능성이 없어 영업 기회로서의 가치가 매우 낮음
