Red Hat 제안
불가능 요소
  • [용역 위주 사업 성격]: 본 사업은 정보시스템 유지관리·운영 용역으로, 신규 상용 SW 납품·구독이 주목적이 아님. SW 분리발주 "해당없음"으로 명시되어 Red Hat SW 신규 조달 발주 가능성 낮음.
  • [상용 SW 목록 비공개]: 현행 운영 중인 190식의 상용 SW 목록이 보안상 비공개 처리되어, 경쟁 제품(VMware, Oracle, Ubuntu 등) 사용 여부 또는 Red Hat 제품 기존 도입 여부를 현 단계에서 확인 불가.
  • [대기업 참여 제한]: 매출액 8천억원 이상 대기업 참여 불가 규정으로 Red Hat Korea 직접 입찰 참여 불가 (SI 파트너사를 통한 간접 참여만 가능).
  • [기존 환경 유지 원칙]: 유지관리 사업 특성상 기존 도입된 HW·SW 환경을 유지하는 것이 원칙이며, 신규 플랫폼 전환은 별도 협의 필요.
  • [특정 Red Hat 제품 미명시]: RFP 공개 범위 내 RHEL, OpenShift, Ansible, JBoss EAP 등 Red Hat 상용 제품명이 품목으로 명시되지 않음.
Red Hat 제안
가능 요소
  • [Linux OS 제안 여지]: 기술적용계획표에 서버용 개방형 운영체제로 "Linux"가 명시되어 있으며, POSIX·Unix 계열도 지원. 현행 OS가 확정되지 않은 신규 도입 자원 또는 OS 교체 시 RHEL 제안 가능.
  • [WEB/WAS 미들웨어 운영 환경]: RFP 전반에 걸쳐 WEB/WAS 미들웨어 운영·관리(JVM·세션·Connection Pool 포함)가 핵심 요구사항으로 명시. 현행 WAS 제품 확인 후 JBoss EAP 제안 또는 기술지원 기회 검토 가능.
  • [하이브리드 클라우드·컨테이너 환경]: 온프레미스와 민간 클라우드가 혼합된 하이브리드 환경 운영. 클라우드 전환 지원 요구사항(PSR-010) 명시. OpenShift 기반 컨테이너 플랫폼 및 하이브리드 클라우드 관리 제안 여지 있음.
  • [AI·GPU 인프라 운영]: AI도우미 서비스의 GPU 인프라, LLM 모델 운영 요구사항 존재. OpenShift AI(RHEL AI) 또는 AI 워크로드 자동화 제안 검토 가능.
  • [운영 자동화 수요]: 43명 이상 대규모 인력 운영, 다수 정보시스템 패치·구성변경·배포 관리 요구. Ansible Automation Platform 기반 인프라 자동화 제안으로 운영 효율화 가치 제시 가능.
  • [보안 강화 요구]: SIEM·SOAR 운영, 취약점 점검, 침해사고 대응 등 보안 요구사항 강화. Advanced Cluster Security(ACS) 또는 Red Hat 보안 포트폴리오 연계 제안 가능.
  • [RFP 내 Red Hat 제품명 직접 명시]: 없음 (상용 SW 목록 비공개로 확인 불가 — 열람 후 재확인 필요)
