불가능 요소
  • VMware 가상화 솔루션 명시 확정: ECR-006에서 "기존 VMware vSphere Foundation(VVF) 라이선스"를 대상으로 신규 호스트에 동일 제품 증설이 명시됨. 통합발주 품목으로 확정되어 RHEV(Red Hat Virtualization) 등 RH 가상화 제품 제안 불가
  • 기존 인프라의 VMware 환경 종속: 신규 가상화 서버(2식)가 기존 VMware vCenter/클러스터에 편입 요건(HA, vMotion 등)이 명시되어 있어, OS 단계에서 RHEL 단독 제안이 사실상 불가
  • 스토리지·SAN 기존 장비 종속: 스토리지 증설은 EMC Unity XT 380H, SAN 스위치는 Cisco MDS 9132T 기존 장비에 부품 추가 방식으로 Red Hat 스토리지 솔루션 제안 기회 없음
  • RFP 내 Red Hat 상용 제품명 전무: RHEL, OpenShift, Ansible, JBoss/EAP 등 Red Hat 상용 제품명이 본 RFP 어디에도 명시되지 않음
Red Hat 제안
가능 요소
  • AI 솔루션(ECR-014) 특정 제품 미지정 — OpenShift AI / RHEL AI 제안 여지: AI 솔루션(통합발주 1식)은 "Kubernetes 기반 컨테이너 환경 + GPU AI 워크로드 + 온프레미스 폐쇄망 운영"을 요건으로 하나 특정 제품명을 지정하지 않음. Red Hat OpenShift AI (구 RHOAI) 또는 OpenShift Container Platform + OpenShift AI 조합이 요건에 부합하며, GPU 자원 관리(vGPU/패스스루), RBAC, 고가용성, 표준 API 서빙 등 요건과 기능적으로 일치
  • 폐쇄망 온프레미스 요건 — Red Hat 강점 부합: "온프레미스 또는 폐쇄망 환경에서 운영 가능한 표준 GPU 기반 AI 플랫폼"이라는 요건은 Red Hat의 Disconnected/Air-gapped 설치 지원 역량(OpenShift, RHEL)의 강점 포인트임
  • AI 모델 서버 OS 미지정: AI 모델 및 관리 서버(3식)·GPU 서버(1식)의 운영체제가 명시되지 않아 RHEL 또는 RHEL AI 제안 가능. 특히 GPU 서버는 AI 학습·추론 환경으로 RHEL AI(NVIDIA NIM 포함) 제안 가능성 있음
  • Kubernetes/컨테이너 플랫폼 요건: ECR-014에서 "Kubernetes 또는 이에 준하는 컨테이너 기반 표준 환경", "RBAC", "표준 API 배포", "모델 레지스트리", "MCP 기반 외부 도구 연계" 등 OpenShift 생태계와 기능적 정합성이 높음
  • RFP 내 Red Hat 상용 제품 직접 명시 현황: 없음 (높음 판정 불가, 중간 유지)
