사업 개요 및 목적
  • 국회 정보시스템의 안정적 운영을 위해 내용연수가 도과하고 제조사 기술지원이 종료된 노후 장비(UNIX 서버 4식, 스토리지 1식 등)를 교체
  • 정전 등 비상상황 시 본회의 무중단 운영 체계 강화를 위해 본회의장 비상전원 시설(UPS 축전지) 증설
  • 정보시스템 성능 개선 및 보안취약점 대응을 위한 상용 S/W 업그레이드 및 확충
  • 노후 장비 교체에 따른 총 15개 정보시스템(의정지원시스템, 행정지원시스템 등) 이관 및 커스터마이징
  • 국회 업무 AI 전환의 일환으로 대국민서비스 한글 문서의 개방형 포맷(HWPX) 지원을 위한 상용 S/W 도입

Red Hat 제안
불가능 요소
  • 경쟁 제품 명시 여부: 서버관제 솔루션 요구사항(ECR-S/W-SSW-02)에서 모니터링 대상 OS로 "Linux(Rocky, RHEL, Ubuntu 등)"가 언급되나, 이는 솔루션이 지원해야 할 환경 목록이지 도입 OS를 Rocky·Ubuntu로 지정한 것이 아님. Red Hat 도입 자체를 배제하는 요소 없음.
  • S/W 미포함 여부: 해당 없음. 본 사업은 통합발주 S/W 납품이 핵심 범위에 포함됨.
  • 기타 제약: 20억 이상~40억 미만 사업으로 대기업 참여 제한 (Red Hat 파트너사 통한 공급 필요). 리스조건부 계약으로 분할납품 대가 및 기성대가 미지급 가능성 있음. Red Hat 직접 입찰 불가, SI 업체를 통한 공급 구조.
Red Hat 제안
가능 요소
  • RFP 명시 Red Hat 상용 제품 (통합발주 확정):
    • RedHat Linux Server — 17개 (통합발주, 직접구매 제외 사유: 기존 정보시스템 호환 불가)
    • RedHat Linux Virtual Datacenters — 18개 (통합발주, 동일 사유)
    • Red Hat Linux 35식 — 기존 라이선스 갱신 (ECR-S/W-SSW-01 명시)
  • 기존 Red Hat 스택 증설·갱신 확정: 직접구매 제외 사유로 "타 제품 도입 시 기존 정보시스템과 호환 불가"가 명시되어 있어, 국회 정보시스템이 Red Hat Linux 기반으로 운영 중임이 확인됨. 기존 도입 환경 유지 및 증설 수요 확정적.
  • UNIX 서버 4식 가상화 구성: 신규 UNIX 서버에 OS 포함 납품 요구 사항이 있으며, "필요 시 서버 사양 및 라이선스 적용 기준에 따라 상용 솔루션 라이선스를 적정 수량으로 확보" 명시 — 추가 RHEL 라이선스 제안 여지 존재.
  • Red Hat 기술 스택 적용 가능 영역: UNIX 가상화 서버 교체 환경에서 RHEL의 가상화 기능(KVM) 및 시스템 관리 자동화(Ansible) 추가 제안 가능. 서버 수 증가(269 Agent)에 따른 Satellite를 통한 패치·구독 관리 제안 여지 있음.
  • 영업 액션 포인트: 통합발주 수행 SI 업체 발굴 및 파트너십 연계 필수. RedHat Linux Server 17 + Virtual Datacenters 18 + 기존 갱신 35식으로 총 70식 규모의 확정 수주 기회.
