Red Hat 제안
불가능 요소
  • 신규 S/W 납품·구독 항목 없음: 본 사업은 순수 유지관리 용역으로, 신규 S/W 도입·납품·구매 항목이 전혀 없음. S/W 분리발주도 해당 없음으로 명시됨.
  • 경쟁 제품 명시: 기존 운영 대상 S/W에 Oracle Database Enterprise(RAC), VMware 가상화 솔루션이 명시되어 있음. 이는 Red Hat 경쟁 제품(Oracle DB, VMware vSphere 등)이 이미 운영 중임을 의미함.
  • WAS: JEUS 8 (티맥스소프트)이 기존 WAS로 명시되어 있어 JBoss EAP 도입 여지 없음.
  • WEB: WebtoB 5 (티맥스소프트)이 기존 웹서버로 명시되어 있어 대체 여지 없음.
  • Red Hat 제품명(RHEL, OpenShift, Ansible, JBoss EAP, Satellite 등) 전혀 미명시: RFP 전체에 걸쳐 Red Hat 상용 제품명이 단 한 건도 등장하지 않음.
  • 서버 OS 미명시: 유지관리 대상 서버 목록에 OS가 명시되어 있지 않으나, Oracle SPARC 서버(SPARC M12-2, SPARC S7-2) 및 IBM, Hitachi, HPE, Fujitsu 서버 등 다양한 플랫폼이 혼재되어 있어 RHEL 단일 환경이 아닌 것으로 추정됨. SPARC 플랫폼은 Solaris OS 운영 가능성이 높음.
  • 20억 미만 중소기업 사업: 대기업·중견기업 참여 불가로 Red Hat 직접 참여 불가 구조임.
Red Hat 제안
가능 요소
  • RFP에 명시된 Red Hat 제품명: 없음 — RFP 전체에 RHEL, OpenShift, Ansible, JBoss EAP, Satellite 등 Red Hat 상용 제품명이 전혀 등장하지 않음.
  • 간접적 제안 여지(매우 제한적): 센터시스템 내 Linux 계열 서버 존재 가능성이 있으나(Netis-SMS/NMS의 Windows/Linux Agent 라이선스 명시), 구체적 OS 명칭이 없어 직접적 RHEL 제안 근거로 활용하기 어려움.
  • 향후 사업 모니터링 가치: BIS 시스템 보강·확대구축 사업에 유지관리업체가 협조 의무가 있으므로, 차기 BIS 구축사업 발주 시 Red Hat 솔루션(RHEL, OpenShift 등) 제안 기회를 모색할 수 있음.
  • 결론: 현 사업은 신규 S/W 도입이 없는 순수 유지관리 용역이며, 기존 운영 환경에 Red Hat 상용 제품이 명시되지 않아 Red Hat 제안 가능성이 낮음. 차기 구축사업 또는 인프라 현대화 사업 시 접근 필요.
