사업 개요 및 목적
  • 국가데이터처가 운영하는 국가통계 마이크로데이터 통합서비스 시스템(MDIS) 및 관련 시스템(원격접근서비스 RAS, 통계데이터센터 SDC 등)의 안정적 운영·유지관리를 위한 사업

  • 2026년 MDIS·SDC 통합 포털 구축에 따른 신규 기능 안정화 지원
  • 마이크로데이터 서비스 무중단 운영 및 이용자 편의성 향상을 통한 마이크로데이터 이용 활성화 기여

Red Hat 제안
불가능 요소
  • 경쟁 제품 명시: Oracle 12C RAC (DBMS, 총 6식)가 기존 운용 DBMS로 명시되어 있어 Red Hat 대체 가능성 매우 낮음
  • 경쟁 가상화 제품 명시: RAS 가상화SW로 Citrix XenApp이 명시되어 있어 Red Hat Virtualization/OpenShift 제안 여지 없음
  • 신규 SW 납품 사업이 아님: 본 사업은 기 구축·운용 중인 시스템의 유지관리 용역 사업으로, 신규 SW 구독·도입 항목이 없음. 유지관리 대상 SW 목록 내 Red Hat 제품이 전혀 없음
  • SW 구성도 비공개: 마이크로데이터 통합서비스 시스템 SW 구성도가 보안상 비공개 처리되어 있어 전체 기술 스택 확인 불가. 기존 스택 교체 가능성 판단 어려움
  • Red Hat 상용 제품명 부재: RFP 전문 어디에도 RHEL, OpenShift, Ansible, JBoss EAP 등 Red Hat 상용 제품명이 전혀 언급되지 않음
Red Hat 제안
가능 요소
  • Linux 서버 운영환경: 기술적용계획표(붙임1)에서 서버용 운영체제 항목 중 "Linux ○(적용)" 으로 표기되어 있어, 운영 서버 일부가 Linux 기반임을 간접적으로 확인 가능. 다만 배포판은 명시되지 않음
  • Java 기반 응용시스템: 전자정부 표준프레임워크(Java 기반) 사용 명시. 이론적으로 JBoss EAP(WAS)나 Red Hat 미들웨어 제안 여지가 있으나, RFP에 WAS 제품명이 명시되지 않아 현재 사용 WAS 불명
  • RH 제품명 전혀 없음: RFP에 Red Hat(또는 동의어) 제품명·수량 명시 없음
  • 종합 평가: 상기 요소들은 제안 가능성을 입증하기에 불충분하며, Oracle DBMS·Citrix 가상화 등 경쟁 제품이 이미 운용 중이어서 Red Hat 제품 영업 기회 없음으로 판단됨
