Red Hat 제안
불가능 요소
  • Red Hat 상용 제품명 미명시: RFP 전체에 걸쳐 RHEL, OpenShift, Ansible, JBoss EAP 등 Red Hat 상용 제품이 구매·유지보수·도입 품목으로 명시되어 있지 않음
  • 경쟁·대체 OS 명시: 조정사건처리시스템 라이선스 갱신 목록(MPR-019)에 Rocky 9.6 OS 6식이 오픈소스 항목으로 명시됨 → Rocky Linux는 RHEL의 대체 무료 클론으로, RHEL 상용 도입 여지 제한
  • 오픈소스 DBMS 명시: MariaDB 10.11 LTS 2식이 오픈소스로 명시됨 → 상용 DBMS(Oracle 등)와 별도로 오픈소스 중심 구성 확인됨
  • 기존 가상화 환경: VMware vCenter 1식, vSphere Ent Plus 전체가 기술지원계약 대상으로 명시됨 → 기존 VMware 가상화 스택 운영 중으로 Red Hat Virtualization(RHEV) 또는 OpenShift 가상화 대체 제안 여지 제한
  • 순수 운영·유지관리 용역 성격: 본 사업은 소프트웨어 신규 통합발주(납품) 사업이 아닌 IT 아웃소싱 운영용역으로, 별도 상용 S/W 직접 구매보다는 기존 솔루션 기술지원계약(갱신) 위주로 구성됨
  • WEB/WAS 환경: DBMS/WEB/WAS 항목에 Oracle DBMS, Weblogic, Jeus, WebtoB, Tibero 등이 명시되어 있어 JBoss EAP 대체 제안 여지가 제한됨
  • 대기업 참여 제한: 매출액 8천억원 이상 대기업 수급 불가 조건이 있어 Red Hat Korea 직접 참여 불가 (파트너사를 통한 제안 필요)
Red Hat 제안
가능 요소
  • RFP 내 Red Hat 상용 제품 명시 없음 (JBoss, RHEL, OpenShift, Ansible 등 미기재)
  • Linux 운영환경 제안 여지: MPR-001에서 OS 유지보수 대상이 명시되어 있고, 플랫폼 및 기반구조 분야 기술적용계획표(별지 제12호)에 "Linux" 항목이 적용 대상으로 포함되어 있어, 현행 Linux 운영체제 환경에 대한 RHEL 제안 여지 존재
  • Rocky Linux → RHEL 전환 제안 가능: 조정사건처리시스템에 Rocky 9.6(RHEL 클론)이 사용 중이므로, 기술지원 한계를 강조하며 RHEL 상용 구독으로 전환 제안 가능 (Rocky는 Red Hat의 업스트림 기반으로 RHEL 마이그레이션 용이)
  • 자동화·운영효율화 제안 가능성: 29명 상주인력이 운영하는 복잡한 멀티시스템 환경(477개 자원)에서 Ansible Automation Platform을 통한 운영 자동화, 패치관리, 구성관리 등 효율화 솔루션 제안 가능
  • 컨테이너·클라우드 전환 지원: 정부 클라우드 전환 정책 지원이 명시되어 있고(기술적용계획표에 IaaS·PaaS·SaaS 항목 포함), 기존 클라우드(삼성SDS, 네이버 클라우드) 환경에 추가로 OpenShift 기반 컨테이너 플랫폼 제안 가능성 존재
  • vSphere 보완·전환 기회: 기존 VMware vSphere 환경 운영 중이나, VMware 라이선스 정책 변화(Broadcom 인수 후) 대응 맥락에서 OpenShift Virtualization 또는 RHEL 기반 KVM 가상화 대안 제안 가능
  • 파트너사 통한 간접 기회: 본 사업 수행 SI/운영사업자에게 RHEL 구독, Ansible 등 Red Hat 솔루션을 간접 제안하여 사업 수행에 활용하도록 유도 가능
  • ※ RFP 내 Red Hat 제품명·수량 명시 없음 — 상용 Red Hat 품목이 직접 기재된 사례 없음. 중간 판정 근거는 Linux 운영환경 및 클라우드 전환 제안 여지에 해당.
