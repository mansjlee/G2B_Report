불가능 요소
  • 본 사업은 H/W·S/W·설치·운영이 포함된 통합 용역으로, 핵심 S/W 3종(플랫폼·화상 Client·중계 플랫폼)은 조달쇼핑몰 직접구매 제외·통합발주 대상이며 Red Hat이 직접 S/W 공급자로 참여하기 어려움
  • 경로당 키오스크·여가기기 OS가 Android 7.0/10, Windows 11로 명시되어 RHEL 엣지 적용 대상 아님
  • VMware, Contrabass, Ubuntu, Oracle/Rocky Linux 등 경쟁 제품 직접 명시는 없으나, 기 구축 월성 스마트경로당 플랫폼·헬스케어 기기와 반드시 호환·연동 요구로 기존 벤더 종속 가능성 높음
  • 플랫폼 GS인증, 안면인식 전용 솔루션, 화상 MCU/중계 전용 솔루션 등 상용 패키지·자체 개발 중심으로 Red Hat 제품 직접 지정 없음
  • 중소기업·소상공인만 입찰 가능, 대기업·중견 SW사업자 참여 제한으로 Red Hat 직접 수주 불가
  • 전자정부표준프레임워크 기반 자체 플랫폼 개발 요구, 하도급 불허로 Red Hat이 하위 S/W 공급 구조 진입 제한
