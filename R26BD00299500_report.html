Red Hat 제안
불가능 요소
  • 신규 S/W 납품 없음: 본 사업은 기존 운영 중인 H/W 및 S/W에 대한 순수 유지관리·운영 용역으로, 신규 Red Hat 제품 납품·구독 갱신 발주 항목은 명시되어 있지 않음
  • VMware 기존 도입 확정: 가상화 플랫폼으로 VMware vSphere Standard 및 vCenter Server Standard가 이미 도입·운영 중이며, OpenShift 등 Red Hat 컨테이너 플랫폼 대체 여지 없음
  • Windows Server 환경 혼재: 가상화 OS로 Windows Server Datacenter 16식이 주요 운영 환경으로 명시되어 있어 RHEL 신규 도입 여지 제한적
  • 중소기업 제한 입찰: 대기업·중견기업 참여 불가 사업으로, Red Hat 코리아가 직접 입찰 불가 (SI 파트너사를 통한 간접 기회만 존재)
  • TMAX(JEUS/WEBTOB), Veritas, Oracle 등 타사 제품 명시: 해당 제품들에 대한 기술지원 확약서 제출이 필수 요건으로, 경쟁 미들웨어·백업 환경이 고정되어 있음
Red Hat 제안
가능 요소		 [RFP에 명시된 Red Hat 제품명 및 수량]
  • Red Hat Enterprise Linux Server, Standard (인증서 갱신): 1식 — [별첨1] 유지관리 대상 소프트웨어 목록 중 "가상화시스템" 항목에 "내부망 가상화 OS 서브스크립션 (Red Hat Enterprise Linux Server, Standard, 인증서 갱신 1식)"으로 명확히 기재됨
[제안 가능 포인트]
  • RHEL 유지보수 대상 명시 (높음 판정 근거): 별첨1에 "Red Hat Enterprise Linux Server, Standard, 인증서 갱신 1식"이 현행 유지관리 대상 S/W로 명시. 판정 규칙 1)-④에 따라 기존 운영 대상에 정확한 Red Hat 상용 제품명이 기재되어 있으므로 반드시 높음으로 판정
  • 구독 갱신 기회: 현재 운영 중인 RHEL Server Standard 구독(인증서 갱신)이 유지관리 범위에 포함되어 있어, 차기 계약 연도(2027~2028년) 구독 갱신 시 Red Hat 파트너사를 통한 구독 확장·업그레이드 기회 존재
  • Linux 가상머신 운영 환경: 내부망 가상화 서버(HPE DL380 G10)에서 VMware vSphere 위에 Linux 가상머신이 다수 운영 중. RHEL이 이미 1식 도입되어 있으며, 향후 추가 Linux VM 도입 시 RHEL 확장 제안 가능
  • Ansible Automation Platform 제안 여지: OS 보안 패치 적용, 가상머신 환경 구성 자동화, Help Desk 운영 효율화 등 반복 작업 자동화 필요성이 높아 Ansible 도입 추가 제안이 가능한 환경
  • 파트너사 협력 기회: 본 사업 낙찰 SI 업체가 RHEL 구독 갱신 및 유지관리를 위해 Red Hat 파트너사와 하도급 계약 체결 가능성 있음. Red Hat 코리아는 낙찰 SI 파트너 대상 영업 활동을 통해 간접 매출 기회 확보 필요
