레드햇 제안 가능성 중간
Linux 기술 적용 명시, OS 협의 가능
사업 개요 및 목적
  • 한국학중앙연구원 한국학대학원의 노후화된 학사행정시스템을 클라우드 기반 차세대 시스템으로 전면 재구축하는 사업 (2차년도)
  • 학적·수업·성적·장학·입시·기숙사·증명서 발급 등 학사행정 업무 전반을 통합한 차세대 학사행정시스템(ERP) 신규 구축
  • 기존 ERP(예산회계/급여/인사)와 포탈 시스템 간 SSO 연계 및 API 기반 데이터 연동 고도화
  • CSAP 인증 민간 클라우드(가비아 기반) 환경에 구축하여 안정적 운영 체계 마련
  • 기존 학사행정시스템 데이터(약 10~15년 분량) 이관 및 UI/UX 현대화를 통한 업무 효율화

    • 반응형 웹(노트북·태블릿 지원), 한/영 다국어, 사용자 맞춤형 대시보드·위젯 제공
    • 소프트웨어 개발보안(시큐어 코딩) 준수, 정적·동적 취약점 진단 2회 이상 실시
    • 라이선스 제한 없이 무제한 영구 사용 가능한 학사행정시스템 구축

Red Hat 제안
불가능 요소
  • Red Hat 상용 제품명 전무: RFP 전문에 RHEL, OpenShift, Ansible, JBoss EAP 등 Red Hat 상용 제품명이 단 한 건도 명시되지 않음
  • SI/개발 용역 중심 사업: 별도 OS·미들웨어 신규 구매 항목 없음. 핵심 S/W는 Oracle DBMS(기존 재활용)이며, Red Hat 제품이 납품 대상으로 지정되지 않음
  • Oracle DBMS 고정: Active/Standby 서버 모두 Oracle Standard DBMS 기존 라이선스 재활용을 명시(ECR-002), DBMS 교체 여지 없음
  • 기존 클라우드 인프라 환경 연속성: 1차 사업에서 가비아(CSP)를 선정하여 운영 중이며 2차 사업도 동 환경 기반으로 구성 — Red Hat 전용 플랫폼(RHOCP 등) 신규 도입 명시 없음
  • 경쟁 또는 대체 제품 확정: Oracle DBMS가 주요 인프라로 재활용 확정되어 있어 RDBMS 영역 Red Hat 진입 불가
Red Hat 제안
가능 요소
  • Linux 운영체제 기술 적용 계획 명시(○): 기술적용계획표(붙임 6호) 플랫폼 및 기반구조 분야에서 "Linux" 항목이 적용(○)으로 표시되어 있어, 서버 OS로 Linux 계열 채택이 전제됨 → RHEL 제안 여지 존재
  • OS·미들웨어 협의 구성 가능: ECR-002에서 "OS, DBMS 및 미들웨어는 기존 시스템을 고려하여 연구원과 협의하여 구성" 명시 — OS가 완전히 확정되지 않아 RHEL 제안·협의 가능
  • 클라우드 기반 시스템 신규 구축: CSAP 인증 민간 클라우드 환경에서 전면 재구축되는 시스템으로, 클라우드 네이티브 전환 맥락에서 RHEL, OpenShift 등 컨테이너 플랫폼 제안 논의 가능
  • 이중화·고가용성 요구: 클라우드 이중화(ECR-003), 365일 24시간 무중단 운영(QAR-001) 요건이 있어 RHEL의 엔터프라이즈 안정성·지원 체계를 영업 포인트로 활용 가능
  • RFP에 명시된 Red Hat 제품명·수량: 없음 (Red Hat 또는 동의어 제품 전혀 미기재)
  • 결론: Red Hat 상용 제품이 명시되지 않았으나, Linux OS 채택 전제 및 OS 협의 가능 조건으로 RHEL 제안 접근이 가능한 수준 (중간). 단, Oracle DBMS 재활용 고정 및 기존 가비아 CSP 환경 연속성으로 인해 적극적 판매 기회는 제한적임. SI 파트너사(사업 수행사)를 통한 RHEL 납품 협의 전략 권장
