Red Hat 제안
불가능 요소
  • Rocky Linux OS 확정 사용 (핵심 불가 요인): 운영체제로 CentOS, Windows Server, Rocky Linux가 명시되어 있으며, 특히 Rocky Linux는 Red Hat 판정 규칙상 경쟁·대체 제품(Ubuntu, Rocky, Oracle Linux 등)으로 분류됨. 이미 CentOS EOL 대안으로 Rocky를 선택한 상태로, RHEL 전환 여지가 사실상 차단됨
  • Red Hat 상용 제품 전무: RHEL, OpenShift, Ansible Automation Platform, JBoss EAP, Satellite, Quay 등 어떠한 Red Hat 상용 제품도 RFP 본문·통합발주 목록·상용SW 유지관리 목록·과업지시서에 단 한 건도 명시되지 않음
  • WAS 플랫폼이 티맥스 Jeus로 확정: WAS 2식이 티맥스 소프트 Jeus로 이미 구성되어 있으며, RFP의 개발 환경 기준에 "WebtoB, Jeus 기반의 Unix 웹어플리케이션"으로 명시됨. JBoss EAP/WildFly 기반의 Red Hat 미들웨어 제안 불가
  • DBMS가 비 Red Hat 제품: 티맥스 Tibero 3식·Oracle 1식으로 구성. Red Hat Data Grid·AMQ 등 Red Hat 데이터 플랫폼 제안 여지 없음
  • 순수 운영·유지관리 용역 성격: 본 사업은 기존 도입 시스템의 유지관리·운영지원 중심 용역이며, 신규 SW 통합발주 및 납품 계획이 명시되지 않음. 추가 S/W 구매 항목 없음
  • 중소기업 전용 입찰 구조: 대기업·중견기업 참여 제한 사업으로, Red Hat Korea가 직접적인 영향력을 행사하거나 공급망에 진입하기 어려운 구조
Red Hat 제안
가능 요소
  • CentOS EOL에 따른 RHEL 전환 가능성 (제한적): 현재 CentOS를 서버 OS로 운영 중이나 CentOS는 이미 EOL 상태. 유지관리 기간 중 OS 마이그레이션 검토 시 RHEL 제안 여지가 이론적으로 존재. 다만, 이미 Rocky Linux를 대체재로 채택한 정황이 명확하여 실질적 전환 가능성은 낮음
  • 인프라 OS 업그레이드·마이그레이션 지원 요구: MAR-008, MAR-011 요구사항에 "OS 업그레이드, 그에 따르는 Migration 지원"이 명시되어 있어, 차기 사업 또는 별도 구축 사업 연계 시 RHEL 제안을 위한 관계 구축 발판으로 활용 가능
  • 클라우드 전환 연계 기회 (PSR-008): 온프레미스 환경의 클라우드 전환 후 DR 활용성 검토 요구사항(PSR-008) 존재. 향후 클라우드 전환 사업 추진 시 OpenShift 또는 RHEL 기반 플랫폼 제안을 위한 사전 포지셔닝 기회로 활용 가능
  • RFP 내 Red Hat(동의어 포함) 제품 명시 현황: 없음 — RHEL, Red Hat, OpenShift, Ansible, JBoss EAP, Satellite 등 Red Hat 상용 제품명 및 동의어가 RFP 전체에서 단 한 건도 확인되지 않음
