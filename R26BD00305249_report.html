Red Hat 제안
불가능 요소
  • Red Hat 상용 제품명 전무: RFP 본문 어디에도 RHEL, OpenShift, Ansible, JBoss 등 Red Hat 상용 제품명이 명시되어 있지 않음
  • 통합발주 S/W 목록 미제공: 과업지시서(별책)가 제공되지 않아 구체적인 통합발주 S/W 품목 및 수량을 확인할 수 없으며, 현재 확인 가능한 범위에서는 Red Hat 제품 도입 근거 없음
  • 경쟁 제품 명시 없음(우호적 요소 아님): Ubuntu, Oracle Linux, Rocky Linux, VMware 등 경쟁 제품도 명시되지 않았으나, Red Hat 제품도 명시되지 않아 제안 근거가 약함
  • SI·개발 용역 중심 사업: 피지컬AI 로봇, 주차 플랫폼, 빅데이터 플랫폼 개발 위주의 SI 사업으로, 특정 상용 OS·미들웨어 도입이 주목적이 아님
  • 중소기업 제한 사업: 대기업 및 대기업 계열사 입찰 참여 제한 적용으로 Red Hat코리아 직접 참여 불가, SI 파트너를 통한 간접 제안만 가능
  • 기술적용계획표의 OS 항목: Linux, Windows Server, UNIX 등이 일반 항목으로 나열되어 있을 뿐, 특정 상용 Linux 배포판 지정 없음
Red Hat 제안
가능 요소
  • RFP 내 Red Hat 제품명 명시 없음: 현재 제공된 텍스트 범위에서 RHEL, OpenShift, JBoss EAP, Ansible 등 Red Hat 상용 제품이 도입 품목으로 명시된 사례 없음
  • Linux 서버 OS 적용 가능성(간접): 기술적용계획표에 "Linux" 항목이 서버용 개방형 운영체제로 포함되어 있어, SI 파트너가 RHEL을 선택하도록 간접 제안 여지는 존재하나 확정 근거 없음
  • 빅데이터 플랫폼·컨테이너 활용 가능성: 빅데이터 통합플랫폼 구축 과업 특성상 Kubernetes/컨테이너 기반 아키텍처 채택 가능성이 있으나, OpenShift 명시 없음
  • Ansible 자동화 제안 여지: 다수 현장 장비(로봇, 주차 단말, CCTV 등)의 구성관리·자동화 필요성이 있어 Ansible 제안 여지가 이론적으로 존재하나, RFP에 명시되지 않음
  • ※ 종합적으로, 과업지시서(별책) 미제공으로 인해 통합발주 S/W 목록을 확인할 수 없는 상태이며, 별책 과업지시서에 Red Hat 상용 제품이 명시되어 있을 경우 제안 가능성 판정이 변경될 수 있음. 과업지시서 확보 후 재검토 권장.
