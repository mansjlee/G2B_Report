불가능 요소
  • 본 사업은 RHEL·OpenShift·Ansible 등 상용 S/W 조달·공급이 아닌 맞춤형 포털·Agent SW 설계·구축·연계 용역 중심임
  • MLOps·AgentOps·DevOps·DataOps·LLMOps·AI Agent 관리 솔루션은 별도 오픈 플랫폼 사업에서 이미 구축·제공 예정이며, 본 RFP는 해당 플랫폼과의 API·SSO 연계가 과업 범위임
  • 벡터DB·임베딩 모델은 「오픈소스·오픈플랫폼 제공 모델 우선 검토」로 명시되어 Red Hat 전용 스택 지정 없음
  • VMware, Ubuntu, Oracle, Rocky Linux 등 경쟁·대체 OS/가상화 제품은 명시되지 않았으나, 인프라·플랫폼 제품 선정 권한도 본 과업 범위에 포함되지 않음
  • 주관기관 ㈜카카오엔터프라이즈 주도 AI 플랫폼·클라우드 생태계 사업으로, Red Hat 제품을 직접 지명·구매하는 구조가 아님
  • 대기업 Red Hat은 「소프트웨어산업진흥법」에 따른 대기업 입찰 참가 제한 대상이며, 본 입찰은 중소 SW 사업자 대상임

  • 하도급(50% 이내·사전승인) 또는 중소 SI·공동수급체 파트너로서 인프라·플랫폼 기술자문·연계 표준(INR-005) 지원 역할은 가능하나, 원도급 Red Hat 직접 수주 구조는 아님
  • AI Agent·MLOps 연계, REST API 표준화(SFR-028), 장애 대응·운영 자동화(QUR-004) 요구와 Ansible·OpenShift GitOps 운영 모델의 개념적 정합성은 있으나 RFP상 필수 지정 기술은 아님
