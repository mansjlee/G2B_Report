S/W 미포함 유지관리 용역
사업 개요 및 목적
  • 시민 안전 확보를 위해 정읍시 관내 CCTV와 통합관제센터 시스템을 24시간 무중단으로 운영하고, 사전 예방 중심의 체계적인 유지관리를 추진함
  • 장애 발생 시 신속히 대응·복구하여 365일 중단 없는 시스템 운영을 보장함
  • 통합관제센터 HW·SW와 현장 방범 CCTV 5,042개소를 유지관리하고, 상주인력 4명과 절연고소작업차량 1대를 운영함
주요 정보
  • 사업 예산: 금 547,868,000원(부가가치세 포함). 회계연도 개시 전 계약이며, 확정예산 범위 내에서 계약금액을 조정할 수 있음
  • 사업 기간: 2027. 1. 1 ~ 2027. 12. 31 (12개월)
  • 사업 범위:
    • 통합관제센터 HW 유지관리
      • 서버: 영상중계·스트리밍 서버 3대, 가상화 서버 5대, GIS·GPS 서버, DMZ 웹서버, LoRa 자가망 서버 등
      • 상황판: DID 18대, IP WALL 1대
      • 스토리지: DELL·히다찌·IBM 1,128TB, SAN 스위치 2대
      • 네트워크·보안장비: 백본·L3·L2 스위치, LoRa 게이트웨이 34대, 망연계장치 3대, VPN 2대, 방화벽 6대, NAC 1식
    • 통합관제센터 SW 유지관리: 영상통합관제솔루션, GIS, 통합플랫폼 등
    • 현장 CCTV 5,042개소 유지관리: 생활방범 1,201, 차량번호판독 100, 마을방범 3,741
    • 상주인력 4명(중급 1, 초급 3) 운영
    • 정기·비정기 점검, 장애처리, 예비품 확보(CCTV 카메라 25대 이상)

    • 2026년 12월: 제안서 평가, 사업자 선정, 협상 및 계약
    • 2027년 1월 ~ 12월: 유지관리 수행

핵심 요구사항

  • HW 운영관리
    • 서버·스토리지·상황판·네트워크 장애를 처리해야 함
    • 운영체제 재설치·복원, 최신 패치·펌웨어 업그레이드, 보안장비 정책 DB 업데이트를 수행해야 함
  • SW 운영관리
    • SW 재설치·업그레이드, 버그 수정, 기능개선을 지원해야 함
    • GIS·DB·영상반출시스템 장애를 처리하고, DBMS 백업·복구를 지원해야 함
  • 통합플랫폼
    • 5대 연계서비스를 안정적으로 운영해야 함
    • 클라우드 시스템에 추가 솔루션을 연계할 때 지원해야 함
  • 보안

    • 방화벽 정책의 적정성을 진단해야 함
    • 원격작업은 금지됨
  • 인력·자격 요건
    • 정보통신공사업 등록 및 SW사업자여야 함
    • 중소기업으로서 직접생산확인증명서(정보시스템 유지관리 서비스)를 보유해야 함
    • 상주인력 4명이 필요함
    • 계약 시 제조사·공급사의 기술지원확약서를 제출해야 함
  • 구매 명시 S/W(통합발주): 해당 없음. 신규 구매·납품 S/W가 없으며, 아래 S/W는 기존 시스템의 유지관리 대상임
    • 영상통합관제솔루션 1식 (메인, 클라이언트 소프트웨어)
    • GIS(Web 포함) 소프트웨어 1식
    • 방범용 CCTV 관리시스템 SW 1식
    • LoRa 자가망 구축 및 마을방범 관제서비스 1식
    • TTA 성능인증 통합플랫폼 1식
    • 영상중계용(RTSP 포함) 소프트웨어 1식
    • 경찰청 스트리밍 서버 소프트웨어 1식
    • 스마트도시안전망 서비스 1식
Red Hat 제안
불가능 요소
  • S/W 공급 미포함: 기존 통합관제센터와 현장 CCTV의 유지관리 용역만 포함되며, 신규 S/W 구매·구독 항목이 없음
  • 경쟁 제품 명시 여부: VMware, Ubuntu, Rocky/Oracle Linux 등 경쟁 OS나 가상화 제품명은 명시되지 않음. 다만 기존 가상화 서버 5대의 하이퍼바이저와 OS가 이미 운영 중이어서 교체 여지는 제한적임
  • 참여 제한
    • 사업금액이 20억원 미만이어서 대기업 및 상호출자제한기업집단은 참여할 수 없음
    • 중소기업 직접생산확인 요건이 있음
    • 하도급이 불허됨
  • 평가 구조: 사업 성격이 현장 CCTV 하드웨어 유지보수 중심(고소작업차, 카메라 예비품 등)이며, 평가도 유지관리 실적과 인력 위주임
  • 기술지원 체계 고정: 기존 제조사·공급사와의 기술지원 협약 체계를 유지하는 구조여서 신규 플랫폼을 도입할 근거가 없음
Red Hat 제안
가능 요소
  • RFP 내 Red Hat(동의어) 제품명·수량: 없음
  • 가상화 서버 5대: 향후 노후 장비 교체나 고도화 사업이 추진될 경우 OpenShift Virtualization과 RHEL 기반 전환을 제안할 수 있는 잠재 기회임
  • 클라우드 연계·통합플랫폼 확장: 클라우드 시스템 연계와 확대 서비스 구성 요구가 있어, 차기 스마트도시 통합플랫폼 고도화 시 OpenShift 기반 컨테이너 플랫폼을 제안할 수 있음
  • OS 패치·취약점 진단 요구: 운영 자동화 측면에서 Ansible Automation Platform과 Satellite가 강점과 부합함. 다만 본 용역 범위에서 별도 구매가 이루어질 가능성은 낮음
  • 영업 활동 제안: 정읍시 정보통신과 통합관제팀과 관계를 형성하고, 향후 통합관제센터 고도화·재구축 사업 정보를 선제적으로 확보하는 것이 바람직함
