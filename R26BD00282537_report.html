  • 2027년 경제총조사 자료처리 확정 공표 및 경제통계 연간조사(광업제조업·서비스업·운수업·기업활동조사) 본조사 시스템의 성공적 운영 지원
  • 전국사업체조사 자료처리 시스템을 경제총조사 통합시스템으로 이관하여 자료처리 효율성 제고

가능 요소
  • 클라우드네이티브 아키텍처 명시: RFP에서 "클라우드네이티브(컨테이너 기반, MSA, 배포 자동화(CI/CD))"를 추진 목표로 명시 → OpenShift Container Platform 제안 기회

  • PaaS 적용 계획 명시: 기술적용계획표에 PaaS ○(적용)로 명시 → OpenShift 기반 PaaS 플랫폼 제안 가능
  • Java 기반 애플리케이션: Java/JSP, 전자정부 표준프레임워크 기반 시스템 → JBoss EAP 애플리케이션 서버 제안 여지
  • 컨테이너 운영(VM·POD): MPR-007에서 VM/POD 기반 상용SW 설치 조건 언급 → 컨테이너 플랫폼(OpenShift) 및 Ansible Automation Platform(배포 자동화) 제안 가능
  • 자동화·CI/CD 요구: 배포 자동화(CI/CD) 기술 요구 → Ansible Automation Platform, OpenShift Pipelines 제안 기회
