사업 개요 및 목적
  • 농촌진흥청 농업지능데이터팀이 운영하는 농업기술 데이터 플랫폼의 유지관리 및 데이터 지원센터를 2027년도에 운영하는 사업
  • 국가연구데이터법 제정('26.6) 및 범정부 AI 대전환(AX) 기조에 대응하여 국가 농업 데이터 허브 역할 수행
  • 핵심 목표: ① 수요 중심 고가치 농업 데이터 발굴·개방, ② LLM 기반 AI 지능형 검색·전처리 서비스 구현, ③ 농업 재배 전주기 DB 품질검증 자동화, ④ 플랫폼 안정적 운영 및 농업 데이터 지원센터 운영
  • 오픈소스 Kubernetes의 보안 취약점 문제를 해결하기 위해 상용 솔루션으로 전환하고, 삼성SCP 클라우드 V1→V2 전환을 지원

Red Hat 제안
불가능 요소
  • Red Hat 상용 제품 미명시: RHEL, OpenShift, JBoss EAP, Ansible Automation Platform 등 Red Hat 상용 제품이 도입·납품·구매 품목으로 단 한 건도 명시되지 않음
  • JBoss는 오픈소스로 분류: RFP 내 JBoss는 공개SW(오픈소스) 항목에 "Apache, JBoss, Tomcat, Nginx, PostgreSQL 등 오픈소스"로 분류되어 있어, 상용 JBoss EAP 구매 근거가 없음
  • 소프트웨어 직접발주 해당 없음: RFP에 "소프트웨어 직접발주: 해당 없음"이 명시되어 별도 SW 직접 구매 계획 없음
  • 클라우드 IaaS 전환 방향: 오픈소스 K8s 전환 목적지가 "클라우드 IaaS"로 명시되어 있어 OpenShift On-Premise 납품 기회 제한적이며, 삼성SCP 클라우드 종속 환경
  • 기존 상용SW 생태계 고정: Brightics, Bandi SSO, GeOnPaas, Konan Search 등 타 벤더 상용SW 7종이 이미 도입되어 있어 Red Hat 솔루션 대체 진입 어려움
  • 하도급 불허: Red Hat이 SI·파트너사를 통해 참여할 여지 축소
Red Hat 제안
가능 요소
  • [OpenShift 제안 핵심 기회] K8s 상용 솔루션 전환: RFP에 "오픈소스 쿠버네티스를 전문 상용 솔루션으로 전환 운영"이 명시되어 있으며, OpenShift Container Platform(OCP)이 가장 직접적인 상용 Kubernetes 솔루션 후보임. 비용 절감(서버 6→3대) 효과도 OpenShift의 운영 효율화로 어필 가능
  • [RHEL 제안 가능] Linux 서버 환경: 기술적용계획표에 Linux 서버 운영체제 적용이 명시되어 있으며, OS 브랜드 미지정 상태로 RHEL 제안 가능. 보안 패치 통제 가능한 엔터프라이즈 OS로의 전환 수요와 일치
  • [Ansible 제안 가능] 데이터 처리 파이프라인 자동화: AirFlow(131건), NiFi(186건), Wrangler(36건) 등 대규모 데이터 처리 마이그레이션 및 인프라 자동화 작업에 Ansible Automation Platform(AAP) 제안 가능
  • [컨테이너 보안] 보안 강화 요구사항: 오픈소스 K8s의 보안 취약점 문제가 전환 이유로 명시되어 있어, OpenShift의 내장 보안 기능(ACS, 이미지 스캔, RBAC 등) 및 Red Hat Advanced Cluster Security 제안 가능
  • [Podman/컨테이너] Docker 대체: Docker(Portainer 포함)가 공개SW로 운영 중이나, 보안 강화 기조에 맞춰 Podman(rootless 컨테이너) 전환 제안 가능
  • RFP 내 Red Hat(동의어) 제품 명시: 없음 (상용 Red Hat 제품 미명시)
