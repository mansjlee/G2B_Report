  • SLA 기반의 정량적 서비스 수준 관리 및 보안 취약점 대응 포함

Red Hat 제안
불가능 요소
  • 신규 S/W 납품 없음: 본 사업은 순수 유지보수·운영 용역으로, 신규 Red Hat 상용 제품의 납품·구독·증설 항목이 RFP 어디에도 명시되어 있지 않음
  • Red Hat 상용 제품명 미명시: RHEL, OpenShift, Ansible, JBoss EAP 등 Red Hat 상용 제품명이 유지보수 대상 SW 목록, 현행 시스템 구성 등 문서 전반에 걸쳐 전혀 등장하지 않음
  • 경쟁·대체 제품 환경 존재: 상주인력 자격 조건에 VMware 가상화 자격증이 명시되어 있어 VMware 기반 가상화 환경이 운영 중임을 시사함
  • DBMS는 Informix 명시: DBMS 유지보수 대상이 IBM Informix로 특정되어 있어 Red Hat 관련 DBMS 제안 여지 없음
  • HW 기술지원확약서 대상이 IBM·DellEMC·Cisco 중심: SW 계열 기술지원확약서 제출 대상은 없음(HW만 해당)으로 명시되어, Red Hat SW 제품 도입 근거가 없음
  • 중소기업 참여 사업: 대기업·중견기업 소프트웨어사업자 참여 불가 조건이 있어, Red Hat 코리아가 직접 입찰하기 어려운 구조
Red Hat 제안
가능 요소
  • Linux 서버 운영 환경 명시: RFP에 "서버(Unix, Linux, NT)는 천안(본원)에서 운영"이라고 명시되어 있으며, 상주인력 자격 조건에 "AIX, Unix, Linux, NT 서버 관리" 경력이 요구됨 → Linux 계열 서버가 운영 중임이 확인되어 RHEL 도입·전환 제안 여지 존재
  • OS 패치·업그레이드 지원 과업 포함: MPR-011에 "운영체제(OS)에 대한 Patch Release 수준의 Upgrade 지원(보안 Patch 포함)"이 명시되어 있어, OS 버전 업그레이드 시 RHEL 구독 갱신·전환 제안 가능
  • WAS 유지보수 대상 포함: MPR-012에 System S/W 종류로 WAS가 명시되어 있음. WAS 환경에 따라 JBoss EAP 도입 제안 가능성 검토 여지 있음(단, 현재 운영 중인 WAS 제품명은 불명확)
  • 컨테이너·자동화 추가 제안 가능: 제안서 평가 항목 중 "추가 제안(7점)"이 별도 항목으로 존재하며, 정보시스템 운영체계 고도화 방안 제안이 권장됨 → OpenShift, Ansible Automation Platform 기반의 운영 자동화·컨테이너 전환 로드맵을 추가 제안으로 제시 가능
  • RFP에 명시된 Red Hat(동의어 포함) 제품명·수량: 없음 (문서 전체에서 Red Hat, RHEL, OpenShift, Ansible, JBoss 등 상용 제품명 미발견)
  • 파트너 협력 기회: 본 사업은 중소 SW사업자 참여 사업으로, Red Hat 파트너사(중소기업)가 입찰 참여 시 RHEL·Ansible 등을 활용한 운영 자동화·보안 강화 방안을 차별화 요소로 제시 가능
