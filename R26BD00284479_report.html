Red Hat 제안
불가능 요소
  • [Red Hat 상용 제품 미명시]: 별첨10 상용SW 37종 목록 어디에도 RHEL, OpenShift, Ansible, JBoss EAP 등 Red Hat 상용 제품이 포함되어 있지 않음. 구독 갱신 대상도 MapR·Elasticsearch에 한정
  • [경쟁 OS 사용 징후]: 월간 운영보고서 표준안(별첨11-6) 작성 예시의 SW 구성 현황표에 Rocky Linux가 WAS·WEB·DB 서버의 OS로 표기되어 있어 현행 시스템이 Rocky Linux 기반일 가능성 있음
  • [기존 플랫폼 스택 고착화]: Hadoop(MapR), Elasticsearch, RPA, DRM 등 타 벤더 솔루션 중심으로 이미 구성·운영 중이며, 이번 사업은 신규 구축이 아닌 유지관리 사업으로 플랫폼 교체 수요 낮음
  • [입찰 참여 제한]: 사업금액 20억 미만으로 대기업·중견기업 참여 불가 (중소SW사업자 전용) — Red Hat Korea가 직접 입찰하는 구조 아님 (단, 제안기회 자체가 없는 것은 아님)
  • [컨테이너 플랫폼 기도입]: 클라우드 플랫폼 SW가 2020년(1식)·2022년(9식) 이미 도입되어 있어 OpenShift로의 신규 교체 여지 제한적

가능 요소
  • [Kubernetes/컨테이너 환경]: RFP 본문에 "Kubernates 기반 컨테이너 등 클라우드 환경에 분석모델 배치, API 서비스, Python 셀프분석 환경 제공"이 명시되어 있어 OpenShift Container Platform 제안 기반이 존재함
  • [클라우드 플랫폼 구독 유지]: 별첨10에 클라우드 플랫폼 SW가 2020년(1식) 및 2022년(9식) 도입되어 있으며, 유지관리 기간 내 구독 갱신 필요 — 차기 사업 또는 이번 갱신 시 OpenShift 전환·업셀 기회 존재
  • [AI·빅데이터 워크로드]: 32개 분석모델(AI OCR, 머신러닝, 데이터마이닝 등)이 운영 중으로 OpenShift AI / RHEL AI 솔루션의 기술적 적합성 확보 가능
  • [자동화 운영 요구]: 24시간 무중단 운영, 정기·비정기 예방점검, 장애자동감지 체계 요구 → Ansible Automation Platform(AAP)을 통한 운영 자동화 제안 여지
  • [Linux OS 기반 서버 환경]: 별첨10 SW 목록에 OS가 명시되지 않아 현행 OS 교체 또는 병행 도입 시 RHEL 제안 가능성 있음 (Rocky Linux → RHEL 전환 제안 가능)
  • [RFP 내 Red Hat 제품 직접 언급 없음]: 별첨10 및 본문 전체에 Red Hat 상용 제품명(RHEL, OCP, Ansible, JBoss 등)은 명시되어 있지 않음
