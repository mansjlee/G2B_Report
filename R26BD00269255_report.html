Red Hat 제안
불가능 요소
  • [경쟁 제품 명시] VMware vSphere 6 Standard 10식 및 VMware vCenter Server 6 Standard 1식이 가상화 SW로 현재 운영 중이며, 유지관리 대상으로 명시됨 → OpenShift Virtualization, RHEV 제안 여지 없음
  • [국산 SW 스택 고착] WAS는 Jeus v8, Web 서버는 WebtoB v5, DBMS는 Tibero v6로 구성되어 JBoss EAP, RHEL-based 오픈소스 전환 여지 없음
  • [유지관리 용역 성격] 본 사업은 기존 시스템의 유지관리가 목적으로, 신규 SW 구매·납품·증설보다는 기존 라이선스에 대한 점검·패치·장애처리 지원이 핵심임 → 신규 Red Hat 제품 추가 도입 기회는 제한적
  • [Ansible·OpenShift 적용 여지 없음] 컨테이너, Kubernetes, 자동화 플랫폼 관련 요구사항 없음
Red Hat 제안
가능 요소
  • [RFP 명시 Red Hat 상용 제품]
    • Red Hat Enterprise Linux Server, Standard (1-2 sockets) 8식 — 중요SW로 분류, 상용 소프트웨어 현황표에 명시, 유지관리 의무 대상
  • [RHEL 유지관리 기회] RHEL 8식이 "중요SW 해당"으로 분류되어 현장 방문 정기점검(MAR-004 준수) 의무가 있음 → Red Hat 또는 공식 파트너를 통한 RHEL 유지관리 서비스(서브스크립션 갱신, 패치·업그레이드 지원) 제안 가능
  • [서브스크립션 갱신 영업 기회] 현재 RHEL Standard 서브스크립션 8식이 운영 중이며, 2027~2028년 사업 기간 내 서브스크립션 만료 시점이 도래할 경우 갱신 영업 연계 가능
  • [SI 사업자 대상 파트너 협력] 본 사업은 시스템 통합사업자(SI)가 낙찰받아 RHEL 유지관리를 수행하는 구조이므로, Red Hat 파트너 또는 공인 유지보수 채널을 통해 사업자에게 RHEL 서비스 제공 가능
