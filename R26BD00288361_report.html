Red Hat 제안
불가능 요소
  • Red Hat 상용 제품명 미명시: RFP 전체 문서에 RHEL, OpenShift, Ansible, JBoss EAP 등 Red Hat 상용 제품명이 구매 품목으로 일절 명시되어 있지 않음
  • 신규 SW 납품·도입 사업 아님: 사업의 핵심은 기존 시스템의 유지관리(응용SW·상용SW·HW) 및 기술지원으로, 신규 상용SW 도입·납품이 사업의 주목적이 아님 — 라이선스 리뉴얼은 기존 제품 2식(모바일백신 등)에 한정
  • 상용SW 목록 비공개: 행정안전부 고시 제17조에 따라 27종 111식 상용SW 전체 목록이 비공개 처리되어 있어 경쟁 제품(Ubuntu, Rocky Linux, VMware 등) 포함 여부도 확인 불가하나, 반대로 Red Hat 제품 포함 여부도 확인 불가한 구조임
  • 인프라 운영 주체 분리: HW, NW, 시스템SW(WEB·WAS·DB)는 국가정보자원관리원(G클라우드) 소관으로 본 사업자가 직접 관여하지 않음 — OS 레벨 Red Hat 제품 신규 제안 여지 제한
  • 경쟁 제품 명시 없음 (단, 대체 여지도 제한): VMware, Ubuntu, Oracle Linux 등 특정 경쟁 제품명은 명시되지 않았으나, 기존 운영 환경을 그대로 유지하는 유지관리 사업 특성상 신규 플랫폼 전환 제안은 현실적으로 어려움
Red Hat 제안
가능 요소
  • 상용SW 27종 111식 비공개 목록 내 Red Hat 제품 포함 가능성: 현행 시스템 구성도·소프트웨어 구성도·HW 구성도가 모두 보안 지침에 따라 비공개 처리됨. 사업자가 보안서약서 제출 후 열람 가능한 목록에 RHEL, JBoss EAP, Ansible 등이 포함되어 있을 가능성이 있으며, 실사 후 확인 시 "높음"으로 상향 가능
  • Linux 서버 환경 적용 확인: 기술적용계획표(별첨6)에서 서버용 운영체제로 Linux(POSIX.0, UNIX, Windows Server, Linux 모두 적용 표시)가 명시되어 있어, 현재 운영 중인 Linux OS가 RHEL일 경우 유지관리 계약 기회 존재
  • G클라우드 환경 변화 대응 기술지원 요구: 국가정보자원관리원 운영 환경 변화(장비, OS, DBMS 교체·업그레이드·이전) 시 기술지원이 요구사항으로 명시되어 있어, 현행 OS가 RHEL인 경우 기술지원 협력 기회
  • Java 기반 WAS 환경: 전자정부 표준프레임워크(Java), RDBMS 환경으로 운영되는 시스템으로, WAS 레이어에 JBoss EAP가 활용될 경우 유지보수 계약 기회
  • AI 기반 KRMS 고도화 지원: AI 정부 실험실 모델 활용 PoC 구현 지원이 명시되어 있어, 향후 컨테이너·AI 플랫폼(OpenShift AI, RHEL AI) 확장 제안 연계 가능
  • 클라우드(IaaS·PaaS) 환경 적용: 기술적용계획표에서 IaaS·PaaS 클라우드 적용이 명시되어 있어 OpenShift 기반 컨테이너 플랫폼 제안 여지 있음
  • RFP 내 Red Hat 제품명 직접 명시 없음: 문서상 Red Hat 상용 제품(RHEL, OCP, AAP, JBoss EAP 등)은 명시되지 않음 — 비공개 목록 확인 전까지 "중간" 판정 유지
