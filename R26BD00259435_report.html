사업 개요 및 목적
  • 한국교육학술정보원(KERIS)이 운영하는 교원 대상 실시간 온라인 지식 공유·연수 플랫폼 「디지털 지식샘터」(educator.edunet.net)의 기능 고도화 사업
  • 현장 교원의 AI 활용 수업 역량 강화를 위한 사용자 중심 서비스 환경 개선
  • 동영상 스트리밍·학습관리(LMS) 기능 구현, 데이터 관리 구조 개선·DB 재설계·이관을 통한 확장성·안정성 확보
  • 17개 시·도교육청 소속 초·중등 교원 대상 실시간 온라인 연수 지원 시스템으로, 유지관리·클라우드 임차 사업자와 협력하여 수행

  • 인프라·플랫폼 레이어 접근 제한: H/W·S/W 구성도 비공개(방문 열람), 클라우드 환경은 기존 임차 사업자 관리. 사업 수행사는 응용 계층 고도화에 집중

  • 기타: 중소 SW사업자·직접생산증명 대상 정보시스템개발서비스 사업으로, Red Hat 구독·인프라 공급보다 커스텀 개발 역량이 핵심 평가 항목(기능·보안·데이터·성능 90%)
Red Hat 제안
가능 요소
  • 간접 제안(파트너/SI 협력): 입찰·제안 주체(SI)의 기술 아키텍처·운영 자동화 제안서에 Red Hat 솔루션을 포함하는 간접 영업 형태는 가능. 단 본 계약의 직접 납품 항목은 아님
  • RHEL: 기술적용계획표에 Linux·POSIX 서버 OS 일반 항목 명시. 클라우드 VM OS 또는 WAS/DB 서버 OS 후보로 RHEL 제안 가능(특정 OS 종속 금지 조건 내)
  • Ansible: QUR-004 장애대응 요구의 「운영·관리, 배포 자동화, 오토 스케일링」 및 PMR-006 클라우드 개발환경 구축 요건과 부합. CI/CD·설정관리·장애복구 자동화 제안 포인트
  • OpenShift: FUR-004·PER-002의 클라우드 적합 구조·모듈화·탄력적 확장(동시 3만명) 요건에 컨테이너 기반 마이크로서비스 아키텍처를 제안할 경우 PaaS 레이어로 OpenShift 언급 가능
  • 보안·컴플라이언스: SER-001~014 광범위한 보안·개인정보 요건, Linux 서버 보안 강화(RHEL SELinux, FIPS 등), 컨테이너 보안(OpenShift) 강점 활용 여지
  • JBoss/EAP: 전자정부 표준프레임워크(Java) 기반 개발 제약과 RESTful API 연계 요건으로 Middleware 레이어 제안 가능성은 있으나, RFP상 WAS 제품 지정·구매 없음
