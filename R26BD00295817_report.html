Red Hat 제안
불가능 요소
  • S/W 신규 구매·납품 항목 없음: 본 사업은 소프트웨어영향평가서상 "소프트웨어 변경이 없는 운영사업(⑥)"으로 분류된 순수 운영·유지관리 용역이며, Red Hat 상용 제품의 신규 구매·도입·납품·구독 항목이 전혀 없음
  • RFP 전반에 Red Hat 상용 제품명 미기재: RHEL, OpenShift, Ansible, JBoss EAP, Satellite 등 Red Hat 상용 제품명이 현행 시스템 구성, 유지관리 대상 S/W 목록, 운영 환경 어디에도 명시되지 않음
  • OS 환경 불특정: 시스템 운영 환경에서 OS는 "x86 서버기반, 웹기반"으로만 기술되어 있으며, 운영체제는 Windows Server 4식만 상용S/W로 명시. Linux/RHEL 도입 여부 불명확
  • WAS 환경 불특정: 웹와스(WEB, WAS) 12식이 유지관리 대상이나 제품명이 명시되지 않아 JBoss EAP 여부 확인 불가. "JBoss"라는 명칭 자체가 RFP 전문에 등장하지 않음
  • 경쟁 제품 존재 가능성: 운영체제 상용S/W로 "Windows Server" 4식이 명시되어 있으며, DBMS는 Oracle 계열 사용 추정 (오라클 버전 업그레이드에 따른 DB 이관 과업 명시)
  • 중소기업 전용 사업: 대기업·중견기업 입찰 불가 사업으로, Red Hat 코리아가 직접 참여하거나 대기업 SI를 통한 간접 채널 활용도 제한됨
  • 일반 문구만 존재: "레드햇", "Red Hat", "Linux", "오픈소스" 등의 일반 문구도 RFP 본문에서 확인되지 않음 (웹로그 분석기 오픈소스 도입 조항 MAR-003 제외)
Red Hat 제안
가능 요소
  • [RFP 내 Red Hat 제품명·수량]: 없음 — RFP 전문 어디에도 RHEL, OpenShift, Ansible, JBoss, Satellite 등 Red Hat 상용 제품명이 명시되지 않음
  • [잠재적 제안 여지 — 매우 제한적]
    • 기술적용계획표에 "Linux" 서버 운영체제가 적용 가능 항목으로 체크되어 있어, 현재 시스템에 Linux 계열 OS가 활용될 가능성 존재 — 단, RHEL 사용 여부 확인 불가
    • 웹와스(WEB/WAS) 12식의 제품명이 비공개 처리되어 있어 JBoss EAP 가능성을 완전히 배제할 수 없으나, 보안 사유로 열람 제한 (사업 담당자에게 보안서약 후 열람 요청 가능)
    • 기술적용계획표에 PaaS 항목이 미적용으로 분류되어 OpenShift 제안 여지 없음
    • 오픈소스 웹로그 분석기 도입(MAR-003) 조항이 있으나 Red Hat 제품과 직접 연관성 낮음
  • [종합 판단]: S/W 신규 구매 없는 순수 운영용역으로, Red Hat 상용 제품 도입·갱신·증설 기회가 없음. 현행 시스템에 Red Hat 제품이 운영 중이더라도 RFP에 명시되지 않아 판정 근거 부재. 사업 담당자 접촉을 통한 현행 시스템 환경 파악(보안서약 후 열람)이 선행되어야 하며, 차기 연도 사업 또는 별도 인프라 도입 사업 발굴에 초점을 맞추는 것이 적합함
