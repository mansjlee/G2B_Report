사업 개요 및 목적
  • 경상북도 영주시 홍보전산실에서 운영하는 각종 정보시스템(서버, 네트워크, 보안장비, DBMS, 스토리지 등)의 원활한 운영 유지 및 신속·정확한 장애 복구를 위한 통합 유지보수 사업

  • 사이버침해대응센터(해킹·바이러스·유해 트래픽 탐지·분석·대응) 운영 포함

불가능 요소
  • 신규 S/W 도입·납품 없음: 본 사업은 순수 통합유지보수 용역으로, 신규 Red Hat 상용 제품의 구매·납품·구독 항목이 명시되어 있지 않음
  • Red Hat 상용 제품명 미명시: RFP 전반(과업지시서, 유지보수 대상 장비 세부내역 등)에 RHEL, OpenShift, Ansible, JBoss EAP 등 Red Hat 상용 제품명이 단 한 건도 명시되지 않음
  • 경쟁 제품 명시: VMware vSOM, VMware vSphere/vCenter(가상화 플랫폼)가 유지보수 대상으로 명확히 기재되어 있어 해당 영역에서 Red Hat 제안 불가
  • Oracle DBMS 고착화: Oracle 9i, Oracle 10g, Oracle 11g 등 Oracle DBMS가 다수 유지보수 대상으로 명시되어 있어 DBMS 영역 대체 제안 불가
  • CentOS 사용 명시: 온-나라 문서 2.0 시스템의 운영체제가 CentOS로 명시되어 있으나(RHEL 상용 제품명 없음), 커뮤니티 제품으로 Red Hat 상용 제품 도입 근거 없음
  • 서버 O/S 미공개 정책: RFP에 "시스템별 서버 운영체제(O/S) 미공개"로 명시되어 있어 운영 OS 현황 파악 불가, Red Hat 상용 OS 운영 여부 확인 불가
  • 중소기업 제한 입찰: 20억원 미만 사업으로 대기업·중견기업 참여 불가 → Red Hat 직접 입찰 불가 (파트너사를 통한 간접 접근 필요)
  • JBoss 미명시: WAS 서버 관련 JBoss 또는 WildFly 제품명이 유지보수 대상 목록에 전혀 나타나지 않음
Red Hat 제안
가능 요소
  • 서버 OS 미공개로 인한 제안 여지: RFP에 "시스템별 서버 운영체제(O/S) 미공개"로 명시되어 있어, 현재 운영 중인 서버 OS가 RHEL일 가능성 존재 → 기술적용계획표에 "Linux" 운영체제가 적용 대상으로 명시되어 있어 RHEL 운영 가능성 있음
  • Linux 계열 OS 적용 명시: 기술적용계획표 "플랫폼 및 기반구조 분야"에서 서버용 운영체제로 UNIX, Windows Server, Linux가 적용 대상으로 기재되어 있어 RHEL 제안 여지 존재
  • CentOS → RHEL 전환 기회: 온-나라 문서 2.0 시스템(AP서버 4식, DB서버 2식, 문서유통서버 2식) 운영체제로 CentOS가 명시 → CentOS EOL 이슈를 활용한 RHEL 마이그레이션 제안 가능 (단, 현 사업 범위 내 전환은 어려움)
  • Netvault Oracle Online APM License for Linux: 백업 S/W 항목에 "Oracle Online APM License for Linux" 명시 → Linux 기반 Oracle 서버 운영 중임이 확인되며, 해당 서버 OS가 RHEL일 가능성에 대한 파트너 확인 필요
  • 클라우드 전환 지원 항목: MAR-15(클라우드 정보시스템 운영 및 전환 지원) 요구사항에서 행안부 정책에 따른 민간 클라우드 전환 지원이 명시 → OpenShift/RHEL 기반 클라우드 환경 제안 기회 (차기 사업 연계)
  • RFP 내 Red Hat 제품명 명시 없음: 본 RFP에서 Red Hat(레드햇/RHEL/OpenShift/Ansible/JBoss 등) 제품명은 전혀 명시되지 않음
