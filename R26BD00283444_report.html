한국석유공사_석유정보 통합 데이터 플랫폼 구축 용역 - 분석 리포트

레드햇 제안 가능성 낮음
RH 관련 SW 미포함, OLAP·ETL·DBMS만 도입
사업 개요 및 목적
  • 한국석유공사가 운영하는 오피넷(유가정보), 페트로넷(가격·수급통계), 페드시스(수급보고) 3개 시스템의 분산 DB를 하나의 통합 데이터 플랫폼으로 통합·재구축하는 사업
  • 약 20년 이상 운영된 레거시 DBMS(Sybase ASE 15.5, Sybase IQ 12.6)의 기술적 한계 극복 및 물리적 재구축 추진
  • 현업 담당자의 DB 직접 접속·수작업 방식 탈피 → No-Code/Low-Code GUI 기반 셀프 서비스 BI 분석 환경 구축
  • 오피넷 346개·페드시스 709개·페트로넷 899개 테이블에 달하는 20TB 이상 대용량 데이터의 안전한 마이그레이션 및 데이터 거버넌스·보안 체계 수립
  • 정부 부처 수시 보고에 유연하게 대응할 수 있는 비정형 보고서 생성·대시보드·사용자 포털 제공
주요 정보
  • 사업 예산: 609,928,330원 (부가가치세 포함)
  • 사업 기간: 계약체결일로부터 90일 (예상: 2026년 11월 ~ 2027년 1월)
  • 사업 범위: ① 통합 데이터베이스 구축 및 데이터 이관, ② 데이터레이크 구성(20TB 이상), ③ 셀프 BI 분석환경(No-Code/Low-Code), ④ 비정형보고서 생성 기능, ⑤ 핵심 대시보드 개발, ⑥ 사용자 포털 구축, ⑦ 데이터 보안·거버넌스 체계 수립, ⑧ 레거시 데이터 마이그레이션, ⑨ 서비스 개시 및 안정화 지원
  • 주요 일정: M+1(착수·분석) → M+2(설계·개발·데이터이관) → M+3(테스트·개발완료·마이그레이션·검수·완료보고) / 과업심의위원회 개최일 2026.8.26. 완료
  • 계약 방법: 제한경쟁입찰(중소기업) / 협상에 의한 계약 / 총액입찰 / 전자입찰
  • 입찰 참가 제한: 대기업 소프트웨어사업자 및 상호출자제한기업집단 속한 회사 참여 불가 (20억원 미만 사업)

    • 수시 변경 가능한 비정형 보고서 생성 기능 제공
    • 국내외 유가 비교, 주유소 가격 모니터링, 이벤트 기반 유가 분석, 석유수급 통계 등 핵심 분석 템플릿 개발

    • 전자정부 표준프레임워크 적용, 반응형 웹, 웹접근성(K-WAH 4.0) 준수

    • ETL S/W: 1식 — 데이터 연계·이관용 ETL 솔루션 (GS 1등급 인증, 분리발주 예외 적용, 병렬처리·스케줄링·GUI 모니터링 기능 포함)

Red Hat 제안
불가능 요소
  • Red Hat 상용 제품명 전혀 미명시: RFP 전문에 RHEL, OpenShift, Ansible, JBoss EAP, AAP 등 Red Hat 상용 제품·동의어가 단 한 건도 등장하지 않음
  • 도입 SW가 Red Hat 스택과 무관: 통합발주 대상 SW는 OLAP(BI 시각화 도구), ETL(데이터 연계·이관 도구), 분석용 DBMS(PostgreSQL 계열) 3종으로 모두 Red Hat 제품군과 직접적 연관 없음
  • 인프라·OS 구매 항목 없음: 서버 H/W, OS, 미들웨어, 컨테이너 플랫폼 등 인프라 계층 도입이 RFP 범위에 포함되지 않음 (개발서버는 수행사 자체 부담)
  • 컨테이너·Kubernetes·자동화 수요 없음: OpenShift, Ansible Automation Platform 등을 활용할 수 있는 컨테이너화, 인프라 자동화, PaaS 플랫폼 관련 요구사항이 없음
  • 중소기업 제한 입찰: 대기업 SW사업자 참여 불가 조건으로, Red Hat Korea의 직접 입찰 참여 자체가 불가함
  • DBMS가 PostgreSQL 계열로 확정적: pg_dump/pg_restore, pgAudit, PgBouncer, Pgpool-II, WAL, PITR 등 PostgreSQL 고유 기능이 요구사항에 명시되어 있어 Red Hat 계열 DBMS 제안 여지 없음
Red Hat 제안
가능 요소
  • RFP 내 Red Hat 제품 명시 없음: RHEL, OpenShift, Ansible, JBoss EAP 등 Red Hat 상용 제품·동의어가 RFP 어디에도 기재되어 있지 않아 직접적인 제안 근거 없음
  • OS 미지정 (간접 기회): ETL 요구사항에서 "Unix, Linux, Windows 등 지원"이라는 일반적 언급이 있어, 향후 수행사 선정 이후 서버 인프라 OS 결정 시 RHEL 제안 가능성이 원론적으로 존재하나, 이는 본 RFP 범위 밖의 수행사 자체 구성 영역임
  • 종합 평가: 본 사업은 BI·ETL·DBMS 중심의 데이터 플랫폼 구축 용역으로, Red Hat 스택(RHEL, OpenShift, Ansible 등)을 직접 제안하거나 납품할 수 있는 기회가 사실상 없는 사업임. 영업 자원 투입 우선순위 낮음으로 판단됨
