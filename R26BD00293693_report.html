Red Hat 제안
불가능 요소
  • S/W 납품 없는 순수 유지관리 용역: 본 사업은 기존 운영 중인 정보자원의 유지관리만을 목적으로 하며, 신규 S/W 구독·도입·납품 항목이 전혀 없음. 따라서 Red Hat 상용 제품의 신규 공급 기회 없음
  • VMware 명시: 유지관리 대상에 VMware CPU 라이선스 1식이 명시되어 있으며, 기존 가상화 플랫폼으로 VMware가 운영 중임. Red Hat Virtualization(RHEV) 또는 OpenShift 가상화 전환 여지 없음
  • Oracle DBMS 다수 운영 중: Oracle 10g Enterprise, Oracle 11g Standard, Oracle 10g Standard 등 총 3식이 유지관리 대상으로 명시되어 있으며, Oracle 전담인력(OCP 자격) 요구. Red Hat 기반 DB 솔루션 제안 여지 없음
  • Red Hat 상용 제품명 전혀 없음: RFP 전체에 RHEL, OpenShift, Ansible, JBoss/EAP, Satellite 등 Red Hat 상용 제품명이 구매·도입·유지관리 대상으로 전혀 언급되지 않음
  • Linux 운영체제 미지정 및 관련 요구 없음: OS 관련 요구사항이 Windows OS(PC 관리) 위주이며, Linux 계열 플랫폼 신규 도입 요구 없음
  • 대기업 입찰 불가: 20억원 미만 중소SW사업자 전용 사업으로 Red Hat이 직접 참여하거나 대기업 채널을 통한 참여 자체가 불가
Red Hat 제안
가능 요소
  • Red Hat 상용 제품 미명시: RFP 및 유지관리 대상 S/W 목록 어디에도 RHEL, OpenShift, Ansible, JBoss EAP 등 Red Hat 상용 제품이 구매·도입·유지관리 품목으로 명시되지 않아 제안 근거 부재
  • 서버 가상화 환경 운영 중: 행정망 소형통합서버(HPE DL380 G7 2대), 인터넷망 소형통합서버(HPE DL380 G7 2대)에 가상화 탑재 운영 중이나, VMware 기반으로 확정되어 있어 Red Hat Virtualization 전환 제안 여지 없음
  • Linux 기반 서버 환경 가능성: 기술적용계획표에 Linux가 서버용 운영체제로 포함되어 있으나(해당없음 체크 없이 적용 검토 항목으로 포함), 이는 기술표준 준수 사항으로 실제 도입과는 무관하며 현행 시스템의 OS가 명시되지 않아 RHEL 제안 근거로 삼기 어려움
  • 결론: 본 사업은 순수 유지관리 용역으로 Red Hat 상용 제품의 신규 도입·납품·구독 갱신 기회가 전무하며, 기존 운영 환경에도 Red Hat 상용 제품이 포함되어 있지 않아 제안 가능 요소가 사실상 없음
