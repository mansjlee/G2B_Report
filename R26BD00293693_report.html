Red Hat 제안
불가능 요소
  • 순수 유지관리 용역 사업: 본 사업은 기존에 도입된 HW·SW를 유지·관리하는 용역으로, 신규 S/W 구독·납품·도입 항목이 RFP에 전혀 명시되어 있지 않음
  • VMware 명시 사용: 서버 가상화 솔루션으로 "VMware CPU 라이선스" 1식이 유지관리 대상 SW 목록에 명시되어 있어, 해당 가상화 플랫폼은 VMware로 확정된 상태임 (RHEV/OpenShift 전환 여지 없음)
  • Oracle 명시 사용: DBMS가 Oracle 10g/11g로 3식 명시되어 있으며 OCP 자격 전담인력 요구 — Red Hat 데이터 플랫폼 제안 불가
  • Red Hat 상용 제품명 전혀 없음: RFP 전체에 RHEL, OpenShift, Ansible, JBoss, AAP 등 Red Hat 상용 제품·동의어가 구매/통합발주/유지관리 품목으로 전혀 명시되어 있지 않음
  • OS 미지정 but 기존 환경 고정: 운영 중인 서버 OS가 별도 지정되지 않았으나, 기존 운영 환경 유지가 원칙이므로 신규 RHEL 도입 가능성 없음
  • 20억원 미만 중소기업 전용 사업: Red Hat이 직접 입찰 불가, SI 통합사업자도 대기업 참여 불가로 Red Hat 제품 납품 채널 매우 제한적
  • Linux 계열 구체 언급 없음: 기술적용계획표에 "Linux" 항목이 있으나, 이는 표준 기술 적용 여부 점검용이며 신규 RHEL 구매 근거 아님
Red Hat 제안
가능 요소
  • RFP 내 Red Hat 상용 제품 명시 없음: RHEL, OpenShift, Ansible, JBoss EAP 등 Red Hat 상용 제품이 품목으로 명시된 사례 전무 — 직접적인 영업 기회 없음
  • Linux 서버 운영 환경 존재 가능성: 사업 대상에 HPE DL380, IBM Power 등 다양한 서버가 포함되어 있어 Linux 기반 OS 운영 환경이 존재할 가능성이 있으나, 구체적인 OS 정보 비공개
  • 향후 OS 전환 기회 탐색: 유지관리 사업 수주 업체(SI)를 통해 향후 CentOS → RHEL 전환 또는 신규 시스템 도입 시 RHEL 제안 여지를 간접적으로 탐색할 수 있으나, 본 사업 범위 내에서는 제안 불가
  • 자동화/관리 솔루션 중장기 제안 가능성: 유지관리 업체가 Ansible 기반 자동화를 자체적으로 활용하는 제안을 할 수 있는 여지가 있으나, 본 RFP의 구매·납품 대상에는 해당 없음
  • 결론: 본 사업은 Red Hat 상용 제품 구매·도입이 없는 순수 유지관리 용역이므로, 직접적인 Red Hat 영업 기회가 없는 사업임
