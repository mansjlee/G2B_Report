Red Hat 제안
불가능 요소
  • S/W 공급 미포함
    • 직접구매 "해당없음"인 순수 유지관리 용역으로, S/W 납품·구독 항목이 없음
    • 유상 상위버전 업그레이드는 발주기관이 별도 협의·부담하는 구조
  • 경쟁 제품 명시
    • 서버 가상화: VMware CPU 라이선스 1식 운영 중이며 유지관리 대상
    • DBMS: Oracle 10g/11g 3식 운영 중
  • Red Hat 제품 미명시: Red Hat 상용 제품명(RHEL, OpenShift, Ansible, JBoss 등)이 문서 어디에도 없음
  • 기타 제약
    • 현행 시스템을 유지하는 성격의 사업으로, 신규 플랫폼 도입이나 OS 전환 과업이 없음
    • UNIX 계열 서버(IBM Power, HP Itanium)는 제조사 OS 기반 운영이 전제됨
    • 중소 SW사업자 전용 사업이며, 제조사 기술지원확약서 대상에 Red Hat이 포함되지 않음
Red Hat 제안
가능 요소
  • RFP 내 Red Hat(또는 동의어) 제품명·수량: 없음
  • OS 미지정
    • x86 서버(DL380, x3650 M5 등)의 운영체제가 명시되지 않음
    • 기술적용계획표의 서버 OS 항목에 Linux가 포함되어 있어, 향후 OS 표준화 시 RHEL 제안 여지가 있음
  • 노후 UNIX 전환 기회
    • HP rx2800 i4(Itanium, 단종)와 IBM S814 등 노후 UNIX 서버를 RHEL 기반 x86으로 전환하는 차기 사업 기획 시 영업 포인트가 될 수 있음
  • 가상화 대체 기회
    • 노후 HPE DL380 G7 기반 VMware 가상화 환경 교체 시점에 OpenShift Virtualization을 대안으로 제시할 수 있음
    • VMware 라이선스 정책 변경 이슈를 활용 가능
  • 운영 자동화
    • 일상점검(모니터링·쉘스크립트 허용), 패치관리, 형상관리, SOP 요구사항이 Ansible Automation Platform의 강점과 일치함
    • 수행사의 추가 제안사항(기타 5점) 항목으로 활용 가능
  • 영업 전략
    • 본 사업에서의 직접 매출은 기대하기 어려움
    • 유지관리 수행사(중소 파트너)와 협력하여 성능점검·개선 보고서에 RHEL/OpenShift/Ansible 전환안을 반영하도록 유도
    • 이를 통해 동작구 차기 HW 교체·가상화 고도화 사업 예산 반영을 노리는 중장기 접근 권장
