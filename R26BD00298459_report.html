Red Hat 제안
불가능 요소
  • 본 사업은 S/W 신규 구매(통합발주·납품) 사업이 아닌 운영·유지보수 용역 사업으로, Red Hat 상용 제품의 신규 구독 구매 품목이 별도로 명시되어 있지 않음
  • 상용SW 유지관리 목록에 Red Hat 제품명(RHEL, OpenShift, Ansible 등)이 직접 기재되어 있지 않음
  • OS 환경은 "Linux(RH 8.6)"으로 표기되어 있으나, 유지보수 대상 상용SW 목록에는 별도 OS 항목으로 포함되어 있지 않아 이번 사업에서 RHEL 구독 갱신 품목으로 직접 계상 여부 불명확
  • 경쟁 OS(Ubuntu, Rocky Linux 등)가 명시된 사항은 없으나, Red Hat 제품 구매가 본 사업 범위에 포함된다는 명시도 없음
  • 중소기업만 입찰 가능(대기업·중견기업 참여 제한)하여 Red Hat이 직접 입찰 불가, SI/유지보수 업체를 통한 간접 공급만 가능
Red Hat 제안
가능 요소
  • [현행 운영 환경에 Red Hat 제품명 명시]: 의료기기안심책방, 전자민원시스템, UDI추적관리시스템, 협업시스템, 행정시스템 등 모든 주요 서비스 시스템의 OS가 "Linux(RH 8.6)"으로 명시되어 있음 — 이는 Red Hat Enterprise Linux 8.6으로 판단되며, 판정 규칙상 정확한 Red Hat 제품명이 운영 환경에 기재된 경우에 해당하여 높음 판정 적용
  • [RHEL 구독 갱신 기회]: RHEL 8.6은 2024년 5월 이후 Full Support가 종료되어 Maintenance Support 단계에 있으므로, 2027년 사업 기간 중 RHEL 9.x 업그레이드 또는 구독 갱신 제안 기회 존재
  • [인프라 증설 연계 기회]: MPR-017 요구사항에 따라 2027년 국가정보자원관리원 광주센터의 신규 서버 도입·기존 서버 증설·스토리지 증설이 예정되어 있어, 증설 서버에 대한 RHEL 신규 구독 제안 가능성이 있음
  • [WAS 서버 환경]: 외부 WAS, 내부 WAS, 인허가 WAS, UDI WAS, 챗봇 WAS, 리포팅 WAS, API WAS 등 다수의 WAS 서버(VM)가 운영 중이며, 현행 egovFramework 기반 Java 환경에서 JBoss EAP 적용 여지 존재 (단, RFP에 JBoss 명시 없음)
  • [Ansible 자동화 제안 기회]: 다수 VM 서버(20여 대) 운영, 월간 정기점검 및 패치·업그레이드 자동화 필요성이 있어 Ansible Automation Platform 제안 여지 있음
  • RFP에 명시된 Red Hat(동의어 포함) 제품명·수량:
    • OS: Linux(RH 8.6) — 의료기기안심책방·전자민원시스템·UDI추적관리시스템·협업시스템·행정시스템 등 각 시스템 개발환경 OS로 명시 (총 5개 시스템, VM 서버 다수)
