Red Hat 제안
불가능 요소
  • 순수 유지관리 용역: 신규 S/W 구독·납품·도입 항목이 전혀 없는 운영·유지관리 서비스 계약으로, Red Hat 상용 라이선스 판매 기회 없음
  • 기존 스택이 비(非) Red Hat 제품으로 고정:
    • DBMS: Oracle Enterprise RAC 12c (통합), Oracle Std Edition 11g (홈페이지)
    • WAS/Web: TmaxSoft WEBTOB / JEUS (JBoss EAP 대신 경쟁 제품 사용 중)
    • UI 개발 툴: Nexacro Platform 17
    • 서버: IBM 서버 2대 (RAC 구성), IBM 스토리지
    • 홈페이지: NHN Cloud 운영
    • 전자결재: Dooray (SaaS)
  • Red Hat 제품명 전혀 미기재: RFP 전문(제안요청서, 기술적용계획표, 과업내용 등) 어디에도 RHEL, OpenShift, Ansible, JBoss EAP, Satellite 등 Red Hat 상용 제품명이 언급되지 않음
  • 중소기업 제한 경쟁: 사업금액 20억 미만으로 대기업·중견기업 참여 불가 — Red Hat Korea 직접 입찰 불가, 파트너 채널을 통한 SW 납품 구조 자체가 성립하지 않음
  • OS 전환 여지 없음: 기술적용계획표에 Linux가 일반 표준 항목으로 체크되어 있으나, 이는 전자정부 표준 준수 여부 확인 항목일 뿐 특정 OS 도입·변경 계획 없음
Red Hat 제안
가능 요소
  • 직접적인 Red Hat 제안 가능 요소 없음: RFP 내 Red Hat(레드햇) 또는 동의어(RHEL, OCP, Ansible, JBoss EAP, AAP, Satellite 등) 제품명·수량이 전혀 명시되지 않음
  • 간접적 관찰 포인트 (영업 레퍼런스 구축 목적):
    • 기술적용계획표에 'Linux' 서버 운영체제가 해당 항목으로 체크되어 있어, 일부 서버가 Linux 기반일 가능성 존재 — 향후 OS 갱신 시 RHEL 제안 여지
    • 상용SW 유지관리(MAR-009) 조항에 따라 기존 WEBTOB/JEUS의 노후화 시 WAS 교체 검토 가능 — JBoss EAP 윈백 기회로 연결 가능 (현 사업 내 아님)
    • 보안관리(NAC, DB암호화, 통합관제 등) 고도화 필요성 언급 — 장기적으로 Ansible Automation Platform을 활용한 보안 패치 자동화 제안 가능 (현 사업 내 아님)
  • 종합: 본 사업은 기존 비(非) Red Hat 환경의 순수 유지관리 용역으로, 현재 Red Hat 제품 제안·납품 기회는 없음. 수요기관 관계 형성 차원의 장기 파이프라인으로만 참고 가능
