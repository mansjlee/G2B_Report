불가능 요소
  • [경쟁 제품 명시] 2단계 SW에 VMware vSphere 7 (4EA)이 유지관리 품목으로 명시되어 있어 Red Hat 가상화(RHEV/RHV) 제안은 해당 범위 내 대체 불가
  • [CentOS 운영 서버 다수] 1단계 HW 서버(STT I/F 서버, STT엔진 서버, STT분석 서버, AI대화엔진 서버, AI브로커 서버) 5대의 OS가 CentOS Linux 7.8로 운영 중이며, 해당 서버 OS는 유지관리 품목에서 별도 명시되지 않아 RHEL 전환 요구는 현 사업범위 外
  • [순수 유지관리 용역 성격] 본 사업은 신규 구축이 아닌 기존 시스템 유지관리 용역으로, 신규 Red Hat 제품 추가 도입보다는 기 도입된 Redhat OS 라이선스 갱신·유지가 핵심
  • [대기업 참여 불가] 중소 소프트웨어사업자 제한 사업으로 Red Hat이 직접 입찰 주사업자로 참여 불가 (협력업체 구조로만 참여 가능)
Red Hat 제안
가능 요소
  • [RFP 명시 Red Hat 상용 제품 — 높음 판정 근거]
    • OS Redhat Linux 1식 (1단계): MAR-001 유지관리 대상 표에 "OS Redhat 1식"으로 명시, OS 라이선스 갱신 포함 (계약 시 제조/공급사 확약서 제출 요구)
    • OS Redhat Linux 2EA (2단계): MAR-001 2단계 유지관리 대상 표에 "OS 2EA"로 명시, 시스템 현황(붙임2)에서 "OS Redhat Linux"로 확인
  • [현 운영 환경 Red Hat 기반] 챗봇WAS서버(AI웹 서버)가 Redhat Linux 7.5로 운영 중이며, 2단계 전체 시스템 OS가 Redhat Linux로 운영 — 버전 업그레이드(RHEL 8/9) 제안 여지
  • [라이선스 갱신 기회] 기존 도입된 Redhat Linux 총 3식(1단계 1식 + 2단계 2EA)의 구독 갱신(Subscription Renewal)이 사업비에 포함되어 있어 Red Hat 직접 매출 기회
  • [상용SW 기술지원 확약서 요구] RFP에서 상용SW 품목별 제조사 또는 공급사와의 협력방안 및 기술지원 확약서를 계약 시 제출하도록 요구하고 있어, Red Hat 공인 파트너사와의 협력 구조 필수 → Red Hat 파트너 영업 기회
  • [향후 확장 가능성] 1단계 CentOS Linux 7.8 서버 5대는 CentOS EOL(2024년 6월) 이후 지원 종료 상태로, 차기 사업에서 RHEL 전환 제안의 선행 레퍼런스 구축 가능
