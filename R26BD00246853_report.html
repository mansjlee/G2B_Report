Enterprise Linux 구독 명시, AI·가상화는 경쟁 치열
사업 개요 및 목적
  • 대법원 주관의 「사법부 AI 기반 형사재판 및 양형지원을 위한 지능형 플랫폼 구축」 사업으로, 양형기준 확대(48개 범죄군)에 따른 형사재판·양형 업무 부담을 AI·빅데이터·LLM 기반 시스템으로 고도화하는 것이 핵심 목표이다.
  • 양형정보·양형기준·운영점검 시스템 재구축, 지능형 유사 양형 판결문 검색, 판결문 양형기준 작성·검토 지원, LLM/RAG 플랫폼, 빅데이터/AI 분석 기반 구축을 통해 법관·양형자료분석관·통계담당자의 업무 효율과 양형 판단의 공정성·신뢰성을 제고한다.
  • 차세대전자소송·형사전자소송·재판사무시스템과 연계하며, 전자정부 표준프레임워크 및 법원 UI 표준을 준수하는 통합 AI 양형 플랫폼을 2026~2028년 3단계로 구축·안정화한다.

Red Hat 제안
불가능 요소
  • **핵심 SW 통합발주가 AI·검색·가상화 전용 솔루션**: ECR-007(AI/ML 텍스트·통계분석), ECR-008(LLM·RAG·검색·한국어 BMT 검증 검색엔진), ECR-009(상용 하이퍼바이저·기존 대법원 클라우드 증설·호환)는 제품 기능·벤더 종속 요건이 상세하여 Red Hat 단독 납품 구조가 아님.
  • **직접구매 제외(별첨6)**: LLM관리솔루션, 가상화, 통계분석 SW는 통합사업자가 공급—조달쇼핑몰 직접구매 경로 없음. 모니터링·계정·취약점·보안·로그 SW는 분리발주로 Red Hat이 본 통합과업에 직접 포함되기 어려움.
  • **경쟁·대체 스택**: ECR-009는 기존 법원 클라우드 가상화와 상호운영 필수 → VMware 등 기존 환경 연장 가능성. LLM은 온프레미스·한국어 사전학습·RAG·TTA BMT 검색엔jin 등 특화 요건으로 국내 AI/검색 SW 및 GPU 스택이 유리.
  • **외부 LLM API 불가**: ChatGPT, Gemini 등 외부망 연계 금지—Red Hat 단독으로 LLM 본체·검색엔진·통계분석 SW를 대체 제안하기 어려움.
  • **애플리케이션 개발 중심**: 전자정부 표준프레임워크 기반 자체 개발 비중이 크고 JBoss/WAS 명시 없음—미들웨어 단독 제안 여지 제한.
Red Hat 제안
가능 요소
  • **RHEL**: ECR-004·ECR-005에서 AI 추론·분석 서버 OS를 「Enterprise Linux + Subscription 3년」으로 명시—RHEL 구독(성능·호환성·기술지원) 직접 부합. x86 Linux 서버 다수·Guest OS 무제한 구성과 연계 가능.
  • **OpenShift**: LLM·AI 워크로드 GPU 자원 관리, 다중 노드 학습·추론, 컨테이너 기반 MLOps/모델 배포(ECR-008 GPU 할당·모니터링) 보조 인프라로 제안 가능. 단, ECR-008·009의 기능 요구는 별도 LLM/가상화 SW와 결합 제안 형태.
  • **Ansible**: 대규모 VM·서버 구성 자동화, 패치·설정·로그 연계, AI 플랫폼·RHEL fleet 운영관리(PER·QUR·SER 운영·하자보수)에 부합하는 자동화 레이어.
  • **Red Hat 솔루션 강점 정합**: 온프레미스 폐쇄망, 보안·CC/국정원 요건, Linux 표준, 확장성·무중단, RHEL 기반 AI/빅데이터 플랫폼 증설(3년차)과 기술지원 EOS 요건.
  • **제안 전략**: 통합사업 SI·HW 제안사 파트너십을 통해 RHEL(필수 OS)·OpenShift/Ansible(인프라·운영) 번들, 기존 법원 Linux/x86 환경과의 호환성·BMT 증빙으로 ECR-001·004·005·009 연계 제안.
