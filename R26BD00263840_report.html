Red Hat 제안
불가능 요소
  • Red Hat 제품 미명시: RFP 전체에 RHEL, OpenShift, Ansible, JBoss, EAP 등 Red Hat 상용 제품명이 전혀 등장하지 않음
  • Oracle 스택 고착 (ECR-007): Oracle Database Appliance(ODA) 도입이 품목으로 확정되어 있으며, ODA는 Oracle Linux 기반의 번들 OS·DB 환경을 전제로 하므로 해당 영역에서 RHEL 적용 여지 없음
  • Oracle DB 중심 아키텍처: Oracle Database 19c, Oracle RAC, Oracle Database Vault, Oracle Audit Vault가 핵심 DB 인프라로 명시되어 있어 DB 레이어에서의 경쟁 제안 공간이 제한됨
  • 순수 SI 비중 높음: 사업의 핵심은 대규모 시스템 개발·구축이며, 인프라 S/W 납품 범위가 명시적으로 제한되어 있음
  • WAS 제품명 미지정: 미들웨어(WAS) 관련 특정 제품 요구 없이 "WAS 비종속적 구조" 요건만 명시되어 JBoss EAP 명시 도입 근거 없음
Red Hat 제안
가능 요소
  • RFP 내 Red Hat(동의어 포함) 명시 제품·수량: 없음 (문서 전체에 직접 언급 없음)
  • Linux OS 허용 환경: ECR-002(검색 솔루션), ECR-006(UI/UX 개발 도구), 기술적용계획표(서버용 OS)에서 Linux가 지원·적용 OS로 명시되어 있어 RHEL 제안의 기술적 근거 확보 가능
  • Docker 기반 컨테이너 환경 구축 요건: RFP에 "Docker를 활용한 서버용 개발 및 운영 환경 마련" 명시 → OpenShift 또는 RHEL 기반 컨테이너 플랫폼 제안 여지
  • CI/CD 파이프라인 구축 요건: 형상관리·통합빌드 서버 구축 요건 → Ansible Automation Platform, OpenShift Pipelines(Tekton) 등 Red Hat 자동화·CI/CD 솔루션 제안 검토 가능
  • 클라우드·PaaS 적용 검토 요건: 기술적용계획표에서 IaaS·PaaS·SaaS 클라우드 컴퓨팅 적용 명시 → OpenShift Container Platform(PaaS) 제안 연계 가능
  • 가상화 환경 허용: ECR-007에서 "KVM 등 가상화 환경 지원" 언급 → RHEL KVM 기반 가상화 환경과의 기술 친화성 어필 가능
  • WAS 제품 비종속 구조 요건: 특정 WAS 제품 미지정 + "WAS 비종속적 구조" 요건 → JBoss EAP 제안을 SI 파트너를 통해 검토 가능 (단, 명시 도입 요건은 아님)
  • 수강신청 고성능 트래픽 처리: Redis/Ehcache 등 In-Memory 캐싱, L4/L7 부하 분산 요건 → OpenShift 기반 고가용성 플랫폼 및 Red Hat Data Grid 제안 검토 가능
