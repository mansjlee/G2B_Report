Red Hat 제안
불가능 요소
  • 통합발주 상용SW에 Red Hat 제품 미포함: 통합발주 대상 6종(DB암호화·문서보안·통계분석·검색엔진·DBMS·연계 SW) 모두 Red Hat 제품과 무관하며, 수행사가 직접 납품하는 상용SW 목록에 Red Hat 제품 없음
  • 시스템 SW는 국가정보자원관리원 위임발주: RHEL·JBCS·JBoss EAP 업그레이드 구매는 국자원(위임발주)이 진행하며, 수행사(SI사업자)는 납품 주체가 아닌 기술지원·적용 역할 수행
  • Oracle Database 유지 확정: DBMS SW 통합발주 요구사항에 "현행 Oracle DBMS 환경과 호환, Oracle RAC 기반 이중화"가 명시되어 Oracle 유지가 사실상 확정. RHEL AI/OpenShift 등 데이터 플랫폼 제안 여지 낮음
  • 중소기업 제한 입찰: 20억원 미만 사업으로 대기업·중견기업 입찰 불가. Red Hat Korea가 직접 입찰 불가하며, 중소 SI 파트너를 통한 간접 기회만 존재
  • 검색엔진 신규 도입: 기존 Search Formula-1 EOS 대응으로 상용 검색엔진 2식 신규 도입. Elasticsearch/OpenSearch 계열 경쟁 제품과 경합 가능성 있으나, OpenShift 기반 제안 연결 가능성은 낮음
Red Hat 제안
가능 요소
  • [RFP 명시 Red Hat 상용 제품 현황]
    • Redhat Linux (RHEL): 현행 OS로 명시 (국자원 관리), EOS 대응 업그레이드 대상 — ECR-006 시스템SW EOS 현황에 "OS: Redhat Linux 6, EOS: ○" 명시, 수량 기재 (국자원 위임발주 구매 예정)
    • JBCS (JBoss Core Services): 현행 Web SW로 명시, EOS 대응 업그레이드 대상 — ECR-006에 "Web: JBCS 1, EOS: ○" 명시 (국자원 위임발주 구매 예정)
    • JBoss EAP: 현행 WAS로 명시, EOS 대응 업그레이드 대상 — ECR-006에 "WAS: Jboss EAP 3, EOS: ○" 명시 (국자원 위임발주 구매 예정)
  • [Red Hat 영업 접근 포인트]
    • 국가정보자원관리원(광주센터) 위임발주를 통해 RHEL·JBCS·JBoss EAP 3개 제품이 공식 구매 예정 → 국자원 대상 Red Hat 라이선스 영업 기회 확실
    • JBoss EAP 3식 EOS 업그레이드: EAP 7→8 버전업 가능성, 기술지원 갱신 기회
    • RHEL EOS(버전 6) → 최신 RHEL(8 또는 9)로 업그레이드, 서버 이중화 환경에서의 라이선스 추가 수요 발생
    • 수행사(SI사업자)는 Red Hat 공급사·파트너와 협력하여 라이선스·기술지원확약서 제출 의무가 있어, Red Hat 파트너 생태계를 통한 매출 기회 존재
    • 서버 이중화 구성(WEB·WAS 이중화)으로 기존 대비 Red Hat 라이선스 수량 증가 가능성 (Active-Active 구성 시 서버 추가)
    • Ansible Automation Platform: 서버 이중화·배포 아키텍처 전환(AS-IS→TO-BE 배포 파이프라인) 자동화 제안 가능
