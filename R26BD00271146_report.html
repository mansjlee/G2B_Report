사업 개요 및 목적
  • 페루 이민청(MIGRACIONES)의 2007년 자체 개발 후 노후화된 C/S 환경 기반 이민행정 시스템(SIM)을 최신 Web 기반 기술로 전환하는 것이 핵심 목표
  • 이번 사업 범위: SIM의 체류심사 모듈(INM) Web 전환 및 신규 Hi-PERU 출입국·민원 포털 구축
  • 단기 목표: 페루 이민행정 혁신을 통한 업무 생산성 증대
  • 중기 목표: 신이민행정 서비스로 행정처리 비용·시간 절감 및 투명성 제고
  • 장기 목표: 페루 정부의 이민행정 효율성 강화로 공공서비스 제공역량 강화 및 외교안보 신뢰도 제고 (페루 디지털정부 비전 달성 기여)
  • KOICA 중남미실이 발주하는 ODA(공적개발원조) 사업으로, 사업수행기관(PC)이 시스템 구축과 기자재 공급을 담당

불가능 요소
  • [S/W 구매 목록 미명시] RFP 본문에 통합발주 또는 분리발주 상용 S/W 품목(OS, WAS, 미들웨어 등) 목록이 구체적으로 명시되지 않아 Red Hat 상용 제품의 직접 납품 기회 불명확
  • [MS-SQL DB 확정] 기존 이민청 DB가 MS-SQL(2018)로 통합·확정되어 있어 DB 레이어에서의 Red Hat 제품 개입 제한적
  • [소프트웨어사업 영향평가 구분] ①(상용 S/W 구매·설치 사업) 해당 없음으로 표기 → 사업의 주된 성격이 개발 용역으로, 별도 상용 S/W 구독 항목 포함 여부 불명확
  • [경쟁 제품 미명시이나 JAVA 프레임워크 지정] 페루 이민청 공통기반이 JAVA 표준 프레임워크로 사전 확정되어 있어 미들웨어·런타임 선택 폭 제한 가능
  • [ODA 사업 특성] 한국의 기술지원(ODA) 사업으로 Red Hat이 직접 입찰 불가, SI/통합사업자 통해서만 접근 가능하며 예산·조달 방식이 복잡함

가능 요소
  • [컨테이너 모듈형 데이터센터 구축] 사업 범위에 "컨테이너 모듈형 데이터센터 구축"이 명시되어, 컨테이너 인프라 운영 OS로 RHEL, 컨테이너 플랫폼으로 OpenShift 제안 가능
  • [클라우드 운영환경 및 CMP 구축] "클라우드 자원의 통합 모니터링 및 관리를 위한 포털(CMP) 적용" 명시 → Ansible Automation Platform(AAP)을 통한 클라우드 자원 자동화·관리 제안 가능
  • [서버·OS 미지정] 운영서버 및 스토리지 기자재 공급이 사업 범위에 포함되나 서버 OS가 명시되지 않아 RHEL 제안 여지 존재
  • [Java 기반 WAS 미지정] JAVA 표준 프레임워크 기반 Web 전환으로 WAS(Web Application Server)가 필요하나 특정 제품을 지정하지 않아 JBoss EAP 제안 검토 가능
  • [오픈소스 검색엔진 권장] FUR-002에서 "오픈소스 검색엔진을 권장"하는 조항이 있어 Red Hat 생태계 오픈소스 기반 솔루션 연계 제안 가능
  • [Red Hat 명시 제품·수량]: 없음 (RFP 본문에 Red Hat 또는 동의어 제품명 전혀 미기재)
