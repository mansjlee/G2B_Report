Red Hat 제안
불가능 요소
  • S/W 신규 납품·구독 항목 없음: 본 사업은 기존 설치된 HW·상용SW·응용SW의 운영·유지관리 서비스 계약으로, 신규 S/W 구매·납품·구독 발주가 포함되지 않음. Red Hat 상용 제품의 신규 도입 기회가 원천적으로 없음
  • Red Hat 상용 제품명 전혀 미명시: RFP 전문 및 상용SW 현황(242식), 기술적용계획표 어디에도 RHEL, OpenShift, Ansible, JBoss EAP, Satellite 등 Red Hat 상용 제품명이 구매·도입 품목으로 명시되어 있지 않음
  • 핵심 시스템SW 관리 주체 제외: 국가정보자원관리원(국정자원)에서 운영·유지관리하는 시스템SW(WEB, WAS, DBMS) 및 HW는 본 과업에서 명시적으로 제외되어, Red Hat 스택이 적용된 핵심 인프라에 대한 접근·제안 기회 제한
  • 경쟁 제품 명시 없음(확인 불가): 상용SW 현황 표에 구체적인 제품명이 대부분 미기재(구분명만 표기)되어 경쟁·대체 OS(Ubuntu, Rocky Linux, Oracle Linux 등)가 현재 운영 중인지 확인 불가
  • 중소기업 참여 제한: 연평균 사업금액 20억 미만으로 중소기업자만 입찰 가능하여 Red Hat(대기업) 직접 참여 불가. SI·통합사업자를 통한 간접 채널만 가능
  • 기술이전·유지보수 중심 과업: 사업 성격이 기존 시스템 운영 안정화·장애처리·기능개선 중심이며, 플랫폼 전환·신규 도입 의사결정은 발주기관 소관으로 본 사업 범위 밖
Red Hat 제안
가능 요소
  • Linux 운영체제 플랫폼 적용 확인: 기술적용계획표(붙임4)의 "운영체제 및 기반환경" 항목에서 POSIX.0, UNIX, Windows Server, Linux가 모두 적용 대상으로 명시(ㅇ 표시). 현재 운영 중인 서버 OS에 Linux 계열이 포함될 가능성 높으며, 향후 RHEL 적용·전환 제안 여지 존재
  • WEB·WAS·DBMS 유지관리 대상 포함: 기록원 전산실 기준 WEB 2식, WAS 5식, RDBMS 3식이 본 사업 유지관리 대상에 포함(국정자원 관리분 제외 후 기록원 자체 관리분). 해당 WAS 등이 WildFly 또는 JBoss 기반일 경우 JBoss EAP 상용 전환 제안 가능성 있음(단, 현재 제품명 미공개)
  • 클라우드 환경 운영 포함: 기술적용계획표에 IaaS·PaaS·SaaS 모두 적용 대상으로 명시. RAMP, cRMS 등이 G-클라우드(국정자원 클라우드) 환경에서 운영 중이며, 클라우드 자원 모니터링 및 증설 요청 지원이 과업에 포함되어 OpenShift·RHEL 기반 인프라 제안 맥락 가능
  • 전자정부 표준프레임워크 기반 응용SW: 기술적용계획표에 "개발프레임워크: 전자정부 표준프레임워크" 적용 명시. 표준프레임워크 기반 Java 애플리케이션 환경에서 JBoss EAP 또는 Ansible Automation Platform 도입 제안 영업 대화 가능
  • RFP에 명시된 Red Hat 제품명·수량: 없음 (RFP 전문에 Red Hat, RHEL, OpenShift, Ansible, JBoss 등 상용 제품명이 구매 품목으로 일절 명시되지 않음)
  • 영업 활용 방안: 본 사업 수주 사업자(SI)를 통해 현재 운영 중인 OS·WAS 환경 파악 후, 차기 고도화·장비교체 사업 발굴 시 RHEL, JBoss EAP, Ansible 기반 인프라 현대화 제안을 위한 관계 구축에 활용 가능
