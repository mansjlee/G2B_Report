서울올림픽기념국민체육진흥공단_체육인복지지원시스템 3차 구축(개발) - 분석 리포트

RH 상용 제품 미명시, 순수 개발 용역
사업 개요 및 목적
  • 서울올림픽기념국민체육진흥공단이 운영하는 체육인복지지원시스템(SPOWell)의 3차 구축 사업으로, 체육인 자격확인 체계 고도화 및 복지서비스 확장을 목적으로 함
  • 체육인 확인체계 개선: 대한체육회·대한장애인체육회 데이터와의 실시간 API 연계를 통해 체육인 자격 자동 확인 및 회원가입 절차 간소화
  • 체육인 인증서 발급: 체육인 유형별(국가대표·체육인·학생선수 등) 인증서 생성·발급·진위확인 기능 및 네이버 전자지갑 연계 구축
  • 온라인 신청 확대: 경기력성과포상금, 체육장학금, 국내교육지원금 등 신규 온라인 신청 기능 개발 및 원스톱 복지서비스 구현
  • 통계 고도화: 사업별 신청·심사·지급·수혜현황 데이터의 통합 관리 및 공개형 통계정보서비스 구축
  • 공제사업 지원: 신규 공제사업 추진을 위한 공제회원 관리, 보험사 연계 기반 마련
  • 검색·챗봇 정비: 메뉴·콘텐츠 변경에 따른 통합검색 재설정 및 챗봇 콘텐츠 정비 지원
주요 정보

Red Hat 제안
불가능 요소
  • 순수 SI·개발 용역 성격 강함: 본 사업은 체육인복지지원시스템의 기능 개발·고도화가 주목적이며, RFP 전반에 걸쳐 Red Hat 상용 제품(RHEL, OpenShift, Ansible, JBoss EAP, Satellite 등) 도입·납품 항목이 전혀 명시되지 않음
  • 경쟁 제품 명시는 없으나 RH 스택 제안 근거도 없음: Ubuntu, VMware, Rocky Linux, Oracle Linux 등 경쟁 제품도 명시되지 않았으나, 이는 OS·플랫폼이 기존 인프라를 활용하는 구조이기 때문으로 판단됨 (시스템 구성도 등 상세정보는 보안 목적으로 비공개 처리)
  • 전자정부 표준프레임워크 종속 개발: 기술 환경이 eGovFramework(Spring 기반 Java) 위주로 고정되어 있어 Red Hat JBoss EAP·OpenShift 등의 신규 제안이 어려운 구조
  • 20억 미만 중소기업 한정 사업: 대기업·중견기업 참여 제한으로 Red Hat 공식 채널을 통한 직접 영업보다 중소 파트너를 통한 간접 영업만 가능
  • 상용SW 직접구매 목록 미확인: RFP에 상용SW 직접구매 계획이 있다고 명시되어 있으나, 실제 품목 표(붙임)가 텍스트로 추출되지 않아 Red Hat 제품 포함 여부를 확인할 수 없음
Red Hat 제안
가능 요소
  • Linux 운영체제 일반 언급: 기술적용계획표(별첨4)의 플랫폼·기반구조 분야에서 서버용 운영체제로 UNIX, Windows Server, Linux가 모두 나열되어 있어 RHEL 제안 여지가 이론상 존재하나, 특정 OS 지정 없이 기존 인프라 활용이 기본 전제임
  • 클라우드 인프라 일반 언급: IaaS, PaaS, SaaS가 기술 지침 항목으로 나열되어 있어 향후 클라우드 전환 시 OpenShift 제안 가능성이 있으나, 현재 사업 범위 내에서는 해당되지 않음
  • API 연계 및 표준화: RESTful API 기반 외부기관 연계, 자동화 배치 처리 등의 요구사항은 잠재적으로 Ansible Automation Platform 관련 필요성을 시사하나, 본 RFP에서 자동화 플랫폼 도입은 명시되지 않음
  • RFP 내 Red Hat 제품명 명시 없음: RHEL, OpenShift, OCP, Ansible, JBoss EAP, Satellite, Quay, ACM, ACS 등 Red Hat 상용 제품 및 동의어가 RFP 전문에 걸쳐 단 한 건도 등장하지 않음 → 현 시점에서 구체적 제안 기회 없음
