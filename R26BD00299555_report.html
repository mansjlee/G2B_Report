Red Hat 제안
불가능 요소
  • 신규 S/W 구매·납품 없음: 본 사업은 순수 유지관리 용역으로, 신규 S/W 도입·납품·구독 항목이 전혀 없음. Red Hat 제품 판매 기회 없음
  • Red Hat 상용 제품명 미명시: 과업지시서 본문 및 유지관리 대상 목록 전반에 걸쳐 RHEL, OpenShift, Ansible, JBoss EAP 등 Red Hat 상용 제품명이 단 한 건도 명시되지 않음
  • 가상화 환경은 Hyper-V 기반: 유지관리 대상 소프트웨어 목록에 Microsoft Hyper-V(18식)가 가상화 플랫폼으로 명시되어 있어 RHEV/OpenShift Virtualization 제안 여지 없음
  • 서버보안 SW는 타사 제품: SGA RedCastle 4 for redhat 6(1식)이 "redhat"을 플랫폼명으로 포함하고 있으나, 이는 Red Hat 제품이 아닌 SGA社 보안 솔루션이며, Red Hat 상용 제품 도입·납품·유지보수 대상이 아님
  • DB는 Tibero 사용: 통합플랫폼 DB로 Tibero std6(국산 DBMS)가 운영 중으로 Red Hat Data Grid 등 제안 여지 없음
  • 일반 문구 수준의 OS 언급만 존재: "SGA RedCastle 4 for redhat 6" 표기는 OS 플랫폼 명칭을 포함하고 있으나 정확한 Red Hat 상용 제품명(RHEL 등)으로 볼 수 없으며, 판정 규칙상 "제품명 없이 플랫폼명만 있는 경우"에 해당 → 높음 판정 불가
  • 20억 미만 소규모 사업: 대기업 소프트웨어사업자 참여 제한 사업으로 Red Hat이 직접 입찰 불가 구조

  • RFP에 명시된 Red Hat(동의어) 제품명·수량: 없음 (※ "SGA RedCastle 4 for redhat 6" 1식은 타사 보안SW의 플랫폼 표기이며 Red Hat 상용 제품 아님)

  • 향후 갱신·확장 모니터링 필요: 2028년 이후 시스템 증설 또는 차기 사업 발주 시 RHEL·Ansible 등 도입 가능성을 사전 파악하기 위해 관계 관리 차원의 모니터링 권장
  • 종합 판단: 본 사업은 신규 S/W 도입이 없는 순수 유지관리 용역이며, 기존 운영 대상에 정확한 Red Hat 상용 제품명이 없어 낮음으로 판정. 대기업 참여 제한으로 직접 입찰도 불가하여 단기적 영업 기회는 없음
