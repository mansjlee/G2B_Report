Red Hat 제안
가능 요소
  • 기존 시스템에 "Linux Redhat" 명시: 시스템 운영환경 현황표에서 연계서버(데이터수집 용도, 서울시 데이터센터)의 OS로 "Linux Redhat"이 명시되어 있어, RHEL이 실 운영 중임을 확인할 수 있음
  • OS 패치·업그레이드 요구사항 존재: MAR-006 요구사항에 따라 "새로운 OS 및 관련 S/W가 출시 또는 업그레이드될 경우 정상 작동되도록 적용"이 명시되어 있어, RHEL 구독 갱신 또는 패치 지원 기회 가능
  • 상용SW 기술지원확약서 제출 의무: 입찰 참가 조건으로 유지관리 대상 상용SW의 원제조사 또는 총판의 기술지원확약서 제출이 요구되어, RHEL 공급사 역할 기회 가능
  • Linux 기반 서버 운영환경 잠재 활용: 기존 Linux Redhat 연계서버가 서울시 데이터센터 내 운영 중이므로, 향후 RHEL 라이선스 갱신 또는 사양 확장 시 제안 가능
  • RFP에 명시된 Red Hat(동의어) 제품명·수량: "Linux Redhat" (연계서버 데이터수집, 1대, 서울시 데이터센터) — 단, 신규 구매/납품 품목이 아닌 기존 운영환경 기재 사항임
