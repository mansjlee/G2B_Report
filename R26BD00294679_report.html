불가능 요소
  • S/W 납품·구매 품목 없음: 본 사업은 운영 및 유지관리 용역 사업으로, RFP 내 Red Hat을 포함한 어떠한 S/W 구매·통합발주·납품 품목도 명시되어 있지 않음 (SW 분리발주 대상: 해당 없음)
  • Red Hat 제품 명시 없음: 문서 전체에서 RHEL, OpenShift, Ansible, JBoss EAP, Satellite 등 Red Hat 상용 제품명이 단 한 건도 언급되지 않음
  • 현행 시스템 구성 비공개: 구체적 OS 종류, DBMS 제품명, 미들웨어 제품명, 가상화 제품명 등 현행 소프트웨어 구성은 보안 및 업무비밀 보호를 이유로 공개하지 않으며 방문 열람만 가능하여 Red Hat 스택 도입 여부 확인 불가
  • 기존 운영 환경 특정 불가: 클라우드 플랫폼 제품명 미공개, 특정 OS·미들웨어·WAS 지정 및 배제 조항 없음 — Red Hat 도입 여부를 직접 단정할 단서 없음
  • 경쟁 제품 대응: 미들웨어 현황에 Notes/LotusScript(코트넷/KMS/메일), Handy gw8.3, GAUCE, WebSquare, OZ Report 등 비Red Hat 솔루션이 다수 명시되어 있으며, 해당 제품들의 운영 유지가 주요 과업임
Red Hat 제안
가능 요소
  • Linux OS 허용 환경: 운영체제로 "Linux (일부 Web 등)"이 명시되어 있으며 특정 Linux 배포판 지정이 없어 RHEL 제안 가능성 존재 — 현재 RHEL이 운영 중일 가능성 배제 불가 (방문 열람 시 확인 필요)
  • 대규모 Linux 서버 환경: 시스템 서버 2,290대, DBMS 262개, 미들웨어 1,789개 규모의 대형 운영 환경으로 RHEL 구독 갱신·신규 도입 시 대형 기회
  • 클라우드·컨테이너 환경: 2025년 차세대전자소송 시스템이 클라우드 기반 인프라로 전환되었으며, IaaS·PaaS·SaaS 적용 계획이 명시되어 있고 클라우드 플랫폼 제품명이 미공개 → OpenShift/RHEL 제안 접점 탐색 가능
  • CI/CD·자동화 환경: Jenkins 기반 CI/CD 파이프라인, SSH CA 인증방식 전환, 형상관리(SVN), 빌드·배포 자동화 등 Ansible Automation Platform 적용 가능한 자동화 수요 존재
  • 재판지원 AI 시스템: DocumentDB·VectorDB 운영, 데이터 파이프라인, LLM 기반 AI 시스템 — OpenShift AI(RHEL AI) 제안 접점 탐색 가능
  • 오픈소스 응용SW 관리 명시: PSR 항목에 "오픈소스 응용SW 운영 및 유지보수·상용 응용SW 관리"가 별도 요구사항으로 명시되어 있어 Red Hat 오픈소스 상용 구독(RHEL, JBoss EAP 등) 도입·전환 협의 여지 있음
  • 현행 Red Hat 제품 도입 가능성: 현행 소프트웨어 구성이 비공개이므로, 방문 열람을 통해 RHEL·JBoss EAP 등 기존 운영 현황 확인 후 구독 갱신·증설 기회 발굴 필요
  • RFP 내 Red Hat 제품명 명시 사항: 없음 (방문 열람 필요)
