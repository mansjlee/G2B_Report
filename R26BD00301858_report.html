Red Hat 제안
불가능 요소
  • Red Hat 제품명 미명시: RFP 전반에 걸쳐 RHEL, OpenShift, Ansible, JBoss EAP 등 Red Hat 상용 제품명이 단 한 건도 명시되지 않음
  • Oracle DB 명시: DB는 Oracle DB로 명시되어 있으며 버전 업그레이드 및 데이터 이관 계획 포함 — Red Hat DBMS 제안 여지 없음
  • WAS 취약점 점검 대상에 경쟁 미들웨어 명시: Apache, Tomcat, JEUS, WebLogic이 취약점 점검 대상으로 명시되어 있어 WAS 영역에서 타사 제품 선호 가능성 존재
  • 가상화 SW 인증 요건: 가상화 소프트웨어는 국정원 보안기능확인서 취득 제품으로 한정 — OpenShift Virtualization 등 도입 시 사전 인증 보유 여부 확인 필수이며 현실적 장벽 존재
  • 보안 제품 국정원 인증 의무: 모든 보안 제품은 CC인증 및 국정원 보안적합성 검증필 필수 — Red Hat 보안 솔루션(ACS 등) 제안 시 해당 인증 충족 여부 별도 확인 필요
  • 온프레미스 구축: 클라우드 환경이 아닌 완전한 온프레미스 구조로 OpenShift 클라우드 서비스 형태 제안 불가
  • S/W 직접구매 품목 多: DBMS, 보안 솔루션 등 주요 품목이 조달쇼핑몰 직접구매로 발주되어 사업자의 S/W 선택권이 제한적
Red Hat 제안
가능 요소
  • OS 미지정 — RHEL 제안 가능성: AP서버 및 DB서버 VM 구성 시 OS를 "호환 가능한 UNIX 또는 Linux 제공"으로만 명시하여 특정 OS를 지정하지 않음 → RHEL 제안 여지 존재
  • 특정 OS·HW 종속 배제 요건: AI SW 요구사항(ECR-012)에서 특정 OS 및 특정 하드웨어에 종속되지 않는 구조를 요구 — RHEL이 이를 충족하는 범용 엔터프라이즈 Linux로 제안 가능
  • WAS 통합발주(20 core) — JBoss EAP 제안 가능성: WAS 20 core가 통합발주 품목으로 명시되어 있고 특정 제품이 지정되지 않음 → JBoss EAP 제안 여지 존재 (단, JEUS·WebLogic·Tomcat 등이 점검 대상으로 언급된 점은 경쟁 요소)
  • WEB 통합발주(16 core): WEB 소프트웨어도 통합발주 품목으로 특정 제품 미지정 — Red Hat 계열 Web 서버 솔루션 제안 가능
  • 연계(ESB) 통합발주(8 core): ESB 기반 연계 솔루션이 통합발주 품목 — Fuse(Red Hat Integration) 등 제안 여지 존재
  • AI·GPU 인프라 온프레미스 구축: 내부망 LLM 온프레미스 운영, GPU 서버 1식(H200×2ea 기준) 등 AI 인프라 구축 포함 — OpenShift AI(RHEL AI) 기반 ML 플랫폼 제안 가능성 검토 가능 (단, 국정원 인증 요건 충족 여부 확인 필요)
  • Ansible Automation Platform 제안 여지: 대규모 SI 구축 프로젝트로 VM 20EA 이상 구성 및 복잡한 연계 환경 — 인프라 자동화·구성 관리 도구로 Ansible 제안 가능성 존재
  • RFP에 명시된 Red Hat(동의어 포함) 제품명·수량: 없음 (Red Hat 상용 제품명은 RFP 내 일체 명시되지 않음)
  • 영업 전략 포인트: 약 207.9억 원 규모의 대형 차세대 SI 사업으로, 수주 사업자(SI)를 통한 RHEL·JBoss EAP·Ansible 등 서브 공급 채널 영업 접근이 현실적인 전략
