사업 개요 및 목적
  • 개인정보보호위원회가 운영하는 마이데이터 지원 플랫폼의 안정적 유지관리 및 운영을 위한 사업
  • 국민의 개인정보 전송요구권 행사를 지원하고, 이종 산업 간 마이데이터 활용 생태계 기반 조성
  • 클라우드 기반 인프라(멀티클라우드: 네이버클라우드 + 국가정보자원관리원 PPP)에서 24시간 × 365일 무중단 서비스 제공
  • 참여기관 기술지원, 헬프데스크 운영, 보안 취약점 점검, 신규 전송분야 연계 확대 등 포함

핵심 요구사항
  • [주요 기술 요구사항]
    • 플랫폼 응용SW(모바일앱, 연계시스템 포함) 및 인프라(SW, HW, 통신망) 전반의 유지관리
    • O/S, 상용S/W, 네트워크 변화에 따른 응용프로그램 점검 및 개선 (MPR-003)
    • 클라우드 기반 H/W 및 상용S/W 유지관리, 상용SW 버전관리·최신패치 적용 (월 1회 이상) (MPR-005)
    • CSAP 인증 유지관리 및 국정원 보안검증 운영기준 준수 (MPR-006)
    • 장애 대응체계 구축, 24×365 비상대응 운영, 모의훈련 연 1회 이상 (MPR-007)
    • SIEM 솔루션 운영, 부당전송 탐지·통제 정책 관리 (MPR-003, MPR-004)
    • 보안 취약점 점검(소스코드·인프라), 모의해킹 연 1회 실시 (MPR-009)
    • 개인정보저장소(PDS) 데이터 암호화·접근통제 정책 준수 (MPR-009)
    • 참여기관 연계체계 유지관리 및 테스트베드 운영 (MPR-010)
    • 헬프데스크 운영 (전문상담 인력 최소 2인 이상 투입, 단순질의 1일·오류 2일 이내 처리) (MPR-011)
    • 투입 인력은 민간 클라우드 운영환경(컨테이너 환경 개발기술 등)에서의 유지관리 지식·경험 필수 (MHR-001)
  • [구매 명시 S/W]
    • S/W 현황은 보안상 비공개 — 세부 모델·버전·수량은 발주기관 방문 열람 필요 (제안서 제출마감일 1일 전까지, 담당자 사전 연락)
    • 통합발주 또는 별도 구매 S/W 품목 목록이 RFP에 명시되지 않음
    • 간편인증 수수료, SMS·메일링 서비스, 클라우드 이용료, 웹접근성 품질인증, 도메인, TLS 인증서 등의 비용은 제안사 부담으로 납부·정산 (MPR-012)

불가능 요소
  • S/W 현황 비공개로 도입 품목 불확실: 인프라 상세 현황(모델, 버전, 수량 등)이 보안상 비공개 처리되어 Red Hat 상용 제품 도입 여부 사전 확인 불가
  • 상용 SW 직접 납품 항목 미명시: RFP 본문에 통합발주 S/W 목록이 없고, 주로 용역(유지관리·운영) 중심 사업으로 Red Hat 상용 제품 구독 구매가 직접 발주 항목으로 명시되지 않음
  • 경쟁 클라우드 플랫폼 고정: 네이버클라우드(민간 클라우드) 및 국가정보자원관리원 PPP 환경이 기구축·확정되어 있어, IaaS 레이어 교체가 사실상 불가
  • 기술적용계획표 상 Windows Server 포함: 서버용 운영체제 항목에 Linux뿐만 아니라 Unix, Windows Server 등이 함께 적용 대상으로 표기됨
  • 대기업 참여 제한: 중소·중견기업만 입찰 참가 가능(20억 이상 40억 미만), Red Hat Korea 직접 수주 불가 — SI/파트너 경유 필수
Red Hat 제안
가능 요소
  • 컨테이너 환경 명시: MHR-001에서 투입인력 요건으로 "민간 클라우드 운영환경(컨테이너 환경 개발기술 등)" 경험을 명시 → OpenShift / Podman 제안 여지
  • Linux 서버 운영 환경 명시: 기술적용계획표(붙임3)의 서버용 운영체제 항목에 Linux ○ 적용으로 표기 → RHEL 제안 가능
  • PaaS·IaaS 클라우드 환경: 기술적용계획표에 IaaS ○, PaaS ○ 적용 명시 → OpenShift Container Platform 등 제안 검토 가능
  • SIEM 솔루션 운영: 부당전송 탐지체계에서 "SIEM 솔루션" 운영 언급 → Red Hat Ansible Automation Platform(AAP)을 활용한 보안 자동화, 또는 OpenShift 기반 로그 수집 파이프라인 제안 여지
  • S/W 현황 비공개에 따른 기존 Red Hat 스택 사용 가능성: 현재 플랫폼의 상세 SW 구성이 비공개 처리되어 있어, 기존 인프라에 RHEL·OpenShift 등이 이미 사용 중일 가능성 존재 (열람 후 확인 필요)
  • RFP에 Red Hat 제품명 직접 명시: 없음 (비공개 SW현황 열람 후 확인 필요)
  • 파트너 제안 전략 권고: 컨소시엄 참여 중소 IT서비스사를 통해 Red Hat RHEL·OpenShift 구독 및 유지관리 항목을 제안서에 포함시키는 간접 제안 방식 검토
