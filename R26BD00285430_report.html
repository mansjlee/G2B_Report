불가능 요소
  • S/W 납품·구독 항목 전무: 본 RFP는 신규 소프트웨어 구매(납품·구독) 항목이 전혀 없는 순수 유지관리 용역 사업으로, Red Hat 상용 제품을 품목으로 제안할 수 있는 구조 자체가 존재하지 않음
  • Red Hat 상용 제품 미언급: RFP 전문에 걸쳐 RHEL, OpenShift, Ansible, JBoss/EAP, Satellite, AAP 등 Red Hat 상용 제품명이 단 한 건도 명시되지 않음
  • 기존 운영 환경 유지 중심: 사업의 본질이 현재 운영 중인 시스템(nTracker USB, SkyEleven, 행정업무통합시스템 등)을 현행 그대로 유지·운영하는 것으로, 신규 기술 스택 전환·도입을 요구하지 않음
  • 경쟁 제품 확정 여부: 특정 경쟁 OS(Ubuntu, Rocky Linux 등)가 명시되지는 않았으나, 기존 운영 환경 유지 조건상 OS 교체·대체 기회가 없음
  • 사업 규모 20억원 미만 제한: 대기업·중견기업 입찰 참여 제한 사업으로, Red Hat이 SI 파트너를 통해 제품을 공급하더라도 참여 업체 자격 구조상 제약이 있음

가능 요소
  • Linux 운영체제 명시(비특정): 기술적용계획표의 플랫폼·기반구조 분야에 서버용 운영체제로 "Linux"가 적용 항목으로 기재되어 있으나, 특정 배포판(RHEL, CentOS, Ubuntu 등)을 지정하지 않음 → 기존 서버 OS가 미확인 상태이므로 향후 관계 구축을 위한 간접적 접촉 여지는 있음
  • 서버 51대 운영 환경: 유지관리 대상 서버 51대(망간자료전송, 산출물관리 등)가 운영되고 있어, 이 중 일부가 RHEL 기반일 가능성을 배제할 수 없음 — 단, RFP 상 확인 불가
  • Red Hat 상용 제품 명시 없음: RFP에 Red Hat 또는 동의어(RHEL, OCP, Ansible, JBoss EAP 등) 품목이 전혀 명시되지 않아 실질적 제안 기회 없음
  • 종합 평가: 위 요소들은 모두 간접적·잠재적 수준에 불과하며, 본 사업은 SW 구매가 포함되지 않은 순수 유지관리 용역이므로 Red Hat 상용 제품 제안이 불가한 사업으로 판단됨
