OS 미지정 서버 교체·RHEL 제안 여지
사업 개요 및 목적
  • 태권도진흥재단의 노후화된 정보보안 장비(방화벽, DDoS, IPS) 및 네트워크 장비(백본·L3·L2·PoE 스위치)를 최신 장비로 교체하여 서비스 안정성과 보안성을 강화하는 사업
  • 백업시스템 신규 구축을 통해 정보시스템 재난·해킹 사고에 대응할 수 있는 체계를 마련
  • 로그저장 용도서버(유휴서버 활용) 및 파일서버 디스크어레이 구축, DNS/NTP 서버 이전을 포함한 서버 인프라 재정비
  • 장비 교체에 따른 보안정책·설정 이관, 운영 안정화 및 케이블 정리 등 통합 구축 서비스 제공

핵심 요구사항
  • [기술 요구사항]
    • 모든 장비는 제조사 정품·최신 사양으로 계약체결일 기준 12개월 이내 제조·출고품 납품
    • 정보보안 장비(방화벽, DDoS, IPS)는 CC인증(EAL4 이상) 또는 보안기능확인서 인증 제품 필수
    • 네트워크 장비(백본·L3·L2 스위치)는 단일 제조사 구성, 보안기능확인서 인증 제품
    • 유휴서버 2대의 OS를 보안 업데이트 지원이 중단되지 않은 운영체제로 변경 설치 (OS 제품명 미지정)
    • 백업시스템: 전체백업·증분백업·즉시복원 지원, 데이터 중복제거·WORM·VTL 기능 포함, 24TB 라이선스 영구 제공
    • EMS 솔루션과 각 장비 연동 설정 필수
    • 운영 안정화를 위해 시험운영 2주(14일) 수행 및 인력 7M/D 투입
  • [구매 명시 S/W 목록]
    • 백업 SW: 백업 어플라이언스에 포함된 통합 백업 소프트웨어 1식 (HW·SW 일체형, 제품명 미지정, 24TB 라이선스 영구 제공)
    • 서버 OS: 로그저장 용도서버(Lenovo SR250) 및 DNS/NTP 서버(HP ProLiant DL20 Gen10) 각 1대에 설치할 OS (제품명 미지정, "보안 업데이트 지원 중단되지 않은 운영체제" 조건)
    • ※ RFP에 "상용 SW 직접구매를 진행하지 않음" 명시 → 통합발주 형태로 SW 포함 납품
Red Hat 제안
불가능 요소
  • 기존 가상화 환경 VMware 명시: 현재 운영 중인 DNS서버·NTP서버가 VMware 가상화 서버(IBM x3650M4 4대, NetApp FAS3220 스토리지 2대) 기반으로 운영 중이며, 본 사업에서는 해당 가상서버를 유휴 물리 서버로 이전하는 것이 목적으로 VMware 대체 또는 OpenShift 전환은 사업 범위 밖
  • 백업 어플라이언스는 HW·SW 일체형: 백업시스템은 SW·HW 통합 일체형 어플라이언스로 요구되어 별도 Red Hat 솔루션(예: RHEL 기반 백업 환경) 제안 불가
  • Red Hat 상용 제품명 전혀 없음: RFP 전체에 RHEL, OpenShift, Ansible, JBoss 등 Red Hat 상용 제품이 품목으로 명시되지 않음
  • 상용 SW 직접구매 미진행: RFP에 "본 사업은 상용 SW 직접구매를 진행하지 않음" 명시 → 조달쇼핑몰 별도 구매 채널 활용 불가
  • 파일서버 OS는 Windows Server: 기존 파일서버 OS가 Windows Server 2022 Standard이며, 신규 파일서버 디스크어레이로 데이터·사용자·권한 이관이 목적으로 OS 변경 필요성 없음
Red Hat 제안
가능 요소
  • [OS 미지정 유휴서버 2대 → RHEL 제안 기회]
    • ECR-011(로그저장 서버): 수요기관 보유 유휴서버(Lenovo SR250)의 OS를 "보안 업데이트 지원이 중단되지 않은 운영체제로 변경 설치"하도록 요구 → OS 제품명 미지정으로 RHEL 제안 가능
    • ECR-013(DNS/NTP 서버): 수요기관 보유 유휴서버(HP ProLiant DL20 Gen10)의 OS를 동일 조건으로 변경 설치 요구 → RHEL 제안 가능
    • RHEL은 장기 지원(10년 이상), 보안 업데이트 지속 제공으로 공공기관 요구사항 부합
  • [Ansible 활용 가능성]: 다수의 네트워크 장비(총 110여 대) 설정 이관·보안정책 적용 자동화 작업에서 Ansible Automation Platform 제안을 통해 운영 효율화 가치 어필 가능 (단, 현 사업 예산 범위 내 추가 제안 필요)
  • [RFP 내 Red Hat(동의어 포함) 제품명·수량]: 없음 (명시된 Red Hat 상용 제품 없음)
  • [향후 확장 제안]: 기존 VMware 가상화 환경(IBM x3650M4 4대)이 노후화 단계에 있어 차기 가상화 인프라 교체 시 Red Hat Virtualization(RHEV) 또는 OpenShift Virtualization 전환 제안을 위한 관계 구축 기회로 활용 가능
