Red Hat 제안
불가능 요소
  • [S/W 신규 납품 없음] 본 사업은 기존 운영 중인 시스템의 운영지원 및 유지관리 용역이 핵심으로, 신규 상용SW 구매·납품·구독 항목이 명시되어 있지 않음
  • [Rocky Linux 사용 정황] RFP 내 월간 운영보고서 표준 양식(별첨 붙임6)의 SW 구성 예시에 "Rocky Linux"가 OS로 기재되어 있어 현행 시스템이 RHEL이 아닌 커뮤니티/대체 OS 기반일 가능성이 높음
  • [비 Red Hat 제품 스택 확인] 동일 예시 양식에서 Tibero(국산 DBMS), JEUS(국산 WAS), WebtoB(국산 웹서버) 등 Red Hat 제품과 무관한 한국형 미들웨어 스택이 확인됨
  • [시스템 상세 비공개] 실제 도입 상용SW 품목이 국가 보안 사유로 비공개 처리되어 있어 Red Hat 제품 포함 여부를 RFP만으로 확인 불가
  • [하도급 불허] 본 사업은 하도급 불허 조건으로, Red Hat이 파트너를 통해 간접 참여하는 구조도 어려움
  • [중소기업 전용 입찰] 20억 미만 사업으로 대기업·중견기업 참여 제한 — Red Hat 코리아 직접 입찰 불가
Red Hat 제안
가능 요소
  • [비공개 상용SW 내 RH 포함 가능성] 자원관리 7식·상황관리 10식의 상용SW 목록이 보안 사유로 비공개 처리되어 있어, 이 중 일부가 RHEL 또는 Red Hat 제품일 가능성을 완전히 배제할 수 없음 (현장 열람 후 확인 필요)
  • [Linux 서버 환경] 기술 적용계획표에 "Linux" 서버 운영체제가 적용 항목으로 명시되어 있어, OS가 RHEL 계열이라면 유지관리 계약 참여 접점 존재
  • [HW/SW 교체 사업 연계] RFP에 "HW/SW 교체, PoC 개발사업의 인계·기술이관" 업무가 포함되어 있어, 교체 대상 SW에 Red Hat 제품이 포함될 경우 향후 기회로 연결 가능
  • [RFP 내 Red Hat 제품명 명시] 없음 — RHEL, OpenShift, Ansible, JBoss EAP, Satellite 등 Red Hat 상용 제품명 및 동의어 일체 미확인
