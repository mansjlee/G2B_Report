Red Hat 제안
불가능 요소
  • S/W 공급 포함 여부: S/W 통합발주 항목 다수 포함된 사업으로, S/W 미포함 순수 용역이 아님 → 제안 불가 사유 해당 없음
  • 경쟁 제품 명시 여부: VMware, Ubuntu, Oracle Linux, Rocky Linux 등 Red Hat 직접 경쟁 OS·가상화 제품은 RFP 본문에 명시되지 않음. 단, 현행 시스템 DBMS는 Oracle 11g, WAS는 티맥스소프트 JEUS, 웹서버는 티맥스소프트 WebToB를 운영 중으로, WAS·WEB 부문은 비Red Hat 제품 우위 가능성 존재
  • 선호 제품 명시(경쟁 상황): DB 암호화는 CubeOne 선호, 서버 백신은 V3(안랩) 선호로 명시되어 있어 해당 품목은 Red Hat과 무관
  • SI 사업 특성: 대형 SI 통합 사업자(수행사)가 납품·구축하는 구조이므로 Red Hat이 단독 입찰하기 어렵고, 파트너사를 통한 간접 영업 필요. 단, 이는 높음 판정 하향 사유가 아님
  • Ansible 자동화·JBoss EAI 관련: RFP에 Ansible, JBoss 등 Red Hat 미들웨어 제품명이 직접 명시되지 않아 해당 영역은 사양 미지정 상태
