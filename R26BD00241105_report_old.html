사업 개요 및 목적
  • 충청북도 교육복지우선지원사업 지정 초·중학교(91개교, 약 38,000명) 대상 우수 민간 온라인 교육 콘텐츠 구독권을 제공하여 취약계층 학생의 교육·정보격차 및 양극화를 해소하고 자기주도적 학습 역량을 함양하는 것이 핵심 목표임
  • 「다차원 학생성장 플랫폼 다채움」(http://dcu.cbe.go.kr)과 SSO·학습데이터(xAPI) 연동을 통해 통합 로그인 및 학습 이력·분석·통계 서비스를 제공하는 것이 추진 방향임

  • 주요 일정: 계약방식 협상에 의한 계약(일반경쟁입찰), 제안서 평가는 조달청 공고 일정 따름, 착수계·사업수행계획서 등은 계약일로부터 10일 이내 제출, 과업심의위원회 개최 예정

Red Hat 제안
불가능 요소
  • S/W 공급 미포함: 본 사업은 인프라·OS·미들웨어 구매가 아닌 민간 에듀테크 콘텐츠 구독권 및 연동 용역이 핵심이며, Red Hat 제품 납품 항목이 RFP에 없음
  • 경쟁·타사 제품 명시: 다채움 SSO는 KsignAccess V4.1 기반으로 기 구현 중이며, 콘텐츠는 CP사 클라우드 서버 스트리밍 제공으로 지정되어 Red Hat 직접 제안 대상이 아님
  • 참가자격 제약: 「이러닝 산업발전 및 이러닝 활용 촉진에 관한 법률」상 이러닝사업자 신고 업체 자격 필수로, Red Hat 단독 또는 주사업자로서의 직접 입찰 구조에 부합하지 않음
  • 평가·과업 특성: 정성평가 70점이 콘텐츠 구성·운영환경·학습지원 등 에듀테크 역량 중심이며, RHEL/OpenShift/Ansible 등 인프라 솔루션 평가 항목 없음
  • 기술적용계획표: Linux·Windows Server 등은 선택적 적용 기술로만 기재되어 있으나, 조달 대상 S/W로 명시되지 않음
Red Hat 제안
가능 요소
  • 간접 적용 가능성: CP사 교육 플랫폼·클라우드 백엔드가 Linux 기반일 경우 RHEL 서브스크립션을 CP·SI 파트너 경유로 제안할 여지는 있으나, RFP상 직접 요구·평가 항목은 아님
  • 기술적용계획표: 플랫폼 분야에서 Linux, IaaS/PaaS/SaaS, RESTful API, 클라우드 보안(CSAP) 등이 적용 대상으로 표기되어 있어, 제안사가 자체 플랫폼·연동 시스템을 구축할 경우 오픈소스·Linux 기반 아키텍처 설명에 RHEL 활용을 부가 제안할 수 있음
  • 제한적 연계: xAPI·SSO·API 연동, 원격지 개발 보안, 컨테이너·자동화 운영 등은 Red Hat(OpenShift, Ansible) 강점과 부합하나, 본 RFP는 해당 인프라 구축·구매를 발주하지 않고 콘텐츠·연동 용역에 집중함
  • 권고 전략: Red Hat 직접 납품보다는 이러닝 CP사·SI·유지관리 업체와의 공동수급 또는 하위 파트너(간접) 형태로 Linux/클라우드 표준 준수를 보조 제안하는 수준에 그침
