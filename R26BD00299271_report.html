Red Hat 제안
불가능 요소
  • 신규 S/W 구매·납품 항목 없음: 본 사업은 기존 위성시스템 운영·유지관리 용역으로, RFP 공개 범위 내에서 Red Hat 상용 S/W의 신규 도입·납품·구독 품목이 명시되지 않음
  • 경쟁 OS 명시: SER-009 보안 요구사항 내 보안지원 종료 운영체제 현황 표에 Ubuntu(20.04/22.04/24.04/25.04/25.10 LTS), Debian(11/12), Rocky Linux(8.9/8.10/9.6/9.7/10.0/10.1), Oracle Linux 9, Fedora(41/42/43)가 현행 운영 환경으로 열거되어 있음 — 경쟁 Linux 배포판 운영 환경이 혼재
  • 유지관리 대상 S/W 목록 별도 열람: [붙임 1] 유지관리 대상 물품 내역이 보안서약서 제출 후 현장 방문 열람만 가능하여, Red Hat 상용 제품 포함 여부를 현재 텍스트만으로는 확인 불가
  • CentOS 7 명시: SER-009에서 "보안지원이 중단 예정인 운영체제(CentOS 7 등)에 대한 교체 방안 마련" 요구 — CentOS 7은 커뮤니티 제품으로 그 자체가 Red Hat 상용 제안 근거가 되지 않음
  • 인터넷 연결 금지(COR-001) 및 외부 원격 작업 금지(COR-002): 보안 제약으로 인해 Red Hat 클라우드 기반 구독 관리(Satellite, RHSM 등) 적용이 제한적일 수 있음
Red Hat 제안
가능 요소
  • CentOS 7 교체 기회 → RHEL 전환 제안 가능: SER-009에서 CentOS 7 등 보안지원 종료 OS 교체 방안 마련을 명시적으로 요구하고 있어, RHEL로의 전환·마이그레이션 제안 여지가 존재함
  • RFP 내 Red Hat 운영체제 지원종료 일정 명시: SER-009 보안지원 종료 OS 현황표에 "Red Hat 7 (2024-06-30), Red Hat 8 (2029-05-31), Red Hat 9 (2032-05-31)"이 기재됨 — 이는 현재 Red Hat 계열 OS가 위성시스템에 운영 중임을 시사하나, 제품명이 "Red Hat"(회사명 수준)으로만 표기되어 정확한 상용 제품명(RHEL) 확인은 미흡 (중간 판정 근거)
  • 상용 S/W 운영·관리 범위 포함: 사업 범위 내 "상용 S/W 분야(OS, DBMS, 미들웨어 등)" 운영 지원이 명시되어 있어, 유지관리 대상 목록([붙임 1] 별도 열람) 확인 시 RHEL·JBoss EAP 등 Red Hat 상용 제품이 포함될 가능성 있음
  • MOR-002 시스템 운영지원 범위: "운영체제, 클러스터링 SW, HPC Workload관리 SW, DBMS, WEB/WAS, 백업SW 등 SW 관리"가 과업에 포함 — WEB/WAS 영역에서 JBoss EAP, OpenShift 등 제안 여지 존재
  • RFP 내 Red Hat 제품명·수량 명시 현황: RFP 공개 텍스트 기준, Red Hat 상용 제품명(RHEL, OpenShift, JBoss EAP 등)이 품목으로 직접 명시된 사례 없음 — 단, SER-009 표에 "Red Hat 7/8/9" 지원종료 일정이 현행 OS로 열거되어 있어 간접적으로 Red Hat OS 운영 환경 추정 가능
  • CentOS→RHEL, 보안지원 종료 OS 교체 컨설팅 기회: 보안지원 종료 OS 다수(CentOS 7, Ubuntu 20.04 등) 운영 중으로 추정되므로, 유지관리 수행 과정에서 RHEL 전환 제안 및 Satellite를 활용한 패치 관리 자동화 제안 가능
  • 고보안 환경의 Ansible 자동화 제안 가능성: 인터넷 차단 환경에서도 Ansible Automation Platform(오프라인 설치 지원)을 활용한 패치·구성 자동화 방안 제안 가능
