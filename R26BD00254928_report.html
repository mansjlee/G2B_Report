Red Hat 제안
불가능 요소
  • **S/W 공급 범위**: 본 사업은 SI(설계·개발·인프라 구축) 용역 중심이며, Red Hat이 직접 납품 주체가 아닌 구조; 상용 SW 일부는 공단 직접구매(별첨1)로 분리
  • **DBMS 고정성**: 통경 Oracle 11G, 올바로·면허 Tibero 운영; 사진검증 DB는 「기존 운영 DBMS와 동일 DBMS」 설치 명시 → Oracle/Tibero 계열 지속, RHEL은 OS로만 접근
  • **애플리케이션 스택**: 전자정부 표준프레임워크·Java/JSP·InHouse 개발 고정, JBoss/WildFly 등 WAS 지정 없음; e-gov 표준과 기존 공통모듈 우선
  • **경쟁·대체 기술 명시**: SFR-72 AI 모니터링에 OpenSearch 기반 이상탐지 엔진 명시(Elastic/OpenSearch 스택); LLM·벡터 DB는 벤더 비특정이나 Red Hat OpenShift AI 직접 지정 없음
  • **회계·예산 솔루션**: 전략예산 상용솔루션 운영, 회계 상용솔루션 벤치마킹·검토 요구 → ERP/회계 패키지 영역은 Red Hat 직접 대응 한계
  • **평가 구조**: 기술 90% SI 역량·방법론·기능구현 중심; Red Hat 제품 단독 지정·가점 없음, 국산제품 활용 기여도(2점)는 별지19호서식 기준
  • **기타**: VMware·Ubuntu·Rocky Linux 등 특정 경쟁 OS 명시는 없으나, ECR-01에서 「검증된 오픈소스 SW 또는 무상 SW 제안 가능」 → RHEL 유료 구독 대비 무상 Linux 경쟁; 컨테이너·OpenShift는 개선방향 수준 언급, 필수 요구 아님
