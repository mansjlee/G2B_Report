Red Hat 제안
불가능 요소
  • RFP 내 Red Hat 상용 제품명 미명시: RHEL, OpenShift, Ansible, JBoss EAP 등 Red Hat 상용 제품이 도입 품목, 유지관리 대상 SW 목록, 운영 환경 어디에도 명시되지 않음
  • 신규 S/W 구매 항목 없음: 본 사업은 운영·유지관리 용역 중심으로, 신규 상용SW 도입·납품·구독 항목이 별도로 명시되어 있지 않아 Red Hat 제품의 직접 납품 기회는 없음
  • 경쟁 제품 명시 없음(단, RH도 없음): Ubuntu, Rocky Linux, Oracle Linux 등 경쟁 OS가 명시적으로 지정되지는 않았으나, Red Hat 상용 제품도 명시되지 않음
  • 중소기업 제한 입찰: 20억 미만 사업으로 중소기업자만 입찰 참가 가능 — Red Hat이 직접 입찰할 수 없는 구조이며, SI·통합운영 사업자를 통해 간접 접근해야 함
  • 상세 SW 목록 비공개: 패키지SW 현황은 방문 열람만 가능하여 현행 운영 중인 Red Hat 제품 존재 여부를 RFP 문서만으로 확인 불가
Red Hat 제안
가능 요소
  • 상용/공개 SW 유지관리 대상 포함: RFP MAR-010에 "상용/공개 소프트웨어의 버전 업그레이드·패치관리"가 명시되어 있으며, SW 유지관리 대상에 시스템SW·패키지SW가 포함됨 → 현행 운영 환경에 RHEL 또는 JBoss가 존재할 가능성 배제 불가
  • 서버 시스템 운영 환경: 서버 1대 및 국가정보자원관리원(대구센터) 입주 SW 운영 포함 → 서버 OS로 RHEL이 사용될 수 있으며, 상세 SW 목록 열람 시 확인 필요
  • 보안SW 1,230식 대규모 유지관리: 대규모 보안SW 운영 환경에서 Ansible Automation Platform 기반 패치 자동화, 보안 취약점 자동 조치 등 제안 가능
  • AI 플랫폼 도입 지원 컨설팅 요구(MAR-019, 평가항목): "신기술(AI 등) 활용을 위한 플랫폼 이행계획 컨설팅 지원" 및 기술성 평가항목 "운영 혁신성(AI 플랫폼 도입 지원)"이 명시 → Red Hat OpenShift AI, RHEL AI 등 AI 플랫폼 제안 여지
  • 인터넷VDI·클라우드 연계 운영: 5G정부망(VDI), 국가정보자원관리원 클라우드 환경 운영 포함 → OpenShift/컨테이너 플랫폼 기반 제안 가능성
  • RFP 내 명시된 Red Hat(동의어) 제품명·수량: 없음 (RFP 문서 내 Red Hat 상용 제품명 직접 기재 없음)
  • 영업 접근 전략: 낙찰 예정 중소 SI 사업자를 통한 하도급 또는 협력사 채널로 RHEL 구독, Ansible 자동화 솔루션, OpenShift AI 컨설팅 제안 접근 권장. 사업 착수 전 발주기관 방문 열람을 통해 현행 SW 목록 내 Red Hat 제품 존재 여부를 반드시 확인할 것
