Red Hat 제안
불가능 요소
  • 신규 S/W 구매·납품·구독 항목 없음: 본 사업은 기존에 운영 중인 응용·상용 소프트웨어에 대한 순수 유지관리 용역으로, 신규 소프트웨어 도입·납품·라이선스 구매 항목이 전혀 없음
  • Red Hat 상용 제품명 미명시: 유지관리 대상 상용 S/W 목록(25개 품목)에 RHEL, OpenShift, Ansible, JBoss EAP, Satellite 등 Red Hat 상용 제품명이 단 한 건도 포함되어 있지 않음
  • 기존 운영 환경에 Red Hat 제품 흔적 없음: RFP 전반(현행 시스템 구성, 유지보수 대상 S/W 목록, 운영 환경, 기술적용계획표 등)에서 "Red Hat", "RHEL", "JBoss", "OpenShift", "Ansible" 등 Red Hat 관련 문구가 전혀 발견되지 않음
  • 경쟁 가상화 제품(VMware) 명시: 상용 S/W 목록에 vSphere 8, vCenter Standard 8(VMware 제품)이 기술협약 대상으로 명시되어 있어 가상화 영역에서 Red Hat 제안 여지 없음
  • DBMS는 Tibero 계열 사용: DBMS로 Tibero 6/5 Enterprise Edition 및 Tibero 6 TAC가 사용 중이며, Red Hat 제품과 무관한 국산 DBMS 환경
  • WAS/웹서버는 티맥스 계열 사용: JEUS Standard v8(웹서버), WebtoB Standard v5(WAS)가 운영 중이며, Red Hat JBoss EAP 제안 여지 없음
  • 운영체제 미지정이나 Linux 계열 제안 여지 불명확: 기술적용계획표에 "Linux" 항목이 일반 기준으로 언급되나, 특정 배포판(RHEL 등) 지정 없이 일반 항목으로만 나열되어 있고, 현행 운영체제에 대한 구체적 명시 없어 RHEL 제안 근거 부족
  • 하도급 원칙 금지 및 공동수급 불허: Red Hat이 직접 입찰하거나 파트너를 통해 참여하기도 어려운 계약 구조
Red Hat 제안
가능 요소
  • RFP 내 Red Hat 제품명 명시 없음: RFP 어디에도 RHEL, OpenShift, Ansible Automation Platform, JBoss EAP, Satellite, Quay 등 Red Hat 상용 제품명 및 동의어가 기재되어 있지 않음
  • Java 기반 응용 SW 환경: 응용 S/W 26종 중 대부분이 Java 기반으로 개발되어 있어, 이론적으로 JBoss EAP 적용 가능성이 존재하나, 현재 WAS는 JEUS/WebtoB(티맥스)로 확정 운영 중이어서 실질적 제안 여지 없음
  • Linux 운영체제 언급(일반 기준): 기술적용계획표 운영체제 항목에 "Linux"가 일반 항목으로 포함되어 있으나, 특정 배포판 지정이 없고 현행 운영 환경의 OS가 명확히 공개되지 않아 RHEL 제안의 직접 근거로 삼기 어려움
  • 클라우드 환경(KT 클라우드): 응용 S/W 항목에 "KT 클라우드 서버 관리"가 포함되어 있으나, 이는 기존 운영 환경 유지 대상으로 Red Hat 클라우드 제품 도입 기회로 보기 어려움
  • 종합 의견: 본 사업은 신규 S/W 도입이 없는 순수 유지관리 용역이며, 기존 운영 환경에 Red Hat 상용 제품이 포함되어 있지 않음. 경쟁 제품(VMware vSphere/vCenter, JEUS/WebtoB, Tibero)이 유지관리 대상으로 확정되어 있어 Red Hat 제품 제안 가능성이 매우 낮음. 향후 차기 시스템 고도화·재구축 사업 발생 시 RHEL/OpenShift/Ansible 제안 기회를 모색하는 것이 현실적
