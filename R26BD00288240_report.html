  • 직접구매 대상 S/W 전량 타사 제품: 붙임 4(직접구매 대상 상용SW)에 해당하는 15종 모두 Red Hat 제품 없음 — 조달쇼핑몰 직접구매 대상에 Red Hat 없음

Red Hat 제안
가능 요소
  • Kubernetes 환경 기 도입 및 확장: 기 구축 클라우드 환경에 Kubernetes 1식, Container Registry 10식이 이미 도입되어 있으며, 본 사업을 통해 추가 확장 예정 → OpenShift Container Platform 제안 여지 (기존 K8s → OCP 전환 또는 증설 제안 가능)
  • CI/CD 자체 구축형 → Ansible/OpenShift GitOps 제안: CI/CD가 현재 자체 구축형(1식)으로 운영 중이어서 Red Hat Ansible Automation Platform 또는 OpenShift Pipelines로의 고도화 제안 가능
  • MLOps 환경 구축 요구: AI모델 파인튜닝·실증을 위한 MLOps 환경 신규 구축 과제 포함 → OpenShift AI(RHOAI) 제안 가능 (AI/ML 워크로드 오케스트레이션)
  • GPU 자원 활용 AI 워크로드: 기 도입 GPU(A100 8장, T4 17장) 및 추가 확장 예정 → OpenShift AI 기반 GPU 워크로드 관리 제안 가능
  • OS 플랫폼 미지정: 클라우드 서비스 기반 구조로 VM/컨테이너 OS가 특정되지 않음 → 클라우드 서버 OS로 RHEL 제안 가능
  • 보안 요구사항 강화: 의료데이터 보안 및 격리 분석 환경(보안 샌드박스) 요구 → OpenShift 기반 보안 격리 환경, ACS(Advanced Cluster Security) 제안 가능
  • 멀티 기관 연계 자동화: 광주·대구·대전 지자체 간 연계 시스템 구축 및 기술지원 → Ansible Automation Platform 기반 자동화 인프라 관리 제안 가능
  • RFP 내 Red Hat 제품명 직접 명시 없음: 판정 규칙상 "중간" 수준이나, 컨테이너/K8s/MLOps/CI-CD 복합 요건이 존재하여 SI 파트너를 통한 영업 활동 및 아키텍처 제안 추진 권장
