불가능 요소
  • [Red Hat 제품 전혀 미명시] RFP 전문에 RHEL, OpenShift, Ansible, JBoss EAP, Satellite 등 Red Hat 상용 제품명이 단 한 건도 언급되지 않음
  • [기존 비-Red Hat SW 유지관리 사업] 유지관리 대상 상용SW(SSO, EAI, 검색엔진, DB암호화, 웹로그분석 등)가 모두 Red Hat 제품군이 아닌 기존 도입 제품으로 구성되어 있으며, 신규 SW 도입이 아닌 기존 라이선스 유지관리 중심
  • [HW/인프라 외부 관리] 서버 HW 및 시스템 SW 인프라는 행정안전부 국가정보자원관리원(광주센터)에서 담당하므로 Red Hat이 OS·플랫폼 레이어에 직접 개입하기 어려운 구조
  • [TIBERO DBMS 환경] 개발 환경에서 DBMS로 TIBERO가 명시되어 있어 Red Hat 기반 데이터 플랫폼 제안 여지 없음
  • [20억원 미만 중소기업 전용 사업] 소프트웨어진흥법 제48조에 따라 대기업 및 중견기업 입찰 참여 제한 — Red Hat Korea의 직접 참여 불가
  • [순수 운영·유지관리 용역] 신규 시스템 구축이나 플랫폼 전환이 없으며, 기술 요구사항도 기존 환경 유지에 초점이 맞춰져 있어 Red Hat 스택을 새로 제안할 명분이 부재

  • [Linux 서버 OS 환경] 기술적용계획표 플랫폼·기반구조 분야에서 서버용 개방형 운영체제로 Linux가 적용 대상으로 체크되어 있어, 향후 OS 교체 시 RHEL 전환 제안 시도 가능 (단, 현재 구매 품목으로는 명시되지 않음)
  • [CI/CD 빌드배포 자동화 항목] 국세법령정보시스템 상용SW 유지관리 목록에 'CI/CD 빌드배포 자동화 2User, 18식'이 포함되어 있어, 계약 갱신 시점에 Ansible Automation Platform 또는 OpenShift GitOps 전환을 검토 제안할 여지가 있음 (현재 어떤 제품인지는 보안 사유로 비공개)
  • [Java/Spring 기반 애플리케이션] 전 시스템이 Java/JSP/Spring/Hibernate 기반으로 구성되어 있어 WAS 영역에서 JBoss EAP 전환 제안 여지가 있으나, 현 RFP에서 WAS 제품은 비공개(보안 사유)이며 WAS모니터링 SW만 언급됨
  • [클라우드 기반 인프라] 국가정보자원관리원 클라우드 환경에서 운영 중이며, 향후 컨테이너화 또는 플랫폼 현대화 과제와 연계하여 OpenShift 또는 RHEL 제안의 간접적 레퍼런스로 활용 가능
  • [RFP에 명시된 Red Hat(동의어) 제품·수량] 없음 — Red Hat 상용 제품은 이 RFP에 전혀 명시되지 않음
