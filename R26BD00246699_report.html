한국승강기안전공단_2026년 정보시스템 인프라 개선 사업 - 분석 리포트

레드햇 제안 가능성 낮음
H/W 중심 SW 미포함
사업 개요 및 목적
  • 한국승강기안전공단의 노후 정보시스템 인프라(통합·데이터 스토리지, 네트워크)를 차세대 고성능 장비로 전면 교체하고, 무결점 데이터 마이그레이션을 통해 운영 안정성과 서비스 연속성을 확보하는 사업
  • AI 기반 데이터 분석 가속화를 위해 백본·서버팜 구간 10G 네트워크 체계로 전환하고, 행정안전부 표준 기관공유시스템(단독형) 및 GPU 기반 AI 개발·추론 인프라를 구축하여 국가공유데이터 플랫폼 연계와 승강기 안전 AI예측 모델 개발 기반을 마련
  • 인프라 변경에 따른 단계별 테스트·검증, 안정화 기간 운영, 기술이전을 통해 자체 유지관리 역량을 강화하는 것을 목표로 함
주요 정보
  • 사업 예산: 금 669,328천원 (VAT 포함, 약 6.69억원)
  • 사업 기간: 착수일로부터 3개월 (M~M+2: 분석/설계 → 장비 납품·설치 → 데이터 마이그레이션·테스트·검수)
  • 사업 범위: 차세대 스토리지 인프라 세대교체 및 데이터 이관, 10G 네트워크(L4/L3 스위치) 체계 전환, 행안부 표준 기관공유시스템(단독형) 및 AI GPU 서버 구축, 시스템 안정화·기술이전
  • 입찰·계약 방식: 제한경쟁입찰, 협상에 의한 계약 (기술평가 90%, 가격평가 10%)
  • 도입 장비: 통합운영 스토리지 1식, 데이터 스토리지 1식, SAN 스위치 2식, L4 스위치 2식, L3 광집선 스위치 2식, 국가공유데이터플랫폼·AI 개발서버 1식
  • 기타: 하도급·공동수급 불허, 중소 SW사업자만 입찰 참가 가능, 상용 SW 직접구매(구 SW분리발주) 대상 아님, 하자담보 1년

핵심 요구사항
  • 스토리지 교체·마이그레이션: NVMe All-Flash 통합운영 스토리지(1대) 및 SAN/NAS Unified 데이터 스토리지(1대) 도입, 기존 VSP G200(1식)·HUS130(1식) 스토리지 데이터 무결점·무중단 이관, 랜섬웨어 대응 스냅샷·원격복제 등 고가용성 구성
  • 네트워크 고도화: L4 스위치 2대(10G SFP+ 16포트 이상, CC인증 필수), L3 광집선 스위치 2대(2Tbps급, VXLAN/MPLS 등), 기존 가상화 인프라·10G 네트워크와 유기적 연계 및 통합관리, L4/L3는 각각 기존 운영장비·백본스위치와 동일 제조사 제품으로 제한
  • AI·데이터 연계 인프라: 행정안전부 표준 기관공유시스템(단독형) 설치, NVIDIA RTX PRO 6000 Blackwell Server Edition 96GB(또는 동급) GPU 1개 이상 탑재 AI 개발용 서버 1대, AI 프레임워크·개발환경·라이브러리 최적화 셋팅
  • 테스트·품질·보안: 단위·통합·성능·부하·인수 테스트, 43개 요구사항(SFR·PER·ECR·TER·QUR·PSR·DAR·PMR·SER·COR) 충족, 국가정보보안기본지침·행안부 정보보안 규정 준수, CC인증(EAL2+) 정보보호제품 납품
  • 통합발주 S/W (명시 수량): 본 RFP의 ECR(시스템 장비 구성) 요구사항에는 Red Hat 등 상용 S/W의 구매 수량이 직접 명시되어 있지 않음. 스토리지는 "제조사 전용 스토리지 OS", GPU 서버는 "AI 프레임워크·개발환경·라이브러리 최적화 셋팅"으로 기능 요구만 제시되며, 별도 S/W 품목·수량은 미기재
Red Hat 제안
불가능 요소
  • S/W 공급 범위 부재: 사업 범위가 스토리지·SAN·네트워크·GPU 서버 등 H/W 납품·설치·이관·테스트·기술이전 중심이며, RHEL·OpenShift·Ansible 등 Red Hat 제품의 구매 수량·라이선스가 RFP에 명시되지 않음
  • 경쟁/전용 제품·벤더 종속: 기존 스토리지(Hitachi VSP G200, HUS130) 마이그레이션 요구, 스토리지 "제조사 전용 OS" 및 OEM/ODM 제외, L4/L3 스위치 기존 제조사 동일 제품 제한, GPU NVIDIA RTX PRO 6000 Blackwell(또는 동급) 명시로 H/W 벤더가 사실상 고정
  • Red Hat 직접 대체 불가 영역: 통합운영·데이터 스토리지, SAN FC 스위치, L4/L7·L3 네트워크 스위치는 Red Hat 제품군(RHEL/OpenShift/Ansible/JBoss)으로 대체·납품 불가
  • 기타 제약: 하도급·공동수급 불허로 Red Hat 파트너가 SI 주사업자 자격(소프트웨어사업자·정보통신공사업·중소기업·직접생산확인증명)을 직접 충족해야 함, 기술평가 90%로 H/W 규격 충족·스토리지 납품 실적이 핵심 평가 요소
Red Hat 제안
가능 요소
  • GPU AI 서버 OS (간접): ECR-08 AI 개발용 서버에 OS가 특정 벤더로 고정되지 않았으므로, 제안사가 SI 주체일 경우 RHEL 또는 RHEL AI를 GPU 서버·AI 프레임워크 운영 OS로 제안할 여지는 있으나 RFP 필수 요건은 아님
  • 가상화·네트워크 연계 (간접): "기존 가상화 인프라와 10G 네트워크 연계·통합관리" 요구가 있어, 기존 환경이 KVM/RHEL 기반일 경우 RHEL 호스트·네트워크 연동 경험을 제안서 차별화 요소로 활용 가능(현행 구성도 비공개)
  • Ansible 자동화 (부가): 스토리지 이관·네트워크 설정·테스트 시나리오 자동화, 인프라 구성관리(IaC)를 Ansible로 제안하여 운영 효율·기술이전 품질을 보강하는 방식은 가능하나, 별도 S/W 조달 항목으로는 미포함
  • 한계: 본 사업의 핵심 납품물이 H/W이므로 Red Hat 라이선스 매출 기회는 매우 제한적이며, SI 제안사의 부가 기술·운영 OS 제안 수준에 그칠 가능성이 높음
