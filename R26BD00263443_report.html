한국지능정보사회진흥원_2026년 국가지식정보 품질개선 및 기술지원 사업 - 분석 리포트

레드햇 제안 가능성 중간
OS 미지정 클라우드·컨테이너 제안여지
사업 개요 및 목적
  • 국가지식정보(디지털집현전) 메타데이터의 품질 표준화 및 기관별 편차 해소를 통한 검색 정확도·데이터 활용성 제고
  • 수작업 중심의 비효율적 품질관리 체계를 AI·LLM 기반 자동화 체계로 전환하여 지속 가능한 품질관리 기반 확보
  • 생성형 AI 기술을 활용한 메타데이터 자동 생성·요약·키워드 추출 등 국가지식정보의 질적 고도화 실현
  • MCP(Model Context Protocol) 기반 외부 개방형 연계 구조 구축으로 외부 AI 에이전트가 국가지식정보를 직접 활용 가능한 환경 조성
  • 6개 대상기관(한국과학창의재단, 국립중앙도서관, 식품안전정보원, 한국언론진흥재단, 한국학중앙연구원, 한국직업능력연구원)의 약 1.23억 건 메타데이터 품질 개선 지원

Red Hat 제안
불가능 요소
  • Red Hat 상용 제품 미명시: RFP 전체에 RHEL, OpenShift, Ansible, JBoss EAP, AAP 등 Red Hat 상용 제품명이 품목으로 전혀 명시되지 않아 "높음" 판정 근거 없음
  • S/W 통합발주 항목 부재: 별도의 상용SW 구매 목록(품목·수량)이 없으며, 인프라는 구독형 클라우드 서비스로 처리되어 라이선스 납품 기회가 명확하지 않음
  • 경쟁 제품 직접 명시는 없으나 대체 여지 존재: VMware, Ubuntu, Rocky Linux 등 경쟁 제품이 명시되지 않은 반면, 특정 클라우드 벤더 종속 가능성이 있음 (기존 디지털집현전 클라우드 환경 준용 조건)
  • 중소SW사업자 제한: 20억원 미만 사업으로 대기업·중견기업 입찰 불가 — Red Hat Korea가 직접 입찰 불가하며, 파트너사를 통한 간접 제안만 가능
  • 기존 시스템 연속성 제약: 기 구축·운영 중인 디지털집현전 클라우드 환경을 준용해야 하므로 기존 인프라 스택 변경이 제한적임 (COR-001, ECR-005)
Red Hat 제안
가능 요소
  • 컨테이너 전환 고려 명시 (OpenShift 제안 여지): ECR-001에서 "향후 디지털집현전 운영 플랫폼의 컨테이너 전환 등을 고려하여 유연한 시스템 아키텍처를 설계하여야 한다"고 명시 → OpenShift Container Platform 제안 포인트
  • 개방형 클라우드 플랫폼 권장 (RHEL/OpenShift 적합): ECR-006에서 "개방형 클라우드 플랫폼 기반으로 플랫폼 개발을 권장함" 명시 → RHEL 기반 클라우드 인프라 및 OpenShift 적용 제안 가능
  • GPU 기반 LLM 추론서버 (RHEL AI 활용 가능): ECR-002에서 GPU 추론서버 구성 요구 → RHEL AI 또는 RHEL 기반 AI/ML 워크로드 환경으로 제안 가능
  • OS 미지정 Linux 서버 환경 (RHEL 제안 여지): 기술적용계획표(붙임4)에서 "Linux" 서버용 운영체제를 지원 항목으로 명시하나 특정 배포판 미지정 → RHEL 제안 가능
  • 대용량 병렬처리·수평 확장 아키텍처 요구 (OpenShift/Ansible 강점 부합): PER-001에서 수평 확장 가능 아키텍처, 병렬 실행 구조 요구 → OpenShift의 Auto-scaling, Ansible Automation Platform(자동화 운영) 제안 적합
  • MCP 기반 API 연계·AI Agent 오케스트레이션 (OpenShift AI 활용 가능): SFR-008에서 MCP Gateway 기반 외부 AI Agent 연계 체계 구축 요구 → OpenShift AI를 통한 AI 워크로드 오케스트레이션 제안 포인트
  • RFP 내 Red Hat 제품명 직접 언급: 없음 (Red Hat 상용 제품 명시 없음)
