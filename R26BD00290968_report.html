Red Hat 제안
불가능 요소
  • 순수 유지관리 용역 사업: 본 사업은 기존 도입 정보시스템의 유지관리·운영 지원 용역으로, 신규 S/W 납품·구독 항목이 존재하지 않음. Red Hat 상용 제품(RHEL, OpenShift, Ansible, JBoss EAP 등)을 신규 도입할 예산 및 근거가 없음
  • Red Hat 상용 제품 전혀 미명시: RFP 본문, 요구사항, 유지관리 대상 목록(붙임1) 전체에서 RHEL, OpenShift, Ansible, JBoss EAP, Satellite 등 Red Hat 상용 제품명이 전혀 등장하지 않음
  • 경쟁 DBMS 기존 운영 중: Oracle 12.2.0.1 SE(홈페이지 DB), Oracle 12g(KOLAS DB)가 유지관리 대상으로 명시되어 있어 기존 스택 교체 여지 없음
  • 대기업 입찰 참가 제한: 사업금액 20억 미만으로 중소 소프트웨어사업자만 참여 가능하여 Red Hat Korea 직접 입찰 불가
  • 기존 시스템 그대로 유지 원칙: 기 도입된 장비·SW를 현행 상태로 안정적으로 운영하는 것이 목표이므로, 플랫폼 전환·대체 제안 여지가 구조적으로 없음
Red Hat 제안
가능 요소
  • 제안 가능 요소 매우 제한적: 본 사업은 순수 유지관리 용역으로 Red Hat 상용 제품 직접 제안 기회는 없음
  • Linux 운영체제 유지관리 포함: 기술적용계획표(붙임2)에서 서버용 Linux 운영체제 유지관리 항목이 적용 대상으로 포함됨. 서버 OS 패치·업그레이드 수행 과정에서 RHEL 운영 환경이 확인될 경우 향후 갱신(Renewal) 영업 연계 가능성이 있으나, 현재 RFP에서 구체적 OS 종류 미확인
  • 서버 OS 업그레이드·마이그레이션 언급: 유지관리 범위에 "기존 시스템 소프트웨어의 기능 보완을 위한 OS 업그레이드 및 migration"이 포함되어 있어, 사업 수행 중 OS 전환 논의가 발생할 경우 RHEL 전환 제안의 간접적 접점이 될 수 있음 (단, 현재 사업 범위 내 가능성은 낮음)
  • RFP 내 Red Hat(또는 동의어) 제품명·수량: 해당 없음 — RFP 전체에 걸쳐 Red Hat 상용 제품명이 단 한 건도 명시되지 않음
