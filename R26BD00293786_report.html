Red Hat 제안
불가능 요소
  • 유지관리 용역 중심 사업: 본 사업은 SW 신규 구매·납품이 아닌 기존 정보시스템 유지관리 용역이므로, Red Hat 구독 라이선스를 신규로 직접 발주·납품하는 조달 기회는 제한적임
  • 경쟁 OS 다수 존재: 공개SW OS 항목에 CentOS, Rocky Linux, Ubuntu가 명시되어 있어 RHEL과 경쟁 관계에 있는 OS가 이미 운영 중임
  • VMware 명시: 기타 상용SW 항목에 VMware가 명시되어 있어 가상화 영역에서 Red Hat Virtualization/OpenShift와 경쟁 관계
  • WildFly 명시: 공개SW WAS 항목에 WildFly가 명시되어 있어, JBoss EAP 상용 전환 대상이나 현재는 커뮤니티 버전 사용 중
  • 대기업 입찰 불가: 40억 미만 사업으로 대기업 참여 제한 — Red Hat 직접 입찰 불가, SI 파트너를 통한 간접 참여 방식 필요
  • SW사업 영향평가 미대상: 상용SW 구매·설치·유지관리 사업으로 분류되어 영향평가 대상 제외 — 별도 레드햇 도입 확대 검토 채널 제한
Red Hat 제안
가능 요소
  • Red Hat 상용 제품 기존 도입 확인 (높음 판정 근거):
    • OS 항목(56식)에 "RedHat"(Microsoft, IBM과 나란히 상용 OS로 명시) — RHEL 상용 구독 기존 도입 확인
    • WAS/WEB 항목(47식)에 "JBoss" 명시 (상용 JBoss EAP 포함 가능성 높음)
    • 공개SW 항목에 "Redhat Ent"(Red Hat Enterprise Linux) 및 "Jboss EAP" 별도 명시 — 상용 Red Hat 제품이 공개SW와 혼재하여 운영 중임을 명확히 확인
  • 유지관리 기술지원 기회: 기존 도입된 RHEL, JBoss EAP에 대한 유지관리 기술지원(패치, 장애처리, 버전 업그레이드 지원)이 사업 범위에 포함되며, SI 파트너가 Red Hat 기술지원확약서를 제출해야 함 (MAR-012 참조)
  • Red Hat 기술지원확약서 필수 제출 요건: RFP MAR-012에서 원공급사 또는 기술지원사의 기술지원확약서를 사업 착수 후 1개월 이내 제출 필수 — Red Hat이 SI 파트너에게 기술지원확약서 발행 기회
  • 오픈소스 기술지원 요구 (PSR-005): 오픈소스 OS, WAS/WEB, DBMS에 대한 유지보수 및 기술이전 방안 요구 — Wildfly→JBoss EAP, CentOS/Rocky→RHEL 전환 제안 기회
  • 가상화·클라우드 영역 (MAR-005): 가상화서버 유지관리 범위에서 OS, 가상화SW 점검·유지관리, 클라우드 전환 지원, PaaS 이미지 유지관리 명시 — OpenShift/RHEL 기반 클라우드 전환 제안 기회
  • RFP 내 Red Hat 제품 명시 현황 요약:
    • 상용 OS: RedHat (OS 56식 중 일부, 수량 미분리)
    • 상용 WAS: JBoss (WAS/WEB 47식 중 일부, 수량 미분리)
    • 공개SW 항목 내 상용 병행: Redhat Ent, Jboss EAP (503식 공개SW 내 병기, 수량 미분리)
  • 파트너 영업 전략: Red Hat이 직접 입찰할 수 없으므로(대기업 제한), 공동수급체 구성원으로 참여하는 SI 파트너(중소·중견기업)를 통해 RHEL, JBoss EAP 유지관리 기술지원 및 향후 구독 갱신·증설 기회 확보 전략 필요
