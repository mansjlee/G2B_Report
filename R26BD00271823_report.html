사업 개요 및 목적

  • 노후화된 웹 프레임워크(Spring Framework 3.XX, Java 1.8)를 최신 버전으로 전환하여 보안 취약점 해소 및 AI 연동 기반 마련
  • DB 표준화 및 메타데이터 정비를 통해 데이터 품질 향상 및 성능 최적화 수행

  • BioIN, BICS, 합성생물학·줄기세포 허브, 바이오미래포럼 등 모든 패밀리사이트 관리 기능을 통합하는 통합관리시스템 신규 개발

핵심 요구사항
  • [기술 요구사항]
    • Spring Framework 3.XX → 최신 버전(Spring 6.x/Boot 3.x), Java 1.8 → 최신 LTS 버전 전환 (javax→jakarta 패키지 전환 포함)
    • 전자정부 표준프레임워크(eGovFrame) 기반 개발 의무 적용
    • DB 표준화: 전체 테이블·컬럼 물리명 표준화, 행안부 공공데이터 표준 단어 매핑, 3 Phase·10 STEP 로드맵 수행
    • 생성형 AI 기반 외부정보 수집·분류·요약 자동화 관리 기능, 바이오 기업정보 분류 매핑 자동화 기능 개발
    • 외부 솔루션 연동 유지: JEUS/WebtoB(티맥스소프트 WAS), 검색엔진, SSO, 사이냅, 마이메일러
    • NTIS 연계(바이오 투자·성과 통계, 과제 연구자 정보), CRETOP 연계(중소벤처기업 정보)
    • 반응형 웹, HTML5 표준, 웹접근성(KWCAG 2.2), 크로스브라우징 준수
  • [구매 명시 S/W]
    • RFP 본문 내 통합발주 상용 S/W 품목 및 수량이 구체적으로 명시되어 있지 않음
    • "SW 분리발주 제도 준수" 조항에 따라 일부 상용 SW는 분리발주 예정이나, 제품명·수량 미기재
    • 하도급 계획서(붙임 7, 8호)의 직접 물품 구매 예정 계획란에 구체적인 HW·상용 SW 품목은 제시 없음
Red Hat 제안
불가능 요소
  • [S/W 납품 미포함]: 본 사업은 BioIN·BICS 시스템 고도화 및 통합관리시스템 개발 위주의 순수 SI 개발 용역으로, Red Hat 상용 제품(OS, 미들웨어, 플랫폼 등)의 납품·구독 항목이 RFP에 전혀 명시되어 있지 않음
  • [Red Hat 상용 제품명 전무]: RFP 전체 문서에 RHEL, OpenShift, Ansible, JBoss EAP, Satellite, AAP 등 Red Hat 상용 제품명이 단 한 건도 등장하지 않음
  • [기존 WAS 스택 고착]: 현재 운영 중인 외부 솔루션으로 JEUS/WebtoB(티맥스소프트 WAS/웹서버)가 명시되어 있으며, 전환 후에도 해당 솔루션과의 연동 유지가 요구됨 → JBoss EAP 제안 여지 없음
  • [전자정부 표준프레임워크 강제]: 개발 프레임워크를 전자정부 표준프레임워크로 의무 적용해야 하며, 특정 OS·미들웨어 도입 필요성이 설계 요건에 포함되지 않음
  • [컨테이너·클라우드 전환 요건 없음]: OpenShift/Kubernetes/컨테이너 플랫폼 도입 요건이 RFP에 존재하지 않으며, 온프레미스 기존 인프라 유지 기반의 애플리케이션 고도화 사업
Red Hat 제안
가능 요소
  • [제한적 Linux OS 제안 가능성]: 기술적용계획표 "플랫폼 및 기반구조 분야"의 서버용 운영체제 항목에 Linux가 옵션으로 포함되어 있으나, 특정 배포판은 지정되어 있지 않음. 이론적으로 RHEL 제안이 가능하나 인프라 납품 범위가 현 RFP에 포함되지 않아 실질적 기회 없음
  • [2027년 AI 온프레미스 도입 연계 가능성]: RFP 내 "2027년 AI 온프레미스 시스템 도입이 예정"이라는 언급이 있어, 차기 사업에서 RHEL AI / OpenShift AI 등을 대상으로 한 선행 영업 기회 탐색 가능. 단, 현재 사업 범위 외의 사안
  • [RFP 내 Red Hat 제품명 명시 없음]: RHEL, OCP, Ansible, JBoss EAP, AAP 등 Red Hat 상용 제품이 RFP 어디에도 품목으로 기재되지 않아 현 사업 내 직접 제안 근거 없음
