사업 개요 및 목적
  • 2024년 천안시 거점형 스마트도시 조성사업의 일환으로, 헬스케어 데이터 실증 및 수집을 목적으로 하는 사업
  • 단국대학교병원 병동 입원환자를 대상으로 비접촉 레이더 센서를 활용한 생체신호(심박수, 호흡수, 낙상, 수면 상태 등) 모니터링 시스템 구축
  • 천안시 내 3개소(천안청년몰 흥흥발전소, 부성2동 행정복지센터, 산업단지 관리공단)에 AI·IoT 기반 스마트 헬스케어존 구축
  • 수집된 헬스케어 데이터를 천안시 거점형 스마트도시 클라우드 및 통합관리시스템에 연계하여 디지털 헬스케어 기반 마련
  • 주관기관: 주식회사 SK플래닛 (솔루션사업팀)

Red Hat 제안
불가능 요소
  • Red Hat 상용 제품명 미명시: RFP 전체에 걸쳐 RHEL, OpenShift, Ansible, JBoss EAP 등 Red Hat 상용 제품이 단 한 건도 품목으로 명시되어 있지 않음
  • OS 특정 - Windows 확정: 건강관리 키오스크 OS로 Microsoft Windows 11 64bit 정품이 명시적으로 요구되어 있어, 해당 항목에 Linux/RHEL 제안 불가
  • S/W 구매 항목이 헬스케어 전용 솔루션 위주: 도입 소프트웨어는 생체신호 모니터링 분석 시스템, AI 헬스케어 분석, 모바일 앱, 키오스크 프로그램 등 헬스케어 도메인 전용 SW로 구성되어 있으며, Red Hat 기술 스택과 직접적인 연관이 없음
  • 클라우드 인프라 지정: 클라우드는 "천안시 거점형 스마트도시 클라우드"를 활용하도록 명시되어 있어 Red Hat 클라우드/플랫폼 신규 제안 공간이 제한적임
  • 사업 규모 제한: 20억 원 미만으로 대기업·중견기업 참여 불가이며, Red Hat 상용 제품 공급 기회가 구조적으로 제약됨
  • 경쟁 OS 명시: 키오스크에 Windows 11이 명시적으로 요구되어 있어 해당 HW 항목에서 Red Hat 계열 OS 제안 불가
Red Hat 제안
가능 요소
  • 서버/백엔드 OS 미지정: 클라우드 서버(WEB/WAS, API 서버, DB 서버) 운영체제가 RFP에 명시적으로 지정되어 있지 않아 이론적으로 RHEL 제안 여지가 있으나, 기존 천안시 거점형 스마트도시 클라우드 인프라를 활용하도록 명시되어 있어 실질적 제안 가능성은 낮음
  • 기술적용계획표 내 Linux 명시: 붙임6 기술적용계획표에 플랫폼·기반구조 분야에서 "Linux" 항목이 포함되어 있어, 서버 운영환경으로 Linux 계열 적용이 검토될 수 있음 (단, 기존 구축 클라우드 환경 의존도가 높아 Red Hat 상용 제품 신규 납품 가능성은 매우 낮음)
  • RFP에 명시된 Red Hat(또는 동의어) 제품명·수량: 해당 없음. RFP 전체에서 Red Hat 상용 제품명이 단 한 건도 명시되지 않음
  • 종합 평가: 실질적인 Red Hat 상용 제품(RHEL, OpenShift, Ansible 등) 납품 기회는 거의 없으며, 사업의 핵심은 헬스케어 전용 HW·SW 공급 및 시스템 개발 용역으로 Red Hat 영업 우선순위가 낮은 사업임
