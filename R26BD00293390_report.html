천안시_2024 천안시 거점형 스마트도시 조성사업(헬스케어 데이터 실증 및 수집) - 분석 리포트

레드햇 제안 가능성 낮음
자체개발 SW 위주, 키오스크 Windows 11 명시
사업 개요 및 목적
  • 2024 천안시 거점형 스마트도시 조성사업의 일환으로, 헬스케어 데이터 실증 및 수집을 목적으로 하는 사업
  • 건강취약계층 비접촉 모니터링 시스템 구축: 단국대학교병원 병동 침상에 비접촉 레이더 센서를 설치하여 환자의 생체신호(심박, 호흡, 자세, 낙상 등)를 실시간 수집·분석하고, 이상징후 발생 시 응급 알림을 제공하는 환자 안전관리 체계 구축
  • 스마트 헬스케어존 구축: 천안 시내 3개소(천안청년몰 흥흥발전소, 부성2동 행정복지센터, 산업단지 관리공단)에 AI·IoT 기반 다양한 건강측정 장비를 비치하여 시민 자가 건강관리 서비스를 제공하고, 수집된 데이터를 천안시 빅데이터 서버로 연계
  • 궁극적으로 첨단 디지털 헬스케어 기술의 의료·공공 현장 적용 가능성을 실증하고, 데이터 기반 건강관리 서비스 확산 기반 마련

Red Hat 제안
불가능 요소
  • 자체 개발 S/W 위주 사업: 도입 S/W 목록 전체가 커스텀 개발 방식(1식 단위)이며, RHEL·OpenShift·Ansible·JBoss EAP 등 Red Hat 상용 제품이 구매·통합발주 품목으로 단 한 건도 명시되어 있지 않음
  • 키오스크 OS 명시 - Windows 11: ECR-015(건강관리 키오스크 장비 사양)에서 운영체제를 "Microsoft Windows 11 64bit (23H2/24H2 빌드 이상)"으로 명시하고, 이미 EOL된 구버전 OS 사용 전면 금지로 RHEL 등 대체 불가
  • 기존 클라우드 인프라 활용: 서버/인프라는 "천안시 거점형 스마트도시 클라우드"(기구축)를 그대로 활용하도록 명시되어 있어 신규 OS·미들웨어·플랫폼 도입 여지 없음
  • Red Hat 관련 언급 전무: RFP 전체에 RHEL, OpenShift, Ansible, JBoss, Quay, Satellite 등 Red Hat 상용 제품명 또는 동의어가 전혀 등장하지 않음
  • 컨테이너·Kubernetes·PaaS 미언급: 시스템 구성에 컨테이너화, 오케스트레이션, 자동화 플랫폼 관련 요구사항이 없어 OpenShift·Ansible 제안 근거 부재
Red Hat 제안
가능 요소
  • 지정맥 리더기 디바이스 호환 OS 목록에 Linux 포함: ECR-014(지정맥 게이트웨이 사양)에서 "지원 OS: Windows, macOS, Android, Linux 호환"을 명시하고 있으나, 이는 말단 장치(디바이스) 호환성 표기로 서버 OS 구매 항목이 아님 — 제안 근거로 활용하기 어려움
  • 클라우드 백엔드 서버 운영환경 미지정: 천안시 스마트도시 클라우드의 내부 서버 OS가 문서에 명시되어 있지 않아 이론적으로 RHEL 운영 가능성이 전혀 없지는 않으나, 기구축 인프라 활용 조건이므로 실제 신규 도입 가능성은 극히 낮음
  • 결론: RFP 내 Red Hat 상용 제품 도입을 확인할 수 있는 근거가 없으며, 사실상 제안 가능 요소가 없는 사업으로 판단됨
