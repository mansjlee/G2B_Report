사업 개요 및 목적

Red Hat 제안
불가능 요소
  • Red Hat 상용 제품 전혀 미명시: RFP 전문에 걸쳐 RHEL, OpenShift, Ansible, JBoss EAP, Satellite 등 Red Hat 상용 제품명이 단 한 건도 등장하지 않음
  • OS 플랫폼이 경쟁 제품으로 명시: 건강관리 키오스크 OS로 Microsoft Windows 11 64bit 탑재가 필수 지정되어 있어 Linux 계열 OS 제안 여지 없음 (ECR-015)
  • 클라우드 인프라 별도 활용 명시: "천안시 거점형 스마트도시 클라우드 활용"으로 명시되어 있어 Red Hat OpenShift 등 플랫폼 신규 제안 공간이 없음. 클라우드 인프라 자체 도입 항목이 본 사업 범위 밖임
  • 순수 SI·개발·H/W 납품 사업 구조: S/W는 모두 자체 개발(맞춤형 개발) 방식이며, 상용 미들웨어·플랫폼 S/W를 별도로 구매·납품하는 항목이 없음
  • Red Hat·Linux·오픈소스 관련 일반 문구조차 부재: 기존 운영 환경, 유지보수 대상, 현행 시스템 구성 목록 어디에도 Red Hat, Linux, 공개SW 등 일반 문구가 전혀 기재되지 않음
  • 사업 규모 제약: 20억 미만 중소기업 전용 입찰로 Red Hat이 직접 참여하는 구조가 아님 (SI 사업자를 통한 간접 공급도 현재 RFP상 근거 없음)
  • 기술 스택이 RH와 무관: 기술적용계획표에서 서버 OS로 Windows Server·UNIX·Linux 등 범용 표현이 있으나, 특정 상용 Linux 제품 도입 요구 없이 개방형 기술 원칙만 명시
Red Hat 제안
가능 요소
  • RFP에 명시된 Red Hat 상용 제품명·수량: 없음 — RHEL, OpenShift, Ansible, JBoss EAP 등 어떠한 Red Hat 상용 제품도 명시되어 있지 않음
  • Linux 서버 환경 가능성 (매우 제한적): 기술적용계획표(붙임6)의 플랫폼 분야에서 서버 운영체제로 "Linux ○(적용)"가 기재되어 있으나, 이는 표준 기술 항목 체크 수준이며 특정 상용 Linux 제품 도입을 명시한 것이 아님. RHEL 제안의 근거로는 매우 약함
  • RESTful API, RDBMS 등 표준 기술 채택: 시스템 개발에 RESTful API, RDBMS, Java 등 Red Hat 기술 스택과 호환 가능한 표준 기술이 적용되나, 특정 제품 지정 없이 개방형 기술로 구현 원칙만 있음
  • 컨테이너·Kubernetes 언급 없음: 클라우드 인프라 구성, AI 분석 시스템, 마이크로서비스 관련하여 컨테이너·Kubernetes·PaaS 등의 요구사항이 전혀 없어 OpenShift 제안 여지도 없음
  • 결론: 본 사업은 헬스케어 H/W 장비 납품 + 맞춤형 S/W 개발 + 인테리어 구축이 핵심이며, Red Hat 상용 제품의 도입·납품·갱신 기회가 전혀 없는 사업 구조임. 레드햇 영업 관점에서 적극적인 제안 활동을 투자할 실익이 없음
