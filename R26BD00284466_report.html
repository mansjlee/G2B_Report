불가능 요소
  • 순수 유지관리 용역: 본 사업은 기존 도입 시스템의 유지관리·기술지원이 목적이며, 신규 S/W 납품·구독 항목이 사실상 없음 (라이선스 갱신은 기존 제품 대상)
  • Red Hat 상용 제품 미명시: RHEL, OpenShift, Ansible, JBoss EAP, Satellite 등 Red Hat 상용 제품이 기존 유지관리 대상 목록에 전혀 포함되어 있지 않음
  • 경쟁 DBMS 확정 사용 중: Oracle S/W 2식, MS-SQL, MySQL 등이 명시되어 있으며 기존 DB 환경으로 확정
  • 제조사 협력 목록에 Red Hat 부재: 기술지원확약서 제출 대상 15개 제조·공급사 목록에 Red Hat이 없음 (펜타시큐리티, 에스지에이솔루션즈, 한국휴렛팩커드 등으로 구성)
  • 중소기업 전용 사업: 추정예산 20억 미만으로 소프트웨어 진흥법에 따라 대기업 참여 불가 — Red Hat 본사 또는 대기업 파트너의 직접 참여 제한
Red Hat 제안
가능 요소
  • RFP 내 Red Hat(동의어 포함) 제품명·수량: 없음 (문서 전체에 Red Hat, RHEL, OpenShift, Ansible, JBoss 등 상용 제품명 일체 미기재)
  • OS 미지정 가능성: OS 업그레이드 및 유지관리가 요구사항에 포함되어 있으나, 특정 OS(Linux 배포판 포함)가 명시되지 않음 — 단, 기존 시스템 환경 유지가 전제이므로 신규 RHEL 제안 현실성 극히 낮음
  • 상용 S/W 라이선스 갱신 협의 여지: "갱신 목록에서 누락된 라이선스가 존재할 경우 계약일로부터 30일 이내 협의 후 추가" 조항이 있으나, 기존 환경에 Red Hat 제품이 없어 실질적 기회 없음
  • 종합 판단: 위의 제안 가능 요소는 모두 이론적 수준에 불과하며, 실질적인 Red Hat 제품 도입 또는 제안 기회가 없는 사업으로 판단됨
