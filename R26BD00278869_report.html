Red Hat 제안
불가능 요소
  • 순수 운영·유지관리 사업: 본 사업은 기존 구축된 시스템의 유지관리가 목적으로, 신규 S/W 납품·구독 항목이 RFP 내 어디에도 명시되어 있지 않음
  • Red Hat 상용 제품명 전무: RHEL, OpenShift, Ansible, JBoss EAP 등 Red Hat 상용 제품이 구매·도입 품목으로 단 한 건도 명시되지 않음
  • 특정 경쟁 OS 확정 미명시(단, 기존 환경 고착 가능성): Ubuntu, Rocky Linux, VMware 등 경쟁 제품이 직접 명시된 것은 없으나, 기존 운영 환경(S/W 58종, 11종)이 이미 확정된 상태로 새로운 OS·플랫폼 교체 기회는 없음
  • DBMS 분석환경 OS 다양성 요구: DBMS분석지원시스템은 조사 대상 기업 DB와 동일한 환경 제공이 목적으로, Oracle/MS-SQL/MariaDB/FireBird/Sybase/PostgreSQL 등 다양한 상용 DBMS 지원이 요구됨 → Red Hat 계열 OS 단독 적용 불가
  • 분석프로그램 Windows 기반 운영: 포렌식 분석프로그램은 Windows Vista 이상, Windows Server 2008 이상에서 실행되도록 관리 요구 → Linux 기반 제안 불가
  • 입찰 자격 제한: 중소기업·소상공인만 입찰 가능하여 Red Hat이 직접 입찰 불가, SI 사업자를 통한 간접 제안도 기존 시스템 유지관리 범위 내에서 신규 제품 추가 어려움
Red Hat 제안
가능 요소
  • Linux 기술 적용 확인: 기술적용계획표(별지 제13호 서식) 내 플랫폼 및 기반구조 분야에서 "Linux"가 서버용 운영체제로 적용(○) 항목에 체크되어 있어, 현재 시스템 일부에 Linux 운영체제가 사용 중임을 확인 가능
  • 가상화 환경 운영: DBMS분석지원시스템에 가상화 환경이 구성·운영 중이며, 기술적용계획표에 "가상화관리제품 보안기능확인서 필수"로 명시됨 → 향후 가상화 플랫폼 전환 시 RHEV/OpenShift Virtualization 제안 여지
  • OS 패치·업그레이드 관리 포함: OS 패치·업그레이드 주기적 관리가 유지관리 범위에 포함되어 있어, 기존 CentOS/기타 Linux 사용 환경에서 RHEL 전환 컨설팅 기회 이론적으로 존재
  • 전자정부 표준프레임워크 버전 업그레이드 대응: EOS/EOL 정책에 따른 행안부 배치 표준프레임워크 버전 업그레이드 요구 포함 → Java/WAS 환경 변경 시 JBoss EAP 전환 제안 여지 (다만 현재 채택 WAS 제품 미공개)
  • RFP 내 Red Hat 제품명 명시 없음: 본 RFP에서 Red Hat 또는 동의어(RHEL, OpenShift, Ansible, JBoss 등)로 명시된 제품·수량은 전무함
  • 종합 평가: 현재 사업 범위 내에서 신규 Red Hat 제품 납품 기회는 없으나, 차기 사업(시스템 고도화·재구축) 진행 시 Linux 운영 환경을 레퍼런스로 RHEL 전환, 컨테이너 기반 아키텍처 제안을 위한 관계 구축 단계로 활용 가능
