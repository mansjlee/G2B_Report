Red Hat 제안
불가능 요소
  • 신규 S/W 납품·구독 항목 없음: 본 사업은 기존 정보시스템의 통합 유지관리 용역으로, 신규 상용 S/W 도입·구매 항목이 RFP에 명시되지 않음. Red Hat 상용 제품(RHEL, OpenShift, Ansible 등)의 신규 납품 기회 없음.
  • VMware 가상화 플랫폼 확정 운용 중: 기존 가상화 인프라로 VMware VS6(2식)·VS7(2식)이 도입·운용 중이며, 본 사업은 이를 유지관리하는 것이 목적. Red Hat Virtualization(RHEV) 또는 OpenShift 기반 대체 제안 여지 없음.
  • Oracle DBMS 확정 운용 중: Oracle 11g Std가 DBMS로 명시되어 있으며, DB 운영 유지관리(MPR-012)가 요구됨. Red Hat Data Grid·AMQ 등 데이터 플랫폼 제안 여지 없음.
  • WEB/WAS로 Tmax(WebtoB/JEUS) 확정: 미들웨어가 Tmax 제품군으로 고정되어 있어 JBoss EAP 등 Red Hat 미들웨어 제안 불가.
  • Red Hat 상용 제품명 전무: RFP 본문, 상용S/W 목록, 기술적용계획표 어디에도 RHEL, OpenShift, Ansible, JBoss, Satellite 등 Red Hat 상용 제품 또는 동의어가 단 한 건도 명시되지 않음.
  • 중소기업 한정 입찰: Red Hat이 직접 참여할 수 없는 구조이며, SI 업체가 유지관리 사업자로 참여하는 구조로 Red Hat 제품 도입 결정권이 없음.
Red Hat 제안
가능 요소
  • 제한적 Linux OS 교체 가능성: 기술적용계획표에 서버용 운영체제로 UNIX, Windows Server, Linux가 열거되어 있으나 특정 배포판이 지정되지 않음. 서버 OS 패치·업그레이드(MPR-002) 항목에서 이론적으로 RHEL 전환을 논의할 여지는 있으나, 기존 시스템 그대로 유지가 목적인 사업 특성상 실현 가능성 매우 낮음.
  • Ansible 자동화 제안 가능성(간접): 서버·네트워크 장비 정기점검, 패치 관리, 구성 변경 관리(MPR-003, MPR-020) 등 자동화 필요 업무가 있으나, RFP에 자동화 플랫폼 도입이 명시되지 않아 Ansible Automation Platform 제안은 제안사의 자발적 부가제안 수준에 불과.
  • RFP에 명시된 Red Hat(또는 동의어) 제품명·수량: 없음. 문서 전체에 Red Hat 상용 제품명이 단 한 건도 등장하지 않음.
  • ※ 종합: 제안 가능 요소가 극히 미약하며, 실질적인 Red Hat 상용 제품 판매 기회는 본 사업에서 발생하지 않을 것으로 판단됨.
