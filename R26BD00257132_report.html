사업 개요 및 목적
  • 한국수자원공사(K-water)가 제주시 애월읍 지방상수도를 대상으로 상수관망 유지관리시스템을 구축·개선하는 S/W 구축 용역이다.
  • 노후 상수관망 정비사업(‘23~’28, 375.86억원)의 일환으로, ICT 기반 관망운영관리 체계를 확립하여 유수율 제고(목표 85%) 및 운영관리 효율 향상을 목표로 한다.
  • 제주시 동지역(서부) 현대화사업으로 기구축된 유지관리시스템을 활용하여 애월읍 관련 시스템을 보완·구축하며, 관망관리 Web 전환, 모바일 원격 모니터링, DB·시설물관리 개선, 요금정보·원격검침 연계, 시운전·교육을 수행한다.

불가능 요소
  • S/W 공급 미포함: 본 사업은 상용 S/W 구매·설치 사업(영향평가 ①항)이 아닌 소프트웨어 개발·변경·DB구축·엔지니어링 용역(⑦항)으로, Red Hat 제품 직접 납품 구조가 아니다.
  • 기존 전용 시스템 의존: 제주시 동지역 현대화사업 기구축 유지관리시스템을 활용·확장해야 하며, 기존 C/S 관망관리시스템과 동일 구성·기능을 Web으로 재구현해야 한다.
  • 경쟁·대체 S/W 명시: 상수도 관망감시(Autobase, InfoU), 관망관리(C-water-NAVI, Step-water) 등 수자원 전용 패키지 S/W가 유사 기능으로 명시되어 있다.
  • 플랫폼·환경 제약: 윈도우 기반 GUI 필수, HMI-SCADA·관망감시제어 등 OT/SCADA 영역 중심, MDM 기반 모바일 보안솔루션·VPN·일방향 전송장비 등 Red Hat 스택과 무관한 요건 다수.
  • 제안 참여 제약: 20억원 미만 SW사업으로 대기업·중견 SW사업자 참여 제한, 직접생산확인증명서(패키지소프트웨어개발 및 도입서비스) 필요, 중소기업·소상공인 확인서 필수.
  • 지식재산·산출물: 개발 산출물·소스코드가 발주처(K-water·제주도)와 공동 소유되며, 공공저작물 자유이용·반출 규정 적용.
Red Hat 제안
가능 요소
  • 간접 인프라 레이어: 기술적용계획표에 Linux 서버 OS, RDBMS, Java 등 개방형 플랫폼 항목이 포함되어 있어, 제안사가 Linux·Java 기반 Web 아키텍처를 제안할 경우 RHEL을 서버 OS로 간접 제안 가능하나 RFP에서 OS 지정은 없다.
  • Web·API·연계: Web방식 관망관리, RESTful·SOAP 웹서비스, 외부 시스템(요금·원격검침·GIS) 연계 요구는 Red Hat JBoss/Web Server 등 미들웨어 적용 여지가 있으나, 명시적 구매·도입 요건은 없다.
  • 보안·가용성: 24시간 무중단 운영, DMZ 분리, 계정/권한 관리, DB 암호화(검증필 암호모듈), 보안취약점 점검 등 엔터프라이즈 Linux·컨테이너 보안 모범사례와 부합하나, Red Hat 전용 요구는 아니다.
  • Ansible/OpenShift: 다수 블록·서버·연계 시스템 운영 자동화, DevOps 관점의 Ansible 또는 컨테이너 플랫폼 제안은 가능하나 RFP에 명시되지 않아 차별화 포인트 수준이다.
  • 현실적 접근: Red Hat은 SI/개발사 파트너 채널을 통해 RHEL·JBoss 등을 하위 레이어로 포함하는 간접 제안이 유일한 현실적 경로이며, Red Hat 단독 수주·직접 제안 구조는 부적합하다.
