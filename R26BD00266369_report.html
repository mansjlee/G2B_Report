불가능 요소
  • Windows OS 전면 명시: 모든 운영 PC 및 컨트롤 PC의 OS가 "최신 운영 OS(Win11) 포함"으로 명시되어 있으며, 서버에는 Windows Server Standard 2022가 통합발주 품목으로 지정됨 → RHEL 도입 여지 없음
  • 무인반납기 내장 OS: Windows 10 이상 LTSC가 ECR-013 요구사항에 명시적으로 지정되어 있어 대체 불가
  • Red Hat 상용 제품명 전무: 전체 RFP·과업지시서 어디에도 RHEL, OpenShift, Ansible, JBoss EAP 등 Red Hat 상용 제품명이 단 한 건도 언급되지 않음
  • 사업 특성: 본 사업은 도서관 ICT 체험 콘텐츠 구축 및 RFID 시스템 설치 중심이며, 엔터프라이즈 Linux/컨테이너 플랫폼이 개입할 서버 인프라 규모가 HPE DL20 Gen11 단일 서버로 매우 소규모
  • Client Agent SW 지정: 콘텐츠 관리 S/W로 "Client Agent (Standard Plus Version)"이 전 시스템에 지정되어 있어 Red Hat 기반 플랫폼 적용 여지 없음
Red Hat 제안
가능 요소
  • MSA 아키텍처 요구: SFR-012(스마트서비스 통합관리시스템)에서 MSA(마이크로서비스 아키텍처) 기반 설계를 명시적으로 요구하고 있으나, 서버 OS가 Windows Server 2022로 고정되어 있어 OpenShift/컨테이너 제안이 사실상 불가
  • 생성형 AI 연계 서비스: LLM·이미지 생성 API 연동 등 AI 서비스가 요구되나 특정 AI 플랫폼 미지정으로 Red Hat OpenShift AI 언급 여지가 있으나, 전체 스택이 Windows 기반으로 현실적 제안 어려움
  • 결론: 위 두 항목 모두 서버 OS로 Windows Server 2022가 지정된 상태이므로 실질적 제안 포인트로 활용하기 어려움. RFP 내 Red Hat(또는 동의어) 제품명·수량은 0건으로 확인됨
