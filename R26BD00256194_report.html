사업 개요 및 목적
  • 고려대학교 내 다양한 LLM(대규모 언어 모델)을 단일 통합 서비스로 제공하기 위한 멀티LLM 통합 플랫폼 구축 사업이다.
  • 생성형 AI 기반 8개 이상 LLM 연동, 통합 SSO 인증, AI 교육·연구 활용 플랫폼, REST/4종 API 연동, LLM 통합 모니터링, 데이터 수집·연동, 사용자 관리 서비스를 포함한다.
  • 교내 AI 서비스의 표준화, 보안 인증 통합, 멀티 LLM 운영 효율화 및 확장성 확보가 핵심 목표이다.

불가능 요소
  • S/W 공급 포함 여부: 본 사업은 LLM 통합 서비스 구축·운영 중심의 SI/플랫폼 사업으로, Red Hat 제품 단독 S/W 납품 사업은 아님
  • 경쟁 제품 명시: 추출 텍스트 내 VMware, Contrabass, Ubuntu, Oracle/Rocky Linux 등 경쟁 OS·가상화·LLM 플랫폼 제품명은 명시되지 않음
  • 기타 제약
  • 핵심 과업이 LLM 애플리케이션 통합·API·SSO·오픈소스 LLM 연계에 집중되어 Red Hat 직접 제안 비중이 제한적
  • GPU AI 워크로드에 특화된 LLM 프레임워크·MLOps 도구가 별도 지정될 경우 Red Hat 단독 대응 어려움
  • 통합발주 S/W 목록 미확인으로 RHEL/OpenShift 등 Red Hat SKU 직접 조달 항목 존재 여부 불명
  • 대학교 자체 AI 정책·기존 SSO/API 인프라와의 호환 요건에 따라 Red Hat 스택 적용 범위 축소 가능
