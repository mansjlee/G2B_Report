Red Hat 제안
불가능 요소
  • RFP 내 Red Hat 상용 제품명 미명시: RHEL, OpenShift, Ansible, JBoss EAP 등 Red Hat 상용 제품이 도입 품목·SW 목록에 명시되지 않음. 판정 규칙 1) 높음 조건 미충족.
  • 경쟁 제품 명시 없음: Ubuntu, Rocky Linux, Oracle Linux, VMware 등 경쟁 OS·플랫폼이 명시적으로 지정되지 않아 직접적인 배제 조건은 없으나, 반대로 Red Hat 제품도 명시 없음.
  • SW 구성 제안사 자유 제시: 데이터 플랫폼 SW는 "단일 제품 또는 복수의 상용·오픈소스 제품 조합 가능"으로 특정 제품 고정 없음. Red Hat 외 다양한 경쟁 솔루션(오픈소스 Kubernetes, MLflow, Kubeflow, MinIO 등)으로도 대응 가능.
  • 오픈소스 활용 허용으로 경쟁 심화: 오픈소스 제품 조합이 허용되어 커뮤니티 기반 솔루션(K8s, Kafka, Airflow 등)과의 경쟁에서 가격 경쟁력이 불리할 수 있음.
  • 대기업 참가 제한: 매출액 8천억 원 이상 대기업 직접 참가 불가 → Red Hat 코리아가 SI사업자로 직접 입찰 불가. 파트너(중소 SI)를 통한 간접 공급만 가능.
  • 하도급 불허: 하도급이 금지되어 Red Hat 제품 공급 구조 설계 시 공동수급(최대 3개사) 형태로만 참여 가능.
Red Hat 제안
가능 요소
  • 엔터프라이즈 Linux OS 명시 — RHEL 제안 가능: NPU 서버(2식)와 데이터 플랫폼 서버(3식) 모두 "기술지원 가능한 엔터프라이즈 Linux 설치·구성" 명시. RHEL(Red Hat Enterprise Linux)이 가장 대표적인 엔터프라이즈 Linux로, 직접 제안 가능. 총 5대 서버의 RHEL 라이선스 납품 기회.
  • 컨테이너 기반 온프레미스 구축 요구 — OpenShift 제안 가능: ECR-003에 "컨테이너 기반 온프레미스로 설치"가 명시되어 있어 OpenShift Container Platform(OCP) 제안이 가능. GPU·NPU 이기종 가속기 오케스트레이션, 멀티테넌시, CI/CD 파이프라인(Tekton), 컨테이너 이미지 레지스트리(Quay) 등 OpenShift 강점과 요구사항 일치.
  • AI/MLOps 플랫폼 — OpenShift AI(RHOAI) 제안 가능: 실험·학습 관리(SFR-009), 모델 저장소·버전 관리(SFR-010), 모델 배포·서빙(SFR-011), 웹 기반 노트북·IDE(SFR-008) 등 MLOps 전반 요구사항이 OpenShift AI(구 RHODS)의 핵심 기능과 직접 매핑됨.
  • CI/CD·형상관리 — OpenShift Pipelines/Quay 제안 가능: SFR-012(형상관리·CI/CD)에서 컨테이너 이미지 저장소, 빌드→테스트→배포 파이프라인, 관리자 승인 게이트 요구 → OpenShift Pipelines(Tekton), Quay 레지스트리 적용 가능.
  • 통합 모니터링·자원 관리 — Ansible AAP 제안 가능: SFR-021(통합 모니터링), SFR-022(자원 관리·멀티테넌시), SFR-005(데이터 처리 워크플로우 자동화) 요구사항에서 Ansible Automation Platform을 활용한 인프라 자동화·운영 자동화 제안 가능.
  • 보안 요구사항 — Advanced Cluster Security(ACS) 제안 가능: SER-001(보안 코딩·취약점 제거), SER-002(공공기관 AI 보안 가이드라인·CSAP 준수) 요구에 OpenShift ACS(컨테이너 보안) 제안 가능.
  • RFP 내 Red Hat 제품명 명시 없음: 현재 RFP에 RHEL, OpenShift, Ansible, JBoss 등 Red Hat 상용 제품명이 직접 명시되지 않아 판정은 "중간"이나, OS·컨테이너·MLOps 전 영역에서 Red Hat 스택으로 구성 가능한 여지가 명확히 존재함.
  • 파트너 전략 필요: 대기업 참가 제한으로 인해 중소 SI 파트너와 공동수급체 구성을 통한 Red Hat 제품 공급 전략 수립 필요. 50억 원 규모의 대형 사업으로 파트너 지원 중요.
