Red Hat 제안
불가능 요소
  • 신규 S/W 구매·납품 항목 없음: 본 사업은 기존 시스템에 대한 통합 유지보수·운영 용역으로, 신규 Red Hat 상용 제품 도입·납품·구독 품목이 명시되지 않음
  • 경쟁 OS 명시: 유지보수 대상 운영체제로 CentOS 6.X, 7.X (커뮤니티 배포판)가 9 EA 명시되어 있으며, Rocky OS, Windows Server 계열도 현행 운영환경에 명시됨 (대국민 홈페이지 운영환경: "Windows Server 2019 / RockyOS / CentOS")
  • VMware 유지보수 대상 명시: SW 유지보수 목록에 VMware(가상화)가 1 EA 포함되어 있어 가상화 플랫폼은 VMware로 확정 운영 중
  • DBMS 경쟁 제품 명시: Tibero Standard가 DBMS로 운영 중이며, MySQL/MariaDB/MsSQL도 사용 중
  • 정확한 Red Hat 상용 제품명 미기재: RFP 전반에 걸쳐 RHEL, OpenShift, Ansible, JBoss EAP 등 Red Hat 상용 제품명이 품목으로 명시되지 않음. 단순히 "Linux 계열" 또는 "CentOS" 등 일반 문구 수준에 그침
  • 민간클라우드 보안 솔루션 타사 제품 확정: FortiGate, AhnLab CPP, 휴네시온 NGS, 신시웨이 Petra 등 타사 보안 솔루션이 클라우드 운영환경에 이미 도입·운영 중
Red Hat 제안
가능 요소
  • Linux 계열 서버 다수 운영: 민간클라우드(NHN) 운영 대상 인프라 39식 중 약 26식이 "Linux 계열" OS로 운영 중. 구체적인 배포판이 일부만 명시(CentOS)되어 있으며, 다수 서버는 단순 "Linux"로만 기재됨 → RHEL 제안·전환 여지 존재
  • CentOS → RHEL 전환 기회: 현행 유지보수 대상 OS에 CentOS 6.X, 7.X (EOL 버전)가 포함되어 있어, 지원 종료 이슈를 활용한 RHEL 마이그레이션 제안 가능. 대국민 홈페이지 운영환경에도 CentOS 명시
  • 오픈소스 기술지원 명시: OMR-001 요구사항에 "정보시스템에 이용되는 오픈소스의 전문인력 기술지원이 될 수 있어야 함" 명시 → Red Hat의 엔터프라이즈급 오픈소스 기술지원 역량 강점으로 활용 가능
  • WEB/WAS 운영환경: Apache, Tomcat 기반 WEB/WAS 18식 운영 중으로 JBoss EAP 또는 Red Hat 미들웨어 솔루션 제안 여지 존재 (단, 현재 명시 없음)
  • 클라우드 인프라 운영·자동화 니즈: 24×365 클라우드 운영·보안관제, OS 패치·업그레이드, 주기적 취약점 점검 등 자동화 수요 존재 → Ansible Automation Platform 제안 여지 (단, 현재 명시 없음)
  • RFP에 명시된 Red Hat 제품명·수량: 없음 (Red Hat 상용 제품명 미기재)
