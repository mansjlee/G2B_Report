Red Hat 제안
불가능 요소
  • 경쟁 OS 확정 운영: 현재 운영 OS가 Rocky Linux 8.10(위버시스템즈)으로 명시되어 있음. Rocky Linux는 Red Hat이 '낮음' 판정 근거로 명시한 경쟁·대체 제품(Ubuntu, Rocky, Oracle Linux 등)에 해당하며, 현 시스템의 OS 스택으로 이미 확정 운영 중
  • Red Hat 상용 제품 전무: RFP 전 문서에 걸쳐 RHEL, OpenShift, Ansible, JBoss EAP, Satellite, AAP 등 Red Hat 상용 제품명이 구매 품목으로 일절 언급되지 않음
  • 신규 상용SW 직접구매 해당 없음: RFP 준수항목에 '상용SW 직접구매 및 SW BMT: 해당 없음'으로 명시되어 있어 신규 상용 라이선스 구매 계획 없음
  • 운영·유지관리 중심 사업: 기존 36종 SW의 유지보수 및 클라우드 운영경비(지출성 비용 실비정산) 위주 사업으로, 신규 SW 납품·구독 도입 여지 매우 낮음
  • 네이버 G-Cloud 인프라 고정: 민간 클라우드는 네이버 G-Cloud(CSAP 인증)로 확정 운영 중이며, Red Hat OpenShift Container Platform을 별도 도입할 필요성이 명시되어 있지 않음
  • WAS 스택 오픈소스 기반: Apache + Tomcat 조합으로 JBoss EAP/WildFly 전환 제안 여지 낮음 (JBoss EAP 미언급)
Red Hat 제안
가능 요소
  • RFP에 명시된 Red Hat(또는 동의어) 제품명·수량: 없음 — RFP 전문에 Red Hat 상용 제품명이 품목으로 명시된 사례 전혀 없음
  • Rocky Linux → RHEL 전환 제안 가능성(제한적): Rocky Linux 8.10은 CentOS/RHEL 호환 무상 배포판으로, EOS 관리(MPR-005) 요구사항 대응 맥락에서 RHEL 유료 구독 전환 제안을 검토해볼 수 있으나, 현 사업 범위 내 신규 OS 교체 예산이 명시되어 있지 않아 현실적 제안 기회는 매우 제한적
  • Kubernetes 운영 언급: MPR-008에 GPU·Kubernetes·스토리지 등 클라우드 자원 운영이 명시되어 있어 이론적으로 OpenShift 활용 제안 여지가 있으나, 네이버 G-Cloud 기반 Kubernetes 환경이 이미 구성되어 있어 실질적 도입 가능성 낮음
  • AI/LLM 인프라 확장: RHEL AI, OpenShift AI 등 Red Hat AI 솔루션 제안을 차기 사업 영업 활동으로 준비할 수 있는 레퍼런스 사업으로 관심 유지 필요
  • Ansible 자동화 제안 여지: 36종 SW 유지보수 및 클라우드 운영 자동화 맥락에서 Ansible Automation Platform(AAP) 제안 가능성이 이론상 존재하나, 현 RFP에 자동화 플랫폼 도입 예산은 명시되어 있지 않음
