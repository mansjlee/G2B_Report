Red Hat 제안
불가능 요소
  • 경쟁·대체 제품 명시: 상용SW 목록 OS/가상화 카테고리에 CONTRABASS/SDS 6식(망분리 솔루션, Red Hat 경쟁 제품)이 명시되어 해당 영역은 대체 어려움
  • VMware 계열 명시: VMware 9식, vSphere vCenter Vsan 1식이 가상화 환경에 포함되어 있어 Red Hat Virtualization(RHEV) 또는 OpenShift Virtualization 대체 제안이 어려운 구조
  • 커뮤니티 OS 다수 운영 중: 노후 OS 교체 목록에 CentOS 6.x/7.x(14대), Rocky Linux(MAR-005에서 공개용 SW로 언급)가 운영 중이나, 이는 RHEL 높음 판정 근거는 아님
  • 순수 유지보수 용역 성격: 신규 SW 도입보다 기존 운영 시스템 유지가 주목적이므로, 새로운 Red Hat 상용 제품 신규 도입 제안보다는 기존 라이선스 갱신·유지보수 계약 형태로 접근해야 함
  • 대규모 SI 사업자 수행: 통합유지보수사업자가 협력업체(제조사) 기술지원 확약서를 별도 수령하는 구조로, Red Hat이 직접 입찰 불가 (SI 파트너 통해 접근 필요)
  • JBoss 6(구버전): 목록에 명시된 JBoss 6는 커뮤니티 버전인 WildFly와 혼재 가능성 있으며, 단순 유지보수 목적으로 EAP 신규 전환 난이도 존재
Red Hat 제안
가능 요소
  • [RFP 명시 Red Hat 상용 제품 — 높음 판정 근거]
    • Red Hat Enterprise Linux Server 6.5: 14식 — 상용 SW 유지보수 목록에 품목으로 명시
    • RedHat Linux: 9식 — 상용 SW 유지보수 목록에 품목으로 명시
    • JBoss 6: 14식 — WAS/WEB 상용 SW 유지보수 목록에 품목으로 명시
  • [OS 라이선스 계약 필요 명시]: MAR-005(전사자원 S/W 관리) 세부내용에 "패치를 위해 제조사와 라이선스 계약이 필요한 OS는 계약을 진행해야 함(Redhat Enterprise Linux 등)"이라고 명시 → RHEL 구독 계약 기회
  • [RHEL EOL 교체로 인한 버전 업그레이드 기회]: MAR-021(노후 OS 교체) 대상에 RHEL 6.5 총 15대(DELL R730 3대·R320 4대, IBM x3650 M4 2대, HP BL460C G7 6대)가 포함되어 있으며 2026~2027년 단계적 교체 예정 → 최신 RHEL 버전(RHEL 8/9) 전환 제안 기회
  • [JBoss → JBoss EAP 업그레이드 기회]: JBoss 6 14식 유지보수 과정에서 Red Hat JBoss EAP 상용 지원 및 버전 업그레이드 제안 가능
  • [Subscription 협의 여지]: MAR-005에서 "공개용 소프트웨어(MariaDB, Jboss, nginx, Rocky Linux 등)도 문제시 유지관리 계약, Call Base 등을 통해 정상적인 서비스를 제공해야 함(단, 필요시 Subscription 협의)"으로 명시 → Rocky Linux 등 커뮤니티 OS에 대한 RHEL Subscription 전환 협의 가능
  • [Ansible 자동화 제안]: 대규모 유지보수 환경(871종 H/W, 891종 S/W, 해외 48개 사무소)에서 패치관리·구성관리 자동화를 위한 Ansible Automation Platform(AAP) 제안 여지
  • [영업 전략]: 낙찰 사업자(SI)에게 Red Hat이 기술지원 확약서 제공 및 RHEL/JBoss EAP 공급 파트너로 참여, 노후 OS 교체 시 RHEL 최신 버전 공급 선점
