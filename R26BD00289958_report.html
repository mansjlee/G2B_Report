Red Hat 제안
불가능 요소
  • 순수 운영위탁 서비스 계약: 본 사업은 시스템 운영·유지관리 위탁 용역으로, Red Hat SW 신규 구매·납품·구독 항목이 RFP에 명시되지 않음
  • 유지보수 대상 상용SW 5종에 Red Hat 제품 미포함: 붙임의 "유지보수 상용소프트웨어 대상 목록"은 Jeus, Anysign, Xtorm, KSignSecureDB, eCoross 5종으로 구성되며, RHEL 또는 JBoss EAP 구독 갱신은 해당 목록에 없음
  • 경쟁 WAS(Jeus) 사용 중: 전자행정 모바일 WAS 및 행정포털에 Tmax소프트의 Jeus 8.0이 사용 중이며 유지보수 대상으로 명시됨
  • H/W 유지관리 제외: 하드웨어 유지관리는 본 사업 범위에서 명시적으로 제외
  • 대기업·중견기업 입찰 제한: 총사업금액 20억원 미만으로 중소 SW사업자만 입찰 가능 — Red Hat 코리아 직접 입찰 불가
Red Hat 제안
가능 요소
  • RHEL 8.8 현재 OS로 사용 중: 전자행정·협업포털 시스템 및 법정민원서비스 시스템의 운영 OS가 RHEL 8.8로 명시됨 — 향후 구독 갱신 및 버전 업그레이드(RHEL 9.x) 영업 기회 존재
  • JBoss EAP 7.4.10 현재 WAS로 사용 중: 전자행정·협업포털 및 법정민원서비스 시스템의 WAS로 JBoss EAP 7.4.10이 명시됨 — 구독 만료 시점에 갱신·업그레이드 제안 가능
  • 운영 환경이 Red Hat 스택 기반: 주요 민원·행정 시스템이 RHEL + JBoss EAP 조합으로 구성되어 있어, 운영 수행 업체가 Red Hat 기술 지원 채널(파트너)을 통해 구독 갱신을 주도할 가능성 있음
  • 보안 강화 요구사항: OS 패치 지원(SER-007)이 명시되어 있어 RHEL 서브스크립션 유지 필요성이 간접적으로 요구됨
  • RFP 명시 Red Hat 제품 목록:
    • RHEL 8.8 — 전자행정·협업포털 OS (수량 미명시, 현재 운영 중)
    • RHEL 8.8 — 법정민원서비스 OS (수량 미명시, 현재 운영 중)
    • JBoss EAP 7.4.10 — 전자행정·협업포털 WAS (수량 미명시, 현재 운영 중)
    • JBoss EAP 7.4.10 — 법정민원서비스 WAS (수량 미명시, 현재 운영 중)
