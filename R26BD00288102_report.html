Red Hat 제안
불가능 요소
  • Red Hat 상용 제품 미명시: RFP 및 통합발주·직접구매 목록 어디에도 RHEL, OpenShift, Ansible, JBoss EAP 등 Red Hat 상용 제품명이 전혀 기재되어 있지 않음
  • 기존 WAS/Web 스택 경쟁 제품 확정: 국회사무처 운영 인프라에 Tmax WebToB(웹서버), Tmax Jeus(WAS)가 이미 명시되어 있으며, 신규 시스템도 기존 인프라를 우선 활용하도록 요구 → JBoss EAP 제안 불가
  • DB Oracle 확정: 인터넷망·업무망 모두 DB를 Oracle(Unix)로 명시 → Red Hat 기반 DB 솔루션 제안 불가
  • 주요 통합발주 품목이 AI 음성인식 SW로 한정: 통합발주 S/W는 AI 음성인식 STT SW 2식이 전부로, Red Hat 제품과 직접적인 연관성 없음
  • 컨테이너/Kubernetes 플랫폼 요구 없음: RFP 전체에 컨테이너, OpenShift, Kubernetes, PaaS 도입에 대한 요구사항이 없어 OpenShift 제안 근거 부재
  • 대기업 참여 제한: 20억 미만 사업으로 대기업 소프트웨어사업자 참여가 제한되어 Red Hat 직접 참여 불가 (파트너사를 통한 납품만 가능)
Red Hat 제안
가능 요소
  • [RHEL 제안 여지 — 통합발주 GPU 서버 OS]: 통합발주 GPU 서버(1식, NVIDIA H200) 스펙에 운영체제를 "Linux"로만 명시하고 특정 배포판을 지정하지 않음 → RHEL 제안 가능. GPU/AI 워크로드에서 RHEL의 안정성·지원 정책 강점을 어필 가능
  • [RHEL 제안 여지 — 직접구매 음성인식 서버 OS]: 직접구매 음성인식 서버(2식) 스펙에도 OS를 "Windows, Linux 지원"으로만 명시 → 조달청 쇼핑몰 직접구매이나 RHEL 등록 제품으로 제안 가능성 존재 (단, 직접구매 품목으로 영업 레버리지 낮음)
  • [온프레미스 LLM 인프라 강점 활용]: 외부망 접속 없이 내부 서버에서 LLM을 직접 구동하는 온프레미스 AI 인프라 요건에 대해, RHEL AI / OpenShift AI의 보안성·엔터프라이즈 지원 역량을 어필할 수 있는 미래 확장 제안 가능 (단, 현 RFP에 해당 품목 없음)
  • [RFP 내 Red Hat(동의어 포함) 제품명 명시 현황]: 없음 — RFP 전문에 Red Hat, RHEL, OpenShift, Ansible, JBoss 등 Red Hat 상용 제품명 및 동의어가 단 한 건도 명시되어 있지 않음
