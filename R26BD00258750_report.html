사업 개요 및 목적
  • 재글로벌바이오인력양성허브지원재단의 글로벌 바이오 인력 양성 교육을 위한 온라인 학습·교육 지원 통합 플랫폼 구축 용역이다.
  • 국문·영문 다국어 웹 서비스, CMS, 회원·교육·선발·수료 관리, 데이터 시각화, SNS 연계, 전자정부 표준프레임워크 4.0 기반 개발을 통해 글로벌 사용자 대상 교육 지원 및 재단·네트워크캠퍼스 통합 운영 창구를 마련하는 것이 핵심 목표이다.
주요 정보
  • 사업 예산: 700,000,000원 (부가세 포함)
  • 사업 기간: 착수일 ~ 2026.12.15.
  • 사업 범위: 교육지원 통합 플랫폼(사용자·네트워크캠퍼스·재단 관리), CMS, 회원·교육·과정·동영상·선발·통계 관리, 클라우드 운영환경 구축, 데이터 이관, 보안·웹접근성·웹표준 준수, 하자보수 12개월
  • 주요 일정: M(착수·요구사항분석) → M+1(설계) → M+2(구현) → M+3(테스트·전환·교육·완료), 제안설명회 2026.08.19., 입찰방식 제한경쟁입찰·협상계약

핵심 요구사항
  • 기술·비즈니스 요구사항: 전자정부 표준프레임워크 4.0+ 기반 웹 플랫폼 개발, 반응형·다국어(국/영) UI/UX, CMS 통합관리, OAuth·본인인증 로그인, 교육과정·수강·선발·수료증·동영상·검색·통계, 민간·공공 클라우드 인프라, OWASP/국정원/KISA 보안·개인정보보호, 웹접근성·웹표준(W3C), SSL·데이터 암호화, 30일 이상 안정화, 감리 대응
  • 통합발주 S/W (명시 규격·구성):
  • OS Linux Rocky 8.X 이상 — WEB/AP/NAS/WAS/DB 서버 각 1식(클라우드 VM 5대 역할)
  • Apache 2.X 이상 — WEB 서버 1식
  • Tomcat 9.X 이상 — WAS 서버 1식
  • MariaDB 10.X 또는 PostgreSQL 16.X — DBMS 1식

Red Hat 제안
불가능 요소
  • Rocky Linux 8.X가 OS 최소 요구사항으로 명시되어 RHEL 직접 지정·대체 제안 여지가 제한적이다.
  • Tomcat·Apache·MariaDB/PostgreSQL 오픈소스 스택 중심으로 JBoss/WildFly 등 Red Hat 미들웨어 요구가 없다.
  • 본 사업은 플랫폼 SI·개발 용역(7억원)으로 S/W 라이선스는 수행사가 사업비 내 포함·제공하므로 Red Hat 단독 S/W 공급 구조가 아니다.
  • OpenShift·Kubernetes·Ansible 등 Red Hat 플랫폼·자동화 솔루션 명시 요구가 없다.
  • 전자정부 표준프레임워크·KRDS UI/UX 등 공공 표준 기반 자체 개발이 핵심 평가 항목(기술 90점)이다.
  • 공동수급·하도급 불허, 중소 SW사업자·직접생산확인증명서(정보시스템개발서비스) 등 입찰 자격 제약 존재
Red Hat 제안
가능 요소
  • 클라우드 Linux 서버 운영환경(ECR-001) 구축 시, 협의 가능 범위에서 RHEL 구독·기술지원을 OS 대안으로 제안할 여지가 있다(단 Rocky 8.X 명시로 난이도 높음).
  • 다중 VM(WEB/WAS/DB/AP/NAS) 운영·확장·보안 패치 관리에 Ansible Automation Platform 적용을 부가 제안(기타 추가제안 5점)으로 제시 가능.
  • 민간·공공 클라우드 기반 안정적 서비스·24시간 가용성(QUR-006)·장애복구(QUR-007) 요구와 RHEL 장기 지원·보안 강점 일부 부합.
  • SI 파트너사와 협력 시 인프라·OS·구독 공급 및 교육·기술이전(PSR-002/003) 지원 모델로 간접 참여 가능
