Red Hat 제안
불가능 요소
  • 신규 납품 아닌 유지관리 사업: 기존 HW·SW 유지관리 및 운영 용역으로, 신규 Red Hat 제품 직접 납품·도입은 사업 범위에 해당하지 않음 (단, 기존 RedHat 서브스크립션 갱신은 명시적으로 포함)
  • 대기업·중견기업 참여 제한: 총사업금액 20억 미만으로 중소 SW사업자만 입찰 참가 가능 → Red Hat 코리아 직접 입찰 불가; 반드시 중소 파트너사를 통해 접근 필요
  • DBMS 경쟁 요소 없음이나 국산 고착: 큐브리드(국산 오픈소스 DBMS)가 기 도입되어 있어 Red Hat 계열 데이터 제품 제안 여지 낮음
  • 경쟁 OS 명시 없음: Ubuntu, Rocky Linux, Oracle Linux, VMware 등 경쟁 제품은 RFP에 명시되어 있지 않음 (부정적 요소 아님)
Red Hat 제안
가능 요소
  • RFP 명시 Red Hat 상용 제품:
    • MOR-001 전산장비 유지관리 세부 내용: "OS(Unix, Linux, NT 등) 설치(업그레이드 포함) 및 환경설정·운영지원(RedHat 서브스크립션 갱신 포함)" → RHEL 상용 서브스크립션 갱신이 과업범위로 확정 명시
  • JBoss 미들웨어 기 도입: 현행 SW 현황에 JBoss가 미들웨어로 등재 → JBoss EAP(Red Hat 상용 애플리케이션 서버) 서브스크립션 현행화·갱신 제안 검토 가능
  • Linux 운영환경: OS 운영지원 범위에 Linux 명시 → 서버별 RHEL 서브스크립션 수량 확인 및 갱신·확장 영업 기회
  • 통합회원 SSO 운영 중: 기 도입 SSO 시스템 노후화 대비 RH-SSO(Keycloak 상용) 전환 제안 여지 있음
  • 자동화·보안 강화 수요: 정기점검·보안패치·형상관리 자동화 필요성 → Ansible Automation Platform(AAP) 제안 가능
  • 국가정보자원관리원 대구센터 입주 및 디지털플랫폼 정부 대응: 클라우드 네이티브·컨테이너화 요구 증가 맥락에서 OpenShift 컨테이너 플랫폼 중장기 전환 제안 가능
