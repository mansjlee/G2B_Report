사업 개요 및 목적
  • 포항시 일월동 도시재생 대상지(70,198㎡)에 생활밀착형 스마트 서비스를 구축하여 지방소멸·초고령화에 대응하고 주민 체감형 도시재생을 실현하는 국토교통부 연계 사업
  • 스마트 트리(환경·CCTV·조명), 스마트 에어존(청정 휴게공간), 스마art 비대면 진료, AI 지능형 CCTV를 통합 구축하고 기존 빅데이터·통합관제 플랫폼과 연계
  • 실시 설계, 주민 참여형 거버넌스, 24시간 AI 안전망, 환경 데이터 분석 기반 정책 지원을 동시 추진하는 물품·용역·공사 혼합형 통합 발주 사업

Red Hat 제안
불가능 요소
  • 소프트웨어 직접 구매 제외 사업으로 Red Hat 제품 단독 공급·조달쇼핑몰 직접구매 경로 없음 (통합 개발사가 S/W 일체를 포함하여 발주)
  • 비대면 진료 키오스크에 Windows 11 PRO OS가 명시적으로 요구되어 해당 단말 영역은 RHEL 적용 불가
  • 전자정부 표준프레임워크(eGovFrame) 기반 개발 의무로 JBoss/WildFly 등 Red Hat 미들웨어 직접 지정 없음
  • 기존 포항시 CCTV 통합관제·VMS·통합플랫폼과의 호환 연계 필수로 타사 영상관제·IoT 솔루션 종속 가능성 높음
  • 대기업 Red Hat 직접 입찰 불가 (중소 SW사업자·중소기업만 참여 가능, 대기업 하도급·인력파견도 불가)
  • VMware, Contrabass, Ubuntu, Oracle/Rocky Linux 등 경쟁 제품은 명시되지 않았으나, CC인증·국정원 보안기능확인서 등 국내 공공 보안 인증 제품 위주로 구성될 전망
Red Hat 제안
가능 요소
  • DB/WAS/Web 서버 OS가 "목적에 적합한 OS"로만 규정되어 RHEL 서버 구독을 통합 제안사 SI 제안서 내 서버 OS로 제안 가능
  • 다수 IoT 시설물(스마트 트리 5식, 에어존 2개소, CCTV 5개소) 원격 모니터링·제어·패치 관리에 Ansible Automation Platform 적용 여지
  • RESTful API·JSON/XML 표준 연계, 마이크로서비스 확장성 요구와 OpenShift 컨테이너 플랫폼 기반 API 게이트웨이·연계 허브 제안 가능 (기존 eGovFrame과 병행 아키텍처 검토 필요)
  • 365일 24시간 무중단·장애관리·백업 요구에 RHEL 고가용성(HA) 및 표준 Linux 운영체계 강점 부각 가능
  • Red Hat은 중소 통합 SI 파트너와 공동수급(3사 이하) 형태로 RHEL·Ansible 라이선스 공급 및 기술지원 역할 수행 가능
