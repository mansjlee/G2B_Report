Red Hat 제안
불가능 요소
  • 주요 DB는 비 Red Hat 플랫폼: 하모니시스템 DB가 IBM AIX + Oracle, 통합개방관리시스템 DB가 Cubrid·Tibero로 구성되어 있어 해당 영역은 Red Hat 제안 불가
  • 중소기업 전용 입찰: 사업 규모 20억 미만으로 소프트웨어 진흥법 제48조에 따라 대기업·중견기업 입찰 참여 제한 → Red Hat 본사 또는 대형 파트너사의 직접 참여 불가, 중소 파트너 채널을 통한 간접 제안 필요
  • SW 신규 구매보다는 유지관리 용역 중심: 사업의 본질이 기존 시스템 운영·유지관리로, 별도 대규모 SW 신규 납품 항목은 제한적
  • 하모니시스템·정보화지원시스템의 JBoss 표기 불명확: "JBoss"로만 표기되어 상용 JBoss EAP인지 커뮤니티 WildFly인지 명확히 구분되지 않음
  • 통합개방관리시스템 상용 SW: WiseOpen, WiseMeta, WiseDQ 등 타사 제품이 명시되어 있어 해당 영역 Red Hat 제안 여지 없음
Red Hat 제안
가능 요소

    • 기관공유데이터 관리시스템 SW 환경에 Red Hat 상용 제품이 명시적으로 기재됨:
      • RHEL (Red Hat Enterprise Linux) — WEB/WAS #1, WEB/WAS #2, DB #1·#2, 연계 #1·#2 서버 전반 (총 6개 노드 이상)
      • JBCS (JBoss Core Services) — WEB/WAS #1, WEB/WAS #2
      • JBoss EAP (JBoss Enterprise Application Platform) — WEB/WAS #1, WEB/WAS #2, 연계 #1·#2
    • 유지관리 범위에 상용 SW 라이선스 현황 및 유효기간 관리, 라이선스 갱신·적용이 명시되어 있어 RHEL·JBCS·JBoss EAP 구독 갱신 영업 기회 존재 (MPR-13)
  • [기타 제안 검토 요소]
    • 하모니시스템, 정보화지원시스템, 통합개방관리시스템의 WAS로 "JBoss" 사용 중 — 상용 JBoss EAP 여부 확인 시 추가 갱신 기회 가능
    • 전 시스템이 Linux 기반 운영 환경을 사용하고 있어 RHEL 전환·확장 제안 여지 있음
    • 기관공유데이터 관리시스템의 AP 유지보수 수행기관이 제공하는 패치·기능개선·버전 업데이트 적용 업무 포함으로 Red Hat 기술지원 연계 가능
    • Ansible Automation Platform(AAP) 제안 검토 가능: 다수 시스템(5개) 통합 운영·패치관리 자동화 수요 존재
