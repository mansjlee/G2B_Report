Red Hat 제안
불가능 요소
  • 신규 S/W 납품·구독 항목 없음: 본 사업은 기존 구축 완료된 시스템에 대한 운영·유지관리 용역으로, 신규 상용 SW 구매·도입 계획이 없음. 상용 SW 항목(OZ Report, 이노릭스, Nexacro N)도 기존 도입 제품의 유지관리에 해당
  • RFP 전체에 Red Hat 상용 제품명 전혀 없음: RHEL, OpenShift, Ansible, JBoss/EAP 등 Red Hat 관련 제품이 품목, 기술 요구사항, 제약사항 어디에도 명시되지 않음
  • 기존 상용 SW가 비RH 제품으로 고정: 유지관리 대상 상용 SW가 OZ Report(티맥스에이앤씨), 이노릭스 플랫폼(이노릭스), Nexacro N(투비소프트)으로 Red Hat 제품과 무관
  • 사업금액 20억 미만, 중소기업 전용 입찰: 대기업·중견기업 참여 제한으로 Red Hat이 직접 입찰하기 어려운 구조
  • 경쟁·대체 제품 확정 여부: 특정 경쟁 OS(Ubuntu, Rocky Linux 등)가 명시되지는 않았으나, 기존 구축 환경 유지 원칙으로 OS 전환 기회 없음
Red Hat 제안
가능 요소
  • RFP에 명시된 Red Hat(또는 동의어) 제품명·수량: 없음 (0건)
  • 제한적 기술 여지 (중간 이하): 기술표준(붙임5)에 서버용 운영체제로 "POSIX, UNIX, Linux"가 기술표준 목록에 포함되어 있어 운영 서버 OS가 Linux 계열일 가능성 있음. 그러나 구체적인 OS 배포판이 지정되지 않아 RHEL 제안 여지가 이론적으로 존재하나, 기존 구축 환경 그대로 운영하는 유지관리 사업 특성상 실질적 전환 기회는 극히 제한적
  • WAS 성능 모니터링 환경: WAS 시스템에 Java/JDK 환경, 스카우터(Scouter) APM 도구 사용 언급이 있어 향후 RHEL 기반 WAS 환경 제안 가능성을 참고할 수 있으나, 본 사업에서의 직접 제안은 불가
  • 종합 의견: 본 사업은 기존 시스템 운영·유지관리 용역으로 Red Hat 상용 제품의 신규 도입·납품 기회가 사실상 없으며, 영업 활동은 차기 신규 구축 사업 또는 인프라 전환 사업 발굴 시 접근하는 것이 적절
