사업 개요 및 목적
  • 국가연구시설장비진흥센터(NFEC)가 운영하는 6종의 정보시스템(ZEUS, RED, STEP, SURVEY, CORE, NFEC홈페이지) 및 전산장비(56식)에 대한 통합 유지보수·운영지원 사업
  • 정보시스템의 안정적 운영, 보안 강화, 클라우드 서비스 운영, 신규 기능(심사·실태조사·구매지원) 개발, 생성형 AI(RAG 기반 대화형 상담서비스) 고도화를 핵심 목표로 함
  • 디지털 플랫폼 정부 비전에 따라 AI 인프라 기반의 연구시설장비 전주기 관리 플랫폼 고도화 및 데이터 품질 향상 추진

Red Hat 제안
불가능 요소
  • 경쟁 OS 명시: 유지관리 대상에 CentOS 7 (2식), Rocky Linux 9.x (1식)이 명시되어 있음. CentOS는 커뮤니티 제품, Rocky Linux는 경쟁 배포판으로 해당 항목은 RHEL 도입 근거로 활용 불가
  • 미들웨어 경쟁 제품 확정: JEUS(TmaxSoft), WebtoB가 WAS/웹서버로 명확히 지정·납품 대상에 포함되어 있어 JBoss EAP, Red Hat JBoss Web Server 등의 제안 여지 없음
  • DBMS 경쟁 제품 확정: Oracle DBMS(Oracle 11g Ent 포함)가 운영 중이며 유지관리 대상으로 명시되어 Red Hat 데이터 관련 제품 제안 어려움
  • 정확한 Red Hat 상용 제품명 부재: 유지관리 목록에 "Linux RedHat 7.3 (1식)"이 기재되어 있으나, 정확한 제품명(Red Hat Enterprise Linux)이 아닌 "RedHat"으로만 표기되어 있어 상용 RHEL 제품 확정 여부 불명확 (중간 판정 근거)
  • S/W 구매보다 용역 비중 높음: 사업의 핵심은 정보시스템 유지보수·운영 용역으로, 독립적인 Red Hat 상용 S/W 신규 도입·통합발주 항목 없음
Red Hat 제안
가능 요소
  • RedHat 7.3 OS 유지관리 대상 존재: 애플리케이션 유지관리 목록에 "Linux RedHat 7.3 (1식)"이 명시되어 있음. 정확한 제품명(RHEL) 표기는 아니나 Red Hat 계열 OS임이 확인되며, RHEL 구독 갱신·업그레이드 기회로 접근 가능 (판정 규칙상 "일반 문구/회사명만 있는 경우"로 중간 판정)
  • OS 업그레이드 기회: RedHat 7.3은 ELS(Extended Lifecycle Support) 구간 진입 또는 종료 시점으로, RHEL 8/9 업그레이드 필요성 제기 가능. 동시에 CentOS 7(EOL) 2식도 전환 대상으로 RHEL 또는 RHEL 기반 솔루션 제안 가능
  • 클라우드 네이티브·컨테이너 환경 확장 여지: RFP에서 "클라우드 네이티브 방식 적용 검토", "컨테이너 모니터링 서비스 제공" 등이 명시되어 OpenShift 또는 RHEL 기반 컨테이너 플랫폼 제안 여지 존재
  • AI 인프라 서버 보유: LLM 서버(Dell XE7740, H200 GPU 2ea)와 LLM Workstation이 별도 운영 중으로, RHEL AI / OpenShift AI 제안 가능성 검토 가능
  • Ansible 자동화 제안 가능: 56식 규모의 다양한 전산장비(서버, 클라우드VM, 스토리지 등) 운영 자동화 및 보안 패치 자동 적용 필요성 측면에서 Ansible Automation Platform 제안 여지 존재
  • RFP에 나온 Red Hat(또는 동의어) 제품명·수량: "Linux RedHat 7.3" 1식 (애플리케이션 유지관리 목록 No.3) — 단, 정확한 RHEL 상용 제품명 표기가 아닌 회사명 수준 표기로 판단
