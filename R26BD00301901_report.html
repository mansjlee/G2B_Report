Red Hat 제안
불가능 요소
  • RFP 내 Red Hat 상용 제품(RHEL, OpenShift, Ansible, JBoss EAP 등)이 구매·납품 품목으로 확정 명시되지 않음 — OS 항목에서 "Ubuntu 22.04 또는 RHEL 9" 중 선택 가능 조건으로 기재되어 있어, Ubuntu로 선정될 경우 RHEL 제안 기회 소멸
  • 경쟁 OS인 Ubuntu 22.04가 RHEL 9과 함께 동등 선택지로 명시 (ECR-01) → Ubuntu 채택 시 Red Hat 도입 여지 없음
  • 서버·저장소·네트워크 장비 및 기반 SW는 발주기관이 제공하며 본 사업금액에 미포함 → OS 직접 구매·납품 항목이 사업 범위에서 제외
  • WEB/WAS는 "보안·호환성·유지관리에 문제가 없는 공개용 소프트웨어 버전"으로 명시 → JBoss EAP 등 상용 WAS 도입 명시 없음
  • 컨테이너 환경은 "도커(Docker)" 기반으로 명시 — OpenShift(OCP) 등 Red Hat 컨테이너 플랫폼 명시 없음
  • 20억 미만 중소 SW사업자 제한 입찰로 Red Hat 직접 입찰 불가 (SI·통합사업자를 통한 간접 제안만 가능)
Red Hat 제안
가능 요소
  • RHEL 9 직접 명시 (ECR-01): OS 항목에 "Linux (Ubuntu 22.04 또는 RHEL 9), 컨테이너 실행 환경"으로 RHEL 9이 선택 가능 옵션으로 명시됨 → 제안사가 RHEL 9을 선택할 경우 Red Hat 구독 판매 기회 발생
  • 컨테이너(도커) 기반 아키텍처 필수 적용: 대표 홈페이지·전직지원 업무 공유시스템·AI 취업상담센터 모두 컨테이너(Docker) 기반 구성 요구 → Podman, OpenShift 등 Red Hat 컨테이너 솔루션 제안 여지
  • CI/CD 파이프라인 구축 필수 (SFR-B-31): CI/CD 자동 빌드·배포 파이프라인 구축 명시 → Ansible Automation Platform, OpenShift Pipelines 제안 가능
  • Linux 서버 환경: 안티바이러스(리눅스용) 3식 명시 (ECR-08), OS 모니터링 3식 필요 → RHEL 선택 시 Red Hat Satellite, Insights 연계 제안 가능
  • 공공 클라우드(CSAP) 환경: 클라우드 이용 시 CSAP 인증 서비스 필수 → RHEL 기반 클라우드 환경 제안 가능
  • SSO 솔루션 도입 (ECR-07): 대표 홈페이지 ↔ AI 취업상담센터 사용자 인증 연계용 SSO SW 라이선스 필요 → Red Hat SSO(Keycloak 기반 상용) 제안 가능성
  • RFP 내 Red Hat/RHEL 관련 직접 언급 제품명·수량:
    • RHEL 9 (Red Hat Enterprise Linux 9): OS 선택지로 명시 (ECR-01, 수량 미확정 — 서버 3식 기준 적용 가능)
  • SI 파트너사 협력을 통한 간접 제안 전략 필요 (중소기업 제한 입찰이므로 Red Hat 직접 참여 불가, 파트너사 통해 RHEL/Podman/RH SSO 등 납품 추진)
