사업 개요 및 목적
  • 국방과학연구소 6연구원이 2017년 구축된 종합시험정보체계 3.0의 노후화에 따른 SW/HW 교체 및 차세대 체계 신규 구축을 목표로 하는 사업
  • 시험의뢰→시험계획→시험수행→결과·성적서 발급까지 시험업무 전 주기(Full Lifecycle)를 온라인 원스톱으로 처리하는 통합 정보체계 구축
  • 시험장 통합 등 내·외부 변화에 유연하게 대응하고, 시험메타데이터 기반의 분산 데이터 통합관리·활용 기반 마련
  • 내·외부 사용자(기술용역 의뢰자, 연구개발부서 등)를 위한 맞춤형 정보제공 및 유관시스템 연계 협업 체계 구축
  • 최신 클라우드 컴퓨팅 기술 적용, 서버 가상화 기반의 운영 환경 이중화를 통한 가용성·신뢰성 확보

Red Hat 제안
불가능 요소
  • Red Hat 상용 제품명 미명시: RFP 본문·구매목록 어디에도 RHEL, OpenShift, JBoss EAP, Ansible, Satellite 등 Red Hat 상용 제품이 품목으로 명시되어 있지 않아, 도입 확정 건으로 볼 수 없음
  • WAS 오픈소스 허용: WAS(4식)는 "오픈소스 허용"으로 명시되어 Tomcat, WildFly 등 무료 오픈소스로도 요구사항 충족 가능. JBoss EAP(상용) 필수 도입을 강제하는 조건 없음
  • 특정 경쟁 제품 확정 없음(긍정적 측면): Ubuntu, VMware, Oracle Linux, Rocky Linux 등 경쟁 제품이 명확히 지정되어 배제된 상황도 아님. 다만 Red Hat 제품도 확정되지 않은 상태
  • 국방 폐쇄망·보안 환경: 국방사이버안보훈령 준수, 망분리(내부망/DMZ/인터넷망) 필수, 국군방첩사령부 보안측정 필요. Red Hat 제품 도입 시 보안 적합성 검증(CC인증, 국정원 검증 암호모듈 등) 추가 요건 충족 필요
  • SW 납품 구조상 SI 사업자 중심: 중소·중견기업 대상 사업(20억~40억 미만)으로, Red Hat이 직접 입찰이 아닌 SI 파트너를 통한 간접 공급 구조. 제안사의 솔루션 선택에 따라 Red Hat 제품이 배제될 수 있음
  • 검색엔진 OpenSearch 언급: SFR-D9-020에서 대용량 분석·통합검색에 "OpenSearch"가 언급되어 있으나, 이는 AWS 관련 오픈소스 프로젝트로 Red Hat 제품이 아님
Red Hat 제안
가능 요소
  • [WAS → JBoss EAP 제안 가능]: WAS 4식(통합발주, 오픈소스 허용)은 "Jakarta EE 표준 준수, 클러스터링·HA 지원, 운영 로그·모니터링 연동, 지속적 보안 패치·기술지원 확보" 요건을 요구. JBoss EAP(Red Hat 상용 WAS)는 이 요건을 충족하며, 특히 "오픈소스 적용 시 상용 수준 기술지원·유지보수 확보 방안 명시" 조건에서 상용 지원이 강점으로 작용 가능
  • [서버 OS → RHEL 제안 가능]: 참고1 도입 대상 시스템의 가상화 서버(운영 2대, 인터넷망 2대, 개발 1대 등)에 "가상화 수량에 맞는 OS 종류/수량 포함"으로 명시되어 있으나 OS 종류 미지정. 기술적용계획표에서 "Linux ●(적용)"으로 명시되어 RHEL 제안 가능
  • [오브젝트 스토리지 → Red Hat Ceph Storage 제안 가능]: 오브젝트 스토리지 SW(2식, 오픈소스 허용)는 "S3 호환 API, 복제/이레이저 코딩 기반 이중화, 폐쇄망 자체 설치 가능" 요건 요구. Red Hat Ceph Storage는 해당 요건 충족 가능
  • [DBMS → 오픈소스 RDBMS 계열 제안 가능]: DBMS 4식(오픈소스 허용)에 대해 PostgreSQL 기반 솔루션 등을 활용하는 방식으로 간접적 Red Hat 생태계 연계 가능 (단, 직접적 Red Hat 제품은 아님)
  • [Ansible → 자동화 인프라 제안 가능]: 서버 가상화 환경 구성·이중화·배포 자동화 관점에서 Ansible Automation Platform 제안 여지 존재 (RFP 내 자동화 도구 미지정)
  • [WAS 모니터링 → 오픈소스 허용]: WAS 모니터링 2식(오픈소스 허용, 폐쇄망 자체 설치)은 Red Hat 관련 APM 솔루션 또는 파트너 제품 연계 제안 가능
  • RFP 내 Red Hat(또는 동의어) 제품명·수량 명시: 없음 (해당 없음)
