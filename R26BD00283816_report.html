Red Hat 제안
불가능 요소
  • [사업 성격] 본 사업은 신규 S/W 도입·납품이 아닌 기존 전산자원 유지관리 용역이 핵심으로, Red Hat 상용 제품(RHEL, OpenShift, JBoss EAP, Ansible 등)이 유지관리 대상 목록에 전혀 명시되지 않음
  • [경쟁 제품 명시] 서버 가상화 플랫폼으로 VMware vCenter 및 VMware vSphere(cSphere)가 이미 운영 중이며 유지관리 대상으로 명시됨 → OpenShift Virtualization 등 Red Hat 가상화 스택 제안 여지 극히 제한적
  • [WAS 환경] WAS로 Oracle Weblogic, TmaxSoft Jeus 등 타사 제품이 이미 운영 중으로 JBoss EAP 전환 가능성이 낮음
  • [DBMS 환경] Oracle DB, Tibero, MS-SQL이 이미 구축되어 있어 Red Hat Data Grid, AMQ 등 제안 영역이 제한적
  • [가상PC 환경] Citrix XenDesktop이 MOIP-Cloud 가상PC 플랫폼으로 운영 중
  • [용역 중심 사업] 주요 과업이 유지관리 인력 투입·장애 대응·예방점검 등 서비스 용역으로, S/W 라이선스 신규 납품·구독 계약의 주체가 되기 어려운 구조임
Red Hat 제안
가능 요소
  • [Linux 서버 다수 운영] 서버 95대 중 Linux 서버가 62대(65%)를 차지하나 구체적인 Linux 배포판(RHEL, CentOS, Rocky 등)이 RFP 내 미명시 → 노후 Linux 서버 교체 시 RHEL 전환 제안 여지 존재
  • [상용SW 변경 지원 조항] PSR-005(상용SW 변경 지원)에서 "노후 장비 교체 또는 운영환경 변경에 따른 SW 변경 작업 지원" 명시 → 간접적으로 OS·미들웨어 교체 시 Red Hat 제품 제안 기회 발생 가능
  • [빅데이터/공개SW 기반 환경] Hadoop, HBase, Flink 기반 빅데이터 통합관제 솔루션 15식 운영 중 → 향후 Red Hat OpenShift Data Science 또는 OpenShift on 컨테이너 환경 전환 제안 여지(단, 현 시점 확정 아님)
  • [RFP 내 Red Hat 제품 직접 명시 없음] RHEL, OpenShift, Ansible, JBoss EAP 등 Red Hat 상용 제품명이 유지관리 대상 목록 및 이전설치 목록 어디에도 기재되지 않아 현재 도입 확정 기회는 없음
