사업 개요 및 목적
  • 한국산업기술기획평가원(KEIT)의 AI 전환(AX) 기반 구축을 위한 사업으로, 글로벌 Agentic AI 트렌드 및 정부 공공 AX 정책에 대응하여 원내 AI 업무 혁신 기반을 마련하는 것이 핵심 목표
  • 내부망 환경에 LLM 기반 자율형 AI Agent 실행환경을 조성하고 PoC를 통해 업무 혁신 모델 검증
  • KEIT 전용 AI 시스템(A-ROME) 구축 및 다양한 AI 서비스(RAG 기반 질의응답, 보고서 생성, 이미지 생성, Agent 연계 등) 통합 제공
  • 업무 데이터를 AI Ready Data로 전환하는 데이터 파이프라인 구축 (Multi-RAG, Vector DB 등)
  • AI Ops 및 통합 모니터링 체계 구축으로 안정적이고 책임 있는 AI 서비스 운영환경 조성
  • R&D 사업관리 및 내부행정 업무에서 AI Agent가 내부 시스템(ERP, GW, 메일 등)과 연계하여 업무를 지원하는 환경 구현
주요 정보
  • 사업 예산: 1,965백만원 이내 (VAT 포함) / 20억원 미만으로 중소기업만 입찰 참가 가능
  • 사업 기간: 계약체결일로부터 12개월 이내 (추진 일정상 2026년 10월 ~ 2027년 11월경)
  • 사업 범위: ① 자율형 Agent PoC (실행환경 조성, Agent 기반 서비스 개발) ② KEIT AI 시스템(A-ROME) 구축 (AI 업무 지원 서비스 개발 포함) ③ AI 데이터 파이프라인 구축 (데이터 수집·연계 체계, AI Ready Data 구축) ④ 최적의 AI 운영환경 조성 (통합 운영관리·모니터링 체계 구축)
  • 주요 일정: 기술협상 및 계약(2026.10) → 착수보고회 → 자율형 Agent 실행환경 조성 및 서비스 개발 → KEIT AI 시스템 구축 → AI 데이터 파이프라인 구축 → 테스트·시범운영 → 산출물 작성 → 검수·종료(2027.11)

핵심 요구사항
  • [기술 요구사항 - 자율형 Agent] LLM 기반 자율형 Agent 실행 프레임워크 도입 (Tool/Skill 실행, Browser 활용, Workflow, MCP 연계, GUI 기반 Agent Builder, Human-in-the-loop, Memory 등 기능 필수). 발주기관 보유 GPT-OSS-120B 우선 검토. 폐쇄망 Standalone 구성 필수.
  • [기술 요구사항 - AI 시스템] KEIT AI 시스템(A-ROME) 구축: RAG 기반 질의응답, 문서 이해, 이미지 생성, 보고서 초안 생성, 연구개발계획서 작성 지원, R&D 과제공고 요약 서비스 등 통합 제공
  • [기술 요구사항 - 데이터] 멀티 테넌시(Multi-Tenancy) 구조 지원, Multi-RAG 구성, Vector DB(A-ROME), 색인DB·정형DB(D-ROME) 구성. 하이브리드 검색(BM25 + Semantic/Vector) 및 Re-ranking 적용
  • [기술 요구사항 - 연계] PMS, D-ROME, GW, ERP, EDMS 등 내부 정보시스템과 데이터 수집 연계 (DB to DB, SFTP, API 방식). SSO(기 보유 제품) 연동. 국가법령정보 OPEN API 연계
  • [성능 요구사항] 전체 사용자 500명/동시 접속 50명 환경 기준. 첫 토큰 생성 시간(TTFT) 평균 3초 이내. 추론 속도 30 Tokens/sec 이상. RAG 품질 평균 80% 이상. 언어모델 정답 유사도 85% 이상
  • [구매가 명시된 S/W] 해당 없음. RFP에 통합발주 또는 상용 S/W 구매 품목 없음. SFR-001에 "실행환경에 필요한 소프트웨어는 오픈소스 또는 무상 소프트웨어 우선 활용" 명시. GPU 서버는 발주기관 제공, SSO는 기 보유 제품 활용 (신규 구매 대상 아님)
  • [오픈소스 라이선스 관리] BSD, MIT, Apache-2.0 등 오픈소스 라이선스 유형 검토 결과 발주기관 제출 필수

불가능 요소
  • [S/W 납품 항목 없음] 본 사업은 AI 시스템 개발·구축 용역 중심의 SI 사업으로, 통합발주 또는 상용 S/W 구매 품목이 RFP에 명시되어 있지 않음. Red Hat 상용 제품(RHEL, OpenShift, Ansible 등)의 납품·도입 기회 없음
  • [오픈소스 우선 정책 명시] SFR-001에 "실행환경에 필요한 소프트웨어는 오픈소스 또는 무상 소프트웨어 우선 활용"이 명시되어 있어 상용 Red Hat 제품 제안 시 수용 가능성 매우 낮음
  • [하드웨어 발주기관 제공] AI 시스템 구축용 GPU 서버(NVIDIA H200)는 KEIT가 직접 제공. 사업자는 서버 구매 불필요하므로 인프라 OS(RHEL) 납품 기회 없음
  • [SSO 신규 구매 제외] ECR-002에 "본 SSO 솔루션은 기 도입·보유 중인 제품을 활용하는 것으로 신규 구매 대상이 아님" 명시. Red Hat SSO(Keycloak) 제안 불가
  • [경쟁·대체 제품] VMware, Ubuntu, Oracle Linux 등 경쟁 제품이 명시적으로 지정되지는 않았으나, 오픈소스 LLM 프레임워크(Langchain, vLLM 등) 기반 개발 환경 예상으로 상용 RH 제품 개입 여지 극히 제한적
  • [중소기업 전용 사업] 사업 금액 20억원 미만으로 중소기업만 입찰 참가 가능. Red Hat 또는 Red Hat 파트너 대기업·중견기업은 입찰 자체 불가

가능 요소
  • [온프레미스 인프라 운영 환경] 폐쇄망(내부망) 온프레미스 환경에서 AI 시스템을 구축·운영하므로, 구축 사업자가 서버 OS로 RHEL을 활용할 여지가 있으나, RFP에 OS 품목 구매가 명시되지 않아 사업자 자체 비용 부담 가능성 있음
  • [컨테이너·멀티 테넌시 아키텍처] SFR-002에 "단일 인프라 내 사용자·부서 간 데이터 및 실행 환경이 상호 격리되는 멀티 테넌시(Multi-Tenancy) 구조 지원" 요구. 컨테이너 기반 아키텍처로 OpenShift/Podman 활용 가능하나 구매 품목으로 명시 없음
  • [RFP 내 Red Hat 제품명 명시] 없음. RHEL, OpenShift, Ansible, JBoss EAP, Satellite 등 Red Hat 상용 제품명이 RFP 어디에도 기재되지 않음
  • [종합 평가] 본 사업은 오픈소스 우선 활용 정책과 SI 개발 용역 특성으로 인해 Red Hat 상용 제품의 직접적인 영업 기회는 사실상 없음. 간접적으로 구축 사업자에게 기술 지원 또는 파트너십 협력을 통한 오픈소스(CentOS Stream → RHEL 전환, WildFly → JBoss EAP 등) 제안 여지만 미미하게 존재
