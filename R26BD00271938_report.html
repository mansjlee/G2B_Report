울산광역시_2025년 스마트도시 데이터허브 시범솔루션 발굴사업 - 분석 리포트

레드햇 제안 가능성 중간
Linux 기반 인프라, 신규 SW 도입 협의 가능
사업 개요 및 목적
  • 울산광역시의 빈집 도시재생, 상권 침체, 에너지·탄소 관리 등 복합 도시 문제를 해결하기 위해 기존 스마트도시 데이터허브를 NGSI-LD 기반 표준 연계형 허브로 고도화하고, 데이터 카탈로그·리니지·시멘틱 브로커·포털 기능을 강화하는 것이 핵심 목표
  • 빈집 도시재생, 상가 공실 상권 활성화, 탄소 예측 관리 등 3종 정책 시뮬레이션 서비스를 구축하여 정책 수립 → 시뮬레이션 → 실행 → 성과관리로 이어지는 데이터 기반 의사결정 체계 마련
  • 구축된 시범솔루션을 오픈소스 기반으로 공개하고 충청북도 등 타 지자체로 확산·실증하여 스마트도시 데이터허브 활용 모델 제시
주요 정보
  • 사업 예산: 1,077,000,000원 (금 십억 칠천칠백만원정, VAT 포함)
  • 사업 기간: 착수일로부터 2027년 7월 31일까지 (약 12개월, 착수 후 M1~M12)
  • 사업 범위: ① 스마트도시 데이터허브 포털 및 표준 연계 체계 고도화(NGSI-LD), ② 3종 정책 시뮬레이션 서비스 구축(빈집 도시재생·상권 활성화·탄소 예측 관리), ③ 국가 유관 시스템(빈집정비 통합지원시스템·탄소공간지도시스템·소상공인365) 연계, ④ 도시가스 등 외부 데이터 구매·연계, ⑤ 오픈소스 공개 및 충청북도 타지자체 확산 실증, ⑥ 검수 완료 후 3년간 운영 지원
  • 주요 일정: 착수·계획 수립(M1~M2) → 설계(M2~M4) → 개발·구현(M4~M9) → 테스트(M9~M10) → 시범운영 및 실증(M10~M12) → 착수·중간·최종 보고, 설계단계·종료단계 감리 실시, 최종 완료일 2027.7.31. 고정

Red Hat 제안
불가능 요소
  • 상용 SW 납품 항목 부재: RFP 내 통합발주 또는 구매 대상 상용 SW 목록이 없으며, 오픈소스 기반 구축을 원칙으로 명시하여 Red Hat 상용 제품 도입 근거가 희박함
  • 신규 H/W 및 SW 도입 지양 원칙: 발주기관 보유 기존 인프라를 최대한 활용하도록 명시, 신규 소프트웨어 도입 시 발주기관 협의 필요로 사전 결정 불가
  • 경쟁 제품 미명시: VMware, Ubuntu, Oracle Linux 등 경쟁 제품은 직접 명시되지 않았으나, 기존 인프라 운영 환경은 보안상 비공개로 현황 파악 불가
  • 오픈소스 기반 구축 의무화: 솔루션 구축 시 오픈소스 모듈 적극 활용 의무, 핵심 모듈 공개 필수로 Red Hat 상용 구독 라이선스 도입 논리 약화
  • 20억원 미만 중소기업 사업: Red Hat 코리아가 직접 입찰 참여 불가(대기업·중견기업 입찰 참여 제한), SI 파트너를 통한 간접 참여만 가능
  • RFP에 Red Hat 상용 제품명 전무: RHEL, OpenShift, Ansible, JBoss EAP 등 어떠한 Red Hat 상용 제품도 문서에 기재되지 않음
Red Hat 제안
가능 요소
  • Linux 서버 운영체제 적용 명시: 기술적용계획표(붙임 3)에서 플랫폼 및 기반구조 분야 운영체제 항목 중 Linux 적용(○)으로 표시되어 있어 RHEL 제안 여지 존재
  • 신규 SW 도입 협의 가능 조항: ECR-001에서 "신규 도입이 필요한 소프트웨어, 라이선스, 연계 모듈 등이 있을 경우 도입 필요성, 활용 목적, 비용, 유지관리 방안을 제시하고 발주기관과 협의하여야 함"으로, RHEL 서브스크립션 도입 협의 가능성 열려 있음
  • 컨테이너/플랫폼 아키텍처 제안 여지: NGSI-LD 기반 데이터허브 포털, 정책 시뮬레이션 서비스, 표준 API 모듈 등 마이크로서비스 구조에서 OpenShift/Podman 기반 컨테이너 플랫폼 제안 가능
  • 오픈소스 기반 확산 구조: "오픈소스 기반 SW 공개·설치·기술 지원" 요구로, Red Hat이 지원하는 업스트림 오픈소스 기술(Kubernetes, Quarkus 등)을 기반으로 한 Red Hat 상용 제품 전환 제안 가능
  • 자동화 및 운영관리 기능 요구: 서비스 이용 현황 모니터링, 연계 상태 관리, 장애 복구 등 운영자동화 요구사항(SFR-005, QUR-004)에 Ansible Automation Platform 제안 여지
  • RFP 내 Red Hat(동의어 포함) 제품명 명시: 없음
