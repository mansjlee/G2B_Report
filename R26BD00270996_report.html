레드햇 제안 가능성 낮음
VMware 기존환경 명시·RH 상용제품 없음
사업 개요 및 목적
  • 2014년 도입 후 노후화된 네트워크·보안장비를 교체하고, 정보화 인프라를 재배치하며, 통합 모니터링 솔루션을 신규 도입하여 대국민 서비스 및 내부 업무시스템의 안정적 운영 기반을 확보함
  • 세부 추진 과제: ① 노후 네트워크·보안장비 교체(백본 스위치·인터넷 방화벽), ② 서버 자원 재배치 및 효율화(임직원 PC 환경 개선, VDI 서버 증설·업그레이드, VMware→Nutanix 마이그레이션), ③ 통합 모니터링 체계 구축
  • 발주기관: 한국소비자원 (공정거래위원회 산하 공공기관)
주요 정보
  • 사업 예산: 545백만원 (총액계약, 20억 미만 중소기업 한정 입찰)
  • 사업 기간: 계약일로부터 90일 이내 (2026년 하반기 수행)
  • 사업 범위: 백본 스위치 교체, 인터넷 방화벽 교체, 노후 VDI 서버 CPU·메모리 업그레이드, VDI 서버 증설, FC SAN 스위치 증설, VMware VM 마이그레이션 및 물리서버 이전, 서버가상화 물리서버 재배치, 통합 모니터링 시스템 도입, 기관 전체 네트워크 재설계
  • 주요 일정: 조달청 경쟁입찰(제한경쟁, 협상에 의한 계약) → 기술평가위원회(8인 이상) → 계약 → 착수보고 → 장비·솔루션 납품 및 구축 → 서버 이관·재구성 → 테스트·안정화 → 완료보고 (계약 후 90일 이내)
  • 계약 방법: 조달청 제한경쟁입찰, 협상에 의한 계약 / 기술평가 90% + 가격평가 10%

핵심 요구사항
  • [기술·비즈니스 요구사항]
    • ECR-003: 백본 스위치 2식 — 9.6Tbps 이상, 듀얼 엔진 이중화, 7슬롯(I/O 5), POE/POE+/UPOE 지원, MACSEC 256bit 암호화, SDN 지원
    • ECR-004: 인터넷(DMZ) 방화벽 2식 — FW Throughput 160Gbps 이상, GS인증 1등급, FQDN 기반 정책, Open API 연동, 국정원 보안인증
    • ECR-005: DELL PowerEdge R720 서버 4대 CPU·메모리 업그레이드 후 VDI 서버존 이전 (재생부품 허용)
    • ECR-006: VDI 서버 증설 6식 — Intel Xeon E5-2690 v3, 256GB RAM, 기존 VMware/VDI HA 클러스터와 완전 호환 (재생장비 허용)
    • ECR-007: FC SAN 스위치 증설 1식 — 기존 Brocade 6510(16Gbps, 48Port) 연동, 활성포트 12개 이상 (재생장비 허용)
    • ECR-008: VMware 서버존(내부C 3대, 개발 1대) 운영 VM 전체를 Nutanix 서버로 마이그레이션 후 물리서버 VDI존 이전·재활용
    • ECR-009: 가상화서버 4개존(서버 8대·스위치 6대·스토리지 5대) 재배치, 개발존 서버 1대·스토리지 1대 폐기
    • ECR-010: 통합 모니터링 시스템 1식 — Web 기반 대시보드, 서버·네트워크·설비 관제, Agent 기반 Log 수집, SNMP v1/2/3 지원, 발주기관 전체 장비 라이선스 포함
    • ECR-011: 기관 전체 네트워크 재설계 — 10년 이상 변화된 운영환경 최적화, 트래픽 분석, 병목 제거
    • 국정원 보안적합성 검증필 제품 납품 필수(SER-009), 재생장비 일부 허용(COR-004)
  • [통합발주 S/W 구매 목록]
    • 인터넷 방화벽 S/W(번들) 2식 — GS인증 1등급 제품, 국정원 검증필
    • 통합 모니터링 시스템(S/W) 1식 — 서버·네트워크·설비 관제, 발주기관 전체 장비 라이선스 포함 (제품명 미지정, 제안사 자유 제안)
    • FC SAN 스위치 증설 라이선스 — 활성포트 확장용 (수량: 12포트 이상)
    • VDI 서버 증설 6식 관련 S/W·F/W 설정 (기존 VDI 라이선스와 호환 필수, 신규 라이선스 추가 없음)
    • ※ 조달쇼핑몰 직접구매 S/W는 별도 명시 없음; 상기 품목 전체 통합발주
Red Hat 제안
불가능 요소
  • VMware 기존 운영환경 명시: ECR-008·ECR-009에서 기존 가상화 인프라가 VMware ESXi 기반임이 명확히 명시되어 있으며, 신규 VM 이전 대상은 Nutanix(뉴타닉스)로 확정됨 — Red Hat Virtualization(RHEV) 또는 OpenShift 가상화 제안 여지 없음
  • Red Hat 상용 제품 전무: RFP 전체에 RHEL, OpenShift, Ansible, JBoss EAP 등 Red Hat 상용 제품명이 단 한 건도 명시되지 않음
  • 주력 S/W가 비 RH 영역: 핵심 신규 S/W인 통합 모니터링 시스템은 SNMP·Syslog 기반 NMS 솔루션으로, Red Hat 포트폴리오와 직접적 연관성 없음
  • HW·네트워크 장비 교체 중심 사업: 사업의 약 80% 이상이 백본 스위치·방화벽·서버 하드웨어 교체 및 재배치로, SW 구독 제안 기회 자체가 협소함
  • 중소기업 한정 입찰: 20억 미만 중소기업 제한, 상호출자제한기업집단 참여 불가 — Red Hat 본사 직접 입찰 불가, 파트너사 통한 참여도 제한적
  • 기존 VDI 라이선스 호환 유지 조건: ECR-006에서 "기존 VDI 라이선스와 호환성이 검증된 제품"을 명시, 기존 VMware/VDI 생태계 유지 강제
Red Hat 제안
가능 요소
  • 통합 모니터링 시스템 제품 미지정(ECR-010): 특정 벤더 미지정이나 Red Hat의 주력 모니터링 제품(AAP 기반 자동화, Ansible 이벤트 대응)과는 직접 매칭 어려움 — 간접 제안 여지만 존재
  • 서버 OS 일부 미지정: VDI 서버 및 모니터링 서버의 운영체제가 명시되지 않아 이론상 RHEL 제안 가능하나, 기존 VMware/Nutanix 환경 유지 조건으로 실질적 가능성 매우 낮음
  • 기술적용계획표에 Linux 일반 항목 포함: 플랫폼·기반구조 분야에 "Linux" 운영체제가 표준 항목으로 기재되어 있으나, 특정 배포판 미지정 수준에 불과
  • RFP에 명시된 Red Hat(또는 동의어) 제품명·수량: 없음 — RFP 전체에서 Red Hat, RHEL, OpenShift, Ansible, JBoss 등 어떠한 Red Hat 상용 제품도 품목으로 명시되지 않음
  • 종합 의견: 본 사업은 VMware/Nutanix 기반 HW 인프라 교체 및 재배치가 핵심이며, Red Hat 상용 제품이 개입할 실질적 접점이 없음. 영업 활동 대상 우선순위에서 후순위로 분류 권고
