사업 개요 및 목적
  • 국민 누구나 AI 서비스를 체험·개발할 수 있는 통합환경을 제공하는 '모두의 AI실험실' 온라인 플랫폼(舊 DPG통합테스트베드) 고도화 사업이다.
  • 기존 개발자 중심 개발·실증 환경을 국민 누구나 아이디어를 제안하고 AI 서비스로 구현·확산할 수 있는 대국민 참여형 AI 서비스 창출 플랫폼으로 전면 개편하는 것이 핵심 목표이다.
  • 주요 과업은 ① 포털 구축(UI/UX 개편, 문제제기·아이디어 발굴, 우수 서비스 선정·확산), ② 시스템 고도화(AI 개발지원·관리 환경, 바이브코딩 지원체계), ③ 홍보 지원으로 구성된다.

  • 주요 일정: M(착수/분석) → M+1(설계) → M+2(개발·구현) → M+3(시험, 이행·안정화, 완료보고)

Red Hat 제안
불가능 요소
  • S/W 공급 미포함: 본 사업은 포털·플랫폼 SW 개발·구축 용역이 핵심이며, Red Hat 제품(RHEL, OpenShift, Ansible 등)의 직접 조달·공급 요구가 RFP에 명시되어 있지 않다.
  • 경쟁·대체 기술 명시: 바이브코딩 도구로 Microsoft Copilot, Google Gemini, OpenAI ChatGPT, Anthropic Claude Code, Cursor 등 상용 SaaS가 직접 명시. LLM 서빙은 vLLM+오픈소스 모델, GPU는 NVIDIA B200, 컨테이너는 일반 K8s로 기술(특정 배포판·벤더 미지정).
  • 인프라 구성 주체 분리: GPU 서버·K8s 클러스터·스토리지 확장은 "시스템 구성은 운영사업단에서 진행"으로 명시되어, 본 고도화 용역 범위 밖에서 인프라가 구축된다.
  • 대기업 참여 제한: 40억원 미만 SW 사업으로 중소·중견기업(설립 5년 이내)을 제외한 대기업 참여 불가. Red Hat이 직접 입찰 주체로 참여하기 어려운 구조이며, SI/중소 SW사업자와의 공동수급·하도급 형태 검토 필요.
  • 하도급 제한: 하도급 비율 50% 초과 불가, 재하도급 원칙 불허. 상용 S/W 물품구매금액 제외 기준 적용.
Red Hat 제안
가능 요소
  • OpenShift/K8s: ECR-001 GPU 노드 K8s 클러스터 통합, CSR-001 컨테이너 플랫폼 보안(독립 K8s, NetworkPolicy) 요구와 부합. 운영사업단·수행사업자 간 기술적용계획(COR-006) 제안 시 OpenShift 기반 GPU 스케줄링·MIG 관리 아키텍처 제안 가능.
  • RHEL: 기술적용계획표 플랫폼 분야 Linux 서버 OS 적용 항목 존재. GPU 추론·LLM Gateway·프록시 서버 등 Linux 기반 워크로드에 RHEL 제안 여지.
  • Ansible: GPU 자원 프로비저닝, 다중 환경(IaaS/SaaS/API) 자동화, DevOps·CI/CD, 인프라 구성 자동화(SFR-021, CSR-002) 요구와 연계한 자동화·구성관리 솔루션 제안 가능.
  • 클라우드 네이티브·보안: 컨테이너 보안, RBAC, 감사 로그, CSP 환경 보안(CSAP·국가 클라우드 가이드) 요구에 Red Hat 보안·컴플라이언스 역량 활용 가능.
  • 제안 전략: 직접 S/W 납품보다는 공동수급·하도급·기술적용계획·GPU/K8s 운영 아키텍처 컨설팅, DevSecOps·플랫폼 운영 자동화 관점에서 Red Hat 파트너/SI와 협력 제안이 현실적.
