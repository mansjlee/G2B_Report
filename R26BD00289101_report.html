사업 개요 및 목적
  • 중소기업의 AX(인공지능 도입) 및 DX(디지털 전환) 기술 수요를 반영하여 공통 문제점을 발굴하고, 혁신 기술을 개발하여 중소 현장에 실증·확산하는 것이 핵심 목표
  • K-ECP 기반 구독형 클라우드 생태계 조성을 통해 중소기업의 초기 도입 비용 절감
  • 현장 제조·에너지 데이터 수집·표준화를 통한 데이터 거버넌스 확립 및 향후 산업 AI 고도화 기반 마련
  • 5개 과제별 AI/IoT/OCR 기반 맞춤형 플랫폼 개발 후 동종 업계 중소기업으로 확산하는 상생협력 모델 추진
  • 발주기관: 한전KDN(주) 전력ICT연구원 중소기업 AXDX솔루션연구개발 TF

Red Hat 제안
불가능 요소
  • [S/W 납품·구독 항목 없음]: RFP 명시 사항 — "분리발주 대상 상용SW 없음 (오픈소스 사용)" (ECR-001 반복 명시). 본 사업은 순수 소프트웨어 개발 용역으로, 상용 OS·미들웨어·플랫폼 라이선스 구매 항목이 전무함
  • [경쟁 OS 명시]: 섬유 원단 자동검단 플랫폼 ECR-001에 Ubuntu 22.04 LTS를 K-ECP 표준 OS 이미지로 명시 — Red Hat Enterprise Linux(RHEL) 제안 불가
  • [K-ECP 플랫폼 종속]: 모든 과제가 발주기관(한전KDN) 자체 클라우드 인프라인 K-ECP 사용을 전제로 하며, OS·미들웨어 선택권이 K-ECP 표준 스택에 종속됨
  • [오픈소스 기반 개발]: COR-001(오픈소스 라이선스 준수) 조항에 따라 개발 전반에 오픈소스 도구 사용을 전제로 하며, 상용 Red Hat 제품명이 RFP 전체에 단 1건도 언급되지 않음
  • [Windows 환경 공존]: 섬유 원단 검단 VISION PC 환경은 Windows 11 Pro + NVIDIA RTX 기반으로 명시 — Red Hat 스택과 무관한 현장 단말 환경
Red Hat 제안
가능 요소
  • [이론적 Linux 계열 제안 여지 — 미약]: 수퍼체인 유통 플랫폼 ECR-001에 "Linux 계열 운영체제"로만 명시되어 OS 미지정 상태이나, K-ECP 표준 스택 확정 전제 조건으로 인해 실질적 RHEL 제안 가능성 극히 낮음
  • [컨테이너 기반 아키텍처 요구]: 전 과제에 K-ECP 기반 컨테이너 네이티브 아키텍처 및 SaaS 전환 요구 → 이론적으로 OpenShift/Podman 제안 여지가 있으나, 오픈소스 사용 원칙 및 상용SW 구매 없음 조건으로 실질적 기회 없음
  • [RFP 내 Red Hat 상용 제품명 언급 없음]: RHEL, OpenShift, Ansible, JBoss EAP, Satellite 등 Red Hat 상용 제품명이 RFP 전체에 전혀 명시되지 않음
  • 종합 판단: 상용SW 미포함 개발 용역 + Ubuntu OS 명시 + K-ECP 표준 스택 종속으로 Red Hat 제품 제안 및 납품 기회 없음 — 낮음 판정
