사업 개요 및 목적
  • 한국과학창의재단이 발주하는 2개 플랫폼 통합 발주 사업으로, ①AI·융합교육 플랫폼 통합 구축·운영과 ②현장체험학습 통합지원 플랫폼 구축·운영을 단일 계약으로 추진
  • 기존 STEAM 사이트(steam.kosac.re.kr)와 AI플랫폼(School AI, sai.software.kr)을 통합·개편하여 RAG 기반 생성형 AI 검색·추천·교수학습 설계지원 기능을 갖춘 공교육 특화 플랫폼 고도화
  • 창의교육넷(크레존, crezone.net)을 MSA 기반 클라우드 네이티브 구조로 전면 재구축하여 전국 현장체험학습 지원 플랫폼(체험처 탐색, 보조인력 구인·구직, 커뮤니티 등)으로 서비스 구조 전환
  • 정부 클라우드 네이티브 정책 부합 및 AI·디지털 전환 교육 수요 대응을 핵심 목표로 함

Red Hat 제안
불가능 요소
  • Rocky Linux 9 OS 명시: ECR-001 장비구성 요건에 응용서버(VM) OS로 Rocky Linux 9가 명시되어 있음. Rocky Linux는 Red Hat Enterprise Linux(RHEL)의 커뮤니티 대체(다운스트림) 배포판으로, Red Hat의 경쟁·대체 OS에 해당하며 판정 규칙상 낮음 기준 적용
  • 발주기관 제공 클라우드(Naver Cloud) 고정: 인프라는 재단에서 운영 중인 네이버 클라우드 공공 환경(NKS, Cloud DB for MySQL 등)이 기 확정되어 있으며, 제안사는 해당 환경 위에서 아키텍처 설계·구현만 담당. RHEL/OpenShift 등 별도 인프라 도입 여지 없음
  • Naver Kubernetes Service(NKS) 컨테이너 플랫폼 지정: 컨테이너 오케스트레이션은 NKS로 명시되어 OpenShift Container Platform 제안 불가
  • RFP 내 Red Hat 상용 제품 전혀 없음: RHEL, OpenShift, Ansible, JBoss EAP, Satellite 등 Red Hat 상용 제품명이 문서 어디에도 명시되지 않음
  • 현행 시스템 SW 스택 비Red Hat: 현재 운영 중인 시스템은 Apache Web Server, Apache Tomcat WAS, JAVA/eFovFramework 기반으로 JBoss/EAP 계열 없음. SSO도 TouchEn Wiseaccess 사용 중
  • 순수 SW 개발 용역 성격: 사업의 핵심은 플랫폼 개발·구축·운영 용역이며, 상용 SW 납품 범위가 AI검색엔진·시각화솔루션 등 특정 분야에 한정됨
Red Hat 제안
가능 요소
  • Kubernetes/MSA 구조 요구: INR-004 및 ECR-001에서 Kubernetes 기반 MSA 아키텍처, Service Mesh(mTLS·트래픽 제어·Circuit Breaker), API Gateway/BFF 구성 등을 요구하고 있어 이론적으로 OpenShift 또는 Ansible Automation Platform 제안 여지가 있으나, NKS(Naver Kubernetes Service)가 이미 지정되어 있어 실질적 진입 불가
  • DevOps/CI·CD 파이프라인 요구: ECR-001에 Git 기반 형상관리, Jenkins/Tekton 등 CI/CD 파이프라인, 컨테이너 이미지 레지스트리 구축이 요구되어 Ansible Automation Platform 또는 OpenShift 제안 이론적 가능성 존재. 단, 특정 도구(Jenkins/Tekton)가 언급되어 있고 발주기관 클라우드 환경 내 구현이 전제됨
  • RFP 내 Red Hat 제품명·수량 명시 없음: 문서 전반에 걸쳐 RHEL, OpenShift, Ansible, JBoss EAP, Satellite 등 Red Hat 상용 제품명이 단 한 건도 명시되지 않음. 제안 기회 부재
  • 종합 평가: Rocky Linux 9 OS 명시, NKS 컨테이너 플랫폼 고정, 발주기관 제공 Naver Cloud 환경 전제 등 복합적 제약으로 인해 Red Hat 제품의 실질적 제안 가능성은 매우 낮음
