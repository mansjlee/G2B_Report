사업 개요 및 목적
  • 한국산업단지공단의 스마트K팩토리(스마트산단 공유플랫폼)에 LLM 기반 AI 서비스를 도입하고, AX(AI 전환) 성과물 공유·확산을 위한 AX공유허브를 구축하는 사업
  • (AI 서비스 도입) 약 20만 개 전국 등록공장 정보 등을 자연어로 질의하고 신뢰 기반 답변(RAG)을 제공하는 LLM 기반 통합 검색·질의응답 서비스 구축
  • (AX 공유허브 구축) AI 모델·제조데이터셋·AX 서비스 등 자산을 표준 메타데이터 카탈로그 기반으로 통합 등록·검색·활용할 수 있는 포털 환경 구축
  • (인프라 서비스 연계) 산업단지 엣지 AIDC 및 5G 특화망 플랫폼과 표준 API 기반으로 연계하여 입주기업이 한 곳에서 인프라 서비스를 확인·활용할 수 있는 체계 마련
  • 수요기관: 한국산업단지공단 (대구광역시 동구 첨단로 39)

불가능 요소
  • [S/W 비공개] 기존 시스템의 H/W·S/W 구성 정보가 비공개로 지정되어 있어, 현재 도입된 OS·플랫폼·미들웨어 환경을 공개 문서만으로 확인 불가
  • [Red Hat 상용 제품 미명시] RFP 본문에 RHEL, OpenShift, Ansible, JBoss EAP 등 Red Hat 상용 제품명이 품목으로 명시되지 않음 → "높음" 판정 근거 없음
  • [오픈소스 우선 정책] COR-004 제약사항에 "시스템 종속성 최소화를 위해 가능하면 공개소프트웨어·오픈소스 기반으로 구현"을 요구하여, 상용 라이선스 제품 제안에 부담이 있음
  • [벡터 DB 오픈소스 우선] ECR-002에서 벡터 DB를 "오픈소스 기반 우선 검토"로 명시하여, 상용 데이터 플랫폼 제안이 제한적
  • [경쟁·대체 OS 미명시이나 확인 불가] Ubuntu, Rocky Linux 등 경쟁 OS가 명시되지는 않았으나, 기존 시스템 환경 비공개로 인해 대체 여지 확인 어려움
  • [20억 미만 중소기업 제한 입찰] 대기업·중견기업의 입찰참여가 제한되므로, Red Hat이 직접 제안사로 참여하기 어렵고 파트너사를 통한 납품 구조에 해당
Red Hat 제안
가능 요소
  • [컨테이너 기반 인프라 → OpenShift 제안 여지] ECR-003에서 "Docker 등 컨테이너 기술을 활용한 자원 격리 환경(CPU Quota, Memory Limit 등)" 및 "MSA 형태의 연동 체계"를 명시 → Red Hat OpenShift Container Platform 제안 가능
  • [GPU 서버 OS 환경 → RHEL 제안 여지] ECR-001에서 "확정된 인프라 위에 OS, 드라이버, 런타임 등 LLM 구동 환경 구성" 요구 → GPU 서버용 RHEL 도입 제안 가능 (RHEL은 NVIDIA GPU 드라이버 인증 OS)
  • [LLM 서빙 환경 → OpenShift AI / RHEL AI 제안 여지] ECR-003 LLM 서빙 프레임워크 구성, ECR-001 AI 연산 인프라 환경 → OpenShift AI(구 RHOAI) 또는 RHEL AI 제안 가능
  • [Linux OS 옵션 포함] 기술적용계획표(별첨1) 운영체제 항목에 Linux가 명시적으로 포함되어 있어, RHEL 제안 근거 존재
  • [기존 H/W·S/W 비공개 → 기회] 세부 구성이 비공개이므로, 제안사가 RHEL/OpenShift 기반 아키텍처를 적극적으로 제안하여 채택 가능성 존재
  • [Ansible 자동화 제안 여지] 복잡한 컨테이너·GPU·MSA 환경의 배포·관리 자동화를 위해 Ansible Automation Platform 제안 가능
  • [RFP 내 Red Hat 제품명 명시 없음] RFP 공개 문서 내에 Red Hat 또는 동의어(RHEL, OCP, Ansible 등) 상용 제품이 명시된 품목은 없음
