Red Hat 제안
불가능 요소
  • [Red Hat 상용 제품명 미명시]: RFP 전문에 RHEL, Red Hat Enterprise Linux, OpenShift, Ansible, JBoss EAP, Satellite 등 Red Hat 상용 제품명이 단 한 건도 명시되지 않음. "높음" 판정 근거 없음
  • [JBoss/WildFly 미명시]: RMS의 WAS 품목이 명시되어 있으나 제품명은 보안상 비공개(방문 열람 필요)로 처리됨. WAS 119식(기존) + 8식(신규, 세종교육청) 도입 예정이나 JBoss/WildFly 등 특정 제품명 불명확
  • [경쟁 제품 존재 가능성]: 월간 운영보고서 예시에 "Rocky Linux", "WebtoB", "JEUS", "Tibero" 등이 예시로 등장하여 현재 운영 환경이 Rocky Linux + TmaxSoft 계열 스택일 가능성이 높음 (단, 예시 문서에 불과하며 확정이 아님)
  • [품목 보안 비공개]: HW 및 SW 품목별 제품명·수량이 국가 보안상 비공개 처리되어 있어 (방문 후 보안서약서 작성 후 열람 가능), 현재 운영 중인 정확한 제품 현황 파악 불가
  • [별첨3 직접구매 목록 불명확]: 직접구매 대상 상용SW 구매계획(별첨3)이 이미지 파일로만 존재하여 세부 내용 확인 불가
  • [기존 스택 종속 가능성]: RMS 2.0은 전자정부 표준프레임워크 기반 Java 환경으로 운영되며, DBMS는 Tibero(국산) 계열이 광범위하게 사용되고 있을 가능성이 있음
Red Hat 제안
가능 요소
  • [RHEL 제안 여지]: 기록관리서버는 "Unix 또는 Linux로 구동"이라고 명시되어 있어 OS 미확정 상태. 신규 도입 x86서버(세종교육청 3식, 각 기관 2식 등 총 17식)에 OS 포함이 명시되어 있으며, OS 품목(기존 8식 유지관리 대상)이 존재함. RHEL 제안 가능
  • [WAS 품목 - JBoss EAP 제안 여지]: 세종교육청 신규 WAS 8식 도입 예정. 현재 WAS 119식을 유지관리 중이며 제품명 비공개. 월간보고서 예시에 "JEUS"가 등장하나 단순 예시일 수 있으며, JBoss EAP를 대안으로 제안 가능
  • [가상화SW - RHEV 또는 OpenShift 제안 여지]: 신규 가상화SW 8식 도입 예정 (세종교육청, 인천 남동, 인천 계양, 경기 가평, 경기 안양, 전북 정읍, 전남광주 담양, 전남광주 함평). 가상화 플랫폼 미확정으로 Red Hat Virtualization 또는 OpenShift Virtualization 제안 가능
  • [Ansible 자동화 제안 여지]: 119개 기관 대상 대규모 통합 유지관리, OS 패치, SW 업그레이드, 모니터링 자동화 필요성이 높음. Ansible Automation Platform 도입을 통한 운영 자동화 제안 가능
  • [AI 기반 운영 요구사항]: MPR-03에서 "AI기술을 적용하여 이상 징후 탐지 및 장애예측, 장애조치방안 제공 등 운영지원"을 명시. Red Hat OpenShift AI, RHEL AI 등의 솔루션과 연계한 제안 여지 존재
  • [RFP에 명시된 Red Hat(동의어) 제품명]: 없음 (보안 비공개 품목 내에 존재 가능성은 있으나 현재 확인 불가)
  • [파트너사 협력 전략]: 수주업체(SI)와 협력하여 HW 서버 OS(RHEL), WAS(JBoss EAP), 가상화SW(RHEV/OpenShift Virt) 품목을 하도급 또는 물품 공급 형태로 제안하는 전략이 유효함. 발주기관과 SI사를 동시 공략 필요
