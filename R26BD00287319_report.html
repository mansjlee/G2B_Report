Red Hat 제안
불가능 요소
  • 운영·용역 중심 사업: 본 사업의 주된 내용은 시스템 운영·유지관리 용역으로, Red Hat이 직접 시스템통합(SI) 사업자로 입찰하기 어려운 구조임
  • 신규 RHEL 통합발주 없음: 이번 사업에서 RHEL 신규 라이선스 통합발주 항목이 별도로 명시되지 않았으며, API 게이트웨이 증설은 조달쇼핑몰 직접구매로 별도 발주됨
  • 20억 원 미만 중소기업 전용: 소프트웨어 진흥법에 의해 대기업·중견기업 입찰 참여가 제한되므로, Red Hat 국내 법인이 직접 수주 불가 (파트너사를 통한 영업 필요)
  • 경쟁 제품 명시 없음(중립적): VMware, Ubuntu, Rocky Linux 등 경쟁 제품이 명시되지 않아 제안 배제 요소는 없으나, 기존 OS가 이미 RHEL로 확정되어 있어 신규 전환 기회는 제한적
Red Hat 제안
가능 요소
  • RHEL 상용 제품 기도입 확정 — 높음 판정 근거
    • 1차 사업에서 RHEL(Red Hat Enterprise Linux) 33식이 OS로 명시 도입됨
    • 2차 사업에서 RHEL(Red Hat Enterprise Linux) 11식이 OS로 명시 도입됨
    • 합계 RHEL 44식이 국가정보자원관리원(대전) 서버에 운영 중
  • 상용SW 유지보수 포함(OMR-02): 본 사업 과업 범위에 상용SW 유지관리가 명시되어 있으며, 기 도입된 RHEL 구독 갱신(Subscription Renewal) 영업 기회 존재
  • SW 자원 증설 시 라이선스 반영: OMR-02에 "운영 중 연계 시스템의 자원 증설 시 상용SW 라이선스 반영"이 명시되어, 추가 서버 도입 시 RHEL 라이선스 확대 가능성 있음
  • RFP 내 Red Hat 제품명 직접 명시: 정보화 현황 표에서 "OS(RHEL, 33식)", "OS(RHEL, 11식)"으로 Red Hat 상용 제품명이 품목으로 명시되어 도입·운영이 확정된 상태
  • 파트너사 영업 기회: 유지관리 사업자(중소 SW사업자)가 RHEL 구독 갱신 등 상용SW 유지보수 비용을 산정할 때 Red Hat 파트너를 통한 납품 기회 발생 가능
  • Ansible/자동화 제안 여지: 60종 이상의 콘텐츠 연계, 다수 서버(50식 이상) 운영 환경에서 Ansible Automation Platform을 통한 운영 자동화·패치 관리 제안 가능 (단, 현재 명시 없음)
