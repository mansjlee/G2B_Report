Red Hat 제안
불가능 요소
  • 신규 S/W 구매 항목 없음: 소프트웨어 분리발주 대상이 해당 없으며, 본 사업은 기존 DIMS 운영·유지를 위한 순수 용역 사업임. 신규 Red Hat 라이선스 납품 기회는 직접적으로 명시되지 않음
  • 연동엔진은 타사 제품: 핵심 연동엔진(Mesim ESB) 및 망연계(Mesim mHub)는 메타빌드 제품으로, Red Hat 제품과 무관
  • 대기업 참여제한: 소프트웨어 진흥법 제48조에 따라 대기업·중견기업 참여 불가. Red Hat Korea가 직접 입찰에 참여할 수 없으며, 파트너사를 통한 간접 참여 구조
  • 국방 보안 제약: 국방망 환경으로 보안 요건이 매우 엄격하며, 외부 인원 접근 및 장비 반입에 강도 높은 통제가 적용됨
  • DBMS 경쟁 제품: DBMS로 CUBRID가 기존에 사용 중이며, Oracle·Rocky Linux 등의 명시는 없으나 Red Hat DBMS 관련 제품 도입 여지 없음
Red Hat 제안
가능 요소
  • JBoss EAP (레드햇 상용 제품) 명시: WAS 서버로 JBoss EAP(레드햇)가 현황 상용 SW 목록에 명시되어 운영 중. 유지보수 수행업체는 해당 제조사(Red Hat)와 협업 방안을 제시해야 하며, 기술지원협약서/확약서 발급이 요구될 수 있음 (RFP 내 [별지 22호] 기술지원협약서 참조)
  • JBoss EWS (레드햇 상용 제품) 명시: WEB 서버로 JBoss EWS(레드햇)가 현황 상용 SW 목록에 명시. 기존 Red Hat 스택이 운영 환경에 통합되어 있어 지속적 기술지원 및 구독 갱신 기회 존재
  • 상용 SW 제조사 협업 요구: MAR-10(정기점검), HRR-01(협력업체 관리), PSR-01 등에서 상용 SW 제조사와의 협업 방안 제시를 명시적으로 요구. 수행업체가 Red Hat과 공식 파트너십을 보유하고 있을 경우 가점 요소로 작용 가능
  • Java 기반 WAS 환경: 개발환경이 Java 1.7 기반 전자정부 표준프레임워크로 구성되어 있어, JBoss EAP 기반의 Red Hat 기술 스택이 핵심 인프라로 지속 활용되는 구조
  • RFP 내 Red Hat 제품명 직접 언급: 상용 SW 현황표에 "WAS서버: Jboss EAP — 레드햇", "WEB서버: Jboss EWS — 레드햇"으로 제조사가 명확히 명기됨
