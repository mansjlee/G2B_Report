Red Hat 제안
불가능 요소
  • Windows OS 명시: AI 자가진단 키오스크(4대) 의 OS로 Windows 10/11 Pro 이상이 요구사항(SIR-003)에 명시되어 있어, RHEL 제안 불가
  • Red Hat 상용 제품 전무: RFP 전체에 RHEL, OpenShift, Ansible, JBoss EAP, Satellite, Quay 등 Red Hat 상용 제품이 품목으로 단 한 건도 명시되지 않음
  • 컨테이너·Kubernetes 요구사항 부재: OpenShift/Kubernetes 기반 플랫폼 구성 요구사항이 없으며, 인프라 구조는 단순 로컬 PC 및 임베디드 장비 중심
  • 주요 SW가 맞춤형 개발 콘텐츠: 납품 SW 대부분이 전시·체험용 커스텀 콘텐츠 및 MES/디지털트윈 개발 결과물로, 상용 미들웨어·플랫폼 SW 도입 항목이 없음
  • 소규모 컴퓨팅 사양: 체험용 PC 사양이 CPU i5/RTX 3060 수준의 워크스테이션급으로, 엔터프라이즈 Linux 서버 구독 도입 근거 없음
Red Hat 제안
가능 요소
  • RFP 내 Red Hat 상용 제품 명시: 없음 — Red Hat(레드햇), RHEL, OpenShift, Ansible, JBoss EAP 등 어떠한 Red Hat 상용 제품명도 RFP에 등장하지 않음
  • AI Agent / LLM 서버 인프라 잠재성 (매우 제한적): AI Agent(LLM + RAG + 멀티에이전트) 구성을 위한 백엔드 컴퓨팅 자원(AI 체험 콘텐츠용 컴퓨팅 자원 3식 이상, GPU: RTX3060 이상)이 요구되나, OS 지정이 없어 이론상 RHEL AI 또는 RHEL 기반 AI 서버를 제안할 여지는 극히 제한적으로 존재 — 단, 사실상 Windows 기반 개발 환경이 전제된 구조이며 공식 요구사항 아님
  • 결론: Red Hat 상용 제품 제안 기회가 실질적으로 없는 사업으로 판단되며, 영업 자원 투입 대비 효과가 매우 낮음
