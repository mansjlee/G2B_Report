Red Hat 제안
불가능 요소
  • S/W 별도 구매·납품 항목 없음: 본 사업은 순수 통합유지보수 용역으로, RFP 내 Red Hat 상용 제품(RHEL, OpenShift, Ansible, JBoss EAP 등)이 도입·납품·증설 품목으로 명시된 항목이 없음
  • Red Hat 상용 제품명 미기재: 현행 유지보수 대상 S/W 목록, 운영 환경, 시스템 구성 현황 어디에도 RHEL, JBoss EAP, OpenShift, Ansible 등 Red Hat 상용 제품명이 명확하게 기재되어 있지 않음
  • 경쟁·커뮤니티 제품 환경 확인: 월간 운영보고서 샘플(붙임6)의 SW 구성 현황 예시에 "Rocky Linux", "JEUS", "WebtoB" 등이 기재되어 있어, 현행 Linux 운영환경이 Rocky Linux(RHEL 대신 커뮤니티/대체 배포판) 기반일 가능성이 있음. Rocky Linux가 명시된 경우 RHEL 대체품으로 간주되어 Red Hat 상용 제품 도입 여지 제한
  • JBoss 표기 미확인: RFP 본문 내 "JBoss"라는 표기가 직접 명시된 항목이 없음 (Tmax JEUS, Apache Tomcat 등 타사 WAS 중심 환경으로 기재됨)
  • 순수 용역 사업: 사업자가 인력을 상주시켜 운영·유지보수를 수행하는 용역 형태이므로, Red Hat이 직접 구독 판매 기회를 얻기 어려운 구조
Red Hat 제안
가능 요소
  • Linux 기반 서버 운영환경 다수 존재: RFP MAR-05에서 "서버 OS(Linux, Unix, Windows Server 등)"를 유지보수 대상으로 명시하고 있어, Linux 계열 OS 환경이 광범위하게 운영 중임. OS 종류가 특정되지 않은 영역에서 RHEL 제안 여지 존재
  • WAS/미들웨어 운영 환경: MAR-05에서 웹/미들웨어 운영 대상으로 "JEUS, Apache, Tomcat, Nginx 등"이 명시되어 있으며, Tomcat 기반 환경에서 JBoss EAP 전환 제안 가능성이 있으나 현재 Tmax JEUS 중심 환경으로 보임
  • 컨테이너·클라우드 환경 언급: MAR-02에서 "클라우드 환경(IaaS/PaaS)" 및 MSP 협업 체계, MAR-03에서 "CI/CD 환경 구축·운영"이 명시되어 있어, OpenShift(컨테이너 플랫폼) 제안 여지가 중장기적으로 존재
  • 자동화·운영효율화 니즈: 24시간 365일 무중단 운영, 대규모 인프라(377대 서버, 1,484대 네트워크·보안장비) 관리 요구로 Ansible Automation Platform(자동화) 도입 가치를 어필할 수 있는 환경
  • 오픈소스 보안 패치 관리 의무화: MAR-03에서 오픈소스 CVE 패치 및 보안취약점 관리가 명시되어 있어, RHEL의 엔터프라이즈 보안 지원(Extended Security Updates 등) 가치 소구 가능
  • Rocky Linux 사용 가능성 → RHEL 전환 영업 기회: 샘플 구성도에 Rocky Linux 기재 확인. CentOS/Rocky Linux 환경에서 RHEL로의 전환(Convert2RHEL) 제안 기회로 활용 가능
  • RFP 내 Red Hat 상용 제품명 명시 없음: 현 단계에서 RHEL, OpenShift, Ansible, JBoss EAP 등 Red Hat 상용 제품이 도입 품목으로 명시된 사례는 없음. 직접 판매 기회보다는 차기 사업 대비 고객 접점 확보 차원의 접근이 현실적
