사업 개요 및 목적
  • 2001년 구축(26년 운영)된 목원대학교 학사행정시스템의 노후화된 UI/UX를 최신 PowerFrame 기반으로 전면 마이그레이션하는 고도화 사업
  • 구형 사용자 인터페이스 개선, 시스템 오류 감소, 사용자 편의성 극대화(FHD 화면 UI 적용)
  • 사용자 권한 체계·로그관리·DB 접근통제 등 보안 취약점 개선 및 개인정보보호법(제29조, 시행령 제30조) 준수
  • 데이터베이스 유니코드(UTF-8) 전환을 통한 다국어 지원 환경 구축
  • Windows 11 호환 배포 환경 구성 및 파일 업/다운로드(HTTP) 서비스 품질 향상

    • 데이터베이스 로그관리 솔루션 — 수량 미명시 (테이블 변경관리, 스크립트 버전관리, 데이터 플래시백, 복구 기능 포함, DAR-004)
Red Hat 제안
불가능 요소
  • Windows 11 환경 확정: 사용자 환경이 Windows 11 + PowerClient로 명시되어 있어 Linux/RHEL 도입 여지가 사실상 없음 (SFR-001)
  • Red Hat 상용 제품 전혀 미언급: RFP 전문에 RHEL, OpenShift, Ansible, JBoss, AAP 등 Red Hat 상용 제품명이 단 한 건도 등장하지 않음
  • 기술 스택이 RH 스택과 무관: 개발 환경 전체가 PowerBuilder 2025 + PowerFrame + PowerBoard(SAP/Sybase 계열) 기반 Windows C/S 아키텍처로, 컨테이너·자동화·Linux 계열 요구사항 없음
  • 도입 S/W 품목 고정: 통합발주 S/W가 PowerBuilder·PowerFrame·PowerBoard·DB 관리 툴·DB 로그관리 솔루션으로 이미 특정되어 있어 Red Hat 제품 추가 제안 공간 없음
  • 중소기업 제한 입찰: 「SW진흥법」제48조에 의거 중소기업만 입찰 가능하여 Red Hat 직접 참여 불가
Red Hat 제안
가능 요소
  • RFP 내 Red Hat 제품명 명시 없음: RHEL, OpenShift, Ansible, JBoss EAP 등 Red Hat 상용 제품이 품목으로 명시된 사례 전무
  • 서버 OS 미지정 (극히 제한적 여지): DB 서버·웹 서버의 운영체제가 명시되지 않아 이론상 RHEL 제안이 불가능하지는 않으나, 전체 아키텍처가 Windows 11 기반 C/S 환경으로 설계되어 있어 실질적 제안 가능성은 매우 낮음
  • 결론: Red Hat 제품을 제안할 수 있는 기술적·사업적 근거가 RFP에 존재하지 않으며, 이번 사업에서 Red Hat 영업 기회는 없는 것으로 판단됨
