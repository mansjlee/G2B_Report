한국은행_통합 업무정보관리 시스템(ECM) 구축 사업 - 분석 리포트

레드햇 제안 가능성 높음
RHEL 품목 명시(ECR-010)
사업 개요 및 목적
  • 한국은행이 현재 사용 중인 MS SharePoint 기반 Digiworks 플랫폼을 고도화·대체하는 통합 업무정보관리 시스템(ECM, Enterprise Content Management) 구축 사업
  • 비정형 데이터(문서·영상·이미지 등)의 체계적 보안등급 부여, 메타데이터 관리, 유통 통제 등 정보 생애주기 전반을 관리하는 기반 시스템 구축
  • 생성형 AI 학습용 데이터 파이프라인 구성, 부서 간 자료공유 확대, 총무업무 효율화 등 당행 주요 디지털전환 사업을 다층적으로 지원하는 것이 핵심 목적
  • 쿠버네티스 기반 On-Premise 환경으로 구축하며, 향후 클라우드 전환 용이성(cloud-agnostic) 확보
  • 기존 결재시스템(BOIS), SSO, ElasticSearch, AI 저장소 등 기존 시스템과의 연계 포함

Red Hat 제안
불가능 요소
  • [가상화 SW 경쟁 제품 명시]: ECR-012에서 "VMware vSphere Foundation (VMware vCenter Server Standard 포함)"이 가상화 소프트웨어로 명시·지정됨. Red Hat Virtualization(RHEV) 또는 OpenShift Virtualization으로 대체 제안 가능성 낮음
  • [DBMS 경쟁 제품 명시]: ECR-011에서 Oracle Exadata 12c(Active-Active)가 기존 DBMS로 지정되어 있으며, 기존 자원 활용 예정. Red Hat Data Grid 등 DB 레이어 제안 여지 제한적
  • [쿠버네티스 환경의 특수성]: 현재 디지털혁신실 운영 중인 쿠버네티스 환경을 확장하는 형태로 구성해야 하므로, 신규 OpenShift 플랫폼 독립 도입보다는 기존 환경에 종속된 구성이 요구됨
  • [통합발주 구조]: SI 통합사업자가 H/W·S/W 일체 납품 책임 — Red Hat이 직접 입찰하기보다 SI 협력사를 통한 제안 필요
Red Hat 제안
가능 요소
  • [RHEL 품목 명시 — 높음 판정 근거]: ECR-010(운영체제 요건)에 "리눅스 — Red Hat Enterprise Server, 수량: 필요수량"이 도입 품목으로 명시됨. 상용 RHEL 라이선스 납품이 사실상 확정된 사업임. 영구 라이선스 제공 원칙(COR-010)에 따라 영구 라이선스 또는 다년 구독 형태 제안 가능
  • [RHEL 수량]: ECM 메인 서버 3대 이상(쿠버네티스 워커노드), 개발서버 2대 이상, 기타 서버(필요수량) 등 전체 서버에 RHEL 적용 예상. 마스터 노드(VMware 환경 가능)에도 Linux OS 필요
  • [OpenShift 제안 여지]: COR-005 및 ECR-002에서 쿠버네티스 환경 운영이 의무화되어 있으며, CNCF 표준 규격 지원 환경 구성 요구. CRI-O 런타임 전환 예정(ECR-002)으로 OpenShift와의 기술적 정합성 높음. 단, 기존 디지털혁신실 쿠버네티스 환경 확장 형태로 제안해야 하므로 별도 OCP 독립 구성보다는 기존 환경 호환 강조 필요
  • [Ansible 제안 여지]: 다수 서버 환경 구성 자동화, VMware·K8s 환경 통합 관리, 보안패치 자동화 등 인프라 자동화 수요 존재. Ansible Automation Platform 도입 제안 가능
  • [JBoss EAP 제안 여지]: ECR-011에서 WAS는 제안사가 선택하도록 되어 있어 JBoss EAP 제안 가능. 단, 기존 한국은행 환경과 호환성 확인 필요
  • [기술 스택 적합성]: CRI-O 런타임 전환 계획, 전자정부 표준프레임워크(Java/JSP 기반), CNCF 표준 쿠버네티스 환경 요구 등은 Red Hat 기술 스택(RHEL + OpenShift + Ansible)과 높은 정합성을 가짐
