Red Hat 제안
불가능 요소
  • Red Hat 상용 제품명 미명시: 통합발주 상용S/W 27종 목록에 RHEL, OpenShift, Ansible, JBoss EAP 등 Red Hat 상용 제품명이 전혀 포함되어 있지 않음
  • DBMS 환경이 Oracle 중심: 상용S/W 목록에 오라클 5종이 명시되어 있어 Oracle Linux 기반 환경일 가능성 존재
  • 미들웨어 환경이 티맥스 중심: 상용S/W에 티맥스 7종 명시 — JBoss EAP 제안 여지 축소
  • 유지보수 용역 성격: 기존 시스템을 유지·관리하는 사업 특성상 기 도입된 제품의 subscription 갱신이 주목적이며, 신규 Red Hat 제품 도입 근거는 문서상 없음
  • 대기업 참여 불가: 중소 SW사업자 한정 입찰로 Red Hat 직접 참여 불가, 파트너를 통한 납품 구조여야 함
Red Hat 제안
가능 요소
  • Linux OS 운영 환경 확인: 기술적용 계획표(플랫폼·기반구조 분야)에 서버용 운영체제로 "Linux ○(적용)"이 명시되어 서버 일부에 Linux OS가 운영 중임을 확인 — RHEL 도입 또는 전환 제안 여지 존재
  • OS subscription 갱신 포함: 사업 내용에 "상용소프트웨어 기술지원서비스 계약(subscription 포함)" 및 "라이선스 갱신 포함"이 명시되어 있어, 기존 RHEL subscription이 갱신 대상일 수 있음
  • OS 패치·업그레이드 지원 요구: MPR-06 요구사항에 "OS에 대한 Patch Release, Hot Fix 수준의 Upgrade 지원(보안 Patch 포함)"이 명시 — RHEL 기술지원 서비스 연계 가능
  • 서버 44대 규모: 다수의 서버에 OS subscription이 필요한 환경으로, RHEL 구독 제안 시 의미 있는 규모
  • 보안 패치 중단 OS 교체 요구: MPR-07에 "보안패치가 중단된 시스템은 OS를 최신 버전으로 업그레이드 조치" 명시 — CentOS → RHEL 전환 제안 기회 가능
  • Red Hat 제품 명시 수량: RFP 본문에 Red Hat(또는 동의어) 제품명·수량이 명시적으로 기재된 항목은 없음
