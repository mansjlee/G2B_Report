Red Hat 제안
불가능 요소
  • 유지관리 용역 중심 사업: 본 사업은 기존 시스템의 유지관리가 주목적이며, 신규 SW 대규모 도입보다는 기존 라이선스 갱신 위주로 구성됨
  • 경쟁 제품 명시 없음: Ubuntu, Rocky Linux, Oracle Linux, VMware 등 Red Hat 경쟁 제품이 RFP 내 명시적으로 지정된 사항은 없음
  • 중소기업 참여 제한: 사업금액 20억 미만으로 대기업 참여 불가. Red Hat Korea가 직접 입찰 불가하며 중소 파트너사를 통한 간접 납품 구조여야 함
  • 하도급 불허: 본 사업은 하도급계약을 허용하지 않으므로, 직접 생산증명서 보유 중소 파트너를 통해서만 참여 가능
  • 보안관제 서버 OS 제품명 비공개: 보안관제 종합시스템 서버 OS(17식)의 구체적 제품명은 현행 시스템 비공개 방침으로 확인 불가(방문 열람 필요)
Red Hat 제안
가능 요소
  • RHEL 연간 라이선스 갱신 확정 (3식): 라이선스 갱신 목록에 "학교통합 누리집 RHEL 연간 라이선스 3식"이 명시적으로 포함되어 있어 Red Hat 상용 제품 도입이 확정된 상태임. 기존 RHEL 운영 환경의 연간 서브스크립션 갱신 기회
  • 서버 OS 추가 제안 여지 (보안관제 서버 OS 17식): "보안관제 종합시스템 서버 OS 17식" 갱신이 명시되어 있으나 제품명 비공개 상태. 방문 열람 시 RHEL 여부 확인 및 미사용 시 전환 제안 가능
  • 뉴타닉스(Nutanix) 가상화 환경 연계: 뉴타닉스 연간 라이선스 48식 갱신 포함. 뉴타닉스 위 Guest OS로 RHEL이 이미 운용 중이며, Nutanix + RHEL 스택 확장 제안 가능
  • WAS 환경 — JBoss EAP 전환 제안 여지: 학교통합 누리집 WAS 2식, 직속기관 WAS 2식 등 WAS 솔루션 유지관리 포함. 현재 사용 WAS 제품 확인 후 JBoss EAP 전환 제안 검토 가능
  • RFP에 명시된 Red Hat 제품명·수량 요약:
