사업 개요 및 목적
  • 명지·녹산 국가산업단지의 노후화에 따른 생산 효율성 저하 및 경쟁력 급감 문제를 해소하기 위해, 디지털트윈 기반 통합산단관제 플랫폼을 구축하는 사업
  • 산단 환경·안전·물류·에너지를 3D 디지털트윈 가상환경에서 통합 모니터링·관제하고, LLM 기반 지능형 운영 UI/UX를 제공
  • SaaS 기반 제조AI 서비스 및 탄소회계 플랫폼을 구축하여 입주 중소·중견기업의 AX(AI 전환) 가속화 지원
  • AI 기반 도로위험 관리, 다차원 멀티센서 환경 모니터링(지상·드론·위성), 탄소배출량 산정·보고 자동화 기능 포함
  • AX 종합지원센터 및 AX 라운지 구축을 통해 산단 내 기업들이 디지털트윈·AI 기술을 체험·확산할 수 있는 거점 조성

가능 요소
  • 클라우드 기반 탄소회계 시스템의 Linux 명시 (ECR-007): "모든 서버는 Linux기반으로 안정적 운영 및 확장성을 확보함"이라고 명시됨. 클라우드 상용 서버 서비스(VM 5대) 구성 시 RHEL 기반 가상 머신 제안 가능
  • 클라우드 인프라 구성 (ECR-009): 탄소회계 시스템용 상용 클라우드 서버 서비스(VM 5대, 스토리지 5TB)를 구축기간 동안 제공하도록 명시됨. RHEL 또는 Red Hat OpenShift 기반 클라우드 환경 제안 가능성 존재
  • PostgreSQL DB 운영 환경: 탄소회계 내부 서버에서 "센서/계측 데이터 실시간 적재용 DB 운영 (PostgreSQL)" 명시됨. RHEL 환경과 PostgreSQL의 조합으로 제안 시너지 가능
  • Open Source GIS 기반 환경 및 오픈소스 활용 (SFR-019): "국제 표준(OGC 표준)을 준수한 최적화된 Open Source GIS 기반 응용 소프트웨어 운영 환경을 구축"이라 명시됨. RHEL 위에서의 오픈소스 GIS 스택 제안 가능
  • 자동화·인프라 관리 필요성: 109개 요구사항, 3차에 걸친 대규모 납품 일정, 다수 서버/장비 통합 운영 등 복잡한 인프라 환경에서 Ansible Automation Platform을 활용한 인프라 자동화·구성 관리 제안 여지 존재 (단, 현재 RFP에 명시 없음)
  • SaaS·멀티테넌시 플랫폼 구조: 탄소회계 SaaS 플랫폼이 "오토스케일링 및 이중화 구성으로 서비스 가용성 확보" 명시됨. 컨테이너/Kubernetes 기반 아키텍처 제안 시 OpenShift 포지셔닝 가능(단, 현재 명시 없음)
  • RFP 내 Red Hat 제품명·수량 명시 없음: 문서 전체에서 RHEL, OpenShift, Ansible, JBoss 등 Red Hat 상용 제품이 품목으로 명기된 사례 없음
