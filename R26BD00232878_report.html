Red Hat 제안 불가능 요소
  • S/W 공급이 아닌 단순 CSP 사업인가?: 아니오. H/W, S/W 도입 및 개발이 포함된 대규모 시스템 통합(SI) 사업입니다. Red Hat 단독 제안이 아닌, SI 파트너사와의 협력이 필수적입니다.
  • 경쟁 제품 명시 여부: VMware가 호환 가능한 가상화 SW로 언급되었으나(ECR-003), 필수 도입 사항은 아닙니다. 오히려 가상화 SW 요구사항(ECR-007)에 Red Hat OpenShift가 명시되어 있어 경쟁 우위에 있습니다.

Red Hat 제안 가능 요소
  • Red Hat OpenShift (제안 필수): ECR-007 요구사항에 "Red Hat OpenShift 1식"이 명시되어 있어 제안의 핵심 요소입니다. MSA, 컨테이너 기반 클라우드 환경 구축이라는 사업의 핵심 목표를 직접적으로 충족시킵니다.
  • Red Hat Enterprise Linux (RHEL) (제안 유력): ECR-003에서 13대의 신규 서버 Guest OS로 "사업 기간뿐만 아니라 향후 유지보수 간 기술지원에 제한없는 Linux OS"를 요구하고 있습니다. 이는 RHEL 서브스크립션의 가치와 완벽하게 일치하며, 안정성과 기술 지원이 필수적인 국방 사업 특성상 최적의 제안입니다.
  • Red Hat JBoss EAP (제안 가능): ECR-008에서 WAS 도입을 요구하고 있어, OpenShift 플랫폼 상에서 MSA 애플리케이션을 운영하기 위한 최적의 경량 미들웨어로 제안할 수 있습니다.
  • Red Hat 3scale API Management (제안 가능): ECR-013에서 API SW 11식 도입이 요구됩니다. 상세 요구사항에 명시된 API 라우팅, 인증, 접근 제어, 사용량 제한 등의 기능을 모두 충족하는 3scale API Management를 제안할 수 있습니다.
  • Red Hat Ansible Automation Platform (가치 제안): 명시되진 않았으나, 복잡한 인프라(서버 13대, SDN 스위치, 스토리지 등) 구성 및 OpenShift 클러스터 배포, 운영 자동화를 통해 사업의 안정성과 효율성을 극대화하는 가치 제안이 가능합니다.
