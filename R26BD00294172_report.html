Red Hat 제안
불가능 요소
  • 신규 S/W 납품·구독 구매 항목 없음: 본 사업은 기존 운영 시스템의 유지관리 및 기능개선 용역 사업으로, 신규 Red Hat 상용 제품의 납품·도입·구독 구매 항목이 별도로 명시되어 있지 않음
  • 상용SW 유지관리 목록에 Red Hat 제품 없음: 26개 유지관리 대상 상용SW 목록(D'Amo, KONAN, OZ Report, Synap Viewer 등)에 RHEL, OpenShift, Ansible 등 Red Hat 상용 제품은 명시되어 있지 않음
  • 경쟁 WAS 제품 명시: 모니터링 대상 WAS로 Jeus(티맥스소프트) 10식, JBoss 4식이 함께 명시되어 있으며, WEB 서버로 WEBTOB 10식, Apache 4식이 명시됨. Tibero(국산 DBMS) 11식 운영 중
  • 중소기업자 간 제한경쟁 사업: 20억 미만 사업으로 대기업 참여 불가, Red Hat 코리아가 직접 입찰에 참여하기 어려운 구조이며 SI 파트너를 통한 간접 기회
  • 하도급 불허: 본 사업은 하도급을 불허하여 Red Hat 제품 공급을 위한 구조적 제약 존재
Red Hat 제안
가능 요소
  • JBoss 4식 모니터링 대상 명시 — 높음 판정 핵심 근거: 모니터링 대상 SW 목록에 "WAS — JBoss — 4식"이 명시되어 있음. 판정 규칙에 따라 RFP 내 "JBoss" 표기는 EAP 표기 유무나 공개SW 분류 여부와 무관하게 Red Hat 상용 제품(JBoss EAP)으로 간주하며, 운영·유지보수 대상으로 명시된 경우 높음으로 판정함
  • 기존 JBoss 운영 환경 기반 구독 갱신·업그레이드 기회: 현재 4식의 JBoss WAS가 농촌진흥청 정보서비스 운영에 활용 중이며, 구독 갱신, JBoss EAP 버전 업그레이드, 지원 확장 등 영업 기회 존재
  • Apache WEB 서버 4식 운영: 현행 WEB 서버로 Apache가 4식 운영 중이며, 이는 RHEL 기반 인프라와 연계 가능성이 있는 환경임
  • Linux 기반 인프라 환경: 기술적용계획표에 "Linux" 서버용 운영체제가 적용 기술로 명시되어 있어 RHEL 제안 여지 존재 (단, 특정 배포판 명시 없음)
  • 클라우드 전환 수요: 대표홈페이지 민간클라우드 이관(SOR-029) 및 OpenShift 기반 PaaS/컨테이너 플랫폼 제안 가능성 (기술적용계획표에 IaaS/PaaS/SaaS 클라우드 컴퓨팅 적용 명시)
  • RFP에 명시된 Red Hat(동의어 포함) 제품명·수량:
    • JBoss — 4식 (WAS, 모니터링 대상 SW 목록 명시)
