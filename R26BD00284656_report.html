사업 개요 및 목적
  • 한국고용노동교육원의 교육 플랫폼에 AI 기반 맞춤형 학습 추천 서비스를 신규 구축하고, 기존 교육·정보 플랫폼을 고도화하는 사업
  • 온프레미스 환경에 LLM(대형언어모델) 및 RAG(검색증강생성) 파이프라인을 구축하고, LLM 서버 및 GPU 서버를 신규 도입하여 AI Agent 플랫폼 기반 마련
  • 개인 프로필·교육이력 기반 맞춤형 강의 추천, 대화형 AI 검색, 규정/FAQ 자동응답 등 AI Agent 서비스(3종 이상) 구현
  • 교육 플랫폼(LMS) 및 정보 플랫폼 UI/UX 전면 개편, 통합검색 강화, 행정 업무 자동화(공모전 심사, 교육실적 통계 등) 추진
  • 사용자 중심의 디지털 교육 환경 구현 및 행정 업무 효율화가 핵심 목표

Red Hat 제안
불가능 요소
  • Red Hat 상용 제품 미지정: RFP 전문에 RHEL, OpenShift, Ansible, JBoss EAP 등 Red Hat 상용 제품명이 구매·납품 품목으로 전혀 명시되지 않음
  • S/W 납품 항목 부재: 별도 상용 S/W 라이선스 구매 항목 없이, AI 오픈소스 모델 활용 및 소프트웨어 개발 중심 사업으로 구성됨
  • 오픈소스 AI 모델 선호: FUN-007에서 "오픈소스 AI모델·라이브러리 사용 시 공식 배포처 확인 및 안정화 버전 사용"을 명시하여 오픈소스 기반 LLM 구축을 우선 고려함
  • 중소기업 제한 입찰: 20억 미만 사업으로 중소기업만 입찰 참가 가능 — Red Hat Korea가 직접 수주하기 어려운 구조 (단, Red Hat 제품 납품 기회는 존재)
  • 경쟁·대체 OS 미지정이나 상용 RH 제품도 부재: Ubuntu, Rocky Linux 등 경쟁 OS가 명시되지 않은 것은 긍정적이나, Red Hat 상용 제품 역시 명시 없음
Red Hat 제안
가능 요소
  • OS 미지정 온프레미스 서버 신규 도입 (RHEL 제안 기회): LLM 서버·RAG 서버 신규 도입 시 OS가 지정되지 않았으며, 기술적용계획표에 "Linux ○ (적용)" 표시 → RHEL(Red Hat Enterprise Linux) 제안 가능
  • AI/ML 워크로드 기반 인프라 → RHEL AI / OpenShift AI 제안 여지: GPU 서버 기반 온프레미스 LLM 인프라 구축은 Red Hat의 RHEL AI(Granite 모델 포함) 및 OpenShift AI 제안 포인트와 일치
  • 컨테이너 기반 확장 아키텍처 요구: ECR-002·ECR-003에서 "확장성", "단계별 배포 체계", "개발/테스트/운영 환경 분리"를 요구하며, AI Agent 플랫폼의 모듈화·플러그인 구조(QUR-003) 요구 → OpenShift Container Platform 제안 여지
  • RAG 파이프라인 및 Vector DB 구축: Vector DB 기반 문서 임베딩·검색 파이프라인은 OpenShift AI의 통합 MLOps 환경에서 구현 가능
  • 보안 및 접근통제 강화 요구: 온프레미스 LLM 인프라의 접근통제, 네트워크 분리 (SER-001) 요구 → RHEL 기반 보안 인프라, Ansible Automation Platform을 활용한 자동화·구성관리 제안 가능
  • API 관리 및 SSO/LDAP 연계 요구: 내부 업무시스템 연계 인터페이스, SSO/LDAP 인증 방식 지원(FUN-006) → Red Hat의 RH-SSO(Keycloak 상용) 또는 API 관리 솔루션 제안 여지
  • RFP 내 Red Hat 제품명 명시 현황: 없음 (Red Hat 상용 제품 미언급)
