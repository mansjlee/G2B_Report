Red Hat 제안
불가능 요소
  • S/W 신규 납품·구독 항목 없음: 본 사업은 기존 구축 시스템에 대한 순수 유지관리·운영 용역으로, RFP 및 과업지시서 어디에도 신규 S/W 도입·납품·구독 품목이 명시되어 있지 않음
  • WAS 경쟁 제품 사용 환경: 투입인력 요구사항(MHR-004)에 개발 및 운영환경으로 WebtoB, JEUS(TmaxSoft 제품) 활용 경험자를 명시하여 현재 시스템이 TmaxSoft WAS 기반으로 운영 중임을 시사 → JBoss EAP 제안 기회 없음
  • DBMS 경쟁 제품 사용 환경: 투입인력 요구사항(MHR-004)에 오라클(Oracle), TIBERO DBMS 활용 경험자를 명시 → Red Hat Data Grid 등 제안 여지 없음
  • 클라우드 인프라 기확정: K-CURE 시스템의 클라우드 인프라는 NHN 클라우드(판교센터)로 이미 확정 운영 중이며, OpenShift 등 Red Hat 플랫폼 제안 불가
  • RFP 내 Red Hat 제품명 전무: RFP 전문에 RHEL, OpenShift, Ansible, JBoss EAP 등 Red Hat 상용 제품명이 단 한 건도 명시되어 있지 않음
Red Hat 제안
가능 요소
  • Linux OS 운영 환경 확인: 인력 요구사항(MHR-004)에 "서버 관리(리눅스, 윈도우즈)" 명시 및 기술적용계획표에 "Linux ○(적용)" 표시 → 현재 시스템 일부에 Linux OS 운영 중임은 확인되나, 특정 배포판(RHEL 여부) 불명확
  • OS 정보 비공개로 RHEL 가능성 잠재: 부록1의 유지관리 대상 SW 목록에서 OS 모델명이 보안상 비공개 처리되어 있어, 기존 운영 OS가 RHEL일 가능성을 배제할 수 없음 → 단, 이것만으로 제안 기회로 보기 어려움 (유지관리 용역이므로 신규 라이선스 구매 미발생)
  • 리눅스 쉘 프로그래밍 기술 요구: 응용SW개발자에 리눅스 서버 프로그램 개발(쉘 프로그래밍) 경험 요구 → Red Hat Enterprise Linux 기술 전문가 투입 시 차별화 포인트로 활용 가능하나, 직접적 제품 판매 기회는 없음
  • 종합 평가: 위의 요소들은 간접적 기술 친화성에 불과하며, 신규 Red Hat 상용 제품 도입·납품·구독을 수반하는 영업 기회는 본 사업에 존재하지 않음. 차기 시스템 구축 사업 추진 시 레퍼런스 확보 관점에서만 관심 가능
