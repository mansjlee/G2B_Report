Red Hat 제안
불가능 요소
  • Red Hat 상용 제품명 미명시: RFP 전체에 걸쳐 RHEL, OpenShift, Ansible, JBoss EAP 등 Red Hat 상용 제품명이 품목으로 명시되지 않음
  • WAS 제품 확정: WAS/웹서버로 "JEUS, WebtoBe(티맥스소프트)"가 명시적으로 유지관리 대상으로 지정되어 있어 JBoss EAP 제안 여지가 없음. 단, "JBoss" 표기는 없고 JEUS(경쟁제품)로 명시됨
  • DBMS 확정: 추진체계도에 "DBMS(ORACLE)"이 상용S/W 유지관리 대상으로 명시되어 있어 별도 DBMS 도입 가능성 없음
  • 시스템 구성 비공개: 정보시스템 구성도는 행정안전부 고시에 따라 공개 금지(방문 열람만 가능)로, 현행 OS 종류·버전 등 세부 사항 파악 불가
  • 순수 운영·유지보수 용역: 신규 S/W 도입·납품·라이선스 구매가 사업 목적이 아니며, 기존 시스템의 운영 유지관리 및 인력 상주가 핵심임
  • 대기업·중견기업 입찰 불가: 20억 미만 사업으로 소프트웨어 진흥법에 따라 대기업 참여 제한 → Red Hat 직접 입찰 불가
  • 경쟁 제품 존재: Oracle DBMS, JEUS/WebtoBe(티맥스) 등 경쟁 제품이 유지관리 대상으로 이미 운영 중
Red Hat 제안
가능 요소
  • OS 미지정 (제안 여지): 유지관리 대상 서버의 OS 사양이 보안상 비공개 처리되어 있으며, 기술적용계획표의 "서버용 운영체제" 항목에 Linux가 포함되어 있어 RHEL 운영 가능성 존재 → 방문 열람 시 현행 OS 확인 필요
  • Linux 서버 운영 환경: 사업범위 내 "OS" 유지관리가 상용S/W 항목으로 명시되어 있고, AP서버 2대, DB서버 2대, Backup서버, Storage, PACS 서버 등 다수 서버 운영 중 → Linux 계열 OS 운영 가능성 있음
  • 공개SW·리눅스 환경 가능성: 기술적용계획표(붙임12)에서 운영체제 항목에 "Linux"가 포함되어 있어 RHEL 도입 혹은 기운영 가능성 있음. 단, 정확한 Red Hat 제품명은 문서에 없음
  • RFP 내 Red Hat 명시 제품·수량: 없음 (Red Hat / RHEL / OpenShift / Ansible / JBoss EAP 등 상용 제품명 전혀 미기재)
  • 영업 접근 전략: 현장 방문 열람(보안서약서 제출)을 통해 현행 시스템 OS 종류 확인 후, RHEL 기운영 여부 파악 → 차년도 구독 갱신 또는 SI 파트너 협력 기회 모색 가능
  • 파트너 협력 기회: 본 사업은 중소 SW사업자 대상이므로, Red Hat 파트너사(SI)를 통한 간접 제안(RHEL 구독 공급) 채널 활용 가능성 검토 필요
