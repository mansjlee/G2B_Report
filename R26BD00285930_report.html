Red Hat 제안
불가능 요소
  • S/W 신규 구매·납품 항목 없음: 본 사업은 기존 시스템에 대한 통합 유지관리 용역으로, 신규 S/W 구독·납품·조달이 포함되지 않음. 기술지원확약서 제출 대상 벤더 목록(IBM, HP, DELL, 젠시스, Hitachi, Avamar, NetWorker, VMware, Able, CUBRID, Oracle, 티맥스 등)에 Red Hat이 명시되지 않음
  • Rocky Linux 9.7 확정 사용: 행정포털시스템 서버 운영환경이 Rocky Linux 9.7로 확정되어 있음 (RHEL 대체 커뮤니티 OS). Rocky Linux는 RHEL 상용 제품이 아니므로 제안 근거 불가
  • 오픈소스 OS 전환 계획: 빅데이터 플랫폼 서버(WEB 내부, WAS, DB, 데이터 수집서버)를 현재의 RHEL/CentOS에서 "오픈소스 OS 기반으로 전환" 예정 — RHEL에서 이탈하는 방향이므로 RHEL 유지관리 기회 없음
  • VMware 가상화 유지관리 포함: VMware가 내부망 가상화 솔루션으로 유지관리 대상에 포함되어 있어 Red Hat Virtualization(RHEV)/OpenShift Virtualization 제안 여지 없음
  • Oracle DB 다수 운용: Oracle DB가 5개 용도로 운용 중이며 유지관리 대상에 포함되어 있어 Red Hat DBMS 계열 제안 여지 없음
Red Hat 제안
가능 요소
  • 현재 RHEL 운영 중 (빅데이터 플랫폼): 빅데이터 플랫폼 운영체제로 "Red Hat Enterprise Linux"가 현재 명시되어 있음. 다만, 신규 구매 품목이 아니며 "오픈소스 OS 전환" 계획으로 인해 실질적 제안 기회는 매우 제한적
  • CentOS EOL 대응 전환 컨설팅 기회: 빅데이터 플랫폼에서 CentOS를 운영 중이며 오픈소스 OS 전환을 준비하고 있어, RHEL 전환의 안정성·지원 우위를 어필할 수 있는 접점은 존재함. 단, Rocky Linux 9.7이 이미 행정포털에 채택된 점을 감안 시 설득력은 낮음
  • RFP에 명시된 Red Hat 상용 제품: 없음 (RHEL은 현재 운영 OS로 언급되나 구매 품목으로 명시되지 않음. OCP, Ansible, JBoss EAP, Satellite 등 기타 RH 상용 제품 언급 없음)
  • 종합 평가: Red Hat 제품의 직접적인 도입·증설 기회는 사실상 없으며, 오픈소스 OS 전환 방향이 RHEL이 아닌 Rocky Linux 등 무상 배포판으로 확인됨. 차기 사업 또는 OS 전환 전략 미팅을 통한 중장기 관계 구축 차원의 접근이 현실적
