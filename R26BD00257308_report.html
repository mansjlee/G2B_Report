사업 개요 및 목적
  • 한국동서발전(주)의 ERP-인사노무 시스템 UX 개선 사업으로, 노후화된 BSP(Business Server Page) 기반 E-HR 화면을 SAPUI5(SAP Fiori) 기반으로 현대화하는 것이 핵심 목표
  • CP(Compatibility Pack) 기반 ECC HR을 H4S4(SAP HR for S/4HANA)로 업그레이드하여 온프레미스 HR 운영 지속성 확보
  • S/4HANA 표준 UI 체계(Fiori Launchpad) 플랫폼 구축 및 출장·교육·근태 등 고사용 영역 UX 재구축
  • 전사 SSO(SAML2/BandiSSO) 연계를 통한 인증 일원화 및 보안 강화
  • 업무생산성 향상, 사용자 만족도 제고, 웹시스템 중복 개발 최소화

Red Hat 제안
불가능 요소
  • SAP 전용 애플리케이션 개발 사업: 핵심 과업이 SAP Fiori/SAPUI5 화면 개발, H4S4 업그레이드, OData·Fiori Launchpad 구성 등 SAP 스택 기반 용역으로 Red Hat 제품 공급 범위에 해당하지 않음
  • S/W 공급 미포함: 본 사업은 소프트웨어 개발 용역이며, Red Hat 제품(RHEL, OpenShift, Ansible 등) 구매·공급 요구사항 없음. 신규 HW 도입도 미포함
  • 경쟁/대체 기술 스택 명시: SAP S/4HANA, SAP Fiori/SAPUI5, H4S4, Fiori Launchpad, BandiSSO 등 SAP 생태계 및 발주사 기존 솔루션이 전면 지정. VMware, Ubuntu, Oracle Linux 등은 언급 없으나 SAP Basis/HANA 환경 전제
  • 인프라는 발주사 제공: HCI 기반 가상화 서버를 발주사가 제공하며, OS·플랫폼 선정·구매 권한이 제안사에 없음
  • 하도급·컨소시엄 불허: Red Hat이 SI 파트너로 간접 참여하기 위한 공동수급·하도급 경로 차단
  • 중소기업 전용 입찰: 대기업 참여 제한으로 Red Hat 직접 입찰 불가
  • 기술평가 항목: SAP UI/UX 전환·H4S4 업그레이드·SSO 연계 등 SAP SI 역량 중심 평가(기술 90점), 인프라·OS 플랫폼 평가 항목 없음
Red Hat 제안
가능 요소
  • 직접 제안 가능성 극히 낮음: RFP상 Red Hat 제품(RHEL, OpenShift, Ansible, JBoss 등) 적용·구매 요구사항이 전혀 명시되지 않아 직접적인 제품 제안 기회 없음
  • 간접 연계 가능성(매우 제한적): 운영환경이 HCI 가상화 서버 기반이나, OS·플랫폼은 발주사 기존 환경(SAP S/4HANA) 활용으로 RHEL 전환 제안 여지 없음
  • Ansible: SAP Basis/HANA 운영 자동화와 연계 가능하나, 본 사업 범위(애플리케이션 UX 개발)에 자동화·구성관리 요구사항 미포함
  • OpenShift: 컨테이너·Kubernetes 기반 구축 요구 없음. SAP Fiori는 Embedded/Hub 방식의 기존 SAP Gateway 환경 구성
  • 파트너 SI 경유 간접 기회: 입찰 참여 SAP SI 업체가 향후 동서발전 인프라 현대화·OS 표준화 사업에서 RHEL을 채택할 경우 간접적 레퍼런스 가능성은 있으나, 본 사업 자체와는 무관
  • 결론: 본 사업은 SAP 애플리케이션 개발·업그레이드 용역으로 Red Hat 직접 제안 대상 아님. 동서발전 SAP 인프라 레이어 별도 사업 모니터링 권고
