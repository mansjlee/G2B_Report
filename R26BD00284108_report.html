Red Hat 제안
불가능 요소
  • 경쟁 가상화 제품 확정: 가상화 인프라가 VMware(Broadcom) 1식으로 명시되어 있으며, 기존 시스템 유지관리 사업 특성상 플랫폼 교체 가능성이 없음
  • OS가 Windows로 고정: 서버 OS가 Windows Server(Microsoft) 총 8식(물리 3식 + 가상 5식)으로 명시되어 RHEL 제안 여지 없음
  • 미들웨어가 경쟁사 제품으로 고정: WEB은 WebtoB, WAS는 JEUS (TMAXSOFT) 로 명시되어 JBoss EAP 제안 불가
  • Red Hat 상용 제품 전무: RFP 및 과업지시서 어디에도 RHEL, OpenShift, Ansible, JBoss EAP 등 Red Hat 상용 제품명이 전혀 언급되지 않음
  • 순수 유지관리 용역: 신규 S/W 도입이 아닌 기존 운영 중인 시스템의 유지관리 용역으로, 기술 스택 변경이 사실상 불가능한 구조
  • Linux 계열 OS 미지정: 기술적용계획표에 Linux 항목이 체크리스트 형태로 있으나, 실제 적용 대상 OS는 Windows로만 확정되어 있음
Red Hat 제안
가능 요소
  • 해당 없음: RFP 전체를 검토한 결과, Red Hat 상용 제품(RHEL, OpenShift, Ansible, JBoss EAP 등)을 제안할 수 있는 항목이 존재하지 않음
  • 향후 고도화 사업 모니터링 권고: 2026~2029년까지 단계적으로 추진되는 고도화 사업(노후 장비 교체, 서버 방식 전환)이 병행 진행 중이므로, 해당 고도화 사업 RFP를 별도 모니터링하여 인프라 전환 시점에 RHEL/OpenShift 제안 기회를 탐색하는 것을 권장함
  • RFP 내 Red Hat(또는 동의어) 제품명·수량: 해당 없음 (0건)
