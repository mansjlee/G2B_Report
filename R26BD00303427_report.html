Red Hat 제안
불가능 요소
  • S/W 신규 구매·납품 항목 없음: 본 사업은 순수 통합 유지보수 용역으로, RFP 본문에 상용 S/W 신규 도입·납품·구독 갱신 품목이 명시되어 있지 않음
  • 경쟁 가상화 제품 명시: 운영 환경에 VMware vSphere가 가상화 플랫폼으로 명시되어 있어, Red Hat Virtualization(RHEV) 또는 OpenShift 가상화 제안 여지가 제한적
  • WAS 환경: 웹·WAS 환경이 WebtoB/JEUS(TmaxSoft 제품)로 명시되어 있어 JBoss EAP 제안 불가
  • DBMS 환경: Oracle, Tibero로 명시되어 있어 Red Hat 관련 DBMS 제안 불가
  • 정확한 Red Hat 상용 제품명 미기재: RFP 전반에 걸쳐 "RHEL", "OpenShift", "Ansible", "JBoss EAP" 등 정확한 Red Hat 상용 제품명이 품목으로 명시되어 있지 않음 (Linux(RHEL 등)이라는 일반 표현만 존재)
  • 별첨 리스트 미공개: 세부 유지보수 대상 리스트([별첨])는 보안서약서 작성 후 현장 열람만 가능하여 Red Hat 상용 제품 포함 여부 현재 확인 불가
Red Hat 제안
가능 요소
  • RHEL 운영 가능성: COR-01 운영 환경에 OS로 "Linux(RHEL 등)"이 명시되어 있어, 현재 운영 중인 Linux 서버에 RHEL이 사용되고 있을 가능성 존재 → 별첨 대상 리스트 확인 필요
  • 별첨 리스트 확인 기회: [별첨] 정보시스템 통합 유지보수 대상 리스트에 RHEL, Ansible 등 Red Hat 상용 제품이 포함되어 있을 가능성 → 보안서약서 작성 후 현장 열람을 통해 반드시 확인 권장
  • EOS/EOL 대응 기회: QUR-01에서 사업기간 중 지원종료 제품의 전환 방안 제시 의무화 → 기존 CentOS 등 커뮤니티 Linux 운영 중인 경우 RHEL 전환 제안 가능
  • 보안 자동화 제안 여지: 보안패치 적용, 취약점 조치, 구성 관리 등 반복 업무에 대해 Ansible Automation Platform 활용 제안 가능 (사업 수행 효율화 추가 제안)
  • RFP에 명시된 Red Hat 관련 제품명·수량: 없음 (Linux(RHEL 등)이라는 일반 표현만 존재하며, 별첨 리스트 미열람 상태)
  • 영업 액션: 현장 열람 신청(보안서약서 작성)을 통해 [별첨] 유지보수 대상 리스트 내 Red Hat 상용 제품 존재 여부를 최우선으로 확인할 것을 강력 권장
