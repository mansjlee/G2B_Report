Red Hat 제안
불가능 요소
  • S/W 납품 미포함: 본 사업은 기 도입된 의료정보시스템(OCS/EMR 등)에 대한 순수 위탁관리(운영·유지보수) 용역으로, 신규 상용 S/W 구매·납품·구독 항목이 전혀 없음
  • Red Hat 상용 제품명 미명시: RFP 전문 어디에도 RHEL, OpenShift, Ansible, JBoss EAP 등 Red Hat 상용 제품명이 기재되지 않음
  • 경쟁·대체 기술 환경 고정: 기존 운영 환경이 VB.NET(.NET Framework 4.7.2) 기반 Windows Server + Oracle Database 19c로 고정되어 있어 Red Hat 기술 스택 적용 여지가 거의 없음
  • Linux 미사용 환경: 기술적용계획표상 서버 OS는 Windows Server가 명시적으로 적용되고, Linux는 해당 없음(미적용)으로 표기됨
  • 클라우드 미적용: IaaS/PaaS/SaaS 모두 "원내 온프레미스 운영"으로 클라우드 전환 계획 없음 → OpenShift 등 컨테이너 플랫폼 제안 불가
  • JBoss/WAS 미언급: WAS 관련 제품(JBoss, WildFly 등) 도입·운영 대상이 RFP에 전혀 명시되지 않음
  • 중소기업 제한 입찰: 20억원 미만 사업으로 중소 소프트웨어사업자만 입찰 가능하여 Red Hat이 직접 입찰 불가 (단, 이 조건 단독으로 낮음 판정 근거는 아님)
