Red Hat 제안
불가능 요소
  • Red Hat 상용 제품명 전혀 미명시: RHEL, OpenShift, Ansible, JBoss EAP, AMQ 등 Red Hat 상용 제품이 RFP 어디에도 품목으로 기재되어 있지 않음
  • 하드웨어 인프라 제외 원칙: 서버·네트워크 등 인프라는 별도 기반시설공사에서 공급 예정으로 본 사업 범위에서 원칙적으로 제외 → OS/플랫폼 납품 기회 제한
  • 오픈소스 우선 정책: SFR-002에서 "특정 기술에 종속되지 않도록 오픈소스 기반의 SW를 적극적으로 활용"을 원칙으로 명시하여 상용 SW 도입 진입장벽 존재
  • 전자정부 표준프레임워크 적용 의무: Java/Spring 중심의 전자정부 표준프레임워크가 개발 기반으로 지정되어 JBoss EAP 등 Red Hat 미들웨어 포지셔닝 어려움
  • TOS/EOP 전문 솔루션 사업: 사업의 핵심이 항만 TOS 솔루션 구축으로, Red Hat이 직접 참여하기보다 SI/솔루션 업체를 통한 간접 참여 구조임
  • 경쟁 OS 명시 없음: Ubuntu, Rocky Linux, Oracle Linux 등 직접 경쟁 제품이 명시된 것은 아니나, Red Hat 상용 제품 도입 근거도 없음
Red Hat 제안
가능 요소
  • OS·플랫폼 미지정 → RHEL 제안 가능: TOS/EOP 서버 운영체제가 명시되지 않아 안정성·보안이 검증된 RHEL 제안 여지 있음. "검증된 상용 SW 적용 가능" 조항(SFR-002) 근거 활용 가능
  • 컨테이너 기반 아키텍처 → OpenShift 제안 가능: 확장성·이중화·Failover 요구사항, 마이크로서비스 아키텍처 적용 시 OpenShift Container Platform 포지셔닝 가능
  • AI/LLM 인프라 → RHEL AI, OpenShift AI 제안 가능: 에이전틱 AI 서비스, LLM(경량화 모델) 온프레미스 운영을 위한 GPU 서버 인프라에 RHEL AI / OpenShift AI 포지셔닝 가능. 언어모델 마스터 가중치 파일 백업·관리에도 적용 검토 가능
  • Kafka 명시 → AMQ Streams 제안 가능: AI 서비스 데이터 파이프라인 구성에 CDC·Kafka가 명시되어 있어 Red Hat AMQ Streams(Kafka 상용 지원) 제안 가능
  • 자동화 운영 → Ansible Automation Platform 제안 가능: 365일 무중단 운영 환경에서 다수 서버·장비의 구성관리 자동화 및 운영 효율화를 위한 Ansible Automation Platform 제안 여지 있음
  • RFP에 명시된 Red Hat 제품명·수량: 없음 (Red Hat 또는 동의어로 명시된 상용 제품 없음)
