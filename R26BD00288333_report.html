Red Hat 제안
불가능 요소
  • 경쟁 제품(가상화) 명시: VMware vSphere 12식, vCenter 2식이 현행 서버 가상화 플랫폼으로 명시적으로 도입·운영 중이며, 이번 사업에서도 유지보수 대상에 포함됨. Red Hat 가상화(RHEV/OpenShift Virtualization) 도입 여지 없음
  • 경쟁 제품(WAS·DB) 명시: 티맥스소프트 JEUS8(40식), WebtoB5(16식)가 WAS·Web Server로, Oracle DB·WebLogic, MS SQL이 DB로 운영 중. JBoss EAP 제안 여지 없음
  • Red Hat 상용 제품 전무: RFP 전체에 RHEL, OpenShift, Ansible, JBoss EAP 등 Red Hat 상용 제품명이 기존 SW 목록 및 신규 도입 계획에 전혀 없음
  • 기존 시스템 유지보수 계약: 신규 시스템 구축이 아닌 기존 인프라·SW 유지보수가 핵심이므로, 기존 비-Red Hat 스택을 유지하는 구조로 스택 전환 가능성 매우 낮음
  • 서버 OS 미지정이나 실질 전환 불가: RFP에 서버 OS가 명시되지 않았으나, 기존 TmaxSoft JEUS·WebtoB 기반 응용시스템 환경상 RHEL 전환 현실적 여지 없음
Red Hat 제안
가능 요소
  • 서버 OS 미명시 (극히 제한적): 서버 19대(DELL, CISCO, 유니와이드)의 OS가 RFP에 명시되지 않아 이론상 RHEL 운영 가능성이 존재하나, 기존 유지보수 계약 특성상 OS 교체 또는 신규 RHEL 도입은 사실상 어려움
  • 본사 이전(용인→오송) 기술 자문 기회: PSR-002에 "기관 본사 이전 관련 장비 구성, DR 구축 등 기술 자문"이 명시되어 있어, 이전 과정에서 Red Hat 솔루션(RHEL, Ansible 자동화 등) 제안 여지가 이론적으로 존재하나 계약 범위 내 기술 자문 수준에 그침
  • AI RAG 도입 환경: AI RAG 솔루션(DO Solution V2.0, 3식)이 신규 도입되어 운영 중이며, 향후 AI/ML 인프라 확장 시 OpenShift AI, RHEL AI 제안 가능성 있음 (본 계약 범위 밖)
  • RFP 내 Red Hat 제품명·수량: 없음 (0건)
