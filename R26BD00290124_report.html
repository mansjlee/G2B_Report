불가능 요소
  • [S/W 납품 미포함]: 본 사업은 신규 S/W 구매·납품이 아닌 기존 운영 중인 정보시스템 및 상용S/W에 대한 유지보수·운영 서비스 용역이 핵심이므로, Red Hat 제품의 신규 납품·구독 기회가 사실상 없음
  • [Red Hat 상용 제품 전혀 미명시]: RFP 전체에 RHEL, OpenShift, Ansible, JBoss/EAP, Satellite 등 Red Hat 상용 제품명이 품목으로 단 한 건도 명시되지 않음
  • [개방형OS로 TmaxOS(구름SD) 확정]: 개방형OS 플랫폼으로 TmaxOS Tmax 구름SD 100대가 이미 도입·운영 중이며 RHEL 기반이 아님. 확산 사업도 동일 플랫폼 유지 예정
  • [VDI는 틸론 Dstation 운영 중]: 인터넷망 VDI 솔루션으로 틸론 Dstation Server 9.0(50대)이 운영 중이며, OpenShift 기반 컨테이너·PaaS 도입 여지 없음
  • [MS KMS 운영 중]: Microsoft Key Management Service 2대 운영으로 Microsoft 생태계 존재
  • [국가정보자원관리원 위탁 인프라]: H/W, 시스템S/W 및 OS 유지보수는 국가정보자원관리원 소관으로, 통합 유지보수 사업자의 개입 범위가 응용프로그램(AP) 부문으로 제한됨
Red Hat 제안
가능 요소
  • [RFP 내 Red Hat 제품명·수량 명시: 없음] — RFP 전체를 검토한 결과, Red Hat(레드햇) 또는 동의어(RHEL, OpenShift, OCP, Ansible, JBoss, EAP, Satellite, Quay 등)에 해당하는 제품명이 품목으로 명시된 사례 없음
  • [클라우드 존 이관 지원 작업 — 간접 기회]: MPR-025에 국가정보자원관리원 클라우드 존(S2존) 이관 작업 지원이 명시되어 있으나, 이는 이관 기술지원 역할에 한정되며 플랫폼 OS/미들웨어 선정권은 국정원 소관으로 직접적인 RHEL·OpenShift 제안 기회는 낮음
  • [Linux 계열 기술 표준 언급]: 기술적용계획표 "플랫폼 및 기반구조" 항목에 서버용 운영체제로 Linux가 범용 표준으로 언급되어 있으나, 특정 배포판(RHEL 등) 지정은 없음
  • [향후 개방형OS 확산 연계 가능성]: 개방형OS 기반 온북 확산 사업(MPR-024) 과정에서 RHEL 계열 서버 인프라와의 연계 가능성이 이론적으로 존재하나, 현재 도입 플랫폼(TmaxOS)과의 직접 연관성은 낮음
  • 결론: Red Hat 상용 제품 도입이 확정·예정된 항목이 전혀 없고, 주요 플랫폼이 경쟁 제품(TmaxOS, 틸론)으로 확정되어 있어 실질적인 Red Hat 제안 가능 요소는 극히 제한적임
