Red Hat 제안
불가능 요소
  • 클라우드(5개 시스템) 영역은 Windows Server, JEUS, WebtoB, MS-SQL 기반으로 구성되어 있어 해당 시스템에 대한 Red Hat 제품 제안 불가
  • 본 사업은 신규 구축이 아닌 기존 시스템 유지관리 사업으로, 기존 SW 스택 변경 없이 현상 유지가 원칙 — Red Hat 신규 SW 도입 여지 제한적
  • 국가정보자원관리원(광주센터) 소재 하드웨어 및 시스템 SW는 본 사업 대상에서 명시적으로 제외되어 해당 영역 제안 불가
  • 비대면 서비스 시스템은 Windows Server 2025 기반으로 Red Hat OS 제안 불가
  • 상용SW 유지관리 비용은 제안사 부담 조건으로, 라이선스 갱신 영업 시 가격 경쟁력 확보 필요
Red Hat 제안
가능 요소
  • [RFP 명시 Red Hat 상용 제품 — 별첨1 상용SW 목록]
    • RHEL 8.9 (Red Hat Enterprise Linux 8.9): 식품이력추적관리시스템 13식 + 위해식품판매차단종합관제시스템 6식 = 총 19식
    • jBoss EAP 7.4.13 (Red Hat JBoss Enterprise Application Platform): 식품이력추적관리시스템 6식 + 위해식품판매차단종합관제시스템 2식 = 총 8식
  • MPR-06(소프트웨어 유지관리) 요구사항에 따라 제안사는 보유 상용SW의 라이선스 갱신 및 유지관리를 수행해야 하며, RHEL·JBoss EAP 구독 갱신이 사업 범위 내에 포함됨 — Red Hat 구독 갱신 영업 기회 직접 발생
  • 소프트웨어 구성현황에서 RHEL 8.9 기반으로 WEB(Apache), WAS(jBoss EAP), DB(Oracle) 서버 전체 운영 중 — RHEL 버전 업그레이드(RHEL 9.x 전환) 제안 가능
  • jBoss EAP 7.4 버전의 경우 Extended Life Cycle 지원 주기 고려 시 향후 EAP 8.x 버전 업그레이드 제안 기회 존재
  • 위해식품판매차단종합관제시스템 주요 서비스 상세에 "WAS서버(jBoss EAP7.4.13)"가 명시되어 있어 Red Hat의 기술 레퍼런스 및 TAM(Technical Account Management) 영업 연계 가능
  • Ansible Automation Platform을 활용한 OS 패치 자동화, 구성관리 자동화 등 추가 제안 여지 있음 (유지관리 효율화 관점)
