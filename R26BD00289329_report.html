사업 개요 및 목적
  • 국토교통부로부터 위탁받은 한국국토정보공사(LX)가 전국 230개 지자체 대상 국토이용정보 통합플랫폼(KLIP)을 안정적으로 운영·유지관리하는 사업
  • 클라우드 기반 KLIP 응용프로그램(AP) 및 전산자원(H/W, 상용 S/W)의 유지관리와 상시 모니터링을 통한 무중단 서비스 제공
  • 헬프데스크 운영, 사용자 교육, 도시계획현황 통계 생산·공표, 기술지원 등 종합적인 플랫폼 운영 지원
  • '26년 토지이용계획확인서 발급·연계기능 이관(KRAS→KLIP)에 따라 행안부 정보시스템 등급제 'A3(행정중요)' 기준으로 운영 요구
  • 월 4백만 건 이상 발급되는 토지이용계획확인서의 중단 없는 서비스 및 외부기관 연계 체계 유지가 핵심 목표

Red Hat 제안
불가능 요소
  • S/W 공급 여부: S/W 납품·구독 항목이 포함된 사업임 (제안 불가 사유 해당 없음)
  • WEB/WAS 오픈소스 지정: WEB Server(17식), WAS(27식)는 "오픈소스"로 명시되어 있어 JBoss EAP 등 Red Hat 상용 WAS 제안이 어려움
  • DBMS 경쟁 제품 확정: DBMS는 EDB(EnterpriseDB, PostgreSQL 기반) 7식으로 확정되어 있어 Red Hat 계열 DB 제안 여지 없음
  • Windows Server 존재: Windows Server 2식이 혼용되어 있으나 전체 OS 교체 제안은 불가
  • 기존 사업자 인수인계 구조: 운영 유지관리 사업 특성상 기존 S/W 구성을 그대로 유지하는 것이 원칙이며, 신규 제품으로의 대체 여지는 제한적
  • GIS 솔루션 지정: MapPrime(14식)이 GIS 솔루션으로 확정되어 있어 해당 영역 대체 불가

  • 라이선스 갱신 영업 기회: RHEL 1식 + RHOSP 26식 연간 라이선스 갱신이 매년 반복 발생하는 구조로 장기적 Revenue 확보 가능

  • OpenShift 전환 제안 가능성: 현 RHOSP 환경에서 컨테이너 기반 플랫폼(OpenShift Container Platform) 전환에 대한 로드맵 제안 가능 (중장기 전략)
