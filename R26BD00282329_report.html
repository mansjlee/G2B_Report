사업 개요 및 목적
  • 대청댐 및 금강유역을 대상으로 물환경 디지털트윈(DT) 시스템을 구축하여 실시간 모니터링, AI 기반 3차원 수질모의 및 예측 기능을 통합한 과학적 의사결정 지원체계 마련
  • 클라우드 기반 물환경 디지털트윈 플랫폼 구축, 3D GIS 기반 가상공간 구현, 통합 물환경 감시체계 구축이 핵심 목표
  • 녹조·탁수·수질오염사고 대응 시뮬레이터 및 AI 기반 예측·의사결정 지원 기능 구현 포함

  • 기존 경쟁 솔루션 사용 중: K-water 현 인프라에 VMware View 7(VDI), Oracle 12c(DB), Jeus 8.0/WebToB 4.1(WAS/WEB) 등 비 Red Hat 솔루션이 이미 구축·운영 중
  • 기존 플랫폼 호환성 준수 요건: K-water 디지털 플랫폼 및 기존 표준프레임워크 환경 준수 의무화 → 기존 인프라 교체 가능성 제한
  • Red Hat 상용 제품명 미명시: RHEL, OpenShift, Ansible, JBoss EAP 등 어떠한 Red Hat 상용 제품도 요구사항 내 품목으로 지정되지 않음
  • SW 개발 결과물 지식재산권 K-water 귀속: 개발 산출물 전체가 발주기관 소유 → 상용 Red Hat 구독형 제품 채택 동기 낮음

  • 클라우드 IaaS/PaaS/SaaS 적용 계획: 기술적용계획표에 IaaS·PaaS·SaaS 모두 적용 계획으로 표기 → OpenShift (PaaS 레이어) 제안 가능
  • API 기반 마이크로서비스 연계 구조 설계 요구: 시스템 간 연계를 API 기반으로 구성, 특정 플랫폼 종속 배제 원칙 → OpenShift + Ansible Automation Platform 적용 여지
