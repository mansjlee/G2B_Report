불가능 요소
  • 사업 성격이 자동분류 물류장비 설계·제작·설치·시운전 Turn-key 공사 중심이며, Red Hat 제품 단독 공급 구조가 아님
  • 이중화 S/W(1식), DB 암호화 S/W(1식)는 조달 디지털 쇼핑몰 직접구매(관급)로 지정되어 Red Hat 경쟁 제품군(RHDB/HSM 등) 직접 납품 경로 없음
  • 자동분류 설비제어 S/W, 통합관리·동시구현·SMC·PLC 응용프로그램은 제안사 자체 개발·국산화 대상으로 벤더 독점 S/W 공급 사업 아님
  • 서버·PC OS는 「업계표준 OS」「업계 최신 OS」로 규정하나 Windows 계열 백신·백업 SW 명시, VMware/Ubuntu/Oracle 등 경쟁 OS 직접 지정은 없으나 실질적으로 통합 SI·장비업체 주도
  • 보안장비·DB암호화·네트워크장비는 CC인증·보안기능확인서·국정원 검증필 제품 등 특정 인증 제품 준수 필수
  • 입찰참가자격: 소프트웨어사업(1468), 정보통신공사(0036), 전기공사(0037), 기계설비·가스공사(6202), 실내건축(0006) 등 — Red Hat 단독 공급 자격 해당 없음

가능 요소
  • 정보시스템 서버(SMC, 통합관리, DB, 이미지, HMI 등 다수) OS를 RHEL로 제안할 여지 — 요구사항이 「업계 최신 OS(서버급)」로 개방되어 있어 RHEL·RHEL Satellite 제안 가능(단, 통합 SI 파트너십 필요)
  • 운영·DB 서버 이중화(HA), 장애 자동전환·세션 유지 요구 — Red Hat High Availability Add-On 또는 RHOS(RHEL 기반)로 고가용성 아키텍처 제안 가능(단, 이중화 S/W는 쇼핑몰 관급 별도)
  • NTP 서버 OS Linux 명시 — RHEL 기반 NTP/Chrony 구성 제안 가능
  • 서버 팜 10G 백본·SAN·다수 Linux/Windows 혼합 환경 — Ansible Automation Platform으로 서버·네트워크 구성 자동화·운영 표준화 보조 제안 가능
  • 향후 통합관리·통계·연동 API 확장 시 컨테이너 기반 마이크로서비스 전환 시 OpenShift 제안 여지(현 RFP 명시 요구는 없음, 장기 로드맵 수준)
