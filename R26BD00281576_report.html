사업 개요 및 목적
  • 강원특별자치도 스마트강원 통합지원센터의 안정적 운영을 위해 H/W, S/W, N/W 등을 최적의 상태로 유지관리하는 사업
  • 스마트시티 통합플랫폼과 다양한 스마트서비스(CCTV 영상통합, 국민안전 5대 연계서비스, 강원특별자치도 특화서비스 등)를 최적의 환경에서 운용하도록 지원
  • 예방점검 및 신속한 장애 조치를 통해 24시간 중단 없는 시스템 운영 환경 구현이 핵심 목표

Red Hat 제안
불가능 요소
  • 신규 S/W 납품·구독 항목 없음: 본 사업은 기존 도입된 시스템에 대한 유지보수 용역으로, S/W 신규 구매·납품·구독 항목이 포함되지 않음
  • Red Hat 상용 제품명 전무: RFP 전체에 RHEL, OpenShift, Ansible, JBoss EAP 등 Red Hat 상용 제품명이 단 한 건도 명시되지 않음
  • 기존 시스템 유지관리 성격: 기 구축된 통합플랫폼, 영상중계SW, DBMS, 백신SW 등을 현행 그대로 유지·운영하는 것이 목적이며, 제품 교체 또는 신규 도입 여지가 없음
  • 중소기업 전용 사업: 총 사업비 20억 미만으로 대기업·중견기업 참여 제한 (소프트웨어 진흥법 제48조), Red Hat코리아 직접 참여 불가
  • OS 미지정이나 제안 여지 없음: "백신SW(Linux Server용) 5식"으로 Linux 서버 존재가 확인되나, 이는 기존 운영 중인 서버로 OS 교체·신규 도입 항목이 아님
Red Hat 제안
가능 요소
  • Linux 서버 운영 환경 확인: 유지보수 대상에 "백신SW(Linux Server용) 5식"이 포함되어 있어 Linux 기반 서버 운영 환경이 존재함을 간접적으로 확인 가능 → 차기 사업 또는 별도 인프라 갱신 시 RHEL 제안 근거로 활용 가능
  • OS 패치·업그레이드 지원 포함: MAR-002 요구사항에 "서버 보안 및 품질향상을 위하여 OS 업그레이드, 패치를 지원"이 명시되어 있어, OS 라이선스 갱신 필요 시 접점 발생 가능성 존재
  • RFP 내 Red Hat 제품명·수량: 해당 없음 (Red Hat 상용 제품명 전혀 명시되지 않음)
  • 전략적 활용: 현재 사업에서의 직접 제안은 어려우나, 유지보수 수행사를 통해 인프라 현황 파악 후 차기 증설·고도화 사업 대비 관계 구축 관점에서 간접적 관심 유지 필요
