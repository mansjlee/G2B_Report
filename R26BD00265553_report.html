Red Hat 제안
불가능 요소
  • 신규 S/W 납품·도입 없음: 본 사업은 기존 구축 완료된 국세상담시스템의 운영·유지관리 사업으로, 신규 S/W 구독·납품 항목이 없음. 라이선스 갱신도 기존 도입된 제품에 한정됨
  • Red Hat 상용 제품명 미명시: RFP 전체 및 유지관리 대상 SW 목록 어디에도 RHEL, OpenShift, Ansible, JBoss EAP 등 Red Hat 상용 제품명이 품목으로 명시되지 않음
  • 경쟁·비연관 DBMS 명시: DBMS 항목에 Microsoft SQL Server(MSSql) 12 Core, IBM DB2 16 Core가 명시되어 있어 해당 DBMS 환경과 Red Hat 제품의 직접 연관성이 낮음
  • 기존 시스템 고정 환경: 정보화 현황이 보안 사항으로 생략되어 있으며, 기존 사업자로부터의 인계인수 방식 운영이 원칙으로 기존 기술 스택 변경 여지 없음
  • 중소기업 대상 사업: 소프트웨어 진흥법 제48조에 따라 대기업·중견기업 입찰 참여 제한(20억 미만 사업)으로 Red Hat Korea의 직접 참여 불가
Red Hat 제안
가능 요소
  • OS 미지정: 유지관리 대상에 "모든 OS"가 포함된다고 명시되어 있으나 특정 OS 제품명이 기재되지 않았음. 이론적으로 기존 서버 OS가 RHEL일 가능성이 있으나, 정보화 현황이 보안상 비공개로 확인 불가
  • WAS 제품명 미특정: WAS(시스템SW) 32 Core가 유지관리 대상으로 포함되어 있으나, 구체적인 제품명이 명시되지 않아 JBoss EAP 가능성을 완전히 배제할 수 없음. 단, 이는 기존 설치 제품의 유지관리로 신규 제안 기회는 아님
  • RFP에 명시된 Red Hat 제품명·수량: 없음 — 본 RFP 전체에서 Red Hat(또는 동의어) 제품명이 품목으로 명시된 사례 없음
  • 종합 평가: 기존 시스템 유지관리 사업 특성상 Red Hat 신규 제안 기회는 사실상 없으며, 향후 차기 시스템 고도화·증설 사업 추진 시점에 관계 구축을 위한 SI 파트너사 접촉 채널로 활용하는 간접적 접근이 현실적 전략임
