Red Hat 제안
불가능 요소
  • 주요 솔루션 유지보수 목록에 RHEL 미포함: MPR-007의 솔루션 유지보수 대상 목록(엣지DB, UbiReport, e-PageSafer, ezPDF, 한컴오피스, Logger™, ZenithECM, Search Formula, VOICEYE)에 Red Hat 제품이 명시되지 않음 → 솔루션 유지보수 항목 내 직접 계약 기회는 제한적
  • 인프라 운영 주체는 국가정보자원관리원: H/W 및 OS 운영 관리 주체가 국가정보자원관리원(광주)으로, 본 사업자는 애플리케이션 레이어 유지관리가 주된 역할 → OS 라이선스 직접 구매 기회 제한 가능
  • DB서버는 AIX 운영: 등록관리 DB서버(IBM E880C / AIX 7.2) 사용 중 → Red Hat DB 스택 제안 어려움
  • WEB/WAS 주요 서버는 WebtoB/JEUS 사용: 기존 운영 미들웨어가 WebtoB, JEUS(티맥스) 기반으로 JBoss EAP 등 Red Hat 미들웨어 전환 여지 낮음
  • 중소기업 전용 사업: 상호출자제한기업 집단 소속 회사 입찰 제한, 대기업·중견기업 입찰 참여 불가 → Red Hat 직접 입찰 불가, SI파트너를 통한 간접 제안만 가능
  • 하도급 불허: 하도급을 허용하지 않는 조건으로 Red Hat이 공급 파트너로서 참여하는 구조 설정이 어려울 수 있음
Red Hat 제안
가능 요소
  • 테스트 서버 OS로 RHEL 8.9 명시 (MPR-008): 과업지시서 내 "테스트 서버 필수 설치 SW"로 RHEL 8.9가 명확히 지정되어 있어, 유지보수 사업자가 테스트 환경 구성을 위해 RHEL 라이선스를 확보해야 할 가능성이 있음 → Red Hat 상용 제품 도입 확실시
  • 기존 운영 서버 RHEL 7.8 사용 중: H/W 현황에 새올행정시스템 연계 EAI WAS서버(2대), 청소년활동통합관리 API WEB서버(2대), API WAS서버(2대) 등 총 6대가 RHEL 7.8로 운영 중 → 기존 스택 유지보수 및 RHEL 버전 업그레이드(7.8 → 8.x 또는 9.x) 기회 존재
  • RHEL 7.8 EOL 이슈: RHEL 7은 ELS(Extended Life Cycle Support) 단계 진입으로, 운영 중인 6개 서버의 RHEL 버전 업그레이드(RHEL 8/9) 필요성이 대두될 수 있어 갱신·증설 영업 기회 존재
  • RFP 내 RHEL 제품명 명시 수량 요약:
    • RHEL 7.8 – 운영 서버 6대 (EAI WAS 2, API WEB 2, API WAS 2) / 관리주체: 국가정보자원관리원
    • RHEL 8.9 – 테스트 서버 OS (1식, 한국청소년활동진흥원 IDC센터 설치)
  • Linux 기반 KOSE 서버군: 청소년활동통합관리 KOSE WEB서버(2대), KOSE WAS서버(2대), KOSE DB서버(2대) 총 6대가 OS 미상의 "Linux"로 기재 → RHEL 제안·전환 여지 있음
  • Ansible 자동화 제안 가능성: 다수 서버(20여 대) 운영 환경에서 패치 관리, 예방점검, 장애 대응 자동화를 위한 Ansible Automation Platform(AAP) 제안 가능
  • 파트너 영업 어프로치 필요: 중소기업 전용 사업이므로, 입찰에 참여하는 SI 파트너사와 협력하여 RHEL 라이선스 공급 및 테스트 서버 구성 지원 형태로 참여 전략 수립 권장
