Red Hat 제안
불가능 요소
  • S/W 납품 항목 없음: 본 사업은 순수 정보시스템 통합 유지보수 용역으로, Red Hat 상용 제품(RHEL, OpenShift, Ansible 등)의 구매·도입·납품 품목이 RFP 어디에도 명시되지 않음
  • VMware 가상화 환경 확정: 현재 운영 중인 상용 소프트웨어 목록에 VMware가 명시되어 있으며, 가상화시스템 유지관리(MAR-12) 대상이 VMware 기반 환경임. 기술자격 평가에도 VMware VCP 자격이 포함됨
  • 경쟁·대체 OS/플랫폼 환경: Microsoft(Windows Server 계열), Oracle DB, VMware 가상화 등 경쟁 스택이 현재 운영 환경으로 고착화됨
  • 유지보수 용역 성격: 기존 도입된 장비·소프트웨어를 유지보수하는 사업이므로, 새로운 Red Hat 제품 도입을 제안할 직접적 기회가 없음
  • Red Hat 상용 제품 전무: RFP 전체에 RHEL, OpenShift, Ansible, JBoss EAP 등 Red Hat 상용 제품이 도입·납품 품목으로 단 한 건도 명시되지 않음
Red Hat 제안
가능 요소
  • RHCSA·RHCE 자격 평가 항목 포함: 기술능력 정량평가 중 리눅스 영역에 RHCSA(Red Hat Certified System Administrator), RHCE(Red Hat Certified Engineer) 자격이 명시되어 있음 → 현재 환경에 Linux(RHEL 가능성)가 운영 중임을 시사하며, 인력 차별화 포인트로 활용 가능
  • 서버·인프라 Linux 운영 환경 가능성: HPE, DELL, Lenovo 등 서버 인프라 운영 환경에서 Linux 기반 서버가 존재할 가능성이 있으며, 향후 OS 교체·증설 시 RHEL 제안 여지 존재
  • 가상화 전환 기회: VMware가 현재 사용 중이나, Broadcom 인수 후 라이선스 정책 변화로 인해 향후 가상화 플랫폼 전환 검토 시 Red Hat OpenShift Virtualization 또는 RHEV 대안 제안 가능 (단, 이번 유지보수 사업 내에서는 직접 제안 불가)
  • RFP에 명시된 Red Hat 제품·수량: 없음 — RFP 및 과업지시서 전체에 Red Hat(레드햇) 상용 제품이 품목으로 명시된 사례 없음
  • 종합 평가: 이번 유지보수 사업 자체에서의 Red Hat 제품 영업 기회는 없으나, 본 사업 수행사와의 관계 형성을 통해 차기 인프라 구축·전환 사업 시 Red Hat 스택 제안을 위한 레퍼런스 확보 차원의 관계관리 대상으로는 적합함
