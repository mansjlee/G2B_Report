Red Hat 제안
가능 요소
  • RHEL: 기술적용계획표 플랫폼 분야에서 서버용 Linux 적용(O) 명시. AI 추론·Vector DB·Staging DB·GPU 서버 OS 레이어로 RHEL 제안 가능
  • OpenShift / OpenShift AI: SFR-003 AI 모델 학습·배포·모니터링 파이프라인, 롤백·스케줄러·벡터DB 재인덱싱, 폐쇄망 sLLM 운영·GPU 자원 통합 요구와 부합. 기술평가 「클라우드네이티브 기반 운영환경 구축 전문성」 가점 요소
  • Ansible Automation Platform: AI 파이프라인 자동·수동·배치 실행, RAG DB 업데이트 자동화, 모델 배포 이력·롤백, 운영 자동화 요구(SFR-003) 대응
  • 제안 전략: Red Hat을 AI 플랫폼·컨테이너 기반 추론 인프라·DevSecOps·자동화 레이어로 포지셔닝. sLLM/OCR/Vision은 파트너·ISV 스택과 공동 제안, RHEL/OpenShift 위에 AI MLOps 파이프라인 구성으로 차별화 가능
