한국국제협력단_콜롬비아 반부패 포털(PACO) 고도화를 통한 투명성 강화 사업 PMC 용역 - 분석 리포트

레드햇 제안 가능성 낮음
PMC용역 S/W미포함
사업 개요 및 목적
  • 한국국제협력단(KOICA)이 발주하는 콜롬비아 ODA 사업으로, 반부패 포털(PACO II) 고도화를 통한 국가 투명성·신뢰도 제고가 장기 목표이다.
  • 단기적으로 PACO II 고도화, 중기적으로 부패 신고 증가 및 부패 감소, 장기적으로 SDG 16.5(부패·뇌물 현저한 감소) 달성을 지향한다.
  • 본 입찰의 PMC(사업관리기관) 용역은 시스템 직접 개발이 아니라, BPR/ISP·중장기 로드맵 수립, PC(시스템개발·감리·대국민홍보) 선정·관리, 공무원·국민 역량강화, 사업 전반 PM/M&E를 수행하는 컨설팅·관리용역이다.
주요 정보
  • 사업 예산: 4,266,499,249원(약 $3,091,666, 환율 1$=1,380원, 2026년 기준, 부가세 등 제반비용 포함) / 문서 표기 $540만
  • 사업 기간: 계약체결일 ~ 2029.12.31.(4개년도 분할 집행: 1차 625,716,740원, 2차 1,165,215,668원, 3차 1,568,187,949원, 4차 907,378,892원)
  • 사업 범위: ① PACO II 중장기 로드맵·BPR/ISP ② PC1(시스템개발)·PC2(감리)·PC3(대국민홍보) RFP 작성·선정·품질관리 ③ 공무원 초청연수·청렴연수원 운영 ④ 대국민 인식제고 PC 관리 ⑤ 사업관리·성과관리(PDM, 기초선/중간선/종료선 조사)
  • 주요 일정: 2026 PMC 선정 → PC(시스템개발사) 선정 → 2026 4/4분기 현황진단·착수공유회 → 2027 1~2/4분기 BPR/ISP·로드맵 → 2027~2028 PACO II 설계·개발·이행·시범운영 → 2028~2029 안정화·종료평가
  • 대상지: 콜롬비아 보고타시(투명성사무국, 대통령행정실)
  • 입찰방식: 국제 일반경쟁, 기술(90%)·가격(10%) 종합평가, 협상에 의한 계약, 공동도급(분담이행, 5개사 이하, 최소지분 10%)
담당자 정보
  • 발주기관: 한국국제협력단(KOICA)
  • 담당 부서: 중미카리브팀
  • 담당자 이름·연락처·이메일: 제안요청서 본문에 개별 담당자 성명·전화·이메일 미기재(입찰공고문·KOICA 전자조달시스템 참조 필요)
  • 수원기관: 콜롬비아공화국 보고타시 투명성사무국(Secretaría de Transparencia, DAPRE 산하)
핵심 요구사항
  • 기술·비즈니스 요구사항: 56개 공공기관(투명성사무국·3대 감찰기관·19개 중앙부처·33개 주정부) 연계 반부패신고·이첩·결과통보 표준화, 3개 포털(대국민·투명성사무국·정부기관) 통합 플랫폼/DB, API/X-Road 기반 타기관(조달·기업·범죄·오픈데이터) 연계, 신고자 신원보호·통계·추적 DB, AI 분류체계 검토, 반응형 웹, MS Azure 클라우드 운영, PHP/Laravel → Java/Spring Boot 전환, ITIL/ITSM·BCP·개인정보보호, KOICA ISP 적정성 검토(약 3개월) 반영
  • 컨설팅 요구사항(CSR 20건): 법·제도·업무·Gap 분석, To-Be BA/AA/DA, 중장기 로드맵, 이행계획, 한국 청렴포털 벤치마킹, 변화관리
  • 프로젝트관리(PMR 14건): PM/FM/PAO 등 전문가 파견, 일정·품질·위험·의사소통·산출물 관리, PC사 산출물 검수·감리 조율
  • 통합발주 S/W 구매 명시: 본 PMC 제안요청서에 조달쇼핑몰 직접구매·통합발주 대상 상용 S/W 품목·수량 명시 없음(별지 제13호 서식만 제시, 기재 품목 없음). PACO II 시스템 개발·S/W는 별도 PC1(사업수행기관) RFP로 분리 발주 예정
Red Hat 제안
불가능 요소
  • S/W 공급 미포함: 본 사업은 PMC 컨설팅·사업관리 용역으로 Red Hat 제품 라이선스·납품 대상이 아님. 하도급 불허.
  • 경쟁 플랫폼 명시: 현행·목표 PACO II 운영환경이 Microsoft Azure 클라우드로 명시됨. 애플리케이션은 Java Spring Boot 프레임워크로 전환 지정(PHP/Laravel 대체).
  • 직접 S/W 조달 부재: RFP 본문·별지에 RHEL, OpenShift, Ansible 등 Red Hat 제품 구매 수량·규격 미명시.
  • 후속 PC 발주 분리: 실제 인프라·미들웨어·DB 등 S/W 선정은 PMC가 작성할 PC1 RFP에서 별도 결정되며, 본 입찰 범위 밖.
  • ODA·하도급 제약: KOICA ODA 표준계약, 하도급 금지, 산출물 IP KOICA 귀속으로 Red Hat이 직접 수주·납품 구조 부적합.
Red Hat 제안
가능 요소
  • BPR/ISP·로드맵 간접 영향: PMC가 수립하는 목표 정보시스템 정의서(CSR-013~017)에서 인프라·오픈소스 SW 제안 가능. CSR-017은 "검증된 오픈소스 SW" 제시 요구 → RHEL, OpenShift(ROSA on Azure), Ansible을 To-Be 아키텍처·중장기 로드맵 후보로 기술 가능.
  • PC1 RFP 작성 지원: PMC 과업에 PC1(시스템개발) 제안요청서 작성·입찰지원 포함 → Azure 호환·이기종 이전 대비 RHEL/OpenShift 컨테이너 플랫폼, Ansible 자동화·구성관리 요구사항 반영 여지.
  • 컨소시엄 파트너 참여: 공동도급(분담이행, 5개사 이하) 가능, ISP·클라우드·보안·DevOps 전문 SI와 컨소시엄 구성 시 Red Hat 기술 자문·아키텍처 제안 역할 수행 가능.
  • 기술 요구 정합: API 연계, 56기관 확산, 보안·가용성·BCP, ITIL/ITSM, 클라우드 이식성 요구는 OpenShift·Ansible Automation Platform·RHEL 강점과 부합.
  • 한국 청렴포털 벤치마킹: CSR-009~010에서 선진사례·Gap 분석 시 Red Hat 기반 공공 클라우드·컨테이너 레퍼런스 제시 가능(직접 납품 아닌 컨설팅 제안).
