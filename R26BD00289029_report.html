Red Hat 제안
불가능 요소
  • S/W 납품 미포함: 본 사업은 기존 시스템에 대한 순수 유지관리·운영 용역으로, 신규 소프트웨어 구독·납품 항목이 전혀 없음. Red Hat 제품의 신규 도입·증설 기회가 구조적으로 없음
  • 경쟁·대체 제품 운영 중: 현재 운영 중인 기술 스택이 TmaxSoft의 JEUS(WAS), WebtoB(Web서버), Oracle DBMS, Jennifer(APM) 등 비Red Hat 상용 제품으로 구성되어 있음. SLA 표준안 예시에 Rocky Linux(커뮤니티 OS)가 언급되어 있어 RHEL 전환 가능성이 낮음
  • Red Hat 상용 제품 전혀 미언급: RFP 전문 및 과업지시서 어디에도 RHEL, OpenShift, Ansible, JBoss EAP 등 Red Hat 상용 제품명이 구매·도입 품목으로 명시되지 않음
  • 응용 환경 비Red Hat: 응용프로그램 개발자 요건에 "JEUS 환경에서 개발 경력자"가 명시되어 있어 JBoss EAP 제안 기반이 없으며, 기존 애플리케이션이 JEUS 기반으로 운영 중임
  • 중소기업 한정 입찰: 20억 미만 사업으로 대기업·중견기업 참여 불가 (Red Hat 직접 입찰 구조 아님, SI사 통해 납품 기회도 매우 제한적)
Red Hat 제안
가능 요소
  • Linux 운영 환경 존재: 상주 인력 요건에 "국제공인 UNIX 계열 자격증", "리눅스마스터 1급" 자격이 명시되어 있어 Linux 기반 서버 운영 환경이 확인됨. 다만 구체적인 OS 정보는 보안 이유로 비공개이며 열람 시 확인 필요
  • OS 미확정 가능성(잠재적 확인 필요): 기관 자원 현황(서버 OS 포함)이 보안서약서 제출 후 열람 가능한 비공개 정보로 분류되어 있어, 실제 RHEL이 운영 중일 가능성을 배제할 수 없으나 현재 RFP 내 근거 없음
  • RFP에 명시된 Red Hat(또는 동의어) 제품명·수량: 없음 — RFP 전문에 Red Hat, RHEL, OpenShift, Ansible, JBoss EAP, OCP 등 Red Hat 상용 제품명이 구매 품목으로 전혀 명시되지 않음
  • 향후 영업 접점: 유지관리 사업자 선정 후, 차기 인프라 교체·증설 사업 발주 시 RHEL 또는 OpenShift 제안 접점 마련 가능 (단, 본 사업 자체에서는 제안 기회 없음)
