불가능 요소
  • [S/W 납품 포함 여부]: 시스템SW(갱신형) 및 상용SW 유지관리 항목이 존재하므로 순수 용역 사업은 아님. 단, 신규 납품·도입이 아닌 기존 SW 구독 갱신·운영 지원 형태이므로 경쟁 제품 교체 가능성은 낮음
  • [경쟁 제품 명시 여부]: RFP 본문 공식 조달 품목에 Ubuntu, VMware, Oracle Linux 등 경쟁 OS는 명시되지 않음. 단, 월간운영보고서 서식(붙임6) 예시에 Rocky Linux(커뮤니티 배포판)가 기재되어 있어 현 운영 환경이 Rocky Linux 기반일 가능성 시사 → 상용 RHEL 품목 명시 없음
  • [기타 제안 제약]: WEB/WAS 엔진 15식, DBMS는 인프라사업자 담당으로 제안사 범위 외 / 기존 유지관리 사업 특성상 현 기술 스택 전면 교체가 어려움 / 상용SW 대부분이 보안·GIS·모니터링 특화 제품으로 Red Hat 포트폴리오와 직접 경쟁 관계 아님
  • [Red Hat 제품 명시 없음]: RFP 전문 어디에도 RHEL, OpenShift, Ansible, JBoss EAP 등 Red Hat 상용 제품명이 품목으로 명시되지 않음
Red Hat 제안
가능 요소
  • [운영체제 미지정 — RHEL 제안 여지]: 제안사 담당 시스템SW로 운영체제(물리서버) 24식, 운영체제(VM) 18식이 포함되어 있으며, 특정 벤더 OS가 명시되지 않음 → RHEL 구독 제안 가능 (대규모 42식 규모)
  • [클라우드 인프라 환경 — RHEL/OpenShift 적합]: KLID 지역클라우드 센터 기반 운영 환경(클라우드 솔루션 24식)으로 RHEL for Cloud·OpenShift 기반 컨테이너 플랫폼 전환 컨설팅 제안 가능
  • [AI 서비스 구축 — OpenShift AI / RHEL AI 제안]: MPR-23에서 주소정보 AI Agent 구축, AI 인터페이스(MCP, Tool·Skill Registry) 구축을 명시 → Red Hat OpenShift AI, RHEL AI 기반 솔루션 제안 여지
  • [자동화 필요성 — Ansible Automation Platform 제안]: 서버접근제어(노드) 150식, 백신 102식, 보안 패치 관리, DB 암호화 등 다수 SW의 일괄 관리·갱신 업무 → Ansible Automation Platform(AAP)으로 자동화 제안 가능
  • [Rocky Linux → RHEL 전환 영업 기회]: 월간보고서 템플릿이 Rocky Linux 예시를 포함하고 있어 현 환경이 Rocky Linux 기반일 가능성 → Red Hat의 RHEL 마이그레이션 지원 프로그램 및 RHEL 전환 제안 가능
  • [RFP 내 Red Hat 상용 제품명 명시]: 없음 (커뮤니티 제품인 Rocky Linux만 템플릿 예시에 등장)
