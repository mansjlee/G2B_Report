불가능 요소
  • Ubuntu OS 명시 확정: 개발환경 운영체제로 Ubuntu 24.04.3 LTS가 명시되어 있으며, 제약 요구사항(COR-002)에서도 "Ubuntu, Python 및 웹 기반 구성요소의 호환성 검토"를 요구하여 Ubuntu 사용이 확정됨 → RHEL 제안 여지 없음
  • Red Hat 상용 제품 전무: RFP 전체에 RHEL, OpenShift, Ansible, JBoss EAP 등 Red Hat 상용 제품명이 단 한 건도 언급되지 않음
  • 통합발주 상용 S/W 없음: 별도로 납품·구독이 필요한 상용 OS, 미들웨어, 플랫폼 S/W 품목이 존재하지 않으며, 전체 소프트웨어 스택이 오픈소스 기반으로 구성
  • 순수 SW 개발 용역 성격: HW(서버 1대) 도입 외에는 웹 IDE 개발 용역이 핵심으로, 상용 SW 납품·구독 항목이 없음
  • 경쟁 OS 확정: Ubuntu는 Red Hat의 경쟁 Linux 배포판으로, 해당 사업의 OS 선택에서 Red Hat 계열 진입 가능성 차단
