응용SW 고도화 용역
사업 개요 및 목적
  • 한국교육학술정보원(KERIS)이 운영하는 교원 대상 온라인 지식 공유·연수 플랫폼 '디지털 지식샘터'(educator.edunet.net)의 기능 고도화 사업이다.
  • 현장 교원의 AI 활용 수업 역량 강화를 위해 사용자 중심 서비스 환경을 개선하고, 동영상 스트리밍·학습관리(LMS) 기능을 구현한다.
  • 이용자 증가에 대비해 데이터 관리 구조를 개선·고도화하여 확장성과 안정적 서비스 운영 기반을 마련하는 것이 핵심 목표이다.

Red Hat 제안
불가능 요소
  • S/W 공급 미포함: 본 사업은 시스템 기능 고도화 및 응용SW 수정·보완 용역(SI)이며, Red Hat 제품을 직접 조달·공급하는 항목이 RFP에 존재하지 않는다.
  • 인프라 운영 주체 분리: 클라우드 인프라 운영·관리는 별도 '클라우드 임차 서비스 사업 수행사' 및 '유지관리 사업 수행사'가 담당하므로, 본 사업 범위에 OS·플랫폼 라이선스 조달 여지가 제한적이다.
  • 전자정부 표준프레임워크 의무: COR-001에 따라 전자정부 표준프레임워크 적용이 필수이며, Java 기반 공공 SI 표준 스택이 우선 적용된다.
  • 경쟁 제품 직접 명시는 없으나: VMware, Contrabass, Oracle/Rocky Linux 등 특정 제품 지정은 없으나, 기술적용계획표에서 Linux·Windows Server·UNIX 등 OS를 선택 가능 항목으로만 기재하고 Red Hat/RHEL을 특정하지 않는다.
  • 중소기업 전용 입찰: 20억원 미만 사업으로 중소 SW사업자만 입찰 참가 가능(대기업·중견기업 제한)하여 Red Hat 직접 입찰·계약 구조와 부합하지 않는다.
  • 직접생산증명서 요건: 정보시스템개발서비스(8111159901) 직접생산증명서 보유 중소기업만 참가 가능하다.
Red Hat 제안
가능 요소
  • 간접 채널(파트너 SI) 협력: 낙찰 SI사의 제안서에 클라우드 기반 아키텍처·확장성·오토스케일링(QUR-004) 구현 시 RHEL 또는 OpenShift를 런타임·컨테이너 플랫폼으로 제안 가능하다.
  • Linux/RHEL 적용 여지: 기술적용계획표 플랫form 분야에 Linux·POSIX 서버 OS가 선택 가능 항목으로 명시되어 있어, 클라우드 사업자와 협의 시 RHEL 기반 WAS/DB 서버 구성을 파트너가 제안할 수 있다.
  • OpenShift/Kubernetes: PER-002의 인프라 증·감설·탄력적 운영, FUR-004/FUR-005의 모듈화·확장성 재구조화 요구와 부합하는 컨테이너 플랫폼 제안 포인트가 있다.
  • Ansible: QUR-004의 운영·관리·배포 자동화, 오토스케aling, 장애대응 요구에 Ansible Automation Platform 연계 제안이 가능하다.
  • 성능·가용성: 동시접속 3만명, 24시간 무중단, CDN 연계, 부하테스트 요구(PER-001~004)는 Red Hat 오픈소스 인프라 스택의 강점 영역과 기술적으로 정합성이 있다.
  • 제한적 직접 영업: Red Hat은 본 입찰의 직접 계약 주체가 될 수 없으며, KERIS·클라우드 사업자·낙찰 SI사를 대상으로 한 파트너 생태계·기술 지원·사전 영업 접근이 현실적 경로이다.
