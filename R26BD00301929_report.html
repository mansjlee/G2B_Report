Red Hat 제안
불가능 요소
  • RFP 전체에 Red Hat 상용 제품명(RHEL, OpenShift, JBoss EAP, Ansible 등) 미명시: 유지보수 대상 S/W 목록 어디에도 Red Hat 상용 제품이 명시되지 않아 직접적인 도입 확정 근거 없음
  • 경쟁 가상화 제품 명시: 소프트웨어 부문에 VMware vSphere(브로드컴) 5식이 유지보수 대상으로 명시되어 있어, 가상화 영역에서 Red Hat Virtualization(RHEV) 또는 OpenShift 대체 제안이 어려운 상황
  • DBMS·WAS 부문 Oracle 독점 구성: Oracle DB EE/SE, WebLogic, Web Tier로 구성되어 JBoss EAP 또는 기타 Red Hat 미들웨어 제안 여지가 현실적으로 낮음
  • 순수 유지보수 용역 성격: 신규 S/W 도입·납품·구독 항목이 없는 기존 시스템 유지보수 용역이며, 중소 소프트웨어사업자만 참여 가능하여 Red Hat 직접 입찰 불가
  • 대기업 참여 제한: 연차별 평균 사업금액 887,345,000원(20억 미만) 구간으로 대기업 소프트웨어사업자 입찰 참여 불가
