Red Hat 제안
불가능 요소
  • [직접 납품·도입 구조 아님]: 본 사업은 신규 구축이 아닌 유지관리 용역 사업으로, Red Hat이 직접 입찰 주체가 되기는 어려운 구조임. 사업자는 중소기업만 참여 가능(20억 미만, 대기업 제한)
  • [별도 Red Hat SW 신규 구매 품목 없음]: 상용SW 통합발주 목록에 Red Hat 제품이 신규 도입 품목으로 별도 명시되어 있지 않으며, 기존 운영 SW 유지관리 중심의 사업임
  • [DB는 경쟁 제품 운영 중]: 데이터베이스로 TIBERO 6(티베로)를 사용 중이며, Oracle/PostgreSQL 등 Red Hat 생태계와 무관한 DB가 운영됨
  • [경쟁 경량 솔루션 혼재]: WebSquare5, KSignAccess 등 국내 상용 SW 위주로 구성되어 있어 Red Hat 미들웨어 추가 제안 여지 제한적
Red Hat 제안
가능 요소
  • [RHEL 8.9 명시 운영 중 — 핵심 기회]: 현재 시스템 운영 목록에 RedHat RHEL 8.9가 웹서버 OS로 명시되어 있음. 유지관리 범위에 상용SW 패치·업데이트·버전업그레이드 지원이 포함되어 있어 RHEL 구독 갱신 및 향후 RHEL 9.x 업그레이드 제안 가능
  • [JBCS Apache(JBoss Core Services) 운영 중]: 웹어플리케이션 서버로 JBCS Apache(JBoss Core Services — Red Hat 상용 제품)가 운영 중임. 유지관리 범위 내 JBCS 구독·기술지원 갱신이 포함될 수 있음
  • [RFP 명시 Red Hat 제품명 및 수량 정리]:
    • RedHat RHEL 8.9 — 웹서버 OS (수량: 시스템 구성상 명시, 별도 수량 미기재)
    • JBCS Apache — 웹어플리케이션 서버 (수량: 시스템 구성상 명시, 별도 수량 미기재)
  • [RHEL EOSL 대응 기회]: MPR-013에서 EOSL(End Of Service Life) 제품 관리 방안 요구. RHEL 8은 2029년 5월 EOSL 예정이므로 RHEL 9 업그레이드 전환 제안 가능
  • [Ansible 자동화 제안 여지]: 정기점검, 보안패치 적용, 형상관리 등 반복 운영 자동화 관련 요구사항(MPR-003, MPR-008 등)에 대해 Ansible Automation Platform 도입 제안 여지 있음
  • [Java 기반 시스템 — JBoss EAP 전환 가능성]: 사용언어가 JAVA로 현재 JBCS(Apache HTTP 서버 레이어) 사용 중이나, 향후 고도화 시 JBoss EAP(Enterprise Application Platform) 제안 여지 존재
