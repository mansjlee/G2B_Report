불가능 요소
  • [SW 구매 항목 비해당] 통합발주 상용 SW 구매 품목으로 명시된 것은 Tmax OpenSQL, ArcGIS, Ksign Secure DB이며, Red Hat 상용 제품은 구매 목록에 전혀 포함되지 않음
  • [비Red Hat 상용 SW 확정] GIS 플랫폼으로 ArcGIS(Esri) 사용이 확정되어 있고, DB 보안으로 Ksign Secure DB, 데이터 처리 도구로 Tmax OpenSQL이 명시 — 해당 영역에서 Red Hat 제품 진입 어려움
  • [JBOSS 상용 라이선스 불명] 오픈소스 현황 목록에 "JBOSS WAS 서버"로만 기재되어 있어 상용 JBoss EAP인지 커뮤니티 WildFly인지 불명확. 상용 SW 유지관리 목록에는 미포함으로, 현재 무상 버전 사용 가능성 높음
  • [H/W·S/W 구성 비공개] 현행 서버·OS 구성이 보안상 공개되지 않아, 운영 중인 OS가 RHEL인지 여부 확인 불가. 방문 열람을 통해서만 파악 가능
  • [순수 유지관리 용역 중심] 사업의 주된 성격은 S/W 신규 도입이 아닌 기존 시스템 운영·유지관리 및 기능개선 용역으로, 대규모 신규 SW 구매 수요는 제한적
  • [20억원 미만 소규모 사업] 총 예산 9억 3,300만원 규모로 중소 SW사업자만 입찰 가능 — 대형 플랫폼 교체 제안보다 기존 체계 유지 성향 강함
Red Hat 제안
가능 요소
  • [JBoss WAS → JBoss EAP 전환 제안] 현재 시스템에 "JBOSS WAS 서버"가 오픈소스로 운영 중. 사업 범위에 "시스템 운영에 필요한 상용/공개 SW 운영 및 관리"가 포함되어 있어, 커뮤니티 버전 사용 중인 경우 Red Hat JBoss EAP 상용 전환을 제안 가능. Spring Framework 기반 Java 애플리케이션과의 호환성 강점 활용 가능
  • [OS 미공개 환경 — RHEL 제안 가능] H/W·S/W 구성이 보안상 비공개이며, Linux 계열 서버 운영이 명시됨(기술적용계획표에 Linux 항목 적용). 운영 OS가 CentOS/Rocky 등 커뮤니티 버전인 경우 RHEL 전환 제안 기회 존재
  • [컨테이너·자동화 인프라 확장 여지] 시스템 복잡도 증가(오픈플랫폼·스마트플랫폼 통합)와 서버 이관(MPR-025) 요구사항이 있어, OpenShift 컨테이너 플랫폼 또는 Ansible 자동화 솔루션 제안 가능. PaaS/IaaS/SaaS 적용 항목이 기술적용계획표에 포함되어 있어 클라우드/컨테이너 전환 논의 가능
  • [PostgreSQL + PostGIS 운영 환경] PostgreSQL 기반 공간 DB를 운영 중으로, Red Hat의 오픈소스 지원 역량(RHEL 위에서의 PostgreSQL 공식 지원) 및 Data Grid 등 인메모리 캐시 솔루션 제안 여지 있음
  • [RFP 내 Red Hat 제품명 명시 여부] RFP 원문 및 구매 목록에 Red Hat, RHEL, OpenShift, Ansible, JBoss EAP 등 상용 제품명이 직접 명시된 항목은 없음. "JBOSS WAS 서버"가 오픈소스 현황에 기재된 것이 유일한 연관 항목
