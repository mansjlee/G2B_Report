사업 개요 및 목적
  • 충청남도 보령시가 지속적인 인구 감소에 선제적으로 대응하기 위해 데이터 수집·저장·분석·개방이 가능한 데이터 실증 플랫폼을 구축하는 사업
  • 인구, 주거, 교통, 편의시설 등 정주 여건 관련 특화데이터를 AI가 즉시 활용할 수 있도록 정제·표준화(AI-Ready Data)하여 데이터 기반 행정 혁신 도모
  • 생성형 AI 언어모델(LLM) 및 RAG 기반 AI 에이전트를 활용한 공직자 행정지원 및 맞춤형 대민서비스 구현
  • 데이터 분석 결과 시각화 대시보드 및 대국민 웹서비스 구축을 통한 데이터 기반 행정 활성화 및 공무원 업무 효율성 향상

불가능 요소
  • S/W 납품 분리 발주: RFP 명시 — "사업추진에 필요한 H/W, 상용SW는 본 용역과 분리하여 별도 발주" → 본 용역(R26BD00288619)은 순수 SW 개발·구축 용역으로, SI 사업자가 직접 SW를 납품·공급하는 구조가 아님. Red Hat 제품도 용역사업자 통한 통합발주 대상이 아님.
  • 직접구매 방식: 붙임 1의 상용SW 9개 품목은 모두 발주기관(보령시)이 조달쇼핑몰을 통해 직접 구매하는 방식 — 제안사가 SW 선정권을 갖지 않으며, 발주기관 자체 선택으로 진행됨.
  • Red Hat 상용 제품명 미명시: RFP 전문, 과업지시서, 직접구매 목록 어디에도 RHEL, OpenShift, Ansible, JBoss EAP, Satellite 등 Red Hat 상용 제품명이 품목으로 명시되지 않음.
  • 경쟁 제품 명시 없음: Ubuntu, Rocky Linux, VMware 등 명시적 경쟁 제품도 지정되지 않아 배제 조건은 없으나, Red Hat 특정 지명도 없음.
  • 참여 제한: 사업금액 20억원 미만 기준으로 대기업·중견기업 참여 불가 → Red Hat Korea 직접 입찰 불가 구조.
Red Hat 제안
가능 요소
  • [클라우드 PaaS 1식 직접구매 → OpenShift Container Platform 제안 기회]: 붙임 1에 "클라우드 PaaS 1식" 직접구매 품목 존재. 발주기관(보령시)이 조달쇼핑몰에서 선택 시 OpenShift Container Platform(OCP) 제안 가능. 3차년도 멀티테넌시 구조 요구사항과 OpenShift의 멀티테넌트 Namespace 기능이 강점 일치.
  • [SSO 1식 직접구매 → Red Hat SSO(Keycloak) 제안 기회]: 붙임 1에 "SSO 1식" 직접구매 품목 존재. 기존 SSO 연동 기반 RBAC(역할 기반 접근제어) 구현 요구사항(SFR-001)과 Red Hat SSO(RH-SSO, Keycloak 기반 상용) 강점 일치.
  • [Linux OS 미지정 → RHEL 제안여지]: 기술적용계획표(붙임 2) 운영체제 항목에 "Linux" 적용 표시(○). 특정 배포판 미지정으로 RHEL 제안 가능. 국정원 보안성 검토 대응 요구(SER-001, SER-010) 및 보안취약점 점검 요건에서 RHEL의 보안 인증(CC인증 등) 강점 활용 가능.
  • [AI 플랫폼 Private/On-Premise 운영 → OpenShift AI 제안여지]: SFR-006에서 "Public Cloud, Private Cloud, On-Premise 환경에서 운영 가능한 구조" 요구 및 2차년도 "고성능 AI서버 기반 내부 LLM 추론환경 구축" 요구 → OpenShift AI(RHEL AI) 기반 프라이빗 LLM 추론 환경 제안 가능.
  • [자동화 요구 → Ansible Automation Platform 제안여지]: 클라우드 인프라 구축, 데이터 수집 스케줄링, 보안 하드닝, 형상관리 요구사항 다수 → AAP(Ansible Automation Platform) 기반 인프라 자동화 및 보안 정책 관리 제안 가능.
  • [AI 솔루션 12식 직접구매 항목]: 구체적 제품명 미명시 상태로, Red Hat 파트너사를 통한 AI 솔루션 포함 가능성 존재. 단, 직접구매 방식이므로 Red Hat 측 사전 영업 활동(발주기관 접촉, 제품 등록) 필요.
  • ※ RFP 내 Red Hat 제품명·수량 명시: 없음 (직접구매 목록 포함 전문 어디에도 Red Hat 상용 제품 미명시)
