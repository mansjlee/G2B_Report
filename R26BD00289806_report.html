사업 개요 및 목적
  • 청원인이 편리하게 청원을 신청하고, 담당자가 효율적으로 청원을 처리할 수 있도록 청원24(온라인 청원시스템)의 안정적인 운영을 목적으로 함
  • 청원24 헬프데스크 운영을 통해 사용자 상시 지원 및 장애 예방을 위한 시스템 관리 수행
  • 청원 신청 안내 기능 개선, 기관별 처리현황 관리, 조직개편·인사이동 관련 관리 기능 개선, DB Link→CDC 방식 전환 등 주요 기능 개선 포함
  • 운영 대상: 청원24 웹사이트(cheongwon.go.kr), 모바일 앱(Android/iOS), 청원24 업무처리시스템(gov.cheongwon.go.kr)

Red Hat 제안
불가능 요소
  • S/W 신규 공급·납품 항목 없음: 본 사업은 기존 도입된 상용 SW의 운영·유지관리를 목적으로 하며, 새로운 SW 라이선스 구매·납품 항목이 RFP에 전혀 명시되지 않음
  • Red Hat 상용 제품명 전무: RHEL, OpenShift, Ansible, JBoss EAP, Satellite 등 Red Hat 상용 제품명이 RFP 어디에도 명시되지 않음
  • HW·시스템SW 관리 주체 제외: OS, WEB서버, WAS, DBMS 등 시스템 소프트웨어의 운영·유지관리는 국가정보자원관리원이 담당하며, 본 사업 수행사는 응용·상용 SW 영역만 담당 → Red Hat OS(RHEL) 제안 진입 불가
  • 경쟁 OS 확인 불가, 그러나 제안 여지 없음: 월간보고서 서식 예시(붙임6)에 Rocky Linux가 언급되나 이는 템플릿 예시에 불과하며 실제 도입 요구사항이 아님. 어떠한 방식으로도 Red Hat 제품 신규 납품 기회 없음
  • 소규모 중소기업 한정 사업: 20억 미만으로 중소기업자만 입찰 가능, Red Hat Korea의 직접 입찰 불가
Red Hat 제안
가능 요소
  • 직접적 제안 가능 요소 없음: RFP 내 Red Hat 또는 동의어(RHEL, OCP, Ansible, JBoss, EAP 등) 제품명이 전혀 명시되지 않아 직접적인 영업 기회 식별 불가
  • 간접적 기술 연관성(매우 낮음):
    • CDC 전환(SFR-06) 관련: Debezium(Red Hat 커뮤니티 프로젝트) 기술이 CDC 솔루션으로 활용될 수 있으나, 해당 CDC 솔루션은 국가정보자원관리원에서 적용 예정이며 본 사업 범위 외
    • 전자정부 표준 프레임워크(Java/JEE 기반) 운영 환경에서 JBoss EAP 또는 RHEL 제안 여지는 이론적으로 존재하나, 기존 인프라 교체 권한이 사업자에게 없어 실질적 기회 없음
  • RFP 내 Red Hat(또는 동의어) 제품명·수량: 없음 (0건)
