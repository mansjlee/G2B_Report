Red Hat 제안
불가능 요소
  • S/W 신규 납품·구독 항목 없음: 본 사업은 기존 정보시스템의 운영·유지관리 위탁용역으로, 상용 S/W 신규 구매·도입·납품 품목이 RFP에 전혀 명시되어 있지 않음
  • Red Hat 상용 제품명 미기재: RFP 전반에 걸쳐 RHEL, OpenShift, Ansible, JBoss EAP, Satellite 등 Red Hat 상용 제품명이 단 한 건도 명시되어 있지 않음. 현행 시스템 구성·유지관리 대상 S/W 목록 어디에도 없음
  • 운영체제 환경 불명확: 서버 운영체제가 "Linux" 일반 항목으로만 기술되었을 뿐, 특정 배포판 명시 없음. 기존 운영 환경에 Red Hat 제품이 있다는 증거 없음
  • 웹서버로 Nginx 명시: 기술지원 SW 목록에 "HyperFrame_Nginx 4Core/8Core"가 웹서버로 명시되어 있어 별도 Red Hat 미들웨어 도입 여지 낮음
  • 경쟁 제품 직접 명시는 없으나: Ubuntu, Rocky Linux, Oracle Linux 등 경쟁 OS 명시도 없으나, Red Hat 계열 제품 역시 전혀 없음
  • 대기업·중견기업 참여 제한: 연평균 사업금액 20억원 미만 사업으로, Red Hat Korea가 직접 입찰 참여하더라도 자격 제한에 해당될 수 있음
  • 순수 용역·운영 사업: S/W 납품 없는 운영·유지관리 용역이고, RFP 어디에도 Red Hat 관련 일반 문구(레드햇, Linux 운영 환경 등)조차 명시되지 않음
Red Hat 제안
가능 요소
  • RFP 내 Red Hat 상용 제품명 명시 없음: RHEL, OpenShift, Ansible, JBoss EAP, Satellite 등 어떠한 Red Hat 상용 제품도 품목으로 기재되어 있지 않음
  • Linux 서버 환경 운영: 기술적용계획표에 "Linux" 서버용 운영체제가 적용 항목으로 포함되어 있어, 현행 시스템이 Linux 기반일 가능성이 있으나 배포판 미확인
  • 간접 접근 가능성 (매우 낮음): 사업 수행 업체(SI)가 내부 운영 환경에서 Linux 계열 OS를 활용할 경우 RHEL 도입 협의 여지가 이론적으로 존재하나, 본 RFP에서는 이를 뒷받침할 근거가 없음
  • 결론: 본 사업은 Red Hat 제품 제안 기회가 사실상 없는 순수 IT 운영·유지관리 용역임. RFP 내 Red Hat 상용 제품 도입·납품·유지보수 대상 명시가 전혀 없으므로, Red Hat 영업 우선순위로 분류하기 어려움
