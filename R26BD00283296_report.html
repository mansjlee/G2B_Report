Red Hat 제안
불가능 요소
  • Red Hat 상용 제품명 미명시: RFP 본문 및 시스템 자원 현황 어디에도 RHEL, OpenShift, JBoss EAP, Ansible 등 Red Hat 상용 제품명이 구체적으로 기재되어 있지 않음
  • SW 품목 비공개: 유상유지보수 대상 상용 SW 목록은 직접 방문 열람만 허용되어, RFP 단계에서 기존 도입 제품 확인 불가
  • 운영·유지관리 중심 용역 사업: 신규 SW 도입·구매가 주목적이 아닌 기존 시스템 유지보수·운영 용역 사업으로, 상용 SW 직접 납품 기회가 제한적
  • 중소기업 제한 입찰: 사업금액 20억 미만 사업으로 대기업·중견기업 참여 불가, Red Hat 코리아 직접 입찰 불가 (SI 파트너사를 통한 간접 참여만 가능)
  • 경쟁 제품 명시 없음: 특정 경쟁 OS(Ubuntu, Rocky, Oracle Linux 등)가 명시된 것은 아니나, 기존 도입 제품이 확인되지 않아 경쟁 여부 불명확
Red Hat 제안
가능 요소
  • 리눅스 운영체제 7식 (브랜드 미지정): 시스템 자원 현황에 "리눅스 운영체제 7식"이 명시되어 있으나 배포판이 특정되지 않음 → RHEL 제안 또는 RHEL로의 전환 가능성 존재
  • WAS 8식 (브랜드 미지정): WAS(Web Application Server) 8식이 존재하나 제품명 미공개 → JBoss EAP 제안 가능성
  • SSO 6식 (브랜드 미지정): SSO 솔루션 6식 운영 중, 제품명 미공개 → RH-SSO(Keycloak) 제안 가능성
  • 서버보안 33식 및 다수 보안 솔루션: 대규모 서버 보안 운영 환경 → Ansible Automation Platform(AAP)을 활용한 보안 패치·설정 자동화 제안 가능
  • HCI 클라우드 환경: HCI(하이퍼컨버지드 인프라) 기반 운영 환경으로 컨테이너·플랫폼 현대화 맥락에서 OpenShift 전환 제안 여지
  • 클러스터&볼륨관리 6식: 클러스터 관리 솔루션 6식 운영 중 → OpenShift / ACM 제안 가능성
  • 대규모 분산 환경: WEB 4식·WAS 8식·DBMS 4식 등 다층 아키텍처, Ansible 기반 운영 자동화 제안 시 효율 향상 논거 가능
  • RFP에 명시된 Red Hat(또는 동의어) 제품명·수량: 없음 (기존 유상유지보수 대상 SW 목록은 방문 열람 필요, 현 RFP 본문에는 Red Hat 상용 제품명 미기재)
