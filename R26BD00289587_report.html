  • ISO20000 국제표준인증 유지 및 ITSM 체계 기반 지속적 품질 고도화

Red Hat 제안
불가능 요소
  • S/W 납품·구독 항목 미포함: 본 사업은 기존 시스템의 운영·유지관리·기능개발 서비스 용역이며, 신규 상용 SW 구매·납품 항목이 RFP에 별도 명시되어 있지 않음. Red Hat 제품 도입을 위한 예산 항목 없음
  • Red Hat 상용 제품명 전무: RHEL, OpenShift, Ansible, JBoss EAP 등 Red Hat 상용 제품명이 RFP 전체에 걸쳐 단 한 건도 언급되지 않음
  • 기존 DBMS·WAS 플랫폼 고정: Oracle DBMS, Tibero DBMS, WebLogic WAS, JEUS WAS, Apache/WebtoB 웹서버 등 특정 타사 제품이 이미 운영 중이며, 유지관리 대상으로 명시됨. JBoss EAP 제안 여지 없음
  • 경쟁·대체 제품 직접 명시는 없으나 기존 스택 고정: VMware, Ubuntu 등 경쟁 제품이 직접 명시되지는 않았으나, 현재 운영 중인 1,304식의 기존 SW 스택 유지가 과업의 핵심이므로 새로운 플랫폼 전환 제안이 사실상 불가
  • 컨테이너·Kubernetes·자동화 요구 없음: OpenShift, Ansible Automation Platform 등의 적용 근거가 될 컨테이너화·K8s·IT 자동화 관련 신규 요구사항이 RFP에 전혀 명시되지 않음
Red Hat 제안
가능 요소
  • [제한적] Linux 서버 운영 환경: 기존 서버 구성에 Linux 서버가 포함되어 있으며(H/W 장비 현황에 "LINUX 등" 명시), Linux 운영 전문 인력(리눅스 관련 자격증 보유, 경력 3년 이상 2인 이상) 투입을 요구하고 있어 RHEL 운영 경험이 간접적 어필 포인트가 될 수 있음
  • [미확정] U2L(Unix to Linux) 전환 지원 가능성: OPR-001, MAR-002에서 "대상시스템 U2L, P2V 적용계획이 있을 경우 발주기관과 협의하여 지원"하도록 명시. 유닉스 서버에서 Linux로 전환 시 RHEL을 제안할 여지가 있으나, 현재 계획이 확정된 것은 아니며 별도 장비구매 사업으로 진행될 가능성이 높음
  • [미확정] 가상화 환경(VM) 운영: 논리서버(VM) 운영이 포함되어 있으나, 구체적인 하이퍼바이저 플랫폼은 공개 미열람 대상(보안서약서 후 열람 가능)으로 RHEV/KVM 기반 여부 확인 불가
  • RFP에 명시된 Red Hat(또는 동의어) 제품명·수량: 없음 — Red Hat, RHEL, OpenShift, Ansible, JBoss, EAP, OCP 등 어떠한 Red Hat 상용 제품명도 RFP 본문에 등장하지 않음
  • 영업 접근 권고사항: 현재 RFP에서는 직접 제안 기회가 없으므로, 사업 수주 예정 SI 업체(운영사업자)를 대상으로 Linux 서버 운영 환경의 RHEL 전환 또는 차기년도 U2L 사업 연계 가능성을 파이프라인으로 관리하는 간접 영업 전략이 현실적임
