Red Hat 제안
불가능 요소
  • Rocky Linux OS 확정: RFP 서비스 환경 표에서 서버 운영체제가 "HP-UX, CentOS → Rocky Linux"로 명시되어 있으며, "Rocky Linux 서버는 발주기관이 준비하여 제공"한다고 명확히 기재되어 있음. OS 전환 대상이 이미 Rocky Linux로 확정되어 RHEL 제안 여지 없음
  • 경쟁 OS 명시: Rocky Linux는 RHEL의 대체·경쟁 오픈소스 OS로, 발주기관이 직접 준비·제공하는 기반 인프라로 확정됨
  • Red Hat 상용 제품 전무: RFP 전문에 RHEL, OpenShift, Ansible, JBoss EAP, Satellite 등 Red Hat 상용 제품명이 단 한 건도 언급되지 않음
  • WEB/WAS 스택 타사 확정: 웹서버(WebtoB)·WAS(JEUS) 모두 티맥스소프트 제품으로 현행 유지 또는 업그레이드가 명시되어 JBoss EAP 제안 불가
  • DBMS 타사 확정: Oracle DBMS를 현행 유지로 명시, Red Hat 관련 데이터 플랫폼 제안 여지 없음
  • 솔루션 8종 모두 타사 제품으로 고정: 유지관리 대상 솔루션 8종이 티맥스소프트, 아이브릭스, 한컴위드, 사이냅소프트 등 타사 제품으로 전부 확정되어 대체 제안 불가
  • 중소기업 전용 사업: 대기업 참여 불가, Red Hat Korea는 입찰 직접 참여 불가 구조
  • S/W 구매 최소화: 구매 S/W가 CMS 1식에 불과하며, 해당 제품 역시 Red Hat 포트폴리오와 무관한 웹 콘텐츠관리 솔루션임
Red Hat 제안
가능 요소
  • RFP 내 Red Hat 상용 제품명 없음: RHEL, OpenShift, Ansible, JBoss EAP 등 Red Hat 상용 제품이 구매 품목이나 기술 요구사항으로 일절 명시되지 않아 직접적인 제안 기회는 없음
  • Rocky Linux → RHEL 전환 간접 여지(매우 제한적): 현행 CentOS에서 Rocky Linux로 전환하는 환경이므로, 향후 안정성·보안지원 측면에서 RHEL 도입의 간접적 영업 대화 소재가 될 수 있으나, 본 사업 내에서는 이미 Rocky Linux로 확정되어 실질적 제안 기회 없음
  • AI/자동화 플랫폼 간접 연관성: 마포브레인(AI) 연계 및 데이터 표준화, API 개발 등의 요구사항이 있으나, OpenShift AI, Ansible Automation Platform 등의 Red Hat 솔루션과 기술적 연관성은 있어도 본 사업 내 도입 품목으로 명시되지 않아 활용 불가
  • 결론: 본 RFP에서 Red Hat 상용 제품 제안 가능 요소 없음. Rocky Linux OS 확정으로 인해 낮음 판정
