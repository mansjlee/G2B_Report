Red Hat 제안
불가능 요소
  • 신규 S/W 납품·구독 항목 미존재: 본 사업은 순수 유지관리 용역 사업으로, RFP 내 통합발주 방식의 Red Hat 상용 제품 구매·도입 품목이 명시되지 않음
  • H/W·상용S/W 분리발주: 상용 S/W는 분리발주 추진으로 명시되어 있어, 본 용역 계약에서 Red Hat 상용 라이선스 직접 납품 기회가 제한됨
  • 기존 확정 S/W 스택: GNSS 핵심 시스템은 Trimble PIVOT, Geo++ GNSmart2 등 전문 GNSS 상용 솔루션으로 이미 고정되어 있어 Red Hat 제품 대체 불가
  • 오픈소스 CI/CD 도구 명시: ArgoCD, Flux, Jenkins, Gitea, GitLab, Tekton 등 커뮤니티 오픈소스 도구가 이미 도입·운영 중으로 명시되어 Red Hat 상용 버전 전환 여지가 낮음
  • 대기업 참여 불가: 사업금액 20억 미만 중소기업 한정 사업으로, Red Hat이 직접 참여하거나 대형 파트너를 통한 납품 채널 활용이 제한적
  • 경쟁·대체 제품 직접 명시는 없으나, 기존 운영 인프라가 특정 상용 제품(Trimble, Geo++)으로 고정되어 있어 Red Hat 플랫폼으로의 전환 가능성 낮음
Red Hat 제안
가능 요소
  • 쿠버네티스 기반 클라우드 네이티브 환경 운영 요구: RFP PMR-003에서 쿠버네티스 클러스터 유지보수, 컨테이너화, MSA, CI/CD, DevOps 전문 인력 명시 → OpenShift Container Platform 제안 여지 존재 (기존 vanilla K8s 환경을 OpenShift로 전환하거나 OpenShift 기반 운영 제안 가능)
  • OS 플랫폼 미지정: 서버 운영체제로 Linux 계열 적용 가능성이 있으며(기술적용계획표에 Linux 항목 적용 표시), RHEL 제안 여지가 있음
  • Keycloak OAuth 연계 유지관리 명시: PMR-003에서 "Keycloak Oauth 연계 유지관리"가 명시되어 있어, 커뮤니티 Keycloak을 Red Hat 상용 RH-SSO(Keycloak) 또는 Red Hat Build of Keycloak로 전환 제안 가능
  • 자동화·DevOps 수요: 배포 자동화(Rolling Update, Blue/Green, Canary), GitOps, CI/CD 파이프라인 관리 요구 → Ansible Automation Platform(AAP)을 활용한 운영 자동화 제안 가능
  • 모니터링 통합 수요: Prometheus, Grafana, ELK/EFK 등 다수 모니터링 도구 운영 요구 → OpenShift 내장 모니터링·로깅 스택으로 통합 제안 가능
  • RFP 내 Red Hat(또는 동의어) 제품명 명시 현황: Keycloak 1건(PMR-003, 수량 미지정) — 상용 제품 여부는 불명확하나 제안 연결 고리로 활용 가능
