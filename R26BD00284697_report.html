사업 개요 및 목적
  • 부산대학교 교육혁신본부가 글로컬대학30 과제(「9-3-2. AI 에듀테크 기반 교육혁신 선도 및 확산」)의 일환으로, 업무 완결형 AI 에이전트 플랫폼을 구축하는 사업
  • 기존 범용 질의응답 챗봇으로는 완결되지 않는 교육과정 상담·교원 성과 등록 등 본부 특화 업무를 AI 에이전트(도구 실행→결과 관찰→다음 단계 판단 반복) 방식으로 처리하는 실행기반 확보
  • 교육혁신본부 홈페이지를 신규 구축하고, 모든 페이지에 에이전트를 사이드 패널로 이식하여 "정보 탐색→질의→신청·조회 실행"이 한 화면에서 완결되는 환경 마련
  • 5개 서비스 과제(성과관리통계, 교수성과입력보조, 학생교육과정상담보조, 언어모델검증 테스트 에이전트, 홈페이지 안내) 시범 구현(MVP)을 통해 학내 AI 활용 확산의 선례 확보

Red Hat 제안
불가능 요소
  • Red Hat 상용 제품 미명시: RFP 전체에 RHEL, OpenShift, Ansible, JBoss EAP 등 Red Hat 상용 제품명이 품목으로 직접 명시되어 있지 않음 → 기존 도입 확정 품목 없음
  • 주요 구매 품목이 AI 에이전트 플랫폼 S/W: 핵심 라이선스 품목은 제안사가 선택하는 AI 에이전트 실행기반 플랫폼이며, Red Hat 제품군이 직접 경쟁 포지션에 있지 않음 (Red Hat은 인프라 OS/플랫폼 레이어 제안이 가능하나, 메인 플랫폼 S/W 자체는 아님)
  • 경쟁 제품 명시는 없음: Ubuntu, VMware, Oracle Linux, Rocky Linux 등 경쟁 제품이 명시되어 있지 않아 특정 경쟁사 확정으로 인한 불가 요소는 없음
  • LLM 자체 도입 제외: 언어모델(LLM) 자체의 도입·구매는 본 사업 범위 외 → Red Hat AI 관련 제품(OpenShift AI, RHEL AI 등)의 직접 도입 기회 제한
  • 중소기업 참여 제한 사업: 20억 미만 사업으로 대기업·중견기업 입찰 불가 → Red Hat이 직접 입찰 참여 불가, SI파트너를 통한 간접 공급 필요
Red Hat 제안
가능 요소
  • OS 미지정 → RHEL 제안 가능: 웹 서버(HW 납품) 및 플랫폼 구동 서버의 운영체제가 미지정 상태. 기술적용계획표에 Linux 계열이 포함되어 있어 RHEL 제안 여지 존재
  • 컨테이너 기반 구조 권장 → OpenShift/Podman 제안 가능: WEB-012에서 "향후 서버 증설 또는 다른 운영 환경으로 이전할 수 있도록 컨테이너 기반 등 이식 가능한 구조로 구성"을 명시 → OpenShift Container Platform 또는 Podman 기반 컨테이너 환경 제안 가능
  • 온프레미스 + 클라우드 확장 구조 → OpenShift Hybrid Cloud 제안 가능: SFR-009에서 "온프레미스 환경에서 동작하여야 하며, 향후 클라우드 환경으로의 확장이 가능하여야 함" 명시 → OpenShift의 하이브리드 클라우드 강점 어필 가능
  • 표준 도구 연동 규격(MCP 등) 기반 자동화 → Ansible Automation Platform 제안 가능: SIR-005에서 학내 시스템 연동을 위한 도구 추가·확장 체계 요구 → AAP를 활용한 자동화 및 연동 도구 관리 제안 여지
  • 다중 사용자·확장성 요구 → RHEL 서브스크립션 기반 인프라 제안: 향후 전교 구성원 약 30,000명(동시 사용자 6,000명) 규모 확장을 전제로 설계 요구 → 엔터프라이즈급 RHEL 기반 인프라 제안으로 신뢰성 및 지원 체계 어필 가능
  • RFP 내 Red Hat(동의어 포함) 상용 제품 직접 명시 없음: 현재 RFP에 Red Hat 상용 제품이 품목으로 명시된 사례 없음
  • 파트너 협력 전략 필요: 중소기업 제한 사업이므로 Red Hat 파트너사(시스템통합 중소업체)와 협력하여 RHEL/OpenShift를 인프라 레이어로 제안하는 전략 수립 권장
