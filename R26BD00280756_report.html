가능 요소
  • [RFP 명시 Red Hat 상용 제품 - 높음 판정 근거]
    • JBoss EAP 7.4 (Red Hat 상용 WAS): 한국어능력시험 접수_시행WAS#1~8 총 8대 (각 16코어, 64GB RAM) — 현재 운영 중인 핵심 트랜잭션 처리 서버
    • JBCS 2.4.62 (JBoss Core Services, Red Hat 상용 Web 서버): 한국어능력시험 접수_시행WEB#1~4 총 4대 (각 8코어, 16GB RAM) — 현재 운영 중
  • [버전 업그레이드 제안 기회] JBoss EAP 7.4는 Extended Life Support(ELS) 단계에 진입 예정. EAP 8.x 또는 OpenShift 기반 JBoss EAP 마이그레이션 제안 가능
  • [RHEL 전환 제안 여지] Oracle Linux 8 Enterprise 사용 서버 8대 이상 존재. Oracle Linux→RHEL 전환 제안 가능 (동일 RHEL 기반 바이너리 호환)
  • [WildFly→JBoss EAP 상용화 기회] 커뮤니티 WildFly 26.1.2 운영 서버(WAS 다수)에 대해 엔터프라이즈 지원이 포함된 JBoss EAP 상용 구독으로 전환 제안 가능
  • [클라우드/컨테이너 기회] IBT 시험 시행기간 자원 급증 대응을 위해 민간 클라우드 사용 중. OpenShift 기반 컨테이너 플랫폼 도입으로 탄력적 자원 운영 및 비용 최적화 제안 가능
  • [Ansible 자동화 기회] 복잡한 다수 서버(30대 이상) 운영 환경에서 Ansible Automation Platform 기반 패치 적용·구성 자동화·장애 대응 자동화 제안 가능
