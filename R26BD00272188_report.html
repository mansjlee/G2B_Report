사업 개요 및 목적
  • 국립환경과학원이 발주하는 차세대 환경영향평가 정보지원시스템(EIASS)의 클라우드 인프라 구축 및 운영을 위한 MSP(Managed Service Provider) 선정 사업
  • 기존 온프레미스 환경에서 국가정보자원관리원 대구센터 민관협력형(PPP) 클라우드로 전환하여, 클라우드 네이티브 기반(쿠버네티스 컨테이너)의 안정적 서비스 운영 환경 제공
  • AI·빅데이터 분석 등 최신 디지털 기술 접목을 통한 환경영향평가 시스템 고도화 및 유관기관(국토부, 기상청, 산림청, 지자체 등)과의 데이터 연계 기반 마련
  • 국가 보안 규격(국정원 가이드라인) 완벽 준수 및 고신뢰성 PPP 클라우드 인프라 확보를 통한 환경영향평가 행정업무 연속성 보장

    • 인터넷망(대국민서비스)과 행정망(내부업무) 이원화 구성, 망간 자료전송 시스템 경유 안전 동기화 아키텍처

    • 데이터 백업(일일 전체·증분), 물리적 분리 2중 소산, DR 구성 방안 제시
    • Block Storage·Object Storage·NAS 등 용도별 스토리지 서비스
  • [구매 명시 S/W - SW 구성 현황 (통합발주 포함)]
    • 본 사업은 MSP 운영 사업으로, S/W는 별도 상용SW 직접구매(3자단가)로 조달 예정이며, 통합발주 품목으로 특정 제품명·라이선스 수량이 명시되지 않음
    • SW 구성 계획 (제품명 미지정, 수량만 명시):

      • Web 서버: 총 6개 (업무지원 2 + 대국민 4)

  • [비기능 요구사항]

불가능 요소
  • SW 별도 구매 구조: 본 사업은 MSP 운영 서비스 사업으로, OS·WAS·DBMS 등 S/W 라이선스 구매는 별도 "상용SW 직접구매(3자단가)" 사업으로 분리 조달 예정 — 본 MSP 계약에서 Red Hat 라이선스를 직접 납품할 기회가 없음
  • CSP 제공 SW 우선 채택 원칙: "시스템SW는 CSP 제공 SW 우선으로 채택"하도록 명시되어, Red Hat 상용 제품의 독자적 제안이 어려울 수 있음 (CSP가 제공하는 관리형 Kubernetes·OS 서비스가 우선 적용될 가능성)
  • RFP 내 Red Hat 상용 제품명 전무: RHEL, OpenShift, JBoss EAP, Ansible, Quay 등 Red Hat 상용 제품명이 RFP 어디에도 명시되지 않음 — "높음" 판정 근거 없음
  • 경쟁·대체 OS 특정 명시는 없으나 CSP 종속 SW 환경 구성으로 Red Hat 도입 여지가 제한적일 수 있음
  • 중소기업 제한 사업: 20억 미만으로 대·중견기업 참여 불가 — Red Hat Korea 직접 참여는 불가하며, 파트너사 채널을 통한 간접 접근 필요

가능 요소
  • Kubernetes 컨테이너 플랫폼 (OpenShift 제안 여지): RFP 전반에 걸쳐 쿠버네티스 기반 컨테이너 환경 구축이 핵심 요구사항으로 명시됨 — WEB/WAS 계층 컨테이너화, 오토스케일링, Pod 단위 자원관리, 컨테이너 이미지 취약점 진단 등 OpenShift Container Platform의 강점과 직접 부합
  • Linux OS (RHEL 제안 여지): OS 총 59개가 필요하며 특정 OS 브랜드 미지정 — "서버용 개방형 운영체제(Linux)" 적용 계획이 있어 RHEL 제안 가능. 단, CSP 제공 OS 우선 원칙으로 인해 별도 직접구매 채널 활용 필요
  • Ansible Automation Platform (자동화 인프라 운영): 24×365 클라우드 자원 관리, 자동화된 점검 시스템, SW 패치·업그레이드 자동화 요구사항이 명시 — Ansible 기반 인프라 자동화 솔루션 제안 적합
  • WAS (JBoss EAP 제안 여지): WAS 6개 도입 예정이며 제품명 미지정 — JBoss EAP 제안 가능하나 CSP 제공 SW 우선 원칙 및 별도 직접구매 구조 감안 필요
  • 컨테이너 보안·레지스트리 (Quay/ACS 제안 여지): "컨테이너 이미지 취약점 진단 및 안전한 레지스트리 운영 환경 구축" 요구 명시 — Red Hat Quay 또는 Advanced Cluster Security(ACS) 제안 여지 존재
  • RFP에 명시된 Red Hat(동의어 포함) 상용 제품명·수량: 해당 없음 (명시된 Red Hat 상용 제품 없음)
  • 파트너 영업 접근 전략: 대구센터 PPP 클라우드 CSP(3社) 또는 MSP 입찰 파트너사와의 협력을 통해 OpenShift 기반 컨테이너 PaaS, RHEL OS, Ansible 자동화 솔루션을 간접 제안하는 채널 영업 전략 권장
