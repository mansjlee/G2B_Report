사업 개요 및 목적
  • 경기도교육청이 운영하는 고등학교 입학·전학 포털시스템(고교입학시스템·고입포털시스템)의 응용프로그램 유지관리 사업
  • 정기적인 장애 예방 활동 및 장애 발생 시 신속한 대응을 통해 24시간 365일 안정적인 시스템 운영 보장
  • 응용프로그램 현행화 및 기능 개선을 통해 학생·학부모 대상 양질의 대국민 서비스 제공
  • 2028학년도 고입전형 계획 및 내신성적 반영 지침 반영, 시스템 사용자 교육 실시
  • 고입포털 홈페이지의 경기도교육청 정보자원통합시스템 이전 지원 포함

Red Hat 제안
불가능 요소
  • WAS 서버 TmaxSoft JEUS 고정: WAS는 JEUS 7.0/8 Enterprise(TmaxSoft)가 기 구축·운영 중이며, COR-002(현재 운영 중인 제품과의 호환성) 요구사항으로 인해 Red Hat JBoss EAP 제안 불가
  • WEB 서버 TmaxSoft WebToB 고정: WEB 서버는 WebToB 4.x/5 Enterprise(TmaxSoft)가 기 구축·운영 중이며 직접구매로 조달쇼핑몰 구매 예정. Red Hat 기반 WEB 서버 대체 기회 없음
  • DBMS IBM DB2 계열 고정: 기존 DB2 Enterprise Server V10.5, DB2 CP4D Advanced Enterprise V11.5.7 운영 중이며, 통합발주 품목도 DB2 AI Standard Edition(IBM)으로 지정. Red Hat DataGrid 등 대체 여지 없음
  • Red Hat 상용 제품명 전혀 미명시: RFP 전체(과업지시서, SW 도입 목록, 통합발주 목록 포함)에서 RHEL, OpenShift, Ansible, JBoss EAP, Satellite 등 Red Hat 상용 제품명이 단 한 건도 언급되지 않음
  • 기존 시스템 유지관리 사업으로 플랫폼 변경 불가: 본 사업은 기 구축된 시스템 유지관리 사업으로, 기존 SW 스택(TmaxSoft 미들웨어, IBM DB2) 교체·대체 가능성이 원천적으로 배제됨
  • OS 미지정이나 실질적 변경 기회 없음: 기술적용계획표에서 Linux를 서버 OS 옵션으로 언급하나, 이는 일반적인 전자정부 기술참조모델 기재 사항이며 기존 운영환경 변경을 전제하지 않음
Red Hat 제안
가능 요소
  • RFP 내 Red Hat(동의어 포함) 제품명: 없음 — RFP, 과업지시서, SW 구매 목록 전체에서 RHEL, OpenShift, OCP, Ansible, JBoss, EAP, Satellite, AMQ, Quay 등 Red Hat 상용 제품명이 전혀 명시되어 있지 않음
  • Java 기반 응용프로그램: 시스템이 Java(전자정부 표준 프레임워크 기반)로 개발되어 있어 이론적으로 JBoss EAP와 기술적 연관성은 있으나, WAS가 JEUS로 고정되어 있어 실질적인 Red Hat 제안 여지 없음
  • 보안 기능 개선 영역: 보안취약점 점검 대응, 개인정보보호 등 보안 요구사항이 다수 존재하나, 해당 보안 솔루션도 HIWARE, Ksign 등 타사 제품으로 기 도입되어 있음
  • 종합 평가: 상기 요소들은 Red Hat 상용 제품을 실질적으로 제안할 수 있는 기회로 보기 어려우며, 이 사업에서 Red Hat SW 납품·구독 기회는 사실상 없음
