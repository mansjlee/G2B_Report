불가능 요소
  • 신규 S/W 통합발주 항목 부재: 본 사업은 기존 보유 정보시스템의 유지보수 용역이 주목적으로, 신규 상용 SW 납품·도입을 위한 통합발주 품목이 명확히 명시되지 않음
  • 경쟁 DBMS 명시: 학사행정시스템 및 교육안내서비스 DBMS로 Oracle이 명시되어 있어 Red Hat의 데이터 관련 제품(Data Grid 등) 직접 제안이 어려움
  • 기술적용계획표 Linux 해당없음: RFP 내 기술적용계획표(참고5)에서 서버용 운영체제 항목 중 Linux가 "해당없음"으로 체크되어 있어 현재 환경에서 RHEL 즉시 도입 근거가 약함
  • Red Hat 상용 제품명 전혀 미명시: RHEL, OpenShift, Ansible, JBoss EAP 등 Red Hat 상용 제품·동의어가 RFP 전체에 단 한 건도 품목으로 기재되지 않음
  • 중소기업 한정 사업: 20억 미만 중소기업 한정 입찰로, Red Hat이 직접 참여하거나 대형 파트너가 주도하기 어려운 규모
Red Hat 제안
가능 요소
  • OS 변경 예정 명시 → RHEL 전환 여지: RFP에 "27년 학사행정시스템 기능개선사업 진행으로 DBMS 및 OS 등 변경 예정"이라고 명시되어 있어, 향후 RHEL 도입 제안 기회 존재. 유지보수 사업자가 OS 전환 컨설팅을 수행하며 RHEL 도입을 자연스럽게 연계 가능
  • 클라우드 이전 방안 제시 필수 → OpenShift/RHEL 제안 기회: OMR-002에서 "학사행정시스템 클라우드 이전사업에 대한 구체적인 이전방안(HW/SW 아키텍처 구성안 포함) 제시" 요구. 평가 항목에도 "클라우드 전환 시 인프라 구성 방안", "클라우드 전환 시 상용 SW 도입 및 구축 방안" 항목이 존재하여 OpenShift Container Platform 또는 RHEL 기반 클라우드 아키텍처 제안 가능
  • Java/WAS 기반 시스템 → JBoss EAP 제안 여지: 학사행정시스템이 Java 기반이며 WAS 서버 1대가 운영 중. 현재 WAS 제품이 비공개로 명시되어 있어, 차기 클라우드 전환 또는 고도화 시 JBoss EAP(Red Hat 상용) 전환 제안 가능
  • Ansible 자동화 제안 여지: 다양한 장비(서버, 네트워크, 보안 장비 등 50여 대 이상)의 패치·업그레이드·형상관리 자동화 수요 존재. Ansible Automation Platform을 활용한 운영 자동화 방안 제안 가능
  • RFP 내 Red Hat 제품명 명시 현황: 없음 (RHEL, OpenShift, Ansible, JBoss EAP 등 Red Hat 상용 제품명 전무)
