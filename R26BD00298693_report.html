불가능 요소
  • S/W 신규 구매·납품 항목 없음: 본 사업은 기존 운영 시스템에 대한 순수 유지관리 용역으로, RFP 내 Red Hat 상용 제품(RHEL, OpenShift, Ansible, JBoss EAP 등)이 신규 도입·납품·구독 품목으로 명시되지 않음
  • Red Hat 상용 제품명 미명시: 유지관리 대상 S/W 목록에 "Linux 279식"으로만 기재되어 있으며, RHEL(Red Hat Enterprise Linux), JBoss EAP 등 정확한 Red Hat 상용 제품명이 기재되지 않음. 회사명(Red Hat/레드햇)도 문서 내 미등장
  • 경쟁·커뮤니티 OS 언급: 보안지원 중단 OS 점검 대상으로 "CentOS 6, CentOS 8, CentOS 7, Ubuntu 14.04, RHEL 7.x 이하" 등이 열거되어 있으나, 이는 도입 확정이 아닌 점검·교체 검토 대상이며, RHEL이 현재 운영 중임을 확정하는 근거가 되지 않음 (제품명 열거 맥락이 운영 대상이 아닌 교체 검토 목록)
  • 중소기업 전용 사업: 대기업·중견기업 참여 불가 (소프트웨어 진흥법 제48조). Red Hat이 SI·총판 채널을 통해 간접 참여하는 구조이나, 사업 자체가 순수 유지관리 용역으로 SW 납품 기회 없음
  • 주요 상용 SW는 경쟁사 제품: 기술지원서 제출 대상 3종(IBM GPFS, Siemens PBS Pro, ITTVIS IDL) 모두 Red Hat 제품과 무관
Red Hat 제안
가능 요소
  • 대규모 Linux 서버 운영 환경: 2027년 기준 Linux 279식(2029년 260식)의 대규모 Linux 서버가 운영 중이며, OS 종류가 미지정 상태로 기재됨. 차기 계약 또는 OS 교체·업그레이드 시 RHEL 제안 가능성 존재
  • 보안지원 중단 OS 교체 검토 조항: MAR-08(성능관리) 요구사항에 "보안지원이 중단된 운영체제 사용 여부를 확인하고 해당사항이 있으면 발주처와 협의하여 운영체제 교체 실시" 명시. 점검 대상 목록에 "CentOS 6, CentOS 7, CentOS 8" 등이 포함되어 있어, 향후 CentOS → RHEL 전환 영업 기회 발생 가능
  • HPC 클러스터 환경의 Ansible 자동화 제안 여지: 245식 이상의 계산서버 환경에서 OS 패치, 환경설정, 업그레이드 등의 자동화 필요성이 높아 Ansible Automation Platform 제안 여지 있음
  • RFP 내 Red Hat 제품명 명시 현황: "RHEL 7.x 이하"가 보안지원 중단 OS 점검 대상 목록에 등장하나, 이는 현행 운영 대상이 아닌 점검·교체 검토 목록이므로 판정 규칙상 "높음" 근거로 활용 불가. 정확한 Red Hat 상용 제품이 유지관리 대상으로 명시된 것은 아님
  • 결론: 현재 사업에서 Red Hat 제품의 직접 납품·구독 기회는 없으나, 기존 Linux 운영 환경의 OS 현대화·교체 기회를 포착하여 차기 사업 또는 별도 조달쇼핑몰 구매 연계 영업 전략 수립 권장. 담당자(남민석, 032-560-7720) 접촉을 통해 현행 Linux 배포판 종류 파악이 선행되어야 함
