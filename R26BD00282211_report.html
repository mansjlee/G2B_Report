S/W 미포함 순수 유지보수 용역
사업 개요 및 목적
  • 2027년도 저압 AMI(Advanced Metering Infrastructure)용 단말기 보안관리 솔루션 및 관련 시스템 2식에 대한 유지보수 용역 사업임.
  • AMI 단말기 보안관리 솔루션의 안정적 운영을 목적으로 하는 유지보수·운영 지원 서비스 제공이 핵심 목표.
  • 입력 텍스트가 파일 인코딩 오류로 인해 대부분 판독 불가한 상태이므로, 세부 내용은 파일명 및 판독 가능한 일부 텍스트를 기반으로 분석함.
주요 정보
  • 사업 예산: 입력 문서 인코딩 오류로 판독 불가 (원문 확인 필요)
  • 사업 기간: 2027년도 (27년) 해당 연도 유지보수 기간으로 추정; 상세 기간 판독 불가
  • 사업 범위: 저압 AMI용 단말기 보안관리 솔루션 2식에 대한 유지보수; 용역시방서 기준 이행방법, 성과관리, 보안 요건 포함 추정
  • 주요 일정: 입력 문서 인코딩 오류로 판독 불가 (원문 확인 필요)
담당자 정보
  • 입력 문서가 HWP 파일 인코딩 오류로 인해 담당 부서명, 담당자 성명, 연락처, 이메일 주소 모두 판독 불가.
  • 나라장터(G2B) 공고 원문(R26BD00282211) 또는 첨부 원본 파일에서 직접 확인 필요.
핵심 요구사항
  • 기술 요구사항: 문서 인코딩 오류로 상세 기술 요구사항 판독 불가. 용역시방서(붙임3) 원문 기준으로 AMI 단말기 보안관리 솔루션의 유지보수 이행 기준, 성과 관리 기준, 보안 요건이 포함된 것으로 추정됨.
  • 비즈니스 요구사항: 저압 AMI 단말기 보안관리 솔루션 2식의 연간 안정적 운영 및 장애 대응, 보안 패치 적용 등 유지보수 서비스 제공.
  • 구매 명시 S/W: 판독 가능한 텍스트 내에 통합발주 또는 조달 구매 대상 S/W 품목이 명시된 내용 없음. 순수 유지보수 용역으로 판단됨.
Red Hat 제안
불가능 요소
  • S/W 납품 항목 없음: 본 사업은 기존 구축된 AMI 단말기 보안관리 솔루션 2식에 대한 유지보수 용역으로, 신규 S/W 구매·납품 항목이 문서 내 확인되지 않음.
  • 순수 용역 사업: 용역시방서 성격상 인력 투입 기반의 유지보수·운영 지원 서비스로, Red Hat 상용 제품(RHEL, OpenShift, Ansible 등) 도입·납품 기회가 없음.
  • Red Hat 제품 미명시: 판독 가능한 범위 내에서 RHEL, OpenShift, Ansible, JBoss/EAP 등 Red Hat 상용 제품명이 전혀 명시되지 않음.
  • 경쟁·대체 제품: 판독 불가로 경쟁 제품 명시 여부는 확인 불가하나, AMI 보안관리 솔루션 특화 유지보수 특성상 Red Hat 스택 적용 여지 낮음.
Red Hat 제안
가능 요소
  • 직접 제안 가능 요소 없음: 현재 판독 가능한 문서 내용 기준으로 Red Hat 상용 제품(RHEL, OpenShift, Ansible, JBoss EAP 등)이 품목으로 명시된 내용 없음.
  • 간접 가능성: AMI 단말기 보안관리 솔루션의 서버·운영 환경이 Linux 기반일 가능성이 있으나, 유지보수 용역 특성상 기존 환경 유지가 원칙이므로 RHEL 전환·도입 제안 가능성 극히 낮음.
  • RFP 내 Red Hat 제품명·수량: 판독 가능한 범위 내에서 Red Hat 또는 동의어로 명시된 제품명·수량 없음.
  • 참고: 입력 문서의 인코딩 오류로 전체 내용 판독이 불가하므로, 원본 HWP 파일을 직접 열어 추가 검토를 권장함.
