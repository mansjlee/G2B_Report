사업 개요 및 목적
  • 한국관광공사 VISITKOREA 플랫폼의 다국어 관광 데이터를 AI 활용에 적합(AI-Ready)하게 고도화하는 용역 사업이다.
  • 글로벌 AI 서비스 경쟁력 강화, 다국어 데이터 거버넌스 체계 구축, VISITKOREA 콘텐츠 마케팅 고도화 및 전사 관광 특화 AI 서비스 기반 마련이 핵심 목표이다.
  • 주요 과업은 AX전환 전략(가이드라인) 수립, 기존 8개 어권 데이터 현행화·정제, 국문 DB 기반 4개 어권 신규 다국어 DB 확충·정제, 데이터 거버넌스·운영 인프라 지원, 한국관광콘텐츠랩(RMS) 입력 및 이력 관리이다.
주요 정보
  • 사업 예산: 991,513,000원 (부가가치세 포함)
  • 사업 기간: 계약체결일 ~ 2026.12.11 (과업종료 후 정산 및 결과보고서 제출 시까지)
  • 사업 범위: 다국어 데이터 컨설팅·진단·표준화, 약 9.9만 건(기존 3.7만+신규 6.2만) 데이터 정제·번역·감수·입력, 비정형 콘텐츠 AI 구조화, CID/TID 식별체계 적용, 데이터 정합성 모니터링, 교육·하자보수(1년) 포함
  • 계약방법: 제한경쟁입찰, 협상에 의한 계약
  • 주요 일정: M(사업자 선정·계약) → M+1(데이터 가이드라인 수립) → M+2~M+4(다국어 데이터 구축·관리·운영 지원, 착수·중간·완료·검수 보고)

Red Hat 제안
불가능 요소
  • S/W 공급 미포함: 본 사업은 데이터 컨설팅·가공·번역·감수·입력 중심의 용역이며, Red Hat 제품(RHEL, OpenShift, Ansible 등)의 조달·납품·라이선스 공급 요건이 없다.
  • 경쟁 제품 명시 없음: VMware, Ubuntu, Oracle Linux, Rocky Linux 등 특정 OS·가상화·컨테이너 플랫폼이 지정되지 않았으나, 반대로 Red Hat 제품 도입 근거도 없다.
  • 기존 플랫폼 종속: VISITKOREA, CMS, 검색엔진, 한국관광콘텐츠랩(RMS) 등 공사 보유 시스템 환경에 데이터를 입력·연계하는 형태로, 인프라·미들웨어 교체·구축 과업이 아니다.
  • GPU·고성능 연산 배제: CIR-001에서 GPU 등 고성능 연산 자원은 명시적으로 배제되어 OpenShift AI 등 AI 플랫폼 구축 여지가 없다.
  • 응용 개발 제외: DAR-002 등에서 '별도의 응용 프로그램 개발 없이' 구조화 데이터셋(JSON, CSV) 형태로 납품하도록 규정.
  • 중소 SW사업자 전용: 20억 미만 사업으로 중소 SW사업자만 입찰 가능하며, Red Hat이 직접 원도급 수주·제품 공급 구조와 맞지 않다.
Red Hat 제안
가능 요소
  • CIR-001 옵션 클라우드(간접): 데이터 정제·이관용 CSAP 인증 민간 클라우드(web, WAS, DB) 임차 시 RHEL을 OS 기반으로 제안할 수 있으나, OS·DB·WAS 특정 제품이 명시되지 않아 수행사(데이터·번역 전문 업체)의 선택 사항이며 Red Hat 직접 제안 경로가 없다.
  • PSR-005 기타 추가제안: 발주기관 협의 시 추가 제안 가능 항목으로, AI 데이터 파이프라인 자동화(Ansible), 컨테이너 기반 데이터 처리 환경(OpenShift), AI/RAG 서비스 플랫폼(OpenShift AI) 등을 '향후 AX 전환 기술 자문' 차원에서 간접 제안할 여지는 있으나 본 RFP 필수 과업 범위는 아니다.
  • 기술 요구 정합(간접): RAG·벡터검색·AI-Ready 데이터 표준, CSAP 클라우드 보안, AI 정보화 사업 보안(SER-018) 등은 Red Hat AI/플랫폼 스택과 개념적으로 부합하나, 본 사업은 해당 플랫폼 구축이 아닌 데이터 품질·콘텐츠 가공이 핵심이다.
  • 파트너 협력 가능성: Red Hat이 직접 입찰 참가는 어렵고, 유사 실적(1억 이상, 3년)을 보유한 중소 데이터·AX 컨설팅 수행사와의 간접 파트너십을 통한 기술 지원·추가제안 정도만 검토 가능하다.
