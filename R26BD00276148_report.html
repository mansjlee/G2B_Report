불가능 요소
  • S/W 납품 포함 여부: S/W 납품 항목 포함 — 연간 상용SW & HW/NW 예산 약 70억원 규모로 라이선스 구매가 계약 범위에 포함되어 있어 제안 불가 요소 아님
  • 경쟁 제품 명시 여부: 업무용 패키지 소프트웨어 약 189종 상세 목록이 보안상 별도 열람으로 미공개 → 경쟁 OS·플랫폼 포함 여부 전체 확인 불가
  • Rocky Linux 사용 가능성: 월간 운영보고서 서식 예시(SLA표준안)에 Rocky Linux가 서버 OS 예시로 기재됨 → 실제 운영 서버에 Rocky Linux 적용 시 RHEL 제안 여지 제한 가능 (단, 예시용 기재이며 실제 운영 목록은 미공개)
  • 특정 기술 종속 구조: 주요 개발환경이 Java/Nexcore(전자정부 프레임워크) 기반으로 고착되어 있어 미들웨어 교체 제안은 어려움
  • 대규모 SI 수주 구조: 총 705억원 규모의 통합 용역 사업으로 대형 SI 사업자 중심으로 진행되며, Red Hat이 직접 입찰하는 구조가 아니라 파트너를 통한 간접 공급 형태
