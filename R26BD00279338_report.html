가능 요소

  • RHEL 구독 갱신 기회: 기존 RHEL 6식에 대한 3년 구독 갱신 및 추가 확장 제안 가능. 사업 기간(2027~2028) 중 구독 만료 시점에 따라 갱신 영업 기회 발생
  • 다수 Linux 기반 서버 운영 환경: HP, Lenovo, IBM, Dell, Fujitsu 등 다양한 x86/Unix 서버 환경에서 RHEL 확장 적용 가능성 존재. 현재 RedCastle 리눅스용 서버보안 솔루션이 다수(6식) 운영 중인 것으로 보아 Linux 서버 환경이 다수임을 확인
  • Ansible 자동화 제안 여지: 342종 1,048점에 달하는 대규모 장비 유지보수 환경에서 패치 관리, 구성 자동화를 위한 Ansible Automation Platform 제안 가능
  • 보안 강화 요구사항 연계: 주요정보통신기반시설 취약점 점검, 보안패치 관리 등 강도 높은 보안 요구사항과 RHEL의 보안 강화 기능(SELinux, RHEL Security Profile 등) 연계 제안 가능
