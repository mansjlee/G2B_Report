불가능 요소
  • 신규 S/W 도입·납품 사업 아님: 본 사업은 기존 구축된 플랫폼의 운영·유지관리 용역으로, 상용SW 신규 구매·증설이 목적이 아님
  • 상용SW 품목 제품명 전면 비공개: 보안 지침에 따라 OS 27식을 포함한 모든 상용SW 제품명이 공개되지 않음 — RHEL 등 Red Hat 상용 제품이 명시된 증거 없음
  • RFP 내 Red Hat 제품명 미명시: RHEL, OpenShift, Ansible, JBoss EAP 등 Red Hat 상용 제품명이 RFP 본문 어디에도 등장하지 않음
  • 월간 운영보고서 샘플에 Rocky Linux 명시: RFP 붙임의 월간 운영보고서 SW 구성 현황 예시에 "Rocky Linux"가 OS로 기재되어 있어, 현행 운영 환경이 Rocky Linux(CentOS 계열 커뮤니티 배포판) 기반일 가능성 있음
  • 경쟁 OS 환경 가능성: Rocky Linux가 현행 OS라면 RHEL로의 전환 필요 — 그러나 RFP에서 OS 변경 요구사항은 없으므로 대체 가능성 낮음
  • 중소기업 제한 입찰: 20억 미만 사업으로 중소기업만 참여 가능하여 Red Hat 직접 제안 불가, SI 파트너 채널 통해서만 접근 가능
  • 하도급 불가: 본 사업은 하도급이 금지되어 있어 협력사를 통한 간접 공급도 제한됨
Red Hat 제안
가능 요소
  • OS 27식 제품명 비공개: 상용SW 목록에 OS 27식이 포함되어 있으나 제품명이 보안상 비공개 처리됨 — 방문 열람 시 RHEL 여부 확인 가능하며, 만약 RHEL로 확인될 경우 판정은 높음으로 상향됨
  • Linux 서버 운영 환경: 기술적용계획표에 "Linux" 항목이 서버용 운영체제로 명시되어 있어 RHEL 제안 여지 존재
  • 가상화 솔루션 6식 운영: 가상화 환경이 운영 중이므로 향후 OpenShift 또는 RHEV 관련 제안 가능성 존재
  • 플랫폼 재구조화 과업 포함: "표준플랫폼 내 서비스간 분리 및 재구조화를 통한 플랫폼 유연성 확보" 요구사항이 명시되어 있어 컨테이너·PaaS 환경 전환 시 OpenShift 제안 가능
  • 기술적용계획표 클라우드 항목: IaaS, PaaS, SaaS 클라우드 컴퓨팅 항목이 기술 적용 계획에 포함되어 있어 클라우드 기반 Red Hat 솔루션 제안 여지 있음
  • RFP 내 Red Hat 명시 제품: RFP 전문 내 Red Hat 상용 제품명(RHEL, OpenShift, Ansible, JBoss EAP 등)은 명시되지 않음 — 방문 열람 후 OS 제품명 확인이 선행되어야 함
