Red Hat 제안
불가능 요소
  • 구매 품목에 Red Hat 상용 제품 없음: 통합발주 S/W는 웹빌더 1식이 유일하며, RHEL·OpenShift·Ansible·JBoss EAP 등 Red Hat 상용 제품이 도입·납품 품목으로 명시되지 않음
  • 응용개발 중심 사업: 본 사업은 인프라(H/W) 구축이 별도 사업(인프라구축사업자)으로 분리되어 있으며, 본 사업은 응용프로그램 개발에 집중 → OS·미들웨어 직접 납품 기회 제한적
  • 운영 S/W 이전은 기존 라이선스 활용: 서버보안·개인정보접속관리 S/W는 신규 구매 없이 기존 라이선스를 이전 적용하므로 Red Hat 제품 진입 불가
  • 클라우드 플랫폼 미지정: 클라우드 전환이 명시되어 있으나 특정 클라우드 서비스(공공 민간 클라우드)를 인프라 사업자가 담당하므로 본 응용개발 사업에서 OpenShift 등 직접 제안 어려움
  • 경쟁 제품 직접 명시 없음: Ubuntu, Rocky Linux, VMware 등 특정 경쟁 제품은 명시되지 않으나, 기존 OS(6식) 제품명도 미공개로 기존 환경 파악 불가
Red Hat 제안
가능 요소
  • OS 플랫폼 미지정 → RHEL 제안 여지: 기존 시스템 OS(6식) 및 신규 클라우드 서버 OS가 명시되지 않아, 인프라 구축 사업자 또는 통합 제안 시 RHEL 제안 가능. 기술지원 중단된 기존 OS 교체 수요 존재
  • 전자정부 표준 프레임워크 / Java 기반 → JBoss EAP 제안 여지: WAS S/W(2식) 교체 필요, Java/전자정부 표준 프레임워크 기반 개발 환경에서 JBoss EAP(Red Hat 상용 WAS) 제안 가능. 단, WAS 선택은 인프라 구축 사업자 또는 응용개발사와 협의 필요
  • 클라우드 전환 환경 → OpenShift 제안 여지: 클라우드 기반 인프라 구축 및 유연한 확장이 요구되어 컨테이너 플랫폼(OpenShift) 제안 가능. 단, 인프라 구축이 별도 사업으로 분리되어 직접 제안 경로 확인 필요
  • 정량적 평가 자격증 목록에 RedHat EX180, EX280 포함: 입찰자 기술인력 자격 평가 항목으로 "RedHat EX180(컨테이너 기초), RedHat EX280(OpenShift 관리)"가 명시됨 → 발주기관이 Red Hat 컨테이너 기술에 친숙하거나 관심이 있음을 시사, 향후 OpenShift 도입 대화 진입점으로 활용 가능
  • AI/LLM 서비스 인프라 → Red Hat AI Accelerator 제안 가능성: GPU 서버 임대 기반 LLM 서비스 구축이 명시되어 있어, RHEL AI 또는 OpenShift AI 등 Red Hat AI 솔루션 소개 기회 존재
  • RFP 내 Red Hat(또는 동의어) 상용 제품명 명시 없음: 자격증 목록(RedHat EX180, EX280) 외 Red Hat 상용 제품 품목 명시 없음
