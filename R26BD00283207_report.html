Red Hat 제안
불가능 요소
  • Red Hat 상용 제품 미명시: RFP 전체에 RHEL, OpenShift, Ansible, JBoss EAP 등 Red Hat 상용 제품명이 단 한 건도 언급되지 않음
  • DaaS 데스크톱 OS 고정: 가상 데스크톱(VD) OS는 반드시 MS Windows 11 Pro (64bit)로 명시되어 있어, 데스크톱 레이어에서 RHEL 도입 여지 없음
  • CSAP-DaaS 인증 플랫폼 요구: Private DaaS 플랫폼은 CSAP-DaaS 인증을 받은 특정 상용 서비스와 동일해야 하므로, 플랫폼 선택이 인증 제품으로 사실상 제한됨 (Red Hat 기반 자체 구성 난이도 높음)
  • 대기업 참여 제한: 사업금액 20억 이상~40억 미만으로 대기업(상호출자제한기업집단 포함) 직접 입찰 불가 — Red Hat Korea가 단독 입찰 불가, SI 파트너를 통한 간접 공급 구조여야 함
  • 하도급·공동수급 불허: 컨소시엄 구성 없이 단독 수행 요구로 Red Hat이 SW 공급 파트너로 참여하는 경로가 제한적
Red Hat 제안
가능 요소
  • 가상화 서버 운영체제 미지정 → RHEL 제안 가능: ECR-001에 "가상화 서비스 운영체제, DBMS, 데스크톱 OS 등 제안 제품 명시"라고만 기술되어 있고, 서버 측 하이퍼바이저/호스트 OS 제품명이 지정되지 않음 → RHEL을 가상화 서버 호스트 OS로 제안 가능
  • Linux 기반 인프라 구성 여지: Private DaaS 플랫폼의 WEB(Apache, Nginx 등), WAS(Tomcat 등), DB, DNS, FTP 등 서버 서비스 구성이 필요하며, 이 모두를 RHEL 기반으로 구성 제안 가능
  • Ansible 자동화 제안 여지: 중앙제어 패치·업데이트, VM 배포·회수 자동화, 동글 점유·해제 자동화 등 반복 운영 자동화 요구사항이 다수 존재 → Ansible Automation Platform(AAP) 적용 제안 가능
  • RFP 내 Red Hat(또는 동의어) 명시 제품 없음: RFP 문서 내에 RHEL, OpenShift, Ansible, JBoss 등 Red Hat 상용 제품이 품목으로 명시된 사례는 없음 (제안 시 파트너사가 자체 구성으로 포함 가능)
