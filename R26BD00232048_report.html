사업 개요 및 목적
  • 독립유공자 포상 기록철 51,285권(약 3,900,000면)을 전산화하여 포상 근거 자료의 보존성 및 업무 효율성 증대
  • 이미지 파일 제작, 문서 유형 정보 입력 등을 통해 국가보훈부 포상심사관리시스템에 연동할 디지털 데이터베이스 구축
  • 계약 방법: 제한경쟁 입찰(협상에 의한 계약), 기술평가 90점 / 가격평가 10점

핵심 요구사항
  • [핵심 기술 요구사항]
    • ECR-01: 원본 훼손 방지를 위한 스캔 장비 구성 및 사용 방안 제시
    • DAR-02: 기록철 51,285권 스캔, 300dpi 이상 JPEG 이미지 제작
    • DAR-03: 이미지 파일 해상도·품질 영향 최소화하는 용량 최적화
    • DAR-04: 문서 유형 정보(공적조서, 공적조사서, 평생이력서 등) 및 색인 데이터 제작 (인명, 작성일 추출)
    • DAR-06: 납품 형식 — JPEG(최적화 전/후), 문서유형별 PDF, 기록철별 PDF, XLSX
    • DAR-07~11: 데이터 표준 수립·관리, 데이터 구조(개념·논리·물리 모델) 설계·검증·관리
    • DAR-12: 순도율 99.9% 이상 데이터 품질 확보 (최소 3단계 점검)
    • SER-01~07: 관리적·물리적·문서·기술적 보안 요건 준수, 개인정보 암호화(SHA-256 이상)
  • [구매가 명시된 S/W]
    • 본 사업의 요구사항 목록(ECR/DAR/SER/QUR/COR/PMR/PSR) 내 신규 상용 SW 구매·납품 품목이 명시되지 않음
    • ※ RFP 소프트웨어 현황(기존 운영 중인 시스템): JBoss EAP 4식, CUBRID 9 4식, Mariner 4(검색엔진) 2식, OZ Report 7(리포팅툴) 2식, EdgeDB 4(암호화솔루션) 2식 — 이는 현황 정보이며 본 사업 구매 대상이 아님
Red Hat 제안
불가능 요소
  • S/W 납품·구독 항목 없음: 본 사업은 종이 기록철 디지털화(스캔·데이터 입력) 중심의 순수 데이터 구축 용역으로, RFP 전 요구사항 목록에 걸쳐 신규 상용 SW 구매 또는 라이선스 구독 항목이 전혀 명시되어 있지 않음
  • 시스템 개발·인프라 구축 범위 없음: 포상심사관리시스템 자체의 신규 구축·고도화가 아닌, 기존 시스템에 입력할 데이터 자산 생산이 목적이므로 플랫폼·미들웨어·OS 도입 기회 없음
  • 경쟁 제품 직접 명시 없음: Ubuntu, VMware, Oracle Linux 등 명시적 경쟁 제품은 없으나, 애초에 SW 공급 범위 자체가 본 사업에 포함되지 않음
  • 하도급 전면 금지: RFP상 하도급을 전혀 허용하지 않으므로 파트너사를 통한 간접 공급 구조도 불가
Red Hat 제안
가능 요소
  • 기존 인프라에 JBoss EAP 운영 중: 포상심사관리시스템 WAS로 JBoss EAP 4식이 현재 운영되고 있어, Red Hat 고객 현황 파악 및 향후 갱신·증설 영업 기반으로 활용 가능
  • RFP 내 Red Hat 상용 제품 도입 명시 없음: JBoss EAP는 기존 현황 항목에만 기재되어 있으며, 본 사업 내 신규 구매·납품 품목으로 명시되지 않음 → 현 사업에서의 직접 제안 기회는 없음
  • 향후 사업 연계 기회: 구축 완료 후 포상심사관리시스템 운영·고도화 사업 발생 시 기존 JBoss EAP 기반으로 EAP 갱신 또는 OpenShift 전환 제안 가능성 존재 (본 사업과 무관한 차기 사업 관점)
  • 운영체제 Linux 명시: WEB/WAS/DB/검색엔진/리포팅 서버 모두 Linux 운영 중이나, OS 교체·구매가 본 사업 범위에 포함되지 않아 RHEL 제안 불가
