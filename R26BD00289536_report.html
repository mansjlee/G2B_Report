Red Hat 제안
불가능 요소
  • 순수 유지관리 용역: 본 사업은 신규 SW 납품·구독이 없는 기존 시스템 유지보수 용역으로, Red Hat 상용 제품의 신규 도입·납품 기회가 없음
  • VMware 제품 명시: 가상화 솔루션으로 VMware vSphere 8 및 vCenter Standard 8이 기존 인프라로 확정되어 기술협약 대상에 포함 → Red Hat Virtualization(RHEV) 또는 OpenShift Virtualization 제안 불가
  • WAS/웹서버 스택 고정: 기존 WAS·웹서버로 TmaxSoft의 JEUS Standard v8 및 WebtoB Standard v5가 이미 운영 중 → JBoss EAP/WildFly 제안 여지 없음
  • DBMS 고정: DBMS로 Tibero 6/5 Enterprise Edition 및 Tibero 6 TAC(DB이중화) 사용 → Red Hat Data Grid 등 제안 불가
  • Red Hat 상용 제품 전무: RFP 전체에 RHEL, OpenShift, Ansible, JBoss EAP 등 Red Hat 상용 제품명이 단 한 건도 명시되지 않음
  • 기존 인프라 유지 원칙: RFP가 기존 구축 시스템의 연속성·안정성을 최우선으로 요구하므로 기술 스택 변경 여지 없음
Red Hat 제안
가능 요소
  • 사실상 Red Hat 제안 가능 요소 없음: 본 사업은 기존 SW 유지관리 용역으로 신규 SW 도입 항목이 없으며, 기존 인프라(VMware, Tibero, JEUS/WebtoB 등)가 모두 비Red Hat 제품으로 고정되어 있음
  • Linux 일반 언급: 기술적용계획표에 서버용 운영체제로 Linux가 일반적으로 언급되나, 특정 배포판이 명시되지 않아 이론적으로 RHEL 언급 가능. 단, 기존 시스템 유지관리가 목적이므로 OS 교체·신규 도입은 현실적으로 불가
  • Java 기반 응용SW 다수: 응용SW 26종 중 다수가 Java 기반이나, WAS는 JEUS/WebtoB로 고정되어 있어 JBoss EAP로의 전환 제안 여지 없음
  • RFP 내 Red Hat(동의어 포함) 제품명: 전혀 없음 (0건)
