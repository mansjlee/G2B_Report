Red Hat 제안
불가능 요소
  • 신규 S/W 도입·납품 항목 없음: 본 사업은 기존 시스템에 대한 순수 유지관리·운영 용역으로, 신규 소프트웨어 구매·납품·구독 항목이 전혀 없음. 조달구매(통합발주 포함) 대상 S/W가 없어 Red Hat 제품 공급 기회 없음.
  • Red Hat 상용 제품명 미명시: RFP 전체(현행 시스템 구성, 유지관리 대상 S/W 목록, 운영 환경 등)에 RHEL, JBoss EAP, OpenShift, Ansible 등 Red Hat 상용 제품명이 단 한 건도 명시되지 않음.
  • 경쟁 OS 환경 명시: 현행 서버 OS로 Windows 2008/2019 Std(MS), Oracle 10G/12C(Oracle)가 명시되어 있으며, Linux 계열 OS는 지정되지 않음. RDBMS도 Oracle/MS-SQL로 한정.
  • 인천광역시 소재 중소기업으로 참가자격 제한: Red Hat Korea(대기업) 및 대형 SI사는 직접 참여 불가. 중소기업 한정 입찰로 Red Hat의 직접 개입 어려움.
  • 공동수급 및 하도급 불허: 단독 수행 의무로 Red Hat이 협력사 형태로 참여하는 구조도 불가.
  • Linux·공개SW·오픈소스 관련 일반 문구도 미포함: 판정 규칙 2) 중간 조건인 "레드햇/Linux/공개SW" 등의 일반 문구조차 현행 시스템 구성에 없음. 순수 Windows/Oracle 기반 환경으로 확인됨.
Red Hat 제안
가능 요소
  • RFP 내 Red Hat 제품명 명시 없음: RFP 어디에도 RHEL, JBoss(EAP 포함), OpenShift, Ansible, Satellite 등 Red Hat 상용 제품명이 기재되어 있지 않음. 제안 가능 근거 없음.
  • 간접적 고려 가능 요소 (실질적 기회 미미):
    • 현행 서버 OS 목록에 Linux 계열이 명시되지 않았으나, 서버(IBM, DELL, Lenovo 등 46대) 중 일부가 Linux 기반일 가능성을 완전히 배제할 수 없음 (단, RFP에 근거 없음)
    • 중장기적으로 차기 사업에서 현재 Windows 기반 환경의 Linux 전환이나 ERP/WAS 환경의 현대화 필요성이 발생할 경우 접근 가능
    • 유지관리 과정에서 담당자(문영호 주임)와의 관계 구축을 통해 향후 신규 사업 발굴 가능성 모색 가능
  • 결론: 현재 사업에서 Red Hat 제품의 직접 제안 기회는 없음. 본 사업은 현행 시스템 유지관리에 한정되며, 판정 규칙에 따라 낮음으로 판정.
