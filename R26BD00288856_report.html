Red Hat 제안
불가능 요소
  • S/W 납품·구독 항목 전무: 본 사업은 「소프트웨어 개발사업의 적정 사업기간 산정 대상 제외」 사업으로 명시된 순수 운영·유지관리 용역이며, 상용 소프트웨어 도입 항목이 일절 포함되지 않음
  • Red Hat 상용 제품명 전혀 없음: RFP 전문에 RHEL, OpenShift, Ansible, JBoss EAP, Satellite 등 Red Hat 상용 제품명이 단 한 건도 명시되지 않음
  • 클라우드 인프라 운영 범위 제외: 클라우드 인프라 운영·관리는 「교육통계센터 통합운영관리사업」을 통해 별도 수행하며 본 사업 범위에 포함하지 않음 → OS·미들웨어·인프라 스택 제안 영역이 본 사업 밖에 있음
  • H/W·S/W 구성도 비공개: 기존 인프라 현황(H/W 구성, S/W 구성도)은 보안 규정에 의거 사업자 요청 시 보안서약서 징구 후 담당자 입회 하에 열람 가능하며, RFP상 기술 스택 확인 불가
  • 경쟁 OS 명시는 없으나 기회도 없음: Ubuntu, Rocky Linux, Oracle Linux, VMware 등 경쟁 제품이 명시되지는 않았으나, 응용시스템 유지관리(소스코드·DB·연계) 중심의 사업 성격상 OS·플랫폼 스택 납품 기회 자체가 없음
  • 대기업·Red Hat 직접 입찰 불가: 20억 원 미만 사업으로 소프트웨어 진흥법에 따라 대기업·중견기업 입찰 참여 제한 → Red Hat Korea 직접 참여 불가
Red Hat 제안
가능 요소
  • RFP 내 Red Hat 상용 제품명 명시: 없음 — RHEL, OpenShift, Ansible, JBoss EAP 등 Red Hat 상용 제품이 단 한 건도 언급되지 않음
  • 기술 스택 언급 수준에서의 잠재적 여지:
    • 기술적용계획표에서 서버용 개방형 OS로 「Linux」가 해당 없음(○) 으로 체크되어 있어, 현재 인프라에 Linux 계열 OS 사용 가능성이 있으나 상용 Red Hat 제품 납품 기회는 아님
    • 클라우드(IaaS/PaaS/SaaS) 적용 계획이 명시되어 있어, 별도의 클라우드 통합운영관리 사업(본 사업 범위 제외)에서 OpenShift·RHEL 제안 여지는 이론적으로 존재
    • 전자정부 표준프레임워크 기반 Java 애플리케이션 환경으로, JBoss EAP 적용 가능한 기술 구조이나 본 사업은 S/W 납품이 없어 실질적 제안 불가
  • 종합 판단: 위의 잠재적 요소들은 모두 본 사업 범위 외이거나 납품 항목이 없는 상태의 간접적 여지에 불과하며, 실질적인 Red Hat 제품 제안·납품 기회는 없음. 향후 클라우드 인프라 확장 또는 플랫폼 전환 관련 후속 사업 발생 시 RHEL·OpenShift 제안 가능성을 모니터링할 것을 권고
