Red Hat 제안
불가능 요소
  • 신규 S/W 납품 없음: 본 사업은 순수 유지관리 용역으로, 신규 Red Hat 상용 제품(RHEL, OCP, Ansible 등)의 도입·납품·구독이 RFP에 명시되지 않음
  • 경쟁 가상화 플랫폼 확정: VMware vSphere 8.0/8.3이 서버 하이퍼바이저로 확정 운영 중이며, MPR-06 상용SW 유지관리 목록에도 VMware Std/vSphere 8.0.2가 포함되어 있어 OpenShift/KVM 기반 전환 제안이 어려움
  • 경쟁 OS 운영 중: CentOS 6.9(x64)가 백업마스터 서버 OS로 운영 중 (EOS 상태이나 유지관리 대상으로 확정)
  • 경쟁 미들웨어/DB 확정: 티맥스소프트 WebtoB/JEUS, 티맥스티베로 Tibero 6·7이 웹/WAS/DB 스택으로 확정 운영 중 (JBoss EAP, AMQ, Data Grid 제안 불가)
  • 하도급/공동수급 불가: Red Hat이 협력사를 통해 참여하는 방식 불가 (COR-01)
  • 운영체제 현황: Windows 2008/2008 R2, ATL Linux, VMware vSphere 등 다양한 OS가 혼재하여 RHEL 단독 제안 범위 제한
Red Hat 제안
가능 요소
  • 기존 RHEL 서버 운영 확인: MPR-02 서버 목록에 DELL R740 "Red Hat 8.3(x64)" 전자결재 서버 1EA가 명시되어 있어, 유지관리 대상에 RHEL 시스템이 포함됨 → RHEL 구독 갱신 및 Extended Life Cycle Support(ELS) 제안 기회
  • RHEL 플랫폼 기반 보안SW 운영: MPR-03 보안장비 목록에 하우리 REDOWL SecuOS V5.6 (RHEL) 6EA가 명시되어 있어 RHEL이 보안 서버 플랫폼으로 운영 중
  • CentOS → RHEL 전환 제안 기회: DELL R740 백업마스터 서버가 CentOS 6.9(EOS 상태)로 운영 중이며, MPR-12/13에 OS 업그레이드 지원이 요구되므로 RHEL 전환 또는 RHEL 마이그레이션 어시스턴스 제안 가능
  • OS 업그레이드·패치 기술지원 요구: MPR-12(성능관리) "OS 버전 업그레이드, 패치, 커널, 환경설정값 수정" 및 MPR-13(구성관리) "재설치 시 운영체제 및 관련 S/W솔루션 포함 지원"이 명시되어 RHEL 유지관리 영역 존재
  • 차세대 VM 서버 대상: AIS PR750 VMware vSphere 8.3 "차세대 VM 서버" 2대가 유지관리 대상에 포함되어 있어, 향후 RHEV/OpenShift Virtualization으로의 전환 제안을 위한 레퍼런스 구축 기회
  • RFP 명시 Red Hat 제품명 요약:
    • DELL R740 Red Hat 8.3(x64) - 전자결재 서버 1EA (MPR-02)
    • 하우리 REDOWL SecuOS V5.6 (RHEL) - 서버보안 6EA (MPR-03)
