사업 개요 및 목적
  • 영상물등급위원회의 온라인등급분류시스템, 자체등급분류관리시스템, 대표홈페이지 등 정보시스템 전반을 2027~2028년(2개년) 동안 안정적으로 유지관리
  • H/W(서버, 스토리지, 네트워크, 보안장비 등) 및 S/W(DBMS, WAS, WEB, 보안SW 등) 운영 지원과 개발 인력 상주를 통한 응용시스템 유지보수 통합 수행
  • 정보보안(방화벽·웹방화벽·개인정보필터), 백업·복구, 웹접근성, 온라인 콘텐츠·뉴스레터 제작·발송 등 부가 운영 업무 포함
  • 정기 점검·SLA 관리 체계 수립을 통해 정보시스템 가용성 및 업무 연속성 확보

  • [콘텐츠·홍보] 뉴스레터 월 1회 제작·발송, 홈페이지 시각 콘텐츠 제작·게시, 웹접근성 품질인증 마크 획득(대표 홈페이지)

Red Hat 제안
불가능 요소
  • [Red Hat 상용 제품 미명시] RFP 전문에 RHEL, OpenShift, Ansible, JBoss EAP 등 Red Hat 상용 제품명이 단 한 건도 명시되어 있지 않음
  • [Oracle DBMS 확정] "Oracle DBMS PS(Premier Support) 증서 제출" 요구가 명시되어 있어 기존 DBMS가 Oracle로 확정된 상태. Oracle 생태계 기반 운영 환경
  • [S/W 목록 비공개] 행정안전부 고시 제17조에 의거 S/W 63~65식의 제품명·버전 정보가 RFP에서 전면 제외되어 기존 스택의 Red Hat 포함 여부 확인 불가 (사전 열람 신청 필요)
  • [신규 S/W 도입 최소화] 사업의 성격이 기존 시스템 유지관리 중심이며, 신규 S/W 구매 명시 항목은 NAS 라이선스, 테이프 백업 미디어에 한정됨
  • [중소기업 한정 입찰] 20억 미만 사업으로 대기업·중견기업 참여 제한 → Red Hat 코리아가 직접 입찰 불가, 파트너사를 통한 공급 필요
  • [경쟁·커뮤니티 제품 명시 없음] VMware, Ubuntu, Rocky Linux 등 경쟁 제품도 명시되지 않아 현 스택 교체 여지 판단 어려움
Red Hat 제안
가능 요소
  • [Linux OS 운영 환경] RFP 사업 범위에 "OS(AIX, Linux, Windows Server 등)"가 명시되어 있어, 기존 Linux 서버에 RHEL이 포함되어 있거나 향후 RHEL 제안 가능성이 존재
  • [S/W 목록 비공개 — 기존 RH 제품 포함 가능성] 유지관리 대상 S/W 63~65식의 목록이 비공개 처리되어 있어, 열람 신청을 통해 RHEL·JBoss EAP·Ansible 등 기 도입 Red Hat 제품 포함 여부 확인 필요. 포함 시 "높음" 재판정 가능
  • [클라우드·PaaS 기술 적용 검토] 기술적용계획표에 IaaS·PaaS·SaaS 항목이 모두 "적용" 또는 "검토" 대상으로 체크되어 있어, 향후 OpenShift 기반 컨테이너 플랫폼 전환 제안 여지 존재
  • [자동화·운영 효율화 니즈] H/W 82식, S/W 63~65식의 대규모 유지관리 환경에서 Ansible Automation Platform을 활용한 패치·형상관리 자동화 제안 가능
  • [보안 강화 니즈] 시큐어코딩, 웹취약점, 개인정보보호 등 강화된 보안 요구사항이 존재하여 Red Hat의 ACS(Advanced Cluster Security) 등 보안 솔루션 연계 제안 검토 가능
  • [RFP 명시 Red Hat 제품명·수량] 없음 — RFP 본문에 Red Hat(레드햇) 또는 동의어(RHEL, OCP, Ansible, JBoss, EAP 등)로 명시된 제품명 및 수량은 확인되지 않음
  • [영업 액션] 입찰 참가 전 S/W 열람 신청(보안서약서 제출 → 담당자 입회 열람)을 통해 기존 Red Hat 제품 포함 여부를 반드시 사전 확인할 것을 권장
