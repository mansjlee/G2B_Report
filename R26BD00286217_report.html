  • 이용료·관리비의 투명한 정산과 사업 종료 시 차기 사업자로의 무중단 인계 체계 마련

Red Hat 제안
불가능 요소
  • Red Hat 상용 제품 미명시: RFP 전체에 RHEL, OpenShift, JBoss EAP, Ansible 등 Red Hat 상용 제품명이 품목으로 단 한 건도 명시되지 않아, 판정 규칙상 '높음' 판정 불가
  • 경쟁 제품도 미명시: Ubuntu, Rocky Linux, Oracle Linux, VMware 등 경쟁·대체 OS/플랫폼이 확정 지정되지 않아 완전 배제 상황은 아님
  • MSP 특성상 S/W 선택 제약: 이 사업은 MSP(관리서비스) 중심으로, 응용SW(AI 솔루션)의 동작 환경과 호환되는 시스템SW를 제안사가 구성해야 함 → 응용SW 사업자가 이미 특정 OS·WAS 환경을 기반으로 구축한 경우 Red Hat 제품 채택이 제한될 수 있음
  • 국자원 PPP존 환경 제약: 국가정보자원관리원 대구센터 민관협력존 환경 내에서 국정원 도입요건 확인을 통과해야 하므로, 제품 도입에 추가 인증 절차 필요
  • 중소기업 입찰 제한: 대기업·중견기업 참여 제한 사업으로, Red Hat 코리아가 직접 입찰 불가하며 중소 MSP 파트너사를 통한 간접 영업만 가능
  • 실증 환경 인수 가능성: 2026년 말 기존 경량 실증 환경(PPP존)을 인수하는 경우, 기 구축된 OS·플랫폼 환경이 고정될 수 있어 Red Hat 신규 도입 여지 축소 가능
Red Hat 제안
가능 요소
  • 운영체제(OS) 20개 미지정 → RHEL 제안 가능: 서버용 OS가 브랜드 지정 없이 20개 명시됨. GPU 서버 6대 포함 전 VM에 RHEL 제안 가능. 국가 보안기준 준수, 국정원 검증·CC인증 등 공공 보안 요건 충족에 RHEL의 강점이 유효함
  • WEB/WAS 2개 미지정 → JBoss EAP 제안 가능: WEB/WAS가 2개 명시되었으나 특정 제품 미지정. JBoss EAP(Red Hat 상용 WAS)를 제안할 수 있으며, 전자정부 표준프레임워크 호환 환경에서도 활용 가능
  • 컨테이너 플랫폼 관리 요구사항 → OpenShift / Podman 제안 가능: AIR-001에서 "GPU 런타임·컨테이너 플랫폼"을 설치·운영·버전 관리하도록 명시. OpenShift Container Platform(OCP) 또는 Podman 기반 컨테이너 운영 환경을 제안할 수 있음
  • GPU 기반 AI 인프라 → OpenShift AI / RHEL AI 제안 여지: GPU 서버(H100급 6대) 기반 생성형 AI 추론·학습 환경 구축 필요. OpenShift AI 또는 RHEL AI 플랫폼을 AI 인프라 운영 솔루션으로 제안 가능
  • 자동화 요구사항 → Ansible Automation Platform(AAP) 제안 여지: 변경 및 구성관리(CMR-004), 보안패치 적기 적용(SER-007), 다수 VM·인프라 자원 관리 등 자동화 수요가 높아 Ansible 기반 운영 자동화 제안 가능
  • 벡터 DB·그래프 DB 포함 DBMS 6개 미지정: DBMS 6개(관계형·벡터·그래프) 중 관계형 DB에 Red Hat Data Grid 또는 연계 솔루션 제안 검토 가능
  • 국가 보안기준 준수 요구: N2SF, 국가 클라우드 컴퓨팅 보안 가이드라인, 국정원 검증필 암호모듈 탑재 요구 → 공공 보안 인증 경험이 풍부한 RHEL 및 OpenShift의 강점과 일치
  • 파트너 영업 전략: 중소 MSP 파트너사(입찰 자격 보유)를 통해 RHEL·OCP·JBoss EAP·AAP 등을 시스템SW 구성 요소로 채택하도록 사전 기술 제안 및 파트너 지원 활동 필요
  • RFP 내 Red Hat(또는 동의어) 명시 제품명·수량: 없음 (Red Hat 상용 제품이 품목으로 직접 명시된 사례 없음)
