사업 개요 및 목적

  • 재난 발생 대비 24시간 연중 무중단 가동 보장, 장애 발생 시 신속한 원상 복구 및 전문적 유지관리 수행
  • H/W 및 S/W 유지보수, 자동기상관측장비(AWS), 재난감시CCTV, 경기도 스마트 영상센터, 시·군(31개) 연계 서버 등 종합적 운영·유지관리 용역

Red Hat 제안
불가능 요소
  • 신규 S/W 납품·구독 품목 없음: 본 사업은 순수 유지관리 용역으로 Red Hat 상용 제품의 신규 도입·납품·구독 갱신 항목이 명시되어 있지 않음
  • Red Hat 상용 제품명 미명시: 유지보수 대상 S/W 목록에 RHEL, OpenShift, Ansible, JBoss EAP 등 Red Hat 상용 제품명이 직접적으로 기재되어 있지 않음
  • 경쟁 가상화 제품 명시: vSphere 7 STD (VMware)가 유지보수 대상 S/W로 명시되어 있어 해당 가상화 영역에서 Red Hat 제품 제안 불가
  • OS 종류 미지정 (리눅스 계열 일반 언급): 상황실 서버보안 S/W 항목에 "리눅스 호환"이라고만 기재되어 있으며, 특정 Red Hat 상용 제품명은 없음
  • 사업 규모 제한: 20억 원 미만 사업으로 대기업 소프트웨어사업자 참여 제한 → Red Hat Korea 직접 입찰 불가, 파트너사를 통한 간접 참여만 가능
  • JBoss/WildFly 미언급: WAS 관련 Red Hat 제품(JBoss EAP 등)이 유지보수 대상에 전혀 명시되지 않음
Red Hat 제안
가능 요소
  • Linux 운영 환경 존재: 유지보수 대상 중 "상황실 서버보안 S/W (리눅스 호환)" 7식이 명시되어 있어 Linux 기반 서버 운영 환경이 확인됨 → RHEL 제안 가능성 존재
  • RD114 장비에 Linux OS 명시: 유지보수 대상 H/W 중 RD114 (PC가상HDD, 10G Link) 장비 사양에 "Os(Linux)"가 기재되어 있어 리눅스 계열 OS 운영 환경 존재 확인
  • 서버 인프라 다수 존재: 스마트도시안전망 서버, 영상통합 중계서버, 영상중계 서버(RTSP), 경찰청 스트리밍서버, 보안정책서버 등 고성능 서버 다수 운영 중 → 향후 OS 갱신 또는 교체 시 RHEL 제안 기회
  • OS 미지정 서버 운영 환경: H/W 장비 목록 내 다수 서버의 OS가 명시되지 않아 Linux 계열 OS(RHEL 등) 운영 가능성 있음
  • 기술적용계획표 내 Linux 명시: 플랫폼 및 기반구조 분야 세부 기술 지침에 운영체제로 "Linux" 적용 계획이 명시되어 있어 Linux 기반 환경이 사업 범위 내에 포함됨
  • Ansible 자동화 제안 여지: 다수의 현장 장비(AWS 66개소, CCTV 현장 장비 100개소 이상, 시·군 서버 31개) 운영 관리 자동화 필요성 존재 → Ansible Automation Platform 제안 가능
  • RFP 내 Red Hat 명시 제품·수량: 없음 (Red Hat 상용 제품명 직접 기재 없음)
