  • 원활한 교통소통 및 교통안전 증진, 시민에게 신뢰성 있는 교통정보 제공이 목적
  • 전문인력 18명 상주 및 Help Desk 운영, 장애 예방·조치, 기술지원, 사용자교육 포함

Red Hat 제안
불가능 요소
  • S/W 신규 납품 항목 없음: 본 사업은 순수 유지관리·운영 용역으로, 신규 S/W 구매·납품·구독 항목이 별도로 없음. 기존 운영 중인 S/W 유지관리가 핵심 목적
  • Red Hat 상용 제품명 미명시: RFP 전반에 걸쳐 RHEL, OpenShift, Ansible, JBoss EAP 등 Red Hat 상용 제품명이 유지관리 대상 목록에 명시되지 않음
  • 경쟁 가상화 제품 명시: VMware vSphere 7 Standard (2 EA), 이노그리드 Cloudit V5 (2 EA) 등 경쟁 가상화 솔루션이 현행 운영 환경으로 명시되어 있음
  • WAS 경쟁 제품 명시: 티맥스소프트 JEUS, WebToB가 현행 WAS·웹서버로 명시되어 있어 JBoss EAP 등 Red Hat WAS 제안 여지가 제한적
  • DBMS는 Oracle로 고정: Oracle Database EE, Oracle Exadata 등 Oracle DBMS가 현행 운영 환경으로 명시되어 있음
  • 백업 S/W 경쟁 제품 명시: Quest Rapid Recovery Enterprise가 현행 백업 솔루션으로 명시되어 있음
  • JBoss 미명시: WAS는 JEUS/WebToB(티맥스소프트) 기반으로 운영 중이며, JBoss(WAS) 항목이 유지관리 대상에 포함되어 있지 않음
Red Hat 제안
가능 요소
  • 서버 OS 미지정: 유지관리 대상 서버 목록(HP DL380, Fujitsu RX2540 등 80종 114대)에 운영체제(OS)가 명시되지 않음. 기술적용계획표에 "Linux ○ (적용)" 항목이 있어 Linux 계열 OS가 운영 중임을 시사하며, RHEL 제안 여지 존재
  • Linux 운영 환경 확인: 기술적용계획표 플랫폼·기반구조 분야에서 서버용 운영체제로 UNIX, Windows Server, Linux 모두 "적용(○)" 표시 — Linux 서버가 현행 인프라에 포함되어 있음을 시사
  • Watchall 에이전트에 Linux/Unix 명시: "Agent for WIN/Linux 5~8Core", "Agent for Unix 5~8Core" 등 Linux·Unix 서버가 운영 중임을 간접 확인 가능. 해당 Linux 서버의 OS 상용 구독(RHEL) 갱신·전환 가능성 존재
  • 컨테이너·가상화 환경: C-ITS 시스템에 가상화 서버(3Score SR285K2-v7 4대), 가상화 스토리지, Cloudit 가상화 솔루션 등이 존재하여, 향후 컨테이너 플랫폼(OpenShift) 또는 RHEL 기반 전환 제안 가능
  • 오픈소스 보안 관리 요구: 기술적용계획표 보안 분야에 "오픈소스 적용 기능 및 리스트 제공 ○" 항목이 있어 오픈소스 기반 솔루션 도입·관리 논의 여지 존재
  • RFP에 명시된 Red Hat(동의어 포함) 제품명·수량: 없음 (Red Hat 상용 제품명은 RFP 어디에도 명시되지 않음)
  • 영업 접근 전략 제안: 현재 운영 중인 Linux 서버의 OS 종류(CentOS, RHEL 등) 파악 후 RHEL 구독 갱신·전환 기회를 담당자(이정현, 052-229-4273)에게 별도 접촉하여 발굴 필요. 본 용역 수행 업체를 통한 간접 채널 활용도 고려
