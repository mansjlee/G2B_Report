사업 개요 및 목적
  • 지속적으로 증가하는 초·중등 이주배경학생의 학교 초기 진입 및 교과 학습 지원을 위해, 현재 PC 웹 중심으로 운영 중인 모두의 한국어 시스템을 모바일 웹 기반으로 확장하는 사업
  • 스마트폰·태블릿 등 다양한 기기에서 안정적으로 한국어 학습 서비스를 이용할 수 있는 환경 구축
  • 기존 PC 웹 서비스와 모바일 웹 간 연계성을 확보하여 교사·학생·학부모·일반 사용자 유형별 서비스 이용 편의성 및 접근성 제고
  • 현재 1,950차시 분량의 학습 콘텐츠(모두를 위한 한국어, 문법쑥쑥, 어휘쑥쑥, 예비과정)를 모바일 환경에 최적화하여 재개발
  • 모바일 웹 시범운영을 통해 현장 적합성을 검증하고 서비스 완성도를 제고하는 것이 핵심 목표

Red Hat 제안
불가능 요소
  • 순수 개발 용역 사업으로 S/W 납품·구독 항목 없음: RFP 법제도 준수여부 정리표에 "상용SW 직접구매 및 SW품질성능 평가시험(BMT): 해당 없음"이 명시되어 있어, 어떠한 상용 소프트웨어도 구매 대상이 아님
  • Red Hat 상용 제품명 전혀 미언급: RFP 전체를 통틀어 RHEL, OpenShift, Ansible, JBoss EAP, AAP 등 Red Hat 상용 제품 또는 동의어가 단 한 건도 언급되지 않음
  • 클라우드 인프라는 별도 사업단 운영: 클라우드 운영 사업단이 이미 구성되어 인프라를 별도로 운영하고 있으며, 본 사업은 개발 환경만 사업자가 자체 구축(비용 부담)하고 완료 시 기존 운영 환경에 이관하는 방식으로 인프라 납품 기회 없음
  • 기존 시스템과의 기술 연속성 요구: "기존 시스템과 동일한 기술 표준을 우선 적용"하도록 명시(COR-001)되어 있어, 기존 전자정부 표준프레임워크(Java) 기반 유지가 우선되며 새로운 플랫폼 도입 가능성 희박
  • 경쟁 제품 미명시: VMware, Ubuntu, Rocky Linux 등 경쟁 제품이 명시되지는 않았으나, 이와 무관하게 SW 납품 자체가 없으므로 Red Hat 도입 기회가 없음
Red Hat 제안
가능 요소
  • 클라우드 환경 기반 개발 언급: 사업 전반이 클라우드 환경(IaaS/PaaS/SaaS 기술 지침 적용표 포함)을 기반으로 하나, 클라우드 플랫폼이 미지정 상태임. 이론적으로는 OpenShift 등의 제안 여지가 있으나, 별도 클라우드 운영 사업단이 이미 인프라를 운영 중이므로 실질적 기회는 없음
  • Linux 서버 환경 가능성: 기술적용계획표에 Linux 운영체제가 적용 항목으로 포함되어 있으나, OS 지정이 없고 별도 인프라 납품 항목도 없으므로 RHEL 제안 기회 없음
  • 전자정부 표준프레임워크(Java) 기반: Java 기반 개발로 이론적으로는 JBoss EAP 제안 여지가 있으나, RFP에 WAS 관련 상용 SW 납품 항목이 명시되지 않았으며 기존 유지관리 사업자가 운영 중인 환경을 그대로 활용하도록 제약
  • RFP 내 Red Hat 제품명·수량: 없음. RFP 전문에서 Red Hat(레드햇) 또는 동의어(RHEL, OpenShift, Ansible, JBoss, EAP, OCP 등) 관련 제품명·수량이 단 한 건도 확인되지 않음.
  • 종합 평가: 클라우드·Linux·Java 환경이라는 기술적 배경은 존재하나, 본 사업은 순수 SW 개발 용역으로서 S/W 납품·구독 항목이 전혀 없어 Red Hat 제품 제안 가능성은 사실상 없음
