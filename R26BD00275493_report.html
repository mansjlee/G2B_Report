Red Hat 제안
불가능 요소
  • 순수 유지관리·운영지원 용역으로 신규 SW 납품·구독 항목 없음: 본 사업은 기존 인프라 유지관리 용역이며, RFP 어디에도 신규 SW 구매·도입·증설 발주 항목이 존재하지 않음
  • VMware 제품 명시: 기존 SW 목록에 vSAN 7 (가상SAN스토리지 SW, 1식) 및 Horizon 600CCU & Vdcops (망분리 유틸리티 SW, 1식)가 명시되어 있어 가상화 환경이 VMware로 고정됨
  • Windows Server 다수 명시: Windows Server Std 2019 OLP 16Lic가 외부DNS, 내부DNS, 형상관리&NTP, 알약ASM, CQ자격검정 채점/문제관리 등 총 6건 이상 명시
  • Oracle DBMS 및 Tibero 명시: Oracle Programmer Named User Plus (1식), Tibero7 Enterprise (1식)가 DB 플랫폼으로 확정 운용 중
  • Red Hat 상용 제품(RHEL, OpenShift, Ansible, JBoss EAP 등) 전혀 언급 없음: 66종 SW 목록 및 전체 RFP 문서 내 Red Hat 관련 제품명이 단 하나도 등장하지 않음
  • 중소기업 입찰 제한 사업: 20억원 미만 사업으로 대기업·중견기업 참여 불가. Red Hat Korea가 직접 입찰하거나 파트너를 통한 납품 기회 구조 자체가 없음
Red Hat 제안
가능 요소
  • RFP 내 Red Hat 상용 제품명 명시 없음: RHEL, OpenShift, Ansible, JBoss EAP, Satellite, Quay 등 Red Hat 상용 제품은 전혀 언급되지 않아 직접적인 제안 기회는 없음
  • 클라우드 운영 환경의 잠재적 전환 여지 (간접 기회): NHN 클라우드 및 네이버 클라우드 기반 시스템 운영 중이며, RFP에서 "민간 클라우드 OS 전환 계획 수립" 언급 — 향후 별도 사업에서 RHEL 또는 OpenShift 전환 제안 가능성
  • CI/CD 체계 구축 요건 (PSR-003): "최소한의 인력에 의해 시스템이 관리·운영될 수 있도록 자동화를 고려하여 CI/CD 체계를 구축 운영해야 함" — 차기 사업에서 Ansible Automation Platform(AAP) 또는 OpenShift 제안 씨앗 가능성
  • 서버 OS 환경 불명확: 64종 서버 장비 중 OS가 명시되지 않은 서버 다수 존재. 현재 Linux 계열 운영 중일 가능성이 있으나 본 RFP에서 확인 불가
  • 종합 평가: 현재 사업 범위 내에서 Red Hat 제품의 신규 도입·납품 기회는 없으며, 유지관리 사업자를 통한 간접 접근도 구조적으로 어려움. 본 사업 담당자(AI디지털심화팀) 접점 유지를 통해 차기 인프라 고도화 사업 발굴에 집중하는 것이 현실적 전략
