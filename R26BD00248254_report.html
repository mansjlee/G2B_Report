Red Hat 제안
가능 요소
  • OpenShift(제한적): SFR-1에서 Docker·Kubernetes 등 컨테이너 기반 실행 환경 요구—추가 제안(PSR-2)으로 OpenShift 기반 AI 서비스 오케스트레이션·GPU 워크로드 관리 제시 가능하나 Ubuntu OS 명시와 충돌 가능
  • Ansible(부분): 다중 서버·RAG 파이프라인·배포 자동화, LLMOps 운영 자동화를 Ansible Automation Platform으로 보조 제안 가능(필수 요구사항 아님)
  • RHEL(대체 제안 한계): “리눅스 계열 OS” 및 Linux 일반 요구는 있으나 Ubuntu 22.x가 서버 최소 규격으로 고정되어 RHEL 직접 대체는 난이도 높음
  • Red Hat AI/OpenShift AI: 생성형 AI·LLM 서빙·MLOps 영역에서 추가 제안·레퍼런스 제시는 가능하나, RFP는 오픈소스 LLM·자체 LLMOps 플랫폼 구축을 전제로 하여 Red Hat AI 단독 납품형 제안은 부적합
  • 종합: Red Hat은 SI 파트너·하위 레이어(컨테이너·자동화) 추가 제안 수준에 그치며, 핵심 과업·평가·명시 S/W 납품 범위에서 직접 수주 가능성은 낮음
