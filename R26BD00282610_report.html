Red Hat 제안
불가능 요소
  • [순수 유지보수 용역] 본 사업은 기존 설치 시스템의 유지보수·점검·인력 상주를 목적으로 하며, 신규 S/W 납품·구독 품목이 별도로 명시되지 않은 서비스 용역임
  • [Red Hat 상용 제품 구매 품목 미명시] RHEL, OpenShift, Ansible, JBoss EAP 등 Red Hat 상용 제품이 도입·납품·증설 품목으로 명시되지 않음
  • [기존 시스템 고정] 유지보수 대상 시스템이 이미 확정된 상태로, 새로운 플랫폼 도입보다 현 시스템 안정 운영이 최우선인 사업 구조
  • [경쟁·대체 솔루션 다수 존재] 기존 환경에 MS Windows Server 2012, 시큐아이 BLUEMAX NGF, 모니터랩 WIWAF 등 타 벤더 제품이 다수 운영 중
  • [공동수급·하도급 불허] 단독 수행만 가능하여 Red Hat이 직접 입찰하거나 파트너와 공동 접근하기 어려운 구조
  • [임베디드 리눅스 명시] 방송수신기에 "임베디드 리눅스" 사용으로 RHEL 전환 가능성 낮음
Red Hat 제안
가능 요소
  • [RHEL 7 운영 환경 확인] 유지보수 대상 목록 중 "시큐브 Secuve TOS V5.0 for RHEL 7, 1~3CPU 서버보안솔루션 조 8"이 명시되어 있어, 현재 환경에 RHEL 7 서버가 최소 8세트 운영 중임이 확인됨
  • [RHEL 7 EOS 갱신 제안 가능] RHEL 7은 Maintenance Support 2 종료(2024년 6월) 이후 Extended Life Cycle Support(ELS)로 전환됨. 기존 RHEL 7 구독의 갱신 또는 RHEL 8/9로의 업그레이드를 파트너 채널을 통해 제안할 수 있는 여지가 있음
  • [다수 서버 인프라 운영] 통합관제시스템, 스마트시티 통합플랫폼 등에 다수의 서버(Dell PowerEdge R740, Uniswide RC218-P2 등)가 운영 중으로, 향후 OS 갱신·업그레이드 시 RHEL 제안 기회 발생 가능
  • [보안·자동화 솔루션 제안 여지] 서버 보안(Secuve TOS), 패스워드 관리, 백신 등 보안 솔루션이 다수 운영 중으로, Red Hat의 Ansible Automation Platform을 통한 보안 자동화(패치 관리, 컴플라이언스 자동화) 제안 가능성 있음
  • [RFP 내 Red Hat 제품명 직접 명시 현황]
    • "Secuve TOS V5.0, for RHEL 7" → RHEL 7이 기존 플랫폼으로 운영 중임을 간접 확인 (상용 구독 품목으로 별도 명시되지는 않음)
  • [차기 사업 연계] 유지보수 중 시스템 노후화·RHEL 7 EOS 이슈 발굴 시 차기연도 인프라 현대화 사업 연계 영업 가능
