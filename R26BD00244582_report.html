불가능 요소
  • S/W 공급 미포함: 본 사업은 정보보호 전문서비스 컨설팅·진단·교육 용역으로, RHEL·OpenShift·Ansible 등 Red Hat 제품의 구매·공급·구축이 과업 범위에 포함되지 않음
  • 경쟁/타사 제품 미명시: VMware, Contrabass, Ubuntu, Oracle/Rocky Linux 등 특정 OS·가상화·클라우드 플랫폼이 지정되어 있지 않으나, Red Hat 제품 제안 대상 자체가 아님
  • 하도급 불허: 산출물 품질 저하 예방을 위해 하도급을 허용하지 않으며, Red Hat이 직접 컨설팅 수행 주체가 될 수 없음(정보보호 전문서비스 기업 자격 필요)
  • 진단도구 제약: 소스코드 진단 시 국가보안기술연구소 인증 보안약점 진단도구 사용 의무 — Red Hat 전용 진단도구가 요구사항으로 명시되지 않음
  • 계약 성격: 기술평가 90%·컨설팅 방법론·수행실적 중심 평가로, 인프라 S/W 라이선스·구독 판매와 무관한 순수 용역 사업
Red Hat 제안
가능 요소
  • 간접적 기회(매우 제한적): 서버 181대·DBMS 15대·WAS 54대 등 대규모 인프라 취약점 진단 과정에서 Linux/RHEL 기반 서버가 진단 대상에 포함될 경우, 진단 결과 개선 권고안에 RHEL 보안 강화·패치 관리 Best Practice를 간접 제안할 여지는 있으나 본 RFP상 필수 요구사항은 아님

  • 파트너 협력 가능성: Red Hat은 정보보호 전문서비스 기업(1542)과 파트너십을 통해 해당 컨설팅 업체 제안서에 RHEL/OpenShift/Ansible 보안 아키텍처·컴플라이언스( ISMS-P, KISA 가이드) 연계 방안을 서브 제안 형태로 지원하는 간접 영업 접근만 가능
