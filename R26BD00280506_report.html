Red Hat 제안
불가능 요소
  • Red Hat 상용 제품명 미명시: RFP 전문에 RHEL, OpenShift, Ansible, JBoss EAP, Satellite 등 Red Hat 상용 제품명이 구매·납품 품목으로 명시되지 않음
  • 운영유지관리 성격의 사업: 신규 SW 도입·납품 중심이 아닌 기존 시스템(NCP 클라우드) 유지관리·운영 용역 사업으로, 별도 상용 OS나 플랫폼 SW 구매 항목이 명확하지 않음
  • 클라우드 종속 환경: NCP(네이버 클라우드 플랫폼) 기반으로 이미 구성된 인프라를 그대로 운영하는 방식이므로, OS·플랫폼 교체 또는 신규 도입 여지가 제한적임
  • 경쟁 제품 명시 없음 (불가능 요소는 없으나 적극 기회도 제한): VMware, Ubuntu, Oracle Linux, Rocky Linux 등 명시적 경쟁 제품은 없으나, 기존 인프라 유지 중심이어서 전환 기회도 낮음
  • 하도급 불허: 본 사업은 하도급을 불허하므로 Red Hat이 파트너사를 통해 SW를 공급하는 방식에 제약이 있음
  • 20억원 미만 중소기업 제한 사업: 상호출자제한기업집단 소속 및 대기업·중견기업의 입찰 참여가 제한되어 Red Hat 직접 참여 불가
Red Hat 제안
가능 요소
  • 쿠버네티스(Kubernetes) 컨테이너 환경 운영 명시: RFP에 "쿠버네티스 서버 2식(컨테이너)" 운영이 명시되어 있으며, Red Hat OpenShift Container Platform(OCP)은 엔터프라이즈 쿠버네티스의 대표 솔루션으로 제안 여지 존재
  • Linux 운영체제 기반 시스템: 기술적용계획표에 "Linux O(적용)"이 명시되어 RHEL 제안 가능성 있음. 현재 운영 중인 Linux 배포판이 CentOS 등 커뮤니티 버전일 경우 RHEL 전환 제안 기회
  • 멀티클라우드 운영 지원: NCP + GPUaaS(H100) 멀티클라우드 환경에서 Ansible Automation Platform(AAP)을 통한 자동화·구성 관리 제안 가능
  • AI/ML 인프라 운영: LLM 모델 서빙, RAG 엔진 운영 환경에서 Red Hat OpenShift AI(RHEL AI) 적용 제안 여지 존재
  • MCP·API 보안 및 접근제어 관리: OAuth, API Key 기반 인증 관리, AI 에이전트 접근제어 요구사항에 Red Hat SSO(Keycloak 상용) 제안 가능
  • RFP 내 Red Hat 제품명 직접 명시 없음: RHEL, OpenShift, Ansible, JBoss EAP, Satellite 등 Red Hat 상용 제품명은 RFP 전문에서 발견되지 않음
  • 영업 접근 전략 제안: 수행사(SI)를 통한 간접 제안 루트를 활용하여, 현행 쿠버네티스 환경을 OCP로 전환하거나 Linux 인프라를 RHEL로 표준화하는 방향으로 어카운트 영업 접근 권고
