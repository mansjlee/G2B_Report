사업 개요 및 목적
  • 우정사업본부의 노후화된 통합경영관리(ERP)시스템을 국가정보자원관리원(국정자원) G-클라우드 환경으로 전환·재구축하는 사업
  • 기획예산처의 新국가결산체계(CoA) 개편에 대응하여 국가회계 결산체계를 개편하고 재무제표 산출 기반 마련
  • 별도 운영 중이던 ERP, HRM(인적자원관리), 도면관리시스템을 단일 클라우드 기반 통합 체계로 구축
  • 범정부 AI 공통기반을 활용한 ERP 데이터 자연어 조회 시범 체계 마련
  • 개인정보 접속기록 모니터링, 메타시스템 등 신규 솔루션을 통한 법적·제도적 이슈 대응

Red Hat 제안
불가능 요소
  • Oracle EBS 명시 재활용: 회계관리 SW로 Oracle EBS가 명시적으로 지정되어 있어 핵심 미들웨어 스택을 Oracle이 점유 중
  • 인프라 SW 국정자원 제공: HW, 시스템SW(OS 포함), DBMS, 네트워크 등 기반 인프라 전체를 국정자원이 제공하므로, 본 사업에서 OS·시스템SW를 별도 구매하거나 지정하는 항목 없음
  • Red Hat 상용 제품 미명시: RFP 전반에 걸쳐 RHEL, OpenShift, Ansible, JBoss EAP 등 Red Hat 상용 제품명이 품목으로 명시되지 않음
  • 통합발주 SW 제한적: 통합발주 대상 SW 4종 모두 기존 솔루션 업그레이드·이관으로, 신규 Red Hat 제품 진입 포지션 없음
  • 직접구매 SW도 RH 무관: 조달쇼핑몰 직접구매 3종(개인정보접속기록, 메타시스템, DB암호화)은 Red Hat 제품군과 무관한 보안·데이터 관리 솔루션
Red Hat 제안
가능 요소
  • 클라우드 OS 미지정 → RHEL 제안 여지: 국정자원 G-클라우드의 가상서버 OS가 RFP에 명시되지 않아, 사업 수행사(통합사업자)가 국정자원과의 협의 과정에서 RHEL 기반 VM 환경을 제안할 수 있음
  • Java 기반 애플리케이션 서버 → JBoss EAP 제안 여지: 전자정부 표준프레임워크(Java 기반) 적용이 명시되어 있고, WAS 증설 라이선스가 포함된 구조이므로 JBoss EAP를 WAS로 제안할 수 있는 여지 존재
  • 형상관리 SW 이관 → GitLab on RHEL 연계 가능: 형상관리 SW가 클라우드 이관 대상이며 제품명이 미지정이어서, 사업 분석·설계 단계에서 RHEL 기반 환경 위에서의 구성 제안 가능
  • 자동화·운영 효율화 → Ansible 제안 여지: 클라우드 전환 및 다수 상용SW 설치·구성·검증 작업이 포함되어 있어, 배포 자동화 목적의 Ansible Automation Platform 제안 가능성 존재
  • 컨테이너/PaaS 기술 명시: 기술적용계획표에 PaaS, IaaS 항목이 적용 대상으로 포함되어 있어 OpenShift 기반 컨테이너 플랫폼 제안 여지 있음
  • RFP 내 Red Hat(동의어) 제품 명시 없음: 문서 전반에 Red Hat 상용 제품명은 명시되지 않았으나, 위에서 언급한 기술 스택 요건에서의 제안 가능성은 유효
