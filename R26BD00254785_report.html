사업 개요 및 목적
  • 한국천문연구원이 2020년부터 수행 중인 GNSS 기반 동아시아 전리권 변화감시 연구 성과를 바탕으로, 일간 전리권 자료 후처리 결과(TEC, ROTI) 및 신틸레이션 정보를 연구기관·연구자에게 대외 제공하는 웹기반 정보서비스를 구축하는 소프트웨어 개발 용역이다.
  • 기존 자료처리 현황 모니터링 기능을 확대·보강하고, 데이터 검색·다운로드, DB 구축·유지관리, 백엔드 자료 동기화 자동화를 통해 연구활용 가치와 수요자 접근성을 높이는 것이 핵심 목표이다.

불가능 요소
  • S/W 공급 미포함: 사업 유형이 「동아시아 GNSS 전리권 정보 웹서비스 개발」 소프트웨어 개발·구축 용역이며, Red Hat 제품 등 인프라 S/W 납품·라이선스 구매가 과업 범위에 포함되지 않음.
  • 경쟁/대체 OS 명시: 자료처리·정보제공 서버 운영환경으로 CentOS Linux 7(Core)이 현행 및 기준 환경으로 명시되어 RHEL/Rocky 등 Red Hat 계열 직접 지정 없음.
  • DB·미들웨어 고정: PostgreSQL DB 사용, WAS·WEB는 Tomcat·Apache(비활성)로 기술되어 JBoss EAP 등 Red Hat 미들웨어 요구 없음.
  • 개발 프레임워크 제약: eGovFramework 4.0+ 필수 적용 및 기술평가 배점(10점) 반영으로 전자정부 Java 웹 개발 스택이 핵심이며 OpenShift·Ansible 등 Red Hat 플랫폼 요구 없음.
  • 사업 규모·참가자격: 예산 5,500만원·150일의 소규모 개발 사업, 중소 SW사업자 전용·대기업 참여 제한으로 Red Hat 직접 수주 구조에 부적합.
Red Hat 제안
가능 요소
  • 제한적 OS 현대화 논의: PER-001에서 성능 최적화를 위해 필요 시 운영체제 업데이트 수행을 요구하나, CentOS 7 EOL 대응 관점에서 RHEL/RHEL-like 마이그레이션을 비과업·부가 제안 수준으로만 언급 가능(명시 요구 아님).
  • 자동화·운영: SFR-006 백엔드 데이터 동기화·스케줄링·대용량 처리 요구는 Ansible Automation Platform으로 운영 자동화 시나리오를 제안사(수행업체) 경유 간접 제안 가능하나 RFP에 명시되지 않음.
  • Linux 기반 호환성: POSIX/Linux 기반 서버 환경으로 RHEL은 기술 호환 가능하나, 발주처가 CentOS 7·PostgreSQL·eGovFramework 조합을 전제로 하여 Red Hat 직접 납품 기회는 극히 제한적.
  • 파트너 연계: 입찰 참가는 중소 SW개발사가 주도하므로, Red Hat은 해당 SI 파트너의 하위 기술지원·OS·자동화 라이선스 공급 파트너 채널로만 간접 기회 존재.
