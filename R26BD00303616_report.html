사업 개요 및 목적

  • 창업지원자, 멘토, 운영기관(허브기관·멘토기관·전담기관) 간 전(全) 주기 창업 지원을 단일 통합 플랫폼에서 처리할 수 있도록 기능 확대
  • 기존 플랫폼의 보안 취약점 보완, 아키텍처 개선, AI 기반 아이디어 검증, 커뮤니티 고도화, 운영관리시스템 통합 등을 목표로 함
  • 「행정기관 및 공공기관 정보시스템 구축·운영 지침(행정안전부고시 제2025-1호)」에 따른 보안성 검토·사전협의·감리·개인정보 영향평가 등 법정 절차 이행

불가능 요소
  • S/W 납품·구독 항목 없음: RFP 전체에 상용 S/W 구매 목록이 없으며, 하드웨어·소프트웨어 통합발주 품목도 명시되지 않은 순수 소프트웨어 개발 용역 사업임
  • Red Hat 제품명 전혀 미명시: RHEL, OpenShift, Ansible, JBoss EAP, Satellite 등 Red Hat 상용 제품명이 RFP 어디에도 등장하지 않음
  • 경쟁 제품 명시 없음(단, RH도 없음): Ubuntu, Rocky Linux, Oracle Linux 등 경쟁 OS가 직접 명시되지는 않았으나, OS·미들웨어·플랫폼 모두 미확정 상태이며 발주기관이 사업자에게 기술 선택을 위임함
  • 기존 운영 환경에 Red Hat 제품 미확인: 현행 시스템 구성 설명 중 "클라우드 기반"으로만 언급되며, Linux 계열 여부조차 명시되지 않음. 정확한 Red Hat 제품명(RHEL, JBoss EAP 등) 기재 없음
  • 공개SW 목록 없음: JBoss, WildFly, CentOS 등 커뮤니티·공개SW 목록도 존재하지 않음
  • 하도급·공동수급 불허: Red Hat이 SI 파트너를 통해 간접 참여하는 구조조차 제한됨 (PMR-09, 기타사항 참조)
  • 20억 미만 중소기업 제한 사업: 대기업·중견기업 참여 불가로 Red Hat 직접 입찰 불가

가능 요소
  • RFP에 명시된 Red Hat 상용 제품명·수량: 없음 (0건)
  • 클라우드 네이티브 아키텍처 지향: ACR-01에서 "향후 클라우드 네이티브 접목을 위해 접근성, 탄력적인 자원관리, 고가용성, 신속한 배포 등의 장점을 최대한 활용할 수 있도록 아키텍처 구성"을 요구하고 있어, 이론적으로 OpenShift 기반 컨테이너 플랫폼 제안 여지가 있으나, 사업자 선택 사항에 불과함
  • Linux 운영체제 적용 가능성: 기술적용계획표(붙임7)에 "Linux"가 서버용 운영체제 항목으로 기재되어 있으나, 특정 배포판 미확정이며 RHEL 제안 가능성이 존재하나 사업자 재량임
  • Auto Scaling·Load Balancing 요구: PER-02에서 클라우드 환경의 자동 확장 및 부하 분산을 요구하여 OpenShift/Kubernetes 기반 인프라 적합성이 있으나, 이를 의무화하는 조항 없음
  • 종합 평가: 위 요소들은 모두 사업자 재량 또는 기술 제안 선택 사항에 해당하며, Red Hat 상용 제품 도입이 확정·명시된 항목은 전혀 없음. 판정 규칙상 "S/W 납품·구독 항목 없는 순수 용역"에 해당하여 낮음으로 판정함
