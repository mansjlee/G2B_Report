  • S/W 납품·구독 항목 없음: 본 사업은 순수 운영·유지관리 용역으로 상용 S/W 신규 도입·납품·구독 갱신 품목이 전혀 없음

  • 경쟁 제품 미명시이나 RH 스택 적용 여지 제한: 운영 환경이 NginX, Tomcat, MySQL, PostgreSQL 등 오픈소스 기반으로 구성되어 있으며, RHEL이나 OpenShift 도입에 대한 언급 없음
  • 오픈소스 우선 정책: 동영상 인코딩 환경 구축 시 "상용 라이선스 비용이 발생하지 않도록 오픈소스 SW를 활용" 명시 → 상용 Red Hat 제품 도입 제약
  • 중소기업 전용 입찰: 20억 미만 사업으로 대기업·중견기업 참여 제한, Red Hat이 직접 입찰하기 어려운 구조 (그러나 이 자체가 낮음 판정 이유는 아님)
  • 클라우드 인프라 별도 사업자: 인프라(클라우드) 운영은 별도의 클라우드 임차 사업자가 담당하여 본 사업에서 인프라 S/W 제안 범위 없음
Red Hat 제안
가능 요소
  • RFP 내 Red Hat 상용 제품 명시 없음: RHEL, OpenShift, Ansible, JBoss EAP 등 Red Hat 상용 제품이 도입·납품·유지보수 대상으로 명시된 사례 없음
  • Linux 계열 운영환경 언급: 기술적용계획표에 "Linux" 운영체제가 서버용 개방형 OS 항목에 포함되어 있으나, 특정 배포판(RHEL 등)이 지정되지 않아 제안 여지가 원칙적으로 존재할 수 있음 — 단, 신규 S/W 납품 항목이 없는 용역 사업이므로 실질적 기회 없음
  • Spring Boot/JDK/Tomcat 업그레이드 과업 존재: EOS에 따른 백엔드 프레임워크 버전 전환 과업이 있으나, JBoss EAP 등 Red Hat 제품으로의 전환 요구는 없으며 오픈소스 기반 전환으로 명시됨
  • 컨테이너/K8s 관련 명시 없음: OpenShift 또는 Kubernetes 기반 컨테이너 플랫폼 도입 요구사항 없음
  • 결론: RFP 내 Red Hat 상용 제품(또는 동의어) 품목이 전혀 없고, 기존 운영 대상에도 Red Hat 상용 제품이 포함되어 있지 않으며, 순수 운영·유지관리 용역으로 S/W 납품 항목이 없어 실질적인 Red Hat 제안 기회 없음
