Red Hat 제안
불가능 요소
  • Red Hat 상용 제품명 미명시: RFP 전체에 걸쳐 RHEL, OpenShift, Ansible, JBoss EAP, Satellite 등 Red Hat 상용 제품명이 도입·납품·유지관리 대상으로 명시되지 않음
  • JBoss/WildFly 미명시: WAS 서버 관련 제품명이 구체적으로 기재되지 않아 JBoss EAP 판정 근거 없음
  • OS 미명시 (경쟁 제품 가능성): 서버 OS로 특정 제품명이 명시되지 않았으나, 경영정보시스템 품질 요구사항(QUR-003)에서 "Windows 11 버전 이상"에서 동작해야 한다고 명시 → Windows 기반 환경이 주요 클라이언트 환경임을 시사
  • 오라클 DBMS 명시: 오라클 DBMS 기술지원 2식이 명시되어 있어 Oracle 의존도가 높은 환경임
  • 순수 유지관리 용역: 신규 Red Hat 상용 SW 도입·납품 항목이 명시되지 않은 운영·유지관리 용역 형태이며, 기존 운영 대상 SW 목록에도 Red Hat 제품명 미기재
  • 중소기업 전용 사업: 20억원 미만 사업으로 대기업·중견기업 입찰 불가 → Red Hat이 직접 입찰 불가, 파트너 채널을 통한 접근도 제한적
  • 서버 가상화 SW 경쟁 가능성: '서버 가상화 SW 1식' 유지관리 대상이 명시되었으나 제품명 미기재 (HPE SimpliVity HCI 환경 운용 중 → VMware 기반 가능성 높음)
Red Hat 제안
가능 요소
  • 서버 OS 미지정 → RHEL 제안 여지: 서버 35대(DL380 시리즈 다수, IBM, Fujitsu 등)에 대한 OS가 RFP에 명시되지 않음. 서버 OS 갱신·교체 시 RHEL 제안 가능성 존재
  • 클라우드·컨테이너 환경 요구: SER-008(클라우드 보안)에서 "독립된 K8s 구성", "NetworkPolicy를 통한 논리 방화벽 구성" 등 컨테이너 플랫폼 보안 지침이 명시됨 → OpenShift(OCP) 제안 여지

  • 자동화·운영 최적화 요구: 24x365 모니터링, 패치 자동화, 스케일링, 자원 최적화 등 자동화 운영 요구 → Ansible Automation Platform 제안 여지
  • 서버 가상화 SW 갱신 가능성: 기존 서버 가상화 SW(제품명 미명시) 유지관리 대상 명시. VMware 라이선스 정책 변화 등에 따른 대안으로 RHEL + KVM 또는 OpenShift Virtualization 전환 제안 가능
