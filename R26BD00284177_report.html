불가능 요소
  • [S/W 납품 없는 순수 유지관리 용역] 본 사업은 기존 시스템의 운영·유지관리·장애대응 서비스 용역이며, 신규 S/W 구독·납품·도입 항목이 RFP 내 전혀 명시되어 있지 않음
  • [Red Hat 상용 제품명 미기재] RHEL, OpenShift, Ansible, JBoss EAP 등 Red Hat 상용 제품이 RFP 내 어디에도 명시되지 않음
  • [기존 DBMS: Oracle 확인] 일상점검 체크리스트에 "DB 오라클 인스턴스, 리스너, 리소스, 테이블스페이스 점검" 명시 → Oracle DBMS 사용 환경 확인
  • [기존 상용SW 세부 내역 비공개] 상용SW 13종(DBMS, 이중화솔루션, WAFS솔루션, DB암호화솔루션, 망연계솔루션 등)의 세부 품목은 방문 열람으로만 확인 가능하며, Red Hat 제품 포함 여부 불명확 (단, RFP 어디에도 Red Hat 제품명 언급 없음)
  • [화웨이 스토리지 사용] MPR-010에 화웨이 스토리지 유지관리가 별도 요구사항으로 명시 → Red Hat 스택과 무관한 타사 인프라 환경
  • [경쟁·대체 제품 직접 명시 없으나 기회 부재] Ubuntu, VMware 등 경쟁 제품이 명시적으로 언급되지는 않으나, Red Hat 상용 제품 도입 근거도 전혀 없음

가능 요소
  • [Linux 서버 운영 환경 존재] 상주인력 요건(MPR-002)에 "Linux 서버 프로그램 운용"이 명시되어 있어 서버 OS로 Linux 계열이 사용 중임을 확인할 수 있으나, 특정 배포판(RHEL, CentOS, Ubuntu 등)은 미기재
  • [특정 Linux 배포판 미지정] OS 종류가 비공개 상태로 방문 열람 시에만 확인 가능하며, 이론적으로 RHEL 사용 가능성을 완전히 배제할 수는 없음
  • [제안 가능성 매우 제한적] 그러나 본 사업은 기존 인프라 유지관리 용역이므로, 신규 RHEL 구독이나 OpenShift 도입 등의 영업 기회는 사실상 없음. Red Hat 상용 제품명·수량 RFP 내 명시 사항: 없음
  • [결론] 순수 유지관리 용역으로서 S/W 납품·구독 항목이 없고, Red Hat 상용 제품이 RFP에 전혀 명시되어 있지 않아 직접적인 Red Hat 영업 기회는 낮음. 다만 기존 운영 환경 파악(방문 열람)을 통해 RHEL 등 사용 여부 확인 후 차기 사업에서의 제안 기반 마련 가능
