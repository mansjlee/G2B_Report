S/W 미포함 순수 개발 용역
사업 개요 및 목적
  • 전문과목학회별로 상이한 수련교육 및 평가체계를 통합 연계·관리하기 위한 웹·모바일 기반 전공의 수련교육 통합플랫폼(e-portfolio) 구축 사업
  • 모바일 우선 설계를 적용하여 전공의의 수련, 교육, 평가, 피드백 및 역량성취 이력을 통합적으로 관리하는 시스템 개발
  • 일회용 PIN/QR코드, 음성·텍스트 입력을 활용한 현장 WBA(직장기반평가) 수행 환경 구축
  • 기존 학회 수련관리시스템 및 e-portfolio와 SSO·딥링크·API 연계를 통한 상호운용 기반 구축
  • Multi-tenant 구조로 26개 전문과목학회 확대 및 신규 서비스 연계 기반 마련
  • AI 기반 음성-문자 변환 및 피드백 구조화 보조 기능 포함
주요 정보
  • 사업 예산: 650,000,000원 (부가가치세 포함)
  • 사업 기간: 계약체결일 ~ 2026년 12월 31일
  • 사업 범위: ① 전공의 수련교육 통합포털 및 공통 서비스 구축 ② Logbook·교육이수·모바일 WBA·EPA 매핑·대시보드 등 수련·평가 기능 개발 ③ 학회 SSO·딥링크·API 연계 및 기존 데이터 이관 ④ 시범운영·사용자 교육·운영환경 이관·기술인수인계
  • 주요 일정: 8~9월 입찰공고·PT심사·계약체결 → 9~11월 요구분석·시스템 개발·커스터마이징·시스템 시연회 및 보완·시스템 포팅 → 12월 전문가 검토 및 최종 검수
  • 계약 방법: 협상에 의한 계약 (제한경쟁입찰, 중소기업 전용)
  • 설치 장소: 발주기관(대한의학회)이 지정하는 서버, 클라우드 또는 데이터센터 환경

Red Hat 제안
불가능 요소
  • 순수 개발 용역 사업: 본 사업은 시스템 개발·구축 용역으로, 상용 S/W 구매·납품·구독 항목이 별도로 존재하지 않음. 인프라·라이선스 비용의 부담 주체는 계약서에서 결정하도록 명시되어 있으나, 조달쇼핑몰이나 통합발주 방식의 상용 S/W 품목 도입은 확인되지 않음
  • Red Hat 상용 제품명 전무: RHEL, OpenShift, Ansible, JBoss EAP 등 Red Hat 상용 제품명이 RFP 전체에서 단 한 건도 명시되지 않음
  • 경쟁·대체 제품 미명시: VMware, Ubuntu, Rocky Linux 등 경쟁 제품도 명시되지 않았으나, OS·플랫폼 선택이 전적으로 제안사 재량으로 열려 있어 특정 스택 제안 근거가 약함
  • 중소기업 전용 입찰: 소프트웨어 진흥법 제48조에 따라 대기업 및 중견기업 입찰 참여 제한으로 Red Hat Korea가 직접 입찰 참여 불가
  • 형상관리 오픈소스 지정: 형상관리 S/W는 오픈소스 기반으로 명시(QUR-002)되어 있어 상용 제품 제안 불가
Red Hat 제안
가능 요소
  • OS·미들웨어 미지정: ECR-001에서 OS, Web server, WAS, DBMS 등을 최신 버전으로 구성하도록 요구하되 특정 제품을 지정하지 않아, 원칙적으로 RHEL(OS), JBoss EAP(WAS) 제안 여지가 존재함. 단, 인프라·라이선스 비용 부담 주체가 계약서에서 결정되므로 실제 상용 S/W 도입 여부는 불확실
  • 컨테이너·클라우드 환경 가능성: "발주기관이 지정하는 서버 또는 클라우드 환경"에 배포하도록 명시되어 있어, OpenShift 기반 컨테이너 플랫폼 제안 가능성이 이론적으로 존재하나 확정 근거 없음
  • API Gateway·연계 환경: API Gateway 기반 통합 연계 환경 구축이 요구되어 있어 Red Hat의 API 관리 솔루션(3scale 등) 제안 여지가 있으나, 역시 상용 제품 지정 근거 없음
  • RFP에 명시된 Red Hat 제품명: 없음 — RHEL, OpenShift, Ansible, JBoss EAP 등 Red Hat 상용 제품이 품목으로 단 한 건도 명시되지 않음
  • 종합 판단: 본 사업은 상용 S/W 구매 없는 순수 SI 용역으로, Red Hat 상용 제품 도입이 확정·확실시되는 근거가 없어 직접적인 영업 기회는 낮음. 수주 업체와의 파트너 협력을 통한 간접 제안을 검토할 수 있으나 우선순위는 낮음
