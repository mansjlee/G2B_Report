Red Hat 제안
불가능 요소
  • 미들웨어 경쟁 제품 확정: 기존 운영 미들웨어로 JEUS 및 WebToB가 명시되어 있어 JBoss EAP 신규 제안이 사실상 어려움 (기존 시스템 유지관리 범위)
  • DBMS 경쟁 제품 확정: Oracle DBMS가 현행 시스템으로 운영 중이며 유지관리 대상으로 명시되어 있음
  • 사업의 성격상 신규 SW 도입 범위 제한: 본 사업은 기존 시스템 유지관리 사업으로, 상용 SW 신규 도입보다 현행 유지 및 라이선스 갱신 위주로 구성됨
  • 컨테이너·Kubernetes 플랫폼 미언급: OpenShift(OCP) 또는 Kubernetes 관련 요구사항이 RFP 내 명시되지 않음
  • 가상화 플랫폼 변경 검토 중이나 방향 미확정: 기존 가상화 라이선스 비용 절감 검토 중이나 구체적 대안 제품이 명시되지 않아 Red Hat Virtualization 경쟁 여부 불확실
Red Hat 제안
가능 요소
  • [RFP 명시 Red Hat 상용 제품 — 높음 판정 근거]
    • Red Hat Enterprise Linux Server (RHEL) 5식: 외부 IDC 임대 OS로 명시 (2026년 도입 예정, 2027년 유지관리 대상 포함) → 본 사업 예산에 유지보수 비용 포함 확정
  • [RHEL 유지관리 계약 기회]: 외부 IDC에서 운영 중인 RHEL 5식에 대한 2027년도 유상 유지보수(구독 갱신) 및 기술지원이 사업비에 포함되어 있어 Red Hat 공식 서브스크립션 영업 기회로 연결 가능
  • [Linux 서버 환경 확장 가능성]: 상담프로그램 서버에 Linux OS가 사용 중이며, 가상화 서버 구성으로 운영되고 있어 추가 RHEL 제안 여지 존재
  • [가상화 플랫폼 교체 검토 중]: RFP에 "기존 가상화 라이선스 비용 절감을 위한 가상화 서비스 변경 예정"으로 명시 → Red Hat OpenShift Virtualization 또는 RHEL KVM 기반 가상화 대안 제안 가능
  • [Ansible Automation 제안 여지]: 대규모 시스템(1,134식) 운영관제 자동화, 보안패치 자동 적용, 정기점검 자동화 등에 Ansible Automation Platform(AAP) 가치 제안 가능
  • [파트너 협력 영업]: 본 사업은 중소 SW사업자 대상 제한 경쟁으로 Red Hat은 직접 입찰 불가하나, 낙찰 사업자(수행사)가 RHEL 구독 갱신·증설 시 채널 파트너를 통한 공급 확보 필요
