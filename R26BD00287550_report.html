Red Hat 제안
불가능 요소
  • [RH 상용 제품 전무] RFP 전문 및 운영 SW 유지관리 목록 어디에도 RHEL, OpenShift, Ansible, JBoss EAP 등 Red Hat 상용 제품명이 전혀 명시되어 있지 않음
  • [Oracle 스택 중심 인프라] 현행 WAS로 Oracle WebLogic, 웹서버로 OHS(Oracle HTTP Server)를 사용하는 Oracle 중심 인프라 → JBoss EAP 제안 여지 없음
  • [기존 서버 OS: Unix/Windows] 현재 서버 인프라가 SUN(Unix) 및 HP(Windows) 기반으로 운영 중이며, RHEL 도입 근거 없음
  • [순수 유지관리 용역] 신규 인프라 도입이 없는 기존 시스템 유지보수·기능개선 사업으로, 플랫폼·OS 교체 항목 없음
  • [지정 SW 유지관리] 운영 SW 유지관리 대상 13개 품목이 이미 특정 벤더 제품으로 고정되어 있으며(디아모, Crownix, Docuzen 등), Red Hat 제품은 포함되어 있지 않음
  • [컨테이너/자동화 요구 없음] Kubernetes, OpenShift, Ansible, 컨테이너 관련 기술 요구사항이 RFP에 전혀 없음
Red Hat 제안
가능 요소
  • [Linux 서버 OS 언급] 기술표준 적용계획표(COR-006, 별첨 기술적용계획표)에서 서버용 운영체제로 UNIX, Windows Server, Linux를 항목으로 열거하고 있어 이론적으로 RHEL 제안 여지가 있으나, 현행 인프라(SUN Unix, HP Windows)가 이미 구축된 상태로 실질적 교체 가능성은 매우 낮음
  • [Java/Spring 기반 개발 환경] 전자정부 표준프레임워크(Spring Boot, Java) 기반 신규 기능 개발 환경에서 이론적으로 RHEL 기반 개발 서버 제안이 가능하나, WAS가 Weblogic·Tomcat으로 고정되어 있어 JBoss EAP 전환 가능성 없음
  • [RFP 내 Red Hat 제품명 명시 없음] 문서 전체에서 Red Hat, RHEL, OpenShift, Ansible, JBoss 등 Red Hat 상용 제품·동의어가 단 한 건도 등장하지 않음 → 높음 또는 중간 판정 근거 부재
  • 종합 의견: 본 사업은 Oracle/Weblogic 중심의 기존 레거시 시스템을 유지관리하는 순수 용역 사업으로, Red Hat 상용 제품의 신규 도입·납품 기회가 사실상 없음. 영업 우선순위 낮음으로 분류 권장.
