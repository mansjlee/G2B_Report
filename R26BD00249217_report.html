Red Hat 제안
불가능 요소
  • **제안 불가능 포인트**: Oracle Linux Support Subscription이 RHEL과 동등 항목(ECR-SWA-019)으로 병행 명시되어 OS 영역 경쟁 불가피, Oracle RDBMS가 현행·To-BE 정형 DB로 명시(Enterprise/Standard/RAC/Partitioning 843 Core급), RDBMS·ESB·검색엔진·DRM·CNAPP·DevSecOps 등 대부분 미들웨어·보안 S/W는 통합발주 수량 확정·Win-Back 허용이나 Red Hat 제품군(JBoss EAP, RHEL DB 등) 직접 지정 없음
  • **S/W 공급 범위**: 직접구매 28종(WEB·WAS·SSO·APM 등)은 본 사업금액 미포함·낙착자 직접구매로 Red Hat 간접 제안만 가능, OpenShift·Ansible은 구매 목록·명칭 미명시
  • **경쟁 제품 명시**: Oracle Linux Support Subscription(기관별 7~14 Server), Oracle DB(현행 유지·업그레이드), 상용 RDBMS(Oracle·DB2·MS-SQL·MySQL·Tibero·PostgreSQL 등), Kubernetes·Service Mesh는 오픈소스 일반 요구(특정 배포판 미지정)
  • **기타 제약**: x86 서버 호환 OS는 제조사 기반 정품·유지보수 필수, 클라우드 플랫폼 특정 HW 종속 금지, 방화벽·VPN 등 일부 보안 장비는 제안사 부담, AI 업무지원(SFR-GEN-007) 구독료 제안사 부담
Red Hat 제안
가능 요소
  • **제안 가능 포인트(RHEL)**: Red Hat Enterprise Linux for Virtual Datacenters·Subscription이 19개 기관 To-BE 수량으로 통합발주 명시(합계 OS 406 Server), OS 요구사항이 "오픈소스 기반 호환성 확보 최신 엔터프라이즈급 OS·5년 이상 EOS·CVE 패치"로 특정 제조사 강제 없음, Oracle Linux와 병행 제안 가능
  • **제안 가능 포인트(OpenShift)**: Kubernetes 기반 컨테이너 오케스트레이션·PaaS·클라우드 네이티브 MSA·17+2 프라이빗 클라우드·Auto-Scaling·멀티테넌트 DR(최대 3개 교육청 동시 운영) 요구와 부합, Kubernetes 특정 벤더 미지정으로 OpenShift Container Platform 제안 여지
  • **제안 가능 포인트(Ansible)**: GitOps(ArgoCD/Flux)·IaC·CI/CD 무중단 배포·163 Server 클라우드 플랫폼·19개 센터 SDDC 운영 자동화에 Ansible Automation Platform 적용 가능
  • **기술 적합성**: Zero Trust·RBAC·DevSecOps·SBOM·DR 자동 Failover/Failback·재해복구자동화 1식 등 Red Hat 클라우드·보안·자동화 스택 강점 영역, COR-GEN-003 개방형 기술·벤더 종속 금지 원칙과 부합, RHEL은 CSAP·국가주요정보통신기반시설 보안 요구 대응 가능
  • **영업 전략**: OS(144+221 Server급 RHEL 라이선스) 직접 입찰 + OpenShift/Ansible은 클라우드 플랫폼·CI/CD·DR 자동화 아키텍처 제안서 내 기술 제안으로 Win-Back 경쟁, 통합사업자(낙착자) 파트너십 통해 RHEL 공급 및 플랫폼 레이어 확장
