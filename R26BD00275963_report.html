불가능 요소
  • [S/W 신규 납품·구독 항목 없음]: 본 사업은 기존 구축된 통합의료정보시스템(EMR)·PACS 및 상용S/W를 유지관리하는 운영 용역으로, 신규 S/W 구매·도입·납품 항목이 존재하지 않음. 판정 규칙상 "순수 용역·운영·유지보수 사업으로 S/W 납품·구독 항목 없음" 에 해당하여 낮음 판정
  • [Red Hat 상용 제품 미명시]: RFP 전문 어디에도 RHEL, OpenShift, Ansible, JBoss/EAP, Satellite, Quay 등 Red Hat 상용 제품명이 구매·도입 품목으로 기재되지 않음
  • [Oracle 기반 환경 추정]: DBMS 유지보수요원 자격 요건으로 "OCP(Oracle Certified Professional) 자격증"을 명시하고 있어, 기존 DBMS는 Oracle DB일 가능성이 매우 높음. Oracle DB 환경에서 Red Hat 제품 추가 제안 명분 약함
  • [HP 기반 HA 환경]: 유지관리 대상 상용S/W에 Serviceguard(HP) 1식이 명시되어 있어, HP-UX 또는 HP 서버 기반의 고가용성 클러스터링 환경을 운영 중임을 알 수 있음. 이는 Red Hat 가상화(RHEV) 또는 OpenShift 스택과 경쟁 관계
  • [Windows 중심 클라이언트 환경]: 주요 요구사항 중 Windows 10→11 전환 작업이 포함되어 있으며, 클라이언트 OS는 Windows 기반으로 확인됨
  • [입찰 참여 제한]: 20억원 미만 사업으로 중소 SW사업자만 참여 가능. Red Hat Korea(대기업)는 직접 입찰 참여 불가하며, 파트너를 통한 S/W 공급 구조도 신규 납품 없이는 의미 없음
  • [경쟁·대체 제품 확정 가능성]: 기존 도입 시스템(2011년 구축) 유지관리 용역으로, 시스템 변경 없이 현행 유지가 목적. Red Hat으로의 OS 또는 플랫폼 전환 여지 없음
Red Hat 제안
가능 요소
  • [서버 OS 환경 미공개]: 서버 사양 및 구체적 S/W 제품명이 보안상 비공개(행정안전부 고시 제17조 적용)이므로, 현재 서버 OS가 Linux 계열인지 확인 불가. 열람 신청을 통해 RHEL 사용 여부 확인 필요
  • [기술적용계획표 Linux 언급]: RFP 내 기술적용계획표(붙임12)의 "플랫폼 및 기반구조" 분야에서 서버용 개방형 운영체제로 "Linux"가 기술 표준 항목으로 나열되어 있으나, 이는 공공 표준 지침상 일반 항목일 뿐 이 사업에서 실제 Linux가 사용 중임을 의미하지는 않음
  • [WAS 환경 확인 필요]: WAS 2식이 유지관리 대상에 포함되어 있으며, JBoss EAP/WildFly 사용 여부는 현장 열람을 통해서만 확인 가능. 단, 상용 제품명 확인 전까지는 제안 근거 없음
  • [RFP 내 Red Hat 제품명 명시 없음]: 현재 문서에서 Red Hat 또는 동의어 제품명은 단 하나도 발견되지 않음. 높음 판정 근거 부재
  • [향후 기회]: 서북병원의 차년도 시스템 고도화·교체 사업 발생 시, 현재 담당자(현병열 02-3156-3382) 접촉을 통해 RHEL, OpenShift 등 도입 기회 선점 활동 권장
