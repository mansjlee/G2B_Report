  • 36개 대학 개별 구축 대비 약 30% 비용 절감 효과를 목표로 하는 통합 클라우드 인프라 구성

Red Hat 제안
불가능 요소
  • 경쟁·커뮤니티 OS 확정: 서버 Linux OS로 Rocky OS 8버전 이상(오픈소스 커뮤니티 배포판)이 명시적으로 지정되어 있으며, DBMS OS로는 Oracle Linux 8버전 이상(Red Hat의 직접 경쟁 제품)이 확정 지정됨 — RHEL 제안 여지 없음
  • WildFly(커뮤니티 WAS) 명시: WAS로 오픈소스 WildFly가 명시 지정(SW 직접구매 제외 사유: 오픈소스). JBoss EAP 등 Red Hat 상용 WAS 제품 도입 여지 없음
  • Oracle DBMS 종속 환경: 코러스(KORUS) 기존 환경인 Oracle 19c 멀티테넌트와의 100% 호환을 요구하며, DB암호화(D'Amo), DB접근제어(DB-i) 등도 Oracle 환경에 종속된 제품으로 고정됨
  • 코러스 기존 보안 솔루션 전제품 고정: 시스템 접근제어(Secuve TOS), 시스템 관리(애플망고), 취약점진단(SolidStep), 로그관리(eysCloudSIM), 백신(AhnLab V3), 계정관리(HI-TAM), DB암호화(D'Amo), DB접근제어(DB-i) 등 모두 기존 코러스 환경과 동일 제품 증설로 확정되어 Red Hat 보안 솔루션 진입 불가
  • Red Hat 상용 제품 구매 품목 전무: RHEL, OpenShift, Ansible, JBoss EAP, Satellite 등 Red Hat 상용 제품이 직접구매 목록 또는 통합발주 품목 어디에도 명시되지 않음
Red Hat 제안
가능 요소
  • HCI 하이퍼바이저 인증 요건에 Red Hat 언급: ECR-004에서 HCI 가상화 소프트웨어(하이퍼바이저)가 "Red Hat CertifiedHypervisor" 프로그램에 등재된 제품이어야 한다고 명시 — HCI 벤더 선택 시 Red Hat 인증 하이퍼바이저 활용 가능성 존재 (단, 제품 구매가 아닌 인증 요건)
  • RHEV 지원 요건 명시: ECR-004 기술지원 항목에 "다양한 가상화 SW(RHEV, VMware, Xen, KVM 등)에 대한 원활한 기술 지원을 보장해야 함"이라고 명시 — RHEV(Red Hat Enterprise Virtualization)가 지원 대상으로 포함되어 있어 인프라 벤더와 협력 시 간접 언급 가능
  • Rocky Linux → RHEL 전환 제안 여지 (중장기): Rocky Linux는 RHEL 호환 커뮤니티 배포판으로, 향후 사업 유지·운영 단계에서 상용 지원이 필요한 경우 RHEL로의 전환을 제안할 수 있는 간접적 여지 있음 (단, 본 사업 RFP 내에서는 확정 불가)
  • 클라우드·컨테이너 아키텍처 요구: 클라우드 기반 인프라, 가상머신 기반 마이크로서비스 구조 요구로 중장기적으로 OpenShift 등 컨테이너 플랫폼 제안 여지가 있으나 현 RFP에서는 해당 제품 구매 항목 없음
  • RFP에 명시된 Red Hat(동의어 포함) 상용 제품명·수량: 없음 — RHEV, Red Hat CertifiedHypervisor는 기술 요건 참조로만 언급되었으며 구매·납품 품목으로 명시된 사례 없음
