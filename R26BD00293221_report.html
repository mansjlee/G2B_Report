  • 지방교부세 인프라 별도 사업: 지방교부세 OS 5식, 가상화 9식, 가상화 관리 1식은 별도 인프라 운영 사업자 수행(제품명 미기재)
  • 경쟁 제품 언급
    • SLA 표준안 예시 구성에 Rocky Linux, Tibero, JEUS, WebtoB가 기재되어 있으나 예시 홈페이지 시스템이며 실제 대상 구성은 아님
    • 기술적용계획표에 Windows Server, UNIX가 일반 항목으로 병기
    • VMware, Contrabass, Ubuntu, Oracle Linux 명시 없음
  • 기타 제약 조건
    • "국산 및 공개SW 이용 권장" 문구 존재
    • 사업자가 추가 장비·SW 도입 시 비용은 계약상대자 부담이므로 신규 구독 도입 동기가 약함
    • 가상화관리제품 도입 시 보안기능 확인서 필수
    • Ansible 등 자동화 도구 명시 없음
Red Hat 제안
가능 요소
  • RFP 내 Red Hat(동의어) 제품명·수량(모두 별도 사업 유지관리 대상, 수량 미기재)
    • RHOCP(Red Hat OpenShift Container Platform): 대내, 대외, 개발검증 환경
    • RHOSP(Red Hat OpenStack Platform): 대내, 대외, 개발검증 환경
    • RHV(Red Hat Virtualization): 관리노드
    • RHEL(Red Hat Enterprise Linux): 지방재정 OS
    • OpenShift·OpenStack: 컴볼트 백업 대상으로 명시
  • 기존 Red Hat 스택 운영 기반: KLID 지역클라우드센터 프라이빗 클라우드가 RHOCP·RHOSP·RHV·RHEL로 구성되어 있어, 별도 "지역클라우드센터 정보자원 통합유지관리 사업" 대상의 서브스크립션 갱신·확장 영업 기회 연계 가능
  • RHV 전환 기회: 관리노드 RHV 운영 중으로, RHV 지원 종료에 따른 OpenShift Virtualization 전환 제안 여지
  • 자동화(Ansible Automation Platform) 적용 여지
    • 인증서 배포·적용 자동화(사전검증, 무중단 적용, 자동 백업·실패 시 복원) 및 SSL/TLS 인증서 유효기간 단축(100일→47일) 대응
    • 주/DR AP 서버 구성(WAS 설정, JDK, 라이브러리) 동일성 월 1회 점검, 보안정책 분기별 대조
    • 상용SW 패치, CVE 패치, OS·미들웨어 업그레이드·패치 공통기준
  • CI/CD·컨테이너 플랫폼 연계: 주/DR 동시 배포 CI/CD 파이프라인, CI/CD 형상관리 자동화, OpenShift POD 자원 전수조사, 발주기관 제공 클라우드 PaaS 환경 이용 → OpenShift GitOps/Pipelines, ACM(멀티클러스터 주/DR 관리) 제안 여지
  • AI 과제 연계: 지방재정 AI 중장기 로드맵 컨설팅, 부정수급신고센터 GPU서버·AI-OCR 인프라 기술지원, MCP·AI Agent 연계 → OpenShift AI / RHEL AI 제안 여지
  • 미들웨어·보안: WAS·Web Server·JDK 및 ESB 연계 운영, CVE 패치 요구 → JBoss EAP, Red Hat 빌드 OpenJDK, ACS(컨테이너 보안) 제안 여지
  • 기술 기준 부합: 기술적용계획표에 Linux, IaaS·PaaS 명시, "특정규격 명시 금지" 원칙으로 OS·플랫폼 개방형, Red Hat 제안 금지 문구 없음
  • 파트너 연계: 착수 2개월 이내 제조사 인정 업체와 연 단위 유지관리 계약 의무로, 통합유지관리 사업자 및 본 사업자 대상 Red Hat 파트너 기술지원 연계 가능
