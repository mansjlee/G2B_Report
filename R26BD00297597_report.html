사업 개요 및 목적
  • 2009년 도입된 노후 탑재모의체계(단독형 노트북 기반)를 최신화하여 해병대 상륙작전 탑재계획 수립 체계를 신규 개발하는 사업
  • 국방망 기반 통합서버 환경으로 전환하여 다수 제대가 동시·순차적으로 탑재계획을 수립할 수 있도록 네트워크 체계 구축
  • AI 및 디지털트윈 기반 분석·예측·시뮬레이션 기능을 적용하여 상륙작전 탑재계획 수립의 정확성·효율성 향상
  • 국방조직및정원관리체계(DIMS), 국방군수통합정보체계 등 타 체계와의 데이터 연동 구현
  • 전자정부 표준프레임워크 기반 개발, 관계형 DBMS 운용, WEB/WAS 서버 구축을 포함하는 국방정보체계 신규 구축 사업

Red Hat 제안
불가능 요소
  • Red Hat 상용 제품명 전혀 없음: RFP 전문 어디에도 RHEL, OpenShift, Ansible, JBoss, EAP, Satellite 등 Red Hat 상용 제품명이 품목으로 명시되지 않음. 현행 시스템 구성·운영 환경에도 Red Hat 관련 기재 없음 (기존 체계: Windows 10 엔터프라이즈 기반 단독망 노트북)
  • OS 미확정이나 경쟁 환경 혼재: WEB/WAS/DB 서버 HW 규격에 "최신 OS 제공 포함(Windows, Linux 등)"으로 표기되어 특정 OS 미지정이나, WAS 요구사항에서 "전자정부표준프레임워크 기반 Java/JSP/Servlet 환경" 중심으로 기술되어 있어 국산 WAS(티맥스 JEUS, 오라클 WebLogic 등) 또는 오픈소스 WAS(Apache Tomcat 등)와의 경쟁이 주요 구도임. RHEL 제안 가능성이 없지 않으나 명시 없음
  • WAS 경쟁 구도 불리: WAS 요구사항(ECR-008)에 "국산/외산 주요 상용 WAS의 복수 인스턴스 그룹과 표준 프로토콜(HTTP/AJP) 기반 연동 지원" 명시 → JBoss EAP 언급 없고, 국산 WAS 중심 경쟁 환경 예상
  • DBMS 경쟁 구도 불리: DBMS 요구사항(ECR-009)에 국정원 암호화 알고리즘(SEED, ARIA), Active-Active 클러스터 명시 → 국산 DBMS(Tibero, Altibase 등) 또는 Oracle 중심 경쟁 환경으로 PostgreSQL/Red Hat 계열 DB 명시 없음
  • 신규 개발 사업으로 기존 Red Hat 스택 없음: 기존 체계가 단독형 노트북이므로 Red Hat 기존 구독 갱신·증설 기회 없음
  • 대기업 참여 제한: 중소기업 대상 사업으로 Red Hat 코리아가 직접 입찰 불가이며 파트너(SI)를 통한 간접 제안 경로가 유일하나, 파트너 채택 여부 불확실
Red Hat 제안
가능 요소
  • RFP 내 Red Hat 상용 제품 명시 없음 — 판정 근거로 활용 불가
  • OS 미지정으로 RHEL 간접 제안 여지 존재: HW 서버 규격에 "최신 OS 제공 포함(Windows, Linux 등)" 명시 → 통합발주 사업자가 서버 OS로 RHEL을 선택하여 제안할 수 있는 간접 기회. 단, 명시적 요구 없어 채택 가능성 낮음
  • Linux 기반 인프라 구성 가능성: WEB/WAS/DB 서버 총 10대(운영·개발 포함) 규모의 신규 서버 구축 → 사업자 재량으로 Linux OS 선택 시 RHEL 제안 가능. 그러나 국방망 환경 특성상 국산 Linux(TmaxOS, 구름OS 등) 또는 무료 배포판 선택 가능성도 있음
  • Ansible 자동화 제안 여지: 다수 서버(WEB 3대, WAS 3대, DB 3대, 백업서버 1대 등) 구성 및 국방망 환경에서의 구성관리 자동화 필요성 → Ansible Automation Platform 제안 가능하나 RFP에 명시 없음
  • 제안 전략 포인트: 파트너(입찰 SI 사업자)를 통해 ① 서버 OS로 RHEL 채택 유도, ② 멀티 서버 환경 운영 자동화를 위한 Ansible 번들 제안을 사전 영업 단계에서 추진 필요
  • 종합 평가: RFP상 Red Hat 제품이 명시되지 않았고, 기존 체계에도 Red Hat 스택이 없으며, WAS·DBMS 경쟁 구도도 Red Hat에 불리함. OS 미지정에 의한 간접 제안 여지만 존재하는 수준으로, 실질적 영업 기회는 매우 제한적임
