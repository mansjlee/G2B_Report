Red Hat 제안
불가능 요소
  • S/W 공급 포함 여부: S/W 납품이 명확히 포함된 사업으로, 제안 불가능 사유 해당 없음
  • 경쟁 OS 명시: 현행 자회사 그룹웨어 서버 OS로 CentOS 7.5(64bit)가 명시되어 있으나, 이는 현행(기존) 환경이며 신규 도입 OS로는 RedHat Linux 9.8이 명시되어 있어 경쟁 대체 확정으로 보기 어려움
  • 현행 DB 환경: 현행 재단 ERP DBMS 및 자회사 ERP에 MSSQL, 그룹웨어에 MariaDB가 사용 중이나, 신규 DB 제품은 미지정 상태로 경쟁 제품 확정은 아님
  • OpenShift·Ansible 등 추가 Red Hat 제품: RFP에 OpenShift, Ansible, Satellite 등 RHEL 외 Red Hat 추가 제품에 대한 명시적 도입 요구나 허용 단서가 없어 적극적 제안 범위가 RHEL로 한정될 가능성 있음
  • 온프레미스 폐쇄망 필수: SaaS·외부 클라우드 의존 아키텍처가 명시적으로 지양되어 있어 Red Hat 클라우드 서비스 형태의 제안은 불가; 단, 온프레미스 제품 형태는 적합
  • 가상화 명시 없음: RFP에 가상화(하이퍼바이저) 도입 요구가 명시되어 있지 않아 RHEV(Red Hat Virtualization) 등의 제안 근거 부족
Red Hat 제안
가능 요소
  • RHEL 9.8 신규 도입 OS로 명시 확정 (최우선 기회):
    • ECR-002(도입 운영 서버 OS 명세): "RedHat Linux 9.8(최신 안정화 버전) 또는 동등 이상의 엔터프라이즈 리눅스 OS" — 운영 서버 2대, 백업 서버 1대 총 3식 도입
    • ECR-004(그룹웨어 S/W 도입): "ECR-002에 명시된 서버용 최신 엔터프라이즈 리눅스 OS(RHEL 9.x 등) 환경에서 무결하게 최적화 구동" — RHEL 9.x 명시적 언급
    • TER-002(테스트 환경 구축): "장비 구성 요구사항 ECR-002 규격 만족 RHEL 9.8 또는 동등 엔터프라이즈 리눅스 OS 포함" — 테스트 환경도 동일 적용
    • QUR-005(가용성 확보): "도입되는 엔터프라이즈 리눅스 운영체제(RHEL 9.x) 및 연계 모듈 전체에 대한 환경설정 상태를 전수 점검하고 고가용성을 위한 성능 최적화 필수 수행" — RHEL 9.x 명시
  • 현행 재단 시스템 Red Hat 운영 환경 (기존 고객):
    • 현행 재단 그룹웨어 WEB/WAS 서버 OS: Red Hat (버전 미명시)
    • 현행 재단 그룹웨어 DBMS 서버 OS: Red Hat (버전 미명시)
    • 현행 재단 메일시스템 WEB 서버 OS: Red Hat (버전 미명시)
    • 태권도진흥재단이 기존에 Red Hat OS를 다수 서버에서 운영 중인 기존 고객으로, 신규 시스템 전환 시 연속성 측면에서 RHEL 채택 가능성 매우 높음
  • RHEL 구독(Subscription) 제안 기회: 운영 서버 2대 + 백업 서버 1대 최소 3개 노드에 대한 RHEL 9.x 구독 납품 가능; 추가로 테스트 환경 서버 구독도 제안 가능
  • SSO 연동 요구사항과 Red Hat SSO(Keycloak) 연계 가능성: RFP에 SAML 2.0 또는 OIDC 기반 SSO 필수 적용 및 독립형 LDAP 디렉터리 서버 연동이 명시되어 있어, Red Hat 계열 SSO 솔루션 제안 여지 있음 (단, 명시적 요구는 없음)
  • Ansible Automation Platform 제안 여지: 오프라인 보안 패치 배포 체계, 형상관리 체계, 고가용성 성능 최적화 등 자동화 요구사항이 명시되어 있어 Ansible을 활용한 자동화 운영 제안 가능 (단, 명시적 요구는 없음)
  • 기술 스택 적합성: RFP에 Java, Spring, Docker 등 현행 기술 스택이 명시되어 있고, 컨테이너 기반 운영 환경 구축 시 OpenShift 또는 RHEL 기반 컨테이너 플랫폼 제안 여지 있음 (단, 명시적 요구는 없음)
  • RFP 내 Red Hat 관련 명시 제품·수량 요약:
    • RedHat Linux 9.8 (RHEL 9.8) — 운영 서버 2대, 백업 서버 1대 (최소 3식, 테스트 환경 별도)
    • Red Hat (버전 미명시) — 현행 재단 그룹웨어 WEB/WAS 서버, DBMS 서버, 메일시스템 WEB 서버 (기존 운영 중)
