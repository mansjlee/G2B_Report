불가능 요소
  • UNIX 유지 서버 존재: 장기요양·급여관리 DB 서버(ECR-C-001), 우편물관리시스템 원주 본부 DB·WEB/WAS 서버(ECR-E-008, IBM Power11)는 "하드웨어 제조사 자체 OS 탑재(OEM 불가)" 명시 → RHEL 적용 불가
  • 권한관리시스템 OS 제약: SSO/EAM 서버 OS는 "반드시 유닉스로 구성" 필수 규정 → 해당 영역 RHEL Linux 적용 불가
  • Oracle ExaData 확정 도입: 통합급여 DB 및 DR DB용 Oracle ExaData (HW·SW·Network 일체형) 9식, Oracle ZFS Storage 2식 명시 → DB 영역 Red Hat 솔루션 진입 불가
  • Oracle DB 갱신 확정: Oracle 11g → 19c 업그레이드 명시 (권한관리시스템) → Oracle 환경 유지
  • Citrix VDI 플랫폼 확정: Citrix XenDesktop VDI Edition 1,000식, vPortal 1,000식 증설 확정 → VDI 영역 Red Hat 가상화 플랫폼 진입 불가
  • Microsoft 플랫폼 확정: WinSvrSTDCore 2025 72식, MS SQL Server 2024 2식, Windows 11 VDI 업그레이드 확정 → 해당 영역 대체 불가
  • APT 어플라이언스 가상화 제한: "상용 VMware, VirtualBox 등 불가, 제조사 자체 개발 가상머신 사용 필수" 명시 → OpenShift/KVM 기반 제안 제한 가능성
  • EDR UNIX 서버 제외: "UNIX 서버는 EDR 미지원으로 DMZ 영역 Linux·Windows 서버 213대만 대상" → UNIX 영역 보안 솔루션 연계 불가
  • 기존 특정 보안 솔루션 유지·증설 요건: V3 백신(AhnLab), Privacy-i, DB Safer, SaferZone, NAC(기존 제품 증설), 악성코드 분석(시큐레터), 모바일 난독화(기 운영 솔루션 호환 필수) 등 기존 벤더 제품 고정
  • WAS 미들웨어: 권한관리시스템 이관 대상으로 Weblogic(WAS) 명시 → JBoss EAP 제안 어려움
Red Hat 제안
가능 요소
  • ★ RHEL 9.x 이상 OS 품목 직접 명시 (최우선 근거): 축전지 모니터링 시스템 서버 OS로 "Linux RedHat 9.x 이상" 직접 지정 (ECR-P-003) → RHEL 상용 제품 도입 확정, 판정 근거 충족
  • Linux 기반 전환 사업 방향성 부합: "특정 Unix 벤더 종속 환경에서 벗어나 개방형 표준 기술(Linux 기반) 도입" 명시, Unix→Linux 전환이 사업의 핵심 목표 → RHEL 계열 Linux 제안 방향성과 정확히 일치
  • 신규 x86 서버 OS 제안 기회: 장기요양·급여관리 WEB/WAS IaaS 전환 서버, DR WEB/WAS 서버 등 다수 신규 x86 Linux 서버 도입 (ECR-C-002, ECR-C-015, ECR-C-018) → 배포판 미지정, RHEL 제안 가능
  • 개방형 오픈시스템 요건 부합: 신규 도입 서버 운영체제 "개방형 오픈시스템(POSIX 기반 64bit OS)" 요건 (ECR-A-001-01) → RHEL은 해당 요건 완벽 부합
  • OTP 개발 어플라이언스 OS Linux 명시: 간편인증 시스템(OTP) 개발 어플라이언스 OS "Linux"로 명시 (배포판 미지정) → RHEL 제안 가능
  • EDR 에이전트 설치 대상 Linux 서버: DMZ 영역 Linux·Windows 서버 213대 대상 → RHEL 서버에 EDR 에이전트 설치 환경 구성, RHEL 라이선스 제안 연계 가능
  • OS 백업 솔루션 RHEL 포함 가능성: OS 백업 솔루션 284개 증설 대상에 Linux 포함, ppc64·x86 등 다중 하드웨어 지원 → RHEL 에이전트 설치 대상 포함 가능
  • IaaS·컨테이너 클라우드 전환 계획: 행안부 클라우드 네이티브 전환사업 산출물 참조, "VMware, 컨테이너 등 점검" 항목 존재, 클라우드컴퓨팅법 준수 의무 → OpenShift 컨테이너 플랫폼 향후 제안 여지
