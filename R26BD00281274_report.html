  • 시스템 운영 중 발생하는 장애 조치, 기능 개선, 사용자 지원(헬프데스크) 등 종합 운영관리 수행
  • 2023~2024년에 구축 완료된 시스템(1차: 조사정보시스템, 2차: 유출신고·신고관리시스템)의 2027년도 연간 유지관리 용역

Red Hat 제안
불가능 요소
  • S/W 납품·구독 항목 없음: 본 사업은 기구축 시스템의 유지관리·운영 용역으로, 신규 S/W 도입·납품 항목이 없으며 인프라(HW, 시스템SW) 유지관리는 국가정보자원관리원이 별도 수행
  • 기존 상용SW 목록 내 Red Hat 제품 부재: 현재 운영 중인 상용SW 18종(웹기안기, SSO, DRM, DB암호화, 연계솔루션 등) 어디에도 RHEL, OpenShift, Ansible, JBoss EAP 등 Red Hat 상용 제품이 포함되지 않음
  • 애플리케이션 스택 비Red Hat: 전자정부 표준프레임워크(Java/JSP) + Cubrid DBMS 조합으로 Red Hat 미들웨어(JBoss EAP 등) 대체 가능성 낮음
  • 기존 시스템 호환 제약: RFP 제약사항(COR-003)에서 "기존 시스템 운영에 영향을 주지 않는 프로그램 구현" 요구 → 기존 스택 변경 불가
  • 경쟁 제품 명시 없으나 신규 도입 구조 자체가 불가: 운영 인프라는 국가정보자원관리원 관할로, 제안사가 OS/플랫폼 제품을 직접 제안·납품하는 구조가 아님
Red Hat 제안
가능 요소
  • 기술적용계획표 내 Linux 서버 OS 명시: 붙임5 기술적용계획표 "플랫폼 및 기반구조" 분야에 Linux(POSIX.0, UNIX, Linux)가 서버용 운영체제로 적용 항목에 포함되어 있으나, 특정 배포판이나 상용 제품(RHEL 등)은 지정되지 않음 → 제안 여지 있으나 직접 납품 구조 아님
  • Java/JEE 기반 WAS 환경: 시스템SW(WEB, WAS, DBMS) 기술지원이 과업 범위에 포함(MPR-002)되어 있어 이론적으로 JBoss EAP 제안 맥락 존재하나, 기존 WAS 변경은 현실적으로 불가
  • RFP 내 Red Hat 제품명 명시 없음: RHEL, OpenShift, Ansible, JBoss EAP 등 Red Hat 상용 제품명이 RFP 어디에도 언급되지 않음 → 직접적 영업 기회 근거 없음
  • 종합 평가: 신규 인프라 구축이 아닌 기존 시스템 운영·유지 사업으로, Red Hat 제품 제안 기회가 구조적으로 제한됨. 향후 차기 구축사업(시스템 고도화 등) 발주 시 RHEL/OpenShift 제안 포석으로 접촉하는 우회 전략만 가능
