우리시(구룡포) GIS 공간정보 DB 구축 - 분석 리포트

레드햇 제안 가능성 낮음
GIS 측량용역, S/W구매없음
사업 개요 및 목적
  • 하수관로 정비 사업으로 변경된 구룡포 지역의 하수도·지하시설물에 대한 GIS 공간정보 데이터베이스 구축 기술용역
  • 1/1,000 수치지형도 기반 현장조사, 정위치 편집, 구조화 편집, DB 로딩을 통해 도시정보시스템(DGIS) 연계 및 시설물 관리 데이터 정확성·일관성 확보
  • 공공측량 성과심사 대응, 기술이전·교육, 준공 후 1년 무상 하자보수 포함
주요 정보
  • 사업 예산: 입력 텍스트(과업지시서) 내 미기재
  • 사업 기간: 입력 텍스트(과업지시서) 내 미기재 (계약일로부터 7일 이내 착수계 제출, 준공 1개월 전 성과품 초안 제출, DB 구축 완료 후 공공측량 성과심사 기간은 과업일수 제외)
  • 사업 범위: GIS 공간정보 DB 구축(공통·기본도, 하수도 DB, 지하시설물 DB), 현장조사·보완측량·탐사, 정위치·구조화 편집, DB 로딩, 도면 제작, 공공측량 성과심사 대응
  • 주요 일정: 계약 후 7일 이내 착수계 제출, 수행 중 수시·월말·중간·최종 성과보고, 준공 1개월 전 성과품 초안 제출, DB 구축 완료 후 성과심사, 준공 후 1년 무상 유지보수
담당자 정보
  • 입력 텍스트(과업지시서) 내 담당 부서·이름·연락처·이메일 미기재 (발주처: 우리시, 감독관 지시·시설물 관리부서·상하수도 부서 협조 언급)
핵심 요구사항
  • 기술·업무 요구사항: 1/1,000(미보유 지역 1/5,000) 수치지형도 기반 하수도·지하시설물 현장조사 및 DB구축지침서 준수 구조화 편집, GRS80 좌표계 적용, 금속·비금속·케이블 관로 분류 탐사(금속관로탐지기·비금속관로탐지기·맨홀탐지기 등), 직선·곡선 구간별 정밀 탐사, 현지 보완측량, 정위치 편집, 속성화일 작성, 공간·속성 DB 로딩(감리 입회), 「도시정보시스템 구축 본사업」·「변동자료갱신 용역」 DB 지침 및 NGIS 표준 준수, 공공측량 성과심사, 기술이전·사용자 교육, 1년 무상 하자보수, 보안·안전관리(지하시설물 조사)
  • 구매 명시 S/W(통합발주): 입력 텍스트 내 조달쇼핑몰·통합발주 대상 S/W 구매 명시 없음 (기술용역 성격, 기존 우리시 편집·조회시스템에 데이터 로딩 방식)
  • 성과물: 정위치편집·구조화·속성·성과관리 데이터 파일 각 2식(CD), 지하시설물(하수도) 평면도 1식(CD), 4급 기준점 측량 성과 1식(CD), INDEX·작업사진첩·작업일지 등 1식(CD), 공공측량 성과심사 제출 성과물 1식
Red Hat 제안
불가능 요소
  • S/W 공급 미포함: 본 사업은 GIS 데이터 조사·편집·로딩 기술용역으로 RHEL·OpenShift·Ansible·JBoss 등 S/W 라이선스·인프라 구축 항목 없음
  • 경쟁 제품 명시 없음: VMware, Contrabass, Ubuntu, Oracle/Rocky Linux 등 특정 OS·가상화·DB 제품 지정 없음 (기존 도시정보시스템·편집시스템 활용만 언급)
  • Red Hat 제안 어려운 조건: 핵심 역량이 현장 측량·탐사·GIS 데이터 생산·공공측량 심사 대응에 집중, 서버·컨테이너·자동화·미들웨어 도입 요구 없음, 하도급 불가·보안·안전 규정 중심의 전통 GIS 용역 구조
Red Hat 제안
가능 요소
  • 직접 제안 포인트 제한적: 본 RFP 범위 내 Red Hat 제품(RHEL, OpenShift, Ansible, JBoss) 직접 적용·구매 요구사항 없음
  • 간접 연계 가능성(매우 낮음): DB 로딩 시 기존 DGIS·편집시스템과 연동되나, 해당 시스템의 OS·DB·미들웨어 스택이 문서에 명시되지 않아 RHEL 등 Red Hat 스택 제안 근거 부족
  • 기술 요구와의 정합성: 공간·속성 DB 구축·로딩, 데이터 검수·유지보수 요구는 있으나 관계형 DBMS·클라우드·컨테이너·DevOps 등 Red Hat 강점 영역과 직접 매칭되는 RFP 조항 없음
