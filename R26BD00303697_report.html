Red Hat 제안
불가능 요소
  • RFP 내 Red Hat 상용 제품명 미명시: RHEL, OpenShift, Ansible, JBoss EAP 등 Red Hat 상용 제품이 구매 목록에 전혀 명시되어 있지 않음
  • 경쟁 OS 명시 없음(긍정적): Ubuntu, Rocky Linux, Oracle Linux 등 경쟁 OS가 명시되지 않아 직접적인 배제 조건은 없으나, 반대로 Red Hat도 명시되지 않음
  • WEB/WAS S/W 제품 미지정: WEB S/W 4식, WAS S/W 17식을 도입하나 제품명이 명시되지 않아 JBoss EAP 제안 가능성이 있지만, 동시에 타사 제품(Apache Tomcat, Nginx 등 오픈소스)으로 대체될 가능성도 높음
  • DBMS 제품 미지정: DBMS 6식 도입이 명시되어 있으나 제품명 불명시 — Oracle, Tibero, PostgreSQL 등 경쟁 제품과 경합 필요
  • HCI 가상화 S/W 제품 미지정: HCI 가상화 S/W 1식(288Core 이상) 도입 명시, 제품명 불명시 — VMware vSAN, Nutanix 등과 경합 가능성 존재 (Red Hat OpenShift Virtualization 제안 가능하나 경쟁 치열)
  • 통합발주 사업: SW 직접구매 제외 사유가 명시된 통합발주 사업으로, Red Hat이 직접 입찰하기 어렵고 SI 사업자를 통한 간접 공급 구조
  • 전자정부 표준프레임워크 의무 적용: Java 기반 전자정부 표준프레임워크 사용 필수로, JBoss EAP 제안 여지는 있으나 오픈소스 WAS와의 경쟁 존재
Red Hat 제안
가능 요소
  • OS 미지정 — RHEL 제안 가능: DBMS 6식, WEB 4식, WAS 17식, HA 12식, 백업SW 4식, EMS 1식 등 모든 상용SW 항목에 "최신OS 및 백신 포함"이 명시되어 있으나 OS 제품명이 미지정 → RHEL 번들 제안 가능
  • WAS 17식 — JBoss EAP 제안 가능: WAS S/W 8 vCore 17식 도입 필요, 제품명 미지정 → JBoss EAP 제안 기회. 전자정부 표준프레임워크와 호환되며 대규모(17식) 도입이므로 비즈니스 규모 상당
  • HCI 가상화 플랫폼 — OpenShift Virtualization 제안 가능: HCI 가상화 S/W 288Core 이상 1식 필요, 제품명 미지정 → Red Hat OpenShift Virtualization 또는 RHEV 제안 검토 가능
  • Ansible Automation Platform — 인프라 자동화: 대규모 서버(HCI 7식, 각종 보안장비, 네트워크 장비 등) 운영 환경에서 구성 자동화·패치 자동화 용도로 Ansible 제안 가능
  • 온프레미스 기반 컨테이너/PaaS 환경: 통합플랫폼 아키텍처가 온프레미스 기반으로 설계되며, 마이크로서비스 및 API Gateway 적용 요구 → OpenShift Container Platform 제안 검토 가능
  • Quay / OpenShift 컨테이너 레지스트리: 형상관리체계(SFR-033) 및 개발소스 버전 통제 요구사항에서 컨테이너 기반 DevSecOps 파이프라인 제안 여지
  • RFP 내 Red Hat 제품명 명시 없음: 현재 RFP 및 과업지시서 어디에도 Red Hat 상용 제품명(RHEL, JBoss, OpenShift 등)이 명시되지 않아 판정 근거 부재 → 중간 판정 적용
