사업 개요 및 목적
  • 광주광역시도시공사에서 운영 중인 기록관리시스템의 기능 고도화를 목적으로 함.
  • 주요 과업은 기록관리시스템의 도면 관리 기능 개발, 대용량 파일 처리 환경 구축, 기존 데이터 이관, 기록관리기준표 관리 프로세스 고도화, 전자결재시스템 연계 체계 마련 등임.
주요 정보
  • 사업 예산: 79,200,000원 (VAT 포함)
  • 사업 기간: 계약일로부터 4개월 이내
담당자 정보

  • 계약 담당: 재무회계팀 진영준 (062-600-6655, jiggy90@gmcc.co.kr)
핵심 요구사항
  • 핵심 기술 및 비즈니스 요구사항
    • GB 단위의 대용량 도면 파일(CAD, PDF 등)에 대한 안정적인 업로드/다운로드 기능 개발
    • 도면 목록 조회 및 검색 결과 5초 이내 화면 표출 성능 요구
    • 기존 전자결재시스템(핸디소프트 그룹웨어)과의 안정적인 연계
    • 특정 웹 브라우저(IE) 종속성을 제거하고 Edge, Chrome 등 다양한 환경에서 호환성 확보
  • 구매 명시 S/W
    • 제안요청서 35페이지 '라. 상용SW 직접구매' 항목에 따라, 본 사업에서 직접구매 대상 상용SW는 존재하지 않음.
Red Hat 제안
불가능 요소
  • S/W 제품 구매가 포함되지 않은 순수 개발 용역 사업임.
  • 사업 예산(약 7,900만원) 규모가 작아, 개발 인건비 외 신규 상용 S/W 도입 비용을 포함하기 어려움.
  • 기존 시스템의 기능을 고도화하는 사업이므로, 현재 운영 중인 인프라(OS, WAS 등)를 그대로 재사용할 가능성이 매우 높음.
  • 경쟁사 제품이 명시되지는 않았으나, 특정 S/W가 지정되지 않아 사업자(SI)가 비용 절감을 위해 무료 S/W(Rocky Linux, Tomcat 등)를 선택할 수 있음.
Red Hat 제안
가능 요소
  • RHEL: 기술적용계획표(67p)의 서버 운영체제 항목에 'Linux'가 명시되어 있어, 안정성과 기술지원을 중시하는 공공기관의 특성을 고려하여 RHEL 제안 기회 탐색 가능.
  • JBoss EAP: 기술적용계획표(68p)에 프로그래밍 언어로 'Java'가 포함되어 있어, Java 기반 애플리케이션 개발 시 경량화되고 안정적인 JBoss EAP(WAS)를 파트너사를 통해 제안할 수 있음.
  • 대용량 파일 처리 및 시스템 안정성, 가용성 보장 등 비기능적 요구사항(11p, 16p)은 RHEL의 기술적 강점과 부합하므로, 이를 제안의 설득 논리로 활용 가능.
