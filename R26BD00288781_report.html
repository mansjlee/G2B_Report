사업 개요 및 목적
  • 한국로봇산업진흥원(KIRIA)의 기관 전체 정보·전산시스템(HW·SW)을 분산 운영에서 통합유지보수 체계로 전환하는 사업
  • 유지보수 창구 일원화를 통해 장애 대응 신속성 제고 및 행정 처리비용 절감
  • 전산시스템의 안정적 운영 및 24시간 365일 무중단 운영체계 유지
  • 업무 환경의 IT 의존도 증가에 따른 사용자 요구사항 신속 대응체계 구축
  • 사이버 침해·재난 등 긴급 피해복구 지원 및 보안운영 체계 확립
주요 정보

  • 사업 기간: 2027년 1월 1일 ~ 2027년 12월 31일 (12개월, 이후 매년 1년 단위 통합유지보수 추진 예정)

  • 주요 일정: 입찰방식 제한경쟁입찰, 낙찰자 선정 후 10일 이내 유지관리 계획서 제출, 계약체결 지연 시 일할계산 정산 / 차년도 계약 지연 시 자동 연장 조건 적용

Red Hat 제안
불가능 요소
  • [S/W 납품 없음] 본 사업은 순수 유지보수 용역으로, SW 신규 도입·납품·구독 구매 항목이 없음. 상용SW 라이선스 갱신 비용은 과업 범위에서 명시적으로 제외됨(MAR-016)
  • [경쟁 OS 확정] 운영 환경에 CentOS 6.9(외부망 메일), Oracle Linux 6.6·6.8(내부망 메일·ERP)이 명시되어 있으며, 이 환경에서의 보안 취약점 대응이 과업 요구사항으로 고정됨(MAR-011, MAR-020)
  • [VMware 가상화 확정] MAR-016에서 VMware vSphere 라이선스 갱신이 유지보수 관리 대상으로 언급되어 있어 기존 VMware 가상화 인프라 확정 상태
  • [Red Hat 상용 제품 전무] RFP 전체에 걸쳐 RHEL, OpenShift, Ansible, JBoss, Satellite 등 Red Hat 상용 제품명이 품목으로 단 한 건도 명시되어 있지 않음
  • [Oracle DBMS 확정] ERP 운영환경 Oracle 11g 명시, Oracle 기반 DB 유지관리가 과업의 핵심 요소
Red Hat 제안
가능 요소
  • [EOS 환경 전환 잠재 기회] CentOS 6.9, Oracle Linux 6.x가 이미 EOS(지원종료) 상태로, RFP에서 보안 취약점 대응 범위를 별도로 명시할 만큼 노후화가 심각함. 향후 OS 전환 사업 발생 시 RHEL 제안 가능성의 씨앗으로 활용 가능
  • [가상화 환경] RP(로봇실증인증시스템) 영역에 HPE·DellEMC 가상화 서버 및 VMware 기반 인프라가 운영 중임. 중장기적으로 OpenShift Virtualization 전환 제안 접점으로 검토 가능하나, 현재 사업에서는 기회 없음
  • [현 사업 내 Red Hat 직접 제안 가능 요소 없음] Red Hat 상용 제품명이 전혀 없고, SW 납품 구매가 제외된 순수 용역 사업으로, 이번 입찰에서 Red Hat 제품을 직접 제안하거나 납품할 기회는 존재하지 않음
