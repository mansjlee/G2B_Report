사업 개요 및 목적
  • AI가 활용 가능한 국가 데이터 인프라 공통기반(원-윈도우)을 고도화하여 데이터 활용성 및 상호운용성을 증대하는 사업
  • 외부 LLM·AI 에이전트가 MCP·A2A 등 표준 기반으로 국가데이터 통합플랫폼의 데이터를 검색·호출·활용할 수 있는 AI 친화적 데이터 환경 구축
  • 연계 플랫폼 메타데이터 정제, 카탈로그 전환·신규연계, 국가데이터 인프라 컴플라이언스·표준 수립 및 협의체 운영을 통한 범국가적 AI 전환(AX) 기반 마련

불가능 요소
  • **S/W 공급 포함 여부**: S/W 공급이 포함된 사업이나, 특정 상용 S/W 조달 명세가 없고 제안사 자율 제안 구조로 Red Hat 제품 직접 지정 근거 부재
  • **경쟁 제품·플랫폼 명시**: 원-윈도우 클라우드 운영계 NCP(네이버클라우드) 및 가비아 GPUaaS가 명시되어 CSP 종속 구조, 기술적용계획표에 Windows Server·Linux(범용) 병기, 전자정부 표준프레임워크·Java/JSP·Python 개발 환경 지정
  • **기타 제약**: 기술독립성·개방형 기술·특정기술 비종속 원칙(COR-004), 기존 원-윈도우 운영계·유지관리업체(MSP/CSP)와 협의 필수, VMware/Oracle/Rocky Linux 등은 명시되지 않으나 Red Hat도 지정 제품 아님, 사업 종료 후 추가 라이선스·구독료 없는 방식 원칙(COR-001), 패키지 제품에는 전자정부프레임워크 적용 제외
Red Hat 제안
가능 요소
  • **RHEL**: 기술적용계획표 플랫폼 분야 Linux 서버 OS 적용 대상, MCP 서비스 구현 인프라(ECR-001)·AI 검색 연계 인프라(ECR-003)의 클라우드 인스턴스 OS로 RHEL 제안 가능(NCP RHEL 지원 시)
  • **OpenShift**: MCP 서버·LLM 모델 서빙·비동기 다중 AI 에이전트 처리 구조(SFR-001~004)의 컨테이너 기반 마이크로서비스 아키텍처, 개발·운영 환경 분리, 확장형 연계 체계에 PaaS 플랫폼으로 제안 가능
  • **Ansible**: 클라우드 인프라 자동 프로비저닝, MCP·LLM 환경 배포 자동화, 데이터 파이프라인·백업 체계 운영 자동화, 다수 플랫폼 API 연계 관리에 IaC/자동화 솔루션으로 제안 가능
  • **기술 요구사항 정합성**: 기술독립성·유연성·확장성 요구, REST API·컨테이너형 모듈형 구조, 클라우드 보안(CSAP)·VPN 연계, 24×365 상시운영·이중화·백업 요구와 Red Hat 엔터프라이즈 Linux·컨테이너·자동화 스택의 강점 일치, 단 SI/컨설팅·개발 비중이 높아 인프라 레이어 제안이 주요 진입점
