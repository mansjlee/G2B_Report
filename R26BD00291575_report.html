불가능 요소
  • [SW 공급 없음] RFP에 "분리발주에 관한 사항: 상용 SW 직접구매 없음"이 명시되어 있으며, "본 사업은 5천만원을 초과하는 소프트웨어 도입이 없으므로 소프트웨어 분리발주 대상에 해당하지 않음"이라고 명확히 규정 → SW 납품·구독 기회 없음
  • [Red Hat 상용 제품명 전무] RFP 전문에 RHEL, OpenShift, Ansible, JBoss EAP, Satellite, AAP 등 Red Hat 상용 제품명이 단 한 건도 명시되지 않음
  • [현행 DBMS 경쟁 제품] 기존 DBMS로 MySQL Enterprise Edition(Oracle 상용 제품)이 명시·운영 중이며, 본 사업은 이의 유지관리를 포함하므로 RH DBMS 진입 여지 없음
  • [순수 위탁운영·용역 사업] 사업의 핵심은 기존 시스템 운영·유지보수 및 기능개선 개발 용역이며, 신규 인프라·플랫폼 구축이 아니므로 Red Hat 솔루션 도입 기회가 구조적으로 차단됨
  • [HW/SW 인프라 현황 비공개] 현행 서버·OS·미들웨어 구성 현황은 보안사항으로 방문 열람만 가능하여 제안 기반 정보 확보가 제한적이나, 전반적인 사업 성격상 RH 제품 제안 가능성이 낮음
  • [중소SW 사업자 제한 입찰] 연차 계약금액 20억원 미만으로 중소SW사업자만 참여 가능, Red Hat이 직접 사업을 수행하거나 주도적으로 관여하기 어려운 구조

가능 요소
  • [클라우드 네이티브 전환 언급] 제조 AI24 통합플랫폼이 "클라우드 네이티브 기반"으로 구축된다고 명시되어 있으나, 이는 본 사업(위탁운영)이 아닌 별도 구축 사업의 내용이며, 현 RFP에서 OpenShift/OCP 등 구체적 기술 스택이 특정되지 않음
  • [Linux 계열 서버 OS 항목 언급] 기술적용계획표에 서버용 개방형 운영체제로 POSIX, UNIX, Windows Server, Linux 항목이 포함되어 있으나, 이는 표준 준수 체크리스트 항목일 뿐 특정 OS 채택을 의미하지 않음
  • [간접 제안 기회] 향후 제조 AI24 통합플랫폼 구축 사업(별도)에서 클라우드 네이티브·컨테이너 플랫폼 요구 시 OpenShift 제안 가능성 존재 — 현재 운영사가 통합 전환을 지원하므로, 해당 구축 사업 수주 업체와의 협업을 통한 간접 기회 모니터링 필요
  • [RFP 내 Red Hat 제품·동의어 명시 없음] 본 RFP에는 RHEL, OpenShift, Ansible, JBoss EAP 등 Red Hat 상용 제품 또는 동의어가 전혀 언급되지 않음 → 직접적인 영업 기회 없음
