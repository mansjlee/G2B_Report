Red Hat 제안
불가능 요소
  • S/W 신규 구매(통합발주) 없음: 본 사업은 기존 운영 중인 시스템의 유지관리·기능개선 용역으로, 신규 S/W 도입·납품 항목이 별도로 명시되어 있지 않음
  • DBMS 경쟁 제품 사용 중: 현행 DBMS로 PostgreSQL(오픈소스)이 사용 중이며, RHEL 기반 DBMS 전환 가능성은 낮음
  • OS 정보 비공개: 하드웨어/소프트웨어 구성 상세 정보가 보안 사유로 공개되지 않아(방문 열람 필요) 현행 OS 환경을 RFP에서 직접 확인 불가
  • 순수 유지관리·용역 사업: 20억 미만 용역 사업으로 중소기업 단독 참여 사업이며, Red Hat이 직접 입찰할 수 없는 구조
  • 경쟁 제품 명시 없음(긍정 요소): Ubuntu, Rocky Linux, Oracle Linux, VMware 등 명시적인 경쟁 제품은 RFP에 등장하지 않음
Red Hat 제안
가능 요소
  • JBoss 4식 유지보수 대상 명시 → 높음 판정 근거: 패키지 소프트웨어 목록 WEB/WAS 항목에 "Jboss 4식"이 유지관리 대상으로 명시되어 있음. 판정 규칙에 따라 JBoss가 운영·유지보수 대상으로 나오면 EAP 표기 여부·라이선스 형태 불문하고 반드시 높음 판정
  • JBoss EAP 구독 갱신 기회: 현행 운영 환경에 JBoss 4식이 운영 중이므로, WAS 사업자를 통한 JBoss EAP 서브스크립션 갱신 또는 신규 전환 영업 기회 존재. SI 사업자와 협력 채널을 통한 접근 필요
  • RHEL 제안 가능성: 현행 서버 OS 정보가 비공개(방문 열람)이나, 공공기관 G-Cloud 환경에서 운영 중이므로 Linux 계열 OS 사용 가능성이 높음. 방문 열람 후 RHEL 운영 여부 확인 시 추가 갱신 기회 발굴 가능
  • 전자정부 표준프레임워크 환경: 교육포털의 전자정부 표준프레임워크 전환 요구(Java/Spring 기반)는 JBoss EAP 운영과 연계될 수 있으며, Red Hat 미들웨어 스택 제안 여지 존재
  • Ansible 자동화 제안 여지: 정기·예방점검 자동화, 시스템 패치 관리, 보안 취약점 점검 자동화 등의 요구사항(MPR-004, SER-003 등)에 Ansible Automation Platform 제안 가능
  • RFP 내 Red Hat 제품명 직접 명시 현황: "Jboss 4식" (WEB/WAS 유지관리 대상, 패키지 소프트웨어 목록)
