불가능 요소
  • 신규 S/W 구매·납품 항목 없음: 본 사업은 기존 도입 장비 및 SW에 대한 유지관리 용역으로, 신규 Red Hat 상용 제품 납품·구독 구매 항목이 명시되어 있지 않음
  • Red Hat 상용 제품명 미명시: RFP 전체에 걸쳐 RHEL, OpenShift, Ansible, JBoss EAP 등 Red Hat 상용 제품명이 유지보수 대상 목록에 명시적으로 기재되어 있지 않음 (보안상 비공개 처리)
  • 유지보수 대상 세부 목록 비공개: 유지보수 품목 세부 현황이 보안상 비공개로, Red Hat 제품 포함 여부 확인 불가 (방문 열람만 가능)
  • 기술지원협약 대상 목록에 Red Hat 미포함: 공개된 기술지원협약 대상 15개 품목(Cisco, 국내 솔루션 업체 등) 중 Red Hat 관련 제품은 없음
  • 경쟁 제품 가능성: 운영 중인 서버 환경의 OS가 명시되지 않아 Windows Server, Oracle Linux 등 경쟁 OS 환경일 가능성 배제 불가. 뷰릭스(관제SW) 등 국내 솔루션 중심의 환경으로 추정됨
  • 중소기업 참여 사업: 20억 미만 사업으로 대기업 참여 제한, Red Hat이 직접 입찰 불가 (SI·유지보수 전문 중소기업 채널 통한 접근 필요)
Red Hat 제안
가능 요소
  • Linux 기술 스택 적용 가능성: 상주인력 자격 요건에 "AIX·리눅스 관련 자격증", 비상주인력 조건에 "Linux(LPIC) 자격증"이 명시되어 있어, 운영 환경에 Linux 계열 OS가 포함되어 있을 가능성이 높음. RHEL 제안 여지 존재
  • 서버·OS 운영 환경 미공개: 유지보수 대상 서버 62대의 운영체제가 비공개이므로, 현장 방문 열람을 통해 RHEL 사용 여부 확인 필요. RHEL 기반 서버가 포함되어 있을 경우 구독 갱신 기회로 연결 가능
  • 기술적용계획표의 Linux 항목 명시: 붙임4 기술적용계획표에 운영체제 항목으로 "Linux"가 명시되어 있어, Linux 기반 서버 운영이 사업 범위에 포함됨을 시사함
  • 상용SW 유지보수 대상 규모: 상용SW 6,905개, 보안솔루션 3,145개 등 대규모 유지보수 대상 중 Red Hat 제품 포함 여부는 현장 방문 확인 필요
  • RFP에 명시된 Red Hat 상용 제품명·수량: 없음 (유지보수 대상 세부 목록 비공개로 확인 불가)
  • 영업 접근 전략: 현장 방문(보안각서 제출) 후 유지보수 대상 SW 목록 열람을 통해 RHEL/JBoss 등 Red Hat 제품 포함 여부를 확인하고, 낙찰 가능 중소 SI 파트너사를 통한 채널 영업 접근 권장
