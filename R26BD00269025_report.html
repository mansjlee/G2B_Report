Red Hat 제안
불가능 요소
  • 경쟁 DB 명시: SAP HANA OEM LEA Edition이 국민건강정보 DB의 현행 및 증설 DBMS로 확정(12TB 라이선스 통합발주). Oracle 11g(R2)는 기존 전자처방전 DBMS로 운영 중.
  • 경쟁 미들웨어 명시: Weblogic, Tuxedo가 기존 내부·외부 시스템 미들웨어로 명시되어 있어 JBoss EAP 신규 제안 공간 제한적.
  • 기존 가상화 인프라: ClovirVDI, ESXi가 현행 VDI 및 가상화 서버 운용체계로 명시. Red Hat Virtualization(RHEV) 대체 여지 낮음.
  • 분석 S/W 기존 구축: SAS, SPSS, STATA가 현행 분석 SW로 운영 중이며 신규 증설 대상은 R·Python 분석솔루션 4식(상용 비RH 솔루션).
  • OpenShift 직접 명시 없음: 컨테이너 기반 분석환경 구축 요건(ECR-C-008)에 특정 플랫폼 미지정이나, OpenShift가 명시된 구매 품목은 아님.
  • 보안 인증 요건: 도입 제품 전반에 국정원 검증필 암호모듈, 보안기능 확인서 또는 CC인증 요건 적용 → Red Hat 제품의 해당 인증 보유 여부 사전 확인 필요.
  • 클라우드 CSAP 요건: 민간 클라우드 활용 시 CSAP 인증 취득 서비스 사용 의무 → OpenShift 기반 PaaS 제안 시 CSAP 인증 여부 확인 필요.
  • Ansible 언급 없음: RFP 전체에 Ansible 또는 자동화 플랫폼(AAP) 관련 언급 없음.
Red Hat 제안
가능 요소
  • [높음 근거] Redhat Linux 8.x 이상 명시 (ECR-E-001): 기관공유데이터 관리시스템 클라우드 서버 구동환경 조건으로 "Redhat Linux 8.x 이상"을 명시. 행안부 표준 솔루션(Apache/Tomcat/PostgreSQL) 구동 환경으로 RHEL 8.x 이상이 사실상 요구됨. → RHEL 구독 라이선스 직접 제안 기회.
  • 개방형 오픈시스템 OS 요건 (ECR-A-001-01): 신규 도입 서버 OS를 "개방형 오픈시스템"으로 명시, RHEL 계열이 적합. GPU 서버 4대 및 분석서버 신규 도입 대상에 RHEL 제안 가능.
  • 기존 Linux 서버 동일 OS 버전 증설 원칙 (ECR-A-003-04): 현행 빅데이터 분석서버·원격연구분석 서버가 Linux OS 운영 중이며, 동일 소프트웨어 최신 버전 증설 원칙에 따라 기존 서버 OS가 RHEL일 경우 RHEL 최신 버전으로 증설 가능.
  • 프리웨어 제안 불가, 상용제품 한정 (ECR-A-003-02): OS를 포함한 SW 전반에 상용 라이선스만 허용. CentOS·Rocky 등 무상 배포판 제안 불가 → RHEL 상용 구독의 경쟁력 부각 가능.
  • 컨테이너 기반 분석환경 구축 요건 (ECR-C-008): GPU 서버 4대에 컨테이너 기반 사용자별 독립 분석환경, 라이브러리 버전 관리·배포·업데이트·자원관리 구축 요구 → OpenShift(OCP) 또는 OpenShift AI 기반 GPU 분석환경 제안 가능 (특정 플랫폼 미지정, 명시적 제한 없음).
  • 클라우드(IaaS) 기반 기관공유데이터 관리시스템 구축: 공단 운영 IaaS 클라우드 자원 내 신규 구축 → OpenShift 기반 PaaS 레이어 제안 가능(CSAP 인증 확인 전제).
  • RFP 명시 Red Hat 제품·수량 요약:
    • Redhat Linux(RHEL) 8.x 이상: 기관공유데이터 관리시스템 클라우드 서버 구동환경 조건으로 명시(수량 별도 명기 없음; 클라우드 가상 서버 2EA 이상 할당 기준)
    • 그 외 RHEL, OpenShift, Ansible, JBoss EAP 등은 구매 품목으로 별도 명시되지 않음
