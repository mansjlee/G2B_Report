  • 「무기발광디스플레이 생태계 육성을 위한 스마트모듈러센터 구축」 사업의 효율적 추진을 위해 기업 의뢰부터 공정 수행 및 설비 운영까지 전주기 통합관리가 가능한 공정관리시스템 구축
  • CRM(고객의뢰관리), MES(제조공정관리), FDC(데이터 수집·분석), TC(Tool Control), CIM(설비 인터페이스) 등 통합 시스템 구축

  • 공정 데이터 관리의 신뢰성 제고 및 업무 활용성·운영 효율성 극대화

Red Hat 제안
불가능 요소
  • Red Hat 상용 제품명 미명시: RFP 전체에 걸쳐 RHEL, OpenShift, Ansible, JBoss EAP 등 Red Hat 상용 제품명이 도입·납품 품목으로 전혀 명시되어 있지 않음
  • OS 사양 불특정 (Linux 계열 일반 표기): OS 요구사항이 "Linux, Unix, NT 계열"로만 표기되어 있어 특정 상용 OS 브랜드가 확정되지 않음 — 구체적인 Red Hat 제품 도입 확정 근거 없음
  • 가상화 VM 제품 미특정: 가상화 VM(상용SW) 3식이 통합발주 품목으로 명시되어 있으나, VMware, Red Hat Virtualization(RHEV), Nutanix 등 특정 제품명이 지정되지 않아 경쟁 구도 불확실
  • DBMS 경쟁 제품 언급: MS SQL Server, PostgreSQL, MariaDB, SQLite 등 타사 DBMS 제품이 명시되어 있어 Red Hat Data Grid 등 도입 여지 제한
  • NT 계열 OS 비중 높음: TC, CIM, Workstation 등 다수 구성 요소가 "NT 계열(Windows)" 운영체제 기반으로 명시되어 Red Hat Linux 적용 범위 제한적
  • 중소기업자 전용 입찰: 대기업 참여 불가 조건으로 Red Hat 코리아 직접 입찰 불가 — 파트너(SI)를 통한 간접 영업만 가능
  • 순수 개발 용역 중심: 사업의 주목적이 응용 SW 개발·구축 용역으로, Red Hat 상용 구독 제품의 명시적 도입이 의무화되어 있지 않음
Red Hat 제안
가능 요소
  • 서버 OS 미지정 — RHEL 제안 여지: CRM, MES, FDC 등 DB 서버(총 3대) 및 백업 서버의 OS가 "Linux, Unix, NT 계열"로만 명시되어 있어, RHEL(Red Hat Enterprise Linux) 제안이 가능. Enterprise 저장소 접근·보안 패치·연간 기술지원 요건이 명시되어 있어 RHEL 상용 구독의 강점과 부합
  • 가상화 VM(상용SW) 3식 통합발주 — RHEV/KVM 기반 가상화 제안 가능: "Enterprise 저장소 접근 및 안정적 SW 업데이트", "국내 기술지원 및 연간 기술지원 티켓/원격지원 포함(3Node, 1년)" 요건이 Red Hat Virtualization(RHEV) 또는 RHEL KVM 기반 가상화 솔루션의 강점과 일치. 총 3식 통합발주 예정(약 42,000,000원 이내)
  • 보안 패치 업데이트 요건 명시: OS 요구사항에 "보안 패치 업데이트 제공" 조건이 명시되어 있어 RHEL의 Extended Update Support(EUS) 및 장기 지원 구독 강점 부각 가능
  • 컨테이너·자동화 환경 제안 여지: MES, FDC 등 마이크로서비스 기반 아키텍처 구성 시 OpenShift(컨테이너 플랫폼) 및 Ansible Automation Platform(인프라 자동화) 제안 가능 — 다만 RFP에 컨테이너·Kubernetes 명시는 없음
  • 대용량 데이터 처리·실시간 수집 요건: 설비 61점 빅데이터 수집, FDC 시계열 데이터 처리, SPC 통계분석 등의 요건은 Red Hat AMQ(메시징), Data Grid(인메모리 캐시) 등 미들웨어 솔루션 검토 여지 존재
  • RFP에 명시된 Red Hat(또는 동의어) 제품명·수량: 없음 — 문서 전체에 Red Hat 상용 제품명(RHEL, OpenShift, JBoss EAP, Ansible 등)이 직접 명시된 항목 없음
  • 영업 접근 전략: 낙찰 예정 SI 파트너사를 통해 서버 OS(RHEL), 가상화(RHEV/KVM), 자동화(Ansible) 제안 유도 필요. 가상화 VM 통합발주 품목(3식, 약 4,200만 원)이 핵심 공략 포인트
