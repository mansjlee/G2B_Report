Red Hat 제안
불가능 요소
  • Red Hat 상용 제품명 전혀 미명시: RFP 전체 문서에 걸쳐 RHEL, OpenShift, Ansible, JBoss EAP 등 Red Hat 상용 제품명이 단 한 차례도 등장하지 않음
  • GIS 특화 상용SW 고착화: 유지관리 대상 상용SW가 GeoGate(㈜지노시스템), Jeus/WebToB(㈜티맥스소프트), ArcGIS Server(㈜한국에스리) 등 국내 GIS 및 미들웨어 중심으로 완전히 고착되어 있으며, 제조사 기술지원 협약서 제출이 계약 조건으로 명시됨
  • WAS 경쟁 제품 명시: Jeus 7.0, Jeus 8.0(티맥스소프트)이 모든 시스템의 WAS로 사용 중이며 기존 유지관리 대상으로 명시 — JBoss EAP 도입 여지 없음
  • OS 미지정이나 Linux 일반 언급 수준: 기술적용계획표에 "Linux" 항목이 범용 표준기술로만 언급되며, 특정 OS 도입·납품 품목 없음. 서버이전(SFR-009) 요건도 OS 종류 미지정
  • 순수 유지관리·운영 용역: 신규 상용SW 구매·납품·구독 항목이 사실상 없으며(기존 SW 유지관리 위주), Red Hat 제품 도입 발생 구조 아님
  • 중소기업 제한 입찰: 대기업·중견기업 입찰 불가 사업으로, Red Hat Korea가 직접 참여하거나 대형 SI를 통한 채널 접근이 구조적으로 제한됨
  • 인력 요건에 경쟁 환경 명시: 투입 개발자 요건에 "리눅스(Linux), Oracle, Redis 유경험자"를 요구하나, 특정 Linux 배포판(RHEL 등)을 지정하지 않아 제안 근거 부재
Red Hat 제안
가능 요소
  • RFP 내 Red Hat 상용 제품 명시: 없음 — RHEL, OpenShift, Ansible, JBoss EAP 등 Red Hat 상용 제품·동의어가 문서 전체에 존재하지 않음
  • 서버이전(SFR-009) 시 OS 선택 가능성: "도로관리, 제설현장, 포장도로, 도로굴착 OS 만료 서버이전" 요건이 명시되어 있으나, 이전 대상 OS가 지정되지 않음. 수행사가 OS 선택 시 RHEL 제안 여지가 이론적으로 존재하나, 발주기관이 현행 인프라를 고려한 개발(COR-009)을 요구하여 실질적 영향력은 미미함
  • Linux 기반 환경 요구: 기술적용계획표 운영체제 항목에 Linux 적용이 명시되어 있고, 투입인력 요건에 Linux 유경험자를 요구하므로 Linux 기반 서버 환경임은 확인됨. 단, 특정 배포판 미지정으로 RHEL 필요성 주장 근거 약함
  • 공간정보 오픈소스 우선 검토 조항: COR-008에서 "공간정보 서비스 관련 소프트웨어는 오픈소스 활용을 우선 검토"를 명시하고 있어, Red Hat 오픈소스 연계 솔루션 제안의 간접적 접점은 존재함
  • 종합 평가: 이 사업은 기존 GIS·미들웨어 중심 상용SW의 유지관리 용역으로, Red Hat 상용 제품 도입 기회가 없으며 제안 가능성은 낮음으로 판정함
