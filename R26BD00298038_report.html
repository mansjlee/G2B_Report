Red Hat 제안
불가능 요소
  • Red Hat 상용 제품명 미명시: RFP 전반에 걸쳐 RHEL, OpenShift, Ansible, JBoss EAP 등 Red Hat 상용 제품명이 도입·납품·유지보수 대상으로 명시되지 않음
  • 경쟁 OS(CentOS) 다수 명시: G클라우드 운영서버 대부분(웹서버·WAS서버·DB서버·블록체인·로드밸런싱·모니터링 등)이 CentOS 7로 확정 운영 중 (서버 약 15대 이상 CentOS 7 적용)
  • Rocky Linux 명시: 망연계 서버 2식에 Rocky 9.2 명시 (Red Hat 계열이나 커뮤니티 배포판으로 RHEL 상용 제품 아님)
  • 운영 OS 현황 고정: 기술현황에 O/S를 "Linux(Rocky, CentOS)"로 명시, RHEL 도입 여지 제한적
  • 순수 운영 용역 성격: 소프트웨어 분리발주 대상이 아닌 기존 시스템 운영·유지관리 용역으로, 신규 상용 SW 납품·구독 항목이 별도로 없음
  • 20억 미만 중소기업 사업: 대기업·중견기업 참여 제한으로 Red Hat이 직접 입찰 불가
  • WAS: SpringBoot(Docker) 명시: JBoss/EAP 등 Red Hat WAS 제품 도입 여지 없음
  • DBMS: MariaDB 확정: Red Hat 데이터 관련 제품 제안 여지 없음
  • WEB: Apache 명시: Red Hat 웹 서버 대체 제안 여지 없음
Red Hat 제안
가능 요소
  • RFP에 명시된 Red Hat 상용 제품: 없음 (RHEL, OpenShift, Ansible, JBoss EAP 등 미기재)
  • CentOS 7 → RHEL 전환 잠재 기회: CentOS 7은 2024년 6월 EOL 도달. 현재 운영 중인 서버 15대 이상이 CentOS 7 기반으로 보안 지원 종료 상태이며, 차기 운영 사업자는 OS 현행화 필요성 직면 가능. 사업 수행사에 RHEL 전환 제안 가능
  • Rocky Linux → RHEL 전환 제안 가능성: 망연계 서버 2식 Rocky 9.2 운영 중. Rocky Linux 대비 RHEL의 엔터프라이즈 지원·보안 패치 우위를 근거로 전환 제안 가능
  • Linux 계열 OS 운영 환경: 전체 서버 OS가 Linux 계열(CentOS/Rocky)로 구성되어 있어, RHEL 도입 시 기술적 전환 부담이 낮음
  • 컨테이너/클라우드 인프라 운영: SpringBoot(Docker) 기반 WAS 운영 환경으로, 향후 컨테이너 플랫폼 고도화 시 OpenShift 제안 여지 존재 (단, 본 사업 범위 내 아님)
  • 사업 수행 SI 업체 대상 간접 영업 가능: 낙찰 사업자에게 CentOS 7 EOL 대응 방안으로 RHEL 구독 제안 가능 (파트너 경유)
  • Ansible 자동화 제안 여지: 서버 20대 이상 운영·관리 자동화, 보안 패치 자동화 등 Ansible Automation Platform 도입 제안 가능 (단, 본 사업 명시 요구사항은 아님)
