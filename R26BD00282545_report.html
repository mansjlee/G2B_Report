Red Hat 제안
불가능 요소
  • 신규 S/W 납품 목적 사업이 아님: 본 사업은 유지보수 용역이 주목적이며, 신규 상용S/W 도입·납품이 과업의 핵심이 아님
  • 상용S/W 현황 비공개: H/W 및 상용S/W 구성 목록이 보안상 비공개 처리되어 현재 Red Hat 상용 제품의 도입 여부를 RFP 본문으로는 확인 불가
  • Red Hat 상용 제품명 미명시: RFP 전체에 RHEL, OpenShift, Ansible, JBoss EAP 등 Red Hat 상용 제품명이 구매·납품 품목으로 명시되지 않음
  • 대기업·중견기업 입찰 불가: 연차별 사업금액 20억원 미만으로 중소 소프트웨어사업자만 참여 가능하여 Red Hat Korea 직접 참여 불가 (파트너사 통해서만 간접 참여 가능)
  • 경쟁 제품 명시 없음: Ubuntu, VMware, Oracle Linux 등 특정 경쟁 제품은 명시되지 않았으나, 대체 OS·플랫폼 도입도 명시되지 않음
Red Hat 제안
가능 요소
  • 쿠버네티스·컨테이너 환경 → OpenShift 제안 여지: PMR-004에서 쿠버네티스 클러스터 유지보수, 컨테이너화, MSA 운영이 핵심 요구사항으로 명시됨. Red Hat OpenShift Container Platform(OCP)은 엔터프라이즈 쿠버네티스 플랫폼으로 동일 환경에 적용 가능
  • Keycloak OAuth 연계 → Red Hat SSO(RH-SSO) 제안 여지: PMR-004에서 "Keycloak Oauth 연계 유지관리"가 명시되어 있어, 커뮤니티 Keycloak의 상용 전환(RH-SSO) 제안 가능성 존재
  • CI/CD·GitOps 자동화 → Ansible Automation Platform 제안 여지: ArgoCD·Flux 기반 GitOps, Jenkins·Tekton CI/CD 파이프라인, 배포 전략(Rolling·Blue/Green·Canary) 운영이 요구됨 → Ansible Automation Platform(AAP) 적용 여지
  • OS·플랫폼 미지정 → RHEL 제안 여지: 상용S/W 현황이 비공개 처리되어 기반 OS가 확정되지 않음. 클라우드 네이티브 서버 OS로 RHEL 제안 가능
  • 클라우드 네이티브 MSA 아키텍처 유지관리: Service Mesh(예: Istio 기반), API Gateway 운영이 요구되어 OpenShift Service Mesh 제안 여지 있음
  • RFP 내 Red Hat(동의어 포함) 명시 제품·수량: 해당 없음 (상용S/W 목록 비공개로 공식 확인 불가)
