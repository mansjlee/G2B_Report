불가능 요소
  • 유지보수 중심 사업 구조: 신규 S/W 도입이 아닌 기존 시스템 유지보수·위탁운영이 주목적으로, Red Hat 신규 제품 납품·구독 기회가 매우 제한적
  • 경쟁 DB 제품 다수 명시: Oracle 10g SE/EE, Oracle Standard, IBM DB2 등 타사 DBMS가 유지보수 대상으로 확정되어 있어 RHEL 기반 DB 플랫폼 전환 불가
  • 기존 응용 S/W 고정: Handy Groupware, SensMail, OZ Report, Midas Integration, CRO CHECK 등 기존 상용 SW가 유지보수 대상으로 확정되어 있어 JBoss EAP 등 미들웨어 신규 제안 어려움
  • Red Hat 상용 제품 미명시: RHEL, OpenShift, Ansible, JBoss EAP 등 Red Hat 상용 제품이 유지보수 대상 물품내역서에 전혀 포함되지 않음
  • 중소 SW 사업자 입찰 제한: 소프트웨어진흥법 제48조에 따라 대기업·중견기업 입찰 불가 (중소 SW사업자만 참가), Red Hat 직접 입찰 불가, SI 채널을 통한 간접 공급만 가능

가능 요소
  • Linux 운영환경 공식 확인: 기술적용계획표 "플랫폼 및 기반구조 분야"에서 서버용 개방형 운영체제로 Linux가 부분적용으로 명시됨. 어떤 배포판인지는 미지정으로 현재 사용 중인 Linux OS를 RHEL로 전환·교체 제안 여지 존재
  • 가상화 솔루션 100식 비공개 확인 필요: "가상화 솔루션 위원회 승인 후 직접 열람 100식"이 유지보수 대상 목록에 포함되어 있으나 내용 비공개. 현장 열람 시 Red Hat Virtualization(RHEV) 또는 OpenShift 기반 환경 여부 확인 권장
  • 망분리 가상화솔루션 비공개: 망분리 가상화솔루션도 내용 비공개 처리됨. 열람을 통해 RHEL 기반 가상화 환경 여부 확인 필요
  • Polestar EMS "for Windows/Linux" 환경 확인: 공공DNA DB 관제시스템 및 자동모니터링 관제시스템 EMS가 Linux 기반 운영임을 간접 확인 가능. 해당 서버 OS로 RHEL 적용 여지 있음
  • RFP에 명시된 Red Hat(또는 동의어) 제품명·수량: 없음 (RFP 전체에서 Red Hat 상용 제품명 미확인)
