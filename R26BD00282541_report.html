Red Hat 제안
가능 요소
  • 쿠버네티스·컨테이너 환경 → OpenShift Container Platform 제안: PMR-008에서 "쿠버네티스 환경하에 클라우드 네이티브 시스템 운영"을 명시, 기존 업스트림 K8s 환경을 Red Hat OpenShift로 전환·제안 가능
  • CI/CD·DevOps·자동화 → Ansible Automation Platform(AAP) 제안: Jenkins·ArgoCD·Tekton 등 CI/CD 파이프라인 자동화 요구사항에 Ansible AAP 통합 자동화 제안 가능
  • Keycloak OAuth 연계 → Red Hat SSO(RH-SSO) 상용 전환 제안: PMR-008에서 "Keycloak OAuth 연계 유지관리"가 명시되어 있어, 현재 커뮤니티 Keycloak 사용 시 엔터프라이즈 지원이 포함된 Red Hat SSO 전환 제안 가능
  • MSA·Service Mesh → OpenShift Service Mesh(Istio) 제안: "서비스 간 통신(Service Mesh, API Gateway) 유지관리" 요구사항에 OpenShift Service Mesh 제안 가능
  • 클라우드 네이티브 OS 기반 → RHEL 제안: 컨테이너 워커노드 및 서버 OS로 RHEL 도입 가능
  • RFP에 명시된 Red Hat(또는 동의어) 제품명·수량: 없음 (상용SW 구성 비공개)
