Red Hat 제안
불가능 요소
  • S/W 신규 도입·납품 항목 없음: 본 사업은 기존 시스템에 대한 순수 유지관리 용역으로, Red Hat 제품을 포함한 어떠한 상용 S/W의 신규 구매·납품·구독(라이선스) 발주가 없음
  • Red Hat 제품명 전혀 미명시: RFP 전체에 걸쳐 RHEL, OpenShift, Ansible, JBoss, Satellite 등 Red Hat 상용 제품명이 단 한 건도 명시되어 있지 않음. Linux, 리눅스, 공개SW 등의 일반 문구도 없음
  • 현행 시스템 환경 비공개: 시스템 세부 구성도 및 환경은 입찰 참가자가 방문 열람(보안서약서 징구 후)해야 하며, RFP 내에 OS·미들웨어·인프라 스택 정보가 없어 Red Hat 스택 운영 여부 확인 불가
  • 명시된 상용S/W는 국내 타 벤더 제품: 기술지원 확약서 대상 10개 상용S/W는 모두 국내 중소 벤더(투비소프트, 엠투소프트, 펜타시큐리티, 웨어밸리, 코난테크놀러지, 드림시큐리티, 엠앤와이즈, 씨엘시스템즈) 제품으로, Red Hat 제품군과 무관
  • 공동수급·하도급 불허: Red Hat 파트너(SI)가 하도급으로 참여하는 구조 자체가 불가능하여 Red Hat 제품 공급 경로 차단
  • 중소기업자만 참여 가능: 대기업 참여 불가 조건으로, Red Hat의 직접 입찰 참여도 어려운 구조
Red Hat 제안
가능 요소
  • 현행 운영 환경 미공개로 가능성 완전 배제 불가: 시스템 세부 현황은 방문 열람으로만 확인 가능하며, 열람 시 서버 OS(RHEL 등), WAS(JBoss EAP 등) 사용 여부를 확인할 여지가 있음. 단, RFP 텍스트 내 근거 없음
  • DB 최적화·DBMS 튜닝 요구: DBMS Parameter 최적화, SQL 튜닝 등 DB 관련 전문 작업이 요구되나, DBMS 제품 미명시로 Red Hat 직접 연관성은 낮음
  • RFP에 명시된 Red Hat(동의어 포함) 제품명·수량: 없음 — RFP 전체에 Red Hat 상용 제품명, 동의어, 회사명이 전혀 등장하지 않음
  • 영업 활동 권고: 현재 단계에서 Red Hat 직접 제안 기회는 없으나, 입찰 참가 예정 SI/유지관리 업체를 사전에 접촉하여 현행 시스템 내 RHEL·JBoss EAP 운영 여부를 파악하고, 향후 구독 갱신·증설 기회를 모색하는 간접 영업 전략이 필요함
