  • **주요 기능**: 태양광 데이터 수집·종합 모니터링 대시보드, 한전 API 전력데이터 연계, 환경개선 예산배분·시설성능리포트(SFCI), URL 기반 외부업체 정보입력, GIS 옹벽·절토사면 형상 약 2,000건, ECM 검색엔진 기반 개선(SFR-024)

불가능 요소
  • **S/W 공급 미포함**: 본 사업은 응용SW 기능개발·구축 용역이며, Red Hat 제품 등 상용SW 신규 구매·납품 과업이 아님. 클라우드·방화벽·DR·백업 등 운영·유지보수도 과업 대상에서 제외
  • **기존 인프라·라이선스 종속**: ECR-004에 따라 기존 DBMS·WEB/WAS 등 시스템SW 라이선스 범위 내 공동활용 필수, 신규 인프라·솔루션 독립 도입 여지 제한
  • **지정·잠재 경쟁 스택**: CSP KT Cloud, MSP 콘텐츠브릿지, 유지보수 ㈜폭스소프트 고정. 기술적용계획표에 Linux·Windows Server 등 개방형 OS 검토는 있으나 RHEL 등 특정 제품 지정 없음. 전자정부프레임워크·JAVA·기존 ECM·GIS 상용솔루션 연계가 핵심
  • **제안 경로 부재**: 입찰 참가자격은 SW사업자(컴퓨터관련 서비스업)이며, Red Hat이 직접 SI·용역 수행 주체로 참여하기 어려운 구조. HW/SW 상세 현황 비공개로 기존 OS·미들웨어 실태 확인 전 제품 교체·증설 제안 근거 확보 곤란
Red Hat 제안
가능 요소
  • **간접 SI 파트너 경로**: 낙착 SI사의 하도급(50% 이내)·기술협력 파트너로 Ansible Automation Platform, RHEL 서브스크립션, OpenShift 등을 제안서 기술·운영 자동화·DevOps 항목에 포함시키는 보조 제안 가능
  • **기술 요구와의 부합**: RESTful API·토큰 관리·실시간 모니터링·컨테이너/가상화 고려(ECR-001)·성능·부하·장애복구 테스트(TER-006~008) 등은 Red Hat OpenShift·Ansible·RHEL 운영 역량과 부분 정합, 다만 기존 KT Cloud·통합정보망 아키텍처 전제
  • **검색·데이터 처리**: ECM 검색엔진 개선(SFR-024), 대용량 통계·집계·실시간 대시보드 요구는 Red Hat 기반 미들웨어·컨테이ner 플랫폼으로 아키텍처 대안 제시 여지 있으나, 기존 ECM·DBMS 교체 없이는 범위 제한적
  • **실질 기회**: 직접 Red Hat 제품 납품·라이선스 판매 기회는 낮음. 유지보수사·MSP·SI 생태계 내 기술 파트너십·서브스크립션 간접 제안이 현실적 접근
