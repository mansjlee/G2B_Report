Red Hat 제안
불가능 요소
  • RFP 전체에 Red Hat 상용 제품명(RHEL, OpenShift, JBoss EAP, Ansible 등) 미명시: 유지관리 대상 S/W 56종 70식 목록 어디에도 RHEL, JBoss EAP, OpenShift 등 Red Hat 상용 제품명이 기재되어 있지 않음
  • 경쟁 가상화 제품 명시: 협력업체 목록(PSR-004) 및 유지관리 대상 S/W 목록에 VMware(에스엔텍)가 가상화솔루션으로 명시·도입 확정 (VMware는 Red Hat OpenShift/RHEV 경쟁 제품)
  • DBMS: 티맥스티베로 확정: DBMS는 티맥스티베로 제품으로 확정 운영 중이며 Red Hat 제품 개입 여지 없음
  • WAS/WEB: 티맥스소프트 확정: WAS·WEB서버는 티맥스소프트(오픈정보) 제품으로 확정 (JBoss EAP 대체 불가)
  • OS 교체 대상이 CentOS: ECR-001에서 명시된 OS 교체 대상 Linux 서버 8대 모두 "Linux CentOS"로 명기됨 — RHEL이 아닌 CentOS(커뮤니티판)이며, 교체 후 도입 OS가 RHEL로 확정되지 않음. "오픈소스의 경우 EOS 기간 고려하여 최적 제품 제공"이라는 조건만 존재
  • 순수 유지관리 용역 성격: 신규 시스템 구축이 아닌 기존 시스템 유지관리 용역으로, 신규 Red Hat 제품 도입이 명시되지 않음
  • 20억 미만 중소기업 사업: 소프트웨어 진흥법에 의거 대기업·중견기업 입찰 불가 — Red Hat Korea는 직접 입찰 불가, SI 파트너를 통한 간접 제안만 가능
  • JBoss 미명시: 유지관리 대상 WAS는 티맥스소프트 제품으로 확정, JBoss/JBoss EAP 관련 언급 전혀 없음
Red Hat 제안
가능 요소
  • CentOS → RHEL 전환 제안 기회 (가장 핵심 포인트):
    • ECR-001에서 EOS 임박/종료 OS로 Linux CentOS 8개 서버(홈페이지#1·#2, 책이음(자관), RFID, 메타검색, 빅데이터, 좌석예약WEB#1·#2)를 교체 대상으로 명시
    • CentOS는 커뮤니티판으로 판단되나, 교체 후 도입 OS가 미확정 상태 — RHEL로의 전환 제안 가능
    • ECR-002에서 "오픈소스의 경우 EOS 기간 고려하여 최적 제품을 제공"이라 명시 → RHEL의 장기 엔터프라이즈 지원(10년) 강점 어필 가능
    • Windows Server 2016(전자도서관WEB#1·#2) 교체 대상도 존재하여 Linux 계열 전환 시 RHEL 추가 제안 여지 있음
  • 서버보안솔루션(Linux) 1식 유지관리 대상 명시: Linux 서버 환경이 현행 운영 중임을 확인할 수 있으며, Linux 운영 환경에서 RHEL 도입 필요성 어필 가능
  • 가상화시스템 유지관리 요구사항(MPR-016): 신규 구축·재구축 필요 시 기술 검토 지원 명시 → 향후 OpenShift/RHEV 전환 가능성 타진 가능 (단, 현재 VMware 확정)
  • Ansible Automation Platform 제안 여지: 보안패치 자동화, OS 패치·업그레이드 자동화, 정기점검 자동화 등 요구사항(MPR-002, MPR-010, SER-002) 대응 솔루션으로 Ansible 제안 검토 가능
  • RFP 내 Red Hat(또는 동의어) 상용 제품 명시 없음: RHEL, OpenShift, JBoss EAP, Ansible, Satellite 등 Red Hat 상용 제품명이 RFP 어디에도 기재되지 않음 — 직접 명시 기회는 없으나 CentOS→RHEL 전환 영업 타겟으로 활용 가능
  • 파트너 활용 간접 제안 전략: 중소기업 대상 사업이므로 Red Hat 공인 파트너(SI)를 통해 CentOS 교체 OS로 RHEL 납품 제안 유도 가능
