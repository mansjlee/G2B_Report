  • 대국민 날씨누리 홈페이지 및 날씨알리미 모바일 앱 운영·유지관리 포함
  • 예보정책 변경에 따른 응용개발 SW 개선·변경 대응 및 보안취약점 조치 수행
  • IBM ESS3500 스토리지(300TB) HW 유지관리 및 재해복구(DR) 체계 유지

    • 계약상대자가 사업수행 시 별도 상용 SW 사용 시 정품 라이선스 증빙 제출 의무 (MPR-001)
    • 소스코드 관리 등을 위한 관련 상용SW 구매 필요 시 비용은 제안사 부담 (오픈소스 기반 SW 사용 권장, MPR-012)
    • 실시간 시스템 모니터링을 위한 상용소프트웨어 구매 제안 시 비용은 제안사 부담 (MPR-005)
Red Hat 제안
불가능 요소
  • [S/W 납품·구독 항목 없음]: 본 사업은 순수 운영·유지관리 용역으로, RHEL·OpenShift·Ansible 등 Red Hat 상용 제품이 구매·납품·구독 품목으로 RFP 어디에도 명시되지 않음
  • [경쟁 OS 명시]: 운영관리 대상 서버 목록(붙임 8)에 Rocky Linux 검증서버 3대(선진예보시스템2 Rocky Linux 검증서버 #1·#2·#3)가 명시적으로 기재됨. Rocky Linux는 RHEL의 커뮤니티 대체 OS로 경쟁 제품에 해당
  • [비Red Hat WAS 환경]: 기술 요구사항(MHR-002)에 WAS로 WebtoB/JEUS(TMAX 제품) 및 Apache/Tomcat이 명시되어 있어 JBoss EAP 제안 여지 없음
  • [인프라 유지보수 제외]: 서버·가상화·쿠버네티스·WEB/WAS·DBMS·네트워크 등 인프라 유지보수는 기상청 정보통신기술과 소관 별도 사업에서 수행하며, 본 사업 범위에서 명시적으로 제외됨
  • [대부분 OS 정보 비공개]: 전체 서버 128대 이상의 OS·IP 정보가 "보안서약서 작성 후 담당자 입회하에 열람 가능"으로 비공개 처리되어 추가 Red Hat 상용 제품 도입 여부 확인 불가
Red Hat 제안
가능 요소
  • [RFP 내 Red Hat 제품명 명시 없음]: RHEL, OpenShift, OCP, Ansible, JBoss EAP, Satellite 등 Red Hat 상용 제품명이 RFP 본문 어디에도 품목으로 나타나지 않음
  • [Linux 기반 서버 다수 운영]: 서울 81대 + 오창 58대 총 139대 이상의 Linux 서버가 운영 중이나, 대부분 OS 정보가 보안상 비공개이며 Rocky Linux 검증서버 외 RHEL 도입 여부는 확인 불가
  • [쿠버네티스 환경 운영]: 날씨누리·날씨알리미 쿠버네티스 워커노드 50여 대 이상이 운영 중이나, 현재 플랫폼이 OpenShift인지 확인 불가하며 본 사업에서 인프라 유지보수는 제외됨
  • [향후 기회]: 현재 Rocky Linux가 검증 환경에 사용되고 있어 프로덕션 환경의 엔터프라이즈 전환 필요성을 어필할 수 있으나, 본 용역 사업 범위 내에서 직접 제안은 어려움. 인프라 구매·증설 관련 별도 발주 사업 모니터링 필요
