사업 개요 및 목적
  • 부산대학교치과병원이 운영 중인 의료정보시스템(OCS·EMR·PACS 등) 관련 서버, 스토리지, 네트워크, DBMS 및 상용 소프트웨어 등 전산 인프라 전반에 대해 전문적이고 체계적인 유지보수 체계를 확보하고자 함
  • 진료 서비스의 연속성을 보장하고 시스템 장애를 예방하며, 정보시스템 성능 및 보안 취약 요소를 지속적으로 개선하여 서비스 품질 향상을 도모하는 것이 핵심 목표
  • 신규 소프트웨어 도입·납품 없이 기존 운영 중인 전산장비 및 상용 SW에 대한 유지보수 용역(기술지원, 예방점검, 장애처리, 성능관리 등)이 사업의 전부임
주요 정보

  • 사업 범위: 서버/스토리지(IBM, Lenovo, Hitachi, NetAPP 등), 네트워크 장비(Cisco 등), RDBMS(Oracle Database 19c), 상용 소프트웨어(PACS, 그룹웨어, 백업솔루션, 보안솔루션 등), 무인수납(KIOSK)/DID, 모바일 솔루션에 대한 통합 유지보수

Red Hat 제안
불가능 요소
  • 신규 S/W 납품·도입 없는 순수 유지보수 용역: AhnLab V3 Endpoint Security Site License 연간 납품 1건을 제외하면 사업 전체가 기존 장비 및 SW 유지보수 용역이며, Red Hat 상용 제품의 신규 도입·납품·구독 항목이 전혀 없음
  • RFP 전체에 Red Hat 상용 제품명 전혀 미기재: RHEL, JBoss, OpenShift, Ansible, Satellite 등 Red Hat 상용 제품명이 유지보수 대상 목록, 서버 구성, 상용 SW 목록 어디에도 명시되지 않음
  • 운영 OS 미명시: 서버 유지보수 범위에 "운영체제를 포함한 S/W"가 포함된다고 기재되어 있으나, 구체적인 OS 제품명(RHEL, CentOS, Ubuntu 등)이 전혀 기재되지 않아 Red Hat 상용 제품 존재 여부 판단 불가
  • DBMS는 Oracle Database 19c로 고정: DBMS 유지보수 대상이 Oracle Database 19c 4식으로 명확히 명시되어 있고, Oracle 파트너(OPN) 자격 보유 업체만 참여 가능하여 Red Hat 제품 개입 여지 없음
  • 경쟁·대체 보안 솔루션 명시: AhnLab, Genian, LogCenter, ChakraMax, Wapples 등 다수 타사 보안/관리 SW가 고정 유지보수 대상으로 명시되어 있어 Red Hat 보안 솔루션 제안 여지 없음
  • 서버 구성도 비공개: 세부 서버 구성도는 보안상의 이유로 공개하지 않아 운영 OS 환경 상세 파악 불가
Red Hat 제안
가능 요소
  • RFP 내 Red Hat(또는 동의어) 제품명·수량: 없음 — RFP 전문 어디에도 Red Hat / RHEL / JBoss / OpenShift / Ansible 등 Red Hat 상용 제품명이 기재되지 않음
  • 간접적 제안 가능성 (매우 제한적): 서버 유지보수 범위에 "운영체제를 포함한 S/W" 지원이 포함된다는 문구가 있어, 비공개된 서버 구성도상 RHEL이 운영 OS로 사용 중일 가능성은 존재하나, 현재 공개 문서만으로는 확인 불가
  • 향후 영업 접점 활용 가능성: IBM Power S1014, IBM X 시리즈 등 IBM 서버가 다수 포함되어 있어 RHEL for SAP / RHEL on IBM Power 등 연계 영업 기회로 활용할 수 있는 간접 접점은 존재하나, 본 사업에서 직접 제안은 불가
  • 결론: 본 사업은 순수 유지보수 용역으로 Red Hat 상용 제품이 유지보수 대상 목록에 명시되지 않아 판정 규칙상 "낮음"에 해당. 단, 서버 구성도 열람(방문 열람 필요) 후 운영 OS가 RHEL로 확인될 경우 판정 상향 재검토 필요
