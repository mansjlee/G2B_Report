사업 개요 및 목적
  • 본청 개발서버에 임시 운영 중인 중경용 112 교육시스템을 별도 전용 인프라로 분리·재구축하고, 실제 112시스템과 동일한 환경에서 신고 접수·지령·종결 등 전 과정을 시나리오 기반으로 반복 훈련할 수 있는 교육용 112시스템을 구축하는 사업이다.
  • 상황요원의 초기 판단·지령 정확도 향상과 교육·평가·이력관리 통합 수행, 전국 표준화된 교육체계 및 교육 이력 관리 기반 마련이 핵심 목표이다.
주요 정보
  • 사업 예산: 7억 2,000만원(부가가치세 포함, 연구용역비 1억 5천만원·자산취득비 5억 7천만원)
  • 사업 기간: 계약일로부터 150일
  • 사업 범위: 웹 방식, 최대 500명 내외 동시 접속, 하드웨어 4대·상용 소프트웨어 6식 도입, 112 교육·훈련 시나리오 내재화, 전문교육 관리 웹·모바일 앱 고도화, 기존 112시스템과의 데이터·시스템 연계
  • 주요 일정: M(개발계획수립·시나리오·시스템 분석/설계) → M+1~M+2(시스템 개발) → M+3(사용자 교육·시범운영) → M+4(전국 배포)
  • 계약 방법: 조달청 제한경쟁입찰(협상에 의한 계약), 기술평가 90%·가격평가 10%
담당자 정보

  • 사업 책임자: 치안상황과 경정 김상균 (02-3150-0525)
  • 사업 실무자: 치안상황과 경위 이병호 (02-3150-0952)
핵심 요구사항
  • 기술·기능: 실제 112시스템과 동일 UI/조작환경, 시나리오 기반 접수·지령·종결·폴맵·보이는112·공동대응·CCTV 등 기능 학습, 조작 이력 자동 기록·평가, 500명 동시접속, 응답 3초 이내, HA·백업·장애 1시간 이내 복구, 전자정부 표준프레임워크(현 112시스템 동일 버전), Multi Browser·반응형 웹, 기존 112시스템 DBMS 연동, 본청 112시스템·교환기·폴맵 등 연계
  • 보안·품질: 관서별 계정·권한 분리, 개인정보보호·시큐어코딩·취약점 점검, 경찰청 보안규정 준수, 하자보증 1년
  • 통합발주 S/W(수량):
  • WEB(Web Server SW) 1식
  • WAS(Web Application Server SW) 1식
  • DBMS(데이터 통합관리 SW) 1식
  • PUSH SW(HTML5 기반 PC·모바일 연동) 1식
  • 리포팅 SW(HTML5 기반 보고서 출력 관리) 1식
  • 클라이언트 연동 미들웨어 SW(HTML5 기반 112 PC 디바이스 연동) 1식
  • 교육용 112시스템 운영 서버 이중화 SW 1식(Unix 서버용)
  • 하드웨어(참고): Unix 서버(운영) 1식, X86서버(GW) 2식, X86서버(배포/관리) 1식
Red Hat 제안
불가능 요소
  • 운영 서버 OS: ECR-004에서 개방형 64Bit UNIX OS 및 HW 제조사 자체 OS 탑재를 요구하여 RHEL 적용 대상에서 제외된다.
  • 기존 SW 증설 방식: 붙임14 직접구매 계획에서 WEB·WAS·DBMS·PUSH·리포팅 SW 모두 직접구매 제외(기존 112시스템 SW 기반 증설)로 명시되어 Red Hat 미들웨어 신규 도입 여지가 없다.
  • 경쟁·대체 스택: WAS는 JDK8·J2EE7 및 Apache/IIS/OHS 등 연동, DBMS는 Active-Active 클러스터 등 상용 DBMS 요구로 Oracle/Tibero 등 기존 112 스택과의 호환성이 전제된다.
  • 전문 솔루션 고정: PUSH(기존 112 PUSH 호환·마이그레이션), 리포팅(GS인증·HWPX Export), 클라이언트 미들웨어(Active-X 전환·112 PC 네이티브 연동) 등 Red Hat 포트폴리오 외 국산·전문 솔루션이 필수다.
  • 사업 성격: HW·SW 납품·설치 및 112 응용 개발·고도화 SI 중심으로 Red Hat 제품 직접 조달 항목이 명시되지 않았다.
  • 입찰 제한: 20억원 미만 중소 SW사업자만 참가 가능(소프트웨어사업자 일반현황 ‘공공 소프트웨어사업 입찰참여 제한금액: 없음’ 확인 대상).
Red Hat 제안
가능 요소
  • RHEL(GW 서버): ECR-005 GW 운영 서버 2식에 “최신 Linux Server OS(오픈소스 운영체제 제외)” 요건이 있어 상용 Linux인 RHEL 구독·지원 제안 가능하다(Oracle Linux, SUSE 등과 경쟁).
  • Linux 플랫폼 호환: WAS 요구사항에 Linux 플랫폼 지원이 명시되어 있어 GW·배포 서버 Linux 기반 구성 시 RHEL을 OS 레이어로 제안할 여지가 있다.
  • Ansible(간접): HA·배포·설정관리·장애복구 요구(PER-003, PSR-002)에 대응하는 자동화·구성관리 보조 솔루션으로 Ansible 제안 가능하나 RFP에 명시되지 않아 SI 제안사 경유 간접 기회에 해당한다.
  • JBoss EAP(제한적): J2EE7·JDK8 WAS 요건과 부분적으로 부합하나, 기존 112 WAS 증설·호환 전제로 실질 제안 가능성은 낮다.
  • 파트너 협력: Red Hat 단독 입찰보다 SI·HW 납품사와 공동수급·하도급(50% 이내) 형태로 GW Linux·자동화 영역에 기술 지원·라이선스 공급 역할 수행 가능하다.
