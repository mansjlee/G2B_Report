Red Hat 제안
불가능 요소
  • 본 사업은 Red Hat 제품(RHEL, OpenShift, Ansible, JBoss 등) 공급이 아닌, 전문 정보보호 상용 솔루션 라이선스 갱신·업그레이드 및 위협 모니터링 서비스 구축이 핵심 과업
  • 모바일 백신, 악성코드 차단, 이메일 샌드박스, EDR, 매체제어·보안USB, CTI(사이버위협 모니터링) 등 특정 보안 벤더 솔루션 갱신·연동이 명시되어 Red Hat 직접 제안 대상 S/W가 없음
  • 악성코드 차단 솔루션은 CC인증·GS인증·국내 개발 엔진 등 전용 보안 제품 요건이 명시되어 Red Hat 제품으로 대체 불가
  • 기존 운영 중인 보안 솔루션과의 호환·연동·갱신이 필수(COR-03, ECR-03~07)이며, 기존 시스템 교체가 아닌 라이선스 갱신 중심 사업
  • 「소프트웨어 개발」사업이 아님에 따라 OpenShift 컨테이너 플랫폼, Ansible 자동화 등 인프라·DevOps 솔루션 적용 요구사항 없음
  • 직접구매 대상(유해사이트 차단 2식, 스팸메일 차단 User 620, 스팸메일 차단 서버 1식)도 네트워크·메일 보안 전용 솔루션으로 Red Hat 해당 없음
Red Hat 제안
가능 요소
  • ECR-01에서 신규 서버 도입 시 "성능이 검증된 최신 OS 버전" 설치 요건이 있으나, 특정 OS·Red Hat 미지정이며 기술적용계획표에서 Linux는 개방형 OS 선택지 중 하나로만 언급
  • 기술적용계획표에 ITIL v3/v4, ISO20000, IaaS/PaaS/SaaS, Linux 등 일반 기술 표준이 포함되어 있으나 본 사업 범위(보안 SW 갱신)와 직접 연관성 낮음
  • Ansible은 사업자(통합 SI)가 프로젝트 관리·배포 자동화 내부 도구로 활용할 여지는 있으나, 발주·평가 대상 Red Hat 제품 공급 요건은 아님
  • Red Hat 직접 입찰·제품 공급보다, 보안 SI/통합사업자의 하도급·파트너 또는 간접 영업(공동수급 구성원) 형태로만 제한적 관여 가능
