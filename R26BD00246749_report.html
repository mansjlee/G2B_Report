  • 상수관망 실시간 감시·누수·유수율 분석·수질·수압 관리·통합 DB 구축을 통해 충남 지방상수도 콘트롤타워 역할 수행 및 수도경영 효율화 도모

불가능 요소
  • 대부분 서버 운영OS가 Windows Server 명시(DMZ·중계·지자체 서버 등), Red Hat OS 직접 지정 없음
  • 가상화 S/W 64Core는 관급 직접구매 대상으로 VMware 등 경쟁 가상화 제품 영역
  • DBMS·WEB·WAS는 상용 제품·동일 제조사·GS인증·Java EE 7 요구로 Oracle/Tibero·JEUS/WebLogic 등 국내 SI 표준 스택에 종속
  • PMS·NMS/SMS·백신·Office·한글 등 인프라·운영 S/W 전량 관급 직접구매로 Red Hat 제품 공급 범위 밖
  • 사업 본질은 상수도 통합모니터링 응용 S/W 개발·유지관리 용역으로 H/W·관급 S/W는 통합사업자 조율·1차 검수 역할
  • 표준프레임워크·전자정부 Java 기반 커스텀 개발 중심으로 OpenShift·JBoss 등 Red Hat 미들웨어 요구 없음
Red Hat 제안
가능 요소
  • 통합서버(ECR-005)에 Windows Server 및 Linux OS 설치 포함 명시 → Linux VM·백업 대상에 RHEL 구독 제안 여지(제한적)
  • 백업 장비 요구에 Linux BMR·가상머신 백업 기능 명시 → RHEL 환경 백업·복구 아키텍처 자문 가능
  • NMS/SMS에 Windows/Linux Class 라이선스 포함 → Linux 서버 모니터링 구간에서 Red Hat 생태계 연계 설명 가능
  • 9개 지자체·통합운영센터 장기 유지관리(36~48개월) → RHEL·Ansible 기반 OS 패치·구성관리를 SI 파트너로서 간접 제안 가능
  • AI·빅데이터·실시간 분석 요구 증가 → 향후 컨테이너·OpenShift 확장 로드맵을 기술 제안서 부가안으로 제시 가능(본 RFP 필수 아님)
