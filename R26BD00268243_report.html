Red Hat 제안
불가능 요소
  • Red Hat 상용 제품 구매 품목 미명시: RFP 및 붙임1 도입대상 품목 목록에 RHEL, OpenShift, Ansible, JBoss EAP 등 Red Hat 상용 제품이 구매·납품 품목으로 명시되지 않음
  • 기존 제품 고착화:
    • 인터넷전화 내선 라이선스: iPECS-UCM IPEXT로 제품 명시 → 타 제품 제안 불가
    • 녹취 라이선스: UBIS-RBT 1.215로 현재 운영 제품 명시 → 동일 제품 증설
    • 컬러링·녹취·음성사서함 S/W: UBIS-RBT, VR, DX 1.215 기존 제품 업그레이드
    • SSL 인증서: 현재 운영 제품 Sectigo Multi SSL 갱신
  • 백업 S/W 인증 요건 제약: GS인증, CC인증, FIPS 140-3, DoDIN, ISO/IEC 27001 등 다수 인증 동시 요구로 사실상 특정 제품에 한정될 가능성 있음 (Red Hat 포트폴리오와 직접적 연관성 낮음)
  • 암·복호화 키관리 S/W: Red Hat 포트폴리오 내 직접 대응 제품 부재
  • S/W 개발 미포함: 본 사업은 시스템 운영 환경 구축(SW 개발 미포함)으로 명시되어 있어 미들웨어(JBoss EAP 등) 도입 맥락 없음
Red Hat 제안
가능 요소
  • Linux OS 미지정 → RHEL 제안 가능: 개발 서버 5대(개발#1 3대, 개발#2 2대) 모두 "리눅스 운영체제 제공" 명시 但 특정 배포판 미지정 → RHEL 제안 여지 존재
  • RHV(Red Hat Virtualization) 기존 운영 환경 확인:
    • 서버 공통규격: "다양한 가상화 S/W 버전 지원(RHEV, KVM 등)" 명시 → RHEV가 기존 인프라에 운영 중임을 시사
    • 백업 S/W 요구사항: "RHV 에이전트 리스 백업 기능 제공" 명시 → RHV(Red Hat Virtualization)가 조달청 현재 운영 환경에 포함되어 있음을 확인
  • 기술 스택 연계 제안 여지: RHEV/RHV 기존 환경이 확인됨에 따라, 개발 서버용 Linux OS를 RHEL로 제안하고 기존 Red Hat 가상화 환경과의 일관성·지원 연속성을 강점으로 어필 가능
  • RFP 내 명시된 Red Hat(동의어) 제품·수량 목록:
    • RHEV (서버 공통규격 지원 요건, 수량 미특정)
    • RHV (백업 S/W 지원 요건, 수량 미특정)
    • ※ 두 항목 모두 구매 품목이 아닌 호환성·지원 요건으로 명시됨
  • 영업 접근 전략: 기존 RHEV/RHV 환경의 유지보수·라이선스 현황을 파악하고, SI 파트너사를 통해 개발 서버 Linux OS(RHEL) 납품 및 기존 RHV 구독 갱신 기회 병행 탐색 권장
