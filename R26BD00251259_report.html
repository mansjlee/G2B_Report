불가능 요소
  • 사업 핵심은 산불조기감지기(센서) H/W 납품·설치가 중심이며, Red Hat 직접 S/W 조달 단독 사업이 아님
  • 통합관제시스템 서버·스위치 H/W는 관급자재로 발주기관이 구축하여, OS·인프라 직접 납품 경로가 제한됨
  • JBoss-WAS 7.8, JBOSS-Apache 2.4 등 레거시 미들웨어가 별첨3에 명시되어 Red Hat 현행 제품(OpenShift, Quarkus 등) 직접 대체 제안이 어려움
  • DBMS는 PostgreSQL 14.0 명시, Red Hat DB 솔루션 직접 지정 없음
  • 전자서명(MagicLine), DB암호화(Petra Cipher) 등 타사 상용보안 S/W가 고정 지정됨
  • 전자정부프레임워크·행안부 표준 연계 아키텍처가 필수이며, OpenShift/Ansible 등 Red Hat 플랫폼 직접 요구 없음
  • 현장시연·감지기 성능이 핵심 평가요소(정성 30점)로 센서·관제 SI 역량이 주도적임
Red Hat 제안
가능 요소
  • 별첨3 행안부 국가공유데이터 플랫폼 연계 인프라 기준에 OS Linux(RHEL 8.8)이 명시되어 RHEL 구독·기술지원 제안 가능
  • JBoss-Apache/JBoss-WAS 기반 WEB/WAS 스택에 Red Hat JBoss EAP 또는 관련 미들웨어 지원·마이그레이션 컨설팅 제안 가능
  • 365일 무중단, 24시간 장애복구, 형상관리·신속 재설치 요구에 RHEL 고가용성·안정성 강점 부각 가능
  • DMZ 중계서버·API 연계, 보안접근통제, 취약점 관리 요구에 RHEL 보안·컴플라이언스 기능 활용 가능
  • 클라우드(CSAP)·IPv4/IPv6 이중지원 등 인프라 요건에 Red Hat OpenShift(간접)·Ansible 자동화를 SI 파트너 연계 제안 가능
  • 계약상대자가 H/W·S/W 자체 확보 원칙이므로, 관제시스템·연계서버 OS 레이어에서 RHEL 라이선스 공급 경로 존재
