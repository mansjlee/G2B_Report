한국수출입은행_노후 정보보호 인프라 교체 - 분석 리포트

레드햇 제안 가능성 낮음
Ubuntu Pro·Windows Server OS 명시 구매, RH 상용 제품 전무
사업 개요 및 목적
  • 한국수출입은행의 노후화된 정보보호 인프라(원격근무 보안 시스템, 모바일 정보보호 인프라)를 최신 제품으로 교체하는 사업
  • 제조사 기술지원 종료로 보안 패치 적용이 불가한 노후 시스템을 교체하여 사이버위협 대응의 지속성 및 운영 안정성 확보
  • 원격근무 보안 시스템(VDI 기반)과 모바일 정보보호 인프라(VMI 기반)의 HW 성능 향상 및 SW 기능 개선을 통해 사용자 체감 성능 개선 및 보안 관리 강화
  • 기존 시스템의 보안정책, 사용자 데이터, OS 이미지 등을 신규 시스템으로 안전하게 이관
주요 정보
  • 사업 예산: 32.5억원 범위 내 (부가세 포함)
  • 사업 기간: 착수일로부터 5개월 이내
  • 사업 범위: ① 원격근무 보안 시스템 HW/SW 교체 (서버·저장장치 6대, L2스위치 11대, 서버 OS 96식, 네트워크 접근제어 1식) ② 모바일 정보보호 인프라 HW/SW 교체 (서버·저장장치 5대, L2스위치 3대, L4/L7스위치 4대, VMI·FIDO·모바일 백신 등 SW 8종) ③ 시스템 재설계, 아키텍처 설계, 시스템 구성, 데이터 이관, 보안정책 이관 용역
  • 주요 일정: M(사업수행계획 수립) → M+1(환경 분석 및 설계) → M+2~M+3(시스템 구성 및 이관, 테스트 및 시험가동) → M+4(운영자 교육, 가동 및 안정화) / 세부 일정은 사업 추진 과정에서 일부 변경 가능

Red Hat 제안
불가능 요소
  • Ubuntu Pro 구매 품목 명시: ECR-017 [모바일] OS설치 기술지원 항목에 "Ubuntu Pro Annual Subscription License" 5식(3년)이 구매 품목으로 명확히 지정되어 있어, 해당 영역의 OS를 RHEL로 대체 제안하기 어려움
  • Windows Server 2025 명시: ECR-008 [원격근무] 기타 S/W 항목에 "Windows Server 2025 Standard 2Core License Pack" 96식이 품목으로 명시되어 있어 서버 OS 영역에서 Red Hat 제안 불가
  • 하이퍼바이저 경쟁 제품 명시: ECR-003/ECR-009 서버 및 저장장치 요건에 "VMware vSphere, Microsoft Hyper-V, Nutanix AHV"와의 호환이 명시되어 있어 Red Hat Virtualization/OpenShift 가상화 제안 여지 극히 제한적
  • Red Hat 상용 제품 전무: RFP 전체에 RHEL, OpenShift, Ansible, JBoss EAP 등 Red Hat 상용 제품명이 단 한 건도 명시되어 있지 않음
  • 정보보호 전문 솔루션 위주 사업: VDI, VMI, FIDO, 모바일 백신, 앱 위변조 방지 등 정보보호 전문 벤더 솔루션 중심의 사업으로 Red Hat 스택의 직접적인 적용 범위가 없음
Red Hat 제안
가능 요소
  • 제안 가능 포인트
    • Linux 서버 OS 일반 언급: 기술적용계획표 플랫폼 분야에 "Linux" 운영체제가 적용 항목으로 표기되어 있으나, 실제 구매 품목은 Ubuntu Pro 및 Windows Server로 고정된 상태
    • FIDO 서버 호환 OS: ECR-014 FIDO인증 시스템 요건에 "Windows Server, Linux, IBM AIX 등 다양한 OS 호환성 확보"가 명시되어 있어, FIDO 서버 하단 OS로 RHEL 제안 가능성이 미약하게 존재하나 별도 구매 품목으로 명시되지 않음
    • 문서변환솔루션 서버 OS: ECR-016 문서변환솔루션 요건에 "다양한 서버 OS 지원: Linux, Windows 지원"이 명시되어 있어 이론적으로 RHEL 탑재 가능성이 있으나 별도 OS 구매 품목으로는 지정되지 않음
  • 제안 불가능 포인트 (결론)
    • RFP 내 Red Hat(또는 동의어) 제품명·수량이 전혀 명시되어 있지 않음
    • 구매 OS 품목이 Ubuntu Pro(5식)와 Windows Server 2025(96식)로 확정되어 있어 RHEL 대체 제안이 사실상 불가
    • 하이퍼바이저 환경이 VMware/Hyper-V/Nutanix AHV 중심으로 설계되어 OpenShift/RHEV 제안 여지 없음
    • 전체적으로 Red Hat 상용 제품의 도입 기회가 거의 없는 사업으로 판단됨
