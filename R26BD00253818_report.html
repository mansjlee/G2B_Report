불가능 요소
  • S/W 공급 미포함: 본 사업은 e-민원시스템·스캐너 운영·유지관리 용역이며, Red Hat 제품(RHEL·OpenShift·Ansible·JBoss 등) 신규 공급·구매 요건이 없음
  • 기존 기술스택 고정: 개발·운영 환경이 Java, JSP, 닷넷, 웹스퀘어, 전자정부 표준프레임워크로 명시되어 Red Hat 미들웨어·컨테이너 플랫폼 전환 요구 없음
  • 경쟁·대체 환경: 사용자 PC는 Windows 10 이상·크롬 등 브라우저 호환 필수, 기술적용계획표에 Windows Server·Linux 등 일반적 OS 옵션만 나열(특정 Linux/RHEL 지정 없음), VMware·Oracle 등 경쟁 제품은 명시되지 않았으나 기존 국세청 e-민원 환경 유지가 전제
  • HW·스캐너 중심: 사업 범위의 상당 부분이 스캐너 5,285대 및 주변 HW 유지관리로, Red Hat SW 제안 여지가 제한적
  • 보안·비공개 제약: 시스템 구성도·HW/SW 목록·장비 명세는 행안부 지침 제17조에 따라 비공개, 보안서약 후 열람만 가능하여 인프라 현황 기반 제안 수립 어려움

가능 요소
  • 간접적 Linux 연계 가능성: [별지 제13호] 기술적용계획표 플랫폼 분야에서 서버용 Linux를 적용 대상(√)으로만 일반 언급, e-민원 서버 OS가 Linux(RHEL)인 경우 유지관리·패치·보안취약점 조치 범위에서 RHEL 서브스크립션 간접 연계 가능(단, RFP에 RHEL 명시 없음)
  • 운영·보안 요구와의 부분 부합: ITIL v3/ISO20000 서비스관리, 패치관리·접근통제·취약점 진단 등 요구사항은 RHEL/Ansible 강점과 맞닿으나, 본 사업은 해당 역량을 인력·용역으로 수행하는 구조이며 Red Hat 제품 도입·교체를 요구하지 않음
  • 하도급·파트너 경로: 낙찰 SI가 Linux 서버·자동화·보안 패치 관리를 수행할 경우 Red Hat은 하도급 SW 공급·기술지원 파트너로 간접 참여 가능(원도급자 직접 물품구매 계획에 OS 항목이 채워질 경우에 한함, 현재 RFP 미기재)
  • 기능개선·연계: 배치 프로세스 모니터링, 장애 복구, 성능진단·과부하 테스트 등 운영 고도화 제안 시 Ansible Automation Platform 등을 제안서 부가안으로 제시할 여지는 있으나, 평가 항목은 유지관리 방법론·장애대응·인력 중심으로 Red Hat 제품 자체는 평가 대상 아님
