사업 개요 및 목적
  • 한국국토정보공사(LX)가 보상전문기관으로서 수행하는 토지보상업무 전 과정(사업수탁·준비·조사·공고·평가산정·협의·재결·이의재결·행정소송·종료)을 공간정보(GIS) 기반 One-Stop 체계로 일원화·표준화·자동화하는 시스템 구축 사업이다.
  • LX 플랫폼 기반 업무환경을 활용하여 내·외부 시스템(정부24, LTIS, 감정평가협회, ERP, 전자결재, 공공인프라, 드론플랫폼 등)과 연계하고, 보상업무의 투명성·효율성·디지털 전환을 달성하는 것이 핵심 목표이다.
  • 본 공고는 1단계('26~'27) 필수기능 구축에 해당하며, 향후 2~3단계(드론+AI 객체탐지, 지능형 플랫폼 고도화)로 확장 계획이 있다.

불가능 요소
  • S/W 공급 비중 낮음: 본 사업은 SW 개발·구축 용역(기능 88건 구현) 중심이며, H/W·운영 S/W는 발주기관(LX) 서버자원·LX 내부 클라우드·플랫폼사업처 인프라를 활용(ECR-001, SFR-002, SFR-003)
  • LX 플랫폼 종속: 모든 기능은 LX 플랫폼에 적재·PaaS API 기반 개발이 우선이며, 기 구축 솔루션 최대 활용·발주처 협의 원칙으로 Red Hat 독자 스택 제안 여지 제한
  • 오픈소스·전자정부 표준 고정: WEB/WAS/DBMS는 오픈소스 원칙, eGovFramework 3.5+·Java 기반 개발 필수(SFR-001)로 RHEL/OpenShift/JBoss 등 Red Hat 제품이 RFP에 명시되지 않음
  • 상용SW 직접구매 분리: 통합발주 대상 상용SW는 발주기관이 별도 직접구매(붙임9)하므로, 용역 계약 범위에서 Red Hat 라이선스 공급 경로가 분리됨
  • 경쟁·대체 기술 명시: 기술적용계획표에 Linux·Windows Server·POSIX 등 범용 OS만 열거, Red Hat 미언급; DB암호화·보안제품은 CC인증·국정원 검증필 등 국내 조달 제품군 기준
  • 참가 자격 제약: 20억 미만 SW사업으로 대기업·중견 SW사업자 입찰 참가 제한 — Red Hat 직접 수주보다는 중소 SI 파트너 경유 필요
  • 추가 라이선스 비용 배제: SIR-007 등에서 사용자·정보 증가 시 추가 라이선스 비용 발생하지 않아야 함 — 상용 미들웨어 도입 부담

가능 요소
  • Linux/RHEL 간접 기회: 기술적용계획표 '플랫폼 및 기반구조' 분야에 Linux·POSIX 서버 OS 적용 항목 존재 — LX 내부 클라우드·WAS/DBMS 계층에서 Linux 채택 시 RHEL 구독 제안 가능(단, 발주처·플랫폼사업처 선정 S/W)
  • PaaS/DevOps: SFR-003에서 PaaS·DevOps(개발환경) 아키텍처 반영 요구 — OpenShift Container Platform을 컨테이너 기반 개발·배포 환경으로 기술 제안 여지(플랫폼 기존 환경과 협의 필요)

  • 고가용·확장성: PER-003(동시 1,000명), QUR-001(365일 무중단), QUR-004(상호운용성) — RHEL/OpenShift의 HA·스케일아웃 아키텍처를 성능·가용성 충족 방안으로 기술 서술 가능
  • 보안·컴플라이언스: SER-003~007, CC인증·암호모듈 요건 — RHEL의 SELinux·FIPS 등 보안 강화 OS 구성을 제안서 보안 아키텍처 보조 근거로 활용 가능
  • 파트너 채널: 중소 SW사업자 대상 사업이므로 Red Hat은 낙찰 SI·컨소시엄(5개 이하, 지분 10% 이상) 파트너로 RHEL/OpenShift/Ansible 서브스크립션·기술지원 공급 형태 접근 적합
