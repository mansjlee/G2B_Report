  • S/W 신규 납품·구독 구조 아님: 기존 시스템 유지보수·운영 용역이며, OS·SW 업그레이드도 기존 주차관제 환경 내 패치 수준으로 Red Hat 상용 구독 도입 구조 아님
  • 중소기업 제한 입찰: 사업금액 20억 미만으로 대기업·중견기업 참여 불가, Red Hat 파트너사의 참여 자격 제한 가능성 존재
  • 공동도급·하도급 불허: Red Hat 제품을 별도 공급사로 참여시키는 구조 불가
  • 기존 기술지원사(KM Park) 고정: 입찰 참가 시 ㈜KM Park의 기술지원 확약서 필수 제출로 기존 SW 에코시스템이 사실상 고정됨
Red Hat 제안
가능 요소
  • OS·시스템 SW 유지보수 항목 존재: MPR-003, MPR-004, QUR-001에서 "OS·상용 S/W 업그레이드, 보안패치 수행", "시스템 S/W(OS, 웹서버, DB 등) 업그레이드 지원 및 최신 패치 적용"을 요구하나, 특정 OS 명시 없음 — 단, 기존 환경에 종속될 가능성 높아 실질적 제안 여지는 매우 제한적
  • 서버·네트워크 인프라 운영 포함: 주차관제시스템 서버·네트워크 장비 운영관리가 범위에 포함되어 있어 이론적으로 인프라 OS 환경 개선 제안의 출발점이 될 수 있으나, 기존 시스템 교체 권한은 없음
  • RFP 내 Red Hat(또는 동의어) 제품명·수량: 해당 없음 — RHEL, OpenShift, Ansible, JBoss, AAP 등 Red Hat 상용 제품명이 RFP 어디에도 명시되지 않음
  • 종합 의견: 이 사업은 기존 주차관제시스템 유지보수 전문 용역으로, Red Hat 제품 도입·납품·구독 기회가 사실상 없음. 향후 주차관제시스템 고도화·신규 구축 사업 발굴 시 Red Hat 인프라(RHEL, OpenShift) 제안을 위한 관계 구축 목적의 레퍼런스 모니터링 대상으로 분류 권고
