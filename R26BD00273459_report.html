Red Hat 제안
불가능 요소
  • S/W 신규 납품·구독 항목 없음: 본 사업은 기존 시스템의 통합 유지관리 용역으로, 신규 상용 S/W 구매·도입 항목이 RFP 내 명시되지 않음
  • Red Hat 상용 제품명 전혀 없음: RHEL, OpenShift, Ansible, JBoss EAP, Satellite 등 Red Hat 상용 제품이 RFP 어디에도 품목으로 명시되지 않음
  • OS 환경 확정: 기존 운영 OS로 SU Linux, WL Linux, CentOS가 명시되어 있으며, 이는 유지관리 대상(현상 유지)으로 기재됨
  • 경쟁 DBMS 다수 명시: Oracle, MS-SQL, MySQL, MariaDB, PostgreSQL 등 다양한 DBMS가 기존 환경으로 고정되어 있어 Red Hat AMQ, Data Grid 등의 진입 여지 제한
  • WEB/WAS 환경 확정: Apache + Tomcat 조합이 기존 WEB/WAS로 명시되어 JBoss EAP 진입 여지 낮음
  • 20억 미만 중소기업 제한 사업: 대기업·중견기업 입찰 참여 제한으로 Red Hat이 직접 입찰 불가 (파트너사 통해 접근 필요하나 SW 납품 항목 자체가 없음)
  • CentOS는 커뮤니티 제품: RFP에 명시된 CentOS는 Red Hat 상용 제품이 아닌 커뮤니티·업스트림 제품으로, 단독으로는 높음 판정 근거 불가
Red Hat 제안
가능 요소
  • CentOS → RHEL 전환 제안 여지: CentOS가 기존 운영 OS로 명시되어 있어, CentOS 지원 종료(EOL) 이슈를 활용한 RHEL 전환 제안 가능. 유지관리 사업자로서 OS 마이그레이션 전략 제안 시 RHEL 구독 영업 연계 가능
  • 클라우드 전환 계획 명시 → OpenShift 제안여지: "유지관리 사업 기간 내 일부 시스템을 클라우드 환경으로 전환할 예정"이라고 명시되어 있어, 컨테이너 플랫폼(OpenShift) 또는 클라우드 기반 RHEL 제안 연계 가능
  • Linux 중심 운영 환경: 물리서버 17대·가상머신 27개 기반의 Linux 운영 환경 전반에 걸쳐 RHEL 제안 여지 존재. IT PM 자격 요건에도 "Linux OS 개발 환경 활용" 명시
  • OS 업그레이드 의무 포함: MPR-004에 "OS 업그레이드(마이너 업그레이드 기준)" 수행이 명시되어 있어, OS 현행화 과정에서 RHEL 전환 제안 기회 창출 가능
  • 자동화·운영 효율화 수요: 24×365 운영관리, 정기점검, 패치 자동화 등의 요구사항은 Ansible Automation Platform을 통한 자동화 제안 여지로 활용 가능 (단, 현재 RFP에 명시 없으므로 간접 제안 수준)
  • RFP 내 Red Hat(또는 동의어) 명시 제품·수량: 없음 (CentOS만 명시되나 이는 커뮤니티 제품)
