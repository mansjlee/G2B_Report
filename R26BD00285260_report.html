사업 개요 및 목적
  • 한국철도기술연구원이 운영하는 업무포털, 전자결재, 통합경영정보시스템(ARIS·MIS) 등 통합정보시스템의 안정적 유지관리 및 장애 대응 체계 확립을 목적으로 함
  • 주기적 점검·정비를 통한 장애요인 사전 제거 및 신속한 복구 지원
  • 업무 환경 변화에 따른 프로그램 개선·추가 개발 수행
  • 서비스수준협약(SLA) 최초 도입을 통한 서비스 품질의 객관적 관리·측정 체계 확립
  • 소프트웨어 개발보안 적용 및 보안취약점 점검·조치를 통한 정보보안 강화

  • 사업 예산: 789,700,000원 이내 (VAT 포함)
  • 사업 기간: 2027.01.01 ~ 2028.12.31 (총 24개월)

  • 계약 방법: 제한경쟁입찰(협상에 의한 계약체결), 기술평가 90% + 가격평가 10%
  • 입찰 참가 제한: 중소기업자 간 경쟁 제품 (대기업·중견기업 참여 제한, 총 사업금액 20억 원 미만)

Red Hat 제안
불가능 요소
  • S/W 납품·구독 항목 부재: 본 사업은 기존 통합정보시스템의 유지관리 용역으로, RFP 전체에 걸쳐 신규 상용 SW 구매·납품·구독을 위한 별도 품목 목록이 존재하지 않음. 순수 인력 기반 유지관리·운영 서비스 용역 사업에 해당
  • Red Hat 상용 제품명 전혀 미명시: RHEL, OpenShift, Ansible, JBoss EAP, Satellite 등 Red Hat 상용 제품 또는 동의어가 RFP 어디에도 품목·구매 대상으로 명시되지 않음
  • 기존 시스템 고정 환경: Oracle 12c DBMS, Tomcat WAS, Apache Web Server 등 기존 스택이 이미 확정 운영 중이며, 유지관리 범위는 기존 시스템의 현상 유지 및 보완이 원칙. JBoss EAP·OpenShift 등으로의 교체 여지 없음
  • SNT 그룹웨어 독점 공급확약 요구: 전자결재 시스템은 에스엔테크놀로지(SNT) 그룹웨어로 특정되어 있으며, 제조사 공급확약서·기술지원확약서 제출이 필수 요건으로 명시됨 (MAR-003). Red Hat 개입 여지 없음
  • 중소기업자 간 경쟁 제품: 총 사업금액 20억 원 미만으로 대기업·중견기업 입찰 참여 제한 대상 사업이므로 Red Hat이 직접 입찰하거나 주도적으로 참여하기 어려운 구조
Red Hat 제안
가능 요소
  • Linux 계열 OS 사용 중 (종류 미지정): 현재 서버 OS가 "Linux"로만 명시되어 있어 배포판이 특정되지 않음. 향후 OS 재계약·업그레이드 시 RHEL 전환 제안 여지가 존재하나, 본 사업 범위 내에서는 납품 기회 없음
  • SW 업그레이드 지원 조항 존재: PSR-001(소프트웨어 업그레이드 지원)에서 OS·DBMS·WEB/WAS 등의 버전 패치·업그레이드 필요 시 수행 방안 제시 요구가 있어, 유지관리 수행 과정에서 Linux OS 관련 기술적 대화 가능성 있음. 그러나 실제 구매 발생 가능성은 매우 낮음
  • Java 기반 시스템 환경: Java·JSP·HTML5 기반 애플리케이션 운영 환경으로, JBoss EAP 또는 OpenShift 기반 전환에 대한 중장기적 제안 가능성은 있으나, 현재 RFP 범위 밖의 내용
  • RFP 내 Red Hat 제품명 명시 없음: RFP 및 관련 문서 전체에 Red Hat(레드햇), RHEL, OpenShift, Ansible, JBoss EAP 등 Red Hat 상용 제품명이 전혀 등장하지 않음. 제안 기회 없음
