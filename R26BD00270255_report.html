경찰청_해안경계 관제시스템 고도화 - 분석 리포트

레드햇 제안 가능성 낮음
S/W 전량 개별개발, 상용 SW 구매 없음
사업 개요 및 목적
  • 경찰청 해안경비단·대에서 운영 중인 해안경계 관제시스템에 해양수산부 e-Navigation 정보를 추가 연계하여 해안경계 업무 효율성 향상
  • 기존 AIS, VHF-DSC, V-Pass 기반 선박 식별 체계에 e-Navigation 단말기(11,000척 이상 운용) 정보를 통합, 모든 어선 위치 실시간 감시 가능하도록 고도화
  • 해수부 GICOMS 시스템을 통해 e-Navigation 정보를 경찰청 보안망으로 연계하는 S/W를 신규 개발하고, 제주·가거·울릉 3개 해안경비부대의 기존 관제시스템을 각각 개선
주요 정보
  • 사업 예산: 620,000,000원 (부가세 포함)
  • 사업 기간: 계약 후 5개월 이내 (조기완료 가능)
  • 사업 범위: 제주해안경비단, 울릉해안경비대, 가거해안경비대 대상 ① 해수부 e-Navigation 경찰청 보안망 연계 S/W 개발(경찰청 연계 S/W 1식 + e-Nav 연계 모듈 3식) ② 기존 해안경계 관제시스템 응용 S/W 개선 및 DB 구조 변경(3개소 개별 수행)
  • 계약 방법: 제한경쟁입찰 (협상에 의한 계약), 중소기업자만 입찰 참가 가능
  • 주요 일정: 착수(M) → 분석/설계(M+1~M+2) → S/W 개발·시스템 구축(M+2~M+4) → 시험/시범운영·준공검사(M+4~M+5) / 준공 전 최소 1개월 이상 시운전 기간 확보 필요

핵심 요구사항
  • [기술 요구사항] 해수부 GICOMS e-Nav 수신서버로부터 경찰청 보안망으로의 데이터 연계·수집·분석 S/W 신규 개발, 3개 경비부대별 G/W 서버 환경에 맞는 e-Nav 연계 모듈 개별 개발
  • [기능 요구사항] 통합 게이트웨이 S/W(프로토콜 변환·데이터 통합), 통합선박모니터링 S/W(전자해도 기반 실시간 표출), 항적저장 S/W(DB 서버 항적 저장·조회) 등 기존 응용 S/W 개선
  • [성능 요구사항] e-Navigation 선박 정보 수신 후 5초 이내 화면 전시, 동시 접속자 30명 기준 365일 24시간 무중단 서비스
  • [보안 요구사항] SW 개발보안 가이드(행안부) 준수, 개인정보 암호화(국정원 기준), 사업수행 인력 신원조사 및 보안서약 필수
  • [이식성 요구사항] 시스템은 윈도우 또는 리눅스 환경에서 운영 가능해야 함 (QUR-004)
  • [구매 S/W 현황] 붙임12(직접구매 대상 상용소프트웨어 구매계획)에 따르면, 연계(1) S/W 1식, 연계(2) S/W 3식, 관제(1) S/W 1식, 관제(2) S/W 1식, 관제(3) S/W 1식이 명시되어 있으나, 전량 직접구매 제외 — "나라장터 종합쇼핑몰·디지털서비스몰 등록 상용제품이 없어 전량 개별 개발·개조로 추진(개발 N21 해당)"으로 명시됨. 통합발주 또는 상용 S/W 구매 품목 없음
Red Hat 제안
불가능 요소
  • [상용 S/W 구매 없음] 붙임12에 명시된 5개 S/W 품목(연계·관제 S/W) 전부 "직접구매 제외 — 개별 개발(N21)"로 처리됨. 나라장터 종합쇼핑몰 등록 상용 제품이 없는 순수 개발 용역 사업으로, Red Hat 상용 제품(RHEL, OpenShift, Ansible 등)의 품목 납품 기회 없음
  • [HW 납품 없음] 기술적용계획표(붙임11) 플랫폼 분야에 "해당 사업 HW 납품 없음"이 명시되어 있어 서버·인프라 도입에 수반되는 OS 구독 기회도 없음
  • [Red Hat 상용 제품명 전혀 없음] RFP 전문에 RHEL, OpenShift, Ansible, JBoss, AAP 등 Red Hat 상용 제품명 또는 동의어가 단 한 건도 언급되지 않음
  • [기존 인프라 재활용] "기존 AIS 연계망 인프라는 재활용(구축비 최소화)"으로 명시되어 신규 인프라 도입 최소화 방침이 확인됨
  • [폐쇄망 작전 시스템] 경찰청 보안망(폐쇄망) 기반 작전용 시스템으로, 소프트웨어 사업 영향평가 제외 대상인 "단일기관 내부사용 목적 SW사업"으로 분류됨
Red Hat 제안
가능 요소
  • [이식성 요구 — Linux 언급] QUR-004(이식성) 요구사항에 "시스템은 윈도우 또는 리눅스 환경에서 운영이 가능해야 한다"고 명시되어 있어, 향후 운영 서버 OS로 Linux 계열 제안 여지가 원론적으로 존재하나, 본 사업에서 OS를 별도 구매하는 품목은 없음
  • [전자정부 표준 프레임워크 적용] Java 기반 전자정부 표준프레임워크 적용이 명시되어 있어, JBoss EAP 등 Java 미들웨어 제안 여지가 있으나 미들웨어 상용 구매 품목이 없어 실질적 영업 기회는 제한적
  • [RFP 내 Red Hat 제품명 없음] RFP에 Red Hat 또는 동의어 제품이 명시된 사례 없음. 제안 가능 요소가 매우 제한적이며 전반적으로 낮음 판정에 부합
