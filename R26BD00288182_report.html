Red Hat 제안
불가능 요소
  • Red Hat 상용 제품 전무: RFP 전체에 RHEL, OpenShift, Ansible, JBoss EAP 등 Red Hat 상용 제품명이 단 한 건도 명시되지 않음
  • WAS 환경이 JEUS(Tmax)로 고정: 투입 인력 기술 요구사항(MHR-002)에 Webtob·Jeus가 명시되어 있으며, 12종 상용SW 유지관리 대상에 WebtoB·JEUS가 포함되어 기존 미들웨어 스택이 Tmax 제품으로 확정됨 → JBoss EAP 제안 불가
  • SW 납품 구조 아님: 신규 상용 SW 구매·도입이 아닌 기존 SW 유지관리비를 사업비에 포함하는 구조로, Red Hat 신규 SW 납품 기회 없음
  • 서버 OS 비공개: WAS·WEB·DB 서버 운영 환경이 보안 사항으로 비공개 처리되어 있어 OS 교체 제안 근거 부재
  • 사업 성격이 용역 중심: 사업비 대부분이 인력 투입 기반의 개발·운영·유지관리 용역이며, HW·SW 직접 구매 항목이 없음
  • 클라우드 플랫폼 미지정: 신규 클라우드 구축은 "발주기관이 도입 예정인 민간 클라우드"로 서울시가 별도 결정하며, 제안사는 해당 환경에 WEB/WAS 소프트웨어만 설치·운영하는 구조
Red Hat 제안
가능 요소
  • Linux 적용 계획 확인: 기술적용계획표(붙임 11)에 Linux 서버용 운영체제 적용 계획(○)이 표기되어 있어, 이론적으로 RHEL 제안 여지가 있으나 현재 운영 OS가 보안 사항으로 비공개이며 교체 여부 불명확
  • 민간 클라우드 신규 구축 시 OS 선택 가능성: 서울형 낀세대 연금 민간 클라우드 환경에서 제안사가 WEB/WAS 등 소프트웨어를 직접 설치·운영하도록 명시되어 있어, 이 환경에서의 Linux OS 선택 가능성 존재 (단, 클라우드 플랫폼 자체는 발주기관 결정)
  • 해당 RFP에 Red Hat(또는 동의어) 제품 명시 없음: RHEL, OpenShift, Ansible, JBoss EAP 등 어떠한 Red Hat 상용 제품도 품목·수량으로 명시되지 않아 제안 근거 매우 취약
  • 종합 평가: 현실적으로 Red Hat 제품 제안 기회는 극히 제한적이며, 본 사업에서 실질적인 Red Hat 영업 기회는 없는 것으로 판단됨
