Red Hat 제안
불가능 요소
  • S/W 납품 미포함: 본 사업은 클라우드 기반 KRAS의 유지관리 및 운영지원 순수 용역으로, 신규 S/W 도입·납품·구독 항목이 전혀 명시되지 않음
  • Red Hat 상용 제품명 미명시: RFP 전문 어디에도 RHEL, OpenShift, Ansible, JBoss EAP, Satellite 등 Red Hat 상용 제품명이 기재되어 있지 않음
  • 경쟁·대체 제품 명시 없음: Ubuntu, Rocky Linux, VMware 등 경쟁 제품도 명시되지 않으나, 동시에 Red Hat 제품도 전혀 언급되지 않음
  • 운영 환경 불명확: 기술적용계획표에 Linux, Windows Server, UNIX 등 OS 선택지가 나열되어 있으나 현행 운영 환경의 특정 OS 제품명이 명시되지 않음 (DB서버만 UNIX 사용으로 일부 언급)
  • 상용SW 유지보수 지원은 간접 지원: 기존 운영 중인 상용SW(레포팅, 암호화, GIS엔진 등)의 유지보수 업체를 지원하는 역할이며, Red Hat SW가 포함된다는 근거 없음
  • 중소기업 참여 사업: 40억원 미만 사업으로 대기업 참여 불가, Red Hat 직접 참여 어려움
Red Hat 제안
가능 요소
  • RFP 내 Red Hat 상용 제품 명시 없음: RHEL, OpenShift, JBoss EAP, Ansible 등 Red Hat 상용 제품이 도입·유지보수 대상으로 명시되지 않아 판정 근거 없음
  • 클라우드 기반 시스템 운영 환경: 클라우드 기반(국가정보자원관리원 광주·대전)으로 운영되는 시스템으로, 향후 인프라 확장이나 차세대 전환 시 RHEL, OpenShift 제안 여지가 존재하나 본 사업 범위 내에서는 해당 없음
  • Linux 계열 OS 사용 가능성: 기술적용계획표에 Linux가 선택지로 포함되어 있어 현행 시스템이 Linux 환경일 가능성이 있으나, 특정 제품명 미확인으로 RHEL 직접 제안 근거 불충분
  • WAS 서버 운영 환경: 대규모 웹 기반 행정시스템으로 Java 기반 WAS 환경이 운영되고 있을 가능성이 높으나, JBoss EAP 등 Red Hat WAS 제품 명시 없음
  • 간접 영업 기회: 현행 사업 수주 SI 업체를 통한 파트너 채널 협력으로 기존 구독 현황 파악 및 갱신 기회 모색 가능
