사업 개요 및 목적
  • 「2023년 목포시 강소형 스마트시티 조성사업」의 일환으로, 목포벤처문화산업지원센터에 데이터 밸류체인 플랫폼(HW·서버실·SW)을 통합 구축하는 용역이다.
  • 스마트시티 운영 서비스(전기셔틀·버스관제·탄소중립형 버스쉼터·업사이클링 등) 및 공공데이터를 NGSI-LD 기반으로 수집·연계·분석·개방하고, 해남 광역 데이터 허브와 연계하여 도시문제 해결 및 정책 활용 기반을 마련하는 것이 핵심 목표이다.
  • 해양환경·기후위기·지역소멸 등 목포시 도시과제를 데이터 기반으로 체계화하고, 친환경 스마트 해양도시 조성을 지원한다.

Red Hat 제안
불가능 요소
  • **S/W 공급 구조**: Red Hat 제품 단독 조달 사업이 아니라, 중소 SW·정통·설비 업체가 수행하는 통합 구축·개발 용역이다. Red Hat은 납품 S/W가 아닌 제안사 선정 OS·플랫폼 후보로만 등장한다.
  • **경쟁·대체 OS 명시**: ECR-003에서 서버 OS를 "Ubuntu, Redhat, Oracle" 중 제안사가 선택하도록 규정하여 특정 Red Hat 제품(RHEL) 지정이 없다.
  • **상용 보안 S/W 고정**: 유닉스/리눅스 서버용 보안솔루션 45조, 패치관리 3조, PC백신 3조, Windows 11 Home 1조 등은 통합발주 품목으로 명시되어 Red Hat 보안·관리 제품(Ansible 외 별도 S/W) 직접 대체·납품 경로가 제한적이다.
  • **플랫폼·미들웨어**: NGSI-LD·FIWARE·Spring OAuth/JWT·전자정부 표준프레임워크 등 자체/오픈소스 기반 커스텀 개발이 중심이며, JBoss EAP 등 미들웨어 지정은 없다.
  • **입찰 참가 제약**: 20억 미만 SW사업으로 대기업·중견 SW사업자 참여 불가 → Red Hat은 직접 입찰 주체가 아니며, 파트너(중소 SI) 경유 간접 제안만 가능하다.
  • **평가 가점**: TTA 스마트시티 데이터허브 인증(3점) 등 Red Hat 인증과 무관한 정량 항목이 있어, Red Hat 단독으로 평가 우위 확보가 어렵다.
Red Hat 제안
가능 요소
  • **RHEL**: DB·외부팜·내부팜 서버 9대 + OS 라이선스 제안 필요(ECR-003). RHEL을 안정적 엔터프라이즈 Linux로 제안 가능하며, Ubuntu·Oracle Linux와 경쟁한다.
  • **Red Hat OpenShift**: SFR-011의 쿠버네티스·멀티클러스터·Helm·RBAC·오프라인 설치·통합 모니터링·GS/CNCF 인증 요구와 높은 정합성. OpenShift Container Platform 또는 OpenShift Kubernetes Engine으로 플랫폼 레이어 제안 가능.
  • **Red Hat Ansible Automation Platform**: 클러스터 설치 자동화, 노드 증설·교체, 보안패치·설정관리, 폐쇄망 오프라인 배포 등 SFR-011·운영 요구에 부합하는 자동화 레이어로 제안 가능(단, RFP의 패치관리솔루션 3조와 역할 구분 필요).
  • **컨테이너·DevOps**: BaseImage(Linux), Java·Python·Node.js, Spring Boot 호환, 프라이빗 레지스트리·이미지 취약점 점검 요구 → OpenShift + Quay(또는 레드햇 레지스트리) 연계 제안 가능.
  • **제안 전략**: 중소 SW·정통 공동수급 SI 파트너와 RHEL+OpenShift(+Ansible) 번들 제안, TTA 데이터허브 인증·NGSI-LD 연계 아키텍처에서 Red Hat 기반 PaaS 레퍼런스를 차별화 포인트로 활용 가능.
