Red Hat 제안
가능 요소
  • RHEL: 플랫폼·데이터 수집·분석 서버, API·배치 처리 노드의 안정적 Linux 기반 OS로 제안 가능(공공 SI 제안서 내 인프라 표준 OS).
  • OpenShift: 실시간 데이터 수집·분석·대시보드·외부 연계 API를 컨테이너·마이크로서비스로 구성하는 플랫폼 기반, AI·IoT 실증 서비스 배포·확장에 적합.
  • Ansible: 다수 건물·설비·센서 연동 환경의 구성관리, 배포 자동화, 운영·패치·장애대응 자동화 제안 가능.
  • 기술 요구 부합: 실시간 모니터링, 대용량 시계열 데이터 처리, 외부 시스템 연동, 보안·가용성·확장성 요구와 Red Hat 플랫폼 스택의 강점(컨테이너 오케스트레이션, 엔터프라이즈 지원, 자동화)이 부분 일치.
  • 추가 제안 여지: RFP상 “과업내용 이외 추가 제안 가능”, “효율적 방안 제시”가 허용되어 파트너 제안서에 Red Hat 기반 아키텍처·운영 자동화를 차별화 요소로 포함 가능.
  • 영업 전략: 유사 공공·스마트시티·에너지 플랫폼 SI 파트너와 공동 제안, 기술평가(90점) 중심 입찰에 OpenShift/Ansible 기반 운영·확장·보안 우수성을 기술제안서에 반영하는 방식이 유효.
