Red Hat 제안
불가능 요소
  • 신규 S/W 구매 없음: 본 사업은 기존 도입 S/W에 대한 유지관리 용역으로, 신규 Red Hat 제품 납품·구독 구매 항목이 별도로 명시되지 않음
  • WildFly(커뮤니티판) 명시: 공개 SW 목록에서 JBoss로 표기된 항목들이 모두 "JBoss(Wildfly24)", "JBoss(Wildfly18.0.1)", "JBoss(Wildfly26.1.3.Final)", "JBoss(Wildfly24.0.1.Final)" 등 Wildfly 버전으로 명시되어 있어, 해당 WAS는 커뮤니티 버전(JBoss EAP 상용 아님)으로 운영 중임 — JBoss EAP 전환 제안 여지는 있으나 현재 확정 도입 아님
  • VMware 명시: 안전성분석시스템(VMware vSphere Standard 8, 192Core, 2024년 도입)과 BMT 테스트서버(VMware vSphere Standard, 2024년 도입) 등 VMware 가상화 솔루션이 유지관리 대상으로 명시됨
  • Tibero, Jeus, WebtoB 등 국산 미들웨어 중심 운영 환경: 대부분의 WAS/DB/웹서버는 Tmax(Jeus, WebtoB, Tibero) 기반으로 구성되어 있어 Red Hat JBoss 제안 범위 제한
  • 경쟁 보안 솔루션(RedCastle)의 "for Redhat Enterprise Linux" 의존: 서버보안 솔루션 RedCastle이 RHEL 환경에 종속 설치되어 있어 OS 교체 제안이 어려운 구조
  • 대기업 입찰 불가: 사업금액 20억~40억 미만으로 대기업 소프트웨어사업자 입찰 참여 제한 — Red Hat 직접 참여보다 파트너사를 통한 간접 제안 필요
Red Hat 제안
가능 요소
  • [RHEL — 유지관리 대상 명시, 높음 판정 근거]
    • 공개 SW 유지관리 대상 목록에 RHEL 8 총 27식 명시 (수입농산물 서버 12식, 친환경 서버 8식, GIS·OTP 등 서버 7식)
    • 상용 SW 목록에 RedCastle V4.0 for Redhat Enterprise Linux 7 (복수 식), RedCastle V4.0 for Redhat Enterprise Linux 8 (RHEL 8) 5식, Secuve TOS 5.0 for Linux (RHEL 9) 2식 명시 → RHEL 7/8/9 운영 환경 확인
    • 기존 RHEL 구독 갱신·버전 업그레이드(RHEL 7→8→9 마이그레이션) 제안 기회
  • [RHEV(Red Hat Enterprise Virtualization) — 유지관리 대상 명시]
    • 상용 SW 목록에 퓨젼데이타_jportal (RedHat Enterprise Virtualization) 1식, 퓨젼데이타_RedHat Enterprise Virtualization Server(20개) 1식 명시 (VDI 가상화 솔루션, 2017·2020년 도입)
    • RHEV는 현재 Red Hat OpenShift Virtualization / OpenShift로 전환 경로 존재 — 차세대 가상화 플랫폼 전환 제안 기회
  • [RHEL AI / OpenShift 제안 여지]
    • 정보시스템의 국가정보자원관리원 대구센터 이전 및 클라우드 전환 방안 수립(PSR-005) 요구 → OpenShift(컨테이너 플랫폼) 기반 클라우드 전환 제안 가능
    • 기존 RHEL 서버 환경을 기반으로 OpenShift로의 현대화 로드맵 제시 가능
  • [Ansible 제안 여지]
    • 다수 서버(133식)·소프트웨어(377식) 대상 패치관리, 보안 취약점 조치, 설정 변경 자동화 필요 → Ansible Automation Platform 도입 제안 가능
  • [JBoss EAP 전환 제안 여지]
    • 현재 Wildfly(커뮤니티) 기반으로 운영 중인 WAS 환경(수입농산물·친환경·정부양곡·공공데이터·안전성분석 시스템)에 대해 상용 JBoss EAP 전환 제안 가능 (보안지원·기술지원·라이선스 안정성 측면)
  • [파트너사 연계 제안 전략]
    • 대기업 입찰 불가 사업이므로, Red Hat 공인 파트너(중소기업)가 입찰사로 참여하여 RHEL 구독 갱신·RHEV 유지보수·OpenShift 전환 제안을 포함한 솔루션 구성 권장
    • 기존 RHEL 구독 만료 시점 확인 및 갱신 영업 기회 선점 필요
